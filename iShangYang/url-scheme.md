<section lang="en" markdown="1">

爱商鞅 / iShangYang supports **`ishangyang://`** shortcut links (URL scheme). Cold start and Home Screen shortcuts are delivered through a unified buffer so links are not opened twice after onboarding.

## Link format

```
ishangyang://{host}?{params}
```

## Unique desk

| URL | Opens |
|-----|-------|
| `ishangyang://daily` | Daily Reform |
| `ishangyang://fables` / `ishangyang://edict?id=` | Reform edicts |
| `ishangyang://chronicle` / `ishangyang://timeline` | Reform chronicle |
| `ishangyang://figures` / `ishangyang://figure?id=` | Figures |
| `ishangyang://study` | Reform Study |
| `ishangyang://hunt` | Moving the Pole |

## Shared reading paths

| URL | Opens |
|-----|-------|
| `ishangyang://home` | Home |
| `ishangyang://passage?id=` / `ishangyang://chapter?id=` | Passage detail |
| `ishangyang://recite` / `ishangyang://recite?id=` | Recite |
| `ishangyang://random` | Random passage |
| `ishangyang://favorites` | Favorites |
| `ishangyang://search?q=` | Search |
| `ishangyang://famous` | Famous lines |
| `ishangyang://categories` | Browse |
| `ishangyang://last-read` | Last read |
| `ishangyang://reading-history` | Reading history |
| `ishangyang://notes` | Notes |
| `ishangyang://handwriting` | Handwriting search (iOS) |
| `ishangyang://settings` | Settings |
| `ishangyang://usage-guide` | Usage guide |
| `ishangyang://widget-guide` | Widget guide |
| `ishangyang://shortcuts-guide` | Shortcuts guide |
| `ishangyang://feature-guide` | Replay onboarding |
| `ishangyang://feedback` | Feedback email |

## Examples

```
ishangyang://daily
ishangyang://chronicle
ishangyang://fables
ishangyang://study
```
