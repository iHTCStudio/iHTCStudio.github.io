<section lang="en" markdown="1">

爱鬼谷子 / iGuige supports **`iguige://`** shortcut links (URL scheme). Cold start and Home Screen shortcuts are delivered through a unified buffer so links are not opened twice after onboarding.

## Link format

```
iguige://{host}?{params}
```

## Unique desk

| URL | Opens |
|-----|-------|
| `iguige://daily` | Daily Strategy |
| `iguige://rhetoric` | Speak to Each Kind |
| `iguige://arts` / `iguige://art?id=` | Art cards |
| `iguige://cases` / `iguige://case?id=` | Warring States cases |
| `iguige://scenarios` | Modern study scenes |
| `iguige://persons` / `iguige://timeline` | Figures & chronology |
| `iguige://study` | Guigu Academy |
| `iguige://hunt` | Hunt the Art |
| `iguige://counselor` | On-device advisor (iOS 26+) |

## Shared reading paths

| URL | Opens |
|-----|-------|
| `iguige://home` | Home |
| `iguige://passage?id=` / `iguige://chapter?id=` | Passage detail |
| `iguige://recite` / `iguige://recite?id=` | Recite |
| `iguige://random` | Random passage |
| `iguige://favorites` | Favorites |
| `iguige://search?q=` | Search |
| `iguige://famous` | Famous lines |
| `iguige://categories` | Browse |
| `iguige://last-read` | Last read |
| `iguige://reading-history` | Reading history |
| `iguige://notes` | Notes |
| `iguige://handwriting` | Handwriting search (iOS) |
| `iguige://settings` | Settings |
| `iguige://usage-guide` | Usage guide |
| `iguige://widget-guide` | Widget guide |
| `iguige://shortcuts-guide` | Shortcuts guide |
| `iguige://feature-guide` | Replay onboarding |
| `iguige://feedback` | Feedback email |

## Examples

```
iguige://daily
iguige://rhetoric
iguige://cases
iguige://study
```
