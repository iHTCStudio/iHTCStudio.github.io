**Everyday math, engineering units, and developer utilities — one beautifully designed app for iPhone and iPad.**

iConverter brings **101 calculators and converters** into a single offline-first toolkit. From mortgage planning to QR scan/generate, from unit conversion to an in-app **Web Browser with NetLog** — tap any result to copy, pin favorites, and jump in from widgets or `iconverter://` deep links.

## Getting Started

1. Open iConverter and browse the tool menu by category or use the search bar.
2. Tap any tool to open it. Results update instantly as you type.
3. Tap any result value to copy it to the clipboard (with haptic feedback).
4. Pin your most-used tools to the home screen for one-tap access.
5. Add widgets to your Home Screen or Lock Screen to access tools without opening the app.

## Key Features

- **101 Tools** — Calculators, converters, encoders, date tools, lifestyle helpers, sensors and more, all in one app.
- **Care Mode** — Large-type home grid of everyday tools, spoken key presses and results, simplified forms, and `iconverter://care/on`. Portrait-only on iPhone while active.
- **Help Center** — Settings → **Help**: usage guide, widget tutorial, Shortcuts & Siri guides, and About. Deep links such as `iconverter://help/widget-guide`.
- **Magnifier** — Rear camera 1–10× zoom, torch, and freeze-frame; pinch to zoom, slider for fine control.
- **Media Download** — Parse common page links on-device (with optional custom resolver you configure); download library, save to Photos or Files, hand off to Video Frame Export. **Share extension** queues links when the main app is not open.
- **QR Code history** — Separate generate/scan history (up to 100 entries) with style restore on tap.
- **Live Activities (iPhone, iOS 17+)** — Continue supported calculator, converter, and relationship tools from Lock Screen / Dynamic Island when you leave the app.
- **Instant Results** — Fields update in real time as you type. No submit button needed.
- **One-Tap Copy** — Tap any result to copy it, with haptic confirmation and a brief toast notification.
- **QR Code** — Generate codes (multiple formats) or **scan** with the camera; open `iconverter://` links directly.
- **Widgets** — 21 interactive widgets for Home Screen, Lock Screen, and StandBy. **Settings → Widget color style** offers default (per-tool colors), partial accent, or full accent (background included). **About → Widget guide** walks through setup.
- **Launcher widget** — Pick any supported tool for one-tap access (**Web Browser** is excluded — no persistent widget state).
- **URL Scheme** — Open any tool from Safari, Shortcuts, another app, or a scanned QR code using `iconverter://` deep links. Parameters can pre-fill input fields. See the [URL Scheme Reference](url-scheme).
- **Pinned Tools** — Pin up to 8 tools to the home quick-access strip.
- **Home Screen Shortcuts** — Add up to 4 tool shortcuts directly to your iOS Home Screen.
- **Calculator History** — Shared history across all three calculators. Tap any entry to restore it.
- **Unit Copy with Symbol** — Optionally include the unit symbol when copying unit conversion results.
- **Accent Color** — Choose from 12 preset colors or a fully custom color picker.
- **App Icons** — Multiple alternate app icons included.
- **Three Languages** — Simplified Chinese · Traditional Chinese · English, switchable in **Settings → Language** (independent of system language). **Widget configuration UI** (iOS system picker when adding/editing widgets) follows **device system language**, not the in-app language override.
- **Dark Mode** — Full support for Light, Dark and System appearance.
- **Offline-first** — All tools work on-device (except the Web Browser tool, which loads pages from the internet).
- **Privacy-first** — No account, no analytics SDKs, no third-party tracking.

## Web Browser Tool

The built-in **Web Browser** (Encoding category) supports:

- Address bar with auto-search (Bing · Google · Baidu · DuckDuckGo · custom engine) and configurable **home page**
- Bookmarks and navigation history
- Desktop User-Agent toggle
- Auto-refresh timer
- **NetLog** — capture fetch/XHR, console output, and page errors in a filterable sheet (Settings → Web Browser section in app)
- JS debugger injection (Eruda / vConsole / custom script)
- Page source viewer
- In-page text search
- URL QR code sharing
- Cookie import/export
- Keep-awake screen lock override

## Video Frame Export Tool

- Optional timecode + frame number watermark
- Batch burst export: configurable radius and step

## 주요 기능

- 101 도구 ** — 계산기， 변환기， 인코더， 날짜 도구， 라이프스타일 도우미， 센서 등 모든 것이 하나의 앱에 있습니다。
- **Care Mode** — 일상용 도구의 대형 홈 그리드， 음성 키 누르기 및 결과， 간소화된 양식， 그리고 `iconverter://care/on`. 활성 상태일 때 iPhone에서만 초상화 사용 가능。
- 도움말 센터 - 설정 → 도움말: 사용 설명서， 위젯 튜토리얼， 단축키 및 Siri 가이드， 정보. `iconverter://help/widget-guide`와 같은 심층 링크。
- 확대기 - 후면 카메라 1~10 배 확대/축소， 손전등 및 정지 프레임; 손가락을 오므려 확대/축소하고， 슬라이더로 미세 조정。
- ** 미디어 다운로드 ** – 장치에서 일반 페이지 링크를 구문 분석합니다 (사용자가 구성한 선택적 사용자 지정 해석기 사용). 라이브러리를 다운로드하고， 사진 또는 파일에 저장하며， 비디오 프레임 내보내기로 전달합니다. ** 메인 앱이 열려 있지 않을 때 공유 확장 ** 대기열에 링크를 넣습니다。
- **QR 코드 기록 ** – 탭 시 스타일 복원을 통해 별도의 생성/스캔 기록 (최대 100 개 항목) 을 분리합니다。
- ** 라이브 활동 (iPhone, iOS 17+)** - 앱을 종료할 때 잠금 화면/Dynamic Island 에서 지원되는 계산기， 변환기 및 관계 도구를 계속 사용할 수 있습니다。
- ** 인스턴트 결과 ** – 입력 시 필드가 실시간으로 업데이트됩니다. 제출 버튼이 필요하지 않습니다。
- ** 원터치 복사 ** – 결과를 탭하여 복사하면 햅틱 확인 및 간단한 건배 알림이 표시됩니다。
- QR 코드 - 코드 (여러 형식) 를 생성하거나 카메라로 스캔합니다. `iconverter://` 링크를 직접 열 수 있습니다。
- ** 위젯 ** – 홈 화면， 잠금 화면 및 대기용 21 개의 대화형 위젯. ** 설정 → 위젯 색상 스타일 ** 은 기본 (도구별 색상), 부분 악센트 또는 전체 악센트 (배경 포함) 를 제공합니다. ** 정보 → 위젯 가이드 ** 는 설정을 안내합니다。
- **Launcher 위젯 ** – 원터치 액세스를 위해 지원되는 모든 도구를 선택합니다 (** 웹 브라우저 ** 는 제외됩니다 – 지속적인 위젯 상태가 없습니다).
- **URL Scheme** – Safari, 단축어， 다른 앱 또는 `iconverter://` 딥 링크를 사용하여 스캔한 QR 코드에서 도구를 엽니다. 매개변수는 입력 필드를 미리 채울 수 있습니다. [URL Scheme 참조](url-scheme) 를 참조하십시오。
- ** 고정된 도구 ** – 홈 빠른 액세스 스트립에 최대 8 개의 도구를 고정합니다。
- 홈 화면 단축키 - 최대 4 개의 도구 단축키를 사용자의 iOS 홈 화면에 직접 추가할 수 있습니다。
- ** 계산기 기록 ** – 세 개의 계산기 모두에서 공유되는 기록입니다. 어떤 항목이든 탭하여 복원합니다。
- 기호를 사용하여 단위 복사 - 단위 변환 결과를 복사할 때 선택적으로 단위 기호를 포함합니다。
- ** 강조 색상 ** – 12 개의 프리셋 색상 또는 완전한 사용자 지정 색상 선택기에서 선택합니다。
- ** 앱 아이콘 ** – 여러 대체 앱 아이콘이 포함됩니다。
- 3 개 언어 ** - 간체 중국어 · 번체 중국어 · 영어， ** 설정 → 언어 ** 에서 전환 가능 (시스템 언어와 독립적). ** 위젯 구성 UI** (위젯을 추가/편집할 때 iOS 시스템 선택기) 는 앱 내 언어 재정의가 아닌 ** 장치 시스템 언어 ** 를 따릅니다。
- ** 다크 모드 ** – 라이트， 다크 및 시스템 모양에 대한 전체 지원。
- ** 오프라인 우선 ** – 모든 도구가 장치에서 작동합니다 (인터넷에서 페이지를 로드하는 웹 브라우저 도구 제외).
- ** 개인정보 보호 우선 ** – 계정 없음， 분석 SDK 없음， 타사 추적 없음。

## Ключевые функции

- 101 Инструменты** — Калькуляторы, конвертеры, кодировщики, инструменты даты, помощники по стилю жизни, датчики и многое другое — все в одном приложении.
- **Режим ухода** — Крупная домашняя сетка повседневных инструментов, голосовые нажатия клавиш и результаты, упрощенные формы и `iconverter://care/on`. Портрет только на iPhone при активном режиме.
- Центр справки** — Настройки → **Справка**: руководство по использованию, учебное пособие по виджетам, руководства по Быстрым командам и Siri и О. Глубокие ссылки, такие как `iconverter://help/widget-guide`.
- **Лупа** — Задняя камера 1–10× увеличение, фонарик и стоп-кадр; сведение пальцев для увеличения, ползунок для точного управления.
