<section lang="en" markdown="1">

爱子思 / iZiSi supports **`izisi://`** shortcut links (URL scheme). Cold start and Home Screen shortcuts are delivered through a unified buffer so links are not opened twice after onboarding.

## Link format

```
izisi://{host}?{params}
```

## Unique desk

| URL | Opens |
|-----|-------|
| `izisi://daily` | Today’s Thought |
| `izisi://shendu` / `izisi://vigilance` | Watchfulness studio |
| `izisi://five-steps` / `izisi://wubu` | Five steps |
| `izisi://wuxing` | Five Conducts gallery |
| `izisi://lineage` | Lineage map |
| `izisi://home-quick` | Home quick grid |
| `izisi://study` | Zisi Study |
| `izisi://hunt` | Find the Mean |

## Shared reading paths

| URL | Opens |
|-----|-------|
| `izisi://home` | Home |
| `izisi://passage?id=` / `izisi://chapter?id=` | Passage detail |
| `izisi://recite` / `izisi://recite?id=` | Recite |
| `izisi://random` | Random passage |
| `izisi://favorites` | Favorites |
| `izisi://search?q=` | Search |
| `izisi://famous` | Famous lines |
| `izisi://categories` | Browse |
| `izisi://last-read` | Last read |
| `izisi://reading-history` | Reading history |
| `izisi://notes` | Notes |
| `izisi://handwriting` | Handwriting search (iOS) |
| `izisi://settings` | Settings |
| `izisi://usage-guide` | Usage guide |
| `izisi://widget-guide` | Widget guide |
| `izisi://shortcuts-guide` | Shortcuts guide |
| `izisi://feature-guide` | Replay onboarding |
| `izisi://feedback` | Feedback email |

## Examples

```
izisi://daily
izisi://shendu
izisi://wuxing
izisi://five-steps
```
