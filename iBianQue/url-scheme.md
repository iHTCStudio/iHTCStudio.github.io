爱扁鹊 / iBianQue supports **`ibianque://`** shortcut links (URL scheme). Cold start and Home Screen shortcuts are delivered through a unified buffer so links are not opened twice after onboarding.

## Link format

```
ibianque://{host}?{params}
```

|-----|-------|

| `ibianque://atlas` / `ibianque://meridian` | Meridian atlas |

| `ibianque://quiz` | Playful constitution quiz |
| `ibianque://tongue` | On-device tongue color sketch |
| `ibianque://nanjing` | Nan Jing shelf |
| `ibianque://study` | Que Study |
| `ibianque://hunt` | Point Hunt |

| `ibianque://concepts` | Concepts |
