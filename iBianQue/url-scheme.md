<section lang="en" markdown="1">

爱扁鹊 / iBianQue supports **`ibianque://`** shortcut links (URL scheme). Cold start and Home Screen shortcuts are delivered through a unified buffer so links are not opened twice after onboarding.

## Link format

```
ibianque://{host}?{params}
```

## Unique desk

| URL | Opens |
|-----|-------|
| `ibianque://daily` | Daily Art |
| `ibianque://atlas` / `ibianque://meridian` | Meridian atlas |
| `ibianque://point?code=` | Jump to an acupoint code |
| `ibianque://quiz` | Playful constitution quiz |
| `ibianque://tongue` | On-device tongue color sketch |
| `ibianque://nanjing` | Nan Jing shelf |
| `ibianque://study` | Que Study |
| `ibianque://hunt` | Point Hunt |
| `ibianque://fables` | Lore |
| `ibianque://concepts` | Concepts |

## Shared reading paths

| URL | Opens |
|-----|-------|
| `ibianque://home` | Home |
| `ibianque://passage?id=` / `ibianque://chapter?id=` | Passage detail |
| `ibianque://recite` / `ibianque://recite?id=` | Recite |
| `ibianque://random` | Random passage |
| `ibianque://favorites` | Favorites |
| `ibianque://search?q=` | Search |
| `ibianque://famous` | Famous lines |
| `ibianque://categories` | Browse |
| `ibianque://last-read` | Last read |
| `ibianque://reading-history` | Reading history |
| `ibianque://notes` | Notes |
| `ibianque://handwriting` | Handwriting search (iOS) |
| `ibianque://settings` | Settings |
| `ibianque://usage-guide` | Usage guide |
| `ibianque://widget-guide` | Widget guide |
| `ibianque://shortcuts-guide` | Shortcuts guide |
| `ibianque://feature-guide` | Replay onboarding |
| `ibianque://feedback` | Feedback email |

## Examples

```
ibianque://daily
ibianque://atlas
ibianque://passage?id=1
ibianque://study
```
