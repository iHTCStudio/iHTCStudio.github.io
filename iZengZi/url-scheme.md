<section lang="en" markdown="1">

爱曾子 / iZengZi supports **`izengzi://`** shortcut links (URL scheme). Cold start and Home Screen shortcuts are delivered through a unified buffer so links are not opened twice after onboarding.

## Link format

```
izengzi://{host}?{params}
```

## Unique desk

| URL | Opens |
|-----|-------|
| `izengzi://daily` | Daily Reflection |
| `izengzi://reflect` / `izengzi://journal` | Three-question journal |
| `izengzi://eight` | Eight steps |
| `izengzi://tales` | Tale hall |
| `izengzi://study` | Cultivation Hall |
| `izengzi://hunt` | Keyword Hunt |

| URL | Opens |
|-----|-------|
| `izengzi://home` | Home |
| `izengzi://passage?id=` / `izengzi://chapter?id=` | Passage detail |

| `izengzi://random` | Random passage |
| `izengzi://favorites` | Favorites |
| `izengzi://search?q=` | Search |
| `izengzi://famous` | Famous lines |
| `izengzi://categories` | Browse |

| `izengzi://reading-history` | Reading history |
| `izengzi://notes` | Notes |
