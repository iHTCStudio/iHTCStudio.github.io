<section lang="en" markdown="1">

iWuBi is a comprehensive Wubi input method learning and character lookup tool for **iPhone, iPad, and Mac**. With a 30,000+ word library covering 86-, 98-, and New Century Wubi standards, **typing practice**, pinyin search and conversion, daily quizzes, 8 widgets, and complete iCloud sync, it is the all-in-one companion for mastering Wubi — **offline, with zero third-party dependencies.**

Built with pure SwiftUI for its 8th anniversary refresh.

## Getting Started

1. Complete the **5-screen onboarding** on first launch (or skip anytime).
2. Open iWuBi and search for any character in **Lookup**, or browse by simple-code level (1–4) in **Levels**. On iOS, **handwriting OCR** can fill the search field on Lookup and Jianma pages.
3. Switch between 86-version, 98-version, and New Century Wubi in Settings or the toolbar menu.
4. Try **Typing** — pick full-code, level-code, or mixed mode; set a **random character count** for generated lists; practice with built-in passages, pasted text, favorites, or your wrong-book.
5. Take the **Daily Quiz** — 8 questions per day to build muscle memory. Review mistakes in the Wrong Question Book.
6. Enable **Show Pinyin** or **Pinyin Search** in App Settings if you also learn pronunciation.
7. Add widgets to your Home Screen, Lock Screen, or StandBy to keep learning at a glance.

## Features

### Learning Core

- **30,000+ Word Library** — Single characters and phrases; 86 / 98 / New Century standards; phrase auto-composition of simple codes.
- **Simple Code Browsing (Levels 1–4)** — List or grid view, random shuffle, swipe between levels; adjustable grid columns on iPhone, iPad, and Mac.
- **Typing Practice** — Dedicated tab with three modes: full code, level code (levels 1–4), and mixed (level first, then full code after a mistake). Content sources: paste custom text, random characters, 14 built-in passages, generated word lists, favorites, and wrong-book review. Passage highlighting, radical breakdown strip, optional on-screen radical keyboard, hint / reveal / skip, accuracy / streak / session stats, and resumable built-in passage progress.
- **Daily Quiz** — 8 questions per day: character-to-code, code-to-character, and character-to-root-key.
- **Wrong Question Book** — Auto-collected quiz mistakes with detail link-back.
- **Learning Status** — Four levels (Not Learned / Learning / Learned / Mastered) with statistics.
- **Tutorials** — 86 / 98 / New Century root tables, concise guides, simple-code reference, 16+ root diagrams (**long-press to share original images**).
- **iCloud Sync (toggleable)** — Favorites, learning status, wrong book, best quiz score, streak, **typing statistics**, and **built-in passage progress**. **On by default for new users.**

### Pinyin Tools

- **Handwriting OCR (iOS)** — draw a character on Lookup / Jianma to fill search locally (Vision on-device).
- **Pinyin Prefix Search** — Type letters in Lookup and switch between **code** and **pinyin** modes; prefix-match characters by toneless pinyin.
- **Global Pinyin Display** — Optional toned pinyin above character tiles in lists, quizzes, wrong book, detail, and share snapshots.
- **Pinyin Converter** — Paste Chinese text and export in 9 styles (toned, toneless, numeric tone, Bopomofo, two-line, aligned grid, etc.); optionally show Wubi codes; copy or share as a long image.

### Lookup & Detail

- **Apple System Dictionary** — Inline definitions on the character detail page (iOS system UI / macOS Dictionary Services).
- **Colored code chips & root key images** — Visual encoding and keyboard-position diagrams.
- **Chinese TTS** — Speak characters from detail and the TTS playground.
- **Long-image sharing** — Share character detail, search results, and pinyin converter output as preview images.

### Personalization

- **16 Built-in Themes** + custom accent color; light / dark / system appearance.
- **8 Alternate App Icons** (iOS).
- **Simplified Chinese / Traditional Chinese / English** UI (independent of system language).
- Widget language and theme mirroring via App Group.

### iOS & iPad

- **8 Widget Types** — Daily Character, Level Spotlight, Daily Quiz, **Typing Glance**, Favorites, Wrong Book, Recent, Learning Progress. Home Screen, Lock Screen, and StandBy.
- Daily Character widget supports **shuffle button** (AppIntent).
- Favorites and Wrong Book widgets show **2×3 (small) / 3×3 (medium) character grids** with Wubi codes.
- **Home Screen Quick Actions** — Pick up to 4 from 7 options.
- **Siri & Shortcuts** — Look up a character, open Today's Character, start daily quiz, open Typing, and more.
- **Spotlight** — Index favorites and recent characters (toggle in Settings).
- Immersive typing layout hides the tab bar during practice.
- Optional radical keyboard: hide temporarily, suppress system keyboard while visible, fall back to system or hardware keyboard when hidden.

### macOS

- Native Mac app with inline Lookup search bar, **Esc** navigation back, floating in-app browser for tutorial links, and system share sheet.
- Physical keyboard typing practice with dedicated shortcuts (see below).
- Default grid layout for character lists; independent column preference.

### Tip Jar

- Optional in-app tips via **StoreKit 2** (Apple handles all payments).

### Privacy

- **Offline** — Core library, quizzes, tutorials, and typing work without network.
- **No Ads · No Tracking** — No analytics, no third-party SDKs.

## Widgets

2. Tap **+** and search for "iWuBi."
3. Choose a widget, select the size, and tap **Add Widget**.
4. For Lock Screen widgets, long-press the Lock Screen, tap **Customize**, and add an iWuBi accessory.

iWuBi は、**iPhone、iPad、Mac** 向けの総合的な五筆入力の学習・文字検索ツールです。86 版、98 版、新世紀版の五筆標準に対応した 3 万語以上のライブラリ、**タイピング練習**、ピンイン検索と変換、デイリークイズ、8 種類のウィジェット、完全な iCloud 同期を備え、五筆を習得するためのオールインワンの相棒です — **オフラインで動作し、サードパーティへの依存はゼロ。**

8 周年のリフレッシュとして、純粋な SwiftUI で構築されています。

## はじめに

1. 初回起動時に **5 画面のオンボーディング**を完了します（いつでもスキップ可能）。
2. iWuBi を開き、**検索**で任意の文字を検索するか、**レベル**で簡码レベル（1〜4）ごとに閲覧します。iOS では、**手書き OCR** で検索と簡码ページの検索欄に入力できます。
3. 設定またはツールバーのメニューで、86 版、98 版、新世紀版の五筆を切り替えます。
4. **タイピング**を試します — フルコード、レベルコード、ミックスのモードを選び、生成リストの**ランダム文字数**を設定し、内蔵文章、貼り付けたテキスト、お気に入り、間違い帳で練習します。
5. **デイリークイズ**に挑戦します — 1 日 8 問で体に覚えさせます。間違いは間違い帳で復習できます。
6. 発音も学ぶ場合は、アプリ設定で**ピンインを表示**または**ピンイン検索**を有効にします。
7. ホーム画面、ロック画面、StandBy にウィジェットを追加して、学習をひと目で確認できるようにします。

## 機能

### 学習のコア

- **3 万語以上のライブラリ** — 単一の文字とフレーズ。86 / 98 / 新世紀の標準。簡码のフレーズ自動合成に対応。
- **簡码の閲覧（レベル 1〜4）** — リストまたはグリッド表示、ランダムシャッフル、レベル間のスワイプ。iPhone、iPad、Mac でグリッドの列数を調整可能。
- **タイピング練習** — 専用タブに 3 つのモード：フルコード、レベルコード（レベル 1〜4）、ミックス（まずレベル、間違えるとフルコード）。コンテンツの出典：カスタムテキストの貼り付け、ランダムな文字、内蔵文章 14 本、生成された単語リスト、お気に入り、間違い帳の復習。文章のハイライト、字根分解バー、任意の画面字根キーボード、ヒント / 答えを見る / スキップ、正答率 / 連続記録 / セッション統計、再開可能な内蔵文章の進捗。
- **デイリークイズ** — 1 日 8 問：文字からコード、コードから文字、文字から字根キー。
- **間違い帳** — クイズの間違いを自動収集し、詳細へのリンクを備えます。
- **学習状況** — 4 段階（未学習 / 学習中 / 学習済み / 習得済み）と統計。
- **チュートリアル** — 86 / 98 / 新世紀の字根表、簡潔なガイド、簡码リファレンス、16 種類以上の字根図（**長押しで元画像を共有**）。
- **iCloud 同期（切り替え可能）** — お気に入り、学習状況、間違い帳、クイズのベストスコア、連続記録、**タイピング統計**、**内蔵文章の進捗**。**新規ユーザーでは既定でオン。**

### ピンインツール

- **手書き OCR（iOS）** — 検索 / 簡码で文字を描くと、検索欄がローカルで入力されます（端末内の Vision を使用）。
- **ピンイン前方一致検索** — 検索でアルファベットを入力し、**コード**モードと**ピンイン**モードを切り替えます。声調なしのピンインで文字を前方一致検索します。
- **全体のピンイン表示** — リスト、クイズ、間違い帳、詳細、共有スナップショットの文字タイルの上に、声調付きピンインを任意で表示します。
- **ピンイン変換** — 中国語のテキストを貼り付けて、9 種類のスタイル（声調付き、声調なし、数字声調、注音符号、2 行、整列グリッドなど）で出力します。五筆コードを表示することもでき、コピーや長い画像としての共有が可能です。

### 検索と詳細

- **Apple システム辞書** — 文字の詳細ページにインラインで定義を表示します（iOS はシステム UI、macOS は辞書サービス）。
- **色分けされたコードチップと字根キーの画像** — コードの視覚的な表示とキー位置の図。
- **中国語 TTS** — 詳細ページと TTS プレイグラウンドから文字を読み上げます。
- **長い画像での共有** — 文字の詳細、検索結果、ピンイン変換の出力をプレビュー画像として共有します。

### パーソナライズ

- **16 種類の内蔵テーマ** + カスタムのアクセントカラー。ライト / ダーク / システムの外観。
- **8 種類の代替アプリアイコン**（iOS）。
- **簡体字中国語 / 繁体字中国語 / 英語**の UI（システム言語とは独立）。
- App Group を通じたウィジェットの言語とテーマの反映。

### iOS と iPad

- **8 種類のウィジェット** — Daily Character、Level Spotlight、Daily Quiz、**Typing Glance**、Favorites、Wrong Book、Recent、Learning Progress。ホーム画面、ロック画面、StandBy に対応。
- Daily Character ウィジェットは**シャッフルボタン**（AppIntent）に対応。
- Favorites と Wrong Book のウィジェットは、五筆コード付きの **2×3（スモール）/ 3×3（ミディアム）の文字グリッド**を表示します。
- **ホーム画面のクイックアクション** — 7 つの選択肢から最大 4 つを選択。
- **Siri とショートカット** — 文字の検索、今日の文字を開く、デイリークイズの開始、タイピングを開く、など。

iWuBi — комплексный инструмент для изучения метода ввода «Утби» (Wubi) и поиска иероглифов для **iPhone, iPad и Mac**. Библиотека из 30 000+ слов охватывает стандарты Утби 86, 98 и «Новый век», а также **тренировку набора**, поиск и преобразование пиньиня, ежедневные викторины, 8 виджетов и полную синхронизацию через iCloud — универсальный помощник для освоения Утби, **офлайн и без сторонних зависимостей.**

Создано на чистом SwiftUI к 8-летию приложения.

## Начало работы

1. При первом запуске пройдите **онбординг из 5 экранов** (или пропустите его в любой момент).
2. Откройте iWuBi и ищите любой иероглиф в **Поиске** или просматривайте по уровням простых кодов (1–4) в **Уровнях**. На iOS **рукописный OCR** может заполнять строку поиска на страницах «Поиск» и «Простые коды».
3. Переключайтесь между Утби 86, 98 и «Новый век» в настройках или в меню панели инструментов.
4. Попробуйте **Набор** — выберите режим полного кода, кода уровня или смешанный; задайте **число случайных иероглифов** для генерируемых списков; тренируйтесь на встроенных текстах, вставленном тексте, избранном или журнале ошибок.
5. Проходите **ежедневную викторину** — 8 вопросов в день для закрепления навыка. Разбирайте ошибки в Журнале ошибок.
6. Включите **Показывать пиньинь** или **Поиск по пиньиню** в настройках приложения, если вы заодно учите произношение.
7. Добавьте виджеты на экран «Домой», экран блокировки или в режим «Ожидание», чтобы учиться с первого взгляда.

## Возможности

### Основа обучения

- **Библиотека из 30 000+ слов** — одиночные иероглифы и фразы; стандарты 86 / 98 / «Новый век»; автоматическая сборка простых кодов для фраз.
- **Просмотр простых кодов (уровни 1–4)** — вид списком или сеткой, случайное перемешивание, переключение между уровнями смахиванием; настраиваемое число столбцов сетки на iPhone, iPad и Mac.
- **Тренировка набора** — отдельная вкладка с тремя режимами: полный код, код уровня (уровни 1–4) и смешанный (сначала уровень, после ошибки — полный код). Источники материала: вставленный текст, случайные иероглифы, 14 встроенных текстов, сгенерированные списки слов, избранное и повторение журнала ошибок. Подсветка текста, полоса разбора по корням, необязательная экранная клавиатура корней, подсказка / показать / пропустить, статистика точности / серии / сессий и возобновляемый прогресс по встроенным текстам.

- **Журнал ошибок** — автоматически собирает ошибки викторин со ссылкой на страницу иероглифа.

## ฟีเจอร์

### แกนหลักการเรียนรู้

- **คลังคำศัพท์กว่า 30,000 คำ** — ตัวอักษรเดี่ยวและวลี มาตรฐาน 86 / 98 / ศตวรรษใหม่ การประกอบรหัสย่อของวลีอัตโนมัติ
- **เรียกดูรหัสย่อ (ระดับ 1–4)** — มุมมองรายการหรือตาราง สุ่มสลับ ปัดสลับระหว่างระดับ ปรับจำนวนคอลัมน์ของตารางได้บน iPhone, iPad และ Mac
- **การฝึกพิมพ์** — แท็บเฉพาะที่มีสามโหมด: รหัสเต็ม รหัสตามระดับ (ระดับ 1–4) และผสม (ระดับก่อน แล้วรหัสเต็มหลังพิมพ์ผิด) แหล่งเนื้อหา: วางข้อความเอง ตัวอักษรสุ่ม บทความในตัว 14 บท รายการคำที่สร้างขึ้น รายการโปรด และการทบทวนสมุดบันทึกข้อที่ตอบผิด ไฮไลต์บทความ แถบแยกราก คีย์บอร์ดรากบนหน้าจอแบบเลือกได้ คำใบ้ / เฉลย / ข้าม สถิติความแม่นยำ / สถิติต่อเนื่อง / รอบ และความคืบหน้าบทความในตัวที่ทำต่อได้
- **แบบทดสอบประจำวัน** — วันละ 8 ข้อ: ตัวอักษรเป็นรหัส รหัสเป็นตัวอักษร และตัวอักษรเป็นปุ่มราก
- **สมุดบันทึกข้อที่ตอบผิด** — รวบรวมข้อที่พลาดในแบบทดสอบโดยอัตโนมัติ พร้อมลิงก์กลับไปยังรายละเอียด
- **สถานะการเรียนรู้** — สี่ระดับ (ยังไม่เรียน / กำลังเรียน / เรียนแล้ว / เชี่ยวชาญ) พร้อมสถิติ

- **การซิงค์ iCloud (เปิด/ปิดได้)** — รายการโปรด สถานะการเรียนรู้ สมุดบันทึกข้อที่ตอบผิด คะแนนแบบทดสอบสูงสุด สถิติต่อเนื่อง **สถิติการพิมพ์** และ **ความคืบหน้าบทความในตัว** **เปิดเป็นค่าเริ่มต้นสำหรับผู้ใช้ใหม่**

- **OCR ลายมือเขียน (iOS)** — วาดตัวอักษรในหน้าค้นหา / รหัสย่อ เพื่อกรอกช่องค้นหาในเครื่อง (Vision บนอุปกรณ์)

iWuBi ist ein umfassendes Werkzeug zum Erlernen der Wubi-Eingabemethode und zum Nachschlagen von Zeichen für **iPhone, iPad und Mac**. Mit einer Bibliothek von über 30.000 Wörtern, die die Wubi-Standards 86, 98 und New Century abdeckt, **Tippen-Training**, Pinyin-Suche und -Konvertierung, täglichen Quizzen, 8 Widgets und vollständiger iCloud-Synchronisierung ist es der Allrounder, um Wubi zu meistern — **offline und ohne Abhängigkeiten von Drittanbietern.**

Für die Auffrischung zum 8. Jubiläum in reinem SwiftUI gebaut.

## Erste Schritte

1. Durchlaufen Sie beim ersten Start das **Onboarding mit 5 Bildschirmen** (oder überspringen Sie es jederzeit).
2. Öffnen Sie iWuBi und suchen Sie in **Suche** nach einem beliebigen Zeichen oder stöbern Sie in **Stufen** nach Kurzcode-Stufen (1–4). Unter iOS kann die **Handschrift-OCR** das Suchfeld auf den Seiten Suche und Kurzcode ausfüllen.
3. Wechseln Sie in den Einstellungen oder im Symbolleistenmenü zwischen der 86er-, der 98er- und der New-Century-Version von Wubi.
4. Probieren Sie **Tippen** — wählen Sie den Modus vollständiger Code, Stufencode oder gemischt; legen Sie eine **zufällige Zeichenanzahl** für erzeugte Listen fest; üben Sie mit integrierten Texten, eingefügtem Text, Favoriten oder Ihrem Fehlerheft.
5. Machen Sie das **tägliche Quiz** — 8 Fragen pro Tag für das Muskelgedächtnis. Gehen Sie Fehler im Fehlerheft durch.
6. Aktivieren Sie **Pinyin anzeigen** oder **Pinyin-Suche** in den App-Einstellungen, wenn Sie auch die Aussprache lernen.
7. Fügen Sie Widgets zu Home-Bildschirm, Sperrbildschirm oder StandBy hinzu, um das Lernen im Blick zu behalten.

### Lernkern

- **Bibliothek mit über 30.000 Wörtern** — Einzelzeichen und Ausdrücke; Standards 86 / 98 / New Century; automatische Zusammensetzung von Kurzcodes für Ausdrücke.

- **Tippen-Training** — Eigener Tab mit drei Modi: vollständiger Code, Stufencode (Stufen 1–4) und gemischt (erst Stufe, nach einem Fehler vollständiger Code). Inhaltsquellen: eigener eingefügter Text, zufällige Zeichen, 14 integrierte Texte, erzeugte Wortlisten, Favoriten und Wiederholung des Fehlerhefts. iWuBi, **iPhone, iPad ve Mac** için kapsamlı bir Wubi giriş yöntemi öğrenme ve karakter arama aracıdır. 86, 98 ve Yeni Yüzyıl Wubi standartlarını kapsayan 30.000'den fazla kelimelik kütüphane, **yazma alıştırması**, pinyin arama ve dönüştürme, günlük testler, 8 widget ve tam iCloud senkronizasyonuyla Wubi'de ustalaşmanız için hepsi bir arada yol arkadaşıdır — **çevrimdışı ve sıfır üçüncü taraf bağımlılığıyla.**

Sekizinci yıl dönümü yenilemesi için tamamen SwiftUI ile geliştirilmiştir.

## Başlarken

1. İlk açılışta **5 ekranlık tanıtımı** tamamlayın (veya istediğiniz zaman atlayın).
2. iWuBi'yi açın ve **Arama**'da herhangi bir karakteri arayın ya da **Seviyeler**'de basit kod seviyesine (1–4) göre göz atın. iOS'ta **el yazısı OCR**, Arama ve Basit Kod sayfalarındaki arama alanını doldurabilir.
3. Ayarlar'da veya araç çubuğu menüsünde 86 sürümü, 98 sürümü ve Yeni Yüzyıl Wubi arasında geçiş yapın.
4. **Yazma**'yı deneyin — tam kod, seviye kodu veya karışık modu seçin; oluşturulan listeler için **rastgele karakter sayısı** belirleyin; yerleşik metinler, yapıştırılan metin, favoriler veya yanlış defteriniz ile alıştırma yapın.
5. **Günlük Test**'i çözün — kas hafızası oluşturmak için günde 8 soru. Hataları Yanlış Soru Defteri'nde gözden geçirin.
6. Telaffuzu da öğreniyorsanız Uygulama Ayarları'nda **Pinyin Göster** veya **Pinyin Araması**'nı etkinleştirin.
7. Öğrenmeyi bir bakışta sürdürmek için Ana Ekran'ınıza, Kilit Ekranı'nıza veya StandBy'a widget'lar ekleyin.

## Özellikler

### Öğrenme Çekirdeği

- **30.000+ Kelimelik Kütüphane** — Tek karakterler ve ifadeler; 86 / 98 / Yeni Yüzyıl standartları; basit kodların ifadeler için otomatik birleştirilmesi.
- **Basit Kod Gezintisi (Seviye 1–4)** — Liste veya ızgara görünümü, rastgele karıştırma, seviyeler arasında kaydırma; iPhone, iPad ve Mac'te ayarlanabilir ızgara sütunları.
- **Yazma Alıştırması** — Üç modlu özel sekme: tam kod, seviye kodu (seviye 1–4) ve karışık (önce seviye, hatadan sonra tam kod). İçerik kaynakları: özel metin yapıştırma, rastgele karakterler, 14 yerleşik metin, oluşturulan kelime listeleri, favoriler ve yanlış defteri tekrarı. Metin vurgulama, kök ayrıştırma şeridi, isteğe bağlı ekran kök klavyesi, ipucu / göster / atla, doğruluk / seri / oturum istatistikleri ve devam ettirilebilir yerleşik metin ilerlemesi.
- **Günlük Test** — Günde 8 soru: karakterden koda, koddan karaktere ve karakterden kök tuşuna.
- **Yanlış Soru Defteri** — Ayrıntıya geri bağlantılı, test hatalarını otomatik toplar.
- **Öğrenme Durumu** — İstatistiklerle dört seviye (Öğrenilmedi / Öğreniliyor / Öğrenildi / Ustalaşıldı).
- **Eğitimler** — 86 / 98 / Yeni Yüzyıl kök tabloları, kısa kılavuzlar, basit kod başvurusu, 16'dan fazla kök diyagramı (**orijinal görselleri paylaşmak için uzun basın**).
- **iCloud Senkronizasyonu (açılıp kapatılabilir)** — Favoriler, öğrenme durumu, yanlış defteri, en iyi test puanı, seri, **yazma istatistikleri** ve **yerleşik metin ilerlemesi**. **Yeni kullanıcılar için varsayılan olarak açıktır.**

### Pinyin Araçları

- **El Yazısı OCR (iOS)** — Aramayı yerel olarak doldurmak için Arama / Basit Kod'da bir karakter çizin (cihaz üzerinde Vision).
- **Pinyin Önek Araması** — Arama'da harf yazın ve **kod** ile **pinyin** modları arasında geçiş yapın; karakterler tonsuz pinyin önekiyle eşleştirilir.
- **Genel Pinyin Gösterimi** — Listelerde, testlerde, yanlış defterinde, ayrıntıda ve paylaşım görsellerinde karakter karolarının üzerinde isteğe bağlı tonlu pinyin.
- **Pinyin Dönüştürücü** — Çince metni yapıştırın ve 9 stilde (tonlu, tonsuz, sayısal ton, Bopomofo, iki satırlı, hizalı ızgara vb.) dışa aktarın; isteğe bağlı olarak Wubi kodlarını gösterin; kopyalayın veya uzun görsel olarak paylaşın.

### Arama ve Ayrıntı

- **Apple Sistem Sözlüğü** — Karakter ayrıntı sayfasında satır içi tanımlar (iOS sistem arayüzü / macOS Dictionary Services).

- **Çince TTS** — Karakterleri ayrıntıdan ve TTS oyun alanından seslendirin.
