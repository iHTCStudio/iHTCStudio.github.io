### How do I browse interview questions?

Open iTer and use the **Languages** tab for 17 programming language categories, or the **Categories** tab for career tracks, company banks, and advanced learning links. Tap a question to open its detail page. Use **global search** (⌘F on iPad/Mac) to find questions across the entire library with optional scope filters.

### Does iTer work offline?

Yes. All **10,000+** questions and learning resources are bundled with the app. No account, login, or internet connection is required. Favorites, quiz progress, wrong-book records, and preferences are stored locally on your device.

### Why don't my widgets show questions?

After installing or updating iTer, **open the main app once** so it syncs the question catalog to App Group storage. Widgets read from this offline mirror. If widgets still appear empty, launch the app and wait for the library to finish loading, then remove and re-add the widget.

### Can I choose which questions appear in the Daily Question widget?

On **iOS 17+**, long-press the Daily Question widget → **Edit Widget** to pick a scope (All / Language / Profession / Company). You can also tap shuffle on the widget to change today's pick. The in-app daily quiz scope syncs to widgets when you change it in the Quiz tab.

### How do keyboard shortcuts work in question detail?

When you open a question from a list with **2 or more** questions, the bottom bar shows Previous · Random · Answer · Next. On **iPad with an external keyboard** or **Mac**:

| Key | Action |
|-----|--------|
| ← | Previous |
| R | Random |
| Space | Show answer |
| → | Next |

On Mac, **Esc** goes back (or closes share preview first). Shortcuts are disabled at list boundaries or after the answer is already shown.

### What languages does the app UI support?

The interface is available in **English**, **Simplified Chinese**, **Traditional Chinese**, and **Follow System**. Change it in Settings → Display Language. Home screen widgets follow the same language preference.

### What are the Home Screen Quick Actions?

On iPhone and iPad, long-press the iTer icon to use shortcuts configured in **Settings → Home Screen shortcuts** (up to **4** of **7**):

| Type | Action |
|------|--------|
| `iTer://search` | Open global search |
| `iTer://quiz` | Open Daily Quiz |
| `iTer://favorites` | Open Favourites |
| `iTer://wrong` | Open wrong-answer book |
| `iTer://categories` | Open Categories tab |
| `iTer://feedback` | Send feedback (mail) |
| `iTer://review` | Rate the app (StoreKit) |

Widgets and Shortcuts can also use **`iTer://question?id=`**, **`quiz`**, **`favorites`**, and **`wrong`** — see the [URL Scheme reference](../url-scheme).

### What platforms are supported?

| Platform | Requirement |
|----------|-------------|
| iPhone / iPad | iOS / iPadOS 16.0+ |
| Mac | macOS 13.0+ |
| Widget scope picker | iOS 17.0+ |

### Where can I download iTer?

iTer is available on the [App Store](https://apps.apple.com/app/id1224934068) for iPhone, iPad, and Mac.

### Still need help?

Contact [AppleOSer@gmail.com](mailto:AppleOSer@gmail.com). We typically respond within 48 hours.

在 **语言** Tab 浏览 17 种编程语言分类，或在 **分类** Tab 进入职业方向、企业真题与进阶学习。点按题目进入详情。**全局搜索**（iPad / Mac 上 ⌘F）可检索全库，并支持按语言 / 职业 / 企业筛选范围。

### 爱技术可以离线使用吗？

可以。全部 **10000+** 题目与学习资源均随 App 打包，无需账号、登录或联网。收藏、测验进度、错题记录与偏好设置均保存在设备本地。

### 小组件为什么没有题目？

安装或更新后，请 **先打开主 App 一次**，以便将题库镜像同步至 App Group，小组件才能离线读取。若仍为空，打开 App 等待题库加载完成，然后移除并重新添加小组件。

### 每日一题小组件可以选择题库范围吗？

**iOS 17+** 可长按「每日一题」小组件 → **编辑小组件**，选择范围（全部 / 语言 / 职业 / 企业）。Widget 上也可 shuffle 换题。App 内每日测验的题库范围变更后会同步至 App Group。

### 题目详情的键盘快捷键怎么用？

从含 **2 道及以上** 题目的列表进入详情时，底部显示 **上一题 · 随机 · 答案 · 下一题**。在 **iPad 外接键盘** 或 **Mac** 上：

| 按键 | 功能 |
|------|------|
| ← | 上一题 |
| R | 随机 |
| 空格 | 显示答案 |
| → | 下一题 |

Mac 上 **Esc** 返回上一级（若正在分享预览则先关闭）。已在首尾题或答案已展开时，对应快捷键无效。

### 应用界面支持哪些语言？

小组件与快捷指令亦支持 **`iTer://question?id=`** 等深度链接——详见 [URL Scheme 说明](../url-scheme)。

### 面接問題をどう探しますか？

iTer を開き、**言語**タブで 17 のプログラミング言語カテゴリ、**カテゴリ**タブでキャリアパス・企業問題集・上級学習リンクを閲覧します。質問をタップして詳細を開きます。**グローバル検索**（iPad/Mac では ⌘F）で、任意の範囲フィルター付きでライブラリ全体を検索できます。

### iTer はオフラインで使えますか？

はい。**10,000 件以上**の問題と学習リソースはすべてアプリに同梱されています。アカウント、ログイン、インターネットは不要です。お気に入り、クイズ進捗、間違い帳、設定は端末内に保存されます。

### ウィジェットに問題が表示されないのはなぜですか？

**iTer のインストールまたは更新後、メインアプリを一度開いて**、問題カタログを App Group ストレージと同期してください。ウィジェットはそのオフラインミラーを読みます。空のままなら、アプリを起動してライブラリの読み込み完了を待ち、ウィジェットを削除して追加し直してください。

### 「今日の問題」ウィジェットの出題範囲を選べますか？

**iOS 17+** では「今日の問題」ウィジェットを長押し → **ウィジェットを編集** で範囲（すべて / 言語 / 職種 / 企業）を選べます。ウィジェット内の「ランダム」で今日の問題を変更できます。クイズタブで日次クイズの範囲を変えるとウィジェットと同期します。

### 問題詳細のキーボードショートカットは？

**2 件以上**のリストから質問を開いたとき、下部バーに 前へ · ランダム · 回答 · 次へ が表示されます。**外付けキーボード付き iPad** または **Mac** では:

| キー | 操作 |
|-----|--------|
| ← | 前の問題 |
| R | ランダム |
| スペース | 回答を表示 |
| → | 次の問題 |

Mac では **Esc** で戻ります（共有プレビューが開いていれば先に閉じます）。リスト端や回答表示後はショートカットが無効になります。

### アプリ UI はどの言語に対応していますか？

**英語**、**简体中文**、**繁體中文**、**システムに従う** です。設定 → 表示言語で変更できます。ホーム画面ウィジェットも同じ言語設定に従います。

### ホーム画面のクイックアクションとは？

iPhone / iPad で iTer アイコンを長押しすると、**設定 → ホーム画面ショートカット** で設定したショートカット（**7 種類から最大 4 つ**）が使えます:

| 種類 | 操作 |
|------|--------|
| `iTer://search` | グローバル検索 |
| `iTer://quiz` | 日次クイズ |
| `iTer://favorites` | お気に入り |
| `iTer://wrong` | 間違い帳 |
| `iTer://categories` | カテゴリタブ |
| `iTer://feedback` | フィードバック（メール） |
| `iTer://review` | App Store で評価 |

ウィジェットとショートカットは **`iTer://question?id=`**、**`quiz`**、**`favorites`**、**`wrong`** も使えます — [URL スキーム](../url-scheme) を参照。

### 면접 질문을 어떻게 찾아볼 수 있나요?

iTer를 열고 **언어** 탭을 사용하여 17개 프로그래밍 언어 카테고리를 확인하거나 **카테고리** 탭을 사용하여 경력 트랙, 회사 은행 및 고급 학습 링크를 확인하세요. 질문을 탭하여 세부정보 페이지를 엽니다. **전체 검색**(iPad/Mac의 경우 ⌘F)을 사용하면 선택적 범위 필터를 통해 전체 라이브러리에서 질문을 찾을 수 있습니다.

### iTer는 오프라인에서 작동하나요?

예. 모든 **10,000+** 질문과 학습 리소스가 앱과 함께 번들로 제공됩니다. 계정, 로그인 또는 인터넷 연결이 필요하지 않습니다. 즐겨찾기, 퀴즈 진행 상황, 잘못된 책 기록 및 기본 설정은 장치에 로컬로 저장됩니다.

### 내 위젯에 질문이 표시되지 않는 이유는 무엇입니까?

iTer를 설치하거나 업데이트한 후 **기본 앱을 한 번 열어** 질문 카탈로그를 앱 그룹 저장소에 동기화하세요. 이 오프라인 미러에서 위젯을 읽습니다. 위젯이 여전히 비어 있는 경우 앱을 실행하고 라이브러리 로드가 완료될 때까지 기다린 후 위젯을 제거했다가 다시 추가하세요.

### 일일 질문 위젯에 표시되는 질문을 선택할 수 있나요?

**iOS 17+**에서는 일일 질문 위젯 → **위젯 편집**을 길게 눌러 범위(전체/언어/직업/회사)를 선택하세요. 위젯에서 임의 재생을 탭하여 오늘의 선택을 변경할 수도 있습니다. 앱 내 일일 퀴즈 범위는 퀴즈 탭에서 변경하면 위젯과 동기화됩니다.

### 질문 세부사항에서 키보드 단축키는 어떻게 작동하나요?

**2개 이상의** 질문이 있는 목록에서 질문을 열면 하단 표시줄에 이전 · 무작위 · 답변 · 다음이 표시됩니다. **외부 키보드가 있는 iPad** 또는 **Mac**에서:

| 열쇠 | 액션 |
|-----|--------|
| ← | 이전 |
| R | 무작위 |
| 공간 | 답변 표시 |
| → | 다음 |

Mac에서는 **Esc**를 누르면 뒤로 이동합니다(또는 먼저 공유 미리보기를 닫습니다). 목록 경계에서 또는 답변이 이미 표시된 후에는 바로가기가 비활성화됩니다.

### 앱 UI는 어떤 언어를 지원하나요?

인터페이스는 **영어**, **중국어 간체**, **중국어 번체** 및 **팔로우 시스템**으로 제공됩니다. 설정 → 표시 언어에서 변경하세요. 홈 화면 위젯은 동일한 언어 기본 설정을 따릅니다.

### 홈 화면 빠른 작업이란 무엇입니까?

iPhone 및 iPad에서 iTer 아이콘을 길게 눌러 **설정 → 홈 화면 바로가기**(최대 **7** 중 **4**)에 구성된 바로가기를 사용하세요.

| 유형 | 액션 |
|------|--------|
| `iTer://search` | 글로벌 검색 열기 |
| `iTer://quiz` | 일일 퀴즈 열기 |

| `iTer://wrong` | 오답책 열기 |
| `iTer://categories` | 카테고리 탭 열기 |
| `iTer://feedback` | 피드백 보내기(메일) |
| `iTer://review` | 앱 평가하기(StoreKit) |

위젯과 바로가기는 **`iTer://question?id=`**, **`quiz`**, **`favorites`** 및 **`wrong`**을 사용할 수도 있습니다. [URL 체계 참조](../url-scheme)를 참조하세요.

### Как просмотреть вопросы для интервью?

Open iTer and use the **Languages** tab for 17 programming language categories, or the **Categories** tab for career tracks, company banks, and advanced learning links. Коснитесь вопроса, чтобы открыть страницу его подробностей. Используйте **глобальный поиск** (⌘F на iPad/Mac), чтобы находить вопросы по всей библиотеке с дополнительными фильтрами области.

### Работает ли iTer в автономном режиме?

Да. Все **10 000+** вопросов и учебные ресурсы включены в приложение. Никакой учетной записи, входа в систему или подключения к Интернету не требуется. Избранное, прогресс викторины, записи о неправильных книгах и настройки хранятся локально на вашем устройстве.

### Почему в моих виджетах не отображаются вопросы?

После установки или обновления iTer **откройте основное приложение один раз**, чтобы оно синхронизировало каталог вопросов с хранилищем группы приложений. Виджеты считываются с этого автономного зеркала. Если виджеты по-прежнему кажутся пустыми, запустите приложение и дождитесь завершения загрузки библиотеки, затем удалите и снова добавьте виджет.

### Могу ли я выбрать, какие вопросы будут отображаться в виджете ежедневных вопросов?

### Wie durchsuche ich Interviewfragen?

Öffnen Sie iTer und verwenden Sie die Registerkarte **Sprachen** für 17 Programmiersprachenkategorien oder die Registerkarte **Kategorien** für Karrierewege, Unternehmensbanken und Links zu fortgeschrittenem Lernen. ### Funktioniert iTer offline?

Ja. Alle **10.000+** Fragen und Lernressourcen sind in der App gebündelt. Es ist kein Konto, Login oder Internetverbindung erforderlich. Favoriten, Quizfortschritt, Falschbuchaufzeichnungen und Präferenzen werden lokal auf Ihrem Gerät gespeichert.

### Warum zeigen meine Widgets keine Fragen an?

**Öffnen Sie nach der Installation oder Aktualisierung von iTer einmal die Haupt-App**, damit der Fragenkatalog mit dem App-Gruppenspeicher synchronisiert wird. Von diesem Offline-Spiegel gelesene Widgets. Wenn die Widgets immer noch leer erscheinen, starten Sie die App und warten Sie, bis die Bibliothek vollständig geladen ist. Entfernen Sie dann das Widget und fügen Sie es erneut hinzu.

### Kann ich auswählen, welche Fragen im Widget „Tägliche Fragen“ angezeigt werden?

Drücken Sie unter **iOS 17+** lange auf das Widget „Tägliche Frage“ → **Widget bearbeiten**, um einen Bereich auszuwählen (Alle / Sprache / Beruf / Unternehmen). Sie können im Widget auch auf „Zufällig“ tippen, um die heutige Auswahl zu ändern. Der Umfang des täglichen In-App-Quiz wird mit Widgets synchronisiert, wenn Sie ihn auf der Registerkarte „Quiz“ ändern.

### Wie funktionieren Tastaturkürzel im Detail der Frage?

Wenn Sie eine Frage aus einer Liste mit **zwei oder mehr** Fragen öffnen, wird in der unteren Leiste Vorherige · Zufällige · Antwort · Nächste angezeigt. Auf **iPad mit externer Tastatur** oder **Mac**:

| Schlüssel | Aktion |
|-----|--------|
| ← | Zurück |
| R | Zufällig |
| Raum | Antwort anzeigen |
| → | Als nächstes |

Auf dem Mac geht **Esc** zurück (oder schließt zuerst die Freigabevorschau). Verknüpfungen werden an Listengrenzen oder nachdem die Antwort bereits angezeigt wird, deaktiviert.
