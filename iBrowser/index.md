**Browse without the chrome. Recover when you need it.**

iBrowser (全屏浏览器 / 全螢幕瀏覽器) is a **true full-screen browser** for iPhone and iPad. Status bar, address bar, and toolbar stay out of the way by default — the page owns the screen. A **float ball** brings shortcuts back; **Home & Lock Screen widgets**, **Siri & Shortcuts**, and Home Screen quick actions open home, search, continue last page, or bookmarks. **Child lock** keeps the address bar hidden. Optional **iCloud** can sync bookmarks and browse preferences. **No ads. No pop-ups. No account.**

**At a glance:** Edge-to-edge WebKit · float ball · widgets · Siri / Shortcuts · `ibrowser://` · continue last page · child lock · optional iCloud · all orientations · iPhone & iPad.

> iBrowser is an independent app and is **not affiliated with Apple Inc.**

## Getting Started

1. Install from the [App Store](https://apps.apple.com/app/id948944368) and open **iBrowser**.
2. Finish the **feature tour** and short **how-to**. New users must **agree to the terms** before browsing; returning users only see the how-to.
3. The home page loads (default Bing, changeable in Settings). External `http` / `https` links open as-is.
4. Tap the **float ball** for back / forward / refresh / home, bookmarks, copy, share, and Settings.
5. Double-tap toolbar **search** for Settings; double-tap **refresh** for a hard reload.
6. Optional: add **widgets**, ask **Siri**, or configure Home Screen quick actions. Replay the tour anytime in Settings.

## Everyday controls

| Action | How |
|--------|-----|
| Open a site or search | Show the address bar (float ball or recover gesture), type a URL or keywords |
| Immersive reading | Tap **Full Screen**, or keep chrome hidden while the float ball is on |
| Quick actions | Tap the **float ball** |
| Hide the float ball | Drag it to the bottom edge |
| Recover chrome / ball | **Shake** on iPhone; on **iPad** tap near the **top** (shake is not supported) |
| Settings | Float ball → Settings, or **double-tap search** |
| Child lock | Settings → **Force-hide address bar** |

When the float ball is on, scrolling does **not** auto-reveal the toolbar. Child lock keeps the address bar hidden even after recover gestures.

## Widgets, Shortcuts & continue last

### Widgets (iOS 14+)

Add from the Home Screen gallery: **Home**, **Bookmarks**, **Search**, **Continue last**. On iOS 16+, Home and Continue last also offer Lock Screen sizes. With child lock on, bookmark widgets stay empty and Search / Continue last open **home** instead.

### Siri & Shortcuts (iOS 16+)

Open home, search, continue last page, bookmarks, Settings, the feature tour, or a specific URL. Full list: [Shortcut Links](url-scheme).

### Continue last page

The app remembers the last successfully loaded page **on this device** (not via iCloud). Cold start still opens **home**; only widgets, Shortcuts, or Home Screen quick actions open “continue last”.

### Home Screen quick actions

Long-press the icon (up to 4). Customize in Settings. Child lock leaves only **Open Home**.

## Child lock

For kids, kiosks, or handing someone a phone to view one page:

1. Set a suitable **home page** (Settings can use the **current page**).
2. Turn on **Force-hide address bar** (store name: **Child lock**).
3. Optionally enable a **Settings password**.

Child lock blocks changing the URL from the address bar. In-page links, back / forward, and Home still work. **Widgets, Shortcuts, and bookmarks** (other than the home URL) also open home while lock is on.

## Settings worth knowing

- **Home page** — default Bing; **Use current page** when available
- **Search engine** — Bing, Google, Sogou, 360, DuckDuckGo, GitHub, Stack Overflow, or a custom prefix
- **Bookmarks** — on device; float ball or Settings; editable / batch delete
- **Float ball menu** — reorder or hide panel buttons (keep at least one; keep Settings if the toolbar is force-hidden)
- **Browser margins** — top / left / right / bottom (notch-safe option on notched devices)
- **Appearance / language** — system or fixed light/dark; UI language (seven locales) applies on next launch
- **iCloud Sync** — off by default; can sync bookmarks, home, search, margins, display locks, float-ball menu — **not** Settings password, last page, float-ball position, appearance, language, or Home Screen quick-action order
- **Guides** — feature tour, widget guide, Shortcuts guide, full handbook

## Why you’ll want to download

- **Real edge-to-edge** — chrome is temporary, not a thinner toolbar.
- **System-native entry points** — widgets, Siri, Shortcuts, Home Screen actions.
- **Child lock that matches the store promise** — hide the address bar; optional password; lock also covers widgets / Shortcuts.
- **Light by design** — no tab farm, no download manager, no ad UI.

アプリはこのデバイス上で最後に正常に読み込まれたページを記憶します（iCloud経由ではありません）。コールドスタートでは依然として**ホーム**が開きます。「続ける最後」を開くのはウィジェット、ショートカット、またはホーム画面のクイックアクションのみです。

### ホーム画面のクイックアクション

アイコンを長押し（最大4つまで）。設定でカスタマイズ可能。チャイルドロックを有効にすると**ホームを開く**のみになります。

## チャイルドロック

子供、キオスク、または誰かに1ページだけ見せるための操作:

1. 適切な**ホームページ**を設定します（設定で**現在のページ**を使用可能）。
2. **アドレスバーを強制非表示**をオンにします（ストア名：**チャイルドロック**）。
3. 必要に応じて**設定パスワード**を有効にします。

チャイルドロックはアドレスバーからのURL変更をブロックします。ページ内リンク、戻る / 進む、ホームは引き続き機能します。**ウィジェット、ショートカット、ブックマーク**（ホームURL以外）もロック中はホームを開きます。

## 知っておくと便利な設定

- **ホームページ** — デフォルトBing; 利用可能な場合は **現在のページを使用**
- **検索エンジン** — Bing、Google、Sogou、360、DuckDuckGo、GitHub、Stack Overflow、またはカスタムプレフィックス
- **ブックマーク** — デバイス上; フロートボールまたは設定; 編集可能 / 一括削除
- **フロートボールメニュー** — パネルボタンの並べ替えまたは非表示（最低1つは残す; ツールバーが強制的に非表示の場合は設定を残す）
- **ブラウザ余白** — 上 / 左 / 右 / 下（ノッチ付きデバイスではノッチ対応オプション）
- **外観 / 言語** — システムまたは固定のライト/ダーク; UI言語（7つのロケール）は次回起動時に適用
- **iCloud同期** — デフォルトでオフ; ブックマーク、ホーム、検索、余白、表示ロック、フロートボールメニューを同期可能 — **設定パスワード、最後のページ、フロートボール位置、外観、言語、ホーム画面クイックアクション順序は同期されません**
- **ガイド** — 機能ツアー、ウィジェットガイド、ショートカットガイド、完全なハンドブック

## ダウンロードしたくなる理由

- **本当のエッジ・トゥ・エッジ** — クロームは一時的であり、薄いツールバーではありません。
- **システムネイティブのエントリーポイント** — ウィジェット、Siri、ショートカット、ホーム画面のアクション。
- **ストアの約束に沿ったチャイルドロック** — アドレスバーを隠す; パスワードは任意; ロックはウィジェット／ショートカットにも適用されます。
- **デザイン上軽量** — タブファームなし、ダウンロードマネージャーなし、広告UIなし。

## 아동 보호 기능

## Родительский замок

## Kindersicherung

Für Kinder, Kioske oder wenn man jemandem ein Telefon gibt, um eine Seite anzusehen:

1. Eine passende **Startseite** festlegen (die Einstellungen können die **aktuelle Seite** verwenden).
2. **Adressleiste erzwingen ausblenden** aktivieren (Anzeigename: **Kindersicherung**).
3. Optional ein **Einstellungs-Passwort** aktivieren.

Die Kindersicherung verhindert das Ändern der URL in der Adressleiste. Links innerhalb der Seite, Zurück / Vorwärts und Startseite funktionieren weiterhin. **Widgets, Kurzbefehle und Lesezeichen** (außer der Startseite) öffnen ebenfalls die Startseite, während die Sperre aktiv ist.

**Naviguez sans l’interface. Récupérez-la quand vous en avez besoin.**

iBrowser (全屏浏览器 / 全螢幕瀏覽器) est un **véritable navigateur plein écran** pour iPhone et iPad. La barre d’état, la barre d’adresse et la barre d’outils restent hors de vue par défaut — la page occupe tout l’écran. Une **boule flottante** ramène les raccourcis ; les **widgets Écran d’accueil & Écran verrouillé**, **Siri & Raccourcis**, et les actions rapides de l’écran d’accueil ouvrent l’écran d’accueil, la recherche, la dernière page ou les signets. Le **verrouillage enfant** garde la barre d’adresse cachée. L’**iCloud** optionnel peut synchroniser les signets et les préférences de navigation. **Pas de pubs. Pas de pop-ups. Pas de compte.**

**En un coup d’œil :** WebKit bord à bord · boule flottante · widgets · Siri / Raccourcis · `ibrowser://` · continuer la dernière page · verrouillage enfant · iCloud optionnel · toutes orientations · iPhone & iPad.

> iBrowser est une application indépendante et n’est **pas affiliée à Apple Inc.**

## Commencer

1. Installez depuis l'[App Store](https://apps.apple.com/app/id948944368) et ouvrez **iBrowser**.
2. Terminez le **tour des fonctionnalités** et le court **mode d'emploi**. Les nouveaux utilisateurs doivent **accepter les conditions** avant de naviguer ; les utilisateurs revenants ne voient que le mode d'emploi.
3. La page d'accueil se charge (Bing par défaut, modifiable dans les Paramètres). Les liens externes `http` / `https` s'ouvrent tels quels.
4. Appuyez sur la **balle flottante** pour revenir / avancer / actualiser / accueil, signets, copier, partager et Paramètres.
5. Double-cliquez sur **recherche** dans la barre d'outils pour accéder aux Paramètres ; double-cliquez sur **actualiser** pour un rechargement complet.
6. Optionnel : ajoutez des **widgets**, demandez à **Siri**, ou configurez les actions rapides de l’écran d’accueil. Rejouez le tour à tout moment dans les Paramètres.

## Contrôles quotidiens

| Actions | Comment | 
|--------|-----| 
| Ouvrir un site ou effectuer une recherche | Afficher la barre d'adresse (balle flottante ou geste de récupération), saisir une URL ou des mots-clés | 
| Lecture immersive | Appuyez sur **Plein écran** ou laissez Chrome caché lorsque la boule flottante est activée |

## Widgets, raccourcis et continuer en dernier 

### Widgets (iOS 14+) 

Ajoutez depuis la galerie de l'écran d'accueil : **Accueil**, **Favoris**, **Recherche**, **Continuer en dernier**. L'application se souvient de la dernière page chargée avec succès **sur cet appareil** (pas via iCloud). Un démarrage à froid ouvre toujours **l'accueil** ; seules les widgets, les Raccourcis ou les actions rapides de l'écran d'accueil ouvrent « continuer la dernière ».

Appuyez longuement sur l'icône (jusqu'à 4). Personnalisez dans les Réglages. Le verrouillage enfant laisse seulement **Ouvrir l'accueil**.

Le verrouillage enfant empêche de changer l'URL depuis la barre d'adresse.
