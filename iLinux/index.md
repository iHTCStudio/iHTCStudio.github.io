<section lang="en" markdown="1">

iLinux is a privacy-first, fully offline **shell command reference and learning app** for **Linux**, **Windows CMD/Batch**, and **PowerShell** — on **iPhone, iPad and Mac**. Browse **1650+** commands per content language, read Markdown documentation, compare cross-platform equivalents, take daily quizzes scoped to each shell library, and track favourites, learning status and wrong answers. Core libraries work **without any account**; optional **iCloud sync** keeps progress aligned across your Apple devices.

> **Important:** iLinux is a local reference and learning companion. It helps you look up and study shell commands on your devices. **It does not connect to or execute commands on a real terminal, remote server or any other machine.**

## Getting Started

1. Open iLinux. Use the **Shell platform** menu in the toolbar (terminal icon) to choose **Linux**, **CMD/Batch** or **PowerShell**.
2. Browse commands from **Commands**, or switch to **Categories** for topic-based exploration. On **Mac**, pick a section from the **sidebar** instead of bottom tabs.
3. Open any command to read its summary, full Markdown documentation, and **cross-platform equivalents** (when available).
4. Go to **Daily Quiz** to practise with today's quiz set for the **current shell platform**.
5. Press **⌘F** (or tap the magnifier on iOS) to search by command name or description.
6. Star a command to add it to **Favourites**; set **learning status** (Unlearned / Learned / Mastered) from the detail page or list actions.
7. Open **Settings** to customise theme, language (iOS/iPad), list/grid layout, favourites scope, **iCloud sync**, widget shell library (iOS/iPad), and Home Screen shortcuts (iOS/iPad).

## Features

### Cross-Platform Equivalents

**100+ equivalent groups** link Linux, CMD and PowerShell commands — for example `ls` ↔ `dir` ↔ `Get-ChildItem`. The **Equivalents** bar on command detail pages lets you jump to another platform in one tap or click.

### Commands

- **A–Z Index** — Optional **Favourites** and **Recent** sections (toggle in Settings).
- **List & Grid Views** — **1–6 columns on iPhone**, **1–8 on iPad and Mac** (each device remembers independently).
- **Quick Filters** — All, Favourites, Recent, Unlearned.
- **Full-Text Search** — Within the current shell library; results update as you type.
- **Command Detail** — Summary + Markdown with syntax highlighting.
- **Learning Status** — Unlearned / Learned / Mastered.
- **Share** — Export a **Markdown file** or **styled PNG share card**.

### Daily Quiz

- Daily quiz set **scoped to the active shell platform**.
- **Match Summary** and **Match Option Meaning** question types.
- **Random Refresh** and **Perfect Streak** (per platform).
- Wrong answers saved to the **Wrong Answer Book**.

### Learning Progress & iCloud Sync

- **Favourites** with **scope** (all platforms vs current platform only).
- **Recent**, **learning status**, and **wrong-answer records**.
- **iCloud Sync** (optional, Settings → Learning stats): when signed into the same Apple ID, syncs **favourites**, **quiz progress**, **theme**, and **display preferences** (language, shell platform, favourites scope, list/grid) across **iPhone, iPad and Mac**. Conflicts merge automatically (e.g. favourites union). Disable per device without affecting others. Requires iCloud; command libraries remain fully offline.

### macOS Desktop Experience

Native **macOS 13.0+** app (not Mac Catalyst):

- **Sidebar shell** — Commands, Categories, Daily Quiz and Settings in a `NavigationSplitView` layout.
- **Window sizing** — minimum **900×560**, default **1100×720**; resizable desktop window.
- **Extended keyboard shortcuts** — **⌘,** Settings; **⌘[** / **Esc** back; **⌘← / ⌘→** previous/next category; quiz keys **1–4**, **⌘R** reshuffle, **Return** next question.
- **System Settings-style toggles** and desktop-optimised sheets.
- **Share** via the macOS share picker; **feedback** via `mailto:` or your mail client.

**Mac limitations (by design):** Home Screen **widgets**, **Home Screen quick actions**, and **alternate app icons** are **iOS/iPad only**. Settings shows a notice — configure widgets on iPhone or iPad.

### iPhone & iPad

- **Tab bar** navigation (Commands / Categories / Quiz / Settings).
- **5 Home Screen & Lock Screen widgets** with configurable shell library and Daily Command shuffle (iOS 17+).
- **Home Screen quick actions** — up to 4 from 7 options.
- **6 app icons** — default plus 5 alternates.
- **Haptic feedback** on key actions.

### URL Scheme

`ilinux://` deep links work on **iOS, iPad and Mac** (command detail with optional `platform=`, quiz, favourites, wrong book). Home Screen quick-action-only URLs (`search`, `categories`, `feedback`, `review`) remain **iOS/iPad only**. See [URL Scheme Reference](url-scheme).

### Themes & Language

- **15 colour presets** + **custom accent**; Light / Dark / System.
- **UI & content language:** English, 简体中文, 繁體中文, or System — picker in **Settings → Language** on **iOS/iPad**; preference **syncs to Mac via iCloud** when enabled.

6. コマンドにスターを付けて **お気に入り**に追加します。詳細ページまたはリストアクションから **学習ステータス** (未学習/学習/習得) を設定します。

## 特長

### クロスプラットフォームの同等物

**100 を超える同等のグループ** が Linux、CMD​​、PowerShell コマンドにリンクします (例: `ls` ↔ `dir` ↔ `Get-ChildItem`)。コマンド詳細ページの **同等** バーを使用すると、1 回のタップまたはクリックで別のプラットフォームにジャンプできます。

- **A–Z インデックス** — オプションの **お気に入り** および **最近** セクション (設定で切り替え)。
- **リストとグリッド ビュー** - **iPhone では 1 ～ 6 列**、iPad および Mac では **1 ～ 8 列** (各デバイスは個別に記憶します)。

- **コマンドの詳細** - 概要と構文の強調表示付きのマークダウン。
- **学習ステータス** — 未学習 / 学習済み / 習得済み。
- **共有** — **Markdown ファイル** または **スタイル付き PNG 共有カード** をエクスポートします。

- 毎日のクイズ セットは **アクティブなシェル プラットフォームを対象としています**。
- **一致概要** および **一致オプションの意味** 質問タイプ。
- **ランダム リフレッシュ** および **パーフェクト ストリーク** (プラットフォームごと)。

iLinux — это полностью автономное **справочное и обучающее приложение по командам оболочки**, ориентированное на конфиденциальность, для **Linux**, **Windows CMD/Batch** и **PowerShell** — на **iPhone, iPad и Mac**. > **Важно!** iLinux — это местный справочный и обучающий инструмент. Это помогает вам искать и изучать команды оболочки на ваших устройствах. **Он не подключается и не выполняет команды на реальном терминале, удаленном сервере или любой другой машине.**

## Начало работы

1. Откройте iLinux. Используйте меню **Платформа оболочки** на панели инструментов (значок терминала), чтобы выбрать **Linux**, **CMD/Batch** или **PowerShell**.
2. Просматривайте команды в разделе **Команды** или переключитесь на раздел **Категории** для изучения по темам. На **Mac** выберите раздел на **боковой панели**, а не на нижних вкладках.

5. Нажмите **⌘F** (или коснитесь лупы на iOS), чтобы выполнить поиск по имени или описанию команды.
6. Отметьте звездочкой команду, чтобы добавить ее в **Избранное**; установите **статус обучения** (Необученный / Изученный / Освоенный) на странице сведений или в списке действий.
7. Откройте **Настройки**, чтобы настроить тему, язык (iOS/iPad), макет списка/сетки, область избранного, **синхронизацию с iCloud**, библиотеку оболочки виджетов (iOS/iPad) и ярлыки главного экрана (iOS/iPad).

## Особенности

### Межплатформенные эквиваленты

**более 100 эквивалентных групп** связывают команды Linux, CMD и PowerShell — например, `ls` ↔ `dir` ↔ `Get-ChildItem`. Панель **Эквиваленты** на страницах сведений о командах позволяет перейти на другую платформу одним касанием или щелчком мыши.

### Команды

- **Указатель A–Z** – необязательные разделы **Избранное** и **Последние** (переключайте в настройках).
- **Вид списка и сетки** — **1–6 столбцов на iPhone**, **1–8 на iPad и Mac** (каждое устройство запоминает независимо).
- **Быстрые фильтры** — «Все», «Избранное», «Недавние», «Неизученные».
- **Полнотекстовый поиск** — в текущей библиотеке оболочки; результаты обновляются по мере ввода.
- **Сведения о команде** — сводка + уценка с подсветкой синтаксиса.
- **Статус обучения** — Необучен/Изучен/Освоен.
- **Поделиться** — экспортируйте **файл Markdown** или **карточку общего доступа в формате PNG**.

- Набор ежедневных викторин **применён к активной платформе**.

### Прогресс обучения и синхронизация с iCloud

- **Избранное** с **объемом** (все платформы и только текущая платформа).

## Özellikler

### Platformlar Arası Eşdeğerler

**100+ equivalent groups** link Linux, CMD and PowerShell commands — for example `ls` ↔ `dir` ↔ `Get-ChildItem`. The **Equivalents** bar on command detail pages lets you jump to another platform in one tap or click.

### Komutlar

- **A–Z Dizini** — İsteğe bağlı **Favoriler** ve **Son** bölümleri (Ayarlar'da geçiş yapın).
- **Liste ve Tablo Görünümleri** — **iPhone'da 1-6 sütun**, **iPad ve Mac'te 1-8 sütun** (her cihaz bağımsız olarak hatırlar).
- **Hızlı Filtreler** — Tümü, Favoriler, En Yeniler, Öğrenilmemişler.
- **Tam Metin Arama** — Geçerli kabuk kitaplığında; siz yazdıkça sonuçlar güncellenir.
- **Komut Ayrıntısı** — Özet + Sözdizimi vurgulamalı İşaretleme.
- **Öğrenim Durumu** — Öğrenilmemiş / Öğrenilmiş / Uzmanlaşmış.
- **Paylaş** — **Markdown dosyasını** veya **stillendirilmiş PNG paylaşım kartını** dışa aktarın.

### Günlük Sınav

- Günlük test seti **aktif kabuk platformunu kapsamaktadır**.
- **Eşleşme Özeti** ve **Eşleşme Seçeneği Anlamı** soru türleri.
- **Rastgele Yenileme** ve **Mükemmel Seri** (platform başına).
- Yanlış cevaplar **Yanlış Cevap Defteri**'ne kaydedilir.

### Öğrenme İlerlemesi ve iCloud Senkronizasyonu

- **Kapsam** ile **Favoriler** (tüm platformlar ve yalnızca mevcut platform).
- **En son**, **öğrenme durumu** ve **yanlış cevap kayıtları**.
- **iCloud Senkronizasyonu** (isteğe bağlı, Ayarlar → Öğrenme istatistikleri): aynı Apple kimliğiyle oturum açtığınızda **iPhone, iPad ve Mac** arasında **favoriler**, **sınav ilerlemesi**, **tema** ve **görüntüleme tercihleri** (dil, kabuk platformu, sık kullanılanlar kapsamı, liste/tablo) senkronize edilir. Çatışmalar otomatik olarak birleşir (örneğin, favorilerin birleşmesi). Başkalarını etkilemeden cihaz başına devre dışı bırakın. iCloud'u gerektirir; komut kitaplıkları tamamen çevrimdışı kalır.

### macOS Masaüstü Deneyimi

Yerel **macOS 13.0+** uygulaması (Mac Catalyst değil):

- **Sidebar shell** — Commands, Categories, Daily Quiz and Settings in a `NavigationSplitView` layout.
- **Pencere boyutlandırma** — minimum **900×560**, varsayılan **1100×720**; yeniden boyutlandırılabilir masaüstü penceresi.
- **Genişletilmiş klavye kısayolları** — **⌘,** Ayarlar; **⌘[** / **Esc** geri; **⌘← / ⌘→** önceki/sonraki kategori; test tuşları **1–4**, **⌘R** yeniden karıştırma, **Geri dön** sonraki soru.
- **Sistem Ayarları tarzı geçişler** ve masaüstü için optimize edilmiş sayfalar.
- **Share** via the macOS share picker; **feedback** via `mailto:` or your mail client.

**Mac sınırlamaları (tasarım gereği):** Ana Ekran **widget'lar**, **Ana Ekran hızlı eylemleri** ve **alternatif uygulama simgeleri** **yalnızca iOS/iPad'dir**. Ayarlar bir bildirim gösteriyor; iPhone veya iPad'de widget'ları yapılandırın.

### iPhone ve iPad

- **Sekme çubuğu** gezinme (Komutlar / Kategoriler / Test / Ayarlar).
- **5 Ana Ekran ve Kilit Ekranı widget'ı**, yapılandırılabilir kabuk kitaplığı ve Günlük Komut karıştırma (iOS 17+) ile.
- **Ana Ekrandaki hızlı işlemler** — 7 seçenekten en fazla 4 tanesi.
- **6 uygulama simgesi** — varsayılan artı 5 alternatif.
- Temel eylemler hakkında **dokunsal geri bildirim**.

### URL Şeması

`ilinux://` deep links work on **iOS, iPad and Mac** (command detail with optional `platform=`, quiz, favourites, wrong book). Home Screen quick-action-only URLs (`search`, `categories`, `feedback`, `review`) remain **iOS/iPad only**. See [URL Scheme Reference](url-scheme).

### Temalar ve Dil

- **15 renk ön ayarı** + **özel vurgu**; Açık / Koyu / Sistem.
- **Kullanıcı arayüzü ve içerik dili:** İngilizce, 简体中文, 繁體中文 veya Sistem — **iOS/iPad**'de **Ayarlar → Dil** bölümündeki seçici; tercih **etkinleştirildiğinde iCloud aracılığıyla Mac ile senkronize edilir**.
