**iPomodoro**(爱番茄 / 愛番茄)는 **iPhone 및 iPad**용 기본 SwiftUI **포커스 스튜디오**입니다. 시대를 초월한 [Pomodoro 기술](https://en.wikipedia.org/wiki/Pomodoro_Technique)을 중심으로 구축되었습니다. 즉, 리듬에 맞춰 일하고, 의도에 따라 휴식을 취하고, 흩어진 시간을 측정 가능한 진전으로 전환하세요.

## 왜 iPomodoro?

대부분의 타이머 앱은 카운트 다운됩니다. IPomodoro는 ** 실제로 일을 끝내고 싶은 사람들을 위해 만들어졌습니다 **:

- **두 번 탭하여 시작** — 즉시 사용할 수 있는 합리적인 기본값; 맞춤 기간이 필요할 때 큰 숫자를 탭하세요. 
- **앞으로 나아가게 만드는 작업** — 모든 세션에 카운트다운 마감일을 연결합니다. 원하는 작업을 길게 누르세요 → **포모도로에 집중** 또는 **공부 타이머에 집중**. 
- **진행 상황을 느낄 수 있습니다** — 일일 목표, 월간 히트맵, 주별 비교, 전체 화면 잠금 해제 축하 기능이 포함된 **9개의 달성 배지**. 
- **증거 공유** — 브랜드 대시보드 긴 카드, 기간 보고서, 연간 리뷰 슬라이드, App Store QR 스냅샷 등은 스터디 그룹이나 개인 일정에 적합합니다. 
- **항상 확인 가능** — 별도의 Pomodoro 및 학습 타이머 위젯, **오늘의 통계** 한눈에 보기, 실시간 활동 카운트다운, 동기 부여 인용문이 잠금 화면에 표시됩니다. 
- **개인정보 보호** — 타이머, 통계, 인용문은 기기에 그대로 유지됩니다. 선택 사항인 iCloud는 당사 서버가 아닌 Apple CloudKit을 사용합니다. 
- **Siri 및 기본 단축키** — 아무 탭이나 열거나 *"오늘 iPomodoro에서 얼마나 오랫동안 집중했나요?"* 스프레드시트를 열지 않고 물어보세요.

## 시작하기

1. **포모도로** 탭을 엽니다. 타이머 숫자를 눌러 작업 기간을 설정하거나 기본값을 사용합니다(25분 작업 · 5분 짧은 휴식 · 15분 긴 휴식). 
2. **시작**을 탭하고 집중하세요. 세션이 종료되면 앱이 자동으로 중단되도록 전환되거나 앱이 백그라운드에 있으면 알려줍니다. 
3. 자유 형식 세션의 경우 **학습 타이머**로 전환하세요. 시간/분 길이를 설정하고 Pomodoro 주기 없이 실행하세요. 
4. **작업**을 열어 카운트다운 목표를 추가하세요. 중요한 목표를 고정하고 드래그하여 순서를 바꾸고 선택적으로 기어 아이콘 아래에서 **iCloud와 작업 동기화**를 활성화하세요. 
5. 포커스 대시보드의 **통계**를 엽니다. 오늘의 개요, 목표, 히트맵, 성과 및 세션에 대한 선택적 **iCloud 동기화**가 표시됩니다. 
6. **홈 화면** 또는 **잠금 화면** 위젯을 추가합니다. 별도의 **Pomodoro** 및 **학습 타이머** 타이머, **카운트다운 작업**, **오늘의 통계** 및 선택 사항인 **일일 동기부여**를 추가합니다. **설정 → 위젯 → 사용방법**을 참고하세요. 
7. 각 타이머 모드에서 독립적으로 **라이브 활동**을 활성화합니다(**기어 아이콘 → 라이브 활동**). 
8. 각 탭의 **기어 아이콘**에서 지속 시간, 사운드 및 **페이지 테마**를 사용자 정의합니다(**통계** 탭의 자체 빨간색 강조 표시 포함). 타이머 설정은 더 빠른 액세스를 위해 전역 설정 탭에서 이동되었습니다. 
9. 홈 화면에서 **앱 아이콘**을 길게 누르면 빠른 작업이 가능합니다(뽀모도로, 공부 타이머, 작업, 통계 — **설정 → 앱 설정 → 홈 화면 바로가기**에서 최대 4개까지 사용자 정의). **`iPomodoro://`** URL을 통해 동일한 대상을 엽니다. [URL 구성표 참조](url-scheme)를 참조하세요. Siri에게 물어보세요. *"오늘 iPomodoro에서 얼마나 오랫동안 집중했나요?"* 
10. **설정 → 앱 설정 → 앱 가이드**에서 워크플로, 위젯, 바로가기에 대한 인앱 **앱 가이드**를 읽어보세요.

## 초점 모드 

### Pomodoro — 클래식 포커스 사이클 

앱의 핵심. 작업 간격, 짧은 휴식, 긴 휴식은 설정에 따라 자동으로 순환됩니다.

-** 링크 카운트 다운 작업 **-옵션 ** 링크 작업 ** 버튼 당신이 작업하고있는 기한을 기록; 통계 고장에 표시됩니다.

- **완전히 사용자 정의 가능한 기간** — 근무 시간/분, 짧은 휴식, 긴 휴식, 긴 휴식 간격(N 포모도로마다). 
- **탭하여 타이머 수정** — 큰 H:M:S 디스플레이를 탭하여 기간 선택기를 엽니다. 미세 조정을 위한 설정의 스테퍼 행. 
- **Chakra Petch 숫자 디스플레이** — 원본 Flutter 디자인에서 확장된 안정적이고 흔들림 없는 카운트다운 타이포그래피입니다. 
- **시작 동기** — Pomodoro 탭에 들어갈 때 앱 실행 시 전체 화면 인용문이 한 번 표시됩니다(스팸이 아니며 탭 스위치에서 반복되지 않음). 
- **세션을 포기한 후** — 중간 타이머를 포기하면 전체 화면 인용문이 나타날 수 있습니다(시작과 동일한 아름다운 UI). 
- **완료 피드백** — 햅틱, 선택적 알람 소리, 10초 후에 사라지는 라이브 활동 **완료** 상태. 
- **단계 완료 확인**(선택 사항) — 활성화되면 다음 단계가 시작되기 전에 각 작업 또는 중단 세그먼트 후에 대화 상자가 나타납니다. 꺼져 있으면 알람 후 다음 단계가 자동으로 시작됩니다. 
- **화면을 활성 상태로 유지** — 세션이 실행되는 동안 선택적으로 항상 켜져 있는 디스플레이입니다. 
- **집중 모드 알림**(선택 사항) — 타이머를 시작할 때 iPomodoro는 iOS Focus가 꺼져 있으면 켜도록 알려줍니다. 알림을 통해 **설정**을 열 수 있지만 앱에서 Focus를 활성화할 수는 없습니다.

### 학습 타이머 — 자신의 페이스대로 학습하세요

모든 세션이 25분 단위에 맞는 것은 아닙니다.

- **시간 단위에서 분 단위까지** 원하는 지속 시간을 설정하세요.
- **카운트다운 작업 연결** — Pomodoro와 동일한 선택적 **작업 연결** 버튼.
- 세련된 타이머 UI, 똑딱 소리, 백그라운드 알림, Pomodoro와 동일한 Live Activity 지원.
- 독립적인 테마 색상 — 기본 오션 블루 그라디언트, 완전 사용자 설정 가능.
- **집중 모드 알림** (선택적) — Pomodoro와 동일; 세션 시작 시 iOS 집중 모드 활성화를 권장.

### 카운트다운 작업 — 명확한 마감일

중요한 내용을 추적하고 남은 일수를 정확히 확인하세요.

- **고정 섹션** — 핀 키 마감일; 그들은 정상에 머물러 있습니다. 
- **맞춤 순서** — 드래그하여 재정렬합니다. 스위치를 자동으로 사용자 정의로 정렬합니다. 
- **정렬 메뉴** — 날짜, 수정 시간 또는 수동 순서(도구 모음 또는 작업 설정) 기준. 
- **iCloud 동기화 옵션** — 작업 탭 → 기어 → **iCloud와 작업 동기화**; 통계 설정 → **iCloud와 연구 통계 동기화**(독립 토글). 
- **집중하는 동안 작업 연결** — 타이머 화면에서 카운트다운 작업을 선택하거나 작업의 상황에 맞는 메뉴에서 **포모도로로 집중** / **공부 타이머로 집중**을 사용하세요. 
- **스와이프하여 수정, 고정, 삭제**; 탐색 모음에서 추가하세요. 편집할 때 작업에 대한 **9가지 강조 색상** 중 하나를 선택하세요(목록 및 작업 위젯에 표시됨). 
- **마감일 알림** — 정확한 목표 날짜/시간에 현지 알림(토글은 목표가 아직 미래인 경우에만 나타납니다). 
- **알림 관리자** — 작업 → 장비 → **작업 기한 알림**; 오늘/내일/다음 7일/나중에로 그룹화됩니다. 시트 바닥글에서 편집하거나 삭제하려면 행을 탭하세요. 

### 연구 통계 — 진행 상황을 확인하세요

Swift 차트와 **자체 페이지 테마**(그라디언트 배경 + 제목 표시줄)가 포함된 전용 **통계** 대시보드입니다. 툴바 **공유**(대시보드 긴 카드) + 설정용 **기어**. 

- **오늘 한 눈에 보기** — 집중 시간, 포모도로, 완료율, 현재/최장 연속 기록. 
- **일일 목표** — 포모도로 수, 집중 시간(분), 진행률 링이 있는 주간 집중 목표(설정에서 전환). 
- **주별 비교**, **월별 히트맵**(이전/다음 달, 월 제목을 탭하여 연도/월 선택기를 통해 이동, **이번 달로 돌아가기**; **향후 날짜**는 점선 윤곽선 자리 표시자로 표시됨), **업적**(9개 배지 - 통계 탭에서 **축하 오버레이 잠금 해제**, 세부 정보를 보려면 탭, 목록 공유 또는 단일 배지). 
- **전체/포모도로/스터디 타이머** 및 **오늘/주/월/년/전체 시간/사용자 지정 날짜 범위**로 필터링합니다. 
- **주중 및 시간 분포**(평일 라벨은 앱 언어를 따름), **연결된 작업별 분석**, 추세 차트, 최근 세션(삭제하려면 스와이프). 
- 이미지 공유가 포함된 **기간 보고서** 및 **연도 검토** 화면; **Stats Glance** 오늘의 진행 상황을 보여주는 홈 화면 위젯입니다. 

**통계 설정**(기어):

| 그룹 | 옵션 | 
|-------|---------| 
| **테마** | 제목 표시줄 및 배경 그라데이션(통계 탭 강조) | 
| **목표** | 목표 활성화, 대시보드, 일일/주간 목표에 표시 | 
| **아이클라우드** | 선택적 학습 세션 동기화(CloudKit `StudySession`, 목표 및 배지 상태에 대한 `StatsGoals` 및 `StatsAchievements`) | 
| **업적** | 잠금 해제된 배지 보기 | 
| **계산/표시/데이터** | 중단된 항목 제외, 최소 기간, 필터 기억, **사용자 정의 날짜 범위**, CSV 가져오기/내보내기, 보관, 모두 지우기 | 

**이미지로 공유:** App Store QR이 포함된 브랜드 카드 — 앱 프로모션(설정), **통계 대시보드 긴 카드**(도구 모음, 현재 필터, 요약, 히트맵, 분포 및 추세 캡처), 기간 보고서, 연간 검토, **성과 목록 또는 단일 배지**. 통계 공유 카드는 **통계 탭 페이지 테마** 색상을 따릅니다. 

CSV 열: `kind,started_at,ended_at,duration_seconds,outcome` 및 선택 사항인 `task_id,task_title,cloud_id`. 데이터는 기본적으로 기기에 유지됩니다. Apple ID에서 기기 간 병합을 위해 **iCloud와 연구 통계 동기화**를 활성화하세요. 

## 실시간 활동 및 동적 섬

지원되는 iPhone(iOS 16.2+)에서 사용할 수 있습니다. **Pomodoro와 Study Timer에는 각각 고유한 실시간 활동이 있습니다** — 각 탭의 기어 설정에서 별도로 활성화하세요. 

| 상태 | 당신이 보는 것 | 
|-------|---| 
| **달리기** | 현재 모드의 강조 색상으로 라이브 카운트다운 | 
| **일시중지됨** | 정적 남은 시간 | 
| **완료** | 축하 메시지, 10초 후 자동 종료 | 
| **배경 힌트** | 카운트다운하면서 한줄 힌트로 보는 오늘의 동기부여 | 

컴팩트한 다이내믹 아일랜드 레이아웃: 왼쪽의 카운트다운, 오른쪽의 모드 아이콘 - 최소 너비, 최대 선명도. 

**세션 복구:** 타이머가 잠금 화면에 계속 표시되는 동안 iOS가 앱을 종료하는 경우, iPomodoro는 다시 열 때 진행 중인 세션을 복원하고 활성 Pomodoro 또는 학습 탭으로 자동으로 이동합니다. **자동 탭 스위치보다 우선순위가 높은 **홈 화면 빠른 작업**을 통해 실행하지 않은 경우**. 

## 위젯 

모든 위젯은 앱 그룹을 통해 기기 내 공유 상태를 읽습니다. 네트워크가 필요하지 않습니다.

| 위젯 | 크기 | 설명 | 
|---------|-------|-------------| 
| **아이포모도로 · 포모도로** | 소형, 중형, 잠금 화면(직사각형 및 인라인) | Pomodoro 탭 타이머만 — Pomodoro 탭에서 세션을 시작할 때 업데이트 | 
| **iPomodoro · 학습 타이머** | 소형, 중형, 잠금 화면(직사각형 및 인라인) | 학습 탭 타이머만 — Pomodoro 위젯과 별개 | 
| **카운트다운 작업** | 소형, 중형, 대형 | 앞으로 남은 작업은 고정되어 있습니다. **각 행은 작업의 강조 색상을 사용합니다** | 
| **오늘의 통계** | 소형, **중형, 대형**, 잠금 화면(직사각형 및 인라인) | 오늘의 집중, 포모도로 & **주간** 목표 진행 상황, 연속 | 
| **일상 동기부여** | 소형, 중형, 대형 | 결정적인 일일 견적 - 앱 내 견적 언어 설정과 동기화됨 | 

동기부여 명언 알고리즘은 `(year × 400 + dayOfYear) % count`이므로, 하루 경계에서 깔끔하게 변하는 안정적인 "오늘의 명언"을 모두가 보게 됩니다. 

**위젯 모양:** 설정 탭 → **위젯** → 토글 **위젯 배경이 테마를 따릅니다** 전역 강조 그라데이션을 반영하거나 제목에 강조 색상을 유지하면서 깔끔한 흰색/시스템 어두운 배경을 사용합니다.

**도움이 필요하신가요?** 설정 → 위젯 → **사용 방법**에서 홈 화면, 잠금 화면, 스탠바이, **포모도로 / 공부 타이머 / 오늘의 통계** 위젯 갤러리, 라이브 액티비티, FAQ를 다루고 있으며, 기존의 단일 타이머 위젯에서 마이그레이션하는 방법도 포함됩니다.

## 동기 부여 & 마인드셋

**1000개 이상의 큐레이션된 명언** (JSON 코퍼스, 완전히 기기 내 저장 — 간체 중국어 + 영어; 모든 필터 적용 시 **1000개 이상** 결합)으로 여섯 개 접점에 힘을 실어줍니다. **두 가지 명언 풀:**

| 풀 | 사용 용도 |
|------|----------|
| **대화 / 일일** | 시작 팝업, 설정 탐색, 라이브 액티비티 힌트, 동기 부여 위젯 |
| **알림** | 백그라운드 타이머 완료 알림 전용 — **언어별 365개의 일반 명언**, 대화/일일 텍스트와 별도로 |

접점:

1. **시작 팝업** — Pomodoro 탭에서 앱 실행 시 한 번 표시 (전체 화면, 언어 인식 닫기 버튼)  
2. **중단 후** — 세션을 일찍 종료할 때 선택적으로 전체 화면 명언 표시  
3. **설정 탐색** — **설정 → 동기 부여 명언 설정 → 동기 부여 명언 모음**: 전체 화면 단일 명언; 하단 버튼을 눌러 다른 명언 보기; 언어 필터 (전체 / 간체 중국어 / 번체 중국어 / 영어만). 기본 필터: 영어 앱 → 영어만; 그 외에는 전체.  
4. **실시간 활동 힌트** — 타이머 사용 중 잠금 화면에서 미묘한 격려 표시  
5. **동기 부여 위젯** — 홈 화면에 일일 명언 표시; **iOS 17+**에서 위젯의 **새로 고침** 버튼을 눌러 즉시 다른 명언 선택 가능  
6. **일일 동기 부여 알림** (선택 사항) — 알림 명언 풀에서 무작위 명언을 사용해 반복 로컬 알림 예약

## 소리 및 알림

- **알림 권한** — 설정 탭에는 시스템 설정을 활성화하거나 열 수 있는 바로가기와 함께 현재 iOS 알림 상태가 표시됩니다. 
- 초점이 맞춰지는 동안 **틱 소리** — 설정에서 루프 미리보기가 포함된 여러 옵션 
- 세션이 완료되면 **알람 소리** - 흐름에 맞는 것을 선택하세요. 
- **백그라운드 타이머 알림** — 전용 기기 내 알림 인용 풀(**언어당 365개의 일반 인용문**, 대화 상자/일일 인용문과 별도); 인용 언어 설정을 존중합니다. 
- **작업 기한 알림** — 정확한 목표 날짜 시간에 캘린더를 통해 로컬 알림이 실행됩니다. 

모든 알림은 **로컬**이며 원격 서버가 아닌 장치에 의해 예약됩니다.

## 개인정보 보호 및 데이터 

- **타이머 및 설정** — 기기의 UserDefaults에 로컬로 저장됩니다. 
- **작업** — SQLite에 로컬로 저장됩니다. 활성화하면 Apple CloudKit을 통해 **iCloud 계정**과 동기화할 수 있습니다. 
- **연구 통계** — 기기 내 SQLite의 세션 기록; 세션에 대한 선택적 **iCloud 동기화**, **일일 목표** 및 **성취 잠금 해제/축하 상태**(통계 → 장비, 작업 동기화와 별도). 활성화되면 증분 CloudKit 동기화를 사용합니다. 
- **위젯 및 실시간 활동** — Pomodoro / 학습 / 작업 / **오늘의 통계** / 앱 그룹을 통한 동기 부여 스냅샷(`group.com.iHTCboy.iPomodoros`); 귀하가 제어하는 ​​선택적 iCloud 동기화를 제외하고 귀하의 기기에 유지됩니다. 
- **분석 SDK 없음**, 광고 없음, 제3자 추적 없음. 
- **iPomodoro 계정 없음** — 절대 없습니다. 
- 선택적 인앱 지원 구매는 전적으로 **Apple StoreKit**에서 처리됩니다.
