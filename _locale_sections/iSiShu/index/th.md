**ชอบความคลาสสิค.. ใช้ชีวิตอย่างมีปัญญา** 

iSiShu (爱四书 / 愛四書) คือ **พื้นที่อ่านหนังสือสี่เล่มแบบออฟไลน์** สำหรับการเรียนรู้แบบมุ่งเน้น ไม่ใช่โปรแกรมอ่านข้อความธรรมดาตัวอื่น **ไม่จำเป็นต้องมีบัญชี** ข้อความ **1257** ทั้งหมดจาก *Daxue*, *Zhongyong*, *Lunyu* และ *Mengzi* จัดส่งบนอุปกรณ์ของคุณด้วย **ภาษาจีนคลาสสิก**, **ภาษาพื้นถิ่น** และ **ภาษาอังกฤษ** รวมถึงการอ่านที่ดื่มด่ำ **ท่อง**, **การศึกษาแบบเน้น**, **การพูดรายวัน**, การ์ดแชร์, วิดเจ็ต, ศูนย์ควบคุม, Siri, Spotlight, กิจกรรมการอ่านสดที่เป็นตัวเลือก และอุปกรณ์เสริม ไอคลาวด์. บนระบบที่รองรับ แอปยังสามารถแสดงคุณสมบัติ AI บนอุปกรณ์และการประเมินการอ่านออกเสียงได้ ข้อความรวบรวมจากแหล่งข้อมูลออนไลน์ที่เปิดเผยต่อสาธารณะ ** ไม่มีโฆษณา ไม่มีการติดตาม Data Not Collected.** 

## เริ่มต้นใช้งาน 

### 1. เปิดตัวครั้งแรก 

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id6797013698) และเปิด **iSiShu** 
2. กรอกคู่มือต้อนรับให้ครบถ้วน: การอ่านสามภาษา → ท่อง → ศึกษา → คำพูดรายวัน → ความเป็นส่วนตัว 
3. เล่นซ้ำได้ทุกเมื่อใน **การตั้งค่า → ช่วยเหลือ → คู่มือคุณสมบัติ** 
4. คำแนะนำการใช้งาน วิดเจ็ต และทางลัดมีอยู่ใน **การตั้งค่า → ความช่วยเหลือ** 

### 2. พูดทุกวันที่บ้าน

1. เปิด **หน้าแรก** 
2. ฮีโร่ **Daily Saying** แสดงข้อความของวันนี้ 
3. ตัวเลือก: เปิดใช้งานการแจ้งเตือนในท้องถิ่นในการตั้งค่า 
4. กระโดดจากหน้าแรกไปยังท่อง ศึกษา ล่า รายการโปรด และค้นหา 

### 3. เรียกดูและค้นหา 

1. เรียกดูหนังสือสี่เล่ม บท Lunyu เล่ม Mengzi ผู้แต่ง และบทที่มีชื่อเสียง 
2. ค้นหาชื่อเรื่อง ข้อความเนื้อหา และบันทึกย่อ บน iOS ตัวเลือกเสริม **การค้นหาด้วยลายมือ** จะจดจำอักขระบนอุปกรณ์ 
3. บันทึกข้อความไปยัง **รายการโปรด** และสร้าง **รายการส่วนตัว** 

### 4. การอ่านแบบปิดสามภาษา 

1. สลับระหว่าง **สองภาษา / จีนเท่านั้น / อังกฤษเท่านั้น** 
2. สลับพินอิน ภาษาพื้นถิ่น และภาษาอังกฤษอย่างอิสระ 
3. ใช้การอ่านที่สมจริง การแบ่งหน้า โฟกัสบรรทัด และแชร์การ์ด 

### 5. ท่องและเน้นการศึกษา 

1. เปิดโต๊ะบรรยายสำหรับ TTS ที่ไฮไลต์และการเล่นคิว 
2. ใช้ **การศึกษาแบบเน้น** เพื่อท่องจำ เติมช่องว่าง ตรวจสอบตนเอง แบบทดสอบ และ **ตามล่า** 
3. ในระบบที่รองรับ การประเมินการบรรยายและเงา AI สามารถช่วยในการศึกษาได้ 

### 6. วิดเจ็ต, Siri และการรวมระบบ

1. เพิ่มวิดเจ็ต **คำพูดรายวัน / บรรทัดที่มีชื่อเสียง / ความคืบหน้าการศึกษา / รายการโปรด** 
2. ใช้ศูนย์ควบคุม, Siri, Spotlight และลิงก์ในรายละเอียด `isishu://` 
3. กิจกรรมการอ่านสดที่เป็นตัวเลือกยังคงมีให้บริการบนอุปกรณ์ iPhone ที่รองรับ 

### 7. ความเป็นส่วนตัวและการซิงค์ 

1. การอ่านหลัก ท่อง ศึกษา วิดเจ็ต และการแจ้งเตือนทำงานแบบออฟไลน์หลังการติดตั้ง 
2. ตัวเลือก **iCloud Sync** จะสะท้อนรายการโปรด รายการ ประวัติ ความคืบหน้า ความคืบหน้า และบันทึกย่อผ่าน **iCloud** ส่วนตัวของคุณ 
3. เคล็ดลับนักพัฒนา (อุปกรณ์เสริม StoreKit) จะไม่ปลดล็อกเนื้อหาเพย์วอลล์และไม่เคยสร้างบัญชี 

## คุณสมบัติ 

- **1,257 ตอน** ในหนังสือทั้งสี่เล่ม 
- **การอ่านแบบปิดสามภาษา**: จีนคลาสสิก + ภาษาพื้นถิ่น + อังกฤษ 
- **โต๊ะบรรยาย** พร้อมการเล่นคิว 
- **เน้นการศึกษา** ด้วยความชำนาญและการล่า 
- **คำพูดรายวัน**, วิดเจ็ต, ศูนย์ควบคุม, Siri, สปอตไลท์ และลิงก์ในรายละเอียด 
- **ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK การวิเคราะห์**
