 iSiShu (愛情四书 / 愛四書) は、別のプレーン テキスト リーダーではなく、集中的に学習するための **オフラインの Four Books 学習スペース**です。 **アカウントは必要ありません。** *Daxue*、*Zhongyong*、*Lunyu*、*Mengzi* のすべての **1257** パッセージは、**古典中国語**、**日常語**、**英語**とともにデバイスに搭載されており、没入型読書、**暗唱**、**集中学習**、**Daily Saying**、共有カード、ウィジェット、コントロール センター、Siri、スポットライト、オプションのリーディング ライブも利用できます。 アクティビティ、およびオプションの iCloud。 サポートされているシステムでは、アプリはオンデバイスの AI 光沢および朗読評価機能も公開できます。 テキストは、公開されているオンライン ソースから編集されています。 **広告はありません。 追跡はありません。 Data Not Collected.**

 ## はじめに

 ### 1. 最初の起動

 1. [App Store](https://apps.apple.com/app/id6797013698) からインストールし、**iSiShu** を開きます。 
2. ウェルカム ガイドを完了します: 三か国語での読書 → 暗唱 → 学習 → 毎日のことわざ → プライバシー。 
3. **[設定] → [ヘルプ] → [機能ガイド]**でいつでも再生できます。 
4. 使用法、ウィジェット、およびショートカットのガイドは、**[設定] → [ヘルプ]** で参照できます。 

### 2. 家庭に関する日常の言葉

1. **ホーム**を開きます。 
2. **日々の格言**の主人公が今日の一節を示します。 
3. オプション: [設定] でローカル リマインダーを有効にします。 
4. ホームから暗唱、学習、狩り、お気に入り、検索にジャンプします。 

### 3. 参照と検索

 1. 四書、論語の章、孟子の巻、著者、名セリフごとに閲覧します。 
2. タイトル、本文、メモを検索します。 iOS では、オプションの **手書き検索** によりデバイス上の文字が認識されます。 
3. パッセージを **お気に入り**に保存し、個人用**リスト**を作成します。 

### 4. 三か国語精読

 1. **バイリンガル/中国語のみ/英語のみ**を切り替えます。 
2. ピンイン、現地語、英語を個別に切り替えます。 
3. 没入型​​読書、セグメント化されたページ、ラインフォーカス、共有カードを使用します。 

### 5. 暗唱と集中学習

 1. ハイライト表示された TTS とキュー再生用の朗読ワークベンチを開きます。 
2. **集中学習**を使用して、暗記、穴埋め、自己チェック、クイズ、**ハント**を行います。 
3. サポートされているシステムでは、暗唱評価と AI 光沢が学習を支援します。 

### 6. ウィジェット、Siri、システム統合

1. **日々の名言/名セリフ/勉強の進捗/お気に入り**ウィジェットを追加します。 
2. コントロール センター、Siri、Spotlight、`isishu://` ディープ リンクを使用します。 
3. オプションの読書ライブ アクティビティは、サポートされている iPhone デバイスで引き続き利用できます。 

### 7. プライバシーと同期

 1. コアの読書、暗唱、学習、ウィジェット、通知はインストール後オフラインで機能します。 
2. オプションの **_iCloud 同期** は、**プライベート iCloud*** を通じてお気に入り、リスト、履歴、進行状況、連続記録、メモをミラーリングします。 
3. 開発者 (オプションの StoreKit) は、ペイウォールで保護されたコンテンツのロックを解除したり、アカウントを作成したりすることはありません。 

## 特徴

 - **4 冊にわたる **1,257 節**
 - **三か国語精読**: 古典中国語 + 現地語 + 英語
 - **朗読ワークベンチ** キュー再生機能付き
 - **集中学習**、熟練と狩り
 - **Daily Saying**、ウィジェット、コントロール センター、Siri、Spotlight、ディープ リンク
 - **アカウントなし、広告なし、分析 SDK なし**
