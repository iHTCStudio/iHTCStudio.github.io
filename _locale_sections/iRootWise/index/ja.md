**知恵の根を噛む。 すべてが可能になります。**

 iRootWise (愛情菜根谭) は、*Caigentan* (菜根谭) に根ざした **東洋のマインドフルネスと栽培スタジオ**です。コールド クォート ダンプではありません。 **アカウントは必要ありません。** **697** の重複排除された明/清の一節が、**各国語ガイド**、**鑑賞** (目的、工芸、今日の用途)、**完全な英語**、用語解説ノート、TTS、**デイリー タン**、**インク呼吸瞑想**、**5 つの栽培コース**とともにデバイスに同梱されています。 **12 の共有カード スタイル** をエクスポートし、**ウィジェット**、オプションの **読書 / 瞑想のライブ アクティビティ**、**Siri とショートカット**、およびオプションの **iCloud** (瞑想の統計情報は **デバイス上のみ**) を追加します。 **広告はありません。 追跡はありません。**

 **概要:** 明 + 清版 · 697 パッセージ · 180 の有名なセリフ · 8 テーマ · 5 コース (7 / 14 / 21 / 30 / 180 日) · デイリー タン · 座って呼吸 · インサイト · 12 枚のシェア カード · ウィジェット · コントロール センター · `irootwise://` · EN / 简 / 繁。 

> たんを読んでください。 座って一息。 一日保管してください。 古い知恵を今日の穏やかなものにしましょう。 

## はじめに (ステップバイステップ)

 ### 1. 最初の起動

1. [App Store](https://apps.apple.com/app/id6797013590) からインストールして **iRootWise** を開きます。
2. **7ページのウェルカムガイド** を完了します（ブランド → デイリータン → 読書 → 座る → コース → システム追加 → プライバシー）。
3. いつでも再度確認できます： **設定 → ヘルプ → 機能ガイド**。
4. アプリ内の **使用法 / ウィジェット / ショートカット** ガイドは **設定 → ヘルプ** にあります。

### 2. ホームで今日のタンに会う

1. **ホーム** タブを開きます。
2. **デイリータン** に今日の文章が表示されます（季節ごとの文脈プール）。読むにはタップするか、**ワンタップで暗唱**（この文章のみ）を使用します。
3. **連続日数** を確認します（詳細はタップ）。オプション：設定で **デイリータン通知** を有効にできます（ローカルのみ）。
4. **続きを読む** は、前回読んだ文章が今日の文章と異なる場合に表示されます。

### 3. ブラウズ、テーマ & 名言

1. **ブラウズ**を開く（設定に隠れている場合があり、その場合はシートとして開きます）。
2. **明／清版**, **テーマ**, **名言**, **コース**を探る。
3. **リスト／グリッド／カード**を切り替え、複数選択して暗唱、 お気に入り、またはリストに追加。
4. **検索**は原文、白話、鑑賞、英語をカバー。iOSでは、オプションの**手書き検索**でデバイス上の文字を認識。ライブラリの読み込み中は「検索準備中」と表示される。

### 4. バイリンガル読書＆カード共有

1. 詳細画面で**読書言語**を設定：バイリンガル／中国語のみ／英語のみ（UI言語とは独立）。
2. 白話、鑑賞、ピンイン、縦書き、分割読書（≥8文、1ページ4～12文）を切り替え。
3. 行を長押し：コピー、システム翻訳、ここから暗唱、または共有カードを事前選択。
4. **共有カード**を開く → **12スタイル**から選択 → 写真／ファイルに保存、またはシステム共有（カードにはピンインなし）。

### 5. 静坐（座って呼吸する）

1. ホーム、コントロールセンター、または`irootwise://meditation`から**瞑想**を開きます。
2. デフォルトのプリセットは**4-7-8 calm**です。自然 / ボックス / ボディスキャンのプリセットも試してみてください。環境音と終了チャイムはオプションです。
3. **30秒以上**のセッションは統計にカウントされます。**瞑想の履歴はこのデバイスに保持されます**（意図的にiCloud同期なし）。
4. オプション: **Appleマインドフルネス時間**を書き込む（デフォルトはオフ — 先にアプリ内で有効にし、その後ヘルスへのアクセスを許可してください）。Reading Live ActivityとMeditation Live Activityは**別々のスイッチ**で、どちらもデフォルトではオフです。

### 6. 五つの養成コース

1. **コース**を開く: 行い (7) · 安らぎ (14) · 逆境 (21) · 養成 (30) · 季節 (180)。
2. ホームの**今日のレッスン**は、希望する / 進行中のパスにジャンプします（長期コースではフェーズ名を表示）。
3. 日数をチェックイン（墓石 + クロスデバイスLWW）、振り返りのノートを書き、必要に応じて1つのコースをリセットします。
4. オプションの**レッスンリマインダー**（Daily Tanとは独立; デフォルトはオフ）。

### 7. ウィジェット、Siri & ショートカット

1. ホーム画面を長押し → **Daily Tan / Famous Line / Favorites / Course Progress** を追加します。
2. 今日のタン、座禅、ランダム、お気に入り、コース、検索、読み続け、その他を **Siri** に聞きます。
3. ホーム画面のクイックアクションを **設定 → ショートカット** で設定します。
4. 全 `irootwise://` テーブル: [ショートカットリンク](url-scheme)。

### 8. プライバシーと同期

1. コアリーディング、座禅、コース、ウィジェット、ローカル通知はインストール後 **オフライン** でも機能します。
2. オプションの **iCloud** はお気に入り、リスト、メモ、習熟度、履歴、コース、連続記録を同期します — 瞑想合計は同期されません。
3. **Spotlight** のインデックス作成はデフォルトで **オフ** です（必要な場合は設定で有効にしてください）。
4. オプションの StoreKit チップは有料コンテンツをアンロックすることはありません。

## ダウンロードしたくなる理由

- **実践できる知恵** — 毎日のタン+シット+デイレッスンは、*カイゲンタン*をブックマークではなく習慣にします。 
- **本物のバイリンガルデスク** - すべての文章に現地語、評価、英語が記載されています。 UI言語と読み上げ言語は独立しています。 
- **落ち着いたデザイン** — ソーシャル フィードなしで、セッション リカバリ、環境音、オプションのライブ アクティビティを備えたインクブレス瞑想。 
- **1 つのリストではなく 5 つのパス** — 7 日間の行動開始から 180 日間の季節編まで。 
- **実感できるプライバシー** — アカウント、広告、分析 SDK はありません。 瞑想の統計がデバイスから離れることはありません。 

## 特徴

 ### Library & reading

 - 明/清以降の **697** パッセージの重複排除; **180** famous lines; **8** themes; glossary notes
- Full English coverage; 現地語 + 3 部構成の鑑賞。 ピンイン; vertical text; immersive reader
 - 分割読書、TTS + Now Playing、連続キュー（お気に入り/コース日）
 - メモ、習熟レベル、読書履歴 (最大 100)、お気に入り、カスタム リスト

 ### 毎日の日焼けと名セリフ

 - Seasonal context pool; local notifications; widget “shuffle”
 - 専用名セリフページ + 安定した毎日の名セリフウィジェット

 ### Meditation

- 複数のプリセット (デフォルト **4-7-8**)、インクブレス UI、アンビエントの雨 / 鐘 / 風 / インク
 - **イマーシブ セッション** — タブ バーが非表示になり、クロムがフェードします。 オーブをタップしてコントロールを再度表示します
 - スナップショットの再開とコールドスタート クレジット (30 秒以上); 終了通知。 オプションの HealthKit マインドフルネス
 - デバイス上の統計のみ。 1 つのセッションを削除するか、すべてをクリアします (該当する場合は連続ロールバック ルールを使用)

 ### コース

 - 毎日のガイド付きの 5 つのシードパス; 長期コースのフェーズ/週/月のグループ化
 - チェックイン、振り返り、修了祝い、オプションのレッスンリマインダー

 ### Insight (悟道)

 - オンデバイス ファウンデーション モデル（利用可能な場合）（iOS 26 以降）。 それ以外の場合はローカルガイドのフォールバック
 - 結果はメモに保存できます

 ### ウィジェットとシステム

 - ウィジェット: 毎日の日焼け、有名なセリフ、お気に入りのカルーセル、コースの進行状況
 - ライブアクティビティ: 読書と瞑想 (個別の切り替え)
 - コントロールセンター (iOS 18+)、Siri / ショートカット、オプションのスポットライト、5 つの代替アイコン

 - [プライバシーポリシー](プライバシー)を参照
