## Начало работы (шаг за шагом) 

### 1. Первый запуск

1. Установите из [App Store](https://apps.apple.com/app/id6797013590) и откройте **iRootWise**.
2. Пройдите **7-страничное приветственное руководство** (бренд → Daily Tan → чтение → сидеть → курсы → системные дополнения → конфиденциальность).
3. Повторяйте в любое время: **Настройки → Справка → Руководство по функциям**.
4. Встроенные руководства **Использование / Виджет / Сочетания клавиш** находятся в **Настройки → Справка**.

### 2. Познакомьтесь с сегодняшним загаром на главной

1. Откройте вкладку **Главная**.
2. **Daily Tan** показывает сегодняшний отрывок (сезонный пул контекста); нажмите, чтобы прочитать, или используйте **чтение в один клик** (только этот отрывок).
3. Проверьте свою **серію** (нажмите для подробностей). Опционально: включите **уведомления Daily Tan** в Настройках (только локально).
4. **Продолжить чтение** появляется, если у вас есть последний прочитанный отрывок, отличный от сегодняшнего.

### 3. Просмотр, темы и знаменитые строки

1. Откройте **Обзор** (может быть скрыт в Настройках; тогда он открывается в виде листа).  
2. Исследуйте **издания Мин / Цин**, **темы**, **знаковые цитаты** и **курсы**.  
3. Переключайте **список / сетка / карточки**; множественный выбор для повторения, добавления в избранное или списки.  
4. **Поиск** охватывает оригинал, разговорный язык, оценку и английский. На iOS можно использовать опциональный **поиск по рукописи**, который распознает символы на устройстве. При загрузке библиотеки отображается сообщение «подготовка поиска» до готовности.  

### 4. Двуязычное чтение и карточки для обмена

1. В деталях установите **язык чтения**: двуязычный / только китайский / только английский (независимо от языка интерфейса).  
2. Переключайте разговорный язык, оценку, пиньинь, вертикальный текст и сегментированное чтение (≥8 предложений; 4–12 на страницу).  
3. Долгое нажатие на строку: копировать, системный перевод, повторять с этого места или предварительно выбрать карточку для обмена.  
4. Откройте **Карточка для обмена** → выберите из **12 стилей** → сохраните в Фото / Файлы или через системный обмен (без пиньинь на карточках).  

### 5. Сидите и дышите (静坐)

1. Откройте **Медитацию** с Главного экрана, из Центра управления или `irootwise://meditation`.
2. Значение по умолчанию — **4-7-8 спокойствие**; попробуйте пресеты «природа», «коробка», «сканирование тела». Фоновый звук и финальный звонок — по желанию.
3. Сеансы **≥30 с** учитываются в статистике. **История медитаций хранится на этом устройстве** (намеренно не синхронизируется с iCloud).
4. Опционально: записывать **минуты осознанности Apple** (выключено по умолчанию — сначала включите в приложении, затем разрешите доступ к Health). Live Activity для чтения и Live Activity для медитации — **отдельные переключатели**, оба по умолчанию отключены.

### 6. Пять курсов развития

1. Откройте **Курсы**: Поведение (7) · Спокойствие (14) · Трудности (21) · Развитие (30) · Сезоны (180).
2. На главной странице **Сегодняшний урок** сразу открывает выбранный или текущий путь (длинные курсы показывают названия фаз).
3. Отмечайте дни посещения (надгробие + LWW между устройствами), записывайте заметки-размышления, при необходимости сбрасывайте один курс.
4. Опциональное **напоминание об уроке** (независимо от «Ежедневного Тана»; по умолчанию выключено).

### 7. Виджеты, Siri и ярлыки

1. Длительное нажатие на главный экран → добавить **Ежедневный загар / Известная фраза / Избранное / Прогресс курса**.
2. Спросите **Siri** про сегодняшний загар, сидение, случайный, избранное, курс, поиск, продолжить чтение и многое другое.
3. Настройте быстрые действия главного экрана в **Настройки → Сочетания клавиш**.
4. Полная таблица `irootwise://`: [Ссылки на сочетания клавиш](url-scheme).

### 8. Конфиденциальность и синхронизация

1. Основное чтение, сидение, курсы, виджеты и локальные уведомления работают **офлайн** после установки.
2. Опциональный **iCloud** дублирует избранное, списки, заметки, мастерство, историю, курсы и серии — **не** общие показатели медитации.
3. Индексация **Spotlight** **выключена по умолчанию** (включите в Настройках, если хотите).
4. Опциональная подсказка StoreKit никогда не открывает контент, защищённый платной подпиской.

## Почему вам стоит скачать

- **Мудрость, которую можно практиковать** — Ежедневный загар + сидение + дневные уроки превращают *Кайгентан* в привычку, а не в закладку. 
- **Настоящий двуязычный стол** — разговорный язык, понимание и английский в каждом отрывке; Язык пользовательского интерфейса и язык чтения независимы. 
- **Спокойствие по задумке** — чернильная медитация с восстановлением после сеанса, окружающим звуком и дополнительными активностями в реальном времени — без ленты социальных сетей. 
- **Пять путей, а не один список** — от 7-дневного старта до 180-дневной сезонной дуги. 
- **Конфиденциальность, которую вы можете почувствовать** — без аккаунта, без рекламы, без аналитического SDK; статистика медитации никогда не покидает устройство. 

## Особенности 

### Библиотека и чтение 

- **697** отрывков после дедупа Мин/Цин; **180** знаменитых строк; **8** тем; глоссарий 
- Полное покрытие английского языка; разговорный язык + трехчастная оценка; пиньинь; вертикальный текст; иммерсивная читалка 
- Сегментированное чтение, TTS + Now Playing, непрерывные очереди (избранное/дни курса) 
- Заметки, уровни мастерства, история чтения (до 100), избранное и настраиваемые списки. 

### Daily Tan и знаменитые линии 

- Сезонный контекстный пул; локальные уведомления; виджет «перемешать» 
- Выделенная страница известных линий + стабильный ежедневный виджет известных линий 

### Медитация

- Несколько пресетов (по умолчанию **4-7-8**), чернильный интерфейс, окружающий дождь / колокольчик / ветер / чернила. 
- **Сеанс погружения** — панель вкладок скрывается, а хром исчезает; коснитесь сферы, чтобы снова открыть элементы управления 
- Снимок резюме и кредит холодного запуска (≥30 с); уведомление о завершении; дополнительный HealthKit для осознанности 
- Только статистика на устройстве; удалить один сеанс или очистить все (с правилами отката серии, если применимо) 

### Курсы 

- Пять засеянных дорожек с ежедневными руководствами; группировка по фазам/неделям/месяцам для длительных курсов 
- Регистрация, размышления, празднование завершения, дополнительные напоминания об уроках. 

### Проницательность (悟道) 

- Модели Foundation на устройстве, если они доступны (iOS 26+); в противном случае местный гид станет запасным вариантом 
- Результаты можно сохранять в заметки 

### Виджеты и система 

- Виджеты: Ежедневный загар, Знаменитая линия, Карусель избранного, Ход курса. 
- Живое занятие: чтение и медитация (отдельные переключатели) 
- Центр управления (iOS 18+), Siri / Ярлыки, дополнительный Spotlight, 5 альтернативных значков
