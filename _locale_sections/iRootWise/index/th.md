**เคี้ยวรากแห่งปัญญา ทุกสิ่งเป็นไปได้** 

iRootWise (爱菜根谭) คือ **สตูดิโอฝึกสติและฝึกฝนแบบตะวันออก** ที่มีรากฐานมาจาก *Caigentan* (菜根谭) — ไม่ใช่การถ่ายโอนข้อมูลแบบเย็น **ไม่จำเป็นต้องมีบัญชี** **ข้อความ Ming / Qing ที่กรองแล้ว 697** รายการออกไปบนอุปกรณ์ของคุณ พร้อมด้วย **คำแนะนำภาษาถิ่น**, **ความชื่นชม** (จุดมุ่งหมาย · งานฝีมือ · การใช้งานในปัจจุบัน), **ภาษาอังกฤษฉบับเต็ม**, อภิธานศัพท์, TTS, **ภาษาตาลรายวัน**, **การทำสมาธิด้วยหมึกลมหายใจ** และ **หลักสูตรการเพาะปลูกห้าหลักสูตร** ส่งออก **รูปแบบการ์ดแชร์ 12 รูปแบบ** เพิ่ม **วิดเจ็ต** ตัวเลือก **กิจกรรมการอ่าน / การทำสมาธิแบบสด** **Siri และคำสั่งลัด** และตัวเลือก **iCloud** (สถิติการทำสมาธิจะคงอยู่ **บนอุปกรณ์เท่านั้น**) ** ไม่มีโฆษณา ไม่มีการติดตาม** 

**โดยสรุป:** รุ่น Ming + Qing · 697 ข้อความ · 180 บรรทัดที่มีชื่อเสียง · 8 ธีม · 5 หลักสูตร (7 / 14 / 21 / 30 / 180 วัน) · Daily Tan · นั่งและหายใจ · Insight · การ์ดแชร์ 12 ใบ · วิดเจ็ต · ศูนย์ควบคุม · `irootwise://` · EN / 简 / 繁

## เริ่มต้นใช้งาน (ทีละขั้นตอน) 

### 1. เปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id6797013590) แล้วเปิด **iRootWise**  
2. ทำ **คู่มือแนะนำ 7 หน้า** ให้ครบ (แบรนด์ → Daily Tan → การอ่าน → นั่ง → หลักสูตร → ระบบเสริม → ความเป็นส่วนตัว)  
3. เล่นซ้ำได้ตลอดเวลา: **การตั้งค่า → ความช่วยเหลือ → คู่มือฟีเจอร์**  
4. คู่มือ **การใช้งาน / วิดเจ็ต / ทางลัด** ในแอป อยู่ภายใต้ **การตั้งค่า → ความช่วยเหลือ**  

### 2. พบกับการแทนวันนี้ที่หน้าโฮม  

1. เปิดแท็บ **โฮม**  
2. **Daily Tan** จะแสดงข้อความประจำวัน (สระวาลบริบทตามฤดูกาล); แตะเพื่ออ่าน หรือใช้ **อ่านซ้ำด้วยการแตะครั้งเดียว** (เฉพาะข้อความนี้)  
3. ตรวจสอบ **สตรีค** ของคุณ (แตะเพื่อดูรายละเอียด) ตัวเลือก: เปิด **การแจ้งเตือน Daily Tan** ในการตั้งค่า (เฉพาะเครื่อง)  
4. **อ่านต่อ** จะแสดงเมื่อคุณมีข้อความที่อ่านล่าสุดต่างจากวันนี้  

### 3. เรียกดู ธีม & ข้อความโด่งดัง

1. เปิด **เรียกดู** (อาจซ่อนอยู่ในการตั้งค่า; จากนั้นจะเปิดเป็นแผ่น).
2. สำรวจ **ฉบับหมิง / ชิง**, **หัวข้อ**, **วลีที่มีชื่อเสียง**, และ **คอร์ส**.
3. สลับ **รายการ / ตาราง / การ์ด**; เลือกหลายรายการเพื่อท่อง, ทำเครื่องหมายโปรด, หรือเพิ่มในรายการ.
4. **ค้นหา** ครอบคลุมต้นฉบับ, ภาษาเรียบง่าย, การชื่นชม, และภาษาอังกฤษ บน iOS มีตัวเลือก **ค้นหาด้วยลายมือ** ที่รู้จำตัวอักษรบนอุปกรณ์ การโหลดห้องสมุดจะแสดง “กำลังเตรียมการค้นหา” จนกว่าจะพร้อม

### 4. การอ่านสองภาษา & การ์ดแชร์

1. บนหน้ารายละเอียด ตั้งค่า **ภาษาการอ่าน**: สองภาษา / ภาษาจีนเท่านั้น / ภาษาอังกฤษเท่านั้น (แยกจากภาษาของ UI)
2. สลับดูภาษาเรียบง่าย, การชื่นชม, พินอิน, ข้อความแนวตั้ง, และการอ่านแบบแบ่งส่วน (≥8 ประโยค; 4–12 ต่อหน้า)
3. กดค้างบนบรรทัด: คัดลอก, แปลโดยระบบ, ท่องจากบรรทัดนี้, หรือเลือกการ์ดแชร์ล่วงหน้า
4. เปิด **การ์ดแชร์** → เลือกจาก **12 สไตล์** → บันทึกไปที่ รูปภาพ / ไฟล์ หรือแชร์ผ่านระบบ (ไม่มีพินอินบนการ์ด)

### 5. นั่ง & หายใจ (静坐)

1. เปิด **การทำสมาธิ** จากหน้าหลัก, ศูนย์ควบคุม หรือ `irootwise://meditation`
2. การตั้งค่าเริ่มต้นคือ **4-7-8 สงบ**; ลองใช้การตั้งค่าธรรมชาติ / กล่อง / สแกนร่างกาย เสียงบรรยากาศ + เสียงระฆังตอนจบเป็นตัวเลือกเสริม
3. เซสชัน **≥30วินาที** จะถูกนับในสถิติ ประวัติการทำสมาธิ **จะอยู่ในอุปกรณ์นี้** (ตั้งใจไม่ซิงค์กับ iCloud)
4. ตัวเลือก: เขียน **Apple Mindfulness minutes** (ปิดโดยค่าเริ่มต้น — เปิดในแอปก่อน แล้วจึงให้สิทธิ์กับ Health) การอ่าน Live Activity และ Meditation Live Activity เป็น **สวิตช์แยกกัน** ปิดโดยค่าเริ่มต้นทั้งคู่

### 6. หลักสูตรการเพาะบ่ม 5 หลักสูตร

1. เปิด **หลักสูตร**: การประพฤติ (7) · ความผ่อนคลาย (14) · ความทุกข์ (21) · การเพาะบ่ม (30) · ฤดูกาล (180)
2. หน้าหลัก **บทเรียนวันนี้** จะพาคุณไปยังเส้นทางที่คุณชื่นชอบ / กำลังทำ (หลักสูตรยาวจะแสดงชื่อเฟส)
3. เช็กวันที่เข้าร่วม (ป้ายหลุมศพ + ข้ามอุปกรณ์แบบ LWW), เขียนบันทึกสะท้อนความคิด, รีเซ็ทหลักสูตรใดหลักสูตรหนึ่งหากจำเป็น
4. ตัวเลือก **เตือนบทเรียน** (แยกจาก Daily Tan; ปิดโดยค่าเริ่มต้น)

### 7. วิดเจ็ต, Siri และทางลัด

1. กดค้างที่หน้าจอหลัก → เพิ่ม **Daily Tan / Famous Line / Favorites / Course Progress**
2. ขอคำสั่งจาก **Siri** สำหรับ tan วันนี้ นั่ง แบบสุ่ม รายการโปรด คอร์ส ค้นหา อ่านต่อ และอื่นๆ
3. ตั้งค่าการดำเนินการด่วนของหน้าจอหลักใน **การตั้งค่า → คำสั่งลัด**
4. ตาราง `irootwise://` เต็มรูป: [Shortcut Links](url-scheme)

### 8. ความเป็นส่วนตัว & การซิงค์

1. การอ่านหลัก การนั่ง คอร์ส วิดเจ็ต และการแจ้งเตือนภายในเครื่องทำงานได้ **ออฟไลน์** หลังติดตั้ง
2. **iCloud** เป็นทางเลือกสำหรับสะท้อนรายการโปรด รายการ โน้ต ทักษะ ประวัติ คอร์ส และการสะสม — **ไม่**รวมยอดการทำสมาธิ
3. การจัดทำดัชนี **Spotlight** ถูกปิดโดยค่าเริ่มต้น (เปิดในการตั้งค่าหากต้องการ)
4. เคล็ดลับ StoreKit เป็นทางเลือกไม่เคยปลดล็อกเนื้อหาที่มีค่าใช้จ่าย

## ทำไมคุณถึงอยากดาวน์โหลด

- **ภูมิปัญญาที่คุณฝึกฝนได้** — บทเรียนผิวแทนรายวัน + นั่ง + รายวันเปลี่ยน *Caigentan* ให้เป็นนิสัย ไม่ใช่ที่คั่นหนังสือ 
- **โต๊ะสองภาษาที่แท้จริง** — เป็นภาษาท้องถิ่น ความชื่นชม และเป็นภาษาอังกฤษในทุกตอน ภาษา UI และภาษาการอ่านมีความเป็นอิสระ 
- **สงบด้วยการออกแบบ** — การทำสมาธิด้วยลมหายใจหมึกพร้อมการกู้คืนเซสชั่น เสียงรอบข้าง และกิจกรรมสดที่เป็นตัวเลือก — โดยไม่ต้องฟีดโซเชียล 
- **ห้าเส้นทาง ไม่ใช่หนึ่งรายการ** — จากการดำเนินการ 7 วันเริ่มต้นไปจนถึงส่วนโค้งตามฤดูกาล 180 วัน 
- **ความเป็นส่วนตัวที่คุณสัมผัสได้** — ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK การวิเคราะห์ สถิติการทำสมาธิไม่เคยออกจากอุปกรณ์ 

## คุณสมบัติ 

### ห้องสมุดและการอ่าน 

- **697** ข้อความหลังจาก Ming / Qing dedupe; **180** บรรทัดที่มีชื่อเสียง **8** ธีม; บันทึกคำศัพท์ 
- ครอบคลุมภาษาอังกฤษเต็มรูปแบบ; ภาษาถิ่น + ความกตัญญูสามส่วน; พินอิน; ข้อความแนวตั้ง ผู้อ่านที่ดื่มด่ำ 
- การอ่านแบบแบ่งส่วน, TTS + กำลังเล่นอยู่, คิวต่อเนื่อง (รายการโปรด / วันเรียน) 
- โน้ต ระดับความเชี่ยวชาญ ประวัติการอ่าน (สูงสุด 100 รายการ) รายการโปรด และรายการแบบกำหนดเอง 

### ตาลรายวัน&สายดัง 

- กลุ่มบริบทตามฤดูกาล การแจ้งเตือนในท้องถิ่น วิดเจ็ต "สับเปลี่ยน" 
- หน้าบรรทัดที่มีชื่อเสียงโดยเฉพาะ + วิดเจ็ตบรรทัดที่มีชื่อเสียงรายวันที่เสถียร 

### การทำสมาธิ

- ค่าที่ตั้งล่วงหน้าหลายรายการ (ค่าเริ่มต้น ** 4-7-8 **), UI ลมหายใจหมึก, ฝนโดยรอบ / กระดิ่ง / ลม / หมึก 
- **เซสชันที่สมจริง** — แถบแท็บซ่อนและโครเมียมจางลง แตะลูกโลกเพื่อเปิดเผยการควบคุมอีกครั้ง 
- ประวัติสแนปชอตและเครดิตเริ่มต้นเย็น (≥30วินาที) สิ้นสุดการแจ้งเตือน; สติทางเลือก HealthKit 
- สถิติบนอุปกรณ์เท่านั้น ลบหนึ่งเซสชันหรือล้างทั้งหมด (โดยมีกฎการย้อนกลับต่อเนื่องหากมี) 

### หลักสูตร 

- ห้าเส้นทางพร้อมคำแนะนำรายวัน การแบ่งกลุ่มเฟส / สัปดาห์ / เดือน สำหรับหลักสูตรระยะยาว 
- การเช็คอิน การไตร่ตรอง การเฉลิมฉลองการเสร็จสิ้น การแจ้งเตือนบทเรียนเพิ่มเติม 

### ข้อมูลเชิงลึก (悟道) 

- โมเดลพื้นฐานบนอุปกรณ์เมื่อมีให้ใช้งาน (iOS 26+) มิฉะนั้นไกด์ท้องถิ่นสำรอง 
- ผลลัพธ์สามารถบันทึกลงในบันทึกย่อได้ 

### วิดเจ็ตและระบบ 

- วิดเจ็ต: Daily Tan, เส้นที่มีชื่อเสียง, ม้าหมุนรายการโปรด, ความคืบหน้าของหลักสูตร 
- กิจกรรมสด: การอ่านและการทำสมาธิ (สลับแยกกัน) 
- ศูนย์ควบคุม (iOS 18+), Siri / ทางลัด, สปอตไลท์เสริม, ไอคอนสำรอง 5 อัน
