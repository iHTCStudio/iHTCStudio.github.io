## 시작하기(단계별) 

### 1. 첫 실행

1. [앱 스토어](https://apps.apple.com/app/id6797013590)에서 설치하고 **iRootWise**를 엽니다.
2. **7페이지 환영 가이드**를 완료합니다 (브랜드 → Daily Tan → 읽기 → 앉기 → 코스 → 시스템 추가 기능 → 개인정보).
3. 언제든지 다시 보기: **설정 → 도움말 → 기능 가이드**.
4. 앱 내 **사용법 / 위젯 / 단축키** 가이드는 **설정 → 도움말**에서 확인할 수 있습니다.

### 2. 오늘의 태닝을 홈에서 확인

1. **홈** 탭을 엽니다.
2. **Daily Tan**이 오늘의 구절을 보여줍니다 (계절별 컨텍스트 풀); 읽으려면 탭하고, 또는 **원터치 암송**을 사용하세요 (이 구절만 해당).
3. **연속 기록(streak)**을 확인하세요 (자세히 보려면 탭). 선택 사항: 설정에서 **Daily Tan 알림** 활성화 가능 (로컬만).
4. **계속 읽기**는 오늘의 구절과 마지막으로 읽은 구절이 다를 때 나타납니다.

### 3. 둘러보기, 테마 & 명언

1. **브라우즈(Browse)** 열기(설정에서 숨겨져 있을 수 있으며, 시트로 열립니다).
2. **명/청판본**, **주제**, **명구**, **코스** 탐색하기.
3. **리스트/그리드/카드** 전환; 여러 개 선택하여 암송, 즐겨찾기, 리스트에 추가 가능.
4. **검색**은 원문, 백화문, 감상, 영어를 포함합니다. iOS에서는 선택적 **손글씨 검색**으로 기기에서 문자 인식 가능. 라이브러리 로딩 중에는 준비될 때까지 “검색 준비 중” 표시됨.

### 4. 이중 언어 읽기 및 카드 공유

1. 상세 화면에서 **읽기 언어** 설정: 이중 언어 / 중국어만 / 영어만(UI 언어와 독립).
2. 백화문, 감상, 병음, 세로 텍스트, 문장 단위 읽기 토글(≥8문장; 페이지당 4–12문장).
3. 한 줄 길게 누르기: 복사, 시스템 번역, 여기서 암송, 카드 공유 미리 선택.
4. **공유 카드(Share Card)** 열기 → **12가지 스타일** 중 선택 → 사진/파일 저장 또는 시스템 공유(카드에는 병음 없음).

### 5. 앉아서 숨쉬기 (静坐)

1. 홈, 제어 센터 또는 `irootwise://meditation`에서 **명상**을 엽니다.
2. 기본 프리셋은 **4-7-8 차분함**입니다. 자연 / 박스 / 바디스캔 프리셋도 시도해 보세요. 환경음 + 종료 차임은 선택 사항입니다.
3. 세션 **≥30초**는 통계에 포함됩니다. **명상 기록은 이 기기에만 저장**됩니다(의도적으로 iCloud와 동기화되지 않음).
4. 선택 사항: **Apple 마음챙김 분**을 기록할 수 있습니다(기본값은 해제 — 앱 내에서 먼저 활성화한 후 Health 접근 권한을 허용). 읽기 라이브 액티비티와 명상 라이브 액티비티는 **별도의 스위치**이며, 기본값은 둘 다 해제입니다.

### 6. 다섯 가지 수련 과정

1. **과정** 열기: 행동(7) · 편안함(14) · 역경(21) · 수련(30) · 계절(180).
2. 홈의 **오늘의 수업**은 사용자가 선호하거나 진행 중인 경로로 이동합니다(장기 과정은 단계 이름 표시).
3. 출석 일 수 확인(묘표 + 기기 간 LWW), 회고 노트 작성, 필요 시 한 과정 재설정.
4. 선택 사항 **수업 알림**(Daily Tan과 독립, 기본값은 해제).

### 7. 위젯, 시리 및 단축어

1. 홈 화면 길게 누르기 → **Daily Tan / Famous Line / Favorites / Course Progress** 추가. 
2. 오늘의 탠, 앉기, 랜덤, 즐겨찾기, 코스, 검색, 이어서 읽기 등은 **Siri**에게 물어보세요.
3. **설정 → 바로가기**에서 홈 화면 빠른 동작 구성.
4. 전체 `irootwise://` 테이블: [바로가기 링크](url-scheme).

### 8. 개인정보 & 동기화

1. 핵심 읽기, 앉기, 코스, 위젯, 로컬 알림은 설치 후 **오프라인**에서 작동.
2. 선택 사항 **iCloud**는 즐겨찾기, 목록, 노트, 숙달, 기록, 코스, 연속 사용 현황을 동기화함 — 명상 총합은 **아님**.
3. **Spotlight** 색인화는 **기본적으로 꺼짐** (원하면 설정에서 활성화).
4. 선택적 StoreKit 팁은 유료 콘텐츠를 절대 해제하지 않음.

## 다운로드해야 하는 이유

- **연습할 수 있는 지혜** — 일일 태닝 + 좌식 + 일일 레슨은 *카이겐탄*을 북마크가 아닌 습관으로 바꿔줍니다. 
- **실제 이중 언어 책상** — 모국어, 감사, 모든 구절에 영어가 사용됩니다. UI 언어와 읽기 언어는 독립적입니다. 
- **차분한 디자인** — 세션 복구, 주변 소리 및 선택적 라이브 활동을 갖춘 수묵 명상 — 소셜 피드가 없습니다. 
- **하나의 목록이 아닌 다섯 가지 경로** — 7일간의 수행 시작부터 180일간의 시즌 아크까지. 
- **당신이 느낄 수 있는 개인 정보 보호** — 계정, 광고, 분석 SDK가 없습니다. 명상 통계는 절대 장치를 떠나지 않습니다. 

## 기능 

### 도서관 및 독서 

- 명/청 중복 제거 이후 **697** 구절; **180** 유명한 대사; **8** 테마; 용어집 참고 
- 전체 영어 지원; 모국어 + 세 부분으로 구성된 감상; 병음; 수직 텍스트; 몰입형 리더 
- 분할 읽기, TTS + Now Playing, 연속 대기열(즐겨찾기/강좌 요일) 
- 노트, 숙달 수준, 읽기 기록(최대 100개), 즐겨찾기 및 사용자 지정 목록 

### 데일리탠 & 유명라인 

- 계절별 컨텍스트 풀 지역 알림; 위젯 "셔플" 
- 전용 명문 페이지 + 안정적인 일일 명문 위젯 

### 명상

- 다중 사전 설정(기본 **4-7-8**), 잉크 브레스 UI, 주변 비/종/바람/잉크 
- **몰입형 세션** — 탭 표시줄이 숨겨지고 크롬이 페이드됩니다. 구체를 탭하면 컨트롤이 다시 표시됩니다. 
- 스냅샷 재개 및 콜드 스타트 크레딧(≥30초) 종료 알림; 선택적 HealthKit 마음챙김 
- 기기 내 통계만 해당됩니다. 하나의 세션을 삭제하거나 모두 지우기(해당되는 경우 연속 롤백 규칙 사용) 

### 강좌 

- 일일 가이드가 포함된 5개의 시드 경로; 장기 코스의 경우 단계/주/월 그룹화 
- 체크인, 반성, 완료 축하, 선택적 수업 알림 

### 통찰력(悟道) 

- 온디바이스 기반 모델(사용 가능한 경우)(iOS 26+) 그렇지 않으면 지역 가이드 대체 
- 결과를 메모에 저장할 수 있습니다. 

### 위젯 및 시스템 

- 위젯: Daily Tan, 유명 라인, 즐겨찾기 캐러셀, 코스 진행 
- 라이브 활동: 독서 및 명상(별도 토글) 
- 제어 센터(iOS 18+), Siri/단축키, Spotlight 옵션, 대체 아이콘 5개
