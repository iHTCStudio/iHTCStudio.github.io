## Mise en route (étape par étape) 

### 1. Premier lancement

1. Installez depuis l'[App Store](https://apps.apple.com/app/id6797013590) et ouvrez **iRootWise**.
2. Complétez le **guide de bienvenue de 7 pages** (marque → Daily Tan → lecture → s’asseoir → cours → extras système → confidentialité).
3. Rejouez à tout moment : **Paramètres → Aide → Guide des fonctionnalités**.
4. Les guides intégrés à l’application **Utilisation / Widget / Raccourcis** se trouvent sous **Paramètres → Aide**.

### 2. Découvrez le tan du jour sur l’écran d’accueil

1. Ouvrez l’onglet **Accueil**.
2. **Daily Tan** affiche le passage du jour (pool de contexte saisonnier) ; appuyez pour lire, ou utilisez **récitation en un clic** (ce passage seulement).
3. Vérifiez votre **série** (appuyez pour les détails). Optionnel : activez les **notifications Daily Tan** dans Paramètres (local uniquement).
4. **Continuer la lecture** apparaît lorsque vous avez un passage lu précédemment différent de celui d’aujourd’hui.

### 3. Parcourir, thèmes et lignes célèbres

1. Ouvrez **Parcourir** (peut être caché dans Paramètres ; il s'ouvre ensuite en tant que feuille).  
2. Explorez les **éditions Ming / Qing**, les **thèmes**, les **lignes célèbres** et les **cours**.  
3. Basculez entre **liste / grille / cartes** ; sélection multiple pour réciter, mettre en favori ou ajouter aux listes.  
4. **Recherche** couvre original, vernaculaire, appréciation et anglais. Sur iOS, **recherche manuscrite** optionnelle reconnaît les caractères sur l'appareil. Le chargement de la bibliothèque affiche « préparation de la recherche » jusqu'à ce qu'elle soit prête.  

### 4. Lecture bilingue & cartes à partager

1. Dans les détails, définissez la **langue de lecture** : bilingue / chinois uniquement / anglais uniquement (indépendant de la langue de l'interface).  
2. Activez ou désactivez le vernaculaire, l'appréciation, le pinyin, le texte vertical et la lecture segmentée (≥8 phrases ; 4–12 par page).  
3. Appuyez longuement sur une ligne : copier, traduction système, réciter à partir d'ici, ou présélectionner une carte à partager.  
4. Ouvrez **Carte à partager** → choisissez parmi **12 styles** → enregistrez dans Photos / Fichiers ou partagez via le système (pas de pinyin sur les cartes).  

### 5. S'asseoir et respirer (静坐)

1. Ouvrez **Méditation** depuis l’Accueil, le Centre de Contrôle ou `irootwise://meditation`.
2. Le préréglage par défaut est **4-7-8 calme** ; essayez les préréglages nature / boîte / scan corporel. Son ambiant + carillon de fin optionnels.
3. Les sessions de **≥30s** comptent pour les statistiques. L’**historique de méditation reste sur cet appareil** (intentionnellement non synchronisé via iCloud).
4. Optionnel : inscrire les **minutes de pleine conscience Apple** (désactivé par défaut — activez d'abord dans l’app, puis accordez à Santé). Lire l’Activité en direct et l’Activité de méditation en direct sont des **interrupteurs séparés**, tous deux désactivés par défaut.

### 6. Cinq cours de cultivation

1. Ouvrez **Cours** : Conduite (7) · Facilité (14) · Adversité (21) · Cultivation (30) · Saisons (180).
2. L’Accueil **Leçon du jour** mène à votre parcours préféré / en cours (les cours longs affichent les noms de phase).
3. Validez les jours (stèle + LWW multi-appareils), rédigez vos notes de réflexion, réinitialisez un cours si nécessaire.
4. **Rappel de leçon** optionnel (indépendant de Daily Tan ; désactivé par défaut).

### 7. Widgets, Siri et raccourcis

1. Appuyez longuement sur l’écran d’accueil → ajoutez **Bronzage quotidien / Citation célèbre / Favoris / Progression du cours**.
2. Demandez à **Siri** le bronzage d’aujourd’hui, la séance, aléatoire, favoris, cours, recherche, continuer la lecture, et plus.
3. Configurez les actions rapides de l’écran d’accueil dans **Réglages → Raccourcis**.
4. Table complète `irootwise://` : [Liens de raccourcis](url-scheme).

### 8. Confidentialité & synchronisation

1. La lecture principale, la séance, les cours, les widgets et les notifications locales fonctionnent **hors ligne** après l’installation.
2. **iCloud** facultatif synchronise les favoris, listes, notes, maîtrise, historique, cours et séries — **pas** les totaux de méditation.
3. L’indexation **Spotlight** est **désactivée par défaut** (activez-la dans les Réglages si vous le souhaitez).
4. L’astuce StoreKit facultative ne débloque jamais le contenu payant.

## Pourquoi vous voudrez télécharger

- **La sagesse que vous pouvez pratiquer** — Les leçons quotidiennes de bronzage + assis + jour transforment *Caigentan* en une habitude, pas un signet. 
- **Un véritable bureau bilingue** — langue vernaculaire, appréciation et anglais à chaque passage ; La langue de l'interface utilisateur et la langue de lecture sont indépendantes. 
- **Calme par conception** — méditation sur le souffle d'encre avec récupération de session, son ambiant et activité en direct en option — sans flux social. 
- **Cinq chemins, pas une liste** — d'un début de conduite de 7 jours à un arc saisonnier de 180 jours. 
- ** Une confidentialité que vous pouvez ressentir ** : pas de compte, pas de publicité, pas de SDK d'analyse ; les statistiques de méditation ne quittent jamais l'appareil. 

## Fonctionnalités 

### Bibliothèque & lecture 

- **697** passages après la déduplication Ming/Qing ; **180** lignes célèbres ; **8** thèmes ; notes du glossaire 
- Couverture complète en anglais ; vernaculaire + appréciation en trois parties ; pinyin; texte vertical ; lecteur immersif 
- Lecture segmentée, TTS + Now Playing, files d'attente continues (favoris/jours de cours) 
- Notes, niveaux de maîtrise, historique de lecture (jusqu'à 100), favoris et listes personnalisées 

### Daily Tan et lignes célèbres 

- Pool de contexte saisonnier ; notifications locales ; widget « mélange » 
- Page dédiée aux lignes célèbres + widget quotidien stable des lignes célèbres 

### Méditation

- Plusieurs préréglages (par défaut **4-7-8**), interface utilisateur de souffle d'encre, pluie ambiante/cloche/vent/encre 
- **Session immersive** — la barre d'onglets se cache et le chrome s'estompe ; appuyez sur l'orbe pour révéler à nouveau les commandes 
- Reprise d'instantané et crédit de démarrage à froid (≥30 s) ; notification de fin ; Pleine conscience HealthKit en option 
- Statistiques sur l'appareil uniquement ; supprimer une session ou tout effacer (avec des règles d'annulation de séquence le cas échéant) 

### Cours 

- Cinq sentiers ensemencés avec des guides quotidiens ; regroupement phases / semaine / mois pour les cours longs 
- Enregistrement, réflexions, célébration de fin, rappels de cours facultatifs 

### Insight (悟道) 

- Modèles Foundation sur appareil lorsqu'ils sont disponibles (iOS 26+) ; sinon, repli du guide local 
- Les résultats peuvent être enregistrés dans des notes 

### Widgets et système 

- Widgets : Daily Tan, Famous Line, carrousel de favoris, progression du cours 
- Activité en direct : lecture et méditation (bascules séparées) 
- Centre de contrôle (iOS 18+), Siri / Raccourcis, Spotlight en option, 5 icônes alternatives
