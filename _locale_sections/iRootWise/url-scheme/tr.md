iRootWise, ** `irootwise://` ** Kısa kesimler, widgets, Siri, Control Center ve Home Ekran eylemleri için bağlantılar.

## Bağlantı biçimi


```
irootwise://{host}?{params}
```


## Daily & reading

| URL | Açar |
|-----|-------|
| `irootwise://daily` or `today` | Daily Tan |
| `irootwise://random` | Rastgele pasaj |
| `irootwise://passage?id=1` (`tan`; host may be numeric) | Pasaj ('focus=' char dengeleme, "speak=1" to ree) |
| `irootwise://last-read` (`lastread`) | Son okumaya devam et |
| `irootwise://reading-history` (`history`) | Okuma geçmişi |
| `irootwise://notes` | Notlar |
| `irootwise://mastered` | Mastered |
| `irootwise://home` | Home (eski çöp) |

## Göz ve çalışma

| URL | Açar |
|-----|-------|
| `irootwise://categories` (`browse`) | Gözat |
| `irootwise://theme?id=` | Tema listesi |
| `irootwise://section?id=` | Edition bölüm listesi listesi |
| `irootwise://famous` (`lines`) | Ünlü dizeler |
| `irootwise://favorites` (`fav`) | Favoriler |
| `irootwise://search?q=` | Ara |
| `irootwise://course` (`courses`) | Ders listesi |
| `irootwise://course?id=&day=` | Course / spesifik gün |
| `irootwise://meditation` (`sit` / `breathe`; optional `preset=`) | Meditasyon |
| `irootwise://insight?id=` (`ai`) | (Bugün) |
