iRootWise 지원 ** `irootwise://` ** 단축키, 위젯, Siri, 제어 센터 및 홈 화면 작업에 대한 링크.

## 링크 형식


```
irootwise://{host}?{params}
```


## 매일 & 독서

| URL | 열리는 화면 |
|-----|-------|
| `irootwise://daily` or `today` | 매일 탄 |
| `irootwise://random` | 무작위 구절 |
| `irootwise://passage?id=1` (`tan`; host may be numeric) | Passage (`focus=` char offset, `speak=1`를 다시 인용) |
| `irootwise://last-read` (`lastread`) | 계속 읽기 |
| `irootwise://reading-history` (`history`) | 읽기 기록 |
| `irootwise://notes` | 메모 |
| `irootwise://mastered` | 인기있는 |
| `irootwise://home` | 홈 (클립 스택) |

## 검색 및 연구

| URL | 열리는 화면 |
|-----|-------|
| `irootwise://categories` (`browse`) | 둘러보기 |
| `irootwise://theme?id=` | 테마 목록 |
| `irootwise://section?id=` | 판 섹션 목록 |
| `irootwise://famous` (`lines`) | 명구 목록 |
| `irootwise://favorites` (`fav`) | 즐겨찾기 |
| `irootwise://search?q=` | 검색 |
| `irootwise://course` (`courses`) | 코스 목록 |
| `irootwise://course?id=&day=` | 코스 / 특정 일 |
| `irootwise://meditation` (`sit` / `breathe`; optional `preset=`) | 학회소개 |
| `irootwise://insight?id=` (`ai`) | Insight (id 없음 → 오늘) |

## 설정 및 가이드

| URL | 열리는 화면 |
|-----|-------|
| `irootwise://settings` | 설정 |
| `irootwise://usage-guide` | 사용 가이드 |
| `irootwise://widget-guide` | 위젯 가이드 |
| `irootwise://shortcuts-guide` | 단축어 가이드 |
| `irootwise://feature-guide` | 관광 명소 |
| `irootwise://home-shortcuts` | 홈 화면 빠른 작업 |
| `irootwise://feedback` (`mail`) | 이름 * |
| `irootwise://in-app-review` (`review`) | 빠른 속도 |

테마 / 섹션 / 유명 / 좋아하는 페이지는 ** 목록 옵션 →이 목록**을 통해 깊은 링크를 복사 할 수 있습니다.
