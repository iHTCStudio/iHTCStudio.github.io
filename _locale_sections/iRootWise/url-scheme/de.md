iRootWise unterstützt ** `irootwise://` ** Links für Shortcuts, Widgets, Siri, Control Center und Home Screen Aktionen.

## Linkformat


```
irootwise://{host}?{params}
```


## Täglich & Lesen

| URL | Öffnet |
|-----|-------|
| `irootwise://daily` or `today` | Tägliche Tannine |
| `irootwise://random` | Zufällige Passage |
| `irootwise://passage?id=1` (`tan`; host may be numeric) | Passage (`focus=` char offset, `speak=1` to recite) |
| `irootwise://last-read` (`lastread`) | Weiterlesen |
| `irootwise://reading-history` (`history`) | Leseverlauf |
| `irootwise://notes` | Notizen |
| `irootwise://mastered` | Beherrscht |
| `irootwise://home` | Zuhause (Clear Stack) |

## Browse & Studie

| URL | Öffnet |
|-----|-------|
| `irootwise://categories` (`browse`) | Durchsuchen |
| `irootwise://theme?id=` | Themenliste |
| `irootwise://section?id=` | Edition Section List |
| `irootwise://famous` (`lines`) | Berühmte Zeilen |
| `irootwise://favorites` (`fav`) | Favoriten |
| `irootwise://search?q=` | Suche |
| `irootwise://course` (`courses`) | Kursliste |
| `irootwise://course?id=&day=` | Kurs / bestimmter Tag |
| `irootwise://meditation` (`sit` / `breathe`; optional `preset=`) | Meditation |
| `irootwise://insight?id=` (`ai`) | Insight (keine ID → heute) |

## Einstellungen & Anleitungen

| URL | Öffnet |
|-----|-------|
| `irootwise://settings` | Einstellungen |
| `irootwise://usage-guide` | Nutzungsanleitung |
| `irootwise://widget-guide` | Widget-Anleitung |
| `irootwise://shortcuts-guide` | Kurzbefehle-Anleitung |
| `irootwise://feature-guide` | Feature Tour |
| `irootwise://home-shortcuts` | Home Bildschirm Schnelle Aktionen |
| `irootwise://feedback` (`mail`) | Feedback |
| `irootwise://in-app-review` (`review`) | Rate prompt |

Theme / Abschnitt / berühmte / Favoritenseiten können ihren tiefen Link über **Listenoptionen → Diese Liste ** kopieren.
