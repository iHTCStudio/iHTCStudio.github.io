iRoot รองรับหน่วยฉลาด ** `irootwise://` BAR * ลิงก์สําหรับปุ่มพิมพ์ลัด, วิดเจ็ต, Siri, ศูนย์ควบคุม, และการกระทําหน้าจอส่วนตัว

## รูปแบบลิงก์


```
irootwise://{host}?{params}
```


## การอ่านทุกวัน

| URL | เปิด |
|-----|-------|
| `irootwise://daily` or `today` | เดลีทัน |
| `irootwise://random` | ข้อความแบบสุ่ม |
| `irootwise://passage?id=1` (`tan`; host may be numeric) | Passage ('Head=' character,'ภาษาอังกฤษ=1'เพื่อท่อง) |
| `irootwise://last-read` (`lastread`) | ทําการอ่านล่าสุดต่อไป |
| `irootwise://reading-history` (`history`) | ประวัติการอ่าน |
| `irootwise://notes` | บันทึก |
| `irootwise://mastered` | สําเร็จการศึกษาแล้ว |
| `irootwise://home` | บ้าน (กองว่าง) |

## เรียกดูการศึกษา

| URL | เปิด |
|-----|-------|
| `irootwise://categories` (`browse`) | เรียกดู |
| `irootwise://theme?id=` | รายการชุดตกแต่ง |
| `irootwise://section?id=` | รายการหัวข้อเพิ่มเติม |
| `irootwise://famous` (`lines`) | บรรทัดขึ้นชื่อ |
| `irootwise://favorites` (`fav`) | รายการโปรด |
| `irootwise://search?q=` | ค้นหา |
| `irootwise://course` (`courses`) | รายการหลักสูตร |
| `irootwise://course?id=&day=` | วัน ที่ พิเศษ |
| `irootwise://meditation` (`sit` / `breathe`; optional `preset=`) | ใคร่ครวญ |
| `irootwise://insight?id=` (`ai`) | Intertain (วันนี้ไม่มีหมายเลข) |

## การตั้งค่าและคู่มือ

| URL | เปิด |
|-----|-------|
| `irootwise://settings` | การตั้งค่า |
| `irootwise://usage-guide` | คู่มือการใช้งาน |
| `irootwise://widget-guide` | คู่มือวิดเจ็ต |
| `irootwise://shortcuts-guide` | คู่มือทางลัด |
| `irootwise://feature-guide` | การเดินทัวร์แบบธรรมชาติ |
| `irootwise://home-shortcuts` | การกระทํากับหน้าจอส่วนตัวอย่างรวดเร็ว |
| `irootwise://feedback` (`mail`) | แหล่งป้อน |
| `irootwise://in-app-review` (`review`) | อัตโนมัติ |
