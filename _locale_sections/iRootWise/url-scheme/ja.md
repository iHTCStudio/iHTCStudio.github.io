iRootWiseは、ショートカット、ウィジェット、Siri、コントロールセンター、ホーム画面のアクションのための** `irootwise://` **リンクをサポートしています。

## リンク形式


```
irootwise://{host}?{params}
```


## 毎日の読書

| URL | 開く画面 |
|-----|-------|
| `irootwise://daily` or `today` | デイリータン |
| `irootwise://random` | ランダムな章句 |
| `irootwise://passage?id=1` (`tan`; host may be numeric) | パッセージ (`focus=` char offset, `speak=1` から recite) |
| `irootwise://last-read` (`lastread`) | 続きを読む |
| `irootwise://reading-history` (`history`) | 閲覧履歴 |
| `irootwise://notes` | ノート |
| `irootwise://mastered` | マスタード |
| `irootwise://home` | ホーム(クリアスタック) |

## ブラウズ&スタディ

| URL | 開く画面 |
|-----|-------|
| `irootwise://categories` (`browse`) | ブラウズ |
| `irootwise://theme?id=` | テーマ一覧 |
| `irootwise://section?id=` | エディションセクションリスト |
| `irootwise://famous` (`lines`) | 名句一覧 |
| `irootwise://favorites` (`fav`) | お気に入り |
| `irootwise://search?q=` | 検索 |
| `irootwise://course` (`courses`) | コース一覧 |
| `irootwise://course?id=&day=` | コース/特定の日 |
| `irootwise://meditation` (`sit` / `breathe`; optional `preset=`) | メディテーション |
| `irootwise://insight?id=` (`ai`) | Insight(IDなし → 本日) |

## 設定とガイド

| URL | 開く画面 |
|-----|-------|
| `irootwise://settings` | 設定 |
| `irootwise://usage-guide` | 使い方ガイド |
| `irootwise://widget-guide` | ウィジェットガイド |
| `irootwise://shortcuts-guide` | ショートカットガイド |
| `irootwise://feature-guide` | 特徴ツアー |
| `irootwise://home-shortcuts` | ホーム スクリーンのクイックアクション |
| `irootwise://feedback` (`mail`) | フィードバック |
| `irootwise://in-app-review` (`review`) | 率のプロンプト |

テーマ/セクション/有名な/お気に入りページは、**Listオプション→このリスト**を介して深いリンクをコピーすることができます。
