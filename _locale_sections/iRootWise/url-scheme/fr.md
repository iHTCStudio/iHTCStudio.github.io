iRootWise prend en charge les liens ** `irootwise://` ** pour les actions Raccourcis, Widgets, Siri, Control Center et Home Screen.

## Format de lien


```
irootwise://{host}?{params}
```


## Lecture quotidienne

| URL | Ouvre |
|-----|-------|
| `irootwise://daily` or `today` | Tan quotidien |
| `irootwise://random` | Passage aléatoire |
| `irootwise://passage?id=1` (`tan`; host may be numeric) | Passage (`focus=` char offset, `speak=1` pour réciter) |
| `irootwise://last-read` (`lastread`) | Continuer la dernière lecture |
| `irootwise://reading-history` (`history`) | Historique de lecture |
| `irootwise://notes` | Notes |
| `irootwise://mastered` | Maîtrise |
| `irootwise://home` | Accueil (pile claire) |

## Parcourir et étudier

| URL | Ouvre |
|-----|-------|
| `irootwise://categories` (`browse`) | Parcourir |
| `irootwise://theme?id=` | Liste des thèmes |
| `irootwise://section?id=` | Liste des sections d'édition |
| `irootwise://famous` (`lines`) | Vers célèbres |
| `irootwise://favorites` (`fav`) | Favoris |
| `irootwise://search?q=` | Recherche |
| `irootwise://course` (`courses`) | Liste des cours |
| `irootwise://course?id=&day=` | Cours / journée spécifique |
| `irootwise://meditation` (`sit` / `breathe`; optional `preset=`) | Méditation |
| `irootwise://insight?id=` (`ai`) | Insight (pas d'id → aujourd'hui) |

## Réglages et guides

| URL | Ouvre |
|-----|-------|
| `irootwise://settings` | Réglages |
| `irootwise://usage-guide` | Guide d'utilisation |
| `irootwise://widget-guide` | Guide des widgets |
| `irootwise://shortcuts-guide` | Guide Raccourcis |
| `irootwise://feature-guide` | Visite principale |
| `irootwise://home-shortcuts` | Actions rapides de l'écran d'accueil |
| `irootwise://feedback` (`mail`) | Commentaires |
| `irootwise://in-app-review` (`review`) | Taux |

Thème / section / célèbre / favoris pages peuvent copier leur lien profond via ** Options de liste → Cette liste**.
