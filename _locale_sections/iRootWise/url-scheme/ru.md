iRootWise поддерживает ссылки ** `irootwise://` ** для ярлыков, виджетов, Siri, Центра управления и действий на домашнем экране.

## Формат ссылки


```
irootwise://{host}?{params}
```


## Ежедневно и чтение

| URL | Открывает |
|-----|-------|
| `irootwise://daily` or `today` | Ежедневный Тан |
| `irootwise://random` | Случайный отрывок |
| `irootwise://passage?id=1` (`tan`; host may be numeric) | Прохождение ('focus=' char offset, 'speak=1' to recite) |
| `irootwise://last-read` (`lastread`) | Продолжить последнее чтение |
| `irootwise://reading-history` (`history`) | История чтения |
| `irootwise://notes` | Заметки |
| `irootwise://mastered` | мастеринг |
| `irootwise://home` | Домой (Clear Stack) |

## Просмотр и изучение

| URL | Открывает |
|-----|-------|
| `irootwise://categories` (`browse`) | Обзор |
| `irootwise://theme?id=` | Тематический список |
| `irootwise://section?id=` | Список разделов издания |
| `irootwise://famous` (`lines`) | Знаменитые строки |
| `irootwise://favorites` (`fav`) | Избранное |
| `irootwise://search?q=` | Поиск |
| `irootwise://course` (`courses`) | Список курсов |
| `irootwise://course?id=&day=` | Курс/конкретный день |
| `irootwise://meditation` (`sit` / `breathe`; optional `preset=`) | Медитация |
| `irootwise://insight?id=` (`ai`) | Insight (No id) сегодня |

## Настройки и руководства

| URL | Открывает |
|-----|-------|
| `irootwise://settings` | Настройки |
| `irootwise://usage-guide` | Руководство по использованию |
| `irootwise://widget-guide` | Руководство по виджетам |
| `irootwise://shortcuts-guide` | Руководство по «Командам» |
| `irootwise://feature-guide` | Особенности тура |
| `irootwise://home-shortcuts` | Домой Экран Быстрые действия |
| `irootwise://feedback` (`mail`) | обратная связь |
| `irootwise://in-app-review` (`review`) | Быстрая ставка |

Тема/раздел/известные/любимые страницы могут скопировать свою глубокую ссылку через **Список опций → Этот список**.
