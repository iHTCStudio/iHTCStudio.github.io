**คําพูดหนึ่งของเมิ่งชุย – เดินด้วยจิตวิญญาณที่กว้างขวาง**

iMencius (อ้ายเมิ่งจื่อ / อ้ายเมิ่งจื่อ) เป็นสตูดิโอ **ออฟไลน์ของ Mencius** — ไม่ใช่การทิ้งข้อความธรรมดาอื่น ๆ **ไม่ต้องใช้บัญชี **ไลบรารี *Mencius* ติดตั้งบนอุปกรณ์ของคุณด้วย **ภาษาต้นฉบับ / ภาษาท้องถิ่น / ภาษาอังกฤษของ Legge** เริ่มต้นด้วย **การพูดประจําวัน** **การท่อง** ด้วยการไฮไลท์ย่อหน้า ฝึกฝนใน **การศึกษาการบํารุงปราณ** เล่น **การล่าสัตว์หยี** ส่งออก **การ์ดเมิ่ง** เพิ่ม **วิดเจ็ต**, ตัวเลือก **การอ่านกิจกรรมสด**, **Siri & คําสั่งลัด** และตัวเลือก **iCloud** ต้นฉบับเป็นข้อความการศึกษาในโดเมนสาธารณะ; โน้ตเป็นสิ่งช่วยเหลือในการศึกษา **ไม่มีโฆษณา ไม่มีการติดตาม Data Not Collected **

**ในพริบตาเดียว: ** 690 บท · 3,549 บท · 100 บรรทัดที่มีชื่อเสียง · 26 การเปรียบเทียบ · 7 เสียงสนทนา · ภาษาอังกฤษดั้งเดิม / ภาษาพื้นเมือง / ภาษาเลอเกะ · ท่อง · การศึกษาบํารุงปราณ · การล่าสัตว์ · การพูดทุกวัน · การ์ดเมิ่ง · วิดเจ็ต · ศูนย์ควบคุม · `imencius://` · EN / ย่อ / หนา

## การเริ่มต้น (ทีละขั้นตอน)

### 1. การเปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store] (https://apps.apple.com/app/id6808957787) และเปิด **iMencius**
2. เสร็จสิ้นคู่มือต้อนรับ (การอ่านประจําวัน → การอ่านปิด → การท่อง → การศึกษา → คุณสมบัติของระบบ → ความเป็นส่วนตัว)
3. เล่นซ้ําได้ทุกเมื่อ: **การตั้งค่า → วิธีใช้ → คู่มือคุณสมบัติ** (`imencius://feature-guide`)
4. คู่มือการใช้งาน / วิดเจ็ต / คําสั่งลัดอยู่ภายใต้ **การตั้งค่า → วิธีใช้**

### 2. อ่านส่วนของวันนี้บน Home

1. เปิดแท็บ **Home**
2. วีรบุรุษ**Daily Saying**แสดงบทของวันนี้ แตะเพื่อเปิดรายละเอียด
3. ไม่บังคับ: เปิดใช้งานการแจ้งเตือน **Daily Saying** ในพื้นที่ในการตั้งค่า
4. กระโดดจาก Home ไปยัง Recitation, Nurturing Qi Study, Yi Hunt, Favorites และ Search

### 3. เรียกดูและค้นหา

1. เรียกดู *Mencius* corpus ทั้งหมด บรรทัดที่มีชื่อเสียง และชั้นวางเฉพาะทาง
2. ค้นหาชื่อเรื่องและบรรทัด (ง่ายขึ้น / สะดวกแบบดั้งเดิม) บน iOS การค้นหาลายมือเขียน** ทางเลือก** จะจดจําอักขระบนอุปกรณ์
3. ติดดาวย่อหน้าลงใน **รายการโปรด** และรวบรวมลงใน **รายการอ่านส่วนตัว**

### 4. ปิดการอ่านและแชร์การ์ด

1. สลับ **สองภาษา / เฉพาะภาษาจีน / เฉพาะภาษาอังกฤษ**; สลับเลเยอร์อย่างอิสระหากมี
2. ลองใช้การอ่านแบบสมจริง เค้าโครงแนวตั้ง ขนาดแบบอักษร และหน้าแบบแบ่งส่วนสําหรับส่วนที่ยาวขึ้น
3. เปิด **การ์ดเมิ่ง** → เลือกสไตล์ / อัตราส่วน → บันทึกไปยังรูปภาพ (เพิ่มเท่านั้น) หรือการแชร์ระบบ

### 5. การศึกษาการท่องและหล่อเลี้ยงพลังปราณ

1. เปิดเวิร์กเบนช์การท่องเพื่อดู TTS ที่ไฮไลท์ไว้ เสียงและจังหวะที่ปรับได้ คําบรรยายภาษาท้องถิ่น/ภาษาอังกฤษแบบไม่บังคับ การเล่นต่อเนื่อง และเสียงพื้นหลัง
2. **การศึกษาการหล่อเลี้ยงปราณ** (`imencius://study`): การจาง การเติมว่าง การตรวจสอบตัวเอง และการทดสอบ พร้อมการติดตามความเชี่ยวชาญ
3. **Yi Hunt** on Home เป็นเกมค้นหาส่วนแยกต่างหาก

### 6. วิดเจ็ต, Siri และคุณสมบัติของระบบ

1. เพิ่มวิดเจ็ต Daily / Famous Line / Favorites / Study Progress (และ Almanac หากมี)
2. ใช้ศูนย์ควบคุม, Siri, Spotlight และ `imencius://` ลิงก์ลึก
3. กิจกรรมการอ่านสดแบบไม่บังคับยังคงมีให้ใช้งานบนอุปกรณ์ที่รองรับ iPhone

### 7. ความเป็นส่วนตัวและการซิงค์

1. คลัง, การอ่าน, การท่อง (ระบบ TTS), การศึกษา, วิดเจ็ต และการแจ้งเตือนในเครื่องจะทํางานแบบออฟไลน์อย่างสมบูรณ์หลังจากติดตั้ง
2. ตัวเลือก**iCloud Sync** สะท้อนรายการโปรด รายการ ประวัติ ความคืบหน้า เส้น และโน้ตผ่าน**iCloud**ส่วนตัวของคุณ
3. เคล็ดลับสําหรับนักพัฒนา (ไม่บังคับ StoreKit) ไม่ควรปลดล็อค Paywall และไม่ควรสร้างบัญชี

## เหตุใดคุณจึงต้องการดาวน์โหลด

- **Mencius เป็นโต๊ะทํางาน** – **แกลเลอรีแบบอนาล็อก** และ **แผนที่บทสนทนา**; ภาษาอังกฤษสาธารณะของ Legge; **4** ประเภทวิดเจ็ต; **6** ไอคอนทางเลือก
- **ปิดการอ่านที่ติด** - การท่องคาราโอเกะ โหมดชั้นเรียน และ Yi Hunt
- **จังหวะประจําวัน** – การพูดทุกวันในบ้าน วิดเจ็ต และรายการเตือนความจําในพื้นที่แบบไม่บังคับ
- **ความเป็นส่วนตัวตามการออกแบบ** – ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK การวิเคราะห์
