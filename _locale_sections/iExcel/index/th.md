iExcel (爱表格) คือ **สตูดิโอการเรียนรู้ Excel ออฟไลน์** สำหรับ **iPhone, iPad และ Mac** เชี่ยวชาญ **สูตร ฟังก์ชัน เคล็ดลับการปฏิบัติ บทเรียนแบบมีโครงสร้าง แบบทดสอบ และแป้นพิมพ์ลัด** — ทั้งหมดนี้รวมอยู่ในแอปแล้ว **ไม่ต้องใช้บัญชี** ติดตามความคืบหน้าด้วยวงแหวนการเรียนรู้และต่อเนื่อง เปิด **ฟังก์ชันรายวัน** ฝึกฝนใน **สนามเด็กเล่นสูตรน้ำหนักเบา** และใกล้ชิดกับ **4 วิดเจ็ต**, **สปอตไลท์**, **ทางลัด Siri / App** และ **`iexcel://` ลิงก์ในรายละเอียด** ตัวเลือก **การซิงค์ iCloud** สำหรับรายการโปรด ความคืบหน้า และการตั้งค่า **ไม่มีโฆษณา ไม่มีการติดตาม**

> **หมายเหตุ:** Excel เป็นเครื่องหมายการค้าของ Microsoft iExcel เป็นเครื่องมือการเรียนรู้อิสระและไม่มีส่วนเกี่ยวข้องกับ Microsoft

## เริ่มต้นใช้งาน

1. ทำตาม **คำแนะนำต้อนรับ 5 หน้า** เมื่อเปิดตัวครั้งแรก (เปิดใหม่ได้ทุกเมื่อใน **การตั้งค่า → คำแนะนำ**)
2. ใน **หน้าแรก** ให้ตรวจสอบ **ความคืบหน้าการเรียนรู้** **เรียนรู้ต่อ** และ **ฟังก์ชั่นรายวัน**
3. เรียกดู **หมวดหมู่** — ฟังก์ชันยอดนิยม คณิตศาสตร์ สถิติ ข้อความ การค้นหา อาร์เรย์ไดนามิก เคล็ดลับ บทเรียน แบบทดสอบ และทางลัด
4. เปิดรายการใดๆ เพื่อดูรายละเอียดที่สมบูรณ์ — ไวยากรณ์ พารามิเตอร์ ตัวอย่าง ขั้นตอน หรือการผูกคีย์ Mac/Windows
5. ทำเครื่องหมายรายการว่า **เชี่ยวชาญ** เมื่อคุณเข้าใจ (การเปิดเพียงอย่างเดียวจะเพิ่มในรายการล่าสุดและแนวของคุณเท่านั้น)
6. ลองใช้ **Formula Playground** กับเซลล์ตัวอย่าง หรือทำ **แบบทดสอบ** และอ่านคำอธิบาย
7. ดาราคนโปรด; เปิดใช้งานตัวเลือก **iCloud Sync** เพื่อติดตามความคืบหน้าในอุปกรณ์ต่างๆ
8. เพิ่ม **วิดเจ็ต** ใช้ **การดำเนินการด่วนบนหน้าจอโฮม** หรือขอให้ **Siri** เปิดฟังก์ชันหรือเริ่มแบบทดสอบ

## คุณสมบัติ

### ห้องสมุดการเรียนรู้

| โมดูล | นับ | ไฮไลท์ |
|--------|------:|------------|
| ฟังก์ชั่น | 265 | ไวยากรณ์ พารามิเตอร์ ตัวอย่าง หมายเหตุ ฟังก์ชันที่เกี่ยวข้อง |
| เคล็ดลับ | 71 | ขั้นตอนการทำงานสเปรดชีตที่ใช้งานได้จริงพร้อมขั้นตอนที่ชัดเจน |
| บทเรียน | 44 | เส้นทางที่มีโครงสร้างตั้งแต่พื้นฐานไปจนถึงขั้นสูง |
| แบบทดสอบ | 23 | ปรนัยพร้อมคำอธิบาย บันทึกคะแนนที่ดีที่สุดแล้ว |
| ทางลัด | 114 | การผูกคีย์ Mac และ Windows (ไม่นับอยู่ในระหว่างดำเนินการ) |

หมวดหมู่ฟังก์ชัน ได้แก่ ยอดนิยม คณิตศาสตร์และตรีโกณมิติ สถิติ ข้อความ ตรรกะ การค้นหาและการอ้างอิง วันที่และเวลา การเงิน ข้อมูล อาร์เรย์ไดนามิก วิศวกรรม และฐานข้อมูล

### หน้าแรกและความคืบหน้า

- **วงแหวนความคืบหน้า** — รายการที่เชี่ยวชาญ ÷ ผลรวมที่เรียนรู้ได้ (ไม่รวมทางลัด)
- **เรียนรู้ต่อ** — ดึงข้อมูลล่าสุดที่ยังไม่ได้อ่านหรือฟังก์ชันยอดนิยมถัดไป
- **ฟังก์ชันรายวัน** — หนึ่งฟังก์ชันเด่นต่อวันตามปฏิทิน
- **ล่าสุด** (สูงสุด 30 รายการ) และ **รายการโปรด** บนหน้าแรก
- **ต่อเนื่อง** — คุณเปิดเนื้อหาการเรียนรู้ติดต่อกันหลายวัน
- ตัวเลือก **รายการโปรด** และ **หมวดหมู่** แท็บ (สลับในการตั้งค่า)

### สนามเด็กเล่นสูตร

**พื้นที่ฝึกหัดน้ำหนักเบา** บนข้อมูลตัวอย่างคงที่ (ไม่ใช่เครื่องมือ Excel เต็มรูปแบบ):

- ลองใช้รูปแบบ `SUM`, `AVERAGE`, `MAX`, `MIN`, `IF` และรูปแบบ `A1+A2+A3` แบบง่ายๆ
- ปุ่มที่ตั้งไว้ล่วงหน้ากรอกตัวอย่างและประเมินทันที
- สูตรอื่นๆ แสดงสถานะ "ยังไม่รองรับ" อย่างชัดเจน

ใช้เพื่อเพิ่มหน่วยความจำ — ไม่ใช่แทนที่สเปรดชีต

### ค้นหาและรายละเอียด

- ค้นหาด้วย **ชื่อ สรุป แท็ก หรือรหัส** (จีนและอังกฤษ)
- **iOS 18+** แท็บค้นหาเฉพาะ iOS รุ่นก่อนหน้าผ่านการดำเนินการด่วน ลิงก์ในรายละเอียด หรือ Intent
- หน้าฟังก์ชัน: คัดลอกไวยากรณ์ ข้ามไปยังฟังก์ชันที่เกี่ยวข้อง
- เคล็ดลับ / หน้าบทเรียน: เนื้อหา ขั้นตอน ฟังก์ชันที่เชื่อมโยง
- ขั้นตอนการตอบคำถาม: คำตอบ → เปิดเผย → คำอธิบาย → คะแนนที่ดีที่สุด + เชี่ยวชาญอัตโนมัติ

### วิดเจ็ตและการรวมระบบ

| บูรณาการ | สิ่งที่คุณได้รับ |
|-------------|--------------|
| **4 วิดเจ็ต** | ฟังก์ชั่นรายวัน, ความคืบหน้า, รายการโปรด, รายการตอบคำถาม |
| **ล็อคหน้าจอ** | อุปกรณ์เสริมฟังก์ชั่นรายวันและความคืบหน้า (iOS) |
| **การดำเนินการด่วนบนหน้าจอหลัก** | หน้าแรก สนามเด็กเล่น แบบทดสอบ ค้นหา |
| **สปอตไลท์** | ดัชนีรายการการเรียนรู้ทั้งหมด |
| **ทางลัด Siri / แอพ** | เปิดหน้าแรก สนามเด็กเล่น แบบทดสอบ หรือฟังก์ชันตามชื่อ |
| **`iexcel://` ลิงก์** | ดู [ลิงก์ทางลัด](url-scheme) |

### ความเป็นส่วนตัว

- **ไม่มีบัญชี · ไม่ต้องลงทะเบียน · ไม่มีโฆษณา · ไม่มีการติดตาม**
- เนื้อหาการเรียนรู้ทั้งหมด **รวมกลุ่มออฟไลน์**
- ตัวเลือก **พื้นที่จัดเก็บคีย์-ค่า iCloud** สำหรับรายการโปรด ความคืบหน้า คะแนนแบบทดสอบ สถิติต่อเนื่อง และการตั้งค่า (ปิดโดยค่าเริ่มต้น)
- รหัสฟังก์ชันรายวันยังคงอยู่ **ต่ออุปกรณ์** (ไม่ได้ซิงค์)
- การซื้อทิปเสริมผ่าน **Apple StoreKit** เท่านั้น
