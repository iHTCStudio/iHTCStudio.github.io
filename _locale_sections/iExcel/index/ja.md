iExcel (爱表格) is an **offline Excel learning studio** for **iPhone, iPad, and Mac**. Master **formulas, functions, practical tips, structured lessons, quizzes, and keyboard shortcuts** — all bundled in the app. **No account required.** Track progress with a learning ring and streaks, open **Daily Function**, practice in a **lightweight formula playground**, and stay close with **4 widgets**, **Spotlight**, **Siri / App Shortcuts**, and **`iexcel://` deep links**. Optional **iCloud sync** for favorites, progress, and preferences. **No ads. No tracking.**

> **注意:** Excel は Microsoft の商標です。 iExcel は独立した学習ツールであり、Microsoft とは提携していません。

## はじめに

1. 初回起動時に **5 ページのウェルカム ガイド**を完了します (**[設定] → [ガイド]**でいつでも再度開きます)。
2. **ホーム**で、**学習の進捗状況**、**学習の継続**、**毎日の活動**を確認します。
3. **カテゴリ**を参照 — 人気のある関数、数学、統計、テキスト、ルックアップ、動的配列、ヒント、レッスン、クイズ、ショートカット。
4. 任意の項目を開いて、構文、パラメーター、例、手順、または Mac/Windows キー バインディングなどの豊富な詳細を表示します。
5. 内容を理解したら、項目を **マスター済み** としてマークします (単独で開くと、最近の件数と連続記録が増えるだけです)。
6. サンプルセルを使用して **数式プレイグラウンド** を試すか、**クイズ**に答えて説明を確認してください。
7. スターのお気に入り。オプションの **iCloud Sync** を有効にして、デバイス間で進行状況を維持します。
8. **ウィジェット**を追加したり、**ホーム画面のクイック アクション**を使用したり、**Siri**に機能を開いたりクイズを開始したりするように依頼してください。

## 特長

### 学習ライブラリ

| モジュール | カウント | ハイライト |
|--------|------:|------------|
| 機能 | 265 | 構文、パラメータ、例、注意事項、関連関数 |
| ヒント | 71 | 明確な手順を備えた実用的なスプレッドシートのワークフロー |
| レッスン | 44 | 基礎から上級までの構造化されたパス |
| クイズ | 23 | 説明付きの多肢選択式。保存されたベストスコア |
| ショートカット | 114 | Mac および Windows のキー バインディング (進行中はカウントされません) |

関数カテゴリには、ポピュラー、数学と三角関数、統計、テキスト、論理、検索と参照、日付と時刻、財務、情報、動的配列、エンジニアリング、データベースが含まれます。

### ホームと進捗状況

- **プログレスリング** — マスターしたアイテム ÷ 学習可能な合計 (ショートカットを除く)
- **学習を続ける** — 未読の最近の記事や次に人気のある機能をピックアップします
- **毎日の機能** — 暦日ごとに 1 つの注目の機能
- ホーム上の **最近** (最大 30) および **お気に入り** の概要
- **連続** — 学習コンテンツを開いた連続日数
- オプションの **お気に入り** タブと **カテゴリ** タブ (設定で切り替え)

### フォーミュラ プレイグラウンド

固定サンプル データ (完全な Excel エンジンではない) を使用した **軽量の練習用サーフェス**:

- `SUM`、`AVERAGE`、`MAX`、`MIN`、`IF`、および単純な `A1+A2+A3` パターンを試してください。
- プリセットボタンでサンプルを入力し、即座に評価します
- 他の数式は明確に「まだサポートされていない」状態を示しています

スプレッドシートの代わりとしてではなく、記憶を強化するために使用してください。

### 検索と詳細

- **名前、概要、タグ、または ID** で検索 (中国語と英語)
- **iOS 18+** 専用の検索タブ;クイック アクション、ディープ リンク、またはインテントを介した以前の iOS
- 関数ページ: 構文のコピー、関連関数へのジャンプ
- ヒント/レッスンページ：本体、ステップ、連携機能
- クイズの流れ：解答→公開→解説→ベストスコア+自動マスター

### ウィジェットとシステム統合

| 統合 | 得られるもの |
|-------------|--------------|
| **4 つのウィジェット** | 毎日の機能、進捗状況、お気に入り、クイズのエントリー |
| **ロック画面** | 毎日の機能と進捗アクセサリ (iOS) |
| **ホーム画面のクイックアクション** | ホーム、遊び場、クイズ、検索 |
| **スポットライト** | 全学習項目の索引 |
| **Siri / アプリのショートカット** | ホーム、プレイグラウンド、クイズ、または機能を名前で開きます |
| **`iexcel://` links** | [ショートカット リンク](url-scheme) を参照してください。 |

### プライバシー

- **アカウントなし、登録なし、広告なし、追跡なし**
- すべての学習コンテンツは **オフラインでバンドルされています**
- オプションの **iCloud Key-Value ストレージ** (お気に入り、進行状況、クイズのスコア、連続記録、および設定用) (デフォルトはオフ)
- Daily Function ID は **デバイスごと**のままです (同期されません)
- オプションのチップは **Apple StoreKit** 経由でのみ購入できます
