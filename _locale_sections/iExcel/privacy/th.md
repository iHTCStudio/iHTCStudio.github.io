iHTC Studio ("เรา", "พวกเรา" หรือ "ของเรา") ได้สร้าง iExcel (หรือที่รู้จักในชื่อ "爱表格" / "愛表格") หน้านี้แจ้งให้คุณทราบนโยบายของเราเกี่ยวกับการรวบรวม การใช้ และการเปิดเผยข้อมูลส่วนบุคคลเมื่อคุณใช้แอปของเรา

## สรุป

**iExcel ไม่จำเป็นต้องมีบัญชีและไม่รวบรวมข้อมูลส่วนบุคคลบนเซิร์ฟเวอร์ iHTC Studio** เนื้อหาการเรียนรู้ทั้งหมดรวมอยู่ในแอปและทำงานแบบออฟไลน์โดยสมบูรณ์ ตัวเลือก **iCloud Sync** จะจัดเก็บรายการโปรด ความคืบหน้า และการตั้งค่าไว้ใน **พื้นที่จัดเก็บคีย์-ค่า iCloud ของคุณ** ภายใต้ Apple ID ของคุณ **ไม่มีโฆษณา ไม่มีการติดตาม**

## การรวบรวมข้อมูล

เราไม่ได้ดำเนินการวิเคราะห์ การโฆษณา หรือการติดตาม โดยเฉพาะ:

- **ไม่มีข้อมูลส่วนบุคคล** ที่ถูกรวบรวมโดย iHTC Studio (ไม่มีชื่อ อีเมล หมายเลขโทรศัพท์ หรือบัญชี iHTC Studio)
- **ไม่มีการผสานรวมการวิเคราะห์การใช้งาน** หรือ SDK การรายงานข้อขัดข้อง
- **ข้อมูลการเรียนรู้ของคุณ** จะยังคงอยู่ในอุปกรณ์ของคุณ และหากคุณเปิดใช้งานการซิงค์ ก็จะอยู่ใน **Apple iCloud** — ไม่ใช่บนเซิร์ฟเวอร์ iHTC Studio
- **ไม่มีคุกกี้หรือเครื่องมือติดตามบุคคลที่สาม** ในแอป

## แอปทำงานอย่างไร

iExcel เก็บข้อมูลที่ผู้ใช้สร้างขึ้นไว้ในอุปกรณ์ของคุณ:

- เนื้อหาการเรียนรู้ทั้งหมด (ฟังก์ชัน เคล็ดลับ บทเรียน แบบทดสอบ ทางลัด) **รวมอยู่ภายในแอป** และไม่เคยดึงข้อมูลจากเซิร์ฟเวอร์เนื้อหาภายนอก
- ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ตเพื่อเรียกดู ค้นหา ฝึกฝน หรือทำแบบทดสอบ
- ตัวเลือก **การซิงค์ iCloud** จะใช้ **NSUbiquitousKeyValueStore** ของ Apple เมื่อคุณลงชื่อเข้าใช้ iCloud และเปิดใช้งานการซิงค์ทิ้งไว้ คุณสามารถปิดอุปกรณ์แต่ละเครื่องได้ในการตั้งค่า
- การเปิดลิงก์ภายนอก (เช่น อีเมลตอบรับ หน้า App Store) ใช้เครือข่ายระบบมาตรฐาน โหลดเพจได้โดยตรงจากโฮสต์ ไม่ใช่ผ่านเซิร์ฟเวอร์ iHTC Studio

## ข้อมูลที่จัดเก็บไว้ในอุปกรณ์ของคุณ

| ข้อมูล | วัตถุประสงค์ |
|------|---------|
| ห้องสมุดเนื้อหาการเรียนรู้ | รวมฟังก์ชัน เคล็ดลับ บทเรียน แบบทดสอบ ทางลัด |
| รายการโปรด | รายการที่คุณติดดาว |
| ล่าสุด | รายการที่ดูล่าสุด (สูงสุด 30) |
| รายการที่เชี่ยวชาญ | รายการที่คุณทำเครื่องหมายว่าเรียนรู้แล้ว เครื่องหมายอัตโนมัติของการตอบคำถามเสร็จสิ้น |
| แบบทดสอบคะแนนที่ดีที่สุด | คะแนนสูงสุดต่อแบบทดสอบ |
| แนวการเรียนรู้และวันที่เรียนรู้ครั้งล่าสุด | การติดตามวันติดต่อกัน |
| รหัสฟังก์ชันรายวันและวันที่ | ฟังก์ชั่นเด่นสำหรับวันตามปฏิทินปัจจุบัน |
| การตั้งค่า | ภาษา ลักษณะที่ปรากฏ การมองเห็นแท็บ ธีมวิดเจ็ต |
| สแนปชอตวิดเจ็ต | แชร์ผ่านกลุ่มแอพสำหรับวิดเจ็ตโฮม / ล็อคหน้าจอ |
| การเริ่มต้นใช้งานเสร็จสิ้น | ไม่ว่าจะเป็นคำแนะนำการต้อนรับที่เสร็จสิ้นแล้ว |

## iCloud ซิงค์ (ไม่จำเป็น)

เมื่อเปิดใช้งาน **iCloud Sync** และคุณลงชื่อเข้าใช้ iCloud:

- **ซิงค์แล้ว:** รายการโปรด ล่าสุด รายการที่เชี่ยวชาญ คะแนนแบบทดสอบ แนวการเรียนรู้ วันที่เรียนรู้ล่าสุด และการตั้งค่า (ภาษา ลักษณะที่ปรากฏ การมองเห็นแท็บหมวดหมู่/รายการโปรด วิดเจ็ตตามธีม แฟล็กการซิงค์)
- **ไม่ซิงค์:** การเลือกฟังก์ชันรายวัน (เลือกแยกกันในแต่ละอุปกรณ์)
- **พื้นที่จัดเก็บข้อมูล:** Apple **พื้นที่จัดเก็บข้อมูลคีย์-ค่า iCloud** ที่เชื่อมโยงกับ Apple ID ของคุณ
- **การเลือกไม่รับ:** ปิดใช้งานใน **การตั้งค่า → การซิงค์ iCloud** บนอุปกรณ์ใดๆ อุปกรณ์นั้นหยุดการอัปโหลดและการรวม แต่จะเก็บข้อมูลในเครื่องไว้
- iHTC Studio ไม่สามารถอ่านคอนเทนเนอร์ iCloud ของคุณได้

## กลุ่มแอป (ส่วนขยายวิดเจ็ต)

iExcel ใช้กลุ่มแอป (`group.com.iHTCboy.iExcel`) เพื่อแชร์สแน็ปช็อตขนาดเล็กพร้อมส่วนขยายวิดเจ็ต:

- ชื่อและบทสรุปที่แปลแล้วสำหรับฟังก์ชั่นรายวันและรายการโปรด
- นับความคืบหน้าและต่อเนื่องสำหรับวิดเจ็ตความคืบหน้า
- การแทนที่ลักษณะที่ปรากฏสำหรับวิดเจ็ต Chrome

ข้อมูลนี้เขียนลงในคอนเทนเนอร์ที่ใช้ร่วมกัน **บนอุปกรณ์ของคุณเท่านั้น** และจะไม่ส่งโดย iHTC Studio

## สิทธิ์

iExcel **ไม่**ต้องการการเข้าถึงกล้อง ไมโครโฟน ตำแหน่ง รายชื่อติดต่อ หรือไลบรารีรูปภาพสำหรับฟีเจอร์การเรียนรู้หลัก

## การซื้อในแอป

iExcel มี **คำแนะนำ/การสนับสนุนสำหรับนักพัฒนา** ให้เลือกซื้อ ธุรกรรมการชำระเงินทั้งหมดได้รับการจัดการโดย **เฟรมเวิร์ก StoreKit ของ Apple** iHTC Studio จะไม่รับ ประมวลผล หรือจัดเก็บข้อมูลบัตรชำระเงินหรือรายละเอียดการเรียกเก็บเงิน

## สิ่งที่ iExcel ไม่ใช่

iExcel เป็น **เครื่องมืออ้างอิงและแบบฝึกหัดการเรียนรู้** จะไม่เปิด แก้ไข หรือซิงค์สมุดงาน Excel ของคุณ Formula Playground ประเมินชุดรูปแบบที่จำกัดในข้อมูลตัวอย่างคงที่ และไม่ใช่กลไกสเปรดชีต Excel เป็นเครื่องหมายการค้าของ Microsoft; แอพนี้ไม่มีส่วนเกี่ยวข้องกับ Microsoft

## ความเป็นส่วนตัวของเด็ก

iExcel จะไม่เก็บรวบรวมข้อมูลส่วนบุคคลใดๆ จากใครก็ตาม รวมถึงเด็กอายุต่ำกว่า 13 ปี โดยเจตนา เนื่องจากเราไม่เก็บรวบรวมข้อมูลส่วนบุคคล จึงไม่จำเป็นต้องมีข้อกำหนดพิเศษใดๆ
