iHTC Studio (「私たち」、「私たち」、または「私たちの」) は、iExcel (「愛情表格」 / 「愛表格」とも呼ばれます) を構築しました。このページでは、お客様が当社のアプリを使用する際の個人データの収集、使用、開示に関する当社のポリシーをお知らせします。

## 概要

**iExcel does not require an account and does not collect personal data on iHTC Studio servers.** All learning content is bundled in the app and runs fully offline. Optional **iCloud Sync** stores favorites, progress, and preferences in **your** iCloud Key-Value Storage under your Apple ID. **No ads. No tracking.**

## データ収集

当社は分析、広告、追跡を行っておりません。具体的には:

- **個人情報**は iHTC Studio によって収集されません (名前、電子メール、電話番号、または iHTC Studio アカウントは収集されません)。
- **使用状況分析** やクラッシュレポート SDK は統合されていません。
- **学習データ**はデバイス上に残ります。また、同期を有効にしている場合は、iHTC Studio サーバーではなく **Apple iCloud** に残ります。
- **アプリには Cookie やサードパーティ トラッカーはありません**。

## アプリの仕組み

iExcel は、ユーザーが生成したデータをデバイス上にローカルに保存します。

- すべての学習コンテンツ (機能、ヒント、レッスン、クイズ、ショートカット) は **アプリ内にバンドル**されており、外部のコンテンツ サーバーから取得されることはありません。
- 閲覧、検索、練習、クイズの受験にはインターネット接続は必要ありません。
- オプションの **iCloud 同期**では、iCloud にサインインし、同期を有効にしたままにすると、Apple の **NSUbiquitousKeyValueStore** が使用されます。設定でデバイスごとにオフにすることができます。
- 外部リンク (フィードバック電子メール、App Store ページなど) を開くには、標準システム ネットワーキングが使用されます。ページは、iHTC Studio サーバーを介さずに、ホストから直接読み込まれます。

## デバイスに保存されているデータ

| データ | 目的 |
|------|---------|
| 学習コンテンツライブラリ | バンドルされた機能、ヒント、レッスン、クイズ、ショートカット |
| お気に入り | スターを付けたアイテム |
| 最近 | 最近見たアイテム (最大 30) |
| マスターアイテム | 学習済みとしてマークした項目。クイズ完了の自動マーク |
| クイズのベストスコア | クイズごとの最高得点 |
| 連続学習数と最終学習日 | 連続日の追跡 |
| 毎日の機能 ID と日付 | 現在の暦日の注目の機能 |
| 設定 | 言語、外観、タブの可視性、ウィジェットのテーマ |
| ウィジェットのスナップショット | ホーム/ロック画面ウィジェットのアプリグループ経由で共有 |
| オンボーディングの完了 | ウェルカムガイドが終了しているかどうか |

## iCloud同期（オプション）

**iCloud 同期**が有効で、iCloud にサインインしている場合:

- **同期済み:** お気に入り、最近の項目、マスター済みアイテム、クイズのスコア、連続学習数、最終学習日、および設定 (言語、外観、カテゴリ/お気に入りタブの可視性、ウィジェットはテーマに従う、同期フラグ)。
- **同期されていません:** 毎日の機能の選択 (各デバイスで個別に選択)。
- **ストレージ:** Apple **iCloud Key-Value ストレージ**、Apple ID に関連付けられています。
- **オプトアウト:** 任意のデバイスの **[設定] → [iCloud 同期]** で無効にします。そのデバイスはアップロードとマージを停止しますが、ローカル データは保持します。
- iHTC Studio は iCloud コンテナを読み取ることができません。

## アプリグループ（ウィジェット拡張機能）

iExcel は、アプリ グループ (`group.com.iHTCboy.iExcel`) を使用して、ウィジェット拡張機能と小さなスナップショットを共有します。

- 毎日の行事とお気に入りのローカライズされたタイトルと概要
- Progress ウィジェットの進捗数と連続数
- ウィジェット クロムの外観オーバーライド

このデータは **お使いのデバイスのみ**の共有コンテナに書き込まれ、iHTC Studio によって送信されることはありません。

## 権限

iExcel では、主要な学習機能にカメラ、マイク、位置情報、連絡先、写真ライブラリへのアクセスは**必要ありません**。

## アプリ内購入

iExcel には、オプションの **チップ/開発者サポート** の購入が含まれています。すべての支払いトランザクションは **Apple の StoreKit フレームワーク**によって独占的に処理されます。 iHTC Studio は、支払いカード情報や請求の詳細を受信、処理、保存しません。

## iExcel ではないもの

iExcel は **学習リファレンスおよび練習ツール**です。 Excel ワークブックを開いたり、編集したり、同期したりすることはありません。 Formula Playground は、固定サンプル データの限られたパターンのセットを評価するものであり、スプレッドシート エンジンではありません。 Excel は Microsoft の商標です。このアプリはマイクロソフトと提携していません。

## 子供のプライバシー

iExcel は、13 歳未満の子供を含むいかなる人物からも、故意に個人データを収集することはありません。個人データを収集しないため、特別な規定は必要ありません。
