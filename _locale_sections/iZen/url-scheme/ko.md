iZen 지원 ** `izen://` ** 단축키, 위젯, 제어 센터, Siri 및 홈 화면 작업에 대한 링크.

## 링크 형식


```
izen://{host}?{params}
```


## 핵심 항법

| URL | 열리는 화면 |
|-----|-------|
| `izen://home` | 홈 |
| `izen://browse` | 둘러보기 |
| `izen://browse/instant` | 즉시 회복 층 |
| `izen://browse/rebuild` | 매일 재건 층 |
| `izen://browse/root` | 뿌리 기복 층 |
| `izen://favorites` | 즐겨찾기 |
| `izen://settings` | 설정 |
| `izen://search` | 검색 |
| `izen://daily` | 매일 젠 |
| `izen://continue` | 마지막 세션 |

## 워크스테이션 및 도구

| URL | 열리는 화면 |
|-----|-------|
| `izen://breathe` | 호흡 책상 (옵션 `/id`) |
| `izen://sos` | SOS / 즉시 복구 팩 |
| `izen://soundscape` | Procedural Soundscape 믹서 |
| `izen://journal` | Mood 저널 |
| `izen://assessment` | 1분 스트레스 평가 |
| `izen://stats` | 복구 통계 |
| `izen://three-tasks` | 매일 3개의 작업 |
| `izen://cognitive` | Cognitive 구조 |
| `izen://help` | Crisis helpline 디렉토리 |

## 내용 깊은 링크

| URL | 열리는 화면 |
|-----|-------|
| `izen://practice/<id>` | 연습 |
| `izen://quote` or `izen://quote/<id>` | 견적 요청 |
| `izen://science/<id>` | 과학 기사 detail |

| URL | 열리는 화면 |

| `izen://usage-guide` | 사용 가이드 |
