iZen unterstützt ** `izen://` ** Links für Shortcuts, Widgets, Control Center, Siri und Home Screen Aktionen.

## Linkformat


```
izen://{host}?{params}
```


## Kernnavigation

| URL | Öffnet |
|-----|-------|
| `izen://home` | Startseite |
| `izen://browse` | Durchsuchen |
| `izen://browse/instant` | Sofortige Wiederherstellungsschicht |
| `izen://browse/rebuild` | Tägliche Wiederaufbauschicht |
| `izen://browse/root` | Wurzelreliefschicht |
| `izen://favorites` | Favoriten |
| `izen://settings` | Einstellungen |
| `izen://search` | Suche |
| `izen://daily` | Tägliches Zen |
| `izen://continue` | Letzte Sitzung fortsetzen |

## Arbeitsplätze und Werkzeuge

| URL | Öffnet |
|-----|-------|
| `izen://breathe` | Atemdesk (optional `/id`) |
| `izen://sos` | SOS / Instant Recovery Pack |
| `izen://soundscape` | Verfahrensweiser Klanglandschaftsmischer |
| `izen://journal` | Mood Journal |
| `izen://assessment` | 1-minütige Stressbeurteilung |
| `izen://stats` | Wiedereinziehungsstatistik |
| `izen://three-tasks` | Täglich drei Aufgaben |
| `izen://cognitive` | Kognitiver Reframe |
| `izen://help` | Krisenhilfeverzeichnis |

## Content Deep Links

| URL | Öffnet |
|-----|-------|
| `izen://practice/<id>` | Einzelheiten zur Praxis |
| `izen://quote` or `izen://quote/<id>` | Angebotsdetails |
| `izen://science/<id>` | Wissenschaftsartikel Details |
