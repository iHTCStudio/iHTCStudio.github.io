iZen は、ショートカット、ウィジェット、コントロールセンター、シリ、ホーム画面のアクションのリンクとして、**         ** をサポートしています。

## リンク形式


```
izen://{host}?{params}
```


## コアナビゲーション

| URL | 開く画面 |
|-----|-------|
| `izen://home` | ホーム |
| `izen://browse` | ブラウズ |
| `izen://browse/instant` | 即刻の回復層 |
| `izen://browse/rebuild` | 毎日の再建層 |
| `izen://browse/root` | ルートリリーフ層 |
| `izen://favorites` | お気に入り |
| `izen://settings` | 設定 |
| `izen://search` | 検索 |
| `izen://daily` | デイリー禅 |
| `izen://continue` | 最後のセッションを続けてください |

## ワークステーションとツール

| URL | 開く画面 |
|-----|-------|
| `izen://breathe` | 呼吸机(オプション `/id`) |
| `izen://sos` | SOS/即刻の回復パック |
| `izen://soundscape` | 先進的なサウンドスケープミキサー |
| `izen://journal` | ムードジャーナル |
| `izen://assessment` | 1分の応力評価 |
| `izen://stats` | 回復統計 |
| `izen://three-tasks` | 毎日3つのタスク |
| `izen://cognitive` | 認知リフレーム |
| `izen://help` | Crisisヘルプラインディレクトリ |

## コンテンツディープリンク

| URL | 開く画面 |
|-----|-------|
| `izen://practice/<id>` | 練習内容 |
| `izen://quote` or `izen://quote/<id>` | 引用の細部 |
| `izen://science/<id>` | 科学記事詳細 |

## ガイド&システム

| URL | 開く画面 |
|-----|-------|
| `izen://usage-guide` | 使い方ガイド |
| `izen://widget-guide` | ウィジェットガイド |
| `izen://shortcuts-guide` | ショートカットガイド |
| `izen://feature-guide` | 特徴ツアー |
| `izen://feedback` | フィードバックメール |
| `izen://in-app-review` | 率のプロンプト |

コールド/ワームの起動は、オンボーディングやライブラリが準備されるまで、深いリンクをバッファすることができます。
