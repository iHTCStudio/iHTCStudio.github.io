iZen, ** `izen://` ** Kısa kesimler, widgets, Control Center, Siri ve Home Ekran eylemleri için bağlantılar.

## Bağlantı biçimi


```
izen://{host}?{params}
```


## Core navigasyon

| URL | Açar |
|-----|-------|
| `izen://home` | Ana sayfa |
| `izen://browse` | Gözat |
| `izen://browse/instant` | Anında kurtarma katmanı |
| `izen://browse/rebuild` | Günlük yeniden inşa katmanı |
| `izen://browse/root` | Kök rahatlama katmanı |
| `izen://favorites` | Favoriler |
| `izen://settings` | Ayarlar |
| `izen://search` | Ara |
| `izen://daily` | Daily Zen |
| `izen://continue` | Son seansa devam et |

## Derin bağlantılar

| URL | Açar |
|-----|-------|
| `izen://practice/<id>` | Uygulama detayı |
| `izen://quote` or `izen://quote/<id>` | Alıntı detayı |
