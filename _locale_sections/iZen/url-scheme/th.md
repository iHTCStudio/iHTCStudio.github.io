iZen รองรับ} `izen://` BAR ลิงก์สําหรับทางลัด, วิดเจ็ต, ศูนย์ควบคุม, Siri และการกระทําหน้าจอส่วนตัว

## รูปแบบลิงก์


```
izen://{host}?{params}
```


## การนําทางแกนหลัก

| URL | เปิด |
|-----|-------|
| `izen://home` | หน้าแรก |
| `izen://browse` | เรียกดู |
| `izen://browse/instant` | เพิ่มเลเยอร์... |
| `izen://browse/rebuild` | สร้างเลเยอร์ใหม่ทุกวัน |
| `izen://browse/root` | เลเยอร์ถัดไป |
| `izen://favorites` | รายการโปรด |
| `izen://settings` | การตั้งค่า |
| `izen://search` | ค้นหา |
| `izen://daily` | เดลี เซน |
| `izen://continue` | ทําวาระการใช้งานล่าสุดต่อไป |

## พื้นที่ทํางานComment

| URL | เปิด |
|-----|-------|
| `izen://breathe` | โต๊ะหายใจ (เลือกตัวเลือก `/ id') |
| `izen://sos` | SOS / กลุ่มกู้ข้อมูลทันที |
| `izen://soundscape` | ตัวผสมเสียงแบบเต็มจอ |
| `izen://journal` | บันทึกประจําวัน% 1 |
| `izen://assessment` | การประเมินความเครียด 1 นาที |
| `izen://stats` | สถิติการฟื้นตัว |
| `izen://three-tasks` | วัน ละ สาม งาน |
| `izen://cognitive` | เฟรมของตัวจับภาพ |
| `izen://help` | ไดเร็กทอรีช่วยเหลือวิกฤต |

## เนื้อหาที่อยู่เชื่อมโยงแบบลึก

| URL | เปิด |
|-----|-------|
| `izen://practice/<id>` | รายละเอียดการฝึกซ้อม |
| `izen://quote` or `izen://quote/<id>` | รายละเอียดการอ้างถึง |
| `izen://science/<id>` | รายละเอียดบทความทางวิทยาศาสตร์ |

## ทิศทางของระบบ

| URL | เปิด |
|-----|-------|
| `izen://usage-guide` | คู่มือการใช้งาน |
| `izen://widget-guide` | คู่มือวิดเจ็ต |
| `izen://shortcuts-guide` | คู่มือทางลัด |
| `izen://feature-guide` | การเดินทัวร์แบบธรรมชาติ |
| `izen://feedback` | อีเมลข้อเสนอแนะ |
| `izen://in-app-review` | อัตโนมัติ |

การปล่อยน้ําเย็น/วาร์มอาจจะบัฟเฟอร์ลิงก์ลึก จนกว่าการเติมเสร็จหรือห้องสมุดพร้อม
