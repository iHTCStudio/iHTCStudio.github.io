iZen prend en charge les liens ** `izen://` ** pour les actions Raccourcis, widgets, Control Center, Siri et Home Screen.

## Format de lien


```
izen://{host}?{params}
```


## Navigation de base

| URL | Ouvre |
|-----|-------|
| `izen://home` | Accueil |
| `izen://browse` | Parcourir |
| `izen://browse/instant` | Couche de récupération instantanée |
| `izen://browse/rebuild` | Reconstruction quotidienne |
| `izen://browse/root` | Couche de relief racine |
| `izen://favorites` | Favoris |
| `izen://settings` | Réglages |
| `izen://search` | Recherche |
| `izen://daily` | Zen quotidien |
| `izen://continue` | Continuer la dernière session |

## Postes de travail & outils

| URL | Ouvre |
|-----|-------|
| `izen://breathe` | Bureau de respiration (optionnel `/id`) |
| `izen://sos` | SOS / pack de récupération instantanée |
| `izen://soundscape` | Mélangeur de paysage sonore |
| `izen://journal` | Revue d'humeur |
| `izen://assessment` | Évaluation de la contrainte d'une minute |
| `izen://stats` | Statistiques sur le recouvrement |
| `izen://three-tasks` | Trois tâches quotidiennes |
| `izen://cognitive` | Recadre cognitif |
| `izen://help` | Répertoire des lignes d'aide à la crise |

## Liens profonds

| URL | Ouvre |
|-----|-------|
| `izen://practice/<id>` | Détails pratiques |
| `izen://quote` or `izen://quote/<id>` | Détail du devis |
| `izen://science/<id>` | Article scientifique détail |

## Guides & système

| URL | Ouvre |
|-----|-------|
| `izen://usage-guide` | Guide d'utilisation |
| `izen://widget-guide` | Guide des widgets |
| `izen://shortcuts-guide` | Guide Raccourcis |
| `izen://feature-guide` | Visite principale |
| `izen://feedback` | E-mail de commentaires |
| `izen://in-app-review` | Taux |

Les lancements à froid ou à chaud peuvent tamponner les liens profonds jusqu'à ce que la bibliothèque soit prête.
