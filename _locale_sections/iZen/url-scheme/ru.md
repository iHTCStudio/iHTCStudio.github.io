iZen поддерживает ссылки ** `izen://` ** для ярлыков, виджетов, Центра управления, Siri и действий на домашнем экране.

## Формат ссылки


```
izen://{host}?{params}
```


## Основная навигация

| URL | Открывает |
|-----|-------|
| `izen://home` | Главная |
| `izen://browse` | Обзор |
| `izen://browse/instant` | Слой мгновенного восстановления |
| `izen://browse/rebuild` | Ежедневный ремонт |
| `izen://browse/root` | Корневой рельефный слой |
| `izen://favorites` | Избранное |
| `izen://settings` | Настройки |
| `izen://search` | Поиск |
| `izen://daily` | Daily Zen |
| `izen://continue` | Продолжение последней сессии |

## Рабочие станции и инструменты

| URL | Открывает |
|-----|-------|
| `izen://breathe` | Дыхательный стол (факультативно "/id") |
| `izen://sos` | SOS / мгновенный пакет восстановления |
| `izen://soundscape` | Процессуальный звуковой миксер |
| `izen://journal` | Журнал "Настроение" |
| `izen://assessment` | 1-минутная оценка стресса |
| `izen://stats` | Статистика восстановления |
| `izen://three-tasks` | Ежедневно три задачи |
| `izen://cognitive` | Когнитивный рефрейм |
| `izen://help` | Каталог кризисных справочников |

## Глубокие ссылки

| URL | Открывает |
|-----|-------|
| `izen://practice/<id>` | Подробнее о практике |
| `izen://quote` or `izen://quote/<id>` | Подробности цитаты |
| `izen://science/<id>` | Научная статья Подробнее |

## Руководство и система

| URL | Открывает |
|-----|-------|
| `izen://usage-guide` | Руководство по использованию |
| `izen://widget-guide` | Руководство по виджетам |
| `izen://shortcuts-guide` | Руководство по «Командам» |
| `izen://feature-guide` | Особенности тура |
| `izen://feedback` | Письмо с отзывом |
| `izen://in-app-review` | Быстрая ставка |

Холодные/теплые запуски могут буферизовать глубокие ссылки до тех пор, пока не закончится посадка или библиотека не будет готова.
