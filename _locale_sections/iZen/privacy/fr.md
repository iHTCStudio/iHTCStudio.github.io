iHTC Studio a développé iSongCi (爱宋词 / 愛宋詞).

## Résumé

**Aucune collecte de données par iHTC Studio.** Les fonctions essentielles marchent **sans envoyer vos données à iHTC Studio**. **Pas de compte, pas de pub, pas de SDK analytics.** Données **incluses sur l’appareil**. **Sync iCloud** optionnelle : **votre iCloud** uniquement.

## Données stockées sur votre appareil

| Données | Objectif |
|------|---------|
| Bibliothèque de contenu | Pratiques, citations, science, helplines |
| Favoris et listes Zen | Favoris et collections |
| Historique de session | Sessions respiration/outils |
| Journal, évaluations, trois tâches | Journaux structurés |
| Séries et stats | Tableau recovery et courbe |
| Préférences | Thème, accent, respiration, notifications, Live Activity, Spotlight |

## Réseau

Après installation, **pas d’internet requis au quotidien**. App Store, liens **web** de crise, e-mail, pourboire via **Apple**, **navigateur**, **mail** — pas de backend iHTC Studio.

Téléphone/SMS de crise via **téléphone système / Messages**.

## Synchronisation iCloud (optionnelle)

Avec iCloud, favoris, listes Zen, journaux peuvent sync via KVS. iHTC Studio ne lit pas votre conteneur iCloud.

## Autorisations

| Autorisation | Quand | Pourquoi |
|------------|------|-----|
| Notifications | Daily Zen / évaluation | Planification locale uniquement |
| iCloud | Sync facultative | Miroir de progression |
| Santé (pleine conscience) | Facultatif, désactivé par défaut | Écrire les minutes choisies |
| Photos (ajout) | Enregistrer cartes partagées | Images sur l’appareil |
| Spotlight | Facultatif, désactivé par défaut | Indexer sur l’appareil |

## Avertissement médical

iZen propose bien-être et annuaire de crise. **Pas** un dispositif médical ni urgence.
