iHTC Studio เป็นผู้พัฒนา iSongCi (爱宋词 / 愛宋詞)

## สรุป

**iHTC Studio ไม่เก็บข้อมูล** ฟีเจอร์หลักทำงาน**โดยไม่ส่งข้อมูลไป iHTC Studio** **ไม่มีบัญชี ไม่มีโฆษณา ไม่มี analytics SDK** ข้อมูลแนวปฏิบัติ คำคม วิทย์ และสายด่วน**อยู่ในเครื่อง** **iCloud Sync** เสริมใช้** iCloud ของคุณ**เท่านั้น

## ข้อมูลที่เก็บบนอุปกรณ์

| ข้อมูล | วัตถุประสงค์ |
|------|---------|
| คลังเนื้อหา | แนวปฏิบัติ คำคม วิทย์ helpline |
| รายการโปรด Zen | รายการติดดาวและคอลเลกชัน |
| ประวัติเซสชัน | บันทึกหายใจ/เซสชันเครื่องมือ |
| บันทึก การประเมิน สามงาน ความคิด | บันทึกที่มีโครงสร้าง |
| สตรีคและสถิติ | แดชบอร์ดฟื้นตัวและเส้นแรงดัน |
| การตั้งค่า | ธีม สี หายใจ แจ้งเตือน Live Activity Spotlight |

## เครือข่าย

หลังติดตั้ง **ใช้ประจำไม่ต้องใช้เน็ต** App Store ลิงก์วิกฤต **เว็บ** อีเมล ทิป ใช้ **Apple** **เบราว์เซอร์** **เมล** ไม่ใช่แบ็กเอนด์ iHTC Studio

โทร/SMS วิกฤตใช้ **โทรศัพท์ระบบ / Messages** เมื่อแตะลิงก์

## การซิงค์ iCloud (ไม่บังคับ)

เมื่อเปิด iCloud รายการโปรด/รายการ Zen/บันทึก อาจซิงค์ผ่าน KVS iHTC Studio อ่าน iCloud ของคุณไม่ได้

## สิทธิ์

| สิทธิ์ | เมื่อไหร่ | ทำไม |
|------------|------|-----|
| การแจ้งเตือน | Daily Zen / ประเมิน | กำหนดในเครื่องเท่านั้น |
| iCloud | ซิงค์เสริม | สะท้อนความคืบหน้า |
| Health (Mindfulness) | เสริม·ปิดตั้งต้น | บันทึกนาทีที่เลือก |
| รูปภาพ (เพิ่ม) | บันทึกการ์ดแชร์ | รูปบนเครื่องที่คุณเลือก |
| Spotlight | เสริม·ปิดตั้งต้น | จัดทำดัชนีบนเครื่อง |
