iHTC Studio が iSongCi(爱宋词 / 愛宋詞)を開発しました。

## 概要

**iHTC Studio によるデータ収集はありません。** コア機能は **iHTC Studio へデータを送らず**に動作します。**アカウント不要・広告なし・分析 SDK なし。** 実践、引用、科学、危機ホットラインのデータは**端末に同梱**されます。任意の **iCloud 同期**は**お客様の iCloud**のみを使用します。

## 端末に保存されるデータ

| データ | 目的 |
|------|---------|
| コンテンツライブラリ | 同梱の実践・引用・科学・危機ホットライン |
| お気に入りと禅リスト | 星付きとカスタムコレクション |
| セッション履歴 | 呼吸 / ツールセッション記録 |
| ジャーナル、評価、三タスク、認知記録 | 構造化ログ |
| 連続と統計 | 回復ダッシュボードと圧力曲線 |
| 設定 | テーマ、アクセント、呼吸、通知、Live Activity、Spotlight |

ネットワーク

インストール後、**日常利用にインternetは不要**です。App Store、危機**Web**リンク、メールフィードバック、任意チップは **Apple**・**ブラウザ**・**メールアプリ**経由で、iHTC Studio のコンテンツ用バックエンドではありません。

危機の電話/SMS はリンクタップ時に**システムの電話 / メッセージ**を使います。

## iCloud同期（オプション）

有効かつ iCloud サインイン時、お気に入り・禅リスト・ログ等は私有 KVS で同期される場合があります。iHTC Studio は iCloud コンテナを読めません。

## 権限

| 権限 | タイミング | 理由 |
|------------|------|-----|
| 通知 | Daily Zen / 評価リマインダー | ローカルスケジュールのみ |
| iCloud | 任意の同期 | 進捗をミラー |
| ヘルス（マインドフルネス） | 任意・既定オフ | 選択した分数を書き込み |
| 写真（追加） | 共有カードを保存 | 端末上の選択画像 |
| Spotlight | 任意・既定オフ | 端末上でコンテンツを索引 |

## 医療に関する免責事項

iZen はウェルネス・教育コンテンツと危機ディレクトリを提供します。**医療機器・セラピスト・緊急サービスではありません**。必要時は専門医療や地域の緊急サービスへ。
