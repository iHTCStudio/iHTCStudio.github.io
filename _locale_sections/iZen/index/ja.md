**あなたの心を本当の意味で再起動してください。**

 iZen (愛情禅) は、長期的な精神疲労のための **オフライン 3 層回復ツールボックス** であり、別の痩せた瞑想プレイヤーではありません。 **アカウントは必要ありません。** 消耗するものをカットし、回復するものを再構築し、**47 の実践**、**~500 の引用**、**17 の科学ブリーフ**、**マルチモードの呼吸デスク**、**プロシージャル サウンドスケープ ミキサー**、**1 分間のストレス評価**、**危機ヘルプライン**、**デイリー ゼン** を使用して根本的な負荷を軽減します。 **6 スタイルの共有カード** をエクスポートし、**ウィジェット**、オプションの **呼吸ライブ アクティビティ**、**Siri とショートカット**、およびオプションの **iCloud** を追加します。 **広告はありません。 追跡はありません。**

 **概要:** 即時回復、毎日の再構築、根の救済、47 の実践、約 500 の引用、17 の科学記事、呼吸 (4-7-8 / ボックス / 生理学的ため息…)、サウンドスケープ、ジャーナル、3 つのタスク、認知的再フレーム、統計、危機ディレクトリ、毎日の Zen、共有カード、ウィジェット、コントロール センター、`izen://`、EN / 简 / 繁。 

> 「押し通す」必要はありません。 ドレインを下げ、復元力を上げます - 一度に 1 呼吸ずつ。 

## はじめに (ステップバイステップ)

 ### 1. 最初の起動

1. [App Store](https://apps.apple.com/app/id6757993810) からインストールし、**iZen** を開きます。 
2. **7 ページのウェルカム ガイド** (ブランド → 3 つのレイヤー → 呼吸 → ツール → システム追加機能 → プライバシー) を完了します。 
3. いつでも再生できます: **[設定] → [ヘルプ] → [機能ガイド]**。 
4. アプリ内の**使用法 / ウィジェット / ショートカット** ガイドは、**設定 → ヘルプ** に表示されます。 

### 2. 自宅から始める

 1. [**ホーム**] タブを開きます。 
2. **Daily Zen** — 今日の引用を、オプションで振り返りを含めて読みます。 タップして詳細を開くか、カードを共有します。 
3. **回復ダッシュボード**: 連続記録、最近のセッション、評価の概要を確認します。 
4. クイックアクション: **呼吸** · **SOS** · **サウンドスケープ** · **最後のセッションを継続**。 
5. オプション: [設定] で **毎日の Zen 通知** を有効にします (ローカルのみ)。 

### 3. 3 つのレイヤーを参照します。 

1. **参照** を開きます (デフォルトでオン。設定で非表示にできます)。 
2. **インスタント リカバリ**、**毎日の再構築**、**ルート リリーフ**に加え、**引用**および**科学** (5 つのサブカテゴリ) を探索します。 
3. 最初の訪問では、レイヤー ガイド カードが表示されます (閉じることができます。メニューから再度開きます)。 
4. **リスト/グリッド/カード**を切り替えます。 フィルターセクション。 オープンな実践、引用、または科学の詳細。 
5. `izen://browse/instant` のようなディープリンクはレイヤーにジャンプします。

### 4. 呼吸する（呼吸机）

 1. ホーム、コントロール センター、ウィジェット、または `izen://breathe` から **Breathe** を開きます。 
2. モードを選択します: **4-7-8**、**ボックス**、**生理学的ため息**、共鳴など。 
3. ビジュアル テーマを選択します: **インクウォッシュ** または **ソフト グロー**。 orb or box pattern; オプションの 3 秒のカウントダウン。 
4. 呼吸フェーズに関するオプションの**音声ガイダンス** (オフにすることもできます)。 pre/post mood check; セッション途中で放棄する場合は確認が必要です。 auto-save on finish.
 5. プロシージャルオーディオ + ハプティクス。 オプションの **Zen モード** 最小限の UI。 オプションの **ライブ アクティビティ** と **HealthKit マインドフルネス時間** (どちらもデフォルトではオフ)。 

### 5. サウンドスケープ、日記、ツール

 1. **Soundscape**: シーン プリセットを備えたマルチトラック プロシージャル ミキサー — `izen://soundscape`。 
2. **ジャーナル**: 構造化された気分ログ — `izen://journal`。 
3. **1 分間の評価**: 睡眠 / タスク / 社会的消耗 → パーソナライズされた推奨事項 — `izen://assessment`。 
4. **3 つのタスク** ボードと、ルート層作業用の **認知再フレーム** エントリ。 
5. **統計**: ストリーク、圧力曲線、セッションの概要 — `izen://stats`。 

### 6. Crisis support

1. ホームには **ローカル リージョンのヘルプライン プレビュー** (ライブ API ではなく、バンドルされたデータから) が表示されます。 
2. 完全な **グローバル検索可能なディレクトリ** (利用可能な場合は電話、SMS、Web) を開きます。 
3. 医療上の免責事項: iZen は救急医療**ではありません**。 必要に応じて地元の緊急サービスに電話してください。 

### 7. お気に入り、検索、共有カード

 1. スターの実践と引用。 **Zen リスト** (カスタム コレクション) を構築します。 クリーンアップ時にお気に入りを**バッチ編集**します。 
2. 実践、引用、科学の全文を **検索** (iOS 18 以降専用の [検索] タブ)。 
3. **カードの共有**: 6 スタイル × 4 比率; オプションの「今日の反省」行。 写真に保存するか共有します。 

### 8. ウィジェット、Siri、プライバシー

 1. ウィジェットを追加します: **Daily Zen**、**Quick Breathe**、**Recovery Streak**、**SOS お気に入り**。 
2. コントロールセンター (iOS 18+): 呼吸、SOS、毎日、日記、評価、サウンドスケープ。 
3. **[設定] → [ショートカット]** でホーム画面のクイック アクションを構成します。 
4. オプションの **iCloud** によるお気に入り、ログ、評価、リスト、ストリークの同期。 **デフォルトではスポットライトはオフになっています。**

 ## ダウンロードする理由

- **単一のタイマーではなくシステム** — 現在、毎日、ルートの 3 つのレイヤーが実際の疲労の仕組みに一致します。 
- **本物のワークステーション** — パッシブオーディオループではなく、呼吸するデスク + プロシージャルなサウンドスケープ + 構造化されたツール。 
- **読むことができる証拠** — 証拠レベル、読書時間、および関連する実践を含む 17 の科学概要。 
- **監視なしの安全** — バンドルされた危機ディレクトリ。 アカウントも広告も分析 SDK もありません。 
- **重要な場合はネイティブ** — ウィジェット、ライブ アクティビティ、コントロール センター、Siri、ディープ リンク、オプションの iCloud。 

## 特徴

 ### 3層ライブラリ

 - **47** のガイド付き実践 · **~500** の引用 · **17** の科学記事 (5 カテゴリー)
 - レイヤーガイドカード · 参考文献を含む科学の詳細 · ステップを含む実践の詳細

 ### 呼吸と音

 - マルチモードフェーズ · インク/グローテーマ · オーブ/ボックスビジュアル
 - 3秒カウントダウン、ムードブックエンド、セッション自動保存、ライブアクティビティ、オプションのHealthKit
 - プロシージャルサウンドスケープミキサー、シーンプリセット、大量のオーディオダウンロードなし

 ### ツールと評価

 - 気分日記・毎日の3つのタスク・認知的リフレーミング
 - 1 分間のストレス プロファイル → 推奨される次のステップ
 - 回復統計、圧力曲線、ストリークの詳細

 ### デイリー禅とシェア

- 毎日の引用 + シャッフルナンス · ウィジェット同期 · ローカル通知
 - シェアカード：クラシック/インク/ミニマル/月/青磁/竹×4面

 ### 危機と安全

 - ホームで地域を意識したプレビュー · グローバル検索可能なヘルプライン カタログ
 - 医療上の明確な免責条項 · システム経由で電話/SMS/ウェブを開く

 ### システム統合

 - 4 つのウィジェット ファミリ · 6 つのコントロール センター コントロール · アプリ インテント · `izen://` ディープ リンク
 - 4 つの代替アイコン · 英語 / 简 / 繁 · オプションのスポットライト (デフォルトではオフ)
