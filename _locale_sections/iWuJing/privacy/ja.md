**最終更新日:** 2026年8月19日

iHTC Studio は **iWuJing**（「爱五经」／「愛五經」、Bundle ID `com.iHTCboy.iWuJing`）を開発しました。本アプリは儒教五経の**オフライン学習机**として動作します。**個人データを収集するバックエンドは運営していません**。

## 概要

- **アカウント:** 不要
- **当社によるデータ収集:** **データは収集しません**
- **主な利用:** インストール後はオフライン
- **広告 / 分析 / トラッキング:** なし
- **任意の Apple サービス:** iCloud KVS、写真ライブラリ（追加のみ）、StoreKit チップ、ローカル通知、Spotlight、Live Activity

## 端末に残るデータ

- お気に入りとリスト
- 閲読履歴と最後に読んだ位置
- 学習進捗、習熟、連続、メモ
- 外観、閲読、音声の設定
- Daily Classic キャッシュとウィジェット状態

これらは端末に留まり、同期を有効にした場合は**お客様の私有 iCloud**にのみ入ります。

## アプリの仕組み

- テキストライブラリ、白话、英語、注释、異文はアプリ同梱（公開 Web 資料より整理）。
- 朗誦は Apple システム TTS を使用します。
- ウィジェットは App Group `group.com.iHTCboy.iWuJing` で軽量状態を共有します。
- 通知はローカルでスケジュールされます。
- 共有カードは端末上で生成されます。
- 周易コンテンツは**古典研究のみ**で、占いではありません。

## 権限

| 権限 | タイミング | 理由 |
|------------|------|-----|
| 通知 | リマインダーを有効 | Daily Classic ローカルリマインダー |
| 写真ライブラリ（追加のみ） | 古典カードを保存 | 描画画像を保存 |
| iCloud | 同期を有効にする | お気に入り、リスト、進捗、メモを同期 |
| Live Activities | 閲読アクティビティを有効 | ロック画面 / Dynamic Island |

当社は、トラッキング、連絡先、位置情報を**要求しません**。
