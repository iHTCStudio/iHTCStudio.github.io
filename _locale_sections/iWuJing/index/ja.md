**1日1つのクラシック。 一生ものの 5 つの古典。**

 iWuJing (爱五经 / 愛五經) は、別のプレーン テキスト ダンプではなく、真剣に精読するための **オフラインの五古典学習机**です。 **アカウントは必要ありません。** *Shijing*、*Shujing*、*Liji*、*Yijing*、*Chunqiu with Zuo Tradition* のすべての **819** パッセージが、**バイリンガル読み物**、*母語**、**光沢**、**バリエーション**、没入型レイアウトとともにデバイスに搭載されています。 段落を強調表示して **暗唱**し、**古典学習**でトレーニングし、状況に合わせた**デイリー クラシック** ルーチンを維持し、**クラシック カード**をエクスポートし、**ウィジェット**、**コントロール センター**、**Siri**、**スポットライト**、オプションの**ライブ アクティビティの読み取り**、およびオプションの**iCloud**を使用します。 『周易』は **厳密に古典研究として紹介されており**、**占いや占いの機能はありません**。 テキストとメモは、公開されているオンライン ソースから厳選されています。 **広告はありません。 追跡はありません。 Data Not Collected.**

 ## はじめに

 ### 1. 最初の起動

1. [App Store](https://apps.apple.com/app/id6797013704) からインストールし、**iWuJing** を開きます。 
2. ウェルカム ガイドを完了します: ブランド → 精読 → 暗唱 → 学習 → デイリー クラシック → プライバシー。 
3. **[設定] → [ヘルプ] → [機能ガイド]**でいつでも再生できます。 
4. アプリ内の**使用法 / ウィジェット / ショートカット** ガイドは、**設定 → ヘルプ** に表示されます。 

### 2. ホームで今日の古典を読む

 1. [**ホーム**] タブを開きます。 
2. **デイリー クラシック** ヒーローが今日の一節を示します。 タップして詳細を開きます。 
3. オプション: 設定でローカル **デイリー クラシック通知**を有効にします。 
4. 続きを読み、有名なセリフを確認し、ホーム ショートカットから暗唱/学習/狩りにジャンプします。 

### 3. 参照と検索

 1. **参照**を開きます。 
2. コレクション、テーマ、有名なセリフ、作者ごとに 5 つの古典を探索します。 
3. **検索**を使用して、タイトル、本文、専門用語、および用語を検索します。 iOS では、オプションの **手書き検索** によりデバイス上の文字が認識されます。 
4. パッセージを **お気に入り**に保存し、個人用 **リスト** (经单) を作成し、学習や暗唱のためにリスト全体をバッチで開きます。 

### 4. バイリンガルの読書と古典的なカード

1. 詳細で、**バイリンガル/中国語のみ/英語のみ**を切り替えます。 
2. **ピンイン**、**各国語アンソロジー**、**英語**を個別に切り替えます。 
3. 没入型​​読書、セグメント化されたページ、ワイドスクリーン レイアウト、グロス ルックアップ、およびバリアント ノートを使用します。 
4. **クラシック カード**を開いて、共有可能な画像をエクスポートします。 

### 5. 暗唱と学習

 1. 詳細で [**朗読**] をタップするか、朗読ワークベンチを直接開きます。 
2. 聞きながら段落の強調表示に従ってください。 
3. [設定] で **[コンテンツの再生] マトリックス**を構成します。 
4. **古典学習**を暗唱、穴埋め、自己チェック、クイズ、および**ハント**に使用します。 

### 6. ウィジェット、Siri、システム統合

 1. **デイリークラシック/名セリフ/学習進捗/お気に入り**ウィジェットを追加します。 
2. 今日、ランダム、勉強、暗唱、お気に入り、検索には、**コントロール センター**、**Siri**、_`iwujing://` のディープ リンクを使用します。 
3. オプションの **Spotlight** インデックス作成は [設定] で使用できます。 
4. サポートされている iPhone デバイスでは、オプションの **ライブ アクティビティの読み取り** が表示されます。 

### 7. プライバシーと同期

1. 主要な読書、暗唱、学習、ウィジェット、通知は、インストール後**完全にオフライン**で機能します。 
2. オプションの **_iCloud 同期** は、**プライベート iCloud*** を通じてお気に入り、リスト、履歴、進行状況、連続記録、メモをミラーリングします。 
3. 開発者 (オプションの StoreKit) は、ペイウォールで保護されたコンテンツのロックを解除したり、アカウントを作成したりすることはありません。 

## 特徴

 - **5 つの古典にわたる 819 のパッセージ**
 - **現地語と英語による**バイリンガル精読**
 - **光沢とバリエーション**の検索
 - **朗読ワークベンチ** 再生コンテンツ マトリックス付き
 - マスタリーとハントによる **古典学習**
 - **デイリー クラシック**、ウィジェット、コントロール センター、Siri、スポットライト、ディープ リンク
 - **アカウントなし、広告なし、分析 SDK なし**
