**คลาสสิกหนึ่งครั้งต่อวัน ห้าคลาสสิกตลอดชีวิต** 

iWuJing (爱五经 / 愛五經) คือ **โต๊ะอ่านหนังสือ Five Classics แบบออฟไลน์** สำหรับการอ่านแบบละเอียดอย่างจริงจัง ไม่ใช่การถ่ายโอนข้อความธรรมดา **ไม่จำเป็นต้องมีบัญชี** ข้อความ **819** ทั้งหมดของ *Shijing*, *Shujing*, *Liji*, *Yijing* และ *Chunqiu with Zuo Tradition* จัดส่งบนอุปกรณ์ของคุณด้วย **การอ่านสองภาษา**, **ภาษาถิ่น**, **เงา**, **ตัวแปร** และรูปแบบที่สมจริง **ท่อง** โดยเน้นย่อย่อหน้า ฝึกฝน **การศึกษาแบบคลาสสิก** เก็บกิจวัตร **คลาสสิกรายวัน** ตามบริบท ส่งออก **การ์ดคลาสสิก** และใช้ **วิดเจ็ต** **ศูนย์ควบคุม** **Siri** **สปอตไลต์** ตัวเลือก **กิจกรรมการอ่านสด** และอาจเป็นทางเลือก **iCloud** Zhouyi นำเสนอ **ถือเป็นการศึกษาแบบคลาสสิกอย่างเคร่งครัด** โดยไม่มี **ไม่มีการทำนายหรือการทำนายดวงชะตา** ข้อความและบันทึกย่อได้รับการดูแลจัดการจากแหล่งข้อมูลออนไลน์ที่เปิดเผยต่อสาธารณะ ** ไม่มีโฆษณา ไม่มีการติดตาม Data Not Collected.** 

## เริ่มต้นใช้งาน 

### 1. เปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id6797013704) และเปิด **iWuJing** 
2. ทำตามคำแนะนำต้อนรับให้ครบถ้วน: แบรนด์ → อ่านอย่างใกล้ชิด → ท่อง → การศึกษา → Daily Classic → ความเป็นส่วนตัว 
3. เล่นซ้ำได้ทุกเมื่อใน **การตั้งค่า → ช่วยเหลือ → คู่มือคุณสมบัติ** 
4. คู่มือ **การใช้งาน / วิดเจ็ต / ทางลัด** ในแอปอยู่ภายใต้ **การตั้งค่า → ความช่วยเหลือ** 

### 2. อ่านคลาสสิกของวันนี้บนหน้าแรก 

1. เปิดแท็บ **หน้าแรก** 
2. ฮีโร่ **Daily Classic** จะแสดงเนื้อเรื่องของวันนี้ แตะเพื่อเปิดรายละเอียด 
3. ตัวเลือกเสริม: เปิดใช้งาน **การแจ้งเตือน Daily Classic** ในการตั้งค่า 
4. อ่านต่อ ดูบรรทัดที่โด่งดัง และข้ามไปท่อง / ศึกษา / ล่าจากทางลัดที่บ้าน 

### 3. เรียกดูและค้นหา 

1. เปิด **เรียกดู** 
2. สำรวจ Five Classics ตามคอลเลกชัน ธีม บทประพันธ์ที่มีชื่อเสียง และผู้แต่ง 
3. ใช้ **ค้นหา** สำหรับชื่อเรื่อง ข้อความเนื้อหา ภาษาพื้นถิ่น และคำเงา บน iOS ตัวเลือกเสริม **การค้นหาด้วยลายมือ** จะจดจำอักขระบนอุปกรณ์ 
4. บันทึกข้อความลงใน **รายการโปรด** สร้าง **รายการส่วนตัว** (经单) และเปิดรายการทั้งหมดเป็นกลุ่มเพื่อการศึกษาหรือท่องจำ 

### 4. การอ่านสองภาษาและการ์ดคลาสสิก

1. ในรายละเอียด ให้สลับระหว่าง **สองภาษา / จีนเท่านั้น / อังกฤษเท่านั้น** 
2. สลับ **พินอิน**, **กวีนิพนธ์พื้นถิ่น** และ **ภาษาอังกฤษ** ได้อย่างอิสระ 
3. ใช้การอ่านที่สมจริง การแบ่งหน้า เค้าโครงหน้าจอกว้าง การค้นหาแบบเงา และบันทึกย่อแบบต่างๆ 
4. เปิด **การ์ดคลาสสิก** เพื่อส่งออกรูปภาพที่แชร์ได้ 

### 5. ท่องและศึกษา 

1. แตะ **ท่อง** โดยละเอียด หรือเปิดโต๊ะบรรยายโดยตรง 
2. ทำตามการเน้นย่อหน้าขณะฟัง 
3. กำหนดค่า **เมทริกซ์เนื้อหาการเล่น** ในการตั้งค่า 
4. ใช้ **การศึกษาแบบคลาสสิก** เพื่อการท่องจำ เติมช่องว่าง ตรวจสอบตนเอง แบบทดสอบ และ **ตามล่า** 

### 6. วิดเจ็ต, Siri และการรวมระบบ 

1. เพิ่มวิดเจ็ต **คลาสสิกรายวัน / สายที่มีชื่อเสียง / ความคืบหน้าการศึกษา / รายการโปรด** 
2. ใช้ **ศูนย์ควบคุม**, **Siri** และ `iwujing://` ลิงก์เชิงลึกสำหรับวันนี้ สุ่ม ศึกษา ท่อง รายการโปรด และค้นหา 
3. ตัวเลือกเสริม **สปอตไลท์** มีอยู่ในการตั้งค่า 
4. ตัวเลือก **กิจกรรมการอ่านสด** จะปรากฏบนอุปกรณ์ iPhone ที่รองรับ 

### 7. ความเป็นส่วนตัวและการซิงค์

1. การอ่านหลัก ท่อง ศึกษา วิดเจ็ต และการแจ้งเตือนทำงาน **ออฟไลน์โดยสมบูรณ์** หลังการติดตั้ง 
2. ตัวเลือก **iCloud Sync** จะสะท้อนรายการโปรด รายการ ประวัติ ความคืบหน้า ความคืบหน้า และบันทึกย่อผ่าน **iCloud** ส่วนตัวของคุณ 
3. เคล็ดลับนักพัฒนา (อุปกรณ์เสริม StoreKit) จะไม่ปลดล็อกเนื้อหาเพย์วอลล์และไม่เคยสร้างบัญชี 

## คุณสมบัติ 

- **819 ข้อความ** ใน Five Classics 
- **การอ่านแบบปิดสองภาษา** พร้อมภาษาพื้นถิ่นและภาษาอังกฤษ 
- **ความเงาและตัวแปร** การค้นหา 
- **โต๊ะบรรยาย** พร้อมเมทริกซ์เนื้อหาการเล่น 
- **การศึกษาแบบคลาสสิก** ด้วยความชำนาญและการล่า 
- **Daily Classic**, วิดเจ็ต, ศูนย์ควบคุม, Siri, Spotlight และลิงก์ในรายละเอียด 
- **ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK การวิเคราะห์**
