**하루에 클래식 한 곡. 평생 동안 5가지 클래식.** 

iWuJing(爱五经 / 愛五經)은 일반 텍스트 덤프가 아닌 진지하게 자세히 읽을 수 있는 **오프라인 오경 학습 책상**입니다. **계정이 필요하지 않습니다.** *Shujing*, *Shujing*, *Liji*, *Yijing* 및 *Chunqiu with Zuo Tradition*의 모든 **819** 구절은 **이중 언어 읽기**, **현지어**, **광택**, **변형** 및 몰입형 레이아웃과 함께 장치에 제공됩니다. **문단 강조 표시로 **암송**, **클래식 학습** 훈련, 상황에 맞는 **데일리 클래식** 루틴 유지, **클래식 카드** 내보내기, **위젯**, **제어 센터**, **Siri**, **스포트라이트**, 옵션 **라이브 활동 읽기** 및 옵션 **iCloud** 사용. Zhouyi는 **점술이나 운세 기능** 없이 **엄격히 고전 연구**로 제공됩니다. 텍스트와 메모는 공개적으로 사용 가능한 온라인 소스에서 선별됩니다. **광고가 없습니다. 추적이 없습니다. Data Not Collected.** 

## 시작하기 

### 1. 첫 실행

1. [App Store](https://apps.apple.com/app/id6797013704)에서 설치하고 **iWuJing**을 엽니다. 
2. 환영 가이드를 완성하세요: 브랜드 → 정독 → 암송 → 공부 → 데일리 클래식 → 개인 정보 보호. 
3. **설정 → 도움말 → 기능 안내**에서 언제든지 재생해 보세요. 
4. 인앱 **사용법/위젯/바로가기** 가이드는 **설정 → 도움말**에 있습니다. 

### 2. 홈에서 오늘의 고전 읽기 

1. **홈** 탭을 엽니다. 
2. **Daily Classic** 영웅이 오늘의 본문을 보여줍니다. 세부정보를 열려면 탭하세요. 
3. 선택 사항: 설정에서 로컬 **Daily Classic 알림**을 활성화합니다. 
4. 홈 바로가기에서 계속해서 읽고, 명대사를 보고, 암송/공부/사냥으로 점프하세요. 

### 3. 탐색 및 검색 

1. **찾아보기**를 엽니다. 
2. 5대 고전을 모음집, 주제, 명대사, 작가별로 살펴보세요. 
3. 제목, 본문, 모국어, 용어에 대한 **검색**을 이용하세요. _iOS에서는 선택적 **필기 검색**이 장치의 문자를 인식합니다. 
4. **즐겨찾기**에 구절을 저장하고, 개인 **목록**(经单)을 만들고, 학습이나 암송을 위해 전체 목록을 일괄 오픈합니다. 

### 4. 이중 언어 읽기 및 클래식 카드

1. 세부사항에서 **이중언어 / 중국어만 / 영어만** 전환하세요. 
2. **병음**, **토착어 선집**, **영어**를 독립적으로 전환합니다. 
3. 몰입형 읽기, 분할된 페이지, 와이드스크린 레이아웃, 글로시 조회 및 변형 메모를 사용하세요. 
4. 공유 가능한 이미지를 내보내려면 **Classic Card**를 엽니다. 

### 5. 암송하고 공부하세요 

1. 세부사항에서 **암송**을 누르거나, 암송 워크벤치를 직접 엽니다. 
2. 들으면서 단락 강조를 따라가세요. 
3. 설정에서 **재생 콘텐츠 매트릭스**를 구성합니다. 
4. 암송, 빈칸 채우기, 자가 점검, 퀴즈, **사냥**에는 **고전 공부**를 사용하세요. 

### 6. 위젯, Siri 및 시스템 통합 

1. **데일리클래식 / 명대사 / 공부진행 / 즐겨찾기** 위젯을 추가합니다. 
2. 오늘, 랜덤, 공부, 암송, 즐겨찾기, 검색에 **제어 센터**, **Siri** 및 `iwujing://` 딥링크를 사용하세요. 
3. 설정에서 선택적으로 **스포트라이트** 색인 생성을 사용할 수 있습니다. 
4. 선택 사항인 **실시간 활동 읽기**는 지원되는 iPhone 장치에 나타납니다. 

### 7. 개인정보 보호 및 동기화

1. 핵심 읽기, 암송, 학습, 위젯 및 알림은 설치 후 **완전히 오프라인**으로 작동합니다. 
2. 옵션 **iCloud 동기화**는 **비공개 iCloud**를 통해 즐겨찾기, 목록, 기록, 진행 상황, 연속 기록 및 메모를 미러링합니다. 
3. 개발자(StoreKit 옵션)는 페이월 콘텐츠를 잠금 해제하거나 계정을 생성하지 않는다는 점을 알려주세요.
