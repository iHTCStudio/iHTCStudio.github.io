** วิทยานิพนธ์หนึ่ง สํานวนหนึ่ง – ค้นพบการดูแลและความไม่ก้าวร้าวอีกครั้ง**

iMoZi (อ้ายโม่จื่อ / อ้ายโม่จื่อ) เป็นสตูดิโอ Mozi ออฟไลน์**—ไม่ใช่ถังขยะข้อความธรรมดาอื่น** ไม่จําเป็นต้องมีบัญชี** ไลบรารี *Mozi* มาพร้อมกับอุปกรณ์ของคุณด้วย **ภาษาต้นฉบับ / ภาษาท้องถิ่น / ภาษาอังกฤษ (พฤษภาคม 1929 หากมี)** เริ่มต้นด้วย **Mo ของวันนี้** **ท่อง** ด้วยการไฮไลท์ย่อหน้า** ฝึกใน **Mohism Study** เล่น **Sentence Hunt** ส่งออก **การ์ดหมึก** เพิ่ม **วิดเจ็ต**, ตัวเลือก **การอ่านกิจกรรมสด**, **Siri & คําสั่งลัด** และตัวเลือก **iCloud** ตัวเลือก **ถาม Mozi** ใช้ Apple on-device Intelligence หากมี ต้นฉบับเป็นข้อความการศึกษาโดเมนสาธารณะ; โน้ตเป็นเครื่องมือช่วยการศึกษา** ไม่มีโฆษณา ไม่มีการติดตาม Data Not Collected**

## การเริ่มต้น (ทีละขั้นตอน)

### 1. การเปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store] (https://apps.apple.com/app/id1240858394) และเปิด **iMoZi**
2. เสร็จสิ้นคู่มือต้อนรับ (การอ่านประจําวัน → การอ่านปิด → การท่อง → การศึกษา → คุณสมบัติของระบบ → ความเป็นส่วนตัว)
3. เล่นซ้ําได้ทุกเมื่อ: **การตั้งค่า → วิธีใช้ → คู่มือคุณสมบัติ** (`imozi://feature-guide`)
4. คู่มือการใช้งาน / วิดเจ็ต / คําสั่งลัดอยู่ภายใต้ **การตั้งค่า → วิธีใช้**

### 2. อ่านส่วนของวันนี้บน Home

1. เปิดแท็บ **Home**
2. วีรบุรุษ Mo** ของ **วันนี้แสดงบทของวันนี้ แตะเพื่อเปิดรายละเอียด
3. ไม่บังคับ: เปิดใช้งานการแจ้งเตือน Mo ในท้องถิ่นของ **Today** ในการตั้งค่า
4. กระโดดจาก Home ไปยัง Recitation, Mohism Study, Sentence Hunt, Favorites และ Search

### 3. เรียกดูและค้นหา

1. เรียกดู *Mozi* corpus ทั้งหมด, บรรทัดที่มีชื่อเสียง และชั้นวางพิเศษ
2. ค้นหาชื่อเรื่องและบรรทัด (ง่ายขึ้น / สะดวกแบบดั้งเดิม) บน iOS การค้นหาลายมือเขียน** ทางเลือก** จะจดจําอักขระบนอุปกรณ์
3. ติดดาวส่วนต่างๆ ลงใน **รายการโปรด** และรวบรวมลงใน **รายการกระดาษหมึกส่วนบุคคล**

### 4. ปิดการอ่านและการแชร์การ์ด

1. สลับ **สองภาษา / เฉพาะภาษาจีน / เฉพาะภาษาอังกฤษ**; สลับเลเยอร์อย่างอิสระเมื่อมี
2. ลองใช้การอ่านแบบดื่มด่ํา เค้าโครงแนวตั้ง ขนาดแบบอักษร และหน้าแบบแบ่งส่วนสําหรับส่วนที่ยาวขึ้น
2. ไม่บังคับ **ถาม Mozi**: `imozi://ask` — บนอุปกรณ์ Apple Intelligence หากมี; กลับไปใช้โน้ตแบบรวมกลุ่ม
3. เปิด **การ์ดหมึก** → เลือกสไตล์ / อัตราส่วน → บันทึกไปยังรูปภาพ (เพิ่มเท่านั้น) หรือการแชร์ระบบ

### 5. การท่องและศึกษามุฮิม

1. เปิดเวิร์กเบนช์การท่องเพื่อค้นหา TTS ที่ไฮไลท์ไว้ เสียงและจังหวะที่ปรับได้ คําบรรยายภาษาท้องถิ่น/ภาษาอังกฤษแบบไม่บังคับ การเล่นต่อเนื่อง และเสียงพื้นหลัง
2. **Mohism Study** (`imozi://study`): การจาง, การเติมว่าง, การตรวจสอบตัวเอง และแบบทดสอบ พร้อมการติดตามความเชี่ยวชาญ
3. **Sentence Hunt** on Home เป็นเกมค้นหาข้อความแยกต่างหาก

### 6. วิดเจ็ต, Siri และคุณสมบัติของระบบ

1. เพิ่มวิดเจ็ต Daily / Famous Line / Favorites / Study Progress (และ Almanac หากมี)
2. ใช้ศูนย์ควบคุม, Siri, Spotlight และลิงก์ลึก `imozi://`
3. กิจกรรมการอ่านสดแบบไม่บังคับยังคงมีให้ใช้งานบนอุปกรณ์ที่รองรับ iPhone

### 7. ความเป็นส่วนตัวและการซิงค์

1. คลัง, การอ่าน, การท่อง (ระบบ TTS), การศึกษา, วิดเจ็ต และการแจ้งเตือนในเครื่องจะทํางานแบบออฟไลน์อย่างสมบูรณ์หลังจากติดตั้ง
2. ตัวเลือก**iCloud Sync** สะท้อนรายการโปรด รายการ ประวัติ ความคืบหน้า เส้น และโน้ตผ่าน**iCloud**ส่วนตัวของคุณ
3. เคล็ดลับสําหรับนักพัฒนา (ไม่บังคับ StoreKit) ไม่ควรปลดล็อค Paywall และไม่ควรสร้างบัญชี
