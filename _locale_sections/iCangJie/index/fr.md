**iCangJie** est un outil complet d'apprentissage de la **méthode de saisie Cangjie** et de recherche de caractères pour **iPhone, iPad et Mac**. Avec une bibliothèque soignée de **plus de 27 000 caractères han** couvrant les standards Cangjie 3e et 5e génération, la décomposition en racines, un **entraînement à la saisie** en code complet/rapide/mixte, un **quiz quotidien** en cartes, 11 tutoriels HTML, la recherche par pinyin et jyutping, des outils de conversion, **8 widgets** et une **synchronisation iCloud** facultative, c'est le compagnon tout-en-un pour maîtriser Cangjie — **hors ligne d'abord, respectueux de la vie privée, sans SDK tiers.**

Conçu en SwiftUI pur.

## Pourquoi iCangJie ?

La plupart des apps de dictionnaire s'arrêtent à des codes froids. iCangJie est conçu pour **les apprenants qui tapent vraiment** :

- Voyez **pourquoi** un code est construit ainsi — surlignage des racines et bandes de clavier sur chaque page de détail.
- **Entraînez-vous** avec trois modes de saisie, 16 textes classiques (simplifié et traditionnel) et la reprise depuis le carnet d'erreurs.
- **Testez-vous** avec un **quiz quotidien configurable** (5–15 questions, source de mots et longueur de code personnalisées).
- **Suivez vos progrès** avec des rapports de saisie sur 7/30 jours et une sauvegarde JSON de vos données d'apprentissage.
- **Gardez un œil** sur l'écran d'accueil, l'écran verrouillé ou le mode Veille avec 8 widgets conçus à cet effet.
- Demandez à **Siri** de rechercher un code Cangjie ou de lancer le quiz du jour ; indexez vos favoris dans **Spotlight**.
- Passez toute l'app en **anglais, chinois simplifié ou chinois traditionnel** — l'interface se met à jour instantanément.

## Premiers pas

1. Parcourez la **prise en main en 5 écrans** au premier lancement (ou ignorez-la à tout moment). Suivez la carte **Parcours débutant** dans **Apprendre** pour des liens rapides.
2. Ouvrez **Recherche** et cherchez par code Cangjie, caractère, préfixe de pinyin ou jyutping — ou touchez la **carte d'invite de recherche** sur l'écran de repos. Sur iOS, l'**OCR d'écriture manuscrite** peut remplir le champ de recherche sur les pages Recherche et Codes simples.
3. Parcourez **Niveaux** par longueur de code (1–5) ou par groupes de méthode rapide ; mélangez pour un entraînement aléatoire.
4. Allez dans **Apprendre** pour les tutoriels HTML et les tableaux de racines zoomables par pincement (taille de lecture réglable).
5. Essayez **Saisie** — choisissez le mode code complet, code rapide ou mixte ; ouvrez le **Rapport d'entraînement** pour les tendances.
6. Faites le **quiz quotidien** — personnalisez les questions dans les réglages du quiz. Revoyez vos erreurs dans le carnet d'erreurs.
7. Ajoutez des **widgets** à votre écran d'accueil ou à l'écran verrouillé. Configurez jusqu'à **4 actions rapides de l'écran d'accueil** et l'**indexation Spotlight** facultative dans les Réglages.

## Fonctionnalités

### Dictionnaire et recherche

- **Plus de 27 000 caractères sélectionnés** — Cangjie 3e et 5e génération ; JSON hors ligne intégré, nettoyé pour ne garder que des caractères han affichables.
- **Quatre priorités de jeu de caractères** — Hong Kong, chinois traditionnel de Taïwan, simplifié et général — influencent le classement de la recherche.
- **Quatre modes de recherche** — préfixe de code Cangjie, caractère exact, préfixe de pinyin et préfixe de jyutping ; indices intelligents lorsqu'un mode ne renvoie aucun résultat.
- **OCR d'écriture manuscrite (iOS)** — dessinez un caractère dans Recherche / Codes simples pour remplir la recherche en local (Vision sur l'appareil).
- **Cartes de l'écran d'accueil** — favoris, consultations récentes et raccourcis rapides par longueur de code (activables).
- **Détail du mot** — grande tuile de caractère, badges de code colorés, bandes de clavier de racines par code ; **comparaison 3e/5e génération côte à côte** pour les caractères isolés ; **copie en un geste** du caractère ou des codes ; statut d'apprentissage, favoris, **recherche en ligne Youdao** et **partage en image longue**.

### Niveaux (longueur de code)

- Parcourez toute la table par **3e / 5e génération** × **longueur de code 1–5** ou par groupes de **méthode rapide**.
- Disposition en **liste ou grille** avec nombre de colonnes adapté à l'appareil ; tirez pour **mélanger**.

### Entraînement à la saisie

- **Trois modes** — Code complet, code rapide (niveaux 1–2) et mixte (code rapide d'abord, puis code complet après une erreur).
- **Sources de contenu** — 16 textes classiques intégrés (JSON simplifié/traditionnel), listes de mots aléatoires, texte collé, favoris et reprise depuis le carnet d'erreurs (résout automatiquement le bon caractère han).
- **Mise en évidence des touches de racine** en direct ; pinyin du texte facultatif ; clavier virtuel avec préférence **conserver ou effacer** pour les touches erronées.
- Les statistiques de session (précision, série) et les **agrégats quotidiens** (jusqu'à 120 jours) se synchronisent via iCloud lorsqu'elle est activée.
- **Rapport d'entraînement** — graphique de tendance de saisie sur 7/30 jours et répartition des longueurs de code ; à ouvrir depuis le hub Saisie ou Réglages → Statistiques d'apprentissage.

### Quiz quotidien et carnet d'erreurs

- **Quiz configurable** — 5 / 8 / 10 / 15 questions par jour ; source de mots : dictionnaire, favoris ou carnet d'erreurs ; filtre de longueur de code 1–5 ; types de questions activables.
- Trois types : caractère→code, code→caractère (avec bande de clavier) et caractère→première touche de racine.
- Interface en cartes avec retour immédiat et **révision des erreurs** en fin de manche. **Remélanger** pour un nouvel ensemble. L'icône d'engrenage ouvre les **Réglages du quiz**.

### Apprendre (tutoriels et prise en main)

- **Prise en main en 5 écrans** au premier lancement (relançable à tout moment depuis **Réglages → Réglages de l'app**) ; carte **Parcours débutant** dans l'onglet Apprendre (recherche, quiz, premier tutoriel, guide des widgets).
- **11 leçons HTML** + **images de tableaux de racines** regroupées dans le hub Apprendre.
- **Taille de lecture réglable** (85 %–160 %) ; le HTML s'adapte au mode clair/sombre ; écriture traditionnelle lorsque la langue de l'app est zh-Hant.
- Tableaux zoomables par pincement ; **galerie par balayage** entre les images à un zoom de 1× ; **enregistrement dans Photos** ou partage (iOS).

### Outils (Réglages)

- **Convertisseur de pinyin et de Cangjie** — Plusieurs styles de sortie (avec tons, simple, numéroté, annoté, grille alignée) ; codes Cangjie facultatifs ; copie ou **partage d'une image d'aperçu**.
- **Terrain de jeu de synthèse vocale** — Lecture, pause et arrêt.
- **Guide des widgets** — Catalogue complet avec les étapes pour l'écran verrouillé et FAQ (iOS).
- **Actions rapides de l'écran d'accueil** — Choisissez jusqu'à 4 parmi 7 options (recherche, quiz, favoris, erreurs, niveaux, avis, notation).
- **Indexation Spotlight** (iOS) — Affiche les favoris et les récents dans la recherche du système (à activer dans les Réglages).
- **Siri et Raccourcis** — App Intents intégrés : rechercher un code Cangjie, lancer le quiz quotidien, ouvrir la recherche, la saisie, les favoris, le carnet d'erreurs, et plus.
- **Icônes d'app alternatives** (iOS) — Huit styles bicolores « 倉 », dont celui par défaut.
- **Sauvegarde et restauration JSON** — Exportez/importez les données d'apprentissage (fusion ou remplacement) depuis Réglages → Statistiques d'apprentissage.
- **Erreurs de frappe** — Les caractères mal tapés entrent dans le carnet d'erreurs pour une reprise immédiate ou ultérieure.

### Personnalisation

- **15 thèmes dégradés prédéfinis** + couleur d'accent personnalisée ; apparence claire / sombre / système.
- **La grille de tuiles suit le thème** — Les tuiles de caractères en vue liste/grille utilisent votre couleur d'accent.
- **Langue de l'app** — Anglais, chinois simplifié, chinois traditionnel ou suivre le système ; les widgets reflètent la langue via l'App Group.
- Préférences de disposition liste/grille ; commutateur de superposition du pinyin ; version Cangjie et jeu de caractères par défaut.

### iOS et iPad

- **8 types de widgets** — Daily Character, Code Length, Daily Quiz, Typing Glance, Favorites, Wrong Book, Recent, Learning Progress. Écran d'accueil, écran verrouillé et mode Veille.
- **Bouton de mélange** de Daily Character en petit et moyen (iOS 17+). Widget Code Length : choisissez **1–5** à l'ajout ; **bouton de mélange** en petit et moyen pour rafraîchir le trio (iOS 17+).
- Les widgets Favorites / Wrong / Recent affichent des aperçus en grille « champ de riz » **2×3 (petit) / 3×3 (moyen)** avec les codes.

### macOS

- App Mac native avec barre de navigation transparente, retour par **Échap**, feuille de partage système et entraînement complet à la saisie.
- Recherche intégrée à la barre de recherche du système ; feuille Safari flottante pour les liens externes des tutoriels.

### Confidentialité

- **Cœur hors ligne** — Le dictionnaire, les quiz, les tutoriels et la saisie fonctionnent sans réseau.
- **Sans publicité · Sans suivi** — Aucun SDK d'analyse. iCloud facultatif n'utilise que le KVS d'Apple.
- L'accès à la photothèque n'est demandé **que lorsque vous choisissez d'enregistrer une image de tableau de racines** (ajout uniquement).

## Widgets

iCangJie propose **8 types de widgets** pour l'écran d'accueil, l'écran verrouillé et le mode Veille. Consultez le **Guide des widgets** dans l'app (Réglages → Outils) pour la configuration pas à pas, un catalogue visuel et une FAQ.

| Widget | Ce qu'il affiche | Un toucher ouvre |
|--------|---------------|-----------|
| Daily Character | Caractère aléatoire + code ; mélange en petit et moyen | Détail du mot |
| Code Length | 3 caractères de la longueur choisie (1–5) ; mélange en petit et moyen | Niveaux |
| Daily Quiz | Score du jour + série | Quiz |
| Typing Glance | Total saisi + précision | Saisie |
| Favorites | Aperçu en grille « champ de riz » + nombre | Favoris |
| Wrong Book | Grille des erreurs récentes | Carnet d'erreurs |
| Recent | Caractères récemment consultés | Recherche |
| Learning Progress | Nombre de caractères maîtrisés / appris / en cours | Apprendre |

L'accent du widget suit le thème de votre app (fond neutre facultatif dans les Réglages).

## Liens profonds et actions rapides

Chemins pris en charge pour `iCangJie://` : `search`, `word`, `quiz`, `typing`, `favorites`, `wrong`, `levels`, `learn`, `feedback`, `review`.

Les **phrases Siri** intégrées et les **App Intents de Raccourcis** ouvrent aussi la recherche, le détail d'un mot et le quiz. Consultez la [référence du schéma d'URL](url-scheme) pour les paramètres, les App Intents et des exemples de Raccourcis.

Les données du dictionnaire Cangjie sont créditées dans l'app et proviennent de projets de dictionnaires communautaires (voir la page À propos dans l'app pour l'attribution complète). Les textes de saisie sont des textes chinois classiques du domaine public.
