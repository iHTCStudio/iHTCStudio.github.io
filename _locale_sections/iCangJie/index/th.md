**iCangJie** เป็นเครื่องมือเรียน **วิธีป้อนฉางเจี๋ย (Cangjie)** และค้นหาตัวอักษรแบบครบวงจรสำหรับ **iPhone, iPad และ Mac** ด้วยคลังอักษรฮั่นที่คัดสรรกว่า **27,000 ตัว** ครอบคลุมมาตรฐานฉางเจี๋ยรุ่นที่ 3 และ 5 การแยกราก **การฝึกพิมพ์** แบบรหัสเต็ม/ซู่เฉิง/ผสม **แบบทดสอบประจำวัน** แบบการ์ด บทเรียน HTML 11 บท การค้นหาด้วยพินอินและจู๊ดผิง เครื่องมือแปลง **วิดเจ็ต 8 แบบ** และ **การซิงค์ iCloud** แบบเลือกได้ จึงเป็นเพื่อนครบเครื่องสำหรับการเรียนฉางเจี๋ยให้เชี่ยวชาญ — **เน้นออฟไลน์ เคารพความเป็นส่วนตัว ไม่มี SDK ของบุคคลที่สาม**

สร้างด้วย SwiftUI ล้วน

## ทำไมต้อง iCangJie?

แอปพจนานุกรมส่วนใหญ่หยุดอยู่แค่รหัสแห้ง ๆ iCangJie สร้างขึ้นสำหรับ **ผู้เรียนที่พิมพ์จริง**:

- ดูว่า **ทำไม** รหัสจึงถูกสร้างอย่างนั้น — ไฮไลต์รากและแถบคีย์บอร์ดในทุกหน้ารายละเอียด
- **ฝึกซ้ำ** ด้วยโหมดการพิมพ์สามแบบ บทความคลาสสิก 16 บท (ตัวย่อและตัวเต็ม) และการพิมพ์ซ้ำจากสมุดบันทึกข้อที่ตอบผิด
- **ทดสอบตัวเอง** ด้วย **แบบทดสอบประจำวันที่ปรับแต่งได้** (5–15 ข้อ กำหนดแหล่งคำศัพท์และความยาวรหัสเอง)
- **ติดตามความคืบหน้า** ด้วยรายงานการพิมพ์ 7/30 วัน และการสำรองข้อมูลการเรียนรู้เป็น JSON
- **ดูในพริบตา** ที่หน้าจอโฮม หน้าจอล็อก หรือ StandBy ด้วยวิดเจ็ต 8 แบบที่ออกแบบมาโดยเฉพาะ
- ขอให้ **Siri** ค้นหารหัสฉางเจี๋ยหรือเริ่มแบบทดสอบวันนี้ จัดทำดัชนีรายการโปรดใน **Spotlight**
- สลับทั้งแอปเป็น **อังกฤษ จีนตัวย่อ หรือจีนตัวเต็ม** — UI รีเฟรชทันที

## เริ่มต้นใช้งาน

1. ผ่าน **การแนะนำการใช้งาน 5 หน้าจอ** เมื่อเปิดครั้งแรก (หรือข้ามได้ทุกเมื่อ) ทำตามการ์ด **เส้นทางผู้เริ่มต้น** ใน **เรียนรู้** เพื่อดูลิงก์ลัด
2. เปิด **ค้นหา** แล้วค้นหาด้วยรหัสฉางเจี๋ย ตัวอักษร คำนำหน้าพินอิน หรือจู๊ดผิง — หรือแตะ **การ์ดคำแนะนำการค้นหา** บนหน้าจอเริ่มต้น บน iOS **OCR ลายมือเขียน** ช่วยกรอกช่องค้นหาในหน้าค้นหาและรหัสย่อ
3. เรียกดู **ระดับ** ตามความยาวรหัส (1–5) หรือกลุ่มวิธีซู่เฉิง สลับสุ่มเพื่อฝึกแบบสุ่ม
4. เข้าไปที่ **เรียนรู้** เพื่อดูบทเรียน HTML และแผนภูมิรากที่ซูมได้ด้วยการถ่างนิ้ว (ปรับขนาดการอ่านได้)
5. ลอง **การพิมพ์** — เลือกโหมดรหัสเต็ม รหัสซู่เฉิง หรือผสม เปิด **รายงานการฝึก** เพื่อดูแนวโน้ม
6. ทำ **แบบทดสอบประจำวัน** — ปรับแต่งคำถามในการตั้งค่าแบบทดสอบ ทบทวนข้อที่พลาดในสมุดบันทึกข้อที่ตอบผิด
7. เพิ่ม **วิดเจ็ต** ลงหน้าจอโฮมหรือหน้าจอล็อก ตั้งค่า **การดำเนินการด่วนบนหน้าจอโฮม** ได้สูงสุด 4 รายการ และ **การจัดทำดัชนี Spotlight** แบบเลือกได้ ในการตั้งค่า

## ฟีเจอร์

### พจนานุกรมและการค้นหา

- **อักษรที่คัดสรรกว่า 27,000 ตัว** — ฉางเจี๋ยรุ่นที่ 3 และ 5; JSON ในตัวแบบออฟไลน์ที่ทำความสะอาดให้เหลือเฉพาะอักษรฮั่นที่แสดงผลได้
- **ลำดับความสำคัญของชุดอักขระสี่แบบ** — ฮ่องกง จีนตัวเต็มไต้หวัน จีนตัวย่อ และทั่วไป — มีผลต่อการจัดอันดับการค้นหา
- **โหมดค้นหาสี่แบบ** — คำนำหน้ารหัสฉางเจี๋ย ตัวอักษรที่ตรงกันทุกตัว คำนำหน้าพินอิน และคำนำหน้าจู๊ดผิง; คำแนะนำอัจฉริยะเมื่อโหมดใดไม่มีผลลัพธ์
- **OCR ลายมือเขียน (iOS)** — วาดตัวอักษรในหน้าค้นหา / รหัสย่อ เพื่อกรอกช่องค้นหาในเครื่อง (Vision บนอุปกรณ์)
- **การ์ดหน้าจอเริ่มต้น** — รายการโปรด การเปิดดูล่าสุด และทางลัดความยาวรหัสแบบรวดเร็ว (เปิด/ปิดได้)
- **รายละเอียดคำ** — ไทล์ตัวอักษรขนาดใหญ่ ป้ายรหัสสี แถบคีย์บอร์ดรากต่อรหัส **เปรียบเทียบรุ่น 3/5 เคียงข้างกัน** สำหรับตัวอักษรเดี่ยว **คัดลอกแตะครั้งเดียว** สำหรับตัวอักษรหรือรหัส สถานะการเรียนรู้ รายการโปรด **การค้นหา Youdao ออนไลน์** และ **แชร์เป็นภาพยาว**

### ระดับ (ความยาวรหัส)

- เรียกดูตารางทั้งหมดตาม **รุ่น 3 / 5** × **ความยาวรหัส 1–5** หรือกลุ่ม **วิธีซู่เฉิง**
- เลย์เอาต์ **รายการหรือตาราง** พร้อมจำนวนคอลัมน์ที่เหมาะกับอุปกรณ์ ดึงเพื่อ **สลับ**

### การฝึกพิมพ์

- **สามโหมด** — รหัสเต็ม รหัสซู่เฉิง (ระดับ 1–2) และผสม (ซู่เฉิงก่อน หลังพิมพ์ผิดถอยไปใช้รหัสเต็ม)
- **แหล่งเนื้อหา** — บทความคลาสสิกในตัว 16 บท (JSON ตัวย่อ/ตัวเต็ม) รายการคำสุ่ม ข้อความที่วาง รายการโปรด และการพิมพ์ซ้ำจากสมุดบันทึกข้อที่ตอบผิด (ระบุอักษรฮั่นที่ถูกต้องให้อัตโนมัติ)
- **ไฮไลต์ปุ่มราก** แบบเรียลไทม์ พินอินของบทความแบบเลือกได้ คีย์บอร์ดเสมือนพร้อมการตั้งค่า **คงไว้หรือล้าง** ปุ่มที่กดผิด
- สถิติรอบ (ความแม่นยำ สถิติต่อเนื่อง) และ **ข้อมูลรวมรายวัน** (สูงสุด 120 วัน) ซิงค์ผ่าน iCloud เมื่อเปิดใช้
- **รายงานการฝึก** — แผนภูมิแนวโน้มการพิมพ์ 7/30 วันและการกระจายความยาวรหัส เปิดจากศูนย์รวมการพิมพ์หรือ การตั้งค่า → สถิติการเรียนรู้

### แบบทดสอบประจำวันและสมุดบันทึกข้อที่ตอบผิด

- **แบบทดสอบที่ปรับแต่งได้** — วันละ 5 / 8 / 10 / 15 ข้อ; แหล่งคำศัพท์: พจนานุกรม รายการโปรด หรือสมุดบันทึกข้อที่ตอบผิด; ตัวกรองความยาวรหัส 1–5; เปิด/ปิดประเภทคำถาม
- สามประเภท: ตัวอักษร→รหัส รหัส→ตัวอักษร (พร้อมแถบคีย์บอร์ด) และตัวอักษร→ปุ่มรากแรก
- UI แบบการ์ดพร้อมผลตอบกลับทันทีและ **ทบทวนข้อที่ตอบผิด** ตอนจบรอบ **สลับใหม่** เพื่อรับชุดใหม่ ไอคอนเฟืองเปิด **การตั้งค่าแบบทดสอบ**

### เรียนรู้ (บทเรียนและการแนะนำการใช้งาน)

- **การแนะนำการใช้งาน 5 หน้าจอ** เมื่อเปิดครั้งแรก (เรียกใหม่ได้ทุกเมื่อจาก **การตั้งค่า → การตั้งค่าแอป**); การ์ด **เส้นทางผู้เริ่มต้น** ในแท็บเรียนรู้ (ค้นหา แบบทดสอบ บทเรียนแรก คู่มือวิดเจ็ต)
- **บทเรียน HTML 11 บท** + **ภาพแผนภูมิราก** ที่จัดกลุ่มไว้ในศูนย์รวมการเรียนรู้
- **ปรับขนาดการอ่านได้** (85%–160%); HTML ปรับตามโหมดสว่าง/มืด; ใช้ตัวเต็มเมื่อภาษาของแอปเป็น zh-Hant
- แผนภูมิซูมด้วยการถ่างนิ้ว; **แกลเลอรีปัดสลับ** ระหว่างภาพที่การซูม 1×; **บันทึกลงรูปภาพ** หรือแชร์ (iOS)

### เครื่องมือ (การตั้งค่า)

- **ตัวแปลงพินอินและฉางเจี๋ย** — รูปแบบผลลัพธ์หลายแบบ (มีวรรณยุกต์ แบบธรรมดา มีตัวเลข มีคำอธิบายประกอบ ตารางจัดแนว); แสดงรหัสฉางเจี๋ยได้ตามต้องการ; คัดลอกหรือ **แชร์ภาพตัวอย่าง**
- **สนามทดลองแปลงข้อความเป็นเสียง** — เล่น หยุดชั่วคราว และหยุด
- **คู่มือวิดเจ็ต** — แคตตาล็อกครบถ้วนพร้อมขั้นตอนสำหรับหน้าจอล็อกและคำถามที่พบบ่อย (iOS)
- **การดำเนินการด่วนบนหน้าจอโฮม** — เลือกได้สูงสุด 4 จาก 7 ตัวเลือก (ค้นหา แบบทดสอบ รายการโปรด ข้อที่ตอบผิด ระดับ ข้อเสนอแนะ ให้คะแนน)
- **การจัดทำดัชนี Spotlight** (iOS) — แสดงรายการโปรดและรายการล่าสุดในการค้นหาของระบบ (เปิด/ปิดในการตั้งค่า)
- **Siri และคำสั่งลัด** — App Intents ในตัว: ค้นหารหัสฉางเจี๋ย เริ่มแบบทดสอบประจำวัน เปิดค้นหา การพิมพ์ รายการโปรด สมุดบันทึกข้อที่ตอบผิด และอื่น ๆ
- **ไอคอนแอปทางเลือก** (iOS) — สไตล์สองโทน "倉" แปดแบบ รวมค่าเริ่มต้น
- **สำรองและกู้คืน JSON** — ส่งออก/นำเข้าข้อมูลการเรียนรู้ (รวมหรือแทนที่) จาก การตั้งค่า → สถิติการเรียนรู้
- **การพิมพ์ผิด** — ตัวอักษรที่พิมพ์ผิดจะเข้าสู่สมุดบันทึกข้อที่ตอบผิดเพื่อพิมพ์ซ้ำทันทีหรือภายหลัง

### การปรับแต่ง

- **ธีมไล่เฉดสีที่ตั้งไว้ล่วงหน้า 15 แบบ** + สีเน้นแบบกำหนดเอง รูปลักษณ์สว่าง / มืด / ตามระบบ
- **ตารางไทล์ตามธีม** — ไทล์ตัวอักษรในมุมมองรายการ/ตารางใช้สีเน้นของคุณ
- **ภาษาในแอป** — อังกฤษ จีนตัวย่อ จีนตัวเต็ม หรือตามระบบ; วิดเจ็ตสะท้อนภาษาผ่าน App Group
- ค่ากำหนดเลย์เอาต์รายการ/ตาราง สวิตช์ซ้อนพินอิน รุ่นฉางเจี๋ยและชุดอักขระเริ่มต้น

### iOS และ iPad

- **วิดเจ็ต 8 แบบ** — Daily Character, Code Length, Daily Quiz, Typing Glance, Favorites, Wrong Book, Recent, Learning Progress รองรับหน้าจอโฮม หน้าจอล็อก และ StandBy
- **ปุ่มสลับ** ของ Daily Character ในขนาดเล็กและกลาง (iOS 17+) วิดเจ็ต Code Length: เลือก **1–5** ตอนเพิ่ม; **ปุ่มสลับ** ในขนาดเล็กและกลางเพื่อรีเฟรชตัวอักษรสามตัว (iOS 17+)
- วิดเจ็ต Favorites / Wrong / Recent แสดงตัวอย่างตารางช่องข้าว **2×3 (เล็ก) / 3×3 (กลาง)** พร้อมรหัส

### macOS

- แอป Mac แบบเนทีฟ มีแถบนำทางโปร่งใส การย้อนกลับด้วย **Esc** ชีตแชร์ของระบบ และการฝึกพิมพ์เต็มรูปแบบ
- การค้นหาผสานกับแถบค้นหา ชีต Safari แบบลอยสำหรับลิงก์ภายนอกในบทเรียน

### ความเป็นส่วนตัว

- **แกนหลักออฟไลน์** — พจนานุกรม แบบทดสอบ บทเรียน และการพิมพ์ใช้งานได้โดยไม่ต้องใช้เครือข่าย
- **ไม่มีโฆษณา · ไม่มีการติดตาม** — ไม่มี SDK วิเคราะห์ iCloud แบบเลือกได้ใช้เฉพาะ KVS ของ Apple
- ขอสิทธิ์เข้าถึงคลังรูปภาพ **เฉพาะเมื่อคุณเลือกบันทึกภาพแผนภูมิราก** (เพิ่มอย่างเดียว)

## วิดเจ็ต

iCangJie มี **วิดเจ็ต 8 แบบ** สำหรับหน้าจอโฮม หน้าจอล็อก และ StandBy ดู **คู่มือวิดเจ็ต** ในแอป (การตั้งค่า → เครื่องมือ) สำหรับการตั้งค่าทีละขั้น แคตตาล็อกภาพ และคำถามที่พบบ่อย

| วิดเจ็ต | สิ่งที่แสดง | แตะแล้วเปิด |
|--------|---------------|-----------|
| Daily Character | ตัวอักษรสุ่ม + รหัส; สลับในขนาดเล็กและกลาง | รายละเอียดคำ |
| Code Length | ตัวอักษร 3 ตัวตามความยาวที่เลือก (1–5); สลับในขนาดเล็กและกลาง | ระดับ |
| Daily Quiz | คะแนนวันนี้ + สถิติต่อเนื่อง | แบบทดสอบ |
| Typing Glance | จำนวนที่พิมพ์ทั้งหมด + ความแม่นยำ | การพิมพ์ |
| Favorites | ตัวอย่างตารางช่องข้าว + จำนวน | รายการโปรด |
| Wrong Book | ตารางข้อที่พลาดล่าสุด | สมุดบันทึกข้อที่ตอบผิด |
| Recent | ตัวอักษรที่เปิดดูล่าสุด | ค้นหา |
| Learning Progress | จำนวนเชี่ยวชาญ / เรียนแล้ว / กำลังเรียน | เรียนรู้ |

สีเน้นของวิดเจ็ตตามธีมของแอป (พื้นหลังเป็นกลางแบบเลือกได้ในการตั้งค่า)

## Deep Link และการดำเนินการด่วน

พาธที่ `iCangJie://` รองรับ: `search`, `word`, `quiz`, `typing`, `favorites`, `wrong`, `levels`, `learn`, `feedback`, `review`

**วลี Siri** ในตัวและ **App Intents ของคำสั่งลัด** ยังเปิดการค้นหา รายละเอียดคำ และแบบทดสอบได้ ดู [เอกสารอ้างอิง URL Scheme](url-scheme) สำหรับพารามิเตอร์ App Intents และตัวอย่างคำสั่งลัด

## ความต้องการของระบบ

| แพลตฟอร์ม | ขั้นต่ำ |
|----------|---------|
| iPhone / iPad | iOS 16.0+ |
| Mac | macOS 13.0+ |
| ส่วนขยายวิดเจ็ต | iOS 17.0+ (AppIntents วิดเจ็ตความยาวรหัสที่กำหนดค่าได้) |

วิดเจ็ตเสริมหน้าจอล็อกต้องใช้ iOS 16+ การโต้ตอบบางอย่างของวิดเจ็ตต้องใช้ iOS 17+

## แหล่งข้อมูล

ข้อมูลพจนานุกรมฉางเจี๋ยมีการให้เครดิตในแอปและมาจากโครงการพจนานุกรมของชุมชน (ดูหน้าเกี่ยวกับในแอปสำหรับการอ้างอิงฉบับเต็ม) บทความฝึกพิมพ์เป็นข้อความภาษาจีนคลาสสิกที่เป็นสาธารณสมบัติ
