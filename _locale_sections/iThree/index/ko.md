iThree(爱三字经 / 愛三字書)는 일반 텍스트 덤프가 아닌 **몰입형 San Zi Jing 학습 스튜디오**입니다. **계정이 필요하지 않습니다.** 모든 **48개 구절**에는 **병음**, **현지어**, **영어**, **21개의 이야기**, **16개의 고전 색인**, **21개의 왕조** 및 **32개의 유명한 대사**가 포함되어 있습니다. **읽기** 나란히; **암송**(줄 강조 표시 포함); **학습 모드**에서 연습하세요. 상황별 **데일리 라인**을 엽니다. **공유 카드** 내보내기, **위젯**, 옵션 **실시간 활동 읽기**, **Siri 및 단축키**, 옵션 **iCloud**를 추가하세요. **광고가 없습니다. 추적이 없습니다. 데이터가 수집되지 않습니다.** 

## 시작하기(단계별) 

### 1. 첫 실행 

1. [App Store](https://apps.apple.com/app/id6796002326)에서 설치하고 **iThree**를 엽니다. 
2. **환영 가이드**(브랜드 → 이중 언어 읽기 → 암송 → 학습 → 시스템 기능 → 개인 정보 보호)를 완료합니다. 
3. 언제든 다시보기: **설정 → 도움말 → 기능안내** (`ithree://feature-guide`). 
4. 인앱 **사용법/위젯/바로가기** 가이드는 **설정 → 도움말**에 있습니다. 

### 2. 홈에서 오늘의 말씀을 읽어보세요

1. **홈** 탭을 엽니다. 
2. **Daily Line** 히어로는 오늘의 본문을 보여줍니다. 세부정보를 열려면 탭하세요. 
3. 선택 사항: 설정에서 **일별 알림**을 켭니다(현지 일정만 해당, 축제는 음력을 따릅니다). 
4. 계속해서 읽으세요. 유명한 대사, 연속선, 단축키(**헌트** 포함)를 탭 한 번이면 됩니다. 

### 3. 탐색 및 검색 

1. **찾아보기**를 엽니다(설정에서 숨길 수 있음). 
2. **6개 장**, **태그**, **이야기**, **고전**, **왕조**, **유명 대사** 및 모든 구절을 탐색하세요. 컬렉션 페이지에는 짧은 소개와 접을 수 있는 에세이가 표시됩니다. 
3. 제목, 대사, 이야기, 저자에 대해 **검색**을 사용합니다(간체/번체 친화적). iOS에서는 선택적 **필기 검색**이 기기의 문자를 인식합니다. 
4. **즐겨찾기**에 별표 표시를 하세요. 좋아하는 **이야기**를 별도로; 개인 **라인 목록**(句单)을 구축합니다. 즐겨찾기 탭은 **기본적으로 켜져 있습니다**. 

### 4. 이중 언어 읽기 및 공유 카드

1. 세부사항에서 **이중언어 / 중국어만 / 영어만** 선택하세요. **병음**, 모국어, 영어, 메모를 독립적으로 전환합니다. 
2. **세로 읽기**, 가운데 맞춤, 글꼴 크기 조정, 몰입형 모드 및 **분할된 페이지**를 사용해 더 길게 펼칩니다. 
3. **공유 카드** 열기 → 스타일/비율 선택 및 모국어, 영어 또는 병음을 포함할지 여부 → 사진(추가 전용) 또는 시스템 공유에 저장합니다. 
4. 선택 사항: iPhone에서 **실시간 활동 읽기**를 활성화합니다(포그라운드에서 시작해야 함). 

5. 암송(诵读) 

1. 세부사항에서 **암송**을 탭하거나 암송 스튜디오를 엽니다. 
2. 들으면서 **라인레벨 강조**를 따라가세요. 
3. **설정 → 암송**에서 **재생 콘텐츠 매트릭스**(제목/저자/본문 × 원본/토국어/영어)를 *보는* 내용과 별개로 설정합니다. 
4. 선택 사항: 무음 모드 재생, 배경 오디오 + Now Playing, 연속 재생, 말하는 동안 화면을 계속 켜두세요. 

### 6. 공부교실(蒙school)

1. 홈 / `ithree://study` / 4가지 모드 메뉴 바로가기에서 **스터디**를 엽니다. 
2. 모드: **암송**, **빈칸 채우기**, **자가 점검**, **퀴즈**(`ithree://quiz`는 오늘의 퀴즈로 바로 이동합니다). 
3. 홈, 제어 센터 또는 `ithree://hunt`을 통해 **Hunt(寻句 / 一字寻句)**를 플레이하세요. 
4. 즐겨찾기, 라인 목록 또는 마스터 항목에서 일괄 연습; 숙련도 레벨과 연속 기록을 추적하세요. 

### 7. 위젯, Siri 및 홈 화면 바로가기 

1. 홈 화면 길게 누르기 → **위젯 편집** → **데일리 라인/유명 라인/공부 진행/즐겨찾기** 추가(데일리 라인은 종이 스타일 지원) 
2. 오늘의 대사, 암송, 랜덤, 즐겨찾기, 헌트, 검색 등을 **Siri**에게 물어보세요. 
3. **설정 → 바로가기**에서 홈 화면 빠른 동작을 구성합니다. 
4. 제어 센터 컨트롤(iOS 18+)에는 오늘/무작위/검색/공부/사냥 등이 포함됩니다. 

### 8. 개인정보 보호 및 동기화 

1. 도서관, 독서, 암송(시스템 TTS), 학습, 위젯, 로컬 알림은 설치 후 **완전히 오프라인**으로 작동합니다. 
2. 선택 사항인 **iCloud 동기화**는 **개인 iCloud**를 통해 즐겨찾기(스토리 즐겨찾기 포함), 목록, 기록, 숙달 및 연속 기록을 미러링합니다. 
3. 개발자(StoreKit 옵션)는 페이월 콘텐츠를 잠금 해제하거나 계정을 생성하지 않는다는 점을 알려주세요.
