**一度に 3 文字。 生涯の基礎。**

 iThree (爱三字经 / 愛三字經) は **没入型の San Zi Jing 学習スタジオ** であり、別のプレーン テキスト ダンプではありません。 **アカウントは必要ありません。** すべての **48 パッセージ**は、**文字ピンイン**、*母語**、**英語**、**21 の物語**、**16 の古典索引**、**21 の王朝**、**32 の有名なセリフ**とともにデバイスに出荷されます。 **並べて読んでください**。 **朗読** 行を強調表示します。 **学習モード**で練習します。 コンテキストに応じた **日次ライン** を開きます。 **共有カード**をエクスポートし、**ウィジェット**、オプションの**ライブ アクティビティの読み取り**、**Siri とショートカット**、およびオプションの **iCloud** を追加します。 **広告はありません。 追跡はありません。 データは収集されません。**

 ## はじめに (ステップバイステップ)

 ### 1. 最初の起動

 1. [App Store](https://apps.apple.com/app/id6796002326) からインストールし、**iThree** を開きます。 
2. **ウェルカム ガイド** (ブランド → バイリンガル リーディング → 暗唱 → 学習 → システム機能 → プライバシー) を完了します。 
3. いつでも再生できます: **[設定] → [ヘルプ] → [機能ガイド]** (`ithree://feature-guide`)。 
4. アプリ内の**使用法 / ウィジェット / ショートカット** ガイドは、**設定 → ヘルプ** に表示されます。 

### 2. ホームで今日の一文を読む

1. [**ホーム**] タブを開きます。 
2. **デイリーライン**のヒーローが今日の一節を示しています。 タップして詳細を開きます。 
3. オプション: [設定] で **毎日の Line 通知** をオンにします (ローカル スケジュールのみ。フェスティバルは旧暦に従います)。 
4. 続きを読む、有名なセリフ、スジ、ショートカット (**ハント**を含む) を 1 回タップするだけでアクセスできます。 

### 3. 参照と検索

 1. **参照** を開きます (設定で非表示にすることができます)。 
2. **6 章**、**タグ**、**ストーリー**、**古典書籍**、**王朝**、**有名なセリフ**、およびすべての文章を探索します。 コレクション ページには、短いイントロと折りたたみ可能なエッセイが表示されます。 
3. **検索**を使用して、タイトル、セリフ、ストーリー、作者を検索します (簡体字/繁体字対応)。 iOS では、オプションの **手書き検索** によりデバイス上の文字が認識されます。 
4. **お気に入り**にスターを付けます。 お気に入りの**ストーリー**を個別に。 個人的な **行リスト** (句单) を作成します。 [お気に入り] タブは **デフォルトでオンになっています**。 

### 4. バイリンガルの読書とカードの共有

1. 詳細で、**バイリンガル/中国語のみ/英語のみ**を選択します。 **ピンイン**、現地語、英語、メモを個別に切り替えます。 
2. 長時間の場合は、**縦読み**、中央揃え、フォント スケール、イマーシブ モード、**分割ページ**を試してください。 
3. **共有カード**を開く → スタイル/比率を選択し、現地語、英語、またはピンインを含めるかどうかを選択 → 写真 (追加専用) またはシステム共有に保存します。 
4. オプション: iPhone で **ライブ アクティビティの読み取り** を有効にします (フォアグラウンドで開始する必要があります)。 

### 5. 朗読（诵读）

 1. 詳細については、**朗読** をタップするか、朗読スタジオを開きます。 
2. 聞きながら **行レベルの強調表示**に従います。 
3. **[設定] → [朗読]** で、*表示内容*とは独立して、**再生コンテンツ マトリックス** (タイトル / 著者 / 本文 × オリジナル / 言語 / 英語) を設定します。 
4. オプション: サイレント モード再生、バックグラウンド オーディオ + 再生中、連続再生、話している間画面をオンにしたままにします。 

### 6. 学習教室 (蒙学)

1. ホーム / `ithree://study` / 4 つのモード メニューのショートカットから **Study** を開きます。 
2. モード: **朗読**、**穴埋め**、**セルフチェック**、**クイズ** (`ithree://quiz` は今日のクイズに直接ジャンプします)。 
3. ホーム、コントロール センター、または `ithree://hunt` 経由で **Hunt (寻句 / 一字寻句)** を再生します。 
4. お気に入り、ラインリスト、またはマスターアイテムからのバッチ練習。 マスタリーレベルと連続記録を追跡します。 

### 7. ウィジェット、Siri、ホーム画面のショートカット

 1. ホーム画面を長押し → **ウィジェットの編集** → **デイリーライン / 有名ライン / 学習進捗 / お気に入り ** を追加します (デイリーラインは用紙スタイルをサポートしています)。 
2. **Siri** に今日のセリフ、朗読、ランダム、お気に入り、検索、または検索を尋ねます。 
3. **[設定] → [ショートカット]** でホーム画面のクイック アクションを構成します。 
4. コントロール センター コントロール (iOS 18 以降) には、Today / Random / Search / Study / Hunt などが含まれます。 

### 8. プライバシーと同期

 1. 図書館、読書、暗唱 (システム TTS)、学習、ウィジェット、およびローカル通知は、インストール後 **完全にオフライン**で機能します。 
2. オプションの **iCloud Sync** は、**プライベート iCloud** を通じてお気に入り (ストーリーのお気に入りを含む)、リスト、履歴、マスタリー、ストリークをミラーリングします。 
3. 開発者 (オプションの StoreKit) は、ペイウォールで保護されたコンテンツのロックを解除したり、アカウントを作成したりすることはありません。

## ダウンロードする理由

 - **San Zi Jing は正しく行われました** — ピンイン + 現地語 + 英語を 1 つの落ち着いたネイティブ スタジオで行います。 
- **文脈を教えるストーリーと索引** — 韻だけではなく、その背後にある古典や王朝についても学びます。 
- **心に残る学習** — 4 つのモード、ハント、マスタリー、ウィジェットを備えた毎日のライン。 
- **役立つところはネイティブ** — ライブ アクティビティ、コントロール センター、Siri、ディープ リンク、オプションの iCloud。 
- **設計によるプライバシー** — アカウント、広告、分析 SDK はありません。 

## 特徴

 ### バイリンガル三子経スタジオ
 - **48** 文章 · 文字ピンイン · 現地語 · 英語 · **32** 有名なセリフ
 - **21** ストーリー · **16** クラシックインデックス · **21** 王朝 · 6 章
 - 縦書き/没入型読書・カードの共有

 ### 朗読と学習
 - レート/音声を調整できるラインレベルTTS
 - 再生コンテンツ マトリックス (混合言語の音声)
 ・朗読・穴埋め・セルフチェック・クイズ・ハント
 - マスタリー + ストリーク · バッチキュー

 ### 日常ラインとシステムの統合
 - コンテキストプール（二十四節気/月祭り/季節）
 - ローカル通知 · ウィジェット · コントロール センター · ライブ アクティビティ · Siri · `ithree://` ディープ リンク
 - オプションのスポットライト (デフォルトではオフ)

### プライバシー
 - **アカウントなし、広告なし、分析 SDK なし**
 - コアの使用には、インストール後に **ネットワークなし** が必要です
 - オプションのプライベート iCloud KVS のみ
