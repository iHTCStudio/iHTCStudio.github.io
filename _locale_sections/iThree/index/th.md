**ครั้งละสามตัวอักษร รองพื้นเพื่อชีวิต** 

iThree (爱三字经 / 愛三字經) คือ **สตูดิโอการเรียนรู้ San Zi Jing ที่สมจริง** — ไม่ใช่การถ่ายโอนข้อความธรรมดาแบบอื่น **ไม่จำเป็นต้องมีบัญชี** ทั้งหมด **48 ตอน** จัดส่งบนอุปกรณ์ของคุณด้วย **อักขระพินอิน**, **ภาษาพื้นถิ่น**, **อังกฤษ**, **21 เรื่อง**, **ดัชนีคลาสสิก 16 รายการ**, **21 ราชวงศ์** และ **32 บทที่มีชื่อเสียง** **อ่าน** เคียงข้างกัน; **ท่อง** โดยเน้นบรรทัด ฝึกฝนใน **โหมดการศึกษา**; เปิดบริบท **Daily Line** ส่งออก **แชร์การ์ด** เพิ่ม **วิดเจ็ต** ตัวเลือกเสริม **กิจกรรมการอ่านสด** **Siri และคำสั่งลัด** และอุปกรณ์เสริม **iCloud** ** ไม่มีโฆษณา ไม่มีการติดตาม ข้อมูลไม่ถูกเก็บรวบรวม** 

## เริ่มต้นใช้งาน (ทีละขั้นตอน) 

### 1. เปิดตัวครั้งแรก 

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id6796002326) และเปิด **iThree** 
2. กรอก **คำแนะนำการต้อนรับ** (แบรนด์ → การอ่านสองภาษา → ท่อง → การศึกษา → คุณสมบัติของระบบ → ความเป็นส่วนตัว) 
3. เล่นซ้ำได้ทุกเมื่อ: **การตั้งค่า → ช่วยเหลือ → คู่มือฟีเจอร์** (`ithree://feature-guide`) 
4. คู่มือ **การใช้งาน / วิดเจ็ต / ทางลัด** ในแอปอยู่ภายใต้ **การตั้งค่า → ความช่วยเหลือ** 

### 2. อ่านบรรทัดวันนี้ที่หน้าแรก

1. เปิดแท็บ **หน้าหลัก**
2. ฮีโร่ **Daily Line** จะแสดงข้อความประจำวันของวันนี้ แตะเพื่อเปิดรายละเอียด
3. เป็นทางเลือก: เปิดใช้งาน **การแจ้งเตือน Daily Line** ในการตั้งค่า (ตั้งเวลาในเครื่องเท่านั้น; เทศกาลตามปฏิทินจันทรคติ)
4. การอ่านต่อ, ประโยคที่มีชื่อเสียง, สถิติการต่อเนื่อง, และทางลัด (รวมถึง **Hunt**) อยู่แค่การแตะครั้งเดียว

### 3. การเรียกดู & การค้นหา

1. เปิด **เรียกดู** (สามารถซ่อนได้ใน การตั้งค่า)
2. สำรวจ **หกบท**, **แท็ก**, **เรื่องราว**, **หนังสือคลาสสิก**, **ราชวงศ์**, **ประโยคมีชื่อเสียง**, และข้อความทั้งหมด หน้าแสดงคอลเล็กชันจะแสดงบทนำสั้น ๆ และเรียงความที่ย่อ/ขยายได้
3. ใช้ **ค้นหา** สำหรับชื่อเรื่อง, ประโยค, เรื่องราว, และผู้แต่ง (รองรับทั้งตัวย่อ / ตัวเต็ม) บน iOS, เป็นทางเลือก **การค้นหาด้วยการเขียนด้วยมือ** จะจดจำตัวอักษรบนอุปกรณ์
4. ทำเครื่องหมายข้อความเป็น **รายการโปรด**; เรื่องราวที่ชอบแยกต่างหาก; สร้าง **รายการประโยคส่วนตัว (句单)** แท็บรายการโปรดจะ **เปิดอยู่เป็นค่าเริ่มต้น**

### 4. การอ่านสองภาษา & การแชร์การ์ด

1. ในรายละเอียด เลือก **สองภาษา / จีนเท่านั้น / อังกฤษเท่านั้น**; สลับ **พินอิน**, ภาษาพูด, ภาษาอังกฤษ และบันทึกแยกต่างหาก  
2. ลอง **การอ่านแนวตั้ง**, การจัดกึ่งกลาง, ขนาดตัวอักษร, โหมดดื่มด่ำ, และ **หน้าที่แบ่งตอน** สำหรับเนื้อหายาว  
3. เปิด **Share Card** → เลือกรูปแบบ / อัตราส่วน และว่าจะรวมภาษาพูด ภาษาอังกฤษ หรือพินอินด้วยหรือไม่ → บันทึกลง Photos (เพิ่มเท่านั้น) หรือแชร์ผ่านระบบ  
4. ไม่จำเป็น: เปิดใช้งาน **Reading Live Activity** บน iPhone (ต้องเริ่มในหน้าจอหลัก)  

### 5. ท่องจำ (诵读)  

1. ในรายละเอียด แตะ **Recite** — หรือเปิดสตูดิโอท่องจำ  
2. ทำตาม **การไฮไลต์ทีละบรรทัด** ขณะฟัง  
3. ใน **การตั้งค่า → การท่องจำ**, ตั้งค่า **แมทริกซ์เนื้อหาเล่นซ้ำ** (หัวข้อ / ผู้แต่ง / เนื้อหา × ต้นฉบับ / ภาษาพูด / ภาษาอังกฤษ) — แยกจากสิ่งที่คุณ *เห็น*  
4. ไม่จำเป็น: เล่นแบบเงียบ, เสียงพื้นหลัง + Now Playing, เล่นต่อเนื่อง, รักษาหน้าจอเปิดขณะพูด  

### 6. ห้องเรียนศึกษา (蒙学)

1. เปิด **ศึกษา** จากหน้าแรก / `ithree://study` / ทางลัดสำหรับเมนูสี่โหมด 
2. โหมด: **การบรรยาย**, **เติมในช่องว่าง**, **ตรวจสอบตัวเอง**, **แบบทดสอบ** (`ithree://quiz` กระโดดเข้าสู่แบบทดสอบของวันนี้โดยตรง) 
3. เล่น **Hunt (寻句 / 一字寻句)** ผ่านทางหน้าแรก ศูนย์ควบคุม หรือ `ithree://hunt` 
4. การฝึกปฏิบัติเป็นชุดจากรายการโปรด รายการบรรทัด หรือรายการที่เชี่ยวชาญ ติดตามระดับความเชี่ยวชาญและลายเส้น 

### 7. ทางลัดวิดเจ็ต, Siri และหน้าจอหลัก 

1. กดหน้าจอหลักค้างไว้ → **แก้ไขวิดเจ็ต** → เพิ่ม **บรรทัดรายวัน / เส้นที่มีชื่อเสียง / ความคืบหน้าการศึกษา / รายการโปรด** (Daily Line รองรับรูปแบบกระดาษ) 
2. ถาม **Siri** เกี่ยวกับบรรทัดของวันนี้ ท่อง สุ่ม รายการโปรด ล่า หรือค้นหา 
3. กำหนดค่าการดำเนินการด่วนบนหน้าจอหลักใน **การตั้งค่า → ทางลัด** 
4. การควบคุมของศูนย์ควบคุม (iOS 18+) รวมถึงวันนี้ / สุ่ม / ค้นหา / ศึกษา / ล่าและอีกมากมาย 

### 8. ความเป็นส่วนตัวและการซิงค์ 

1. ห้องสมุด การอ่าน การท่อง (ระบบ TTS) การศึกษา วิดเจ็ต และการแจ้งเตือนในท้องถิ่นทำงาน **ออฟไลน์โดยสมบูรณ์** หลังการติดตั้ง 
2. ตัวเลือกเสริม **iCloud Sync** จะสะท้อนรายการโปรด (รวมถึงเรื่องราวโปรด) รายการ ประวัติศาสตร์ ความเชี่ยวชาญ และลายเส้นผ่าน **iCloud ส่วนตัวของคุณ** 
3. เคล็ดลับนักพัฒนา (อุปกรณ์เสริม StoreKit) จะไม่ปลดล็อกเนื้อหาเพย์วอลล์และไม่เคยสร้างบัญชี

## ทำไมคุณถึงต้องการดาวน์โหลด 

- **San Zi Jing ทำได้ดีมาก** — พินอิน + ภาษาพื้นถิ่น + ภาษาอังกฤษในสตูดิโอพื้นเมืองอันเงียบสงบแห่งเดียว 
- **เรื่องราวและดัชนีที่สอนบริบท** — ไม่ใช่แค่บทกวีเท่านั้น แต่ยังรวมถึงความคลาสสิกและราชวงศ์ที่อยู่เบื้องหลังสิ่งเหล่านั้นด้วย 
- **การศึกษาที่คงอยู่** — สี่โหมด, ล่า, เชี่ยวชาญ และไลน์รายวันพร้อมวิดเจ็ต 
- **เนทีฟที่ช่วยได้** — กิจกรรมสด, ศูนย์ควบคุม, Siri, ลิงก์ในรายละเอียด, ตัวเลือกเสริม iCloud 
- **ความเป็นส่วนตัวตามการออกแบบ** — ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK การวิเคราะห์ 

## คุณสมบัติ 

### สตูดิโอสองภาษาซานซีจิง 
- **48** ข้อความ · ตัวอักษรพินอิน · ภาษาพื้นถิ่น · อังกฤษ · **32** บรรทัดที่มีชื่อเสียง 
- **21** เรื่องราว · **16** ดัชนีคลาสสิก · **21** ราชวงศ์ · หกบท 
- การอ่านแนวตั้ง / ดื่มด่ำ·แชร์การ์ด 

### ทบทวนและการศึกษา 
- TTS ระดับสายพร้อมอัตรา / เสียงที่ปรับได้ 
- เมทริกซ์เนื้อหาการเล่น (พูดภาษาผสม) 
- การบรรยาย · เติมช่องว่าง · ตรวจสอบตนเอง · แบบทดสอบ · ล่า 
- ความชำนาญ + ลายเส้น · คิวแบทช์ 

### การรวมสายและระบบรายวัน 
- สระน้ำตามบริบท (เงื่อนไขแสงอาทิตย์ / เทศกาลทางจันทรคติ / ฤดูกาล) 
- การแจ้งเตือนในท้องถิ่น · วิดเจ็ต · ศูนย์ควบคุม · กิจกรรมสด · Siri · `ithree://` ลิงก์ในรายละเอียด 
- สปอตไลท์เสริม (ปิดโดยค่าเริ่มต้น)

### ความเป็นส่วนตัว
- **ไม่มีบัญชี · ไม่มีโฆษณา · ไม่มี SDK วิเคราะห์ข้อมูล**
- การใช้งานหลัก **ไม่ต้องเชื่อมต่อเครือข่าย** หลังติดตั้ง
- ตัวเลือก iCloud KVS ส่วนตัวเท่านั้น
