**Trois personnages à la fois. Une fondation pour toute une vie.** 

iThree (爱三字经 / 愛三字經) est un **studio d'apprentissage immersif San Zi Jing** – pas un autre vidage de texte brut. **Aucun compte requis.** Les **48 passages** sont livrés sur votre appareil avec **caractère pinyin**, **vernaculaire**, **anglais**, **21 histoires**, **16 index classiques**, **21 dynasties** et **32 lignes célèbres**. **Lire** côte à côte ; **réciter** en surlignant les lignes ; pratiquer en **modes d'étude** ; ouvrez une **Daily Line** contextuelle. Exportez des **cartes de partage**, ajoutez des **widgets**, **Reading Live Activity** en option, **Siri et raccourcis** et **iCloud** en option. **Aucune publicité. Aucun suivi. Données non collectées.** 

## Mise en route (étape par étape) 

### 1. Premier lancement 

1. Installez depuis l'[App Store](https://apps.apple.com/app/id6796002326) et ouvrez **iThree**. 
2. Complétez le **guide de bienvenue** (marque → lecture bilingue → réciter → étudier → fonctionnalités du système → confidentialité). 
3. Rejouez à tout moment : **Paramètres → Aide → Guide des fonctionnalités** (`ithree://feature-guide`). 
4. Les guides **Utilisation / Widget / Raccourcis** intégrés à l'application se trouvent sous **Paramètres → Aide**. 

### 2. Lisez la ligne d'aujourd'hui sur Accueil

1. Ouvrez l'onglet **Accueil**.
2. Le héros **Ligne Quotidienne** montre le passage du jour ; appuyez pour ouvrir le détail.
3. Optionnel : activez les **notifications Ligne Quotidienne** dans les Paramètres (programmation locale seulement ; les festivals suivent le calendrier lunaire).
4. Continuez à lire, accéder aux lignes célèbres, aux séries et aux raccourcis (y compris **Chasse**) en une seule touche.

### 3. Parcourir et rechercher

1. Ouvrez **Parcourir** (peut être caché dans les Paramètres).
2. Explorez les **six chapitres**, les **étiquettes**, les **histoires**, les **livres classiques**, les **dynasties**, les **lignes célèbres**, et tous les passages. Les pages de collection montrent une courte introduction et un essai rétractable.
3. Utilisez **Recherche** pour les titres, les lignes, les histoires et les auteurs (compatible Simplifié / Traditionnel). Sur iOS, la **recherche manuscrite** optionnelle reconnaît les caractères sur l'appareil.
4. Étoilez les passages dans **Favoris** ; appréciez les **histoires** séparément ; créez des **listes de lignes** personnelles (句单). L'onglet Favoris est **activé par défaut**.

### 4. Lecture bilingue et partage de cartes

1. Dans le détail, choisissez **bilingue / chinois uniquement / anglais uniquement** ; activez ou désactivez indépendamment **le pinyin**, le vernaculaire, l’anglais et les notes.
2. Essayez la **lecture verticale**, le centrage, l’échelle de police, le mode immersif et les **pages segmentées** pour des passages plus longs.
3. Ouvrez **Carte de partage** → choisissez le style / le ratio et si vous souhaitez inclure le vernaculaire, l’anglais ou le pinyin → enregistrez dans Photos (ajout uniquement) ou partage système.
4. Facultatif : activez **Activité de lecture en direct** sur iPhone (doit démarrer au premier plan).

### 5. Réciter (诵读)

1. Dans le détail, appuyez sur **Réciter** — ou ouvrez le studio de récitation.
2. Suivez le **surlignage ligne par ligne** tout en écoutant.
3. Dans **Paramètres → Récitation**, définissez la **matrice de contenu de lecture** (titre / auteur / corps × original / vernaculaire / anglais) — indépendant de ce que vous *voyez*.
4. Facultatif : lecture en mode silencieux, audio en arrière-plan + Maintenant en lecture, lecture continue, garder l’écran allumé pendant la parole.

### 6. Salle d’étude (蒙学)

1. Ouvrez **Étude** depuis Accueil / `ithree://study` / Raccourcis pour le menu des quatre modes. 
2. Modes : **Récitation**, **Remplir le blanc**, **Auto-vérification**, **Quiz** (`ithree://quiz` passe directement au quiz d'aujourd'hui). 
3. Jouez à **Hunt (寻句 / 一字寻句)** via Accueil, Centre de contrôle ou `ithree://hunt`. 
4. Pratique par lots à partir de favoris, de listes de lignes ou d'éléments maîtrisés ; suivre les niveaux de maîtrise et les séquences. 

### 7. Raccourcis des widgets, Siri et de l'écran d'accueil 

1. Appuyez longuement sur l'écran d'accueil → **Modifier les widgets** → ajoutez **Daily Line / Famous Line / Study Progress / Favorites** (Daily Line prend en charge les styles de papier).
 2. Demandez à **Siri** la ligne du jour, récitez, aléatoirement, favoris, chassez ou recherchez. 
3. Configurez les actions rapides de l'écran d'accueil dans **Paramètres → Raccourcis**. 
4. Les commandes du centre de contrôle (iOS 18+) incluent Aujourd'hui / Aléatoire / Recherche / Étude / Chasse et plus encore. 

### 8. Confidentialité et synchronisation 

1. La bibliothèque, la lecture, la récitation (système TTS), l'étude, les widgets et les notifications locales fonctionnent **entièrement hors ligne** après l'installation. 
2. **iCloud Sync** en option reflète les favoris (y compris les favoris d'histoire), les listes, l'historique, la maîtrise et les séquences via **votre iCloud privé**. 
3. Donnez un conseil au développeur (StoreKit en option) ne déverrouille jamais le contenu payant et ne crée jamais de compte.
