iCouplet (爱对联 / 愛對聯) คือ **สตูดิโอเรียนรู้คำคู่แบบดื่มด่ำ** ไม่ใช่แค่รายการคำคู่ทั่วไป **ไม่ต้องใช้บัญชี** **คำคู่ที่คัดสรรทั้ง 3,369 บท** (ผู้ประพันธ์ ~102 ท่าน ประโยคเด่น ~3,348 ประโยค) รวมอยู่ในอุปกรณ์ของคุณ: **ไม่มีคำขอผ่านเครือข่ายเลย** หลังติดตั้ง **ท่อง** พร้อมไฮไลต์สไตล์คาราโอเกะ เพลิดเพลินกับ **การอ่านแนวตั้ง** (品联) ฝึกใน **ห้องเรียนฝึกฝน** (ค่อย ๆ จางหาย เติมช่องว่าง ตรวจสอบการท่อง แบบทดสอบ และ 对对子) และเปิด **คำคู่ประจำวันตามบริบท** ที่ผูกกับฤดูกาลทางสุริยคติ เทศกาล และฤดูกาล ส่งออก **การ์ดแชร์ 12 สไตล์** เพิ่ม **วิดเจ็ตบนหน้าจอหลัก / หน้าจอล็อก** **Live Activity ขณะอ่าน** แบบเลือกใช้ **Siri และคำสั่งลัด** และ **iCloud** แบบเลือกใช้สำหรับรายการโปรดและความคืบหน้า **ไม่มีโฆษณา ไม่มีการติดตาม ไม่เก็บข้อมูล**

## เริ่มต้นใช้งาน (ทีละขั้นตอน)

### 1. เปิดแอปครั้งแรก

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id6793778879) แล้วเปิด **iCouplet**
2. ทำ **คู่มือต้อนรับ 6 หน้า** ให้จบ (แบรนด์ → การท่อง → การอ่านแนวตั้ง → การเรียน → ฟีเจอร์ของระบบ → ความเป็นส่วนตัว)
3. **เปิดดูคู่มือฟีเจอร์ซ้ำ** ได้ทุกเมื่อ: **การตั้งค่า → ความช่วยเหลือ → คู่มือฟีเจอร์**
4. คู่มือ **การใช้งาน / วิดเจ็ต / คำสั่งลัด** ในแอปอยู่ที่ **การตั้งค่า → ความช่วยเหลือ** และลิงก์ถึงกัน

### 2. อ่านคำคู่ประจำวันบนหน้าหลัก

1. เปิดแท็บ **หน้าหลัก**
2. ส่วนเด่น **คำคู่ประจำวัน** แสดงชื่อพร้อม **วรรคบนและวรรคล่าง** (และหัวเรื่องแนวนอน / 横批 หากมี)
3. แตะส่วนเด่นเพื่อเปิดหน้ารายละเอียดฉบับเต็ม
4. ไม่บังคับ: เปิด **การแจ้งเตือนคำคู่ประจำวัน** ที่ **การตั้งค่า → คำคู่ประจำวัน** (ตั้งเวลาในเครื่องเท่านั้น)

### 3. เรียกดูและค้นหา

1. เปิด **เรียกดู** (หรือการค้นหาบนหน้าหลักใน iOS รุ่นเก่า)
2. สำรวจห้าส่วน: **รูปแบบ (体裁)** **หัวข้อ** **ผู้ประพันธ์ (联家)** **ประโยคเด่น** และ **คอลเลกชัน**
3. ใช้ **ค้นหา** สำหรับชื่อเรื่อง ประโยค และผู้ประพันธ์ (รองรับทั้งอักษรจีนตัวย่อและตัวเต็ม)
4. แตะคำคู่ใดก็ได้เพื่อดูรายละเอียด ติดดาวเพื่อเพิ่มใน **รายการโปรด**

### 4. การท่อง (诵联)

1. ในหน้ารายละเอียดของคำคู่ แตะ **ท่อง**
2. ตามไฮไลต์ **สไตล์คาราโอเกะ** (ระดับย่อหน้าในหน้ารายละเอียด ระดับตัวอักษรในสตูดิโอการท่อง)
3. ปรับ **ความเร็ว / ระดับเสียง / เสียงพูด** ได้ที่ **การตั้งค่า → การอ่านและการท่อง**
4. ไม่บังคับ: เปิด **เล่นในโหมดเงียบ** **เสียงเบื้องหลัง** (กำลังเล่น / หน้าจอล็อก) และเพลย์ลิสต์ต่อเนื่อง
5. ลิงก์ลึกหรือ Siri **ท่อง** สามารถเปิดคำคู่และเริ่มอ่านออกเสียงโดยอัตโนมัติ

### 5. การอ่านแนวตั้งและการ์ดแชร์ (品联 / 联卡)

1. ในหน้ารายละเอียด สลับเค้าโครง **แนวตั้ง / แนวนอน** เปิดหรือปิด **พินอิน** อักษรตัวเต็ม และการจัดกึ่งกลางตามต้องการ
2. เปิด **การ์ดแชร์** → เลือกจาก **12 สไตล์** (คลาสสิก / หมึกจีน / แนวตั้ง / แดงชาด / …) และอัตราส่วนภาพ
3. ดูตัวอย่าง **บันทึกลงรูปภาพ** (สิทธิ์เพิ่มอย่างเดียว) หรือแชร์ผ่านชีตของระบบ
4. ไม่บังคับ: เปิด **Live Activity ขณะอ่าน** ในการตั้งค่า (iPhone ต้องเริ่มขณะแอปอยู่เบื้องหน้า)

### 6. ห้องเรียนฝึกฝน (对课学堂)

1. เปิด **เรียน** จากหน้าหลัก / ลิงก์ลึก `icouplet://study` / คำสั่งลัด
2. ลองโหมด: **ค่อย ๆ จางหาย** **เติมช่องว่าง** **ตรวจสอบการท่อง** **แบบทดสอบ**
3. เล่น **对对子** (เกมจับคู่)
4. ติดตาม **ระดับความชำนาญ 4 ระดับ** (ยังไม่เรียน → คุ้นเคย → รู้แล้ว → ชำนาญ) และสถิติต่อเนื่อง

### 7. วิดเจ็ต Siri และทางลัดบนหน้าจอหลัก

1. กดค้างที่หน้าจอหลัก → **แก้ไขวิดเจ็ต** → เพิ่ม **คำคู่ประจำวัน / ประโยคเด่น / ความคืบหน้าการเรียน / รายการโปรด**
2. บนวิดเจ็ตคำคู่ประจำวัน ลอง **สไตล์กระดาษ** (นุ่มนวล / แดงทึบ / เรียบ) และ **การรีเฟรชบนหน้าจอหลัก** เพื่อเปลี่ยนคำคู่ของวันนี้ (ข้อความแจ้งเตือนของวันนี้จะซิงค์ตามด้วย)
3. ขอให้ **Siri** บอกคำคู่ประจำวัน ท่อง สุ่ม รายการโปรด หรือค้นหา
4. กำหนด **การทำงานด่วนบนหน้าจอหลัก** ได้สูงสุด 4 รายการที่ **การตั้งค่า → ทางลัด**

### 8. ความเป็นส่วนตัวและการซิงค์

1. ทุกอย่างทำงาน **แบบออฟไลน์เต็มรูปแบบ** หลังติดตั้ง
2. **การซิงค์ iCloud** แบบเลือกใช้ (การตั้งค่า → ข้อมูล) จะทำสำเนารายการโปรด รายการคำคู่ ประวัติการอ่าน ระดับความชำนาญ และสถิติต่อเนื่อง ผ่าน **iCloud ส่วนตัวของคุณ** ไม่ใช่เซิร์ฟเวอร์ของ iHTC Studio
3. การให้ทิปนักพัฒนา (การซื้อ StoreKit แบบเลือกได้) ไม่ปลดล็อกเนื้อหาแบบเสียเงินและไม่สร้างบัญชี

## ฟีเจอร์

### สตูดิโอการท่อง

- **TTS** สไตล์คาราโอเกะพร้อมไฮไลต์
- ปรับ **ความเร็ว** **ระดับเสียง** และ **เสียงพูด** ได้
- **เสียงเบื้องหลัง** แบบเลือกใช้ + **กำลังเล่น** บนหน้าจอล็อก
- คิว **การอ่านต่อเนื่อง** จากรายการโปรด / หมวดหมู่

### การอ่านแนวตั้งแบบดื่มด่ำ

- เค้าโครง **แนวตั้งและแนวนอน** แบบคลาสสิก
- **พินอิน** การแปลงเป็นอักษรตัวเต็ม หมายเหตุประกอบ / บทวิจารณ์
- ลำดับบรรทัดเป็น **横批 (ถ้ามี) → วรรคบน → วรรคล่าง** เสมอ
- **การ์ดแชร์ 12 สไตล์** พร้อมอัตราส่วนภาพหลายแบบ

### ระบบการเรียน

- ค่อย ๆ จางหาย · เติมช่องว่าง · ตรวจสอบการท่อง · แบบทดสอบ
- โหมดเกม **对对子**
- **ระดับความชำนาญ 4 ระดับ** + สถิติต่อเนื่อง

### คำคู่ประจำวันตามบริบท

- ฤดูกาลทางสุริยคติ · เทศกาล · ฤดูกาล (พร้อมแคชภายในวัน / การรีเฟรชบนหน้าจอหลัก)
- การแจ้งเตือนในเครื่อง (ช่วงตั้งเวลาล่วงหน้าประมาณ 60 วัน)
- วิดเจ็ต + ตัวควบคุม Control Center (iOS 18+)

### เนื้อหาโดยสรุป

- **คำคู่ 3,369 บท** · **ผู้ประพันธ์ ~102 ท่าน** · **ประโยคเด่น ~3,348 ประโยค** · ข้อมูลในตัวแอปประมาณ 3.9 MB
- ห้าส่วนสำหรับเรียกดู แสดงตัวอย่างแบบรายการ / ตาราง / การ์ด
- **ออฟไลน์ 100%** — ไม่ใช้เครือข่าย ไม่ต้องมีบัญชี ไม่มีโฆษณา

### วิดเจ็ต Siri และการเชื่อมต่อกับระบบ

- วิดเจ็ตคำคู่ประจำวัน / ประโยคเด่น / ความคืบหน้า / รายการโปรด (+ หน้าจอล็อก)
- **Live Activity** ขณะอ่าน (แบบเลือกใช้)
- ดัชนี Spotlight; **ลิงก์ลึก `icouplet://`** — ดู [ลิงก์ทางลัด](url-scheme)
- คู่มือในการตั้งค่า: การใช้งาน · วิดเจ็ต · คำสั่งลัด · เปิดดูคู่มือฟีเจอร์ซ้ำ

### ความเป็นส่วนตัว

- **ไม่มีคำขอออกสู่เครือข่ายเลย** หลังติดตั้ง (ยกเว้น Apple StoreKit แบบเลือกใช้สำหรับการให้ทิป และปลายทางแชร์ของระบบที่คุณเลือก)
- **ไม่มีบัญชี · ไม่มีโฆษณา · ไม่มี SDK วิเคราะห์**
- ข้อมูล App Group ในเครื่อง + iCloud KVS ส่วนตัวแบบเลือกใช้
