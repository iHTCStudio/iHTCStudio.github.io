**壁紙にトーンを合わせる。本当に欲しいウィジェットを作る。**

**iWidget**（爱组件 / 愛組件）は **iPhone、iPad、Mac** 向けの **ウィジェットデザインスタジオ** — 単なるカレンダーアプリではありません。カレンダー、天気、カウントダウン、デバイス情報はグリッド上の **データブロック** です。**54 プリセットセット**（126 サイズインスタンス）、フル **ブロックエディタ**、**スロット別壁紙クロップ**、任意の **透明** ホームウィジェット、**タップシールド** でホーム画面の glance を維持。

App Store は有料ダウンロード。**機能解放 IAP なし** — 任意の **開発者へのチップ**（StoreKit 消耗型）のみ **設定 → この App について**。

## はじめに

1. **初回ガイド** を完了。**マイウィジェット** が空なら iWidget が **Calendar**、**Weather**、**Month** プリセットを自動投入。
2. **今日** で太陽暦・农历、祝日、黄历、天気、カウントダウンをプレビュー — カードタップで詳細シート。
3. **ウィジェットライブラリ** — カテゴリ filt、プリセット/セット名検索、セットタップで小/中/大プレビュー → **追加** または **追加して編集**。
4. **マイウィジェット** — サイズ別グリッド、明暗プレビュー、検索・並べ替え；カードタップで **エディタ** へ。
5. iPhone/iPad でホーム画面長押し → **＋** → **iWidget** 検索 → サイズ選択 → **ウィジェットを編集** → **マイウィジェット** の **保存済みデザイン**（サイズ別グループ）。
6. **設定 → ヘルプ** — **ユーザーガイド**、**ウィジェットを追加**、**ショートカットと Siri**、**ハイライト**。

## 今日

一覧ハブ — 統一スタイルのカード：

- **太陽・农历** — 西暦行、农历日、干支、生肖、休/班バッジ。
- **節気カード** — 区間進捗、物候、古典詩；タップで日詳細。
- **天気** — **設定 → 天気表示** で任意ブロック；今日で引っ張って更新。ホーム時間行は履歴＋予報（`homeHourlyScroll`）。
- **近い祝日** — 横プレビュー（最大 8 件 dedupe）；**すべて見る** で約 1 年。**設定** の祝日 filt へジャンプ可。
- **カウントダウン** — 最大 5 件プレビュー；**すべて** で手動/日付/名前 sort、編集モードでドラッグ並べ替え（App Group 保存）。
- **黄历** — 宜忌、冲など；タップで日詳細。
- 日付タップ → **月グリッド** → **日詳細**（節気詩含む）。

## ウィジェットライブラリとマイウィジェット

| エリア | 内容 |
|--------|------|
| **ライブラリ** | 約 **54 セット**、**126** インスタンス（小/中/大）。セット 1 行・3 列；欠サイズは破線プレースホルダ。おすすめ＋カテゴリ filt；セット/メンバー名検索。 |
| **マイウィジェット** | サイズ別グリッド；明暗サムネ切替；検索；手動/名前/新しい/古い sort。サムネは **ラスタキャッシュ** でスムーズスクロール。 |
| **操作** | ボード画像共有、名前変更、複製、削除（確認）。古いウィジェット参照は **失効デザイン** バナー → **ウィジェットガイド**。 |

## ブロックエディタ

- **グリッド** — ドラッグ・リサイズ；削除、同サイズ置換；**最近** ブロック種を記憶。
- **レイアウト** — **4×4**、**8×4**、**8×8** 別レイアウトを 1 デザインに保存。
- **外観** — ブロックごと配置、文字色/サイズ（高さ比含む）、塗り role/不透明度/角丸/パディング、枠（実線/破線/点線）、影；**外観コピー**；**全ブロックに既定外観**。
- **背景** — 単色、グラデ、**壁紙**（全体またはデザイン別スクショ）；**12 色プリセット**；任意 **色の説明**（対応端末の Apple Intelligence）。
- **動作** — 週始まり上書き；**タップインターセプト**；低コントラストヒントと修正メニュー。
- **Undo** — 30 段；エディタからボード画像共有。

### ブロックファミリー（概要）

| ファミリー | 例 |
|------------|-----|
| **西暦** | 日数字スタイル、日付、曜日、休/班、日メモ、月グリッド、週ストリップ、年進捗 |
| **农历** | 农历行、干支、次の祝日/節気、祝日カウントダウン、黄历、節気詩/区間/物候、月相 |
| **時計** | デジタル、アナログ |
| **天気** | レイアウト段、時間数、詳細 toggles、降水 |
| **カウントダウン** | タイトル+日数 / 日数のみ / 大数字；ウィジェット上サイクル |
| **デバイス (iOS)** | バッテリー、ストレージ、Now Playing、Health 歩数 — アプリ＋BG 更新 |
| **装飾** | テキスト、区切り、ステッカー (SF Symbols)、挨拶 |

ライブラリ/アプリ内プレビューは **サンプルデータ**；**ホームウィジェットはライブデータのみ**。

## 通知（任意）

ローカル通知のみ — 最大 **48** 件：

- 夕方 **20:00** — 翌日 **休/班** 入替、祝日開始、祭日、節気（**21 日**以内）。
- カウントダウン当日 **09:00**。

**設定 → 通知** でカテゴリ切替。

## 設定ハイライト

- **外観** — ライト/ダーク/システム；**アプリ内言語**（システム/简体/繁體/English）；大文字；月曜始まり；°C/°F；祝日レイヤー；天気の **位置または手動都市**；壁紙；歩数用 Health (iOS)。
- **iCloud** — 既定オフ；オンで **CloudKit** 私有 DB 経由でデザイン JSON とクロップ壁紙（Apple ID）。
- **データ** — ウィジェットタイムライン再読込；天気キャッシュ削除。
- **この App について** — 評価、任意チップ、診断付き feedback、他アプリ、ライセンス。

## Siri、ショートカット、URL

- 組み込みフレーズ例：*「iWidget の今日の农历」*、*「iWidget の次の祝日」*。
- 別 **Workday** App Intent — **日付** が休/班か（Shortcuts で手動追加）。
- Deep link：`iwidget://today`、`iwidget://day?y=&m=&d=`、`iwidget://settings?scroll=festivals` — [URL Scheme](url-scheme)。

## データとプライバシー

- 农历、黄历、節気表は **端末内計算**（iHTC Studio iCalendar 系譜に整合；**UI/ウィジェットは別製品**）。
- 天気はオンライン時 **Apple WeatherKit**；App Group キャッシュ。
- **iHTC Studio アカウントなし。** 任意 iCloud は Apple ホスト。詳細：[Privacy Policy](privacy)。
