**배경화면에 맞추세요. 원하는 위젯을 만드세요.**

**iWidget**(爱组件 / 愛組件)은 **iPhone, iPad, Mac**용 **위젯 디자인 스튜디오**입니다. 캘린더·날씨·카운트다운·기기 정보는 그리드 **데이터 블록**. **54 프리셋 세트**(126 크기), **블록 편집기**, **슬롯별 배경 크롭**, **투명** 홈 위젯, **탭 차단**.

App Store 유료. **기능 잠금 IAP 없음** — **설정 → 정보**의 선택 Tip.

## 시작하기
1. **첫 실행 가이드**. **내 위젯** 비면 Calendar/Weather/Month 자동 시드.
2. **오늘** — 양력·음력, 공휴일, 黄历, 날씨, 카운트다운.
3. **위젯 라이브러리** — 카테고리, 검색, S/M/L 미리보기, **추가** / **추가 및 편집**.
4. **내 위젯** — 크기별 그리드, 라이트/다크, 검색·정렬.
5. 홈 화면 길게 누르기 → **＋** → **iWidget** → 크기 → **위젯 편집** → 저장 디자인.
6. **설정 → 도움말**.

## 에디터·홈·잠금화면·Mac
블록 패밀리(양력/음력/시계/날씨/카운트다운/기기/장식). 홈 S/M/L, 잠금 화면, Control Center(iOS 18+), StandBy, Mac 메뉴 막대. **투명 위젯**.
