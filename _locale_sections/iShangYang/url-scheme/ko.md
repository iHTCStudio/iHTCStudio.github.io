short / iShangYang 지원 ** `ishangyang://` ** 단축 링크 (URL 계획). 콜드 시작 및 홈 화면 단축은 통합 버퍼를 통해 전달되므로 링크가 내장 된 후 두 번 열리지 않습니다.

## 링크 형식


```
ishangyang://{host}?{params}
```

| URL | 열리는 화면 |
|-----|-------|

| `ishangyang://fables` / `ishangyang://edict?id=` | 관련 기사 |
| `ishangyang://chronicle` / `ishangyang://timeline` | 만성질환 |
| `ishangyang://figures` / `ishangyang://figure?id=` | 사이트맵 |
| `ishangyang://study` | 연구분야 |
| `ishangyang://hunt` | 폴란드 이동 |
