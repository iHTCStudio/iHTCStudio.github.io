* `ishangyang://` ** ショートカットリンク(URLスキーム)をサポートしています。 コールドスタートとホーム画面のショートカットは、統一されたバッファを介して配信されますので、リンクはオンボーディング後2回開いていません。

## リンク形式


```
ishangyang://{host}?{params}
```


## ユニークなデスク

| URL | 開く画面 |
|-----|-------|
| `ishangyang://daily` | 毎日の改革 |
| `ishangyang://fables` / `ishangyang://edict?id=` | 予測の改革 |
| `ishangyang://chronicle` / `ishangyang://timeline` | 慢性的な変形 |
| `ishangyang://figures` / `ishangyang://figure?id=` | プロフィール |
| `ishangyang://study` | 研究改革 |
| `ishangyang://hunt` | ポールの移動 |
