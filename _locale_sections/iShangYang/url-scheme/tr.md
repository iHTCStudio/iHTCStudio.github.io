). / iShangYang, ** `ishangyang://` ** kısayol bağlantıları (URL planı). Soğuk başlangıç ve Ev Ekran kısayolları birleşik bir tampon aracılığıyla teslim edilir, bu yüzden bağlantılar gemiden sonra iki kez açılmaz.

## Bağlantı biçimi


```
ishangyang://{host}?{params}
```


## Benzersiz masası

| URL | Açar |
|-----|-------|
| `ishangyang://daily` | Günlük Reform |
| `ishangyang://fables` / `ishangyang://edict?id=` | Reform edicts |
| `ishangyang://chronicle` / `ishangyang://timeline` | Reform kronik |
| `ishangyang://figures` / `ishangyang://figure?id=` | Şekiller Şekiller |
| `ishangyang://study` | Reform Çalışması |
| `ishangyang://hunt` | Polen |
