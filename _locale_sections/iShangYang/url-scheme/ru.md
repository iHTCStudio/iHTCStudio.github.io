). / iShangYang поддерживает ярлыки ** `ishangyang://` ** (схема URL). Холодный старт и ярлыки домашнего экрана доставляются через единый буфер, поэтому ссылки не открываются дважды после входа.

## Формат ссылки


```
ishangyang://{host}?{params}
```


## Уникальный стол

| URL | Открывает |
|-----|-------|
| `ishangyang://daily` | Ежедневная реформа |
| `ishangyang://fables` / `ishangyang://edict?id=` | Указы о реформе |
| `ishangyang://chronicle` / `ishangyang://timeline` | Хроника реформ |
| `ishangyang://figures` / `ishangyang://figure?id=` | Рисунки |
| `ishangyang://study` | Исследование реформ |
| `ishangyang://hunt` | Перемещение полюса |
