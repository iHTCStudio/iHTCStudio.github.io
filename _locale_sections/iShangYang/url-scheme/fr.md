Le logiciel iShangYang prend en charge les liens de raccourci ** `ishangyang://` ** (système URL). Les raccourcis de démarrage à froid et d'écran d'accueil sont livrés via un tampon unifié de sorte que les liens ne sont pas ouverts deux fois après l'embarquement.

## Format de lien


```
ishangyang://{host}?{params}
```


## Bureau unique

| URL | Ouvre |
|-----|-------|
| `ishangyang://daily` | Réforme quotidienne |
| `ishangyang://fables` / `ishangyang://edict?id=` | Réformes |
| `ishangyang://chronicle` / `ishangyang://timeline` | Chronique de la réforme |
| `ishangyang://figures` / `ishangyang://figure?id=` | Chiffres |
| `ishangyang://study` | Étude sur la réforme |
| `ishangyang://hunt` | Déplacement du pôle |
