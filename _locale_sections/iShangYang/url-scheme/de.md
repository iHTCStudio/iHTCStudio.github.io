爱商鞅 / iShangYang unterstützt ** `ishangyang://` ** Shortcut Links (URL-Schema). Kaltstart- und Home Screen-Verknüpfungen werden über einen einheitlichen Puffer geliefert, so dass Links nach dem Onboarding nicht zweimal geöffnet werden.

## Linkformat


```
ishangyang://{host}?{params}
```


## Einzigartiger Schreibtisch

| URL | Öffnet |
|-----|-------|
| `ishangyang://daily` | Tägliche Reform |
| `ishangyang://fables` / `ishangyang://edict?id=` | Reformedikte |
| `ishangyang://chronicle` / `ishangyang://timeline` | Reformchronik |
| `ishangyang://figures` / `ishangyang://figure?id=` | Zahlen |
| `ishangyang://study` | Reformstudie |
| `ishangyang://hunt` | Die Pole bewegen |
