爱商鞅 / iShang Language รองรับ~ `ishangyang://` BAR * ลิงก์ลัด (URL scheme). การเริ่มหน้าจอหน้าจอเย็นและหน้าจอบ้าน จะถูกส่งไปผ่านระบบบัฟเฟอร์แบบรวม ดังนั้นลิงก์จึงไม่ถูกเปิดสองครั้งหลังจากขึ้นเครื่อง

## รูปแบบลิงก์


```
ishangyang://{host}?{params}
```


## โต๊ะยูนิโค้ด

| URL | เปิด |
|-----|-------|
| `ishangyang://daily` | การ ปฏิรูป ทุก วัน |
| `ishangyang://fables` / `ishangyang://edict?id=` | ราช กฤษฎีกา ปฏิรูป |
| `ishangyang://chronicle` / `ishangyang://timeline` | บันทึก การ ปฏิรูป |
| `ishangyang://figures` / `ishangyang://figure?id=` | ตัวเลข |
| `ishangyang://study` | การ ศึกษา คัมภีร์ ไบเบิล |
| `ishangyang://hunt` | การ ย้าย โปแลนด์ |
