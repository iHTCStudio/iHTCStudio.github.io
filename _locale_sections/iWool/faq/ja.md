### iWool は iPad で動作しますか?

はい。 iWool は **iPhone および iPad** (iOS 15.0 以降) 用のユニバーサル アプリです。レイアウトは iPad の画面サイズに適応します。ウィジェットとライブ アクティビティは iPhone と同じルールに従います。

### iWool にはアカウントやインターネット接続が必要ですか?

いいえ、iWool は完全にオフラインで動作します。すべてのデータは SQLite を使用してデバイスにローカルに保存されます。どの機能を使用する場合でも、アカウント、サインアップ、ネットワーク接続は必要ありません (アプリ内で http/https リンクを開く場合を除く)。

### 私のデータはどこに保存されますか?安全ですか？

すべてのデータ (アクティビティ、リマインダー、収益記録、繰り返し状態) は、デバイス上のローカル SQLite データベースに保存されます。どのサーバーにも何もアップロードされません。アプリをアンインストールするとデータは削除されます。 **[設定] → [データ] → [完全バックアップのエクスポート]** を使用して定期的にバックアップしてください。

### データをバックアップおよび復元するにはどうすればよいですか?

**[設定] → [データ] → [完全バックアップのエクスポート]** に移動して、CSV ファイルを生成します。ファイルに保存するか、Mac に AirDrop で保存するか、電子メールで送信します。

復元するには、**設定 → データ → バックアップのインポート** に移動し、ファイルを選択します。次のいずれかを選択するように求められます。

- **すべてのデータを置換** — すべてをクリアし、バックアップから復元します。機種変更時や再インストール時にご利用ください。
- **追加のみ (既存を維持)** — デバイス上の何も削除せずに、バックアップ アクティビティを新しいレコードとして挿入します。これを使用して、別のデバイスからのデータを結合します。

### 定期的なアクティビティはどのように機能しますか?

繰り返しルール (毎日、毎週、毎月、毎年、またはカスタム間隔) を設定すると、iWool は 1 つのマスター レコードを保存し、それを毎日の個別の発生に仮想的に拡張します。リストとカレンダーには、定期的なシリーズの今日の出来事が常に表示されます。

特定の日の出来事を完了としてマークするには、長押しメニューまたは詳細ページ下部のツールバーを使用します。それはその日だけを示しています。シリーズは続きます。

### リマインダーが表示されないのはなぜですか?

iOS では、各アプリが一度に保留中のローカル通知を約 64 件に制限しています。 iWool は非定期的なアクティビティを優先し、定期的なアクティビティについては最大 120 日間の将来のアクティビティをスケジュールしますが、非常に大規模な定期的なリマインダーのコレクションはトリミングされる場合があります。

**[設定] → [通知] → [スケジュールされたローカル リマインダー]** を確認して、現在どのリマインダーが登録されているかを正確に確認してください。

以下も確認してください。

- 通知許可が付与されます (iOS 設定 → iWool → 通知)。
- アクティビティはキャンセルされません (キャンセルされたアクティビティのリマインダーは自動的に消去されます)。
- リマインダーの時刻は未来です。

### 「推定収益」と「実績収益」の違いは何ですか？

- **推定収益** — アクティビティ フォームに入力します。アクティビティカードに表示されます。統計にはカウントされません。
- **記録された収益** — 収益フォームを介してアクティビティの詳細ページに入力されます。これらは、すべての統計合計、トレンド チャート、プラットフォーム ランキングでカウントされた実際の金額です。

### 定期的なアクティビティの特定の日の収益を記録するにはどうすればよいですか?

その日のアクティビティの詳細を開きます (その日のリストまたはカレンダー内のアクティビティをタップします)。詳細ページの収益セクションで [**記録**] をタップします。記録日はデフォルトでその日の発生日になります。

### アクティビティに影響を与えずに単一の収益エントリを削除できますか?

はい。アクティビティの詳細を開き、編集する収益行をタップし、編集フォームを一番下までスクロールします。 [**この収益記録を削除**] をタップして確認します。その 1 つのエントリのみが削除されます。アクティビティとその他すべての記録は変更されません。

### 統計グラフに日本円 (JPY) / 韓国ウォン (KRW) の誤った金額が表示されています。

これらの通貨にはデフォルトで小数点以下の桁がないため、古いバージョンでは金額が整数として表示される可能性があります。現在のバージョンでは、小数点以下の桁数を個別に設定できます。

- **[設定] → [外観と言語] → [金額の小数点以下の桁数]** に移動して、すべての金額表示の小数点以下の桁数を設定します (デフォルト: 2)。
- **[設定] → [外観と言語] → [グラフの小数点以下の桁数]** に移動して、グラフの棒ラベルの小数点以下の桁数を具体的に設定します (デフォルト: 0)。

### ダイナミックアイランド/ライブアクティビティ機能を使用するにはどうすればよいですか?

**イベント カウントダウン** (iOS 16.1 以降、サポートされている iPhone): **[設定] → [通知] → [ライブ アクティビティ]** で有効にします。リードタイムを設定します (1 ～ 480 分)。ウィンドウ内のアクティビティは自動的に選択されます。ホームまたはカレンダーを長押し → **ダイナミックアイランドに追加**。

**クイック カウントダウン** (iOS 16.2 以降): **アクティビティ データベースに関連付けられていない**スタンドアロン**アイランド タイマー**。 **[設定] → [アイランド リマインダー]** を開き、ホーム画面のクイック アクション、または `iwool://island` を使用します。持続時間 **1 秒～8 時間**;オプションのタイトル、メモ、アクセントカラー。終了すると、ライブ アクティビティは終了します。ウール アクティビティを個別に作成しない限り、何も保存されません。

### クイック カウントダウンとイベント ライブ アクティビティとは何ですか?

|  | イベントカウントダウン | クイックカウントダウン |
|---|-----------------|-----------------|
| アクティビティにリンク | はい | いいえ |
| アプリ内に保持される | はい | いいえ |
| 最小iOS | 16.1 | 16.2 |
| 始め方 | 自動または長押しアクティビティ | 設定 / ショートカット / `iwool://island` |

### ホーム画面のクイックアクションはどのように機能しますか?

Long-press the iWool icon (iOS). Choose up to **4** from **9** presets in **Settings → Tools → Home Screen Shortcuts**: Home, Calendar, Statistics, Quick Countdown, New Activity, Scheduled Reminders, Scanner, Rate, Feedback. Default: Home, Calendar, Statistics, Quick Countdown. Each uses an `iwool://` URL.

### How do `iwool://` deep links work?

iWool は、ウィジェット、ショートカット、およびクイック アクションで使用される、タブ、アクション、およびイベントの詳細に対して **`iwool://`** をサポートします。例:

- `iwool://home`, `iwool://calendar`, `iwool://stats`, `iwool://settings`
- `iwool://new`, `iwool://island`, `iwool://scanner`, `iwool://reminders`
- `iwool://event/42`、`iwool://event/42?day=189345600` (繰り返し発生)

不明なパスは無視されます (ホームへのサイレント リダイレクトはありません)。完全な [**URL スキーム リファレンス**](../url-scheme) を参照してください。

### アクティビティや統計情報を画像として共有するにはどうすればよいですか?

アクティビティの詳細ページまたは [**統計**] タブのツールバーから、[**共有**] を使用してブランド付きの **PNG 画像カード** (グラデーション、QR コード、[設定] で有効になっている場合はオプションの収益) をレンダリングします。画像はデバイス上で生成されます。写真に保存すると、写真ライブラリへのアクセスが要求される場合があります。

### iWool にはウィジェットがいくつ含まれていますか?

**12 ウィジェット ファミリ** — 8 つのホーム画面ウィジェット (今日のアクティブ、今日のすべて、今日の今後のウィジェット、すべてのイベント、統計概要、収益、概要、トップ プラットフォーム) と 4 つのロック画面アクセサリ スタイル (iOS 16 以降)。

### ホーム画面またはロック画面にウィジェットを追加するにはどうすればよいですか?

詳しい手順は、アプリ内の**設定 → ウィジェット → ウィジェット ガイド**でご覧いただけます。要するに:

1. ホーム画面の何もない領域を長押しし、**+** ボタンをタップします。
2. ウィジェット ギャラリーで **iWool** を検索します。
3. ウィジェットのスタイルとサイズを選択し、[**ウィジェットを追加**] をタップします。

ロック画面ウィジェット (iOS 16 以降) の場合: ロック画面を長押しし、**カスタマイズ** をタップして、iWool ウィジェットをロック画面ウィジェット行に追加します。

### ウィジェットに古いデータが表示されるのはなぜですか?

ウィジェットは、アプリを開いたとき、またはデータが変更されたときに更新されます。また、iOS はウィジェットのタイムラインをバックグラウンドで定期的に更新します (最大で約 15 分ごと)。ウィジェットが古い場合は、iWool を一度開いて強制的に更新してください。

### 表示言語を変更するにはどうすればよいですか?

**[設定] → [外観と言語] → [表示言語]** に移動します。デバイスのシステム言語とは関係なく、13 言語から選択できます。

英語、簡体字中国語、繁体字中国語、日本語、韓国語、タイ語、ヒンディー語、スペイン語、フランス語、ドイツ語、ポルトガル語（ブラジル）、ロシア語、アラビア語。

変更はアプリ全体ですぐに有効になります。

### 収益額を共有せずにアクティビティを共有できますか?

はい。デフォルトでは、アクティビティをコピーまたは共有しても、収益記録は含まれません。これらを含める場合は、**[設定] → [外観と言語]** に移動し、**共有時に収益を含める** を有効にします。

### QRコードまたはバーコードをスキャンするにはどうすればよいですか?

**[設定] → [ツール] → [QR/バーコード スキャナー]** に移動します。カメラをコードに向けるか、アルバム アイコンをタップして画像を選択します。結果はリストに表示され、コピーしたり、Safari で開くことができます。

アクティビティ フォームから直接スキャンすることもできます。アクティビティ URL フィールドに入力するときに、その横にあるスキャン アイコンをタップしてコードをスキャンし、URL を自動的に入力します。

### 「アーカイブ」とはどういう意味ですか?削除と同じですか？

いいえ。アーカイブすると、アクティビティは削除されずにメイン リストから非表示になります。アーカイブされたアクティビティは、**[設定] → [アクティビティ管理] → [アーカイブされたアクティビティ]** から表示、復元、または削除できます。

完了したアクティビティ、期限切れのアクティビティ、またはキャンセルされたアクティビティを長押しすると、アーカイブ オプションが表示されます。完了したアクティビティ、期限切れのアクティビティ、およびキャンセルされた非定期アクティビティをすべて一度にアーカイブするには、**[設定] → [アクティビティ管理] → [完了したすべてのアクティビティをアーカイブ]** を使用します。

### まだ助けが必要ですか?

[AppleOSer@gmail.com](mailto:AppleOSer@gmail.com) までお問い合わせいただくか、アプリ内の **[設定] → [フィードバックを送信]** オプションを使用してください。通常、48 時間以内に返信いたします。
