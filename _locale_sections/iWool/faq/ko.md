### iWool은 iPad에서 작동하나요?

예. iWool은 **iPhone 및 iPad**(iOS 15.0+)용 범용 앱입니다. 레이아웃은 iPad 화면 크기에 맞게 조정됩니다. 위젯과 라이브 활동은 iPhone과 동일한 규칙을 따릅니다.

### iWool에는 계정이나 인터넷 연결이 필요합니까?

아니요. iWool은 완전히 오프라인으로 작동합니다. 모든 데이터는 SQLite를 사용하여 장치에 로컬로 저장됩니다. 모든 기능을 사용하려면 계정, 가입, 네트워크 연결이 필요하지 않습니다(앱 내에서 http/https 링크 열기 제외).

### 내 데이터는 어디에 저장되나요? 안전합니까?

활동, 알림, 수입 기록, 반복 상태 등 모든 데이터는 장치의 로컬 SQLite 데이터베이스에 저장됩니다. 어떤 서버에도 아무것도 업로드되지 않습니다. 앱을 제거하면 데이터가 삭제됩니다. **설정 → 데이터 → 전체 백업 내보내기**를 사용하여 정기적으로 백업하세요.

### 데이터를 어떻게 백업하고 복원하나요?

**설정 → 데이터 → 전체 백업 내보내기**로 이동하여 CSV 파일을 생성하세요. 파일에 저장하거나 Mac에 AirDrop하거나 이메일로 보내세요.

복원하려면 **설정 → 데이터 → 백업 가져오기**로 이동하여 파일을 선택하세요. 다음 중에서 선택하라는 메시지가 표시됩니다.

- **모든 데이터 교체** — 모든 데이터를 지우고 백업에서 복원합니다. 기기를 전환하거나 재설치할 때 사용하세요.
- **추가만(기존 유지)** — 장치에서 아무것도 삭제하지 않고 백업 활동을 새 기록으로 삽입합니다. 이를 사용하여 다른 장치의 데이터를 병합합니다.

### 반복 활동은 어떻게 진행되나요?

반복 규칙(일일, 주간, 월간, 연간 또는 사용자 정의 간격)을 설정하면 iWool은 하나의 마스터 레코드를 저장하고 매일 개별 발생으로 가상으로 확장합니다. 목록과 달력에는 반복되는 시리즈에 대해 항상 오늘의 항목이 표시됩니다.

특정 날짜의 발생을 완료로 표시하려면 길게 누르기 메뉴나 세부정보 페이지 하단 도구 모음을 사용하세요. 그것은 그날만을 의미합니다. 시리즈는 계속됩니다.

### 알림이 표시되지 않는 이유는 무엇입니까?

iOS는 각 앱을 한 번에 보류 중인 로컬 알림을 약 64개로 제한합니다. iWool은 반복되지 않는 활동과 향후 최대 120일의 반복 활동 일정에 우선순위를 두지만 매우 큰 반복 알림 모음은 잘릴 수 있습니다.

**설정 → 알림 → 예약된 로컬 알림**을 확인하여 현재 어떤 알림이 등록되어 있는지 정확하게 확인하세요.

또한 다음 사항을 확인하세요.

- 알림 권한이 부여됩니다(iOS 설정 → iWool → 알림).
- 활동은 취소되지 않습니다(취소된 활동의 미리 알림은 자동으로 지워집니다).
- 알림 시간이 미래입니다.

### '예상 수익'과 '기록 수익'의 차이점은 무엇인가요?

- **예상 수입** — 활동 양식에 입력됩니다. 활동 카드에 표시됩니다. 통계에는 포함되지 않습니다.
- **기록된 수입** — 수입 양식을 통해 활동 세부정보 페이지에 입력됩니다. 이는 모든 통계 합계, 추세 차트 및 플랫폼 순위에 계산된 실제 금액입니다.

### 반복 활동의 특정 날짜에 대한 수입을 어떻게 기록합니까?

해당 날짜에 대한 활동 세부 정보를 엽니다(해당 날짜의 목록이나 달력에서 활동을 탭합니다). 세부정보 페이지의 수익 섹션에서 **기록**을 탭하세요. 기록 날짜는 기본적으로 해당 날짜의 발생 날짜로 설정됩니다.

### 활동에 영향을 주지 않고 단일 수입 항목을 삭제할 수 있습니까?

예. 활동 세부정보를 열고 편집하려는 수입 행을 탭한 다음 편집 양식에서 아래쪽으로 스크롤합니다. **이 수익 기록 삭제**를 탭하고 확인하세요. 해당 항목 하나만 제거됩니다. 활동 및 기타 모든 기록은 그대로 유지됩니다.

### 통계 차트에 일본 엔(JPY)/한국 원(KRW) 금액이 잘못 표시되어 있습니다.

이러한 통화에는 기본적으로 소수 자릿수가 없으므로 이전 버전에서는 금액이 정수로 표시될 수 있습니다. 현재 버전에서는 소수 자릿수를 독립적으로 구성할 수 있습니다.

- **설정 → 모양 및 언어 → 소수점 이하 금액**으로 이동하여 모든 금액 표시의 소수점 이하 자릿수를 설정하세요(기본값: 2).
- 차트 막대 레이블의 소수 자릿수를 구체적으로 설정하려면 **설정 → 모양 및 언어 → 차트 소수점 이하 자릿수**로 이동하세요(기본값: 0).

### 다이내믹 아일랜드/라이브 액티비티 기능은 어떻게 사용하나요?

**이벤트 카운트다운**(iOS 16.1+, iPhone 지원): **설정 → 알림 → 라이브 활동**에서 활성화하세요. 리드 타임(1~480분)을 설정합니다. 창의 활동은 자동으로 선택됩니다. 홈이나 캘린더를 길게 누르세요 → **다이내믹 아일랜드에 추가**.

**빠른 카운트다운**(iOS 16.2+): **독립형** 섬 타이머 **활동 데이터베이스에 연결되지 않음**. **설정 → 섬 알림**을 열고 홈 화면 빠른 동작 또는 `iwool://island`를 사용하세요. 지속 시간 **1초 ~ 8시간**; 선택적인 제목, 메모 및 강조 색상. 종료되면 라이브 활동이 닫힙니다. Wool 활동을 별도로 생성하지 않는 한 아무것도 저장되지 않습니다.

### 빠른 카운트다운과 이벤트 라이브 활동이란 무엇입니까?

|  | 이벤트 카운트다운 | 빠른 카운트다운 |
|---|-----------------|-----------------|
| 활동에 연결됨 | 예 | 아니요 |
| 앱에서 지속됨 | 예 | 아니요 |
| 최소 iOS | 16.1 | 16.2 |
| 시작하는 방법 | 자동 또는 길게 누르기 활동 | 설정/바로가기/`iwool://island` |

### 홈 화면 빠른 작업은 어떻게 작동하나요?

iWool 아이콘(iOS)을 길게 누르세요. **설정 → 도구 → 홈 화면 바로가기**: 홈, 달력, 통계, 빠른 카운트다운, 새 활동, 예약된 알림, 스캐너, 속도, 피드백의 **9** 사전 설정 중에서 최대 **4**를 선택하세요. 기본값: 홈, 달력, 통계, 빠른 카운트다운. 각각 `iwool://` URL을 사용합니다.

### `iwool://` 딥링크는 어떻게 작동하나요?

iWool은 위젯, 바로가기 및 빠른 동작에서 사용되는 탭, 작업 및 이벤트 세부정보에 대해 **`iwool://`**을 지원합니다. 예:

- `iwool://home`, `iwool://calendar`, `iwool://stats`, `iwool://settings`
- `iwool://new`, `iwool://island`, `iwool://scanner`, `iwool://reminders`
- `iwool://event/42`, `iwool://event/42?day=189345600` (반복발생)

알 수 없는 경로는 무시됩니다(홈으로 자동 리디렉션되지 않음). 전체 [**URL 체계 참조**](../url-scheme)를 확인하세요.

### 활동이나 통계를 이미지로 공유하려면 어떻게 해야 하나요?

활동 세부정보 페이지 또는 **통계** 탭 도구 모음에서 **공유**를 사용하여 브랜드 **PNG 이미지 카드**(설정에서 활성화된 경우 그라데이션, QR 코드, 선택적 수입)를 렌더링합니다. 이미지는 기기에서 생성됩니다. 사진에 저장하면 사진 라이브러리 액세스가 필요할 수 있습니다.

### iWool에는 몇 개의 위젯이 포함되어 있나요?

**12가지 위젯 제품군** — 8가지 홈 화면 위젯(오늘 활성, 오늘 전체, 오늘 예정, 모든 이벤트, 통계 개요, 수익, 한눈에 보기, 상위 플랫폼)과 4가지 잠금 화면 액세서리 스타일(iOS 16+).

### 홈 화면이나 잠금 화면에 위젯을 어떻게 추가하나요?

자세한 단계별 안내는 앱 내 **설정 → 위젯 → 위젯 가이드**에서 확인하실 수 있습니다. 간단히 말해서:

1. 홈 화면의 빈 공간을 길게 누르고 ****버튼을 탭하세요.
2. 위젯 갤러리에서 **iWool**을 검색하세요.
3. 위젯 스타일과 크기를 선택한 다음 **위젯 추가**를 탭하세요.

잠금 화면 위젯(iOS 16 이상): 잠금 화면을 길게 누르고 **사용자 지정**을 탭한 다음 iWool 위젯을 잠금 화면 위젯 행에 추가합니다.

### 위젯에 오래된 데이터가 표시되는 이유는 무엇입니까?

앱을 열거나 데이터가 변경되면 위젯이 새로 고쳐집니다. iOS는 또한 백그라운드에서 주기적으로 위젯 타임라인을 새로 고칩니다(최대 15분마다). 위젯이 오래된 경우 iWool을 한 번 열어 강제로 새로 고치세요.

### 표시 언어를 어떻게 변경하나요?

**설정 → 모양 및 언어 → 표시 언어**로 이동하세요. 장치의 시스템 언어와 관계없이 13개 언어 중에서 선택할 수 있습니다.

영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 태국어, 힌디어, 스페인어, 프랑스어, 독일어, 브라질 포르투갈어, 러시아어, 아랍어.

변경 사항은 앱 전체에 즉시 적용됩니다.

### 수입 금액을 공유하지 않고 활동을 공유할 수 있나요?

예. 기본적으로 활동 복사 또는 공유에는 수입 기록이 포함되지 않습니다. 이를 포함하려면 **설정 → 모양 및 언어**로 이동하여 **공유 시 수익 포함**을 활성화하세요.

### QR 코드나 바코드를 어떻게 스캔하나요?

**설정 → 도구 → QR/바코드 스캐너**로 이동합니다. 카메라로 코드를 가리키거나 앨범 아이콘을 탭하여 이미지를 선택하세요. 결과는 Safari에서 복사하거나 열 수 있는 목록에 나타납니다.

활동 양식에서 직접 스캔할 수도 있습니다. 활동 URL 필드를 채울 때 옆에 있는 스캔 아이콘을 탭하면 코드를 스캔하고 URL이 자동으로 채워집니다.

### "아카이브"은(는) 무슨 뜻인가요? 삭제랑 똑같나요?

아니요. 보관처리하면 활동을 삭제하지 않고 기본 목록에서 숨깁니다. 보관된 활동은 **설정 → 활동 관리 → 보관된 활동**에서 확인, 복원 또는 삭제할 수 있습니다.

완료, 만료 또는 취소된 활동을 길게 누르면 보관 옵션이 표시됩니다. 완료, 만료, 취소된 비반복 활동을 모두 한 번에 보관하려면 **설정 → 활동 관리 → 완료된 모든 활동 보관**을 사용하세요.
