iWool is a privacy-first local tracker built for capturing deals, following activities and counting earnings on **iPhone and iPad**. **`iwool://` deep links** open Home, Calendar, Statistics, Settings, in-app actions (new activity, Quick Countdown, scanner, reminders) or a specific activity — from widgets, Shortcuts or Home Screen Quick Actions. **No sign-up, no upload — your data stays on-device.**

サポートされているすべてのパスとエイリアスについては、完全な [**`iwool://` URL スキーム リファレンス**](url-scheme) を参照してください。

## はじめに

1. ホーム画面で [**+**] をタップして、最初のアクティビティを作成します。
2. タイトル、プラットフォーム、開始時間と終了時間を入力します。必要に応じてリマインダーを追加します。
3. [**保存**] をタップします。アクティビティがステータスごとにグループ化されてリストに表示されます。
4. 取引が成功したら、詳細ページをタップして、**収益を記録** をタップします。
5. **統計**をいつでもチェックして、合計、傾向、プラットフォームのランキングを確認してください。
6. ホーム画面またはロック画面ウィジェットを追加すると、アプリを開かなくても最新の状態を維持できます。

## 特長

### ホーム画面

- **7 つのステータス概要カード** — アクティブ、今後、すべて、期限切れ、完了、キャンセル、一時停止。任意のカードをタップすると、すぐにフィルタリングできます。もう一度タップすると、今日に戻ります。
- **発効日を指定して一時停止またはキャンセル** — 今日/カレンダーから非表示にし、収益履歴を保持しながらリマインダーを停止します。
- **アクティビティ共有エクスポート** — 友人がインポートしてフォローできる共有パックをエクスポートします (完全バックアップとは別に)。
- **全文検索** — タイトル、メモ、プラットフォーム、要件、ルールを横断して検索します。
- **長押しアクション** — 完了のマーク、一時停止/再開、キャンセル/復元、アーカイブ、新規として複製、または削除。
- 定期的なアクティビティには常に **今日の出来事** が表示されるため、ステータスと時間が実際のスケジュールと一致します。

### カレンダー

- **月表示**と**週タイムライン**を切り替えると、設定が記憶されます。
- 日付をタップすると、その日のアクティビティが表示されます。ドットと左側のバーの色はプラットフォームの色に従います。
- リストの任意の行を長押しすると、ホーム画面と同じクイック アクションが実行されます。
- いつでも引っ張ってリフレッシュできます。

### 活動詳細

- **カウントダウンで開始** — 現在または次の発生までの時間を表示します。 24 時間未満の場合はオレンジ色でハイライトされます。
- **次回の発生日**は、定期的なアクティビティの場合に表示されます。シリーズが終了すると「次の出現はありません」。
- アクティビティ URL、要件、ルール、メモはすべてリンクを表示します。 **シングルタップ** Safari (http/https) または関連アプリで開きます。 **長押し**すると、「[App]で開く」、「Safariで開く」、「リンクのコピー」、「共有」などのネイティブiOSリンクメニューが表示されます。

### 記録的な収益

- 金額、オプションのメモ、**記録日**を記載した半紙形式。
- アクティビティごとに複数のエントリがあり、それぞれ独立して編集または削除できます。
- 収益は、ここに記録された場合にのみ統計に表示されます。推定収益は表示のみを目的としています。

### 統計

- 今日、今週、今月、今年の合計。
- **月次傾向グラフ** — 任意のバーをタップすると (金額 > 0 の場合)、その期間のすべての収益エントリが表示されます。
- **プラットフォーム ランキング** — 独立した時間範囲セレクター (年/月/週)。プラットフォームの行をタップすると、エントリごとの詳細が表示されます。
- **アクティビティの概要** — ステータス行または合計行をタップすると、一致するアクティビティ リストが表示されます。
- 定期的なアクティビティの収益ポリシー (厳格または寛大) は、[設定] で構成できます。

### リマインダー

- アクティビティごとに複数のリマインダー — 開始時、開始前、締め切り前、または毎日の固定時間。
- システムのローカル通知。アプリを開くたびに、リマインダーのスケジュールが整理されます。
- キャンセルされたアクティビティの呼び出し音は自動的に停止します。
- ホームとカレンダーのリスト行には **小さなリマインダー グリフ**が表示されるので、何がスケジュールされているかが一目でわかります。

### 画像カードを共有する

**アクティビティ**または**統計ダッシュボード**を**ブランドのPNG画像カード**としてシステム共有シート(グラデーション背景、App Store QRコード、オプションの透かし)を介して共有します。 [設定] で共有カードに収益を表示するかどうかを切り替えます (**デフォルトではオフ**)。画像はデバイス上でレンダリングされます。何もアップロードされていません。 「写真に保存」では、フォト ライブラリへのアクセスが要求される場合があります。

### ホーム画面のクイックアクション

iOS で iWool アイコンを長押しすると、最大 **4** のショートカットが起動します。 **[設定] → [ツール] → [ホーム画面のショートカット]** で **9** プリセットから選択します。

ホーム · カレンダー · 統計 · **クイックカウントダウン** · 新しいアクティビティ · スケジュールされたリマインダー · スキャナ · アプリの評価 · フィードバック

Default: **Home, Calendar, Statistics, Quick Countdown**. Each action uses an `iwool://` URL (same router as widgets and Shortcuts).

### ダイナミックな島とライブアクティビティ

サポートされている iPhone モデルの 2 つのライブ アクティビティ タイプ:

**1.イベントカウントダウン** (iOS 16.1以降)

- Wool アクティビティに関連付けられています — **[設定] → [通知] → [ライブ アクティビティ]** で有効にします。
- **リードタイム** (開始の 1 ～ 480 分前) を調整します。複数のウィンドウ内アクティビティでそれぞれ島を表示したり、回転したりできます。
- ホームまたはカレンダーで対象となるアクティビティを長押し → **ダイナミックアイランドに追加**。

**2.クイックカウントダウン** (iOS 16.2以降)

- **スタンドアロン** アイランド / ロック画面のカウントダウン — **アクティビティ データベースに保存されません**。
- **設定 → アイランドリマインダー** または `iwool://island` / ホーム画面のクイックアクションから作成します。
- 期間 **1 秒～8 時間** — プリセットチップ (30 秒、1 ～ 480 分) または期限を選択します。オプションのタイトル、メモ、アクセントカラー、秒表示。
- 時間が経過すると自動的に終了します。フラッシュセール、サインインウィンドウ、またはアドホックタイマーに最適です。

### ホーム画面とロック画面ウィジェット

**合計 12 ウィジェット ファミリ** (8 つのホーム画面 + 4 つのロック画面アクセサリ スタイル):

| ウィジェット | 説明 |
|--------|-------------|
| 今日はアクティブです | 現在進行中の今日のアクティビティ |
| 今日はすべて | 今日の活動のすべて |
| 今日の予定 | 今日のまだ始まっていないアクティビティ |
| すべてのイベント | ステータスごとに並べ替えられた完全なリストのプレビュー |
| 統計の概要 | アクティブ / 今後のカウント / すべてのカウント - 大きいサイズでは期限切れ / 完了 / キャンセル済みが追加されます |
| 収益 | 今日、今週、今月、そして今年 |
| 一目見る | アクティビティ数 + 収益 + アクティブ数が一目でわかる |
| トッププラットフォーム | 今年のプラットフォーム別収益ランキング |
| ロック画面（4種類） | 円形、長方形、およびインラインのアクセサリ - iOS 16+ |

iOS 17 以降では、リスト ウィジェットは、**行ごとにタップ**して、一致するアクティビティを直接開くことをサポートしています。

[設定] に組み込まれた **ウィジェット ガイド** では、ウィジェット ギャラリーと FAQ を使用して、ウィジェットを追加する手順を段階的に説明します。

### アクティビティフォームの追加事項

- **人気のアプリ リンク** — 一般的な Pay、銀行、ショッピング アプリの URL スキームをワンタップで入力します。
- **アルバムからスキャンまたは選択** - QR コードをスキャンするか画像を選択して、アクティビティ URL を自動入力します。

### QR/バーコードスキャナー

**[設定] → [ツール]** のスタンドアロン スキャナ:

- フラッシュライトをサポートするリアルタイムカメラスキャン。
- ビジョンによる検出を使用してフォト アルバムから選択します。
- 結果リストにはワンタップでコピー、アプリ内 Safari で http/https リンクが表示され、共有シート経由でエクスポートできます。

### 外見と言語

- 8 + テーマカラー (ゴールド、オーシャンブルー、フォレストグリーン、ローズピンク、ラベンダー、サンセットオレンジ、ミント、チェリーレッド…)
- 明/暗/システムの外観 - スイッチの触覚フィードバック付き。
- **20 個の代替ホーム画面アプリ アイコン。**
- 13 の表示言語: 英語、簡体字中国語、繁体字中国語、日本語、韓国語、タイ語、ヒンディー語、スペイン語、フランス語、ドイツ語、ブラジルポルトガル語、ロシア語、アラビア語 - システム言語とは別に切り替え可能。
- 複数の通貨 (ISO 4217)。一般的な金額 (デフォルト 2) とグラフ ラベル (デフォルト 0) のカスタマイズ可能な **小数点以下の桁数**。
- 構成可能な **アプリ バッジ戦略** (オフ / 今日のカウント / 保留中の合計)。
- **その他の推奨事項** — [設定] → [バージョン情報] にある開発者の App Store ページへのリンク。

### データとプライバシー

- **完全バックアップのエクスポート** — すべてのアクティビティ、リマインダー、収益、繰り返しの状態、およびテンプレートを含む CSV ファイル。
- **インポート バックアップ** - ライブラリ全体を置き換えるか、追加のみのマージ (既存のデータを保持します)。
- **ワンタップアーカイブ** — 完了/期限切れ/キャンセルされた非定期的なアクティビティをすべて一度にアーカイブします。
- アーカイブは設定から​​いつでも復元できます。
- アクティビティを共有すると、テキストがクリップボードにコピーされます。 **収益を含む共有** トグル (デフォルトではオフ) により、収益額は非公開に保たれます。

## 反復ルール

| 種類 | オプション |
|------|---------|
| 毎日 | N日ごと |
| 毎週 | 平日の任意の組み合わせ |
| 毎月 | 1 日、終了日または月末まで |
| 毎年 | 1 日、終了日または 12 月 31 日まで |
| カスタム | カスタム間隔（日単位） |

終了条件: 特定の終了日または最大出現数。
