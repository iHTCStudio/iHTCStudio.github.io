iWool은 **iPhone 및 iPad**에서 거래를 포착하고, 활동을 추적하고, 수익을 계산하기 위해 제작된 개인 정보 보호 우선 로컬 추적기입니다. **`iwool://` 딥 링크**는 홈, 캘린더, 통계, 설정, 인앱 작업(새 활동, 빠른 카운트다운, 스캐너, 알림) 또는 특정 활동(위젯, 바로가기 또는 홈 화면 빠른 작업)을 엽니다. **가입이나 업로드가 필요하지 않습니다. 데이터는 기기에 그대로 유지됩니다.**

지원되는 모든 경로와 별칭은 전체 [**`iwool://` URL 체계 참조**](url-scheme)를 참조하세요.

## 시작하기

1. 첫 번째 활동을 만들려면 홈 화면에서 **+**를 탭하세요.
2. 제목, 플랫폼, 시작 및 종료 시간을 입력합니다. 필요한 경우 알림을 추가하세요.
3. **저장**을 탭하세요. 활동이 상태별로 그룹화되어 목록에 나타납니다.
4. 거래가 성사되면 세부정보 페이지를 탭하고 **수익 기록**을 탭하세요.
5. 언제든지 **통계**를 확인하여 총계, 동향, 플랫폼 순위를 확인하세요.
6. 홈 화면이나 잠금 화면 위젯을 추가하면 업데이트를 받기 위해 앱을 열 필요가 없습니다.

## 특징

### 홈 화면

- **7가지 상태 요약 카드** — 활성, 예정, 모두, 만료, 완료, 취소, 일시 중지. 카드를 탭하면 즉시 필터링됩니다. 오늘로 돌아가려면 다시 탭하세요.
- **일시 중지 또는 유효 날짜로 취소** — 오늘/캘린더에서 숨기고 수입 내역을 유지하면서 알림을 중지하세요.
- **활동 공유 내보내기** — 친구가 따라갈 수 있도록 공유 팩을 내보냅니다(전체 백업과 별개).
- **전체 텍스트 검색** — 제목, 메모, 플랫폼, 요구 사항 및 규칙을 검색합니다.
- **길게 누르기 작업** — 완료 표시, 일시중지/재개, 취소/복원, 보관, 새 항목으로 복제 또는 삭제.
- 반복 활동에는 항상 **오늘의 일**이 표시되므로 상태와 시간이 실제 일정과 일치합니다.

### 달력

- **월 보기**와 **주 타임라인** 간에 전환하세요. 기본 설정이 저장됩니다.
- 날짜를 탭하면 해당 날짜의 활동을 볼 수 있습니다. 점과 왼쪽 막대 색상은 플랫폼 색상을 따릅니다.
- 홈 화면과 동일한 빠른 작업을 수행하려면 목록 행을 길게 누르세요.
- 언제든지 새로고침하려면 당겨보세요.

### 활동 세부정보

- **카운트다운 시작** — 현재 또는 다음 발생까지의 시간을 표시합니다. 24시간 미만인 경우 주황색으로 강조 표시됩니다.
- **다음 발생 날짜**는 반복 활동에 대해 표시됩니다. 시리즈가 끝나면 "다음 발생 없음".
- 활동 URL, 요구 사항, 규칙 및 메모는 모두 링크를 렌더링합니다. **한 번 탭**하면 Safari(http/https) 또는 관련 앱에서 열립니다. **길게 누르기**하면 '[앱]에서 열기', 'Safari에서 열기', '링크 복사', '공유'를 포함한 기본 iOS 링크 메뉴가 표시됩니다.

### 기록적인 수익

- 금액, 선택적 메모 및 **기록 날짜**가 포함된 반쪽짜리 양식입니다.
- 활동당 여러 항목이 있으며 각각 독립적으로 편집하거나 삭제할 수 있습니다.
- 수입은 여기에 기록된 경우에만 통계에 표시됩니다. 예상 수입은 표시용일 뿐입니다.

### 통계

- 오늘, 이번주, 이번달, 올해의 합계입니다.
- **월간 추세 차트** — 막대를 탭하면(금액이 0보다 큰 경우) 해당 기간의 모든 수입 항목을 볼 수 있습니다.
- **플랫폼 순위** — 독립적인 시간 범위 선택기(년/월/주); 항목별 세부정보를 자세히 살펴보려면 플랫폼 행을 탭하세요.
- **활동 개요** — 상태 행이나 총계 행을 탭하여 일치하는 활동 목록을 확인하세요.
- 반복 활동 수입 정책(엄격하거나 관대함)은 설정에서 구성할 수 있습니다.

### 알림

- 활동당 여러 알림 — 시작 시, 시작 전, 마감일 전 또는 일일 고정 시간.
- 시스템 로컬 알림. 앱을 열 때마다 알림 일정이 정리됩니다.
- 취소된 활동의 벨소리는 자동으로 중지됩니다.
- 홈 및 캘린더 목록 행에는 **작은 알림 문자**가 표시되므로 예정된 일정을 한눈에 확인할 수 있습니다.

### 이미지 카드 공유

시스템 공유 시트(그라데이션 배경, App Store QR 코드 및 선택적 워터마크)를 통해 **활동** 또는 **통계 대시보드**를 **브랜드 PNG 이미지 카드**로 공유하세요. 설정에서 공유 카드에 수입을 표시할지 여부를 전환합니다(**기본적으로 꺼져 있음**). 이미지는 기기 내에서 렌더링됩니다. 아무것도 업로드되지 않았습니다. 사진에 저장하면 사진 라이브러리 액세스가 필요할 수 있습니다.

### 홈 화면 빠른 작업

iOS에서 iWool 아이콘을 길게 누르면 최대 **4** 단축키를 실행할 수 있습니다. **설정 → 도구 → 홈 화면 바로가기**에서 **9** 사전 설정 중에서 선택하세요.

홈 · 달력 · 통계 · **빠른 카운트다운** · 새 활동 · 예정된 알림 · 스캐너 · 앱 평가 · 피드백

Default: **Home, Calendar, Statistics, Quick Countdown**. Each action uses an `iwool://` URL (same router as widgets and Shortcuts).

### 역동적인 섬 및 라이브 활동

지원되는 iPhone 모델의 두 가지 실시간 활동 유형:

**1. 이벤트 카운트다운** (iOS 16.1+)

- Wool 활동과 연결 — **설정 → 알림 → 실시간 활동**에서 활성화하세요.
- **리드 타임**을 조정합니다(시작 전 1~480분). 여러 창 내 활동은 각각 섬을 표시하거나 회전할 수 있습니다.
- 홈이나 캘린더에서 해당 활동을 길게 누르세요 → **동적 섬에 추가**.

**2. 빠른 카운트다운**(iOS 16.2+)

- **독립형** 섬/잠금 화면 카운트다운 — 활동 데이터베이스에 **저장되지 않음**.
- **설정 → 섬 알림** 또는 `iwool://island` / 홈 화면 빠른 작업에서 생성하세요.
- 지속 시간 **1초 ~ 8시간** — 사전 설정된 칩(30초, 1~480분) 또는 마감일 선택 선택적인 제목, 메모, 강조 색상 및 초 표시.
- 시간이 다 되면 자동으로 종료됩니다. 반짝 세일, 로그인 창 또는 임시 타이머에 이상적입니다.

### 홈 화면 및 잠금 화면 위젯

**총 12개의 위젯 제품군**(홈 화면 8개 + 잠금 화면 액세서리 스타일 4개):

| 위젯 | 설명 |
|--------|-------------|
| 오늘의 활동 | 현재 진행중인 오늘의 활동 |
| 오늘 전체 | 오늘의 모든 활동 |
| 오늘 예정 | 오늘 아직 시작하지 않은 활동 |
| 모든 이벤트 | 상태별로 정렬된 전체 목록 미리보기 |
| 통계 개요 | 활성/예정/모든 카운트 — 큰 크기 추가 만료/완료/취소 |
| 수입 | 오늘, 이번주, 이번달, 올해 |
| 한눈에 | 활동 개수 + 수입 + 활동 개수를 한눈에 |
| 최고의 플랫폼 | 올해 플랫폼별 수익 순위 |
| 잠금 화면(4가지 스타일) | 원형, 직사각형 및 인라인 액세서리 — iOS 16+ |

iOS 17 이상에서 목록 위젯은 일치하는 활동을 직접 열 수 있도록 **행당 탭**을 지원합니다.

설정에 내장된 **위젯 가이드**는 위젯 갤러리 및 FAQ와 함께 위젯을 추가하는 과정을 단계별로 안내합니다.

### 활동 양식 추가 사항

- **인기 앱 링크** — 일반적인 Pay, Bank 및 쇼핑 앱 URL 구성표를 한 번의 탭으로 채울 수 있습니다.
- **앨범에서 스캔 또는 선택** — QR 코드를 스캔하거나 이미지를 선택하여 활동 URL을 자동으로 입력하세요.

### QR / 바코드 스캐너

**설정 → 도구**의 독립형 스캐너:

- 손전등을 지원하는 실시간 카메라 스캔.
- Vision 기반 감지 기능을 통해 사진 앨범에서 선택하세요.
- 탭 한 번으로 복사할 수 있는 결과 목록, http/https 링크를 위한 인앱 Safari 및 공유 시트를 통해 내보내기가 가능합니다.

### 외관 및 언어

- 8개 이상의 테마 색상(골드, 오션 블루, 포레스트 그린, 로즈 핑크, 라벤더, 선셋 오렌지, 민트, 체리 레드…)
- 밝음/어두움/시스템 외관 - 스위치에 대한 촉각 피드백이 있습니다.
- **20개의 대체 홈 화면 앱 아이콘.**
- 13개 표시 언어: 영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 태국어, 힌디어, 스페인어, 프랑스어, 독일어, 브라질 포르투갈어, 러시아어, 아랍어 — 시스템 언어와 독립적으로 전환 가능.
- 다중 통화(ISO 4217) 일반 금액(기본값 2) 및 차트 라벨(기본값 0)에 대해 사용자 정의 가능한 **소수점**.
- 구성 가능한 **앱 배지 전략**(꺼짐 / 오늘 개수 / 총 보류 중)
- **추가 권장사항** — 설정 → 정보에서 개발자의 App Store 페이지로 연결됩니다.

### 데이터 및 개인정보 보호

- **전체 백업 내보내기** — 모든 활동, 알림, 수입, 반복 상태 및 템플릿이 포함된 CSV 파일입니다.
- **백업 가져오기** - 전체 라이브러리를 교체하거나 추가 전용 병합(기존 데이터 유지)을 수행합니다.
- **원터치 보관** — 완료/만료/취소된 비반복 활동을 한 번에 보관합니다.
- 보관 파일은 설정에서 언제든지 복원할 수 있습니다.
- 활동을 공유하면 텍스트가 클립보드에 복사됩니다. **공유-포함-수입** 토글(기본적으로 꺼져 있음)은 수입 금액을 비공개로 유지합니다.

## 반복 규칙

| 유형 | 옵션 |
|------|---------|
| 매일 | N일마다 |
| 주간 | 평일의 모든 조합 |
| 월간 | 하루, 종료일까지 또는 월말까지 |
| 매년 | 단 하루(종료일까지 또는 12월 31일까지) |
| 맞춤 | 사용자 정의 간격(일) |

종료 조건: 특정 종료 날짜 또는 최대 발생 횟수.
