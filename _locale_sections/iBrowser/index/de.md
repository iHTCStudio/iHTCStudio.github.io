**Durchsuchen ohne Chrome. Wiederherstellen, wenn Sie es brauchen.**

iBrowser (Vollbild-Browser / Vollbild-Browser) ist ein **echter Vollbild-Browser** für iPhone und iPad. Statusleiste, Adressleiste und Symbolleiste bleiben standardmäßig aus dem Weg — die Seite gehört dem Bildschirm. Eine **Schwebetaste** bringt die Kurzbefehle zurück; **Home- & Sperrbildschirm-Widgets**, **Siri & Kurzbefehle** und Schnellaktionen auf dem Home-Bildschirm öffnen Home, Suche, letzte Seite fortsetzen oder Lesezeichen. **Kindersicherung** hält die Adressleiste verborgen. Optional **iCloud** kann Lesezeichen und Browsing-Einstellungen synchronisieren. **Keine Werbung. Keine Pop-ups. Kein Konto.**

**Auf einen Blick:** Bildschirmfüllendes WebKit · Schwebetaste · Widgets · Siri / Kurzbefehle · `ibrowser://` · letzte Seite fortsetzen · Kindersicherung · optionale iCloud · alle Ausrichtungen · iPhone & iPad.

> iBrowser ist eine unabhängige App und **nicht mit Apple Inc. verbunden**.

## Erste Schritte

1. Installieren Sie die App aus dem [App Store](https://apps.apple.com/app/id948944368) und öffnen Sie **iBrowser**.
2. Beenden Sie die **Funktionsübersicht** und das kurze **Wie es geht**. Neue Benutzer müssen den **AGB zustimmen**, bevor sie surfen; zurückkehrende Benutzer sehen nur das Wie-es-geht.
3. Die Startseite wird geladen (Standard Bing, änderbar in den Einstellungen). Externe `http` / `https` Links werden unverändert geöffnet.
4. Tippen Sie auf den **Schwebeball** für Zurück / Vorwärts / Aktualisieren / Startseite, Lesezeichen, Kopieren, Teilen und Einstellungen.
5. Doppeltippen Sie auf die **Suchleiste** in der Symbolleiste für Einstellungen; doppeltippen Sie auf **Aktualisieren** für einen harten Reload.
6. Optional: Fügen Sie **Widgets** hinzu, fragen Sie **Siri** oder konfigurieren Sie Schnellaktionen auf dem Startbildschirm. Sie können die Tour jederzeit in den Einstellungen erneut abspielen.

## Alltägliche Steuerungen

| Aktion | Wie | 
|--------|-----| 
| Öffnen Sie eine Website oder suchen Sie | Zeigen Sie die Adressleiste an (Ball schweben oder Wiederherstellen), geben Sie eine URL oder Schlüsselwörter ein | 
| Immersive Lektüre | Tippen Sie auf **Vollbild** oder lassen Sie Chrome ausgeblendet, während die Float-Kugel eingeschaltet ist | 
| Schnelle Aktionen | Tippen Sie auf den **Schwimmball** | 
| Verstecke den Schwimmball | Ziehen Sie es an den unteren Rand | 
| Chrom / Kugel wiederherstellen | **Schütteln** auf dem iPhone; Tippen Sie auf dem **iPad** in die Nähe der **Oberseite** (Schütteln wird nicht unterstützt) | 
| Einstellungen | Floatball → Einstellungen oder **Doppeltippen auf Suche** | 
| Kindersicherung | Einstellungen → **Adressleiste ausblenden erzwingen** | 

Wenn der Float-Ball aktiviert ist, wird die Symbolleiste beim Scrollen **nicht** automatisch angezeigt. Durch die Kindersicherung bleibt die Adressleiste auch nach Wiederherstellungsgesten verborgen. 

## Widgets, Verknüpfungen & zuletzt fortfahren 

### Widgets (iOS 14+) 

Aus der Galerie des Startbildschirms hinzufügen: **Startseite**, **Lesezeichen**, **Suchen**, **Zuletzt fortfahren**. Unter iOS 16+ bieten „Home“ und „Fortfahren“ zuletzt auch Sperrbildschirmgrößen. Wenn die Kindersicherung aktiviert ist, bleiben die Lesezeichen-Widgets leer und stattdessen wird „Zuletzt geöffnete Startseite“ durch Suchen/Fortfahren geöffnet. 

### Siri und Verknüpfungen (iOS 16+) 

Öffnen Sie die Startseite, suchen Sie, fahren Sie mit der letzten Seite fort, Lesezeichen, Einstellungen, die Funktionstour oder eine bestimmte URL. Vollständige Liste: [Shortcut-Links](URL-Schema).

### Letzte Seite fortsetzen

Die App merkt sich die zuletzt erfolgreich geladene Seite **auf diesem Gerät** (nicht über iCloud). Ein Kaltstart öffnet weiterhin **Startseite**; nur Widgets, Kurzbefehle oder Schnellaktionen auf dem Startbildschirm öffnen „Letzte fortsetzen“.

### Schnellaktionen auf dem Startbildschirm

Langes Drücken des Symbols (bis zu 4). In den Einstellungen anpassen. Mit Kindersicherung bleibt nur **Startseite öffnen**.

## Kindersicherung

Für Kinder, Kioske oder wenn man jemandem ein Telefon gibt, um eine Seite anzusehen:

1. Eine passende **Startseite** festlegen (die Einstellungen können die **aktuelle Seite** verwenden).
2. **Adressleiste erzwingen ausblenden** aktivieren (Anzeigename: **Kindersicherung**).
3. Optional ein **Einstellungs-Passwort** aktivieren.

Die Kindersicherung verhindert das Ändern der URL in der Adressleiste. Links innerhalb der Seite, Zurück / Vorwärts und Startseite funktionieren weiterhin. **Widgets, Kurzbefehle und Lesezeichen** (außer der Startseite) öffnen ebenfalls die Startseite, während die Sperre aktiv ist.

## Nützliche Einstellungen

- **Startseite** — Standard Bing; **Aktuelle Seite verwenden**, wenn verfügbar
- **Suchmaschine** — Bing, Google, Sogou, 360, DuckDuckGo, GitHub, Stack Overflow oder ein benutzerdefiniertes Präfix
- **Lesezeichen** — auf dem Gerät; Schwebe-Button oder Einstellungen; bearbeitbar / Stapellöschung möglich
- **Schwebe-Button-Menü** — Panel-Tasten neu anordnen oder ausblenden (mindestens eine behalten; Einstellungen behalten, wenn die Werkzeugleiste erzwungen ausgeblendet ist)
- **Browserränder** — oben / links / rechts / unten (Notch-sichere Option auf Geräten mit Notch)
- **Erscheinungsbild / Sprache** — system- oder festgelegte Hell/Dunkel-Option; UI-Sprache (sieben Sprachversionen) gilt beim nächsten Start
- **iCloud-Synchronisation** — standardmäßig aus; kann Lesezeichen, Startseite, Suche, Ränder, Display-Sperren, Schwebe-Button-Menü synchronisieren — **nicht** Passwort für Einstellungen, letzte Seite, Position des Schwebe-Buttons, Erscheinungsbild, Sprache oder Home-Screen-Schnellaktionsreihenfolge
- **Anleitungen** — Feature-Tour, Widget-Anleitung, Shortcuts-Anleitung, vollständiges Handbuch

## Warum Sie es herunterladen möchten

- **Echter randloser Modus** — Chrome ist vorübergehend, keine schmalere Symbolleiste.
- **Systemeigene Einstiegspunkte** — Widgets, Siri, Kurzbefehle, Aktionen auf dem Startbildschirm.
- **Kindersicherung, die dem Versprechen des Stores entspricht** — Adressleiste ausblenden; optionales Passwort; Sperre gilt auch für Widgets / Kurzbefehle.
- **Leichtgewichtiges Design** — kein Tab-Farm, kein Download-Manager, keine Werbeoberfläche.
