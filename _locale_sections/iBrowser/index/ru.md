iBrowser (全屏浏览器 / 全螢幕瀏覽器) — это **настоящий полноэкранный браузер** для iPhone и iPad. Строка состояния, адресная строка и панель инструментов по умолчанию остаются скрытыми — страница занимает весь экран. **Плавающий шар** возвращает ярлыки; **виджеты на Главном экране и заблокированном экране**, **Siri и Быстрые команды**, а также быстрые действия на Главном экране открывают главный экран, поиск, продолжают просмотр с последней страницы или закладки. **Детский замок** скрывает адресную строку. Необязательный **iCloud** может синхронизировать закладки и настройки просмотра. **Нет рекламы. Нет всплывающих окон. Нет аккаунта.**

**В двух словах:** WebKit по всей ширине экрана · плавающий шар · виджеты · Siri / Быстрые команды · `ibrowser://` · продолжить с последней страницы · детский замок · необязательный iCloud · все ориентации · iPhone и iPad.

> iBrowser — независимое приложение и **не связано с Apple Inc.**

## Начало работы

1. Установите из [App Store](https://apps.apple.com/app/id948944368) и откройте **iBrowser**.
2. Пройдите **обзор функций** и короткое **руководство**. Новые пользователи должны **согласиться с условиями** перед просмотром; возвращающиеся пользователи видят только руководство.
3. Загружается главная страница (по умолчанию Bing, можно изменить в Настройках). Внешние `http` / `https` ссылки открываются как есть.
4. Нажмите на **плавающий шар** для перехода назад / вперед / обновления / домой, закладок, копирования, поделиться и Настроек.
5. Дважды нажмите на **поиск** на панели инструментов для Настроек; дважды нажмите **обновить** для полной перезагрузки.
6. По желанию: добавьте **виджеты**, спросите **Siri** или настройте быстрые действия на главном экране. Повторите тур в любое время в Настройках.

## Ежедневное управление

| Действие | Как | 
|--------|-----| 
| Открыть сайт или выполнить поиск | Отобразите адресную строку (шарик или жест восстановления), введите URL-адрес или ключевые слова | 
| Захватывающее чтение | Нажмите **Во весь экран** или скройте Chrome, пока включен плавающий шарик | 
| Быстрые действия | Нажмите на **плавающий шар** | 
| Спрятать плавающий шар | Перетащите его к нижнему краю | 
| Восстановить хром/шар | **Встряхните** на iPhone; на **iPad** коснитесь **верхней точки** (встряхивание не поддерживается) | 
| Настройки | Поплавок → Настройки или **Поиск по двойному касанию** | 
| Замок от детей | Настройки → **Принудительно скрыть адресную строку** | 

Когда плавающий шарик включен, при прокрутке **не** автоматически отображается панель инструментов. Блокировка от детей скрывает адресную строку даже после жестов восстановления. 

## Виджеты, ярлыки и продолжение последними 

### Виджеты (iOS 14+) 

Добавьте из галереи главного экрана: **Главная**, **Закладки**, **Поиск**, **Продолжить последним**. В iOS 16+ кнопки «Домой» и «Продолжить» также предлагают размеры экрана блокировки. При включенной блокировке от детей виджеты закладок остаются пустыми, а вместо этого последний раз открывается **домашняя страница** для поиска/продолжения. 

### Siri и ярлыки (iOS 16+) 

Открыть домашнюю страницу, выполнить поиск, продолжить последнюю страницу, закладки, настройки, обзор функций или конкретный URL-адрес. Полный список: [Ярлыки ссылок](url-схема).

### Продолжить с последней страницы

Приложение запоминает последнюю успешно загруженную страницу **на этом устройстве** (не через iCloud). При холодном запуске по-прежнему открывается **главная**; только виджеты, Быстрые команды или быстрые действия на главном экране открывают «продолжить с последней». 

### Быстрые действия на главном экране

Длительное нажатие на иконку (до 4). Настраивается в Настройках. Родительский замок оставляет только **Открыть главную**.

## Родительский замок

Для детей, киосков или когда нужно показать кому-то телефон для просмотра одной страницы:

1. Установите подходящую **главную страницу** (Настройки могут использовать **текущую страницу**).
2. Включите **Принудительное скрытие адресной строки** (имя в хранилище: **Родительский замок**).
3. При желании включите **пароль для Настроек**.

Родительский замок блокирует изменение URL через адресную строку. Ссылки внутри страницы, кнопки «назад/вперед» и Главная по-прежнему работают. **Виджеты, Быстрые команды и закладки** (кроме главного URL) также открывают главную при включенном замке.

## Настройки, которые стоит знать

- **Главная страница** — Bing по умолчанию; **Использовать текущую страницу**, когда доступно
- **Поисковая система** — Bing, Google, Sogou, 360, DuckDuckGo, GitHub, Stack Overflow или пользовательский префикс
- **Закладки** — на устройстве; плавающая кнопка или Настройки; редактирование / массовое удаление
- **Меню плавающей кнопки** — изменить порядок или скрыть кнопки панели (оставьте хотя бы одну; оставьте Настройки, если панель принудительно скрыта)
- **Поля браузера** — верх / левая сторона / правая сторона / низ (опция безопасного выреза на устройствах с вырезом)
- **Внешний вид / язык** — системный или фиксированный светлый/тёмный; язык интерфейса (семь локалей) применяется при следующем запуске
- **Синхронизация iCloud** — по умолчанию выключена; может синхронизировать закладки, главную страницу, поиск, поля, блокировки отображения, меню плавающей кнопки — **не** соответствует паролю Настроек, последней странице, позиции плавающей кнопки, внешнему виду, языку или порядку быстрых действий на главном экране
- **Руководства** — обзор функций, руководство по виджетам, руководство по Shortcuts, полный справочник

## Почему стоит скачать

- **Настоящий по краям** — хром временный, а не более тонкая панель инструментов.
- **Системные точки входа** — виджеты, Siri, Сценарии, действия на главном экране.

- **Лёгкий по дизайну** — без множества вкладок, без менеджера загрузок, без рекламного интерфейса.
