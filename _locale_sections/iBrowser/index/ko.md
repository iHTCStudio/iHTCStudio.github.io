iBrowser (全屏浏览器 / 全螢幕瀏覽器)는 iPhone 및 iPad용 **진정한 전체 화면 브라우저**입니다. 상태 표시줄, 주소 표시줄, 툴바는 기본적으로 화면에서 벗어나 있으며 — 페이지가 화면을 차지합니다. **플로트 볼**이 바로 가기를 다시 가져옵니다; **홈 및 잠금 화면 위젯**, **Siri 및 단축어**, 홈 화면 빠른 동작으로 홈, 검색, 마지막 페이지 계속, 또는 북마크를 열 수 있습니다. **자녀 보호 잠금**으로 주소 표시줄을 숨길 수 있습니다. 선택적 **iCloud**는 북마크 및 탐색 환경 설정을 동기화할 수 있습니다. **광고 없음. 팝업 없음. 계정 필요 없음.**

**한눈에 보기:** 엣지 투 엣지 WebKit · 플로트 볼 · 위젯 · Siri / 단축어 · `ibrowser://` · 마지막 페이지 계속 · 자녀 보호 잠금 · 선택적 iCloud · 모든 방향 · iPhone & iPad.

> iBrowser는 독립적인 앱이며 **Apple Inc.와 관련이 없습니다.**

## 시작하기

1. [앱 스토어](https://apps.apple.com/app/id948944368)에서 설치하고 **iBrowser**를 엽니다.
2. **기능 투어**와 짧은 **사용 방법**을 완료합니다. 신규 사용자는 브라우징 전에 **약관에 동의**해야 하며, 기존 사용자는 사용 방법만 확인합니다.
3. 홈 페이지가 로드됩니다(기본 Bing, 설정에서 변경 가능). 외부 `http` / `https` 링크는 그대로 열립니다.
4. **플로트 볼**을 탭하여 뒤로가기 / 앞으로가기 / 새로고침 / 홈, 즐겨찾기, 복사, 공유, 설정을 이용합니다.
5. 툴바의 **검색**을 더블탭하면 설정으로 이동; **새로고침**을 더블탭하면 강력 새로고침이 실행됩니다.
6. 선택 사항: **위젯** 추가, **Siri**에 질문, 또는 홈 화면 빠른 동작 구성. 설정에서 언제든지 투어를 다시 볼 수 있습니다.

## 일상적인 컨트롤

| 액션 | 어떻게 | 
|---------|------| 
| 사이트 열기 또는 검색 | 주소 표시줄(플로팅 볼 또는 복구 동작)을 표시하고 URL 또는 키워드를 입력하세요 | 
| 몰입형 독서 | **전체 화면**을 탭하거나 플로트 볼이 켜져 있는 동안 크롬을 숨긴 상태로 유지 | 
| 빠른 조치 | **플로트 볼** |을 탭하세요. 
| 플로트 볼 숨기기 | 아래쪽 가장자리로 드래그 | 
| 크롬/공 복구 | iPhone에서 **흔들기**; **iPad**에서 **상단** 근처를 탭하세요(흔들기는 지원되지 않음) | 
| 설정 | 플로트볼 → 설정 또는 **더블탭 검색** | 
| 어린이용 자물쇠 | 설정 → **주소 표시줄 강제 숨기기** | 

플로트 볼이 켜져 있으면 스크롤해도 도구 모음이 자동으로 표시되지 **않습니다**. 어린이 잠금 기능은 복구 동작 후에도 주소 표시줄을 숨긴 상태로 유지합니다. 

## 위젯, 바로가기 및 마지막으로 계속 

### 위젯(iOS 14 이상) 

홈 화면 갤러리에서 추가: **홈**, **북마크**, **검색**, **마지막으로 계속**. iOS 16 이상에서는 홈 및 계속이 마지막으로 잠금 화면 크기도 제공합니다. 어린이 잠금 기능을 켜면 북마크 위젯이 빈 상태로 유지되고 대신 검색/계속이 마지막으로 열린 **홈**을 엽니다. 

### Siri 및 단축키(iOS 16+) 

홈 열기, 검색, 마지막 페이지 계속, 북마크, 설정, 기능 둘러보기 또는 특정 URL을 엽니다. 전체 목록: [바로가기 링크](url-scheme).

### 마지막 페이지 계속하기

앱은 **이 기기에서** 마지막으로 성공적으로 로드된 페이지를 기억합니다 (iCloud를 통해서는 아님). 기기가 냉각 시작하면 여전히 **홈**이 열리며, 위젯, 단축어, 홈 화면 빠른 동작만 '마지막 계속'을 엽니다.

### 홈 화면 빠른 동작

아이콘을 길게 누르기 (최대 4개). 설정에서 사용자화 가능. 아동 보호 기능은 **홈 열기**만 남깁니다.

## 아동 보호 기능

아이들, 키오스크, 또는 한 페이지만 보여주기 위해 누군가에게폰을 건네줄 때:

1. 적절한 **홈 페이지** 설정 (설정에서 **현재 페이지** 사용 가능).
2. **주소 표시줄 강제 숨기기** 켜기 (스토어 이름: **아동 보호**).
3. 선택적으로 **설정 비밀번호** 활성화.

아동 보호 기능은 주소 표시줄에서 URL 변경을 차단합니다. 페이지 내 링크, 뒤로/앞으로, 홈은 여전히 작동합니다. 아동 보호 기능이 켜져 있을 때 **위젯, 단축어, 북마크** (홈 URL 제외)도 홈을 엽니다.

## 꼭 알아둬야 할 설정

- **홈 페이지** — 기본 Bing; 가능할 경우 **현재 페이지 사용**
- **검색 엔진** — Bing, Google, Sogou, 360, DuckDuckGo, GitHub, Stack Overflow, 또는 사용자 지정 접두사
- **북마크** — 기기 내; 플로트 볼 또는 설정에서; 편집 / 일괄 삭제 가능
- **플로트 볼 메뉴** — 패널 버튼 재정렬 또는 숨기기 (최소 하나 유지; 툴바가 강제로 숨겨진 경우 설정 유지)
- **브라우저 여백** — 상 / 좌 / 우 / 하 (노치 있는 기기에서는 노치 안전 옵션)
- **외관 / 언어** — 시스템 또는 고정된 밝기/어둡기; UI 언어(7개 로케일) 다음 실행 시 적용
- **iCloud 동기화** — 기본적으로 꺼짐; 북마크, 홈, 검색, 여백, 화면 잠금, 플로트 볼 메뉴 동기화 가능 — **설정 비밀번호, 마지막 페이지, 플로트 볼 위치, 외관, 언어, 홈 화면 빠른 실행 순서**는 동기화되지 않음
- **가이드** — 기능 투어, 위젯 가이드, 단축어 가이드, 전체 안내서

## 다운로드해야 하는 이유

- **실제 가장자리까지 확대** — 크롬은 일시적이며, 얇은 툴바가 아님.
- **시스템 기본 진입점** — 위젯, 시리, 단축어, 홈 화면 액션.
- **스토어 약속에 맞는 아동 잠금** — 주소 표시줄 숨기기; 선택적 비밀번호; 위젯/단축어도 잠금 적용.
- **디자인상 가벼움** — 탭 농장 없음, 다운로드 관리자 없음, 광고 UI 없음.
