**Naviguez sans l’interface. Récupérez-la quand vous en avez besoin.**

iBrowser (全屏浏览器 / 全螢幕瀏覽器) est un **véritable navigateur plein écran** pour iPhone et iPad. La barre d’état, la barre d’adresse et la barre d’outils restent hors de vue par défaut — la page occupe tout l’écran. Une **boule flottante** ramène les raccourcis ; les **widgets Écran d’accueil & Écran verrouillé**, **Siri & Raccourcis**, et les actions rapides de l’écran d’accueil ouvrent l’écran d’accueil, la recherche, la dernière page ou les signets. Le **verrouillage enfant** garde la barre d’adresse cachée. L’**iCloud** optionnel peut synchroniser les signets et les préférences de navigation. **Pas de pubs. Pas de pop-ups. Pas de compte.**

**En un coup d’œil :** WebKit bord à bord · boule flottante · widgets · Siri / Raccourcis · `ibrowser://` · continuer la dernière page · verrouillage enfant · iCloud optionnel · toutes orientations · iPhone & iPad.

> iBrowser est une application indépendante et n’est **pas affiliée à Apple Inc.**

## Commencer

1. Installez depuis l'[App Store](https://apps.apple.com/app/id948944368) et ouvrez **iBrowser**.
2. Terminez le **tour des fonctionnalités** et le court **mode d'emploi**. Les nouveaux utilisateurs doivent **accepter les conditions** avant de naviguer ; les utilisateurs revenants ne voient que le mode d'emploi.
3. La page d'accueil se charge (Bing par défaut, modifiable dans les Paramètres). Les liens externes `http` / `https` s'ouvrent tels quels.
4. Appuyez sur la **balle flottante** pour revenir / avancer / actualiser / accueil, signets, copier, partager et Paramètres.
5. Double-cliquez sur **recherche** dans la barre d'outils pour accéder aux Paramètres ; double-cliquez sur **actualiser** pour un rechargement complet.
6. Optionnel : ajoutez des **widgets**, demandez à **Siri**, ou configurez les actions rapides de l’écran d’accueil. Rejouez le tour à tout moment dans les Paramètres.

## Contrôles quotidiens

| Actions | Comment | 
|--------|-----| 
| Ouvrir un site ou effectuer une recherche | Afficher la barre d'adresse (balle flottante ou geste de récupération), saisir une URL ou des mots-clés | 
| Lecture immersive | Appuyez sur **Plein écran** ou laissez Chrome caché lorsque la boule flottante est activée | 
| Actions rapides | Appuyez sur la **balle flottante** | 
| Cacher la boule flottante | Faites-le glisser vers le bord inférieur | 
| Récupérer chrome / boule | **Secouez** sur iPhone ; sur **iPad**, appuyez près du **haut** (le tremblement n'est pas pris en charge) | 
| Paramètres | Boule flottante → Paramètres, ou **recherche en appuyant deux fois** | 
| Sécurité enfants | Paramètres → **Forcer le masquage de la barre d'adresse** | 

Lorsque la boule flottante est activée, le défilement ne révèle **pas** automatiquement la barre d'outils. Le verrouillage enfant maintient la barre d'adresse cachée même après des gestes de récupération. 

## Widgets, raccourcis et continuer en dernier 

### Widgets (iOS 14+) 

Ajoutez depuis la galerie de l'écran d'accueil : **Accueil**, **Favoris**, **Recherche**, **Continuer en dernier**. Sur iOS 16+, Accueil et Continuer proposent également des tailles d'écran de verrouillage. Avec le verrouillage enfant activé, les widgets de favoris restent vides et Rechercher/Continuer est ouvert en dernier **accueil** à la place. 

### Siri et raccourcis (iOS 16+) 

Ouvrez l'accueil, recherchez, continuez la dernière page, les favoris, les paramètres, la visite guidée des fonctionnalités ou une URL spécifique. Liste complète : [Liens de raccourci] (schéma d'url).

### Continuer la dernière page

L'application se souvient de la dernière page chargée avec succès **sur cet appareil** (pas via iCloud). Un démarrage à froid ouvre toujours **l'accueil** ; seules les widgets, les Raccourcis ou les actions rapides de l'écran d'accueil ouvrent « continuer la dernière ».

### Actions rapides de l'écran d'accueil

Appuyez longuement sur l'icône (jusqu'à 4). Personnalisez dans les Réglages. Le verrouillage enfant laisse seulement **Ouvrir l'accueil**.

## Verrouillage enfant

Pour les enfants, les kiosques ou pour donner un téléphone à quelqu'un pour qu'il voie une seule page :

1. Définissez une **page d'accueil** appropriée (les Réglages peuvent utiliser la **page actuelle**).
2. Activez **Forcer la suppression de la barre d'adresse** (nom du magasin : **Verrouillage enfant**).
3. Facultativement, activez un **mot de passe pour les Réglages**.

Le verrouillage enfant empêche de changer l'URL depuis la barre d'adresse. Les liens dans la page, les boutons retour / avance et l'accueil fonctionnent toujours. **Les widgets, les Raccourcis et les favoris** (autres que l'URL d'accueil) ouvrent également l'accueil pendant que le verrouillage est activé.

## Réglages à connaître

- **Page d'accueil** — Bing par défaut ; **Utiliser la page actuelle** quand disponible
- **Moteur de recherche** — Bing, Google, Sogou, 360, DuckDuckGo, GitHub, Stack Overflow ou un préfixe personnalisé
- **Signets** — sur l'appareil ; ballon flottant ou Paramètres ; modifiable / suppression en lot
- **Menu du ballon flottant** — réorganiser ou masquer les boutons du panneau (garder au moins un ; garder Paramètres si la barre d'outils est obligatoirement masquée)
- **Marges du navigateur** — haut / gauche / droite / bas (option compatible encoche sur les appareils à encoche)
- **Apparence / langue** — système ou clair/sombre fixe ; langue de l'interface utilisateur (sept locales) s'applique au prochain lancement
- **iCloud Sync** — désactivé par défaut ; peut synchroniser les signets, page d'accueil, moteur de recherche, marges, verrous d'affichage, menu du ballon flottant — **pas** le mot de passe des Paramètres, la dernière page, la position du ballon flottant, l'apparence, la langue ou l'ordre des actions rapides de l'écran d'accueil
- **Guides** — visite guidée des fonctionnalités, guide du widget, guide des Raccourcis, manuel complet

## Pourquoi vous voudrez télécharger

- **Véritable plein écran** — le chrome est temporaire, pas une barre d’outils plus fine.
- **Points d’entrée natifs du système** — widgets, Siri, Raccourcis, actions de l’écran d’accueil.
- **Verrouillage enfant conforme à la promesse de l’app store** — masquer la barre d’adresse ; mot de passe optionnel ; le verrouillage couvre également les widgets / Raccourcis.
- **Léger par conception** — pas de ferme d’onglets, pas de gestionnaire de téléchargement, pas d’interface publicitaire.
