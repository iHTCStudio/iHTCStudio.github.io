**ท่องเว็บแบบไม่ต้องมีแถบเครื่องมือ รีคัฟเวอร์เมื่อคุณต้องการ**

iBrowser (全屏浏览器 / 全螢幕瀏覽器) เป็น **เบราว์เซอร์เต็มหน้าจอจริงๆ** สำหรับ iPhone และ iPad แถบสถานะ, แถบที่อยู่ และแถบเครื่องมือ จะไม่ขวางสายตาโดยค่าเริ่มต้น — หน้าเว็บครอบครองหน้าจอ **บอลลอย** ช่วยนำทางลัดกลับมา; **วิดเจ็ตหน้าหลัก & หน้าล็อก**, **Siri & Shortcuts**, และการกระทำด่วนบนหน้าจอหลักเปิดหน้าแรก, ค้นหา, ต่อจากหน้าที่เปิดล่าสุด, หรือบุ๊คมาร์ก **ล็อกสำหรับเด็ก** ทำให้แถบที่อยู่ถูกซ่อนไว้ **iCloud** เป็นทางเลือก สามารถซิงค์บุ๊คมาร์กและการตั้งค่าการท่องเว็บ **ไม่มีโฆษณา ไม่มีป๊อปอัพ ไม่มีบัญชีผู้ใช้**

**ภาพรวม:** WebKit เต็มจอทุกขอบ · บอลลอย · วิดเจ็ต · Siri / Shortcuts · `ibrowser://` · ต่อจากหน้าที่เปิดล่าสุด · ล็อกสำหรับเด็ก · iCloud เป็นทางเลือก · ทุกการวางแนว · iPhone & iPad

> iBrowser เป็นแอปอิสระและ **ไม่มีความเกี่ยวข้องกับ Apple Inc.**

## การเริ่มต้นใช้งาน

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id948944368) และเปิด **iBrowser**  
2. ทำ **ทัวร์ฟีเจอร์** และ **คู่มือสั้น** ให้เสร็จ ผู้ใช้ใหม่ต้อง **ยอมรับเงื่อนไข** ก่อนเริ่มท่องเว็บ; ผู้ใช้เดิมจะเห็นแค่คู่มือสั้น  
3. หน้าแรกโหลด (ค่าเริ่มต้นคือ Bing, เปลี่ยนได้ในการตั้งค่า) ลิงก์ `http` / `https` ภายนอกจะเปิดตามเดิม  
4. แตะ **ลูกบอลลอยตัว** เพื่อย้อนกลับ / ไปหน้า / รีเฟรช / หน้าแรก, บุ๊กมาร์ก, คัดลอก, แชร์ และการตั้งค่า  
5. แตะสองครั้งที่แถบเครื่องมือ **ค้นหา** เพื่อเปิดการตั้งค่า; แตะสองครั้งที่ **รีเฟรช** เพื่อโหลดใหม่แบบเต็ม  
6. ตัวเลือกเสริม: เพิ่ม **วิดเจ็ต**, ถาม **Siri**, หรือกำหนดการกระทำด่วนในหน้าจอหลัก เล่นทัวร์ซ้ำได้ทุกเวลาในการตั้งค่า  

## การควบคุมในชีวิตประจำวัน

| การกระทำ | อย่างไร | 
|--------|-----| 
| เปิดไซต์หรือค้นหา | แสดงแถบที่อยู่ (ลูกบอลลอยหรือท่าทางการกู้คืน) พิมพ์ URL หรือคำสำคัญ |
 | การอ่านที่ดื่มด่ำ | แตะ **เต็มหน้าจอ** หรือซ่อน Chrome ไว้ในขณะที่ลูกบอลลอยเปิดอยู่ | 
| การดำเนินการด่วน | แตะ **ลูกบอลลอย** | 
| ซ่อนลูกบอลลอย | ลากไปที่ขอบด้านล่าง | 
| กู้โครเมียม / บอล | **เขย่า** บน iPhone; บน **iPad** ให้แตะใกล้กับ **ด้านบน** (ไม่รองรับการสั่น) | 
| การตั้งค่า | ลูกบอลลอย → การตั้งค่า หรือ **แตะสองครั้งค้นหา** | 
| ล็อคป้องกันเด็ก | การตั้งค่า → **บังคับซ่อนแถบที่อยู่** | 

เมื่อลูกบอลลอยเปิดอยู่ การเลื่อนจะไม่ **ไม่** เปิดเผยแถบเครื่องมือโดยอัตโนมัติ ล็อคป้องกันเด็กซ่อนแถบที่อยู่ไว้แม้หลังจากกู้คืนท่าทางแล้ว 

## วิดเจ็ต ทางลัด & ดำเนินการต่อล่าสุด 

### วิดเจ็ต (iOS 14+) 

เพิ่มจากแกลเลอรีหน้าจอหลัก: **หน้าแรก**, **บุ๊กมาร์ก**, **ค้นหา**, **ทำต่อล่าสุด** บน iOS 16+ หน้า Home และ Continue Last จะมีขนาดหน้าจอล็อคด้วย เมื่อเปิดการล็อกป้องกันเด็ก วิดเจ็ตบุ๊กมาร์กจะว่างเปล่า และค้นหา / ดำเนินการต่อ เปิด **home** แทน 

### Siri และทางลัด (iOS 16+) 

เปิดหน้าแรก ค้นหา ดำเนินการต่อหน้าสุดท้าย บุ๊กมาร์ก การตั้งค่า ทัวร์ชมคุณลักษณะ หรือ URL ที่เฉพาะเจาะจง รายการทั้งหมด: [ลิงก์ทางลัด](url-scheme)

### ต่อจากหน้าที่แล้ว

แอปจะจำหน้าที่โหลดสำเร็จล่าสุด **บนอุปกรณ์นี้** (ไม่ใช่ผ่าน iCloud) การเริ่มต้นใหม่แบบเต็มจะยังคงเปิด **หน้าแรก**; จะมีเพียงวิดเจ็ต, คำสั่งลัด, หรือการกระทำด่วนบนหน้าจอหลักเท่านั้นที่เปิด “ต่อจากหน้าเดิม” ได้

### การกระทำด่วนบนหน้าจอหลัก

กดไอคอนค้างไว้ (สูงสุด 4 รายการ) ปรับแต่งได้ใน การตั้งค่า การล็อกเด็กจะปล่อยให้มีเพียง **เปิดหน้าแรก** เท่านั้น

## การล็อกเด็ก

สำหรับเด็ก, คีออส, หรือเมื่อให้ใครสักคนใช้โทรศัพท์เพื่อดูหน้าเดียว:

1. ตั้งค่า **หน้าหลัก** ที่เหมาะสม (การตั้งค่าสามารถใช้ **หน้าปัจจุบัน** ได้)
2. เปิด **ซ่อนแถบที่อยู่บังคับ** (ชื่อร้าน: **ล็อกเด็ก**)
3. สามารถเปิดใช้ **รหัสผ่านการตั้งค่า** ได้ตามต้องการ

การล็อกเด็กจะบล็อกการเปลี่ยน URL จากแถบที่อยู่ ลิงก์ภายในหน้า, ปุ่มย้อนกลับ / ไปข้างหน้า, และหน้าแรกยังคงทำงานได้ **วิดเจ็ต, คำสั่งลัด, และบุ๊กมาร์ก** (นอกจาก URL หน้าแรก) จะยังคงเปิดหน้าแรกขณะเปิดล็อกอยู่

## การตั้งค่าที่ควรรู้

- **หน้าแรก** — Bing เป็นค่าเริ่มต้น; **ใช้หน้าปัจจุบัน** เมื่อมีให้เลือก  
- **เครื่องมือค้นหา** — Bing, Google, Sogou, 360, DuckDuckGo, GitHub, Stack Overflow หรือกำหนดค่าแบบกำหนดเอง  
- **บุ๊คมาร์ก** — อยู่บนอุปกรณ์; ลูกบอลลอยหรือตั้งค่า; แก้ไข / ลบเป็นกลุ่มได้  
- **เมนูลูกบอลลอย** — จัดลำดับหรือซ่อนปุ่มแผง (อย่างน้อยเก็บไว้หนึ่งปุ่ม; เก็บ Settings ไว้ถ้าแถบเครื่องมือถูกซ่อนโดยบังคับ)  
- **ขอบเบราว์เซอร์** — ด้านบน / ซ้าย / ขวา / ล่าง (ตัวเลือกปลอดภัยสำหรับรอยบากบนอุปกรณ์ที่มีรอยบาก)  
- **รูปลักษณ์ / ภาษา** — ระบบหรือกำหนดค่าแสง/มืด; ภาษาของ UI (เจ็ดภาษาท้องถิ่น) จะมีผลเมื่อเปิดครั้งถัดไป  
- **การซิงค์ iCloud** — ปิดเป็นค่าเริ่มต้น; สามารถซิงค์บุ๊คมาร์ก, หน้าแรก, การค้นหา, ขอบ, การล็อกการแสดงผล, เมนูลูกบอลลอย — **ไม่**รวมถึงรหัสผ่าน Settings, หน้าล่าสุด, ตำแหน่งลูกบอลลอย, รูปลักษณ์, ภาษา หรือ ลำดับการกระทำด่วนบนหน้าจอหลัก  
- **คู่มือ** — ทัวร์ฟีเจอร์, คู่มือวิดเจ็ต, คู่มือทางลัด, คู่มือฉบับเต็ม  

## ทำไมคุณถึงควรดาวน์โหลด

- **เต็มหน้าจอจริงๆ** — chrome เป็นเพียงชั่วคราว ไม่ใช่แถบเครื่องมือบาง  
- **จุดเข้าระบบที่เป็นของระบบตัวเครื่อง** — วิดเจ็ต, Siri, Shortcuts, การกระทำบนหน้าจอโฮม  
- **ล็อกสำหรับเด็กที่ตรงตามคำมั่นสัญญาของร้านค้า** — ซ่อนแถบที่อยู่; รหัสผ่านแบบตัวเลือก; ล็อกครอบคลุมทั้งวิดเจ็ต / Shortcuts  
- **ออกแบบให้เบา** — ไม่มีแท็บมากมาย, ไม่มีตัวจัดการดาวน์โหลด, ไม่มีโฆษณา UI
