**เต๋าที่พูดได้ เริ่มต้นด้วยบทของวันนี้** 

iDao (爱道德经 / 愛道德經) คือ **สตูดิโอเรียน Tao Te Ching ที่น่าตื่นตาตื่นใจ** — ไม่ใช่การถ่ายโอนข้อมูลข้อความธรรมดาแบบอื่น **ไม่จำเป็นต้องมีบัญชี** ทั้งหมด **81 บท** จัดส่งบนอุปกรณ์ของคุณพร้อม **ภาษาท้องถิ่นของบท**, **พินอินต่อตัวอักษร**, **ข้อคิดเห็นคลาสสิก 2 รายการ**, **การแปลภาษาอังกฤษ 2 รายการ** (สลับหรือเปรียบเทียบ) พร้อมด้วย **Qingjing Jing** และ **Yinfu Jing** สำหรับการอ่านเพิ่มเติม และ **74** บทอ่านสองภาษาที่มีชื่อเสียง **อ่าน** เคียงข้างกัน; **ท่อง** โดยเน้นบรรทัด ฝึกซ้อมใน **ห้องศึกษา**; เล่น **แสวงหาเต๋า** บนหน้าแรก เปิดบริบท **บทรายวัน** ส่งออก **แชร์การ์ด** (“การ์ด Dao”) เพิ่ม **วิดเจ็ต** ตัวเลือกเสริม **กิจกรรมการอ่านสด** **Siri และคำสั่งลัด** และตัวเลือก **ผสาน iCloud แบบสองทิศทาง** ** ไม่มีโฆษณา ไม่มีการติดตาม ข้อมูลไม่ถูกเก็บรวบรวม** 

**โดยสรุป:** 81 บท · ข้อคิดเห็นคู่ · ฉบับภาษาอังกฤษสองฉบับ · พินอินต่อตัวอักษร · ห้องศึกษา · แสวงหาเต๋า · บทรายวัน · 74 บรรทัดที่มีชื่อเสียง · การ์ด Dao · วิดเจ็ต · ศูนย์ควบคุม · `idao://` · EN / 简 / 繁 

## เริ่มต้นใช้งาน (ทีละขั้นตอน) 

### 1. เปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id6796016006) และเปิด **iDao**  
2. ทำตาม **คู่มือแนะนำต้อนรับ** ให้ครบ (แบรนด์ → การอ่านสองภาษา → ท่องจำ → Study Hall → ฟีเจอร์ของระบบ → ความเป็นส่วนตัว)  
3. เล่นซ้ำได้ทุกเมื่อ: **การตั้งค่า → ความช่วยเหลือ → คู่มือฟีเจอร์** (`idao://feature-guide`)  
4. คู่มือ **การใช้งาน / วิดเจ็ต / ทางลัด** ในแอปอยู่ภายใต้ **การตั้งค่า → ความช่วยเหลือ**  

### 2. อ่านบทของวันนี้ที่หน้า Home

1. เปิดแท็บ **Home**  
2. ฮีโร่ **บทประจำวัน** จะแสดงบทของวันนี้ (ช่วงฤดูกาล / เทศกาล / ฤดู) แตะเพื่อเปิดรายละเอียด  
3. ตัวเลือก: เปิดการแจ้งเตือน **บทประจำวัน** ในการตั้งค่า (กำหนดเวลาในเครื่องเท่านั้น)  
4. อ่านต่อ บทที่โด่งดัง คะแนนต่อเนื่อง, **ค้นหาต้าว**, และแนะนำเต๋า Laozi อยู่เพียงแตะเดียว  

### 3. เรียกดู & ค้นหา

1. เปิด **เรียกดู** (เปิดโดยค่าเริ่มต้น สามารถซ่อนได้ในการตั้งค่า) 
2. สำรวจ **Dao / De parts**, ธีม, **บทพูดที่มีชื่อเสียง**, คอลเลกชั่นหนังสือ (`ddj` / Qingjing / Yinfu) และทุกบท 
3. ใช้ **ค้นหา** สำหรับชื่อเรื่อง บรรทัด ภาษาท้องถิ่น และธีม (เป็นมิตรแบบง่าย / ดั้งเดิม) บน iOS ตัวเลือก **การค้นหาบทที่เขียนด้วยลายมือ** จะจดจำอักขระบนอุปกรณ์ 
4. ติดดาวบทต่างๆ ใน ​​**รายการโปรด**; สร้างรายการ **ส่วนตัว (道单)** แท็บรายการโปรด **เปิดใช้งานโดยค่าเริ่มต้น** 

### 4. ปิดการอ่าน โน้ตคู่ & การ์ดดาว 

1. ในรายละเอียด ให้เลือก **สองภาษา / จีนเท่านั้น / อังกฤษเท่านั้น**; สลับ **พินอิน** ภาษาถิ่น ฉบับวิจารณ์ และฉบับแปลโดยอิสระ 
2. สลับข้อคิดเห็น **วังปี้ ↔ เหอซ่างกง** เปรียบเทียบฉบับภาษาอังกฤษทั้งสองฉบับเมื่อมีทั้งสองฉบับ 
3. ลองใช้ **การแช่ในแนวตั้ง** การจัดกึ่งกลาง ขนาดแบบอักษร และ **การแบ่งหน้า** สำหรับบทที่ยาวขึ้น ใช้เมนูบท **เพิ่มเติม** สำหรับบันทึกย่อ ความเชี่ยวชาญ และบทที่อยู่ติดกัน 
4. เปิด **แชร์การ์ด** → เลือกสไตล์ / อัตราส่วน → บันทึกไปที่รูปภาพ (ส่วนเสริมเท่านั้น) หรือแชร์ระบบ 

### 5. ท่อง (诵读)

1. ในหน้ารายละเอียด แตะ **ท่องจำ** — หรือเปิดแท่นงานท่องจำ  
2. ทำตาม **การเน้นทีละบรรทัด** ขณะฟัง  
3. ใน **การตั้งค่า → การท่องจำ** ตั้งค่า **เมทริกซ์เนื้อหาการเล่น** (ต้นฉบับ / ภาษาเขต / ภาษาอังกฤษ) — แยกจากสิ่งที่คุณ *เห็น*; สลับได้ระหว่างการท่องจำและ **ต่อเนื่อง**  
4. ตัวเลือกเสริม: เล่นแบบเงียบ, เสียงพื้นหลัง + ตอนที่กำลังเล่น, เล่นต่อเนื่อง, ให้หน้าจอเปิดขณะพูด  
5. **จิ้งจิ้งจิง** และ **อินฟูจิง** ยังมาพร้อมฉบับภาษาอังกฤษสองฉบับเพื่อเปรียบเทียบและท่องจำ  

### 6. ห้องเรียน & แสวงหาต้าว  

1. เปิด **Study** จากหน้าหลัก / `idao://study` / ทางลัดสำหรับเมนูสี่โหมด  
2. โหมด: **Fade**, **Fill-blank**, **Self-check**, **Quiz** — พร้อมป้ายความเชี่ยวชาญสี่ระดับ  
3. เล่น **Seek the Tao (寻道)** ผ่านหน้าหลัก, ศูนย์ควบคุม หรือ `idao://hunt`  
4. ฝึกชุดจากรายการโปรดหรือรายการ; ติดตามความชำนาญและช่วงเวลาการอ่านต่อเนื่อง  

### 7. วิดเจ็ต, Siri & ทางลัดหน้าจอหลัก

1. กดค้างที่หน้าจอโฮม → **แก้ไขวิดเจ็ต** → เพิ่ม **บทประจำวัน / ประโยคดัง / ความคืบหน้าในการศึกษา / รายการโปรด**
2. ขอให้ **Siri** บอกบทวันนี้, ท่อง, สุ่ม, รายการโปรด, ล่า หรือค้นหา
3. ตั้งค่าการทำงานด่วนบนหน้าจอโฮมใน **การตั้งค่า → คำสั่งลัด**
4. การควบคุมในศูนย์ควบคุม (iOS 18+) รวมถึง วันนี้ / สุ่ม / ค้นหา / การศึกษา / การล่า และอื่น ๆ

### 8. ความเป็นส่วนตัว & การซิงค์

1. ไลบรารี, การอ่าน, การท่อง (TTS ระบบ), การศึกษา, วิดเจ็ต และการแจ้งเตือนในเครื่องทำงาน **ได้เต็มที่แบบออฟไลน์** หลังติดตั้ง
2. **การซิงค์ iCloud** เป็นทางเลือก จะสะท้อนรายการโปรด, รายการ, ประวัติ, ความชำนาญ, โน้ต และสถิติผ่าน **iCloud ส่วนตัวของคุณ** โดยมี **การรวมสองทาง** (ไม่ทับโดยไม่ดู)
3. ให้ทิปนักพัฒนา (ผ่าน StoreKit เป็นทางเลือก) จะไม่ปลดล็อกเนื้อหาที่ต้องจ่ายและจะไม่สร้างบัญชี

## ทำไมคุณถึงอยากดาวน์โหลด

- **Tao Te Ching เป็นสตูดิโอ** — โน้ตคู่ + ภาษาอังกฤษคู่ + พินอินในแอปเนทีฟอันเงียบสงบแอปเดียว 
- **การศึกษาที่ยั่งยืน** — จางหายไป / เติมข้อมูล / ตรวจสอบตัวเอง / แบบทดสอบ แสวงหาเต๋า และตราความเชี่ยวชาญ 
- **ประตูสู่ข้อความรายวัน** — บทรายวันตามบริบทพร้อมวิดเจ็ตและ Siri 
- **เนทีฟที่ช่วยได้** — กิจกรรมสด, ศูนย์ควบคุม, ลิงก์ในรายละเอียด, ตัวเลือกเสริมการผสาน iCloud 
- **ความเป็นส่วนตัวตามการออกแบบ** — ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK การวิเคราะห์
