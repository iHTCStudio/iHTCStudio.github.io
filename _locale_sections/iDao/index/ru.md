## Начало работы (шаг за шагом) 

### 1. Первый запуск

1. Установите из [App Store](https://apps.apple.com/app/id6796016006) и откройте **iDao**.
2. Пройдите **руководство для новичка** (бренд → двуязычное чтение → заучивание → Учебный зал → системные функции → конфиденциальность).
3. Повторите в любое время: **Настройки → Справка → Руководство по функциям** (`idao://feature-guide`).
4. Встроенные руководства по **Использованию / Виджетам / Быстрым командам** находятся в **Настройки → Справка**.

### 2. Читайте сегодняшнюю главу на главной странице

1. Откройте вкладку **Главная**.
2. В блоке **Ежедневная глава** отображается сегодняшняя глава (солнечные термины / праздники / сезоны); нажмите, чтобы открыть детали.
3. По желанию: включите **уведомления о ежедневной главе** в Настройках (только локальное расписание).
4. Продолжайте читать, знаменитые строки, серии, **Искать Дао** и введение в Лао Цзы доступны в один клик.

### 3. Просмотр и поиск

1. Откройте **Обзор** (по умолчанию включено; можно скрыть в настройках). 
2. Изучите **Части Дао/Дэ**, темы, **знаменитые строки**, коллекции книг (`ddj`/Цинцзин/Иньфу) и все главы. 
3. Используйте **Поиск** по названиям, строкам, диалекту и темам (упрощенный/традиционный вариант). В iOS дополнительный **поиск по главам** распознает символы на устройстве. 
4. Поместите главы в **Избранное**; создавать личные **списки (道单)**. Вкладка «Избранное» включена **по умолчанию**. 

### 4. Чтение внимательнее, двойные заметки и карты Дао. 

1. Подробно выберите **двуязычный/только китайский/только английский**; независимо переключать **пиньинь**, народный язык, версию комментариев и версию перевода. 
2. Переключить комментарии **Ван Би ↔ Хешанг Гун**; сравните два английских издания, когда оба будут доступны. 
3. Попробуйте **вертикальное погружение**, центрирование, масштаб шрифта и **сегментированные страницы** для более длинных глав. Используйте меню главы **Дополнительно** для примечаний, мастерства и соседних глав. 
4. Откройте **Карточка общего доступа** → выберите стиль/пропорции → сохраните в «Фото» (только для добавления) или в системную папку. 

### 5. Произнесите (诵读)

1. В режиме просмотра деталей нажмите **Recite** — или откройте рабочую панель для чтения вслух.
2. Следите за **подсветкой на уровне строк** во время прослушивания.
3. В **Настройки → Чтение вслух** установите **матрицу воспроизведения контента** (оригинал / разговорный / английский) — независимо от того, что вы *видите*; меняйте на ходу во время чтения и **продолжайте**.
4. Необязательно: воспроизведение в тихом режиме, фоновое аудио + теперь воспроизводится, непрерывное воспроизведение, не выключать экран во время озвучивания.
5. **Qingjing Jing** и **Yinfu Jing** также поставляются с двумя английскими изданиями для сравнения и чтения вслух.

### 6. Учебный зал и поиск Дао

1. Откройте **Изучение** с главного экрана / `idao://study` / Ярлыки для меню четырех режимов.
2. Режимы: **Fade**, **Fill-blank**, **Self-check**, **Quiz** — с бейджами мастерства из четырех уровней.
3. Воспроизведите **Seek the Tao (寻道)** через Главный экран, Пункт управления или `idao://hunt`.
4. Пакетная практика из избранного или списков; отслеживайте уровень мастерства и серию чтений.

### 7. Виджеты, Siri и ярлыки на главном экране

1. Долгое нажатие на главный экран → **Редактировать виджеты** → добавить **Ежедневная глава / Известная фраза / Прогресс обучения / Избранное**.
2. Спросите **Siri** о сегодняшней главе, прочтите, случайной, избранном, поиске или охоте.
3. Настройте быстрые действия на главном экране в **Настройки → Сочетания клавиш**.
4. Элементы управления в Пункте управления (iOS 18+) включают Сегодня / Случайное / Поиск / Обучение / Охота и другие.

### 8. Конфиденциальность и синхронизация

1. Библиотека, чтение, повторение (системный TTS), обучение, виджеты и локальные уведомления работают **полностью офлайн** после установки.
2. Опциональная **синхронизация iCloud** зеркалирует избранное, списки, историю, освоение, заметки и серии через **ваш приватный iCloud** с **двусторонним слиянием** (без слепой перезаписи).
3. Пожертвование разработчику (опциональный StoreKit) никогда не открывает платный контент и никогда не создаёт аккаунт.
