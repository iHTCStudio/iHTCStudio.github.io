## การเก็บข้อมูล

เรา **ไม่** เก็บ, ขาย, หรือแชร์ข้อมูลส่วนบุคคลสำหรับการโฆษณาหรือการวิเคราะห์

- **ไม่ต้องมีบัญชี** — คุณสามารถใช้คุณสมบัติหลักทั้งหมดได้โดยไม่ต้องสร้างบัญชีกับเรา
- **ไม่มีการวิเคราะห์หรือโฆษณา** — ไฟล์แอปไม่ได้รวม SDK การวิเคราะห์ บุคคลที่สาม, การโฆษณา หรือรายงานข้อขัดข้องที่ส่งข้อมูลกลับมาหาเรา
- **ไม่มีการอัปโหลดเนื้อหา** — ประวัติการอ่าน รายการโปรด รายการ หมายเหตุ บันทึกการสตรีม หนังสือที่ผิด ความเชี่ยวชาญ สตรีค และการตั้งค่าของคุณจะเก็บอยู่บนอุปกรณ์ของคุณ (และสามารถเก็บใน **iCloud ของคุณ** ได้ตามต้องการ) ข้อมูลเหล่านี้จะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ iHTC Studio เพราะ **เราไม่ได้ดำเนินการเซิร์ฟเวอร์ดังกล่าวสำหรับแอปนี้**

## วิธีการทำงานของแอป

- **ไลบรารีรวม** — Hexagram JSON, Ten Wings, ไตรแกรม, เส้นที่มีชื่อเสียง และดัชนีจัดส่งภายในชุดแอป / วิดเจ็ต การเรียกดูและการศึกษาไม่จำเป็นต้องมีการร้องขอเครือข่าย 
- **คำพูดบนอุปกรณ์** — การบรรยายใช้ระบบของ Apple **AVSpeechSynthesizer** (TTS) เราไม่ส่งข้อความหกเหลี่ยมไปที่ iHTC Studio 
- **การคัดเลือกนักแสดงทางวัฒนธรรม** — ขั้นตอนการใช้เหรียญและยาร์โรว์ทำงานบนอุปกรณ์ทั้งหมดเพื่อเป็นสัญลักษณ์ทางการศึกษา บันทึกที่คุณเลือกที่จะบันทึกอยู่ในเครื่อง (และเป็นทางเลือกใน iCloud ของคุณ) 
- **วิดเจ็ตและกลุ่มแอป** — วิดเจ็ตและแอปแบ่งปันการตั้งค่าและสถานะแบบเบาผ่านกลุ่มแอป `group.com.iHTCboy.iYiJing` บนอุปกรณ์ของคุณ 
- **การแจ้งเตือนรายวัน** — กำหนดเวลาภายในเครื่องด้วยการแจ้งเตือนผู้ใช้ การแตะจะเปิดลิงก์ในรายละเอียดไปยังรหัสหกเหลี่ยมบนอุปกรณ์ ไม่มีการปิดเซิร์ฟเวอร์ 
- **การ์ดการศึกษา** — รูปภาพถูกเรนเดอร์บนอุปกรณ์ การบันทึกจะใช้ **เฉพาะส่วนเสริมคลังรูปภาพ** เฉพาะเมื่อคุณแตะบันทึก เอกสารการแชร์ระบบอาจส่งรูปภาพไปยังแอป **คุณ** เลือก; นโยบายความเป็นส่วนตัวของปลายทางนั้นจึงจะมีผลใช้บังคับ 
- **เคล็ดลับเสริม** — “Tip Developer” เป็นการซื้อ **StoreKit** แบบบริโภคที่ดำเนินการโดย Apple เราไม่ได้รับรายละเอียดบัตรชำระเงินของคุณ 
- **Siri / ทางลัด / ศูนย์ควบคุม** — การรวมระบบที่เป็นตัวเลือกจะเปิดลิงก์ในรายละเอียดบนอุปกรณ์ พวกเขาไม่ได้ส่งห้องสมุดของคุณมาให้เรา 
- **สปอตไลท์เสริม** — หากคุณเปิดใช้งานการจัดทำดัชนี เนื้อหาจะถูกจัดทำดัชนีโดยระบบบนอุปกรณ์สำหรับการค้นหาในท้องถิ่น เราไม่ได้ดำเนินการแบ็กเอนด์การค้นหา 
- **กิจกรรมสดเสริม** — ปิดตามค่าเริ่มต้น เมื่อเปิดใช้งาน จะแสดงแฉกที่คุณกำลังอ่านบนหน้าจอล็อค / เกาะไดนามิก

## การซิงค์ iCloud (ไม่บังคับ)

หากคุณเปิดใช้งาน **การซิงค์ iCloud** ในการตั้งค่า แอปจะสะท้อนข้อมูลผู้ใช้ที่เลือกผ่าน **`NSUbiquitousKeyValueStore`** ของ Apple ที่เชื่อมโยงกับ **Apple ID ของคุณ** โดยใช้กฎการรวมสำหรับรายการโปรด รายการ ประวัติ การเชี่ยวชาญ บันทึก หมายเหตุ บันทึกการสะกดผิด และสถิติการทำติดต่อกัน  

ข้อมูลซิงค์จะส่งไปยัง **Apple iCloud** ไม่ใช่ iHTC Studio คุณสามารถปิดการซิงค์ได้ในการตั้งค่า เราไม่สามารถอ่านเนื้อหา iCloud ของคุณได้

iYijing ขอสิทธิ์การเข้าถึงเฉพาะเมื่อมีฟีเจอร์ที่ต้องการ:

| สิทธิ์ | เมื่อ | ทำไม |
|------------|------|-----|
| การแจ้งเตือน | คุณเปิดการแจ้งเตือนรายวันของเลขศาสตร์ | การตั้งเวลาแจ้งเตือนภายในแอป |
| ไลบรารีรูปภาพ (เพิ่มได้เท่านั้น) | คุณบันทึกการ์ดการศึกษา | เขียนภาพที่สร้างขึ้น; เราไม่ต้องการสิทธิ์อ่านไลบรารีทั้งหมด |
| iCloud | คุณเปิดการซิงค์ | ซิงค์รายการโปรด / รายการ / ประวัติ / ความชำนาญ / โน้ต / การทอย / หนังสือผิด / สถิติการใช้งานต่อเนื่อง |
| กิจกรรมสด (iOS) | คุณเปิดกิจกรรมสดสำหรับการอ่าน | แสดงเลขศาสตร์ที่คุณกำลังอ่านบนหน้าจอล็อก / Dynamic Island |
| เสียงพื้นหลัง (ความสามารถ) | คุณเปิดการท่องจำพื้นหลัง | ดำเนินการ TTS ต่อเมื่อแอปไม่อยู่หน้าแรก |

เรา **ไม่** ขอสิทธิ์ การเข้าถึงรายชื่อผู้ติดต่อ, ตำแหน่งที่แน่นอน, กล้อง, ไมโครโฟน (ยกเว้นการเล่น TTS ของระบบ), หรือ การติดตาม.

## สิ่งที่เราไม่ทำ

- เราไม่ **ไม่** ขายข้อมูลส่วนบุคคล 
- เราไม่ **ไม่** สร้างโปรไฟล์การโฆษณา 
- เรา **ไม่** จำเป็นต้องมีบัญชีหรือการเข้าสู่ระบบโซเชียล 
- เราไม่ **ไม่** ฝังโฆษณา การวิเคราะห์ หรือ SDK โซเชียลของบุคคลที่สามสำหรับการรวบรวมข้อมูล 
- เราไม่ **ไม่** เข้าถึงคลังภาพของคุณเกินกว่า **เพิ่มเท่านั้น** เมื่อคุณเลือกที่จะบันทึกการ์ด 
- เรา **ไม่** รับหมายเลขบัตรชำระเงิน StoreKit (Apple ดำเนินการชำระเงิน) 
- เราไม่ **ไม่** ส่งคำถามการคัดเลือกนักแสดงหรือผลลัพธ์ไปยังเซิร์ฟเวอร์ใดๆ 

## ความเป็นส่วนตัวของเด็ก 

iYijing จะไม่รวบรวมข้อมูลส่วนบุคคลจากใครก็ตามโดยเจตนา รวมถึงเด็กอายุต่ำกว่า 13 ปี (หรืออายุเทียบเท่าในภูมิภาคของคุณ) เนื่องจากเราไม่ได้ดำเนินการแบ็กเอนด์การรวบรวมข้อมูล จึงไม่มีโปรไฟล์ย่อยเก็บไว้กับเรา ครอบครัวอาจใช้คุณสมบัติการอ่านและการศึกษาแบบออฟไลน์บนอุปกรณ์ของตนเอง 

## บุคคลที่สาม 

- **Apple** — การจำหน่าย App Store, การซื้อ StoreKit ที่เป็นตัวเลือก, ตัวเลือก iCloud KVS, TTS ระบบ, ปลายทาง Share Sheet ที่คุณเลือก และการแจ้งเตือนระดับระบบปฏิบัติการ / กิจกรรมสด / Siri / การส่งทางลัด 
- **ไม่มี SDK บุคคลที่สามอื่นๆ** สำหรับโฆษณา การวิเคราะห์ หรือการเข้าสู่ระบบโซเชียลรวมอยู่ในการรวบรวมข้อมูล 

## ผู้ใช้ต่างประเทศ

แอปได้รับการออกแบบมาให้ทำงานแบบออฟไลน์บนอุปกรณ์ของคุณ บริการเสริมของ Apple เป็นไปตามข้อกำหนดของ Apple และความพร้อมให้บริการในภูมิภาค 

## การเก็บรักษาและการลบข้อมูล 

- **บนอุปกรณ์** — การตั้งค่าท้องถิ่นและความคืบหน้าจะยังคงอยู่จนกว่าคุณจะล้างข้อมูลในแอป (หากมี) รีเซ็ตอุปกรณ์ หรือถอนการติดตั้งแอป 
- **iCloud (เป็นทางเลือก)** — ข้อมูลที่คุณซิงค์จะยังคงอยู่ในบัญชี **ของคุณ** iCloud ภายใต้นโยบายของ Apple จนกว่าคุณจะปิดใช้งานการซิงค์และ/หรือล้างข้อมูลผ่านเครื่องมือของ Apple 
- **iHTC Studio** — เนื่องจากเราไม่ได้เก็บรวบรวมข้อมูลส่วนบุคคลบนเซิร์ฟเวอร์ของเรา จึงไม่มีชุดข้อมูลบัญชีให้เราลบตามคำขอ นอกเหนือจากการตอบคำถามทางอีเมลของคุณ
