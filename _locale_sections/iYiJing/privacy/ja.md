**最終更新日:** 2026年8月5日

iHTC Studio（「私たち」、「当社」または「弊社」）は**iYijing**（「爱周易」／「愛周易」とも呼ばれる、バンドルID `com.iHTCboy.iYiJing`）を開発しました。本プライバシーポリシーは、アプリを使用する際にどのデータが取り扱われる（及び取り扱われない）かを説明します。**AppleのApp Review**やユーザーは、アプリの公開プライバシーポリシーとして**本ページ**を利用することができます。App Store Connect用には、ブラウザで本プライバシーポリシーを開き、アドレスバーからアドレスをコピーしてください（公開サイトのドメインは時間とともに変更される場合があります）。

## 概要（Appleプライバシー栄養表示ラベルとの整合）

| トピック | 当アプリの取り組み |
|-------|----------------|
| アカウント | **不要** — 登録、メールサインイン、電話番号は必要ありません |
| iHTCスタジオによるデータ収集 | **収集なし** — 個人データを受け取るバックエンドは運営していません |
| ネットワーク | ライブラリ、読書、暗唱、文化キャスティング、学習ホール、ウィジェット、毎日の通知はインストール後**オフライン**で動作します |
| 分析／広告／追跡 | **なし** — サードパーティの分析、広告、追跡SDKはありません；App Tracking Transparencyも使用していません |
| 任意のAppleサービス | **iCloud**（個人KVS、マージ）、**写真ライブラリ（追加のみ）**、学習カード用、**StoreKit**（任意のチップ）、**ローカル通知**、任意の**ライブアクティビティ** |

## データ収集

個人情報を広告や分析のために**収集、販売、共有**することはありません。

- **アカウント不要** — アカウントを作成しなくても、すべての基本機能を利用できます。
- **分析や広告なし** — アプリ本体には、私たちに情報を送信するサードパーティの分析、広告、クラッシュ報告SDKは組み込まれていません。
- **コンテンツアップロードなし** — あなたの読書履歴、お気に入り、リスト、ノート、キャスティング記録、誤った本、習得状況、連続記録、設定はデバイス上に保持されます（必要に応じて**あなたの**iCloudにも保存されます）。iHTC Studioのサーバーには一切アップロードされません。**このアプリにはそのようなサーバーは運営していません。**

## アプリの仕組み

- **バンドルされたライブラリ** — ヘキサグラム JSON、十翼、トリグラム、有名なセリフ、インデックスがアプリ / ウィジェット バンドル内に同梱されています。 閲覧や学習にはネットワーク リクエストは必要ありません。 
- **オンデバイス音声** - 朗読には Apple のシステム **AVSpeechSynthesizer** (TTS) が使用されます。 ヘキサグラムのテキストは iHTC Studio に送信されません。 
- **文化的鋳造** — 教育的象徴性を目的として、コインとノコギリソウの手順は完全にデバイス上で実行されます。 保存することを選択したレコードはローカルに残ります (オプションで iCloud にも保存できます)。 
- **ウィジェットとアプリ グループ** - ウィジェットとアプリは、デバイス上のアプリ グループ `group.com.iHTCboy.iYiJing` を介して設定と軽量状態を共有します。 
- **毎日の通知** - ユーザー通知を使用してローカルにスケジュールされます。 タップすると、デバイス上のヘキサグラム ID へのディープ リンクが開きます。 サーバーのファンアウトはありません。 
- **学習カード** — 画像はデバイス上でレンダリングされます。 保存すると、[保存] をタップした場合にのみ **フォト ライブラリの追加のみ**が使用されます。 システム共有シートは、**あなた**が選択したアプリに画像を送信できます。 その場合、その宛先のプライバシー ポリシーが適用されます。 
- **オプションのチップ** - 「チップ開発者」は、Apple によって処理される消耗品 **StoreKit** の購入です。 私たちはあなたの支払いカードの詳細を受け取りません。 
- **Siri / ショートカット / コントロール センター** — オプションのシステム統合により、デバイス上のディープ リンクが開きます。 彼らはあなたのライブラリを私たちに送ることはありません。 
- **オプションのスポットライト** — インデックス作成を有効にすると、ローカル検索のためにデバイス上のシステムによってコンテンツのインデックスが作成されます。 当社は検索バックエンドを運用していません。 
- **オプションのライブ アクティビティ** — デフォルトではオフです。 有効にすると、ロック画面/ダイナミックアイランドに現在読んでいる六芒星が表示されます。

 | データ | どこ | 目的 |

 | キャスティング記録 | アプリグループのUserDefaults | あなたが保存する文化的な鋳造の歴史 |
 | メモ | アプリグループのUserDefaults | あなたが書くメモ |
 | 連続記録 / チェックイン | アプリグループのUserDefaults | 日々の習慣 |
 | 外観と読み取り設定 | アプリグループのUserDefaults | テーマ、アクセント、言語、レイアウト、TTS、タブ、ウィジェット |
 | 毎日の Hexagram キャッシュと通知設定 | アプリグループのUserDefaults | 今日のID、予定時間 |

アプリをアンインストールすると、アプリに関連するサンドボックスおよびアプリグループのデータが削除されます（iOS/macOSの動作に依存します）。オプションで作成されたiCloudコピーは、削除するか同期をオフにして他の場所で削除するまで、**あなたの**iCloudに残ります。

## iCloud同期（オプション）

設定で**iCloud同期**を有効にすると、アプリは選択されたユーザーデータを**あなたのApple ID**に紐づけられたAppleの**`NSUbiquitousKeyValueStore`**を通じてミラーリングし、フェイバリット、リスト、履歴、習熟度、メモ、投げ記録、間違い帳、連続使用記録に対する統合ルールを使用します。

同期トラフィックは**Apple iCloud**に送信され、iHTC Studioには送信されません。設定で同期を無効にすることができます。私たちはあなたのiCloudの内容を読むことはできません。

## 権限

iYijingは、機能が必要とする場合にのみ権限を要求します:

| 許可 | いつ | なぜ |
|------------|------|-----|
| 通知 | 毎日の六十四卦のリマインダーを有効にしたとき | リマインダー通知のローカルスケジュール管理 |
| 写真ライブラリ（追加のみ） | 学習カードを保存するとき | レンダリングされた画像を書き込むため；ライブラリ全体の読み取り権限は不要 |
| iCloud | 同期を有効にしたとき | お気に入り / リスト / 履歴 / 習熟度 / メモ / 占い / 間違い帳 / 連続記録を同期 |
| ライブアクティビティ（iOS） | リーディングライブアクティビティを有効にしたとき | ロック画面 / ダイナミックアイランドに読んでいる卦を表示 |
| バックグラウンドオーディオ（機能） | バックグラウンドでの朗読を有効にしたとき | アプリが前面でないときもTTSを継続 |

私たちは**連絡先、正確な位置情報、カメラ、マイク（システムTTS再生を除く）、トラッキング**は要求しません。

## 私たちがしないこと

- 当社は個人データを**販売しません**。 
- 当社は広告プロフィールを構築しません**。 
- アカウントやソーシャル ログインは**必要ありません**。 
- データ収集のためにサードパーティの広告、分析、ソーシャル SDK を埋め込むことは**ありません**。 
- カードの保存を選択した場合、**追加のみ**を超えてフォト ライブラリにアクセスすることは**ありません**。 
- 当社は StoreKit 支払いカード番号を**受け取りません** (Apple は支払いを処理します)。 
- キャストに関する質問や結果をサーバーに送信することは**ありません**。 

## 子供のプライバシー

 iYijing は、13 歳未満 (またはお住まいの地域の同等の年齢) の子供を含む、いかなる人物からも故意に個人データを収集することはありません。 当社はデータ収集バックエンドを運用していないため、お子様のプロファイルは保存されません。 家族は自分のデバイスでオフラインで読書および学習機能を使用できます。 

## サードパーティ

 - **Apple** — App Store の配布、オプションの StoreKit の購入、オプションの iCloud KVS、システム TTS、選択した共有シートの宛先、および OS レベルの通知 / ライブ アクティビティ / Siri / ショートカットの配信。 
- **広告、分析、ソーシャル ログイン用の他のサードパーティ SDK** はデータ収集には含まれません。 

## 海外ユーザー

アプリはデバイス上でオフラインで機能するように設計されています。 オプションの Apple サービスは、Apple の規約と利用可能な地域に従います。 

## データの保持と削除

 - **デバイス上** — ローカル設定と進行状況は、アプリ内でクリアするか (可能な場合)、デバイスをリセットするか、アプリをアンインストールするまで残ります。 
- **iCloud (オプション)** - 同期したデータは、同期を無効にするか、Apple のツールを通じて消去するまで、Apple のポリシーに従って **iCloud アカウントに残ります。 
- **iHTC Studio** – 当社はサーバー上で個人データを収集しないため、メールでの質問に回答する以外に、リクエストに応じて削除できるアカウント データセットはありません。
