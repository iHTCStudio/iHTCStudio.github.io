**หนึ่งแฉก โลกแห่งความหมาย** 

iYijing (爱周易 / 愛周易) คือ **สตูดิโอเรียน Zhouyi ออฟไลน์** — ไม่ใช่คำทำนายดวงชะตา และไม่ใช่การถ่ายโอนข้อมูลข้อความธรรมดาอื่นๆ **ไม่จำเป็นต้องมีบัญชี** ทั้งหมด **64 hexagrams** จัดส่งบนอุปกรณ์ของคุณพร้อมการตัดสินและบรรทัด **Tuan / Xiang** ตัวเลือก **ภาษาถิ่น** **พินอิน** บนชื่อหลัก และ **ภาษาอังกฤษ**; บวก **ห้าสิบปีก**, **แปดไตรแกรม** และ **100** บรรทัดที่มีชื่อเสียง **อ่าน** พร้อมแผนที่ความสัมพันธ์ (นิวเคลียร์ / ตรงกันข้าม / กลับด้าน / เปลี่ยนแปลง); **ท่อง** พร้อมไฮไลท์; การปฏิบัติใน **อี้จิงศึกษา**; ลองใช้ **การคัดเลือกนักแสดงทางวัฒนธรรม** (เหรียญและยาร์โรว์) เป็นการรู้หนังสือ ไม่ใช่การทำนาย เปิด **แฉกรายวัน** ตามบริบท ส่งออก **การ์ดการศึกษา**, เพิ่ม **วิดเจ็ต**, ตัวเลือก **กิจกรรมการอ่านสด**, **Siri และคำสั่งลัด** และตัวเลือก **ผสาน iCloud** ** ไม่มีโฆษณา ไม่มีการติดตาม ข้อมูลไม่ถูกเก็บรวบรวม** 

**โดยสรุป:** 64 เฮกซะแกรม · สิบปีก · 8 ไตรแกรม · การศึกษาสองภาษา · การคัดเลือกนักแสดงทางวัฒนธรรม · ห้องศึกษา (6 โหมด + ค้นหาคำหลัก) · แฉกรายวัน · 100 บรรทัดที่มีชื่อเสียง · การ์ดการศึกษา · วิดเจ็ต · ศูนย์ควบคุม · `iyijing://` · EN / 简 / 繁 

## เริ่มต้นใช้งาน (ทีละขั้นตอน) 

### 1. เปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id6796014759) และเปิด **iYijing** 
2. กรอก **คู่มือต้อนรับ 6 หน้า** (แบรนด์ → การอ่าน → การคัดเลือกนักแสดงทางวัฒนธรรม → ห้องศึกษา → คุณสมบัติของระบบ → บันทึกความเป็นส่วนตัว / การศึกษา) 
3. เล่นซ้ำได้ทุกเมื่อ: **การตั้งค่า → ช่วยเหลือ → คู่มือฟีเจอร์** (`iyijing://feature-guide`) 
4. คู่มือ **การใช้งาน / วิดเจ็ต / ทางลัด** ในแอปอยู่ภายใต้ **การตั้งค่า → ความช่วยเหลือ** 

### 2. พบกับแฉกวันนี้ที่หน้าแรก 

1. เปิดแท็บ **หน้าแรก** 
2. **รูปหกเหลี่ยมรายวัน** แสดงกัวของวันนี้พร้อมลำดับชั้นของชื่อ (ชื่อหลัก → พินอิน → ชื่อรูปภาพ → อังกฤษ → หนึ่งบรรทัด) แตะเพื่อเปิดรายละเอียด 
3. ตัวเลือกเสริม: เปิดใช้งาน **การแจ้งเตือน Hexagram รายวัน** ในการตั้งค่า (การตั้งเวลาท้องถิ่นเท่านั้น) 
4. อ่านต่อ ทางลัด ลายเส้น เส้นดัง **นักแสดง** และ **เรียน** ทำได้ด้วยการแตะเพียงครั้งเดียว 

### 3. เรียกดู ไตรแกรม และปีกทั้งสิบ 

1. เปิด **เรียกดู** (สามารถซ่อนได้ในการตั้งค่า) 
2. สำรวจ **64 เมทริกซ์ / รายการ**, หลักบนและล่าง, **พระราชวังแปดแห่ง**, **ไตรแกรม** (พร้อมวงกลมบอกทิศทาง), **สิบปีก** และเส้นที่มีชื่อเสียง 
3. ปรับแต่งการมองเห็นส่วน การเรียงลำดับ และจำนวนคอลัมน์ 
4. **ค้นหา** ครอบคลุมถึงชื่อ ต้นฉบับ ภาษาถิ่น และภาษาอังกฤษ (ประยุกต์/ดั้งเดิมที่เป็นมิตร)

### 4. การอ่านอย่างละเอียด ความสัมพันธ์ & การ์ดศึกษาซ้ำ

1. ในรายละเอียด ตั้งค่า **การแสดงผลภาษาอังกฤษ**: ปิด / ภาษาอังกฤษใต้ต้นฉบับ / เปรียบเทียบสองภาษา; สลับภาษาท้องถิ่น, พินอิน, และเซียงได้อิสระ
2. สำรวจ **ชิปความสัมพันธ์** (ปกติ / ตรงข้าม / กลับหัว / เปลี่ยน) เพื่อกระโดดระหว่างเลขหกเหลี่ยมที่เกี่ยวข้อง
3. ลอง **การอ่านแนวตั้งแบบดื่มด่ำ**, **ขนาดตัวอักษรต่อเนื่อง** (50%–300%), หมายเหตุ และความชำนาญ
4. เปิด **แชร์การ์ด** → เลือกสไตล์ / อัตราส่วนหลากหลาย → บันทึกไปยัง Photos (เพิ่มได้อย่างเดียว) หรือแชร์ผ่านระบบ

### 5. การท่องจำ

1. ในรายละเอียด แตะ **พูด** — หรือเปิด **เวิร์กเบนช์การท่องจำ** สำหรับคิวหลายเลขหกเหลี่ยม
2. ติดตามการเน้นระดับบรรทัด; สามารถตั้งหยุดตามเลื่อนขณะที่คุณลากได้
3. ใน **การตั้งค่า → การพูด**, กำหนดเสียง, ความเร็ว, และเนื้อหาการเล่น
4. เสริมได้: เสียงพื้นหลัง + กำลังเล่น; **กิจกรรมการอ่านสด** ถูกปิดโดยค่าเริ่มต้น (ต้องเลือกใช้เอง)

### 6. การสร้างเลขหกเหลี่ยมทางวัฒนธรรม (起卦) — เพื่อรู้หนังสือ ไม่ใช่ทำนาย

1. เปิด **การทำนาย** จากหน้าแรก / ศูนย์ควบคุม / `iyijing://divination`
2. เลือกวิธี **เหรียญ** หรือพิธี **ก้านเย่ย (ดายัน)** เพื่อเรียนรู้ขั้นตอนและสัญลักษณ์แบบดั้งเดิม
3. ดูหกเหลี่ยมเริ่มต้น / หกเหลี่ยมที่เปลี่ยนแปลง และเส้นที่เคลื่อนไหว; บันทึกตัวเลือกพร้อมคำถามและข้อคิดของคุณ
4. การคัดลอกในแอปชัดเจน: ผลลัพธ์ **เพื่อการศึกษาและการสะท้อนทางวัฒนธรรมเท่านั้น** — **ไม่ใช่** การทำนายโชคชะตา คำแนะนำ หรือการพยากรณ์

### 7. การศึกษาอี้จิง & การล่าสำคัญคำ

1. เปิด **การศึกษา** จากหน้าแรก / `iyijing://study`
2. มี 6 โหมดแบบทดสอบ: **ชื่อ / ตัวอักษร / ลำดับ / เติมคำตัดสิน / ตำแหน่งเส้น / แปดทิศ**, บวก **การล่าคำสำคัญ** (`iyijing://hunt`)
3. คำตอบผิดจะไปยัง **สมุดคำตอบผิด**; คำตอบถูกจะช่วยพัฒนาความชำนาญ (พร้อมการสะสม)
4. ทำชุดจากรายการโปรดหรือ **รายชื่อหกเหลี่ยม (卦单)** ที่กำหนดเอง

### 8. วิดเจ็ต, Siri & ความเป็นส่วนตัว

1. เพิ่มวิดเจ็ต: **แฉกรายวัน / เส้นที่มีชื่อเสียง / รายการโปรด / ความคืบหน้าการศึกษา** 
2. ถาม **Siri** สำหรับกัว สุ่ม คัดเลือก ศึกษา ล่า หรือค้นหาในวันนี้ 
3. ตัวเลือก **iCloud Sync** จะรวมรายการโปรด รายการ ประวัติศาสตร์ ความเชี่ยวชาญ โน้ต บันทึกการคัดเลือก สมุดผิด และลายเส้นผ่าน **iCloud ส่วนตัวของคุณ** 
4. เคล็ดลับนักพัฒนา (อุปกรณ์เสริม StoreKit) จะไม่ปลดล็อกเนื้อหาเพย์วอลล์และไม่เคยสร้างบัญชี 

## ทำไมคุณถึงต้องการดาวน์โหลด 

- **Zhouyi เป็นสตูดิโอการเรียนรู้ที่แท้จริง** — ข้อความ ความสัมพันธ์ Ten Wings และการอ่านสองภาษาในแอปเนทีฟอันเงียบสงบแอปเดียว 
- **การคัดเลือกนักแสดงเป็นวัฒนธรรม** — เรียนรู้พิธีกรรมโดยไม่ต้องอาศัยการทำนายดวงชะตา 
- **การศึกษาที่ยึดติด** — โหมดตอบคำถามหกโหมด การล่าคำหลัก หนังสือเล่มที่ผิด และความเชี่ยวชาญ 
- **ประตูสู่ความคลาสสิกทุกวัน** — Hexagram รายวันพร้อมวิดเจ็ตและ Siri 
- **ความเป็นส่วนตัวตามการออกแบบ** — ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK การวิเคราะห์ 

## คุณสมบัติ 

### สตูดิโอ Zhouyi สองภาษา 
- **64** หกเหลี่ยม · การตัดสินและเส้น · ต้วน / เซียง · ภาษาพื้นถิ่น · พินอิน · อังกฤษ 
- **5** สิบปีก · **8** ไตรแกรม · **100** เส้นที่มีชื่อเสียง · แผนที่สัมพันธ์ 
- การอ่านแบบดื่มด่ำ / แนวตั้ง · การ์ดการศึกษาหลายสไตล์

### การบรรยาย การคัดเลือกนักแสดง และการศึกษา 
- TTS ระดับบรรทัด · คิวการบรรยาย · กิจกรรมสดที่เป็นตัวเลือก (เลือกใช้) 
- เหรียญและยาร์โรว์ **การคัดเลือกนักแสดงทางวัฒนธรรม** พร้อมข้อจำกัดความรับผิดชอบด้านการศึกษาเท่านั้น 
- โหมดตอบคำถามหกโหมด · การค้นหาคำหลัก · หนังสือผิด · ความเชี่ยวชาญ · ต่อเนื่อง 

### Hexagram รายวันและการรวมระบบ 
- พูลรายวันตามบริบท · การแจ้งเตือนในท้องถิ่น 
- วิดเจ็ต · ศูนย์ควบคุม · Siri · `iyijing://` ลิงก์ในรายละเอียด 
- สปอตไลต์เสริม · ผสาน iCloud แบบสองทิศทางเสริม 

### ความเป็นส่วนตัว 
- **ไม่มีบัญชี · ไม่มีโฆษณา · ไม่มี SDK การวิเคราะห์**
