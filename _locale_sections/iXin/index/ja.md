**認識し、一丸となって行動する**

 iXin (愛王阳明 / 愛王陽明) は **オフラインの陽明スタジオ** であり、別の *Chuanxilu* ダンプではありません。 **アカウントは必要ありません。** すべての **102** パッセージがデバイスに同梱されています: *実践的な生活のための指示*、*偉大な学習に関する調査*、*龍昌の学生への指示*、*埋葬旅行者に関するエッセイ*、さらに詩、年代記、コンセプト カード。 すべての作品には、Henke (1916) の精神に基づいた **現地語の中国語** と **英語** が含まれています。 ユニークな **Knowing-Acting ジャーナル** と **Liangzhi の 3 つの質問** は、知行合一を毎日の実践に変えます。 **デイリー インサイト**から始めます。 段落を強調表示して **暗唱**します。 **ハートスクール**で練習してください。 **インサイト カード**をエクスポートします。 **ウィジェット**、オプションの**ライブアクティビティの読み取り**、**Siriとショートカット**、およびオプションの**iCloud**を追加します。 オリジナルはパブリックドメインです。 ノートは勉強の補助です。 **広告はありません。 追跡はありません。 Data Not Collected.**

 **概要:** 102 の文章 · 8 人の著者 · 100 の有名なセリフ · バイリンガル · 知識と行動のジャーナル · 梁志プロンプト · グラフ / タイムライン / 地図 / 人物 · 朗読 · ハートスクール · ハートハント · デイリーインサイト · インサイトカード · ウィジェット · コントロールセンター · `ixin://` · EN / 简 / 繁。 

## はじめに (ステップバイステップ)

### 1. 最初の起動

 1. [App Store](https://apps.apple.com/app/id1180009069) からインストールし、**iXin** を開きます。 
2. ウェルカム ガイドを完了します: デイリー インサイト → 朗読 → 精読 → ハート スクール → 日記 → 良知 → ジェスチャー → プライバシー。 
3. **[設定] → [ヘルプ] → [機能ガイド]** (`ixin://feature-guide`) でいつでも再生できます。 
4. 使用法、ウィジェット、およびショートカットのガイドは、**設定 → ヘルプ** にあります。 

### 2. ホームで今日の洞察を読む

 1. [**ホーム**] タブを開きます。 
2. **Daily Insight** のヒーローが今日の一節を示します。 タップして詳細を開きます。 
3. オプション: 設定でローカルの **Daily Insight 通知**を有効にします。 
4. ホームから暗唱、ハートスクール、ハートハント、日記、お気に入り、検索にジャンプします。 

### 3. 参照と検索

 1. *伝西路*、*大いなる学問の探求*、龍昌の指示、*埋葬エッセイ*、詩/年代記/概念、人物、および**100の有名なセリフ**を閲覧します。 
2. タイトル、原文、名セリフを検索します。 iOS では、オプションの **手書き検索** によりデバイス上の文字が認識されます。 
3. 文章にスターを付けて **お気に入り**に追加し、個人用**リスト** (心单) に集めます。 

### 4. 精読、日記、洞察カード

1. **バイリンガル/中国語のみ/英語のみ**を切り替えます。 母国語、英語、ピンインを個別に切り替えます。 
2. **Knowing-Acting ジャーナル** (`ixin://journal`) と **良志の 3 つの質問** (`ixin://liangzhi`) を開きます。 コンセプト グラフ、タイムライン、マップ、人物: `ixin://graph` / `timeline` / `map` / `people`。 
3. 没入型​​の読書、縦方向のレイアウト、中央揃え、フォント スケール、分割されたページを試してください。 
4. **インサイト カード**を開き、スタイル/比率を選択し、写真 (追加専用) またはシステム共有に保存します。 

### 5. 暗唱＆心の学校

 1. ハイライトされた TTS、調整可能な音声とペース、オプションの現地語/英語のキャプション、連続再生、およびバックグラウンド オーディオの朗読ワークベンチを開きます。 
2. **ハート スクール** (`ixin://study`): フェード、穴埋め、セルフチェック、クイズ、マスタリー追跡機能付き。 
3. ホームの **ハート ハント** は、別の通路探しゲームです。 

### 6. ウィジェット、Siri、システム機能

 1. **デイリーインサイト/名セリフ/お気に入り/学習進捗状況/日記**ウィジェットを追加します。 
2. コントロール センター、Siri、Spotlight、`ixin://` ディープ リンクを使用します。 
3. オプションの読書ライブ アクティビティは、サポートされている iPhone デバイスで引き続き利用できます。 

### 7. プライバシーと同期

1. ライブラリ、読書、朗読 (システム TTS)、ハート スクール、ジャーナル、ウィジェット、およびローカル通知は、インストール後 **完全にオフライン**で機能します。 
2. オプションの **_iCloud 同期** は、お気に入り、リスト、履歴、進行状況、連続記録、メモ、**、および日記エントリ**を **プライベート iCloud** を通じてミラーリングします。 
3. 開発者 (オプションの StoreKit) は、ペイウォールのロックを解除したり、アカウントを作成したりすることはありません。 

## ダウンロードする理由

 - **実践知行合一** — 日記と良知のプロンプトは、単なる引用ではなく、学校の日常的な行為になります。 
- **コアテキストを 1 つのデスクに** — *Chuanxilu*、*Daxuewen*、Longchang の指示、および埋葬エッセイをオフラインで。 
- **ネイティブ学習デスク** — 朗読、グラフ、タイムライン、ウィジェット、Siri、ディープリンクを 1 つのアプリで実行します。 
- **設計によるプライバシー** — アカウント、広告、分析 SDK はありません。
