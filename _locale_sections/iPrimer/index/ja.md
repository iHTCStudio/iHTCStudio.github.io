**1日1章。 一生もののキャラクター。**

 iPrimer (愛し小学 / 愛小學) は、Zhu Xi の *Xiaoxue* (初等学習) を中心に構築された **オフラインの知恵の成長コンパニオン** であり、単なる古典のダンプではありません。 **アカウントは必要ありません。****6** 巻にわたるすべての**388** 章が、**日常語**、**収集されたメモ**、**タップして光沢のある用語**、**段落に合わせた英語**とともにデバイスに出荷されます。 **朗読** 部分を強調表示します。 **キャラクター スタディ** ホールでトレーニングします。 **6 つのガイド付き瞑想**を実践します。 **生活指導**に基づいて**反省日誌**を付け、毎日の習慣をチェックしてください。 状況に応じた**毎日の学習**から始めます。 **共有カード**をエクスポートし、**6 種類のウィジェット**、オプションの **読書 / 瞑想ライブ アクティビティ**、**Siri とショートカット**、およびオプションの **iCloud** を追加します。 ライブラリのテキストは、公開されている Web ソースから厳選されています。 **広告はありません。 追跡はありません。 Data Not Collected.**

 ## はじめに (ステップバイステップ)

 ### 1. 最初の起動

1. [App Store](https://apps.apple.com/app/id6798921004) からインストールし、**iPrimer** を開きます。 
2. **6 ページのウェルカム ガイド** (ブランド → 学習 → 暗唱 → 瞑想 → ガイダンス → プライバシー) を完了します。 
3. いつでも再生できます: **[設定] → [ヘルプ] → [機能ガイド]**。 
4. アプリ内の**使用法 / ウィジェット / ショートカット** ガイドは、**設定 → ヘルプ** に表示されます。 

### 2. ホームに関する今日の章を読んでください。 

1. [**ホーム**] タブを開きます。 
2. **Daily Study** ヒーローは、UI が英語の場合、英語のプレビューで今日の章を表示します。 タップして詳細を開きます。 
3. **クラシック**、**瞑想**、**ライフ ガイダンス**の 3 つのモジュールを学習します。 
4. オプション: **[設定] → [毎日]** で **毎日の学習通知** をオンにします (ローカル スケジュールのみ)。 

### 3. 参照と検索

 1. **参照** を開きます (デフォルトでオン。設定で非表示にできます)。 
2. **6 巻** (教えの確立、人間関係、自尊心、古代、素晴らしい言葉、善行)、著者、有名なセリフ、およびすべての章を調べてください。 
3. **検索**を使用して、中国語、英語、または**声調なしピンイン**を検索します。 
4. 章にスターを付けて**お気に入り**に追加します。 個人の **学習リスト** (学单) を作成します。 [お気に入り] タブは **デフォルトでオンになっています**。 

### 4. バイリンガルの読書とカードの共有

1. 詳細で、**バイリンガル/中国語のみ/英語のみ**を選択します。 母国語、収集されたメモ (Ann.)、および英語を個別に切り替えます。 
2. **グロス ポップオーバー**の下線付きの用語をタップします (グローバル切り替えなし)。 章レベルの専門用語は、節レベルの専門用語が存在する場合の **ガイド** として表示されます。 
3. **没入型読書**、フォント サイズ、長い章の **分割読書**、および章ごとの **振り返りプロンプト**を試してください。 
4. **カードの共有** を開き、プレビューし、写真 (追加専用) またはシステム共有に保存します。 

### 5. 朗読（诵读）

 1. 詳細については、**朗読** をタップするか、朗読スタジオを開きます。 
2. 聞きながら **セグメントの強調表示**に従います。 
3. **[設定] → [読み上げと音声]** で、*表示内容*とは独立して、**再生コンテンツ マトリックス** (タイトル / 著者 / 本文 × オリジナル / 言語 / 英語) を設定します。 
4. オプション: サイレント モード再生、バックグラウンド オーディオ + 再生中、連続再生、スリープ タイマー、画面オンの維持、ライブ アクティビティの読み取り (フォアグラウンドで開始)。
