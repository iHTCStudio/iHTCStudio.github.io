iHTC Studio («мы») разработала iConverter (также известное как «爱计算»). На этой странице описано, как мы собираем, используем и раскрываем данные при использовании приложения.

## Кратко

**iConverter не собирает, не хранит и не передаёт персональные данные.** Все вычисления и конвертации выполняются только на вашем устройстве. Учётная запись не нужна, для основных функций интернет не требуется.

## Сбор данных

Мы не собираем никаких данных. В частности:

- **Персональная информация** (имя, e-mail, телефон, аккаунт) не собирается.
- **Данные об использовании** и аналитика не собираются.
- **Сторонние SDK** для рекламы, аналитики или отчётов о сбоях не интегрированы.
- **Cookie и технологии отслеживания** не используются.
- Инструмент «Веб-браузер» загружает страницы из интернета — трафик идёт напрямую на посещаемые сайты и регулируется их политиками конфиденциальности. iHTC Studio не перехватывает и не журналирует этот трафик.

## Данные, хранящиеся локально на устройстве

Все данные, созданные iConverter, остаются на устройстве:

| Данные | Хранение | Управление |
|------|---------|--------------|
| История калькулятора | Локально (UserDefaults) | Удаление записей или очистка в «Настройках» |
| Закладки и история браузера | Локально (UserDefaults) | Очистка в настройках веб-браузера |
| Записи NetLog (веб-браузер) | В памяти на время сессии | Сброс при отключении NetLog или выходе |
| Акцент виджета | App Group UserDefaults | «Настройки → Стиль цвета виджета» |
| Настройки приложения | Локально (UserDefaults) | Сброс при удалении приложения |
| Загруженные файлы | Локальная песочница / «Файлы» | Удаление в приложении «Файлы» |
| Экспорт кадров видео | Медиатека «Фото» | Удаление в «Фото» |

Виджеты используют контейнер **App Group** для обмена данными между приложением и расширениями. Контейнер остаётся на устройстве и недоступен третьим лицам.

## Разрешения

iConverter запрашивает следующие разрешения только при первом использовании соответствующей функции:

| Разрешение | Назначение |
|------------|---------|
| Медиатека (чтение) | Выбор видео для экспорта кадров |
| Медиатека (запись) | Сохранение экспортированных кадров |
| Камера | Сканирование QR-кодов (необязательный ярлык) |
| Движение и фитнес | Компас, уровень, датчики высоты |
| Геопозиция (при использовании) | Инструмент высоты (калибровка барометрической высоты) |
| Локальная сеть | Не запрашивается |
| Контакты / микрофон | Не запрашиваются |

Разрешения используются только для указанных целей.

## Конфиденциальность детей

iConverter сознательно не собирает персональные данные, в том числе у детей младше 13 лет. Поскольку данные не собираются, дополнительные меры не требуются.
