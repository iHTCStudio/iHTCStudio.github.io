iHTC Studio ("เรา") พัฒนา iConverter (หรือที่รู้จักในชื่อ "爱计算") หน้านี้อธิบายนโยบายการเก็บรวบรวม ใช้ และเปิดเผยข้อมูลเมื่อคุณใช้แอป

## สรุป

**iConverter ไม่เก็บรวบรวม จัดเก็บ หรือส่งข้อมูลส่วนบุคคล** การคำนวณและการแปลงหน่วยทำงานบนอุปกรณ์ของคุณทั้งหมด ไม่ต้องมีบัญชี และไม่ต้องใช้อินเทอร์เน็ตสำหรับฟีเจอร์หลัก

## การเก็บรวบรวมข้อมูล

เราไม่เก็บข้อมูลใดๆ โดยเฉพาะ:

- **ไม่เก็บข้อมูลส่วนบุคคล** (ชื่อ อีเมล โทรศัพท์ บัญชี)
- **ไม่เก็บข้อมูลการใช้งาน** หรือการวิเคราะห์
- **ไม่มี SDK บุคคลที่สาม** สำหรับโฆษณา การวิเคราะห์ หรือรายงานข้อขัดข้อง
- **ไม่ใช้คุกกี้หรือการติดตาม**
- เครื่องมือเว็บเบราว์เซอร์โหลดหน้าเว็บจากอินเทอร์เน็ต — การรับส่งไปยังเว็บไซต์ที่คุณเข้าชมโดยตรงและอยู่ภายใต้นโยบายความเป็นส่วนตัวของแต่ละไซต์ iHTC Studio ไม่ดักจับหรือบันทึกการรับส่งนั้น

## ข้อมูลที่เก็บในเครื่อง

ข้อมูลที่ iConverter สร้างทั้งหมดอยู่บนอุปกรณ์ของคุณ:

| ข้อมูล | ที่เก็บ | การควบคุม |
|------|---------|--------------|
| ประวัติเครื่องคิดเลข | ในเครื่อง (UserDefaults) | ลบรายการหรือล้างทั้งหมดในการตั้งค่า |
| บุ๊กมาร์กและประวัติเบราว์เซอร์ | ในเครื่อง (UserDefaults) | ล้างในการตั้งค่าเว็บเบราว์เซอร์ |
| รายการ NetLog (เว็บเบราว์เซอร์) | ในหน่วยความจำระหว่างเซสชัน | ล้างเมื่อปิด NetLog หรือออกจากแอป |
| สีเน้นวิดเจ็ต | App Group UserDefaults | การตั้งค่า → สไตล์สีวิดเจ็ต |
| การตั้งค่าแอป | ในเครื่อง (UserDefaults) | รีเซ็ตโดยลบแอป |
| ไฟล์ที่ดาวน์โหลด | Sandbox ในเครื่อง / แอปไฟล์ | ลบในแอปไฟล์ |
| การส่งออกเฟรมวิดีโอ | คลังภาพ | ลบในแอปรูปภาพ |

วิดเจ็ตใช้คอนเทนเนอร์ **App Group** แชร์ข้อมูลระหว่างแอปหลักและส่วนขยาย คอนเทนเนอร์อยู่บนอุปกรณ์และบุคคลที่สามเข้าถึงไม่ได้

## สิทธิ์

iConverter ขอสิทธิ์ต่อไปนี้เมื่อคุณใช้ฟีเจอร์ที่เกี่ยวข้องครั้งแรกเท่านั้น:

| สิทธิ์ | วัตถุประสงค์ |
|------------|---------|
| คลังภาพ (อ่าน) | เลือกวิดีโอสำหรับส่งออกเฟรม |
| คลังภาพ (เขียน) | บันทึกเฟรมที่ส่งออก |
| กล้อง | สแกน QR (ทางลัดทางเลือก) |
| การเคลื่อนไหวและฟิตเนส | เข็มทิศ ระดับ เซนเซอร์ความสูง |
| ตำแหน่ง (ขณะใช้แอป) | เครื่องมือความสูง (ความสูงจากบารอมิเตอร์ต้องใช้ตำแหน่งเพื่อปรับเทียบ) |
| เครือข่ายท้องถิ่น | ไม่ขอ |
| รายชื่อติดต่อ / ไมโครโฟน | ไม่ขอ |

สิทธิ์ใช้เฉพาะตามวัตถุประสงค์ที่ระบุ

## ความเป็นส่วนตัวของเด็ก

iConverter ไม่เก็บข้อมูลส่วนบุคคลจากใคร รวมถึงเด็กอายุต่ำกว่า 13 ปี เนื่องจากไม่มีการเก็บข้อมูลจึงไม่ต้องมีมาตรการพิเศษ

## การเปลี่ยนแปลงนโยบาย
