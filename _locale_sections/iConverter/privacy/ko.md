iHTC Studio(「당사」)는 iConverter(「爱计算」로도 알려짐)를 개발했습니다. 이 페이지는 앱 사용과 관련된 데이터 수집, 이용 및 공개에 대한 당사 정책을 설명합니다.

## 요약

**iConverter는 개인 데이터를 수집, 저장 또는 전송하지 않습니다.** 모든 계산과 단위 변환은 기기에서만 이루어집니다. 계정이 필요 없으며 핵심 기능에 인터넷 연결이 필요하지 않습니다.

## 데이터 수집

당사는 어떠한 데이터도 수집하지 않습니다. 구체적으로:

- **개인 정보**(이름, 이메일, 전화번호, 계정 등)를 수집하지 않습니다.
- **사용 데이터**나 분석 데이터를 수집하지 않습니다.
- 광고, 분석, 크래시 리포팅용 **서드파티 SDK**를 통합하지 않습니다.
- **쿠키 또는 추적** 기술을 사용하지 않습니다.
- 웹 브라우저 도구는 인터넷에서 페이지를 불러옵니다. 해당 트래픽은 방문하는 웹사이트로 직접 전달되며 각 사이트의 개인정보 처리방침이 적용됩니다. 당사는 해당 트래픽을 가로채거나 기록하지 않습니다.

## 기기에 로컬로 저장되는 데이터

iConverter가 생성하는 모든 데이터는 기기에 남습니다.

| 데이터 | 저장 위치 | 사용자 제어 |
|------|---------|--------------|
| 계산기 기록 | 로컬(UserDefaults) | 설정에서 개별 삭제 또는 전체 지우기 |
| 북마크 및 방문 기록 | 로컬(UserDefaults) | 웹 브라우저 설정에서 지우기 |
| NetLog 항목(웹 브라우저) | 세션 중 메모리 | NetLog 비활성화 또는 앱 종료 시 삭제 |
| 위젯 강조 색상 | App Group UserDefaults | 설정 → 위젯 색상 스타일 |
| 앱 설정 | 로컬(UserDefaults) | 앱 삭제로 초기화 |
| 다운로드 파일(파일 다운로드) | 로컬 샌드박스 / 파일 앱 | 파일 앱에서 삭제 |
| 동영상 프레임 내보내기 | 사진 라이브러리 | 사진 앱에서 삭제 |

위젯은 **App Group** 컨테이너로 본 앱과 확장 간 데이터를 공유합니다. 컨테이너는 기기에만 있으며 제3자가 접근할 수 없습니다.

## 권한

iConverter는 특정 기능을 처음 사용할 때만 다음 권한을 요청합니다.

| 권한 | 목적 |
|------------|---------|
| 사진 라이브러리(읽기) | 동영상 프레임 내보내기에서 동영상 선택 |
| 사진 라이브러리(쓰기) | 내보낸 프레임 저장 |
| 카메라 | QR 코드 스캔(선택적 단축어) |
| 동작 및 피트니스 | 나침반, 수준기, 고도 센서 도구 |
| 위치(사용 중) | 고도 도구(기압 고도 보정에 위치 필요) |
| 로컬 네트워크 | 요청하지 않음 |
| 연락처 / 마이크 | 요청하지 않음 |

권한은 위에 명시된 목적 외에는 사용되지 않습니다.

## 아동의 개인정보

iConverter는 13세 미만을 포함하여 누구로부터도 개인 데이터를 고의로 수집하지 않습니다. 데이터를 전혀 수집하지 않으므로 별도 조치가 필요하지 않습니다.
