iHTC Studio（以下「当社」）は iConverter（「爱计算」としても知られています）を開発しました。本ページでは、本アプリの利用に伴うデータの収集、利用、開示に関する当社の方針を説明します。

## 概要

**iConverter は個人データを収集、保存、送信しません。** 計算と単位換算はすべて端末上で完結します。アカウントは不要で、主要機能にインターネット接続は必要ありません。

## データの収集

当社はデータを一切収集しません。具体的には次のとおりです。

- **個人情報**（氏名、メール、電話番号、アカウントなど）は収集しません。
- **利用状況データ**や分析データは収集しません。
- 広告、分析、クラッシュレポート用の**サードパーティ SDK**は組み込んでいません。
- **Cookie やトラッキング**技術は使用しません。
- Web ブラウザツールはインターネットからページを読み込みます。その通信はお客様が訪問するサイトに直接届き、各サイトのプライバシーポリシーの対象となります。当社はその通信を傍受または記録しません。

## 端末にローカル保存されるデータ

iConverter が作成するデータはすべて端末に残ります。

| データ | 保存場所 | ユーザーの操作 |
|------|---------|--------------|
| 電卓履歴 | ローカル（UserDefaults） | 設定で個別削除または一括消去 |
| ブックマークと閲覧履歴 | ローカル（UserDefaults） | Web ブラウザ設定で消去 |
| NetLog エントリ（Web ブラウザ） | セッション中はメモリ | NetLog 無効化またはアプリ終了で消去 |
| ウィジェットのアクセント設定 | App Group UserDefaults | 設定 → ウィジェットの色スタイル |
| アプリの設定 | ローカル（UserDefaults） | アプリ削除でリセット |
| ダウンロードファイル（ファイルダウンロード） | ローカルサンドボックス / 「ファイル」 | 「ファイル」アプリで削除 |
| 動画フレームの書き出し | 写真ライブラリ | 「写真」アプリで削除 |

ウィジェットは **App Group** コンテナで本体アプリと拡張機能間のデータを共有します。コンテナは端末内に留まり、第三者からはアクセスできません。

## 権限

iConverter は、特定の機能を初めて使うときにのみ、次の権限を要求します。

| 権限 | 目的 |
|------------|---------|
| 写真ライブラリ（読み取り） | 動画フレーム書き出しで動画を選択 |
| 写真ライブラリ（書き込み） | 書き出したフレームを保存 |
| カメラ | QR コードスキャン（任意のショートカット） |
| モーションとフィットネス | コンパス、水準器、高度センサー |
| 位置情報（使用中のみ） | 高度ツール（気圧高度の校正に位置情報が必要） |
| ローカルネットワーク | 要求しません |
| 連絡先 / マイク | 要求しません |

権限は上記の目的以外には使用されません。

## お子様のプライバシー

iConverter は 13 歳未満を含め、いかなる方からも個人データを意図的に収集しません。データを一切収集しないため、特別な措置は不要です。
