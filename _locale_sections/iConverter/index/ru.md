**Ежедневные математические, инженерные единицы и утилиты для разработчиков — одно прекрасно разработанное приложение для iPhone и iPad.**

iConverter объединяет **101 калькуляторы и конвертеры** в один автономный набор инструментов. От планирования ипотеки до сканирования/создания QR, от преобразования единиц до встроенного веб-браузера с NetLog** — коснитесь любого результата, чтобы скопировать, закрепить избранное и перейти из виджетов или глубоких ссылок `iconverter://`.

## Начало работы

1. Откройте iConverter и просмотрите меню инструментов по категориям или используйте строку поиска.
2. Коснитесь любого инструмента, чтобы открыть его. Результаты обновляются мгновенно по мере ввода.
3. Нажмите любое значение результата, чтобы скопировать его в буфер обмена (с тактильной обратной связью).
4. Закрепите наиболее часто используемые инструменты на главном экране для доступа одним касанием.
5. Добавьте виджеты на главный экран или экран блокировки для доступа к инструментам без открытия приложения.

## Ключевые функции

- 101 Инструменты** — Калькуляторы, конвертеры, кодировщики, инструменты даты, помощники по стилю жизни, датчики и многое другое — все в одном приложении.
- **Режим ухода** — Крупная домашняя сетка повседневных инструментов, голосовые нажатия клавиш и результаты, упрощенные формы и `iconverter://care/on`. Портрет только на iPhone при активном режиме.
- Центр справки** — Настройки → **Справка**: руководство по использованию, учебное пособие по виджетам, руководства по Быстрым командам и Siri и О. Глубокие ссылки, такие как `iconverter://help/widget-guide`.
- **Лупа** — Задняя камера 1–10× увеличение, фонарик и стоп-кадр; сведение пальцев для увеличения, ползунок для точного управления.
- **Загрузка мультимедиа** — Разбор общих ссылок на страницах на устройстве (с дополнительным настраиваемым резолютором, который вы настраиваете); загрузка библиотеки, сохранение в Фото или Файлы, передача в Экспорт видеокадра. **Общий доступ к расширению** ставит ссылки в очередь, когда главное приложение не открыто.
- **История QR-кода** — Отдельная история создания/сканирования (до 100 записей) с восстановлением стиля по нажатию кнопки.
- **Live Activities (iPhone, iOS 17+)** — Продолжайте работу с поддерживаемыми калькуляторами, преобразователями и инструментами отношений с экрана блокировки / Dynamic Island при выходе из приложения.
- ** Мгновенные результаты** — Поля обновляются в режиме реального времени по мере ввода. Не требуется кнопка отправки.
- Копирование одним касанием - Коснитесь любого результата, чтобы скопировать его, с тактильным подтверждением и кратким уведомлением о тосте.
– QR-код – Создавайте коды (в нескольких форматах) или сканируйте их с помощью камеры; открывайте ссылки `iconverter://` напрямую.
- **Виджеты** — 21 интерактивный виджет для экрана «Домой», экрана блокировки и режима ожидания. **Параметры → Стиль цвета виджета** предлагает значение по умолчанию (цветы для каждого инструмента), частичный акцент или полный акцент (включая фон). **О → Руководство по виджету** проходит настройку.
— Виджет Launcher — Выберите любое поддерживаемое средство для доступа одним касанием (за исключением веб-браузера — нет постоянного состояния виджета).
- **URL Scheme** — Откройте любой инструмент из Safari, «Быстрые команды», другого приложения или отсканированный QR-код с помощью глубоких ссылок `iconverter://`. Параметры могут предварительно заполнять поля ввода. См. справочник по [URL Scheme](url-scheme).
- **Закрепленные инструменты** — Закрепите до 8 инструментов на домашнюю панель быстрого доступа.
- **Сочетания клавиш для экрана «Домой»** — Добавьте до 4 сочетаний клавиш для инструментов непосредственно на экран «Домой» вашей iOS.
- **История калькулятора** — Общая история всех трех калькуляторов. Коснитесь любой записи, чтобы восстановить ее.
- **Копирование единиц с символом** — При копировании результатов преобразования единиц при необходимости включите символ единицы.
- **Цвет акцента** — Выберите один из 12 готовых цветов или полностью настраиваемый цветовой селектор.
- **Значки приложений** — включено несколько альтернативных значков приложений.
- **Три языка** - Упрощенный китайский · Традиционный китайский · Английский, переключаемый в **Параметры → Язык** (независимо от системного языка). **UI конфигурации виджетов** (iOS системный селектор при добавлении/изменении виджетов) следует **системному языку устройства**, а не переопределению языка в приложении.
- **Темный режим** — Полная поддержка светлого, темного и системного оформления.
- **Офлайн-первый** — Все инструменты работают на устройстве (кроме инструмента веб-браузера, который загружает страницы из Интернета).
- **Конфиденциальность превыше всего** — Нет учетной записи, нет аналитических SDK, нет отслеживания третьими сторонами.
