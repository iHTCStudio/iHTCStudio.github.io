爱曾 / iZENZi รองรับ~ `izengzi://` BAR *ลิงก์ลัด (URL scheme). การเริ่มหน้าจอหน้าจอเย็นและหน้าจอบ้าน จะถูกส่งไปผ่านระบบบัฟเฟอร์แบบรวม ดังนั้นลิงก์จึงไม่ถูกเปิดสองครั้งหลังจากขึ้นเครื่อง

## รูปแบบลิงก์


```
izengzi://{host}?{params}
```


## โต๊ะยูนิโค้ด

| URL | เปิด |
|-----|-------|
| `izengzi://daily` | ภาพสะท้อนทุกวัน |
| `izengzi://reflect` / `izengzi://journal` | บันทึกประจําวันสามคําถาม |
| `izengzi://eight` | แปดขั้น |
| `izengzi://tales` | ศาลากลาง |
| `izengzi://study` | ห้อง เพาะ ปลูก |
| `izengzi://hunt` | ใช้คําค้น |
