). / iZengZi, ** `izengzi://` ** kısayol bağlantıları (URL planı). Soğuk başlangıç ve Ev Ekran kısayolları birleşik bir tampon aracılığıyla teslim edilir, bu yüzden bağlantılar gemiden sonra iki kez açılmaz.

## Bağlantı biçimi


```
izengzi://{host}?{params}
```


## Benzersiz masası

| URL | Açar |
|-----|-------|
| `izengzi://daily` | Günlük |
| `izengzi://reflect` / `izengzi://journal` | Üç sorulu dergi |
| `izengzi://eight` | Sekiz adım |
| `izengzi://tales` | Tale hall |
| `izengzi://study` | Cultivation Hall |
| `izengzi://hunt` | Keyword Hunt |
