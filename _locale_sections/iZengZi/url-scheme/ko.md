short子 / iZengZi 지원 ** `izengzi://` ** 단축 링크 (URL 계획). 콜드 시작 및 홈 화면 단축은 통합 버퍼를 통해 전달되므로 링크가 내장 된 후 두 번 열리지 않습니다.

## 링크 형식


```
izengzi://{host}?{params}
```


## 회사 소개

| URL | 열리는 화면 |
|-----|-------|
| `izengzi://daily` | 매일 반사 |
| `izengzi://reflect` / `izengzi://journal` | 세 가지 질문 저널 |
| `izengzi://eight` | 8 단계 |
| `izengzi://tales` | Tale 홀 |
| `izengzi://study` | Cultivation 홀 |
| `izengzi://hunt` | 키워드 사냥 |
