Le logiciel iZengZi prend en charge les liens de raccourci ** `izengzi://` ** (système URL). Les raccourcis de démarrage à froid et d'écran d'accueil sont livrés via un tampon unifié de sorte que les liens ne sont pas ouverts deux fois après l'embarquement.

## Format de lien


```
izengzi://{host}?{params}
```


## Bureau unique

| URL | Ouvre |
|-----|-------|
| `izengzi://daily` | Réflexion quotidienne |
| `izengzi://reflect` / `izengzi://journal` | Revue de trois questions |
| `izengzi://eight` | Huit étapes |
| `izengzi://tales` | Salle de conférence |
| `izengzi://study` | Salle de culture |
| `izengzi://hunt` | Chasse aux mots clés |
