爱曾子 / iZengZiは** `izengzi://` **ショートカットリンク(URLスキーム)をサポートしています。 コールドスタートとホーム画面のショートカットは、統一されたバッファを介して配信されますので、リンクはオンボーディング後2回開いていません。

## リンク形式


```
izengzi://{host}?{params}
```


## ユニークなデスク

| URL | 開く画面 |
|-----|-------|
| `izengzi://daily` | 毎日の反射 |
| `izengzi://reflect` / `izengzi://journal` | 3つの質問ジャーナル |
| `izengzi://eight` | 8ステップ |
| `izengzi://tales` | テイルホール |
| `izengzi://study` | 文化会館 |
| `izengzi://hunt` | キーワード ハント |

## 例


```
izengzi://daily
izengzi://reflect
izengzi://eight
izengzi://study
```
