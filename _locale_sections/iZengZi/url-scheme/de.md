爱曾子 / iZengZi unterstützt ** `izengzi://` ** Shortcut Links (URL-Schema). Kaltstart- und Home Screen-Verknüpfungen werden über einen einheitlichen Puffer geliefert, so dass Links nach dem Onboarding nicht zweimal geöffnet werden.

## Linkformat


```
izengzi://{host}?{params}
```


## Einzigartiger Schreibtisch

| URL | Öffnet |
|-----|-------|
| `izengzi://daily` | Tägliche Reflexion |
| `izengzi://reflect` / `izengzi://journal` | Drei Fragen Journal |
| `izengzi://eight` | Acht Stufen |
| `izengzi://tales` | Tale Halle |
| `izengzi://study` | Anbauhalle |
| `izengzi://hunt` | Stichwort Jagd |
