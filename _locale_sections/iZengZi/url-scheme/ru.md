Поддерживает ярлыки ** `izengzi://` ** (схема URL). Холодный старт и ярлыки домашнего экрана доставляются через единый буфер, поэтому ссылки не открываются дважды после входа.

## Формат ссылки


```
izengzi://{host}?{params}
```


## Уникальный стол

| URL | Открывает |
|-----|-------|
| `izengzi://daily` | Ежедневные размышления |
| `izengzi://reflect` / `izengzi://journal` | Журнал с тремя вопросами |
| `izengzi://eight` | Восемь шагов |
| `izengzi://tales` | Зал славы |
| `izengzi://study` | Культивационный зал |
| `izengzi://hunt` | Ключевое слово Hunt |

## Общие пути чтения

| URL | Открывает |
|-----|-------|
| `izengzi://home` | Главная |
| `izengzi://passage?id=` / `izengzi://chapter?id=` | Страница отрывка |
| `izengzi://recite` / `izengzi://recite?id=` | читать |
| `izengzi://random` | Случайный отрывок |
| `izengzi://favorites` | Избранное |
| `izengzi://search?q=` | Поиск |
| `izengzi://famous` | Знаменитые строки |
| `izengzi://categories` | Обзор |
| `izengzi://last-read` | Последнее прочитанное |
| `izengzi://reading-history` | История чтения |
| `izengzi://notes` | Заметки |
| `izengzi://handwriting` | Поиск почерка (iOS) |
| `izengzi://settings` | Настройки |
| `izengzi://usage-guide` | Руководство по использованию |
| `izengzi://widget-guide` | Руководство по виджетам |
| `izengzi://shortcuts-guide` | Руководство по «Командам» |
| `izengzi://feature-guide` | Повторное знакомство |
| `izengzi://feedback` | Письмо с отзывом |

## Примеры


```
izengzi://daily
izengzi://reflect
izengzi://eight
izengzi://study
```
