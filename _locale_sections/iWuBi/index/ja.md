iWuBi は、**iPhone、iPad、Mac** 向けの総合的な五筆入力の学習・文字検索ツールです。86 版、98 版、新世紀版の五筆標準に対応した 3 万語以上のライブラリ、**タイピング練習**、ピンイン検索と変換、デイリークイズ、8 種類のウィジェット、完全な iCloud 同期を備え、五筆を習得するためのオールインワンの相棒です — **オフラインで動作し、サードパーティへの依存はゼロ。**

8 周年のリフレッシュとして、純粋な SwiftUI で構築されています。

## はじめに

1. 初回起動時に **5 画面のオンボーディング**を完了します（いつでもスキップ可能）。
2. iWuBi を開き、**検索**で任意の文字を検索するか、**レベル**で簡码レベル（1〜4）ごとに閲覧します。iOS では、**手書き OCR** で検索と簡码ページの検索欄に入力できます。
3. 設定またはツールバーのメニューで、86 版、98 版、新世紀版の五筆を切り替えます。
4. **タイピング**を試します — フルコード、レベルコード、ミックスのモードを選び、生成リストの**ランダム文字数**を設定し、内蔵文章、貼り付けたテキスト、お気に入り、間違い帳で練習します。
5. **デイリークイズ**に挑戦します — 1 日 8 問で体に覚えさせます。間違いは間違い帳で復習できます。
6. 発音も学ぶ場合は、アプリ設定で**ピンインを表示**または**ピンイン検索**を有効にします。
7. ホーム画面、ロック画面、StandBy にウィジェットを追加して、学習をひと目で確認できるようにします。

## 機能

### 学習のコア

- **3 万語以上のライブラリ** — 単一の文字とフレーズ。86 / 98 / 新世紀の標準。簡码のフレーズ自動合成に対応。
- **簡码の閲覧（レベル 1〜4）** — リストまたはグリッド表示、ランダムシャッフル、レベル間のスワイプ。iPhone、iPad、Mac でグリッドの列数を調整可能。
- **タイピング練習** — 専用タブに 3 つのモード：フルコード、レベルコード（レベル 1〜4）、ミックス（まずレベル、間違えるとフルコード）。コンテンツの出典：カスタムテキストの貼り付け、ランダムな文字、内蔵文章 14 本、生成された単語リスト、お気に入り、間違い帳の復習。文章のハイライト、字根分解バー、任意の画面字根キーボード、ヒント / 答えを見る / スキップ、正答率 / 連続記録 / セッション統計、再開可能な内蔵文章の進捗。
- **デイリークイズ** — 1 日 8 問：文字からコード、コードから文字、文字から字根キー。
- **間違い帳** — クイズの間違いを自動収集し、詳細へのリンクを備えます。
- **学習状況** — 4 段階（未学習 / 学習中 / 学習済み / 習得済み）と統計。
- **チュートリアル** — 86 / 98 / 新世紀の字根表、簡潔なガイド、簡码リファレンス、16 種類以上の字根図（**長押しで元画像を共有**）。
- **iCloud 同期（切り替え可能）** — お気に入り、学習状況、間違い帳、クイズのベストスコア、連続記録、**タイピング統計**、**内蔵文章の進捗**。**新規ユーザーでは既定でオン。**

### ピンインツール

- **手書き OCR（iOS）** — 検索 / 簡码で文字を描くと、検索欄がローカルで入力されます（端末内の Vision を使用）。
- **ピンイン前方一致検索** — 検索でアルファベットを入力し、**コード**モードと**ピンイン**モードを切り替えます。声調なしのピンインで文字を前方一致検索します。
- **全体のピンイン表示** — リスト、クイズ、間違い帳、詳細、共有スナップショットの文字タイルの上に、声調付きピンインを任意で表示します。
- **ピンイン変換** — 中国語のテキストを貼り付けて、9 種類のスタイル（声調付き、声調なし、数字声調、注音符号、2 行、整列グリッドなど）で出力します。五筆コードを表示することもでき、コピーや長い画像としての共有が可能です。

### 検索と詳細

- **Apple システム辞書** — 文字の詳細ページにインラインで定義を表示します（iOS はシステム UI、macOS は辞書サービス）。
- **色分けされたコードチップと字根キーの画像** — コードの視覚的な表示とキー位置の図。
- **中国語 TTS** — 詳細ページと TTS プレイグラウンドから文字を読み上げます。
- **長い画像での共有** — 文字の詳細、検索結果、ピンイン変換の出力をプレビュー画像として共有します。

### パーソナライズ

- **16 種類の内蔵テーマ** + カスタムのアクセントカラー。ライト / ダーク / システムの外観。
- **8 種類の代替アプリアイコン**（iOS）。
- **簡体字中国語 / 繁体字中国語 / 英語**の UI（システム言語とは独立）。
- App Group を通じたウィジェットの言語とテーマの反映。

### iOS と iPad

- **8 種類のウィジェット** — Daily Character、Level Spotlight、Daily Quiz、**Typing Glance**、Favorites、Wrong Book、Recent、Learning Progress。ホーム画面、ロック画面、StandBy に対応。
- Daily Character ウィジェットは**シャッフルボタン**（AppIntent）に対応。
- Favorites と Wrong Book のウィジェットは、五筆コード付きの **2×3（スモール）/ 3×3（ミディアム）の文字グリッド**を表示します。
- **ホーム画面のクイックアクション** — 7 つの選択肢から最大 4 つを選択。
- **Siri とショートカット** — 文字の検索、今日の文字を開く、デイリークイズの開始、タイピングを開く、など。
- **Spotlight** — お気に入りと最近の文字をインデックス化（設定で切り替え）。
- 没入型のタイピングレイアウトで、練習中はタブバーを非表示にします。
- 任意の字根キーボード：一時的に非表示、表示中はシステムキーボードを抑制、非表示時はシステムまたはハードウェアキーボードにフォールバック。

### macOS

- インライン検索バー、**Esc** で戻る操作、チュートリアルリンク用のフローティング内蔵ブラウザ、システムの共有シートを備えたネイティブ Mac アプリ。
- 専用ショートカット付きの物理キーボードでのタイピング練習（下記参照）。
- 文字リストの既定はグリッドレイアウトで、列数の設定は独立しています。

### 投げ銭

- StoreKit 2 による任意のアプリ内投げ銭（決済はすべて Apple が処理）。

### プライバシー

- **オフライン** — 基本ライブラリ、クイズ、チュートリアル、タイピングはネットワークなしで動作します。
- **広告なし・トラッキングなし** — 分析なし、サードパーティ SDK なし。

## ウィジェット

iWuBi は、ホーム画面、ロック画面、StandBy 向けに **8 種類のウィジェット**を提供します。

### 追加方法

1. ホーム画面を長押しして編集モードに入ります。
2. **+** をタップして「iWuBi」を検索します。
3. ウィジェットを選び、サイズを選択して、**ウィジェットを追加**をタップします。
4. ロック画面ウィジェットは、ロック画面を長押しして**カスタマイズ**をタップし、iWuBi のアクセサリを追加します。

### ウィジェット一覧

| ウィジェット | 説明 | サイズ |
|--------|-------------|-------|
| Daily Character | 五筆コード付きの今日の文字。シャッフルボタンで別の文字に切り替え。 | スモール、ミディアム、ロック画面アクセサリ |
| Level Spotlight | 編集時にコードレベルを選択。毎日ローテーション。 | スモール、ミディアム |
| Daily Quiz | 今日のベストスコアと連続記録。 | スモール、ロック画面 |
| Typing Glance | 正答率、連続記録、セッション数 — タップでタイピングを開く。 | スモール、ロック画面 |
| Favorites | 五筆コード付きのグリッドプレビュー。セルをタップ、またはすべてのお気に入りを開く。 | スモール、ミディアム、ロック画面 |
| Wrong Book | コード付きのグリッドプレビュー。セルをタップでその間違いへ。 | スモール、ミディアム、ロック画面 |
| Recent | 最近見た文字をコード付きで表示。 | スモール、ミディアム、ロック画面 |
| Learning Progress | 習得済み / 学習済み / 学習中の件数。 | スモール、ミディアム、ロック画面 |

ウィジェットの背景はアプリのテーマグラデーションに追従できます（設定で切り替え）。

## キーボードショートカット

### アプリのナビゲーション（ハードウェアキーボード接続時の iPad と Mac）

| ショートカット | 操作 |
|----------|--------|
| ⌘F | 検索を開いて検索欄にフォーカス |
| ⌘1 | 検索タブ |
| ⌘2 | レベルタブ |
| ⌘3 | 学習タブ |
| ⌘4 | **タイピングタブ** |
| ⌘5 | 設定タブ |
| Esc（Mac） | 戻る、またはシート / フローティングブラウザを閉じる |

### タイピング練習

| プラットフォーム | キー | 操作 |
|----------|------|--------|
| iOS / iPad | A–Z | 五筆コードの文字を入力 |
| iOS / iPad | スペース | ヒントを表示 |
| iOS / iPad | リターン | 現在の入力を確定 |
| iOS / iPad | バックスペース | 最後のキーを削除 |
| Mac | A–Z | 五筆コードの文字を入力 |
| Mac | スペースまたは 1 | ヒントを表示 |
| Mac | 2 | 答えを表示 |
| Mac | 3 | 現在の文字をスキップ |
| Mac | リターン | 現在の入力を確定 |
| Mac | Backspace / Delete | 最後のキーを削除 |

フル入力（最大 4 キー）は自動送信されます。ヒント、答えの表示、スキップでも現在の文字が送信されます。画面上のボタンは常に利用できます。

## ディープリンク

`iWuBi://` の対応パス：`search`、`word`、`quiz`、`favorites`、`wrong`、`levels`、`learn`、**`typing`**。[URL スキームリファレンス](url-scheme)をご覧ください。

## システム要件

| プラットフォーム | 最低バージョン |
|----------|---------|
| iPhone / iPad | iOS 16.0 以降 |
| Mac | macOS 13.0 以降 |

ロック画面のアクセサリウィジェットには iOS 16 以降が必要です。一部のウィジェット操作（シャッフルボタン、レベルピッカー）には iOS 16.4 以降が必要です。
