iWuBi est un outil complet d'apprentissage de la méthode de saisie Wubi et de recherche de caractères pour **iPhone, iPad et Mac**. Avec une bibliothèque de plus de 30 000 mots couvrant les standards Wubi 86, 98 et New Century, un **entraînement à la saisie**, la recherche et la conversion de pinyin, des quiz quotidiens, 8 widgets et une synchronisation iCloud complète, c'est le compagnon tout-en-un pour maîtriser Wubi — **hors ligne, sans aucune dépendance tierce.**

Conçu en SwiftUI pur pour la refonte du 8e anniversaire.

## Premiers pas

1. Parcourez la **prise en main en 5 écrans** au premier lancement (ou ignorez-la à tout moment).
2. Ouvrez iWuBi et recherchez n'importe quel caractère dans **Recherche**, ou parcourez par niveau de code simple (1–4) dans **Niveaux**. Sur iOS, l'**OCR d'écriture manuscrite** peut remplir le champ de recherche sur les pages Recherche et Codes simples.
3. Passez de la version 86 à la version 98 ou à New Century Wubi dans les Réglages ou dans le menu de la barre d'outils.
4. Essayez **Saisie** — choisissez le mode code complet, code par niveau ou mixte ; définissez un **nombre de caractères aléatoires** pour les listes générées ; entraînez-vous avec les textes intégrés, du texte collé, les favoris ou votre carnet d'erreurs.
5. Faites le **quiz quotidien** — 8 questions par jour pour construire la mémoire musculaire. Revoyez vos erreurs dans le carnet d'erreurs.
6. Activez **Afficher le pinyin** ou **Recherche par pinyin** dans les Réglages de l'app si vous apprenez aussi la prononciation.
7. Ajoutez des widgets à votre écran d'accueil, à l'écran verrouillé ou au mode Veille pour apprendre d'un coup d'œil.

## Fonctionnalités

### Cœur de l'apprentissage

- **Bibliothèque de plus de 30 000 mots** — Caractères isolés et expressions ; standards 86 / 98 / New Century ; composition automatique des codes simples pour les expressions.
- **Navigation par codes simples (niveaux 1–4)** — Vue liste ou grille, mélange aléatoire, balayage entre les niveaux ; colonnes de la grille réglables sur iPhone, iPad et Mac.
- **Entraînement à la saisie** — Onglet dédié avec trois modes : code complet, code par niveau (niveaux 1–4) et mixte (niveau d'abord, puis code complet après une erreur). Sources de contenu : texte personnalisé collé, caractères aléatoires, 14 textes intégrés, listes de mots générées, favoris et révision du carnet d'erreurs. Surlignage du texte, bandeau de décomposition en racines, clavier de racines à l'écran facultatif, indice / révéler / passer, statistiques de précision / série / sessions et progression des textes intégrés reprenable.
- **Quiz quotidien** — 8 questions par jour : caractère vers code, code vers caractère et caractère vers touche de racine.
- **Carnet d'erreurs** — Collecte automatique des erreurs de quiz avec lien de retour vers le détail.
- **Statut d'apprentissage** — Quatre niveaux (Non appris / En cours / Appris / Maîtrisé) avec statistiques.
- **Tutoriels** — Tables de racines 86 / 98 / New Century, guides concis, référence des codes simples, plus de 16 schémas de racines (**appui long pour partager les images originales**).
- **Synchronisation iCloud (activable)** — Favoris, statut d'apprentissage, carnet d'erreurs, meilleur score de quiz, série, **statistiques de saisie** et **progression des textes intégrés**. **Activée par défaut pour les nouveaux utilisateurs.**

### Outils de pinyin

- **OCR d'écriture manuscrite (iOS)** — Dessinez un caractère dans Recherche / Codes simples pour remplir la recherche en local (Vision sur l'appareil).
- **Recherche par préfixe de pinyin** — Saisissez des lettres dans Recherche et basculez entre les modes **code** et **pinyin** ; les caractères sont trouvés par préfixe de pinyin sans tons.
- **Affichage global du pinyin** — Pinyin avec tons facultatif au-dessus des tuiles de caractères dans les listes, quiz, carnet d'erreurs, détails et aperçus de partage.
- **Convertisseur de pinyin** — Collez du texte chinois et exportez-le en 9 styles (avec tons, sans tons, tons numériques, bopomofo, sur deux lignes, grille alignée, etc.) ; affichage facultatif des codes Wubi ; copie ou partage sous forme d'image longue.

### Recherche et détail

- **Dictionnaire système d'Apple** — Définitions intégrées sur la page de détail du caractère (interface système iOS / Dictionary Services macOS).
- **Pastilles de code colorées et images des touches de racine** — Encodage visuel et schémas de position des touches.
- **TTS chinois** — Faites lire les caractères depuis le détail et le terrain de jeu TTS.
- **Partage en image longue** — Partagez le détail d'un caractère, les résultats de recherche et la sortie du convertisseur de pinyin sous forme d'images d'aperçu.

### Personnalisation

- **16 thèmes intégrés** + couleur d'accent personnalisée ; apparence claire / sombre / système.
- **8 icônes d'app alternatives** (iOS).
- Interface en **chinois simplifié / chinois traditionnel / anglais** (indépendante de la langue du système).
- Langue et thème des widgets reflétés via l'App Group.

### iOS et iPad

- **8 types de widgets** — Daily Character, Level Spotlight, Daily Quiz, **Typing Glance**, Favorites, Wrong Book, Recent, Learning Progress. Écran d'accueil, écran verrouillé et mode Veille.
- Le widget Daily Character prend en charge un **bouton de mélange** (AppIntent).
- Les widgets Favorites et Wrong Book affichent des **grilles de caractères 2×3 (petit) / 3×3 (moyen)** avec les codes Wubi.
- **Actions rapides de l'écran d'accueil** — Choisissez jusqu'à 4 parmi 7 options.
- **Siri et Raccourcis** — Rechercher un caractère, ouvrir le caractère du jour, lancer le quiz quotidien, ouvrir la Saisie, et plus.
- **Spotlight** — Indexation des favoris et des caractères récents (à activer dans les Réglages).
- La disposition de saisie immersive masque la barre d'onglets pendant l'entraînement.
- Clavier de racines facultatif : masquage temporaire, suppression du clavier système tant qu'il est visible, repli sur le clavier système ou matériel lorsqu'il est masqué.

### macOS

- App Mac native avec barre de recherche intégrée, navigation arrière par **Échap**, navigateur flottant dans l'app pour les liens de tutoriel et feuille de partage système.
- Entraînement à la saisie au clavier physique avec raccourcis dédiés (voir ci-dessous).
- Disposition en grille par défaut pour les listes de caractères ; préférence de colonnes indépendante.

### Pourboires

- Pourboires facultatifs dans l'app via **StoreKit 2** (Apple gère tous les paiements).

### Confidentialité

- **Hors ligne** — La bibliothèque principale, les quiz, les tutoriels et la saisie fonctionnent sans réseau.
- **Sans publicité · Sans suivi** — Aucune analyse, aucun SDK tiers.

## Widgets

iWuBi propose **8 types de widgets** pour l'écran d'accueil, l'écran verrouillé et le mode Veille.

### Comment les ajouter

1. Appuyez longuement sur votre écran d'accueil pour passer en mode édition.
2. Touchez **+** et recherchez « iWuBi ».
3. Choisissez un widget, sélectionnez la taille, puis touchez **Ajouter le widget**.
4. Pour les widgets de l'écran verrouillé, appuyez longuement sur l'écran verrouillé, touchez **Personnaliser** et ajoutez un accessoire iWuBi.

### Aperçu des widgets

| Widget | Description | Tailles |
|--------|-------------|-------|
| Daily Character | Caractère du jour avec son code Wubi ; bouton de mélange pour en choisir un autre. | Petit, Moyen, accessoires d'écran verrouillé |
| Level Spotlight | Choisissez un niveau de code lors de la modification ; change chaque jour. | Petit, Moyen |
| Daily Quiz | Meilleur score du jour et série. | Petit, Écran verrouillé |
| Typing Glance | Précision, série et nombre de sessions — touchez pour ouvrir la Saisie. | Petit, Écran verrouillé |
| Favorites | Aperçu en grille avec codes Wubi ; touchez une cellule ou ouvrez tous les favoris. | Petit, Moyen, Écran verrouillé |
| Wrong Book | Aperçu en grille avec codes ; touchez une cellule pour accéder à cette erreur. | Petit, Moyen, Écran verrouillé |
| Recent | Caractères récemment consultés avec leurs codes. | Petit, Moyen, Écran verrouillé |
| Learning Progress | Nombre de caractères maîtrisés / appris / en cours. | Petit, Moyen, Écran verrouillé |

Le fond du widget peut suivre le dégradé du thème de l'app (commutateur dans les Réglages).

## Raccourcis clavier

### Navigation dans l'app (iPad avec clavier matériel et Mac)

| Raccourci | Action |
|----------|--------|
| ⌘F | Ouvrir Recherche et activer le champ de recherche |
| ⌘1 | Onglet Recherche |
| ⌘2 | Onglet Niveaux |
| ⌘3 | Onglet Apprendre |
| ⌘4 | **Onglet Saisie** |
| ⌘5 | Onglet Réglages |
| Échap (Mac) | Revenir en arrière ou fermer les feuilles / le navigateur flottant |

### Entraînement à la saisie

| Plateforme | Touches | Action |
|----------|------|--------|
| iOS / iPad | A–Z | Saisir les lettres du code Wubi |
| iOS / iPad | Espace | Afficher l'indice |
| iOS / iPad | Retour | Valider la saisie en cours |
| iOS / iPad | Suppr. arrière | Supprimer la dernière touche |
| Mac | A–Z | Saisir les lettres du code Wubi |
| Mac | Espace ou 1 | Afficher l'indice |
| Mac | 2 | Révéler la réponse |
| Mac | 3 | Passer le caractère en cours |
| Mac | Retour | Valider la saisie en cours |
| Mac | Suppr. arrière / Supprimer | Supprimer la dernière touche |

La saisie complète (jusqu'à 4 touches) est envoyée automatiquement. Indice, révéler et passer envoient aussi le caractère en cours. Les boutons à l'écran sont toujours disponibles.
