iWuBi เป็นเครื่องมือเรียนวิธีป้อนอู่ปี่ (五笔) และค้นหาตัวอักษรแบบครบวงจรสำหรับ **iPhone, iPad และ Mac** ด้วยคลังคำศัพท์กว่า 30,000 คำที่ครอบคลุมมาตรฐานอู่ปี่รุ่น 86, 98 และศตวรรษใหม่ **การฝึกพิมพ์** การค้นหาและแปลงพินอิน แบบทดสอบประจำวัน วิดเจ็ต 8 แบบ และการซิงค์ iCloud ที่สมบูรณ์ จึงเป็นเพื่อนครบเครื่องสำหรับการเรียนอู่ปี่ให้เชี่ยวชาญ — **ใช้งานออฟไลน์ และไม่พึ่งพาบุคคลที่สามเลย**

สร้างด้วย SwiftUI ล้วน เพื่อการปรับโฉมครบรอบ 8 ปี

## เริ่มต้นใช้งาน

1. ผ่าน **การแนะนำการใช้งาน 5 หน้าจอ** เมื่อเปิดครั้งแรก (หรือข้ามได้ทุกเมื่อ)
2. เปิด iWuBi แล้วค้นหาตัวอักษรใดก็ได้ใน **ค้นหา** หรือเรียกดูตามระดับรหัสย่อ (1–4) ใน **ระดับ** บน iOS **OCR ลายมือเขียน** ช่วยกรอกช่องค้นหาในหน้าค้นหาและรหัสย่อ
3. สลับระหว่างอู่ปี่รุ่น 86, รุ่น 98 และศตวรรษใหม่ในการตั้งค่าหรือเมนูแถบเครื่องมือ
4. ลอง **การพิมพ์** — เลือกโหมดรหัสเต็ม รหัสตามระดับ หรือผสม ตั้ง **จำนวนตัวอักษรสุ่ม** สำหรับรายการที่สร้างขึ้น ฝึกด้วยบทความในตัว ข้อความที่วาง รายการโปรด หรือสมุดบันทึกข้อที่ตอบผิด
5. ทำ **แบบทดสอบประจำวัน** — วันละ 8 ข้อ เพื่อสร้างความจำของนิ้ว ทบทวนข้อที่พลาดในสมุดบันทึกข้อที่ตอบผิด
6. เปิด **แสดงพินอิน** หรือ **ค้นหาด้วยพินอิน** ในการตั้งค่าแอป หากคุณเรียนการออกเสียงด้วย
7. เพิ่มวิดเจ็ตลงหน้าจอโฮม หน้าจอล็อก หรือ StandBy เพื่อเรียนรู้ได้ในพริบตา

## ฟีเจอร์

### แกนหลักการเรียนรู้

- **คลังคำศัพท์กว่า 30,000 คำ** — ตัวอักษรเดี่ยวและวลี มาตรฐาน 86 / 98 / ศตวรรษใหม่ การประกอบรหัสย่อของวลีอัตโนมัติ
- **เรียกดูรหัสย่อ (ระดับ 1–4)** — มุมมองรายการหรือตาราง สุ่มสลับ ปัดสลับระหว่างระดับ ปรับจำนวนคอลัมน์ของตารางได้บน iPhone, iPad และ Mac
- **การฝึกพิมพ์** — แท็บเฉพาะที่มีสามโหมด: รหัสเต็ม รหัสตามระดับ (ระดับ 1–4) และผสม (ระดับก่อน แล้วรหัสเต็มหลังพิมพ์ผิด) แหล่งเนื้อหา: วางข้อความเอง ตัวอักษรสุ่ม บทความในตัว 14 บท รายการคำที่สร้างขึ้น รายการโปรด และการทบทวนสมุดบันทึกข้อที่ตอบผิด ไฮไลต์บทความ แถบแยกราก คีย์บอร์ดรากบนหน้าจอแบบเลือกได้ คำใบ้ / เฉลย / ข้าม สถิติความแม่นยำ / สถิติต่อเนื่อง / รอบ และความคืบหน้าบทความในตัวที่ทำต่อได้
- **แบบทดสอบประจำวัน** — วันละ 8 ข้อ: ตัวอักษรเป็นรหัส รหัสเป็นตัวอักษร และตัวอักษรเป็นปุ่มราก
- **สมุดบันทึกข้อที่ตอบผิด** — รวบรวมข้อที่พลาดในแบบทดสอบโดยอัตโนมัติ พร้อมลิงก์กลับไปยังรายละเอียด
- **สถานะการเรียนรู้** — สี่ระดับ (ยังไม่เรียน / กำลังเรียน / เรียนแล้ว / เชี่ยวชาญ) พร้อมสถิติ
- **บทเรียน** — ตารางรากรุ่น 86 / 98 / ศตวรรษใหม่ คู่มือสั้น ๆ ตารางอ้างอิงรหัสย่อ แผนภาพรากกว่า 16 แบบ (**กดค้างเพื่อแชร์ภาพต้นฉบับ**)
- **การซิงค์ iCloud (เปิด/ปิดได้)** — รายการโปรด สถานะการเรียนรู้ สมุดบันทึกข้อที่ตอบผิด คะแนนแบบทดสอบสูงสุด สถิติต่อเนื่อง **สถิติการพิมพ์** และ **ความคืบหน้าบทความในตัว** **เปิดเป็นค่าเริ่มต้นสำหรับผู้ใช้ใหม่**

### เครื่องมือพินอิน

- **OCR ลายมือเขียน (iOS)** — วาดตัวอักษรในหน้าค้นหา / รหัสย่อ เพื่อกรอกช่องค้นหาในเครื่อง (Vision บนอุปกรณ์)
- **ค้นหาด้วยคำนำหน้าพินอิน** — พิมพ์ตัวอักษรในหน้าค้นหาและสลับระหว่างโหมด **รหัส** กับ **พินอิน** จับคู่ตัวอักษรด้วยคำนำหน้าพินอินแบบไม่มีวรรณยุกต์
- **การแสดงพินอินทั่วทั้งแอป** — แสดงพินอินมีวรรณยุกต์เหนือไทล์ตัวอักษรได้ในรายการ แบบทดสอบ สมุดบันทึกข้อที่ตอบผิด หน้ารายละเอียด และภาพแชร์
- **ตัวแปลงพินอิน** — วางข้อความภาษาจีนและส่งออกได้ 9 รูปแบบ (มีวรรณยุกต์ ไม่มีวรรณยุกต์ วรรณยุกต์ตัวเลข จู้อินฝูเฮ่า สองบรรทัด ตารางจัดแนว ฯลฯ) แสดงรหัสอู่ปี่ได้ตามต้องการ คัดลอกหรือแชร์เป็นภาพยาว

### ค้นหาและรายละเอียด

- **พจนานุกรมระบบของ Apple** — คำนิยามแบบอินไลน์ในหน้ารายละเอียดตัวอักษร (UI ระบบของ iOS / Dictionary Services ของ macOS)
- **ชิปรหัสสีและภาพปุ่มราก** — การเข้ารหัสแบบเห็นภาพและแผนภาพตำแหน่งปุ่ม
- **TTS ภาษาจีน** — อ่านออกเสียงตัวอักษรจากหน้ารายละเอียดและสนามทดลอง TTS
- **แชร์เป็นภาพยาว** — แชร์รายละเอียดตัวอักษร ผลการค้นหา และผลลัพธ์ตัวแปลงพินอินเป็นภาพตัวอย่าง

### การปรับแต่ง

- **ธีมในตัว 16 แบบ** + สีเน้นแบบกำหนดเอง รูปลักษณ์สว่าง / มืด / ตามระบบ
- **ไอคอนแอปทางเลือก 8 แบบ** (iOS)
- UI **จีนตัวย่อ / จีนตัวเต็ม / อังกฤษ** (ไม่ขึ้นกับภาษาของระบบ)
- ภาษาและธีมของวิดเจ็ตสะท้อนผ่าน App Group

### iOS และ iPad

- **วิดเจ็ต 8 แบบ** — Daily Character, Level Spotlight, Daily Quiz, **Typing Glance**, Favorites, Wrong Book, Recent, Learning Progress รองรับหน้าจอโฮม หน้าจอล็อก และ StandBy
- วิดเจ็ต Daily Character รองรับ **ปุ่มสลับ** (AppIntent)
- วิดเจ็ต Favorites และ Wrong Book แสดง **ตารางตัวอักษร 2×3 (เล็ก) / 3×3 (กลาง)** พร้อมรหัสอู่ปี่
- **การดำเนินการด่วนบนหน้าจอโฮม** — เลือกได้สูงสุด 4 จาก 7 ตัวเลือก
- **Siri และคำสั่งลัด** — ค้นหาตัวอักษร เปิดตัวอักษรประจำวัน เริ่มแบบทดสอบประจำวัน เปิดการพิมพ์ และอื่น ๆ
- **Spotlight** — จัดทำดัชนีรายการโปรดและตัวอักษรล่าสุด (เปิด/ปิดในการตั้งค่า)
- เลย์เอาต์การพิมพ์แบบเต็มหน้าจอซ่อนแถบแท็บระหว่างฝึก
- คีย์บอร์ดรากแบบเลือกได้: ซ่อนชั่วคราว ระงับคีย์บอร์ดระบบขณะแสดง และสลับไปใช้คีย์บอร์ดระบบหรือฮาร์ดแวร์เมื่อซ่อน

### macOS

- แอป Mac แบบเนทีฟ มีแถบค้นหาแบบอินไลน์ การย้อนกลับด้วย **Esc** เบราว์เซอร์ลอยในแอปสำหรับลิงก์บทเรียน และชีตแชร์ของระบบ
- ฝึกพิมพ์ด้วยแป้นพิมพ์จริงพร้อมแป้นลัดเฉพาะ (ดูด้านล่าง)
- เลย์เอาต์ตารางเป็นค่าเริ่มต้นสำหรับรายการตัวอักษร และตั้งค่าจำนวนคอลัมน์แยกอิสระ

### ทิป

- การให้ทิปในแอปแบบเลือกได้ผ่าน **StoreKit 2** (Apple จัดการการชำระเงินทั้งหมด)

### ความเป็นส่วนตัว

- **ออฟไลน์** — คลังหลัก แบบทดสอบ บทเรียน และการพิมพ์ใช้งานได้โดยไม่ต้องใช้เครือข่าย
- **ไม่มีโฆษณา · ไม่มีการติดตาม** — ไม่มีการวิเคราะห์ ไม่มี SDK ของบุคคลที่สาม

## วิดเจ็ต

iWuBi มี **วิดเจ็ต 8 แบบ** สำหรับหน้าจอโฮม หน้าจอล็อก และ StandBy

### วิธีเพิ่ม

1. กดค้างที่หน้าจอโฮมเพื่อเข้าสู่โหมดแก้ไข
2. แตะ **+** แล้วค้นหา "iWuBi"
3. เลือกวิดเจ็ต เลือกขนาด แล้วแตะ **เพิ่มวิดเจ็ต**
4. สำหรับวิดเจ็ตหน้าจอล็อก ให้กดค้างที่หน้าจอล็อก แตะ **ปรับแต่ง** แล้วเพิ่มวิดเจ็ตเสริมของ iWuBi

### ภาพรวมวิดเจ็ต

| วิดเจ็ต | คำอธิบาย | ขนาด |
|--------|-------------|-------|
| Daily Character | ตัวอักษรประจำวันพร้อมรหัสอู่ปี่ ปุ่มสลับเพื่อเลือกตัวอื่น | เล็ก, กลาง, วิดเจ็ตเสริมหน้าจอล็อก |
| Level Spotlight | เลือกระดับรหัสเมื่อแก้ไข หมุนเวียนทุกวัน | เล็ก, กลาง |
| Daily Quiz | คะแนนสูงสุดและสถิติต่อเนื่องของวันนี้ | เล็ก, หน้าจอล็อก |
| Typing Glance | ความแม่นยำ สถิติต่อเนื่อง และจำนวนรอบ — แตะเพื่อเปิดการพิมพ์ | เล็ก, หน้าจอล็อก |
| Favorites | ตัวอย่างตารางพร้อมรหัสอู่ปี่ แตะช่องหรือเปิดรายการโปรดทั้งหมด | เล็ก, กลาง, หน้าจอล็อก |
| Wrong Book | ตัวอย่างตารางพร้อมรหัส แตะช่องเพื่อไปยังข้อที่ตอบผิดนั้น | เล็ก, กลาง, หน้าจอล็อก |
| Recent | ตัวอักษรที่เปิดดูล่าสุดพร้อมรหัส | เล็ก, กลาง, หน้าจอล็อก |
| Learning Progress | จำนวนเชี่ยวชาญ / เรียนแล้ว / กำลังเรียน | เล็ก, กลาง, หน้าจอล็อก |

พื้นหลังวิดเจ็ตตามไล่เฉดสีธีมของแอปได้ (เปิด/ปิดในการตั้งค่า)
