iWuBi는 **iPhone, iPad, Mac**용 종합 오필(五笔) 입력법 학습 및 글자 조회 도구입니다. 86, 98, 새 세기 오필 표준을 아우르는 3만 단어 이상의 라이브러리, **타이핑 연습**, 병음 검색 및 변환, 일일 퀴즈, 8종 위젯, 완전한 iCloud 동기화를 갖춘, 오필을 마스터하기 위한 올인원 동반자입니다 — **오프라인으로 작동하며 서드파티 의존성이 전혀 없습니다.**

8주년 리프레시를 맞아 순수 SwiftUI로 제작되었습니다.

## 시작하기

1. 처음 실행하면 **5화면 온보딩**을 완료하세요(언제든 건너뛸 수 있습니다).
2. iWuBi를 열고 **조회**에서 글자를 검색하거나, **레벨**에서 간마(简码) 레벨(1~4)별로 둘러보세요. iOS에서는 **손글씨 OCR**로 조회 및 간마 페이지의 검색창을 채울 수 있습니다.
3. 설정 또는 툴바 메뉴에서 86 버전, 98 버전, 새 세기 오필을 전환하세요.
4. **타이핑**을 사용해 보세요 — 전체 코드, 레벨 코드, 혼합 모드를 고르고, 생성 목록의 **무작위 글자 수**를 설정하고, 내장 글, 붙여넣은 텍스트, 즐겨찾기, 오답 노트로 연습하세요.
5. **일일 퀴즈**에 도전하세요 — 하루 8문제로 손에 익히세요. 틀린 문제는 오답 노트에서 복습하세요.
6. 발음도 함께 배운다면 앱 설정에서 **병음 표시** 또는 **병음 검색**을 켜세요.
7. 홈 화면, 잠금 화면, StandBy에 위젯을 추가해 한눈에 학습하세요.

## 기능

### 학습 핵심

- **3만 단어 이상 라이브러리** — 단일 글자와 구절, 86 / 98 / 새 세기 표준, 간마의 구절 자동 조합.
- **간마 둘러보기(레벨 1~4)** — 목록 또는 그리드 보기, 무작위 섞기, 레벨 간 스와이프, iPhone·iPad·Mac에서 조절 가능한 그리드 열 수.
- **타이핑 연습** — 세 가지 모드를 갖춘 전용 탭: 전체 코드, 레벨 코드(레벨 1~4), 혼합(레벨 먼저, 틀리면 전체 코드). 콘텐츠 출처: 사용자 텍스트 붙여넣기, 무작위 글자, 내장 글 14편, 생성된 단어 목록, 즐겨찾기, 오답 노트 복습. 글 하이라이트, 자근 분해 막대, 선택형 화면 자근 키보드, 힌트 / 정답 보기 / 건너뛰기, 정확도 / 연속 기록 / 세션 통계, 이어서 할 수 있는 내장 글 진행 상황.
- **일일 퀴즈** — 하루 8문제: 글자→코드, 코드→글자, 글자→자근 키.
- **오답 노트** — 퀴즈에서 틀린 문제를 자동으로 모으고 상세로 돌아가는 링크를 제공합니다.
- **학습 상태** — 네 단계(미학습 / 학습 중 / 학습함 / 마스터함)와 통계.
- **튜토리얼** — 86 / 98 / 새 세기 자근표, 간결한 가이드, 간마 참조, 16종 이상의 자근 도해(**길게 눌러 원본 이미지 공유**).
- **iCloud 동기화(전환 가능)** — 즐겨찾기, 학습 상태, 오답 노트, 퀴즈 최고 점수, 연속 기록, **타이핑 통계**, **내장 글 진행 상황**. **신규 사용자는 기본으로 켜져 있습니다.**

### 병음 도구

- **손글씨 OCR(iOS)** — 조회 / 간마에서 글자를 그리면 검색창이 로컬에서 채워집니다(기기 내 Vision 사용).
- **병음 접두사 검색** — 조회에서 알파벳을 입력하고 **코드**와 **병음** 모드를 전환하세요. 성조 없는 병음으로 글자를 접두사 일치 검색합니다.
- **전역 병음 표시** — 목록, 퀴즈, 오답 노트, 상세, 공유 스냅샷의 글자 타일 위에 성조 포함 병음을 선택적으로 표시합니다.
- **병음 변환기** — 중국어 텍스트를 붙여넣어 9가지 스타일(성조 포함, 성조 없음, 숫자 성조, 주음부호, 두 줄, 정렬 그리드 등)로 내보냅니다. 오필 코드를 표시할 수 있고, 복사하거나 긴 이미지로 공유할 수 있습니다.

### 조회 및 상세

- **Apple 시스템 사전** — 글자 상세 페이지에서 인라인 뜻 표시(iOS 시스템 UI / macOS 사전 서비스).
- **색상 코드 칩과 자근 키 이미지** — 시각적인 코드 표시와 키 위치 도해.
- **중국어 TTS** — 상세 화면과 TTS 놀이터에서 글자를 읽어 줍니다.
- **긴 이미지 공유** — 글자 상세, 검색 결과, 병음 변환기 출력을 미리보기 이미지로 공유합니다.

### 개인화

- **16가지 내장 테마** + 사용자 지정 강조 색상, 라이트 / 다크 / 시스템 외관.
- **8가지 대체 앱 아이콘**(iOS).
- **중국어 간체 / 중국어 번체 / 영어** UI(시스템 언어와 별개).
- App Group을 통한 위젯 언어 및 테마 반영.

### iOS 및 iPad

- **8종 위젯** — Daily Character, Level Spotlight, Daily Quiz, **Typing Glance**, Favorites, Wrong Book, Recent, Learning Progress. 홈 화면, 잠금 화면, StandBy 지원.
- Daily Character 위젯은 **셔플 버튼**(AppIntent)을 지원합니다.
- Favorites와 Wrong Book 위젯은 오필 코드가 있는 **2×3(소형) / 3×3(중형) 글자 그리드**를 보여 줍니다.
- **홈 화면 빠른 동작** — 7개 옵션 중 최대 4개 선택.
- **Siri 및 단축어** — 글자 조회, 오늘의 글자 열기, 일일 퀴즈 시작, 타이핑 열기 등.
- **Spotlight** — 즐겨찾기와 최근 글자 색인(설정에서 전환).
- 몰입형 타이핑 레이아웃은 연습 중 탭 바를 숨깁니다.
- 선택형 자근 키보드: 일시적으로 숨기기, 표시 중에는 시스템 키보드 억제, 숨기면 시스템 또는 하드웨어 키보드로 대체.

### macOS

- 인라인 조회 검색창, **Esc** 뒤로 가기, 튜토리얼 링크용 플로팅 앱 내 브라우저, 시스템 공유 시트를 갖춘 네이티브 Mac 앱.
- 전용 단축키를 지원하는 물리 키보드 타이핑 연습(아래 참조).
- 글자 목록의 기본값은 그리드 레이아웃이며 열 수 설정은 독립적입니다.

### 후원

- StoreKit 2를 통한 선택형 앱 내 후원(모든 결제는 Apple이 처리).

### 개인정보 보호

- **오프라인** — 핵심 라이브러리, 퀴즈, 튜토리얼, 타이핑은 네트워크 없이 작동합니다.
- **광고 없음 · 추적 없음** — 분석 없음, 서드파티 SDK 없음.

## 위젯

iWuBi는 홈 화면, 잠금 화면, StandBy용으로 **8종의 위젯**을 제공합니다.

### 추가 방법

1. 홈 화면을 길게 눌러 편집 모드로 들어갑니다.
2. **+**를 누르고 "iWuBi"를 검색합니다.
3. 위젯을 고르고 크기를 선택한 뒤 **위젯 추가**를 누릅니다.
4. 잠금 화면 위젯은 잠금 화면을 길게 누르고 **사용자화**를 누른 뒤 iWuBi 액세서리를 추가합니다.

### 위젯 개요

| 위젯 | 설명 | 크기 |
|--------|-------------|-------|
| Daily Character | 오필 코드가 있는 오늘의 글자. 셔플 버튼으로 다른 글자 선택. | 소형, 중형, 잠금 화면 액세서리 |
| Level Spotlight | 편집할 때 코드 레벨을 선택. 매일 순환. | 소형, 중형 |
| Daily Quiz | 오늘의 최고 점수와 연속 기록. | 소형, 잠금 화면 |
| Typing Glance | 정확도, 연속 기록, 세션 수 — 탭하면 타이핑 열기. | 소형, 잠금 화면 |
| Favorites | 오필 코드가 있는 그리드 미리보기. 셀을 누르거나 모든 즐겨찾기 열기. | 소형, 중형, 잠금 화면 |
| Wrong Book | 코드가 있는 그리드 미리보기. 셀을 누르면 해당 오답으로 이동. | 소형, 중형, 잠금 화면 |
| Recent | 코드와 함께 최근 본 글자. | 소형, 중형, 잠금 화면 |
| Learning Progress | 마스터함 / 학습함 / 학습 중 개수. | 소형, 중형, 잠금 화면 |

위젯 배경은 앱 테마 그라데이션을 따를 수 있습니다(설정에서 전환).

## 키보드 단축키

### 앱 탐색(하드웨어 키보드를 사용하는 iPad 및 Mac)

| 단축키 | 동작 |
|----------|--------|
| ⌘F | 조회를 열고 검색창에 포커스 |
| ⌘1 | 조회 탭 |
| ⌘2 | 레벨 탭 |
| ⌘3 | 학습 탭 |
| ⌘4 | **타이핑 탭** |
| ⌘5 | 설정 탭 |
| Esc(Mac) | 뒤로 가기 또는 시트 / 플로팅 브라우저 닫기 |

### 타이핑 연습

| 플랫폼 | 키 | 동작 |
|----------|------|--------|
| iOS / iPad | A–Z | 오필 코드 글자 입력 |
| iOS / iPad | 스페이스 | 힌트 표시 |
| iOS / iPad | 리턴 | 현재 입력 확인 |
| iOS / iPad | 백스페이스 | 마지막 키 삭제 |
| Mac | A–Z | 오필 코드 글자 입력 |
| Mac | 스페이스 또는 1 | 힌트 표시 |
| Mac | 2 | 정답 보기 |
| Mac | 3 | 현재 글자 건너뛰기 |
| Mac | 리턴 | 현재 입력 확인 |
| Mac | Backspace / Delete | 마지막 키 삭제 |

전체 입력(최대 4키)은 자동 제출됩니다. 힌트, 정답 보기, 건너뛰기도 현재 글자를 제출합니다. 화면 버튼은 항상 사용할 수 있습니다.
