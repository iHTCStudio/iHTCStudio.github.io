iWuBi — комплексный инструмент для изучения метода ввода «Утби» (Wubi) и поиска иероглифов для **iPhone, iPad и Mac**. Библиотека из 30 000+ слов охватывает стандарты Утби 86, 98 и «Новый век», а также **тренировку набора**, поиск и преобразование пиньиня, ежедневные викторины, 8 виджетов и полную синхронизацию через iCloud — универсальный помощник для освоения Утби, **офлайн и без сторонних зависимостей.**

Создано на чистом SwiftUI к 8-летию приложения.

## Начало работы

1. При первом запуске пройдите **онбординг из 5 экранов** (или пропустите его в любой момент).
2. Откройте iWuBi и ищите любой иероглиф в **Поиске** или просматривайте по уровням простых кодов (1–4) в **Уровнях**. На iOS **рукописный OCR** может заполнять строку поиска на страницах «Поиск» и «Простые коды».
3. Переключайтесь между Утби 86, 98 и «Новый век» в настройках или в меню панели инструментов.
4. Попробуйте **Набор** — выберите режим полного кода, кода уровня или смешанный; задайте **число случайных иероглифов** для генерируемых списков; тренируйтесь на встроенных текстах, вставленном тексте, избранном или журнале ошибок.
5. Проходите **ежедневную викторину** — 8 вопросов в день для закрепления навыка. Разбирайте ошибки в Журнале ошибок.
6. Включите **Показывать пиньинь** или **Поиск по пиньиню** в настройках приложения, если вы заодно учите произношение.
7. Добавьте виджеты на экран «Домой», экран блокировки или в режим «Ожидание», чтобы учиться с первого взгляда.

## Возможности

### Основа обучения

- **Библиотека из 30 000+ слов** — одиночные иероглифы и фразы; стандарты 86 / 98 / «Новый век»; автоматическая сборка простых кодов для фраз.
- **Просмотр простых кодов (уровни 1–4)** — вид списком или сеткой, случайное перемешивание, переключение между уровнями смахиванием; настраиваемое число столбцов сетки на iPhone, iPad и Mac.
- **Тренировка набора** — отдельная вкладка с тремя режимами: полный код, код уровня (уровни 1–4) и смешанный (сначала уровень, после ошибки — полный код). Источники материала: вставленный текст, случайные иероглифы, 14 встроенных текстов, сгенерированные списки слов, избранное и повторение журнала ошибок. Подсветка текста, полоса разбора по корням, необязательная экранная клавиатура корней, подсказка / показать / пропустить, статистика точности / серии / сессий и возобновляемый прогресс по встроенным текстам.
- **Ежедневная викторина** — 8 вопросов в день: иероглиф → код, код → иероглиф, иероглиф → корневая клавиша.
- **Журнал ошибок** — автоматически собирает ошибки викторин со ссылкой на страницу иероглифа.
- **Статус изучения** — четыре уровня (Не изучен / Изучается / Выучен / Освоен) со статистикой.
- **Обучающие материалы** — таблицы корней 86 / 98 / «Новый век», краткие руководства, справочник простых кодов, 16+ схем корней (**долгое нажатие — поделиться исходным изображением**).
- **Синхронизация iCloud (переключается)** — избранное, статус изучения, журнал ошибок, лучший результат викторины, серия, **статистика набора** и **прогресс по встроенным текстам**. **Для новых пользователей включена по умолчанию.**

### Инструменты пиньиня

- **Рукописный OCR (iOS)** — нарисуйте иероглиф в «Поиске» / «Простых кодах», чтобы заполнить поиск локально (Vision на устройстве).
- **Поиск по префиксу пиньиня** — вводите буквы в «Поиске» и переключайтесь между режимами **кода** и **пиньиня**; иероглифы подбираются по префиксу пиньиня без тонов.
- **Отображение пиньиня везде** — необязательный пиньинь с тонами над плитками иероглифов в списках, викторинах, журнале ошибок, на странице иероглифа и в снимках для отправки.
- **Конвертер пиньиня** — вставьте китайский текст и экспортируйте в 9 стилях (с тонами, без тонов, с цифрами тонов, чжуинь, в две строки, выровненная сетка и др.); при желании показывайте коды Утби; копируйте или делитесь длинным изображением.

### Поиск и страница иероглифа

- **Системный словарь Apple** — встроенные определения на странице иероглифа (системный интерфейс iOS / службы словаря macOS).
- **Цветные чипы кода и изображения корневых клавиш** — наглядное кодирование и схемы расположения клавиш.
- **Китайский TTS** — озвучивание иероглифов со страницы иероглифа и из площадки TTS.
- **Отправка длинным изображением** — делитесь страницей иероглифа, результатами поиска и результатом конвертера пиньиня как изображением для предпросмотра.

### Персонализация

- **16 встроенных тем** + собственный акцентный цвет; светлое / тёмное / системное оформление.
- **8 альтернативных значков приложения** (iOS).
- Интерфейс на **упрощённом китайском / традиционном китайском / английском** (независимо от языка системы).
- Язык и тема виджетов отражаются через App Group.

### iOS и iPad

- **8 видов виджетов** — Daily Character, Level Spotlight, Daily Quiz, **Typing Glance**, Favorites, Wrong Book, Recent, Learning Progress. Экран «Домой», экран блокировки и «Ожидание».
- Виджет Daily Character поддерживает **кнопку перемешивания** (AppIntent).
- Виджеты Favorites и Wrong Book показывают **сетки иероглифов 2×3 (малый) / 3×3 (средний)** с кодами Утби.
- **Быстрые действия на экране «Домой»** — выберите до 4 из 7 вариантов.
- **Siri и «Быстрые команды»** — найти иероглиф, открыть «Иероглиф дня», начать ежедневную викторину, открыть «Набор» и другое.
- **Spotlight** — индексирование избранного и недавних иероглифов (переключатель в настройках).
- Иммерсивный режим набора скрывает панель вкладок во время тренировки.
- Необязательная клавиатура корней: можно временно скрыть, подавлять системную клавиатуру, пока она видна, и переходить на системную или внешнюю клавиатуру, когда она скрыта.

### macOS

- Нативное приложение для Mac со встроенной строкой поиска, возвратом по **Esc**, плавающим браузером для ссылок из обучения и системным меню «Поделиться».
- Тренировка набора с физической клавиатуры со специальными сочетаниями клавиш (см. ниже).
- Сетка по умолчанию для списков иероглифов; число столбцов настраивается независимо.

### Пожертвования

- Необязательные пожертвования в приложении через StoreKit 2 (все платежи обрабатывает Apple).

### Конфиденциальность

- **Офлайн** — основная библиотека, викторины, обучающие материалы и набор работают без сети.
- **Без рекламы · без отслеживания** — никакой аналитики, никаких сторонних SDK.

## Виджеты

iWuBi предлагает **8 видов виджетов** для экрана «Домой», экрана блокировки и режима «Ожидание».

### Как добавить

1. Нажмите и удерживайте экран «Домой», чтобы войти в режим редактирования.
2. Нажмите **+** и найдите «iWuBi».
3. Выберите виджет, укажите размер и нажмите **Добавить виджет**.
4. Для виджетов экрана блокировки нажмите и удерживайте экран блокировки, нажмите **Настроить** и добавьте аксессуар iWuBi.

### Обзор виджетов

| Виджет | Описание | Размеры |
|--------|-------------|-------|
| Daily Character | Иероглиф дня с кодом Утби; кнопка перемешивания для выбора другого. | Малый, средний, аксессуары экрана блокировки |
| Level Spotlight | Выберите уровень кода при редактировании; меняется ежедневно. | Малый, средний |
| Daily Quiz | Лучший результат и серия за сегодня. | Малый, экран блокировки |
| Typing Glance | Точность, серия и число сессий — нажмите, чтобы открыть «Набор». | Малый, экран блокировки |
| Favorites | Сетка предпросмотра с кодами Утби; нажмите на ячейку или откройте всё избранное. | Малый, средний, экран блокировки |
| Wrong Book | Сетка предпросмотра с кодами; нажмите на ячейку, чтобы перейти к этой ошибке. | Малый, средний, экран блокировки |
| Recent | Недавно просмотренные иероглифы с кодами. | Малый, средний, экран блокировки |
| Learning Progress | Количество освоенных / выученных / изучаемых. | Малый, средний, экран блокировки |

Фон виджета может следовать градиенту темы приложения (переключатель в настройках).

## Сочетания клавиш

### Навигация по приложению (iPad с внешней клавиатурой и Mac)

| Сочетание | Действие |
|----------|--------|
| ⌘F | Открыть «Поиск» и перейти в строку поиска |
| ⌘1 | Вкладка «Поиск» |
| ⌘2 | Вкладка «Уровни» |
| ⌘3 | Вкладка «Обучение» |
| ⌘4 | **Вкладка «Набор»** |
| ⌘5 | Вкладка «Настройки» |
| Esc (Mac) | Назад или закрыть панели / плавающий браузер |

### Тренировка набора

| Платформа | Клавиши | Действие |
|----------|------|--------|
| iOS / iPad | A–Z | Ввод букв кода Утби |
| iOS / iPad | Пробел | Показать подсказку |
| iOS / iPad | Return | Подтвердить текущий ввод |
| iOS / iPad | Backspace | Удалить последнюю клавишу |
| Mac | A–Z | Ввод букв кода Утби |
| Mac | Пробел или 1 | Показать подсказку |
| Mac | 2 | Показать ответ |
| Mac | 3 | Пропустить текущий иероглиф |
| Mac | Return | Подтвердить текущий ввод |
| Mac | Backspace / Delete | Удалить последнюю клавишу |

Полный ввод (до 4 клавиш) отправляется автоматически. Подсказка, показ ответа и пропуск также отправляют текущий иероглиф. Экранные кнопки доступны всегда.
