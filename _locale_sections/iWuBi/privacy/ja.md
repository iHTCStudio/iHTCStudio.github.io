iHTC Studio（以下「当社」）は、iWuBi（「爱五笔」とも呼ばれます）を開発しました。このページでは、本アプリのご利用時におけるデータの収集、利用、開示に関する方針を説明します。

## 概要

**iWuBi は、個人データを収集、保存、送信することは一切ありません。** 単語の検索、クイズ、学習の進捗はすべて端末上だけで処理されます。アカウントは不要で、主要機能にインターネット接続は必要ありません。

## データ収集について

当社はデータを一切収集しません。具体的には次のとおりです。

- **個人情報は収集されません**（氏名、メールアドレス、電話番号、アカウントなし）。
- **利用データや分析データは収集されません。**
- 広告、分析、クラッシュレポート向けの**サードパーティ SDK は組み込まれていません。**
- **Cookie やトラッキング技術は使用しません。**

## iCloud 同期

iWuBi には、任意の iCloud 同期機能があります（設定で切り替え可能）。**新規ユーザーでは iCloud 同期が既定でオンです。** 有効にすると、次のデータが、Apple が提供・管理するサービスである **iCloud キーバリューストレージ（iCloud KVS）** を通じて同期されます。

| 同期されるデータ | 目的 |
|-------------|---------|
| お気に入り | ブックマークした文字 |
| 学習状況 | 各文字の進捗レベル |
| 間違い帳 | クイズで間違えた問題 |
| クイズのベストスコア | デイリークイズの最高得点 |
| 連続記録 | デイリークイズの連続日数 |
| タイピング統計 | タイピング練習の正答率、連続記録、セッション数 |
| 内蔵文章の進捗 | 内蔵タイピング文章の再開位置 |

このデータは、Apple の iCloud インフラを通じて、お客様のデバイス間で直接送信されます。iHTC Studio はサーバーを運用しておらず、お客様の iCloud データにアクセスすることはできません。iCloud データの取り扱いには [Apple のプライバシーポリシー](https://www.apple.com/privacy/)が適用されます。

iCloud 同期は、設定でいつでも無効にできます。無効にすると、すべてのデータは各デバイスのローカルにとどまります。

タイピング UI の設定（画面キーボード、文章のピンイン、ミスキーの保持）は各デバイスにローカルで保存され、iCloud では同期されません。

## 端末内に保存されるデータ

iWuBi が作成するデータはすべて端末内にとどまります。

| データ | 保存場所 | ユーザーによる管理 |
|------|---------|--------------|
| お気に入り | ローカル（UserDefaults） | アプリ内で個別に削除、またはすべて消去 |
| 学習状況 | ローカル（UserDefaults） | アプリの設定でリセット |
| 間違い帳 | ローカル（UserDefaults） | アプリ内で消去 |
| クイズのスコアと連続記録 | ローカル（UserDefaults） | アプリの設定でリセット |
| タイピング統計と文章の進捗 | ローカル（UserDefaults / App Group）、任意で iCloud KVS | 学習データのリセット時に消去 |
| タイピング UI の設定 | ローカル（UserDefaults） | 設定 → タイピングで変更 |
| アプリの設定とテーマ | ローカル（UserDefaults） | アプリを削除してリセット |

ウィジェットは、メインアプリとウィジェット機能拡張の間でデータを共有するために **App Group** コンテナを使用します。このコンテナは端末内にとどまり、第三者がアクセスすることはできません。

## アプリ内の投げ銭

iWuBi では、**StoreKit 2** による任意の投げ銭を用意しています。決済処理はすべて Apple が行います。当社は、金融情報、クレジットカードの詳細、Apple ID のデータを受け取ったり、保存したり、アクセスしたりすることはありません。投げ銭の取引には、Apple 自身のプライバシーポリシーと規約が適用されます。

## 権限

iWuBi は、特別なデバイス権限を要求しません。カメラ、マイク、連絡先、位置情報、写真ライブラリ、ローカルネットワークにはアクセスしません。

## お子様のプライバシー

iWuBi は、13 歳未満のお子様を含め、誰からも個人データを意図的に収集することはありません。データをまったく収集しないため、特別な措置は必要ありません。

## 本ポリシーの変更

当社は、本プライバシーポリシーを随時更新することがあります。変更は更新日とともにこのページに掲載します。定期的にこのページをご確認いただくことをお勧めします。
