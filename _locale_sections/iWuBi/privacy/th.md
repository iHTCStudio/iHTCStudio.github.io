iHTC Studio ("เรา") เป็นผู้พัฒนา iWuBi (หรือที่รู้จักในชื่อ "爱五笔") หน้านี้อธิบายนโยบายของเราเกี่ยวกับการเก็บรวบรวม การใช้ และการเปิดเผยข้อมูลเมื่อคุณใช้แอปของเรา

## สรุป

**iWuBi ไม่เก็บรวบรวม จัดเก็บ หรือส่งข้อมูลส่วนบุคคลใด ๆ** การค้นหาคำ แบบทดสอบ และความคืบหน้าการเรียนรู้ทั้งหมดประมวลผลบนอุปกรณ์ของคุณเท่านั้น ไม่ต้องมีบัญชี และฟีเจอร์หลักทั้งหมดไม่ต้องเชื่อมต่ออินเทอร์เน็ต

## การเก็บรวบรวมข้อมูล

เราไม่เก็บรวบรวมข้อมูลใด ๆ โดยเฉพาะอย่างยิ่ง:

- **ไม่เก็บข้อมูลส่วนบุคคล** (ไม่มีชื่อ อีเมล หมายเลขโทรศัพท์ หรือบัญชี)
- **ไม่เก็บข้อมูลการใช้งาน** หรือการวิเคราะห์
- **ไม่มี SDK ของบุคคลที่สาม** สำหรับโฆษณา การวิเคราะห์ หรือรายงานข้อขัดข้อง
- **ไม่ใช้คุกกี้หรือเทคโนโลยีติดตาม**

## การซิงค์ iCloud

iWuBi มีฟีเจอร์ซิงค์ iCloud แบบเลือกใช้ (เปิด/ปิดได้ในการตั้งค่า) **สำหรับผู้ใช้ใหม่ การซิงค์ iCloud เปิดไว้เป็นค่าเริ่มต้น** เมื่อเปิดใช้ ข้อมูลต่อไปนี้จะซิงค์ผ่าน **ที่เก็บข้อมูลคีย์-ค่าของ iCloud (iCloud KVS)** ซึ่งเป็นบริการที่ Apple จัดหาและดูแลทั้งหมด:

| ข้อมูลที่ซิงค์ | วัตถุประสงค์ |
|-------------|---------|
| รายการโปรด | ตัวอักษรที่คุณบุ๊กมาร์กไว้ |
| สถานะการเรียนรู้ | ระดับความคืบหน้าของแต่ละตัวอักษร |
| สมุดบันทึกข้อที่ตอบผิด | คำถามแบบทดสอบที่ตอบผิด |
| คะแนนแบบทดสอบสูงสุด | คะแนนสูงสุดของแบบทดสอบประจำวัน |
| สถิติต่อเนื่อง | จำนวนวันติดต่อกันที่ทำแบบทดสอบประจำวัน |
| สถิติการพิมพ์ | ความแม่นยำ สถิติต่อเนื่อง และจำนวนรอบจากการฝึกพิมพ์ |
| ความคืบหน้าบทความในตัว | ตำแหน่งที่ทำต่อในบทความฝึกพิมพ์ในตัว |

ข้อมูลนี้ส่งตรงระหว่างอุปกรณ์ของคุณผ่านโครงสร้างพื้นฐาน iCloud ของ Apple iHTC Studio ไม่ได้ดำเนินการเซิร์ฟเวอร์ใด ๆ และไม่สามารถเข้าถึงข้อมูล iCloud ของคุณ การจัดการข้อมูล iCloud อยู่ภายใต้ [นโยบายความเป็นส่วนตัวของ Apple](https://www.apple.com/privacy/)

คุณปิดการซิงค์ iCloud ได้ทุกเมื่อในการตั้งค่า เมื่อปิด ข้อมูลทั้งหมดจะอยู่ในเครื่องของแต่ละอุปกรณ์

ค่ากำหนด UI การพิมพ์ (คีย์บอร์ดบนหน้าจอ พินอินของบทความ การคงปุ่มที่กดผิด) จะจัดเก็บในเครื่องของแต่ละอุปกรณ์และ **ไม่** ซิงค์ผ่าน iCloud

## ข้อมูลที่จัดเก็บในเครื่องบนอุปกรณ์ของคุณ

ข้อมูลทั้งหมดที่ iWuBi สร้างขึ้นจะอยู่บนอุปกรณ์ของคุณ:

| ข้อมูล | ที่เก็บ | การควบคุมโดยผู้ใช้ |
|------|---------|--------------|
| รายการโปรด | ในเครื่อง (UserDefaults) | ลบทีละรายการหรือล้างทั้งหมดในแอป |
| สถานะการเรียนรู้ | ในเครื่อง (UserDefaults) | รีเซ็ตในการตั้งค่าแอป |
| สมุดบันทึกข้อที่ตอบผิด | ในเครื่อง (UserDefaults) | ล้างในแอป |
| คะแนนแบบทดสอบและสถิติต่อเนื่อง | ในเครื่อง (UserDefaults) | รีเซ็ตในการตั้งค่าแอป |
| สถิติการพิมพ์และความคืบหน้าบทความ | ในเครื่อง (UserDefaults / App Group); iCloud KVS แบบเลือกได้ | ล้างเมื่อรีเซ็ตข้อมูลการเรียนรู้ |
| ค่ากำหนด UI การพิมพ์ | ในเครื่อง (UserDefaults) | เปลี่ยนใน การตั้งค่า → การพิมพ์ |
| การตั้งค่าแอปและธีม | ในเครื่อง (UserDefaults) | รีเซ็ตโดยลบแอป |

วิดเจ็ตใช้คอนเทนเนอร์ **App Group** เพื่อแบ่งปันข้อมูลระหว่างแอปหลักและส่วนขยายวิดเจ็ต คอนเทนเนอร์นี้อยู่บนอุปกรณ์ของคุณและบุคคลที่สามเข้าถึงไม่ได้

## การให้ทิปในแอป

iWuBi มีการให้ทิปแบบเลือกได้ผ่าน **StoreKit 2** การประมวลผลการชำระเงินทั้งหมดดำเนินการโดย Apple เราไม่ได้รับ จัดเก็บ หรือเข้าถึงข้อมูลทางการเงิน รายละเอียดบัตรเครดิต หรือข้อมูล Apple ID ธุรกรรมการให้ทิปอยู่ภายใต้นโยบายความเป็นส่วนตัวและข้อกำหนดของ Apple เอง

## สิทธิ์การเข้าถึง

iWuBi ไม่ขอสิทธิ์พิเศษใด ๆ ของอุปกรณ์ ไม่มีการเข้าถึงกล้อง ไมโครโฟน รายชื่อติดต่อ ตำแหน่งที่ตั้ง คลังรูปภาพ หรือเครือข่ายภายในเครื่อง

## ความเป็นส่วนตัวของเด็ก

iWuBi ไม่ได้ตั้งใจเก็บข้อมูลส่วนบุคคลจากใครก็ตาม รวมถึงเด็กอายุต่ำกว่า 13 ปี เนื่องจากไม่มีการเก็บข้อมูลเลย จึงไม่จำเป็นต้องมีข้อกำหนดพิเศษ

## การเปลี่ยนแปลงนโยบายนี้

เราอาจปรับปรุงนโยบายความเป็นส่วนตัวนี้เป็นครั้งคราว การเปลี่ยนแปลงใด ๆ จะเผยแพร่บนหน้านี้พร้อมวันที่ที่อัปเดต เราขอแนะนำให้คุณตรวจดูหน้านี้เป็นระยะ
