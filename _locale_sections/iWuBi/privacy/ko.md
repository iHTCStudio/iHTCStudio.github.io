iHTC Studio("당사")는 iWuBi("爱五笔"로도 알려져 있음)를 만들었습니다. 이 페이지는 앱 사용 시 데이터 수집, 이용 및 공개에 관한 당사의 방침을 설명합니다.

## 요약

**iWuBi는 어떤 개인 데이터도 수집, 저장 또는 전송하지 않습니다.** 모든 단어 조회, 퀴즈, 학습 진행 상황은 전적으로 기기에서 처리됩니다. 계정이 필요 없으며, 핵심 기능에는 인터넷 연결이 필요하지 않습니다.

## 데이터 수집

당사는 어떤 데이터도 수집하지 않습니다. 구체적으로 다음과 같습니다.

- **개인정보를 수집하지 않습니다**(이름, 이메일, 전화번호, 계정 없음).
- **사용 데이터나 분석 데이터를 수집하지 않습니다.**
- 광고, 분석, 충돌 보고용 **서드파티 SDK가 통합되어 있지 않습니다.**
- **쿠키나 추적 기술을 사용하지 않습니다.**

## iCloud 동기화

iWuBi는 선택적 iCloud 동기화 기능을 제공합니다(설정에서 전환 가능). **신규 사용자는 iCloud 동기화가 기본으로 켜져 있습니다.** 켜면 다음 데이터가 Apple이 전적으로 제공하고 관리하는 서비스인 **iCloud 키-값 저장소(iCloud KVS)**를 통해 동기화됩니다.

| 동기화되는 데이터 | 목적 |
|-------------|---------|
| 즐겨찾기 | 북마크한 글자 |
| 학습 상태 | 각 글자의 진행 단계 |
| 오답 노트 | 퀴즈에서 틀린 문제 |
| 퀴즈 최고 점수 | 일일 퀴즈 최고 점수 |
| 연속 기록 | 일일 퀴즈 연속 일수 |
| 타이핑 통계 | 타이핑 연습의 정확도, 연속 기록, 세션 수 |
| 내장 글 진행 상황 | 내장 타이핑 글의 이어하기 위치 |

이 데이터는 Apple의 iCloud 인프라를 통해 기기 간에 직접 전송됩니다. iHTC Studio는 서버를 운영하지 않으며 사용자의 iCloud 데이터에 접근할 수 없습니다. iCloud 데이터의 처리에는 [Apple 개인정보 보호 정책](https://www.apple.com/privacy/)이 적용됩니다.

설정에서 언제든 iCloud 동기화를 끌 수 있습니다. 끄면 모든 데이터는 각 기기에 로컬로 남습니다.

타이핑 UI 환경설정(화면 키보드, 글 병음, 오타 키 유지)은 각 기기에 로컬로 저장되며 iCloud로 동기화되지 **않습니다**.

## 기기에 로컬로 저장되는 데이터

iWuBi가 만드는 모든 데이터는 기기에 남습니다.

| 데이터 | 저장 위치 | 사용자 제어 |
|------|---------|--------------|
| 즐겨찾기 | 로컬(UserDefaults) | 앱에서 개별 삭제 또는 전체 지우기 |
| 학습 상태 | 로컬(UserDefaults) | 앱 설정에서 초기화 |
| 오답 노트 | 로컬(UserDefaults) | 앱에서 지우기 |
| 퀴즈 점수 및 연속 기록 | 로컬(UserDefaults) | 앱 설정에서 초기화 |
| 타이핑 통계 및 글 진행 상황 | 로컬(UserDefaults / App Group), 선택적으로 iCloud KVS | 학습 데이터 초기화 시 삭제 |
| 타이핑 UI 환경설정 | 로컬(UserDefaults) | 설정 → 타이핑에서 변경 |
| 앱 환경설정 및 테마 | 로컬(UserDefaults) | 앱을 삭제해 초기화 |

위젯은 메인 앱과 위젯 확장 간에 데이터를 공유하기 위해 **App Group** 컨테이너를 사용합니다. 이 컨테이너는 기기에 남으며 어떤 제3자도 접근할 수 없습니다.

## 앱 내 후원

iWuBi는 **StoreKit 2**를 통한 선택적 후원을 제공합니다. 모든 결제 처리는 전적으로 Apple이 담당합니다. 당사는 금융 정보, 신용카드 정보, Apple ID 데이터를 받거나 저장하거나 접근하지 않습니다. 후원 거래에는 Apple 자체의 개인정보 처리방침과 약관이 적용됩니다.

## 권한

iWuBi는 특별한 기기 권한을 요청하지 않습니다. 카메라, 마이크, 연락처, 위치, 사진 보관함, 로컬 네트워크에 접근하지 않습니다.

## 아동 개인정보 보호

iWuBi는 13세 미만 아동을 포함해 누구에게서도 개인 데이터를 의도적으로 수집하지 않습니다. 데이터를 전혀 수집하지 않으므로 별도의 조치는 필요하지 않습니다.
