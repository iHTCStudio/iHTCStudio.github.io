iVirtue(爱弟子规 / 愛弟子規)은 단순한 대련 목록이 아닌 **몰입형 대련 학습 스튜디오**입니다. **계정이 필요 없습니다.** 엄선한 **대련 90개**(작가 약 102명, 명구 약 3,348구)가 모두 기기에 내장되어 있어 설치 후 **네트워크 요청이 전혀 없습니다**. 노래방 스타일 하이라이트로 **낭송**하고, **세로쓰기 읽기**(品联)를 즐기고, **학습 교실**(페이드, 빈칸 채우기, 낭송 확인, 퀴즈, 寻规)에서 연습하며, 절기·명절·계절에 맞춘 **상황별 오늘의 대련**을 열어 보세요. **12가지 스타일의 공유 카드** 내보내기, **홈 / 잠금 화면 위젯**, 선택적 **읽기 실시간 현황(Live Activity)**, **Siri 및 단축어**, 즐겨찾기와 진행 상황을 위한 선택적 **iCloud**도 지원합니다. **광고 없음. 추적 없음. 수집되는 데이터 없음.**

## 시작하기(단계별)

### 1. 처음 실행

1. [App Store](https://apps.apple.com/app/id6796000304)에서 설치하고 **iVirtue**을 엽니다.
2. **6페이지 시작 가이드**(브랜드 → 낭송 → 세로쓰기 읽기 → 학습 → 시스템 기능 → 개인정보 보호)를 완료하세요.
3. 기능 가이드는 언제든 **다시 볼 수 있습니다**: **설정 → 도움말 → 기능 가이드**.
4. 앱 내 **사용법 / 위젯 / 단축어** 가이드는 **설정 → 도움말**에 있으며 서로 연결되어 있습니다.

### 2. 홈에서 오늘의 대련 읽기

1. **홈** 탭을 엽니다.
2. **오늘의 대련** 히어로에 제목과 **상련·하련**(그리고 있으면 가로 제목인 横批)이 표시됩니다.
3. 히어로를 탭하면 전체 상세 페이지가 열립니다.
4. 선택: **설정 → 오늘의 대련**에서 **오늘의 대련 알림**을 켜세요(로컬 예약만 사용).

### 3. 탐색 및 검색

1. **탐색**을 엽니다(이전 iOS 빌드에서는 홈 검색).
2. 다섯 가지 섹션을 둘러보세요: **형식(体裁)**, **주제**, **작가(联家)**, **명구**, **모음집**.
3. **검색**으로 제목, 구절, 작가를 찾을 수 있습니다(간체 / 번체 모두 지원).
4. 대련을 탭해 상세 정보를 보고, 별표를 눌러 **즐겨찾기**에 추가하세요.

### 4. 낭송(诵联)

1. 대련 상세 페이지에서 **낭송**을 탭합니다.
2. **노래방 스타일** 하이라이트를 따라가세요(상세 화면은 문단 단위, 낭송 스튜디오는 글자 단위).
3. **속도 / 음높이 / 음성**은 **설정 → 읽기 및 낭송**에서 조절합니다.
4. 선택: **무음 모드 재생**, **백그라운드 오디오**(지금 재생 중 / 잠금 화면), 연속 재생 목록을 켤 수 있습니다.
5. 딥링크나 Siri의 **낭송**으로 대련을 열고 자동으로 읽기를 시작할 수도 있습니다.

### 5. 세로쓰기 읽기와 공유 카드(品联 / 规卡)

1. 상세 화면에서 **세로 / 가로** 레이아웃을 전환하고, **병음**, 번체 글자, 가운데 정렬을 원하는 대로 설정하세요.
2. **공유 카드**를 열어 **12가지 스타일**(클래식 / 수묵 / 세로쓰기 / 주홍 / …)과 화면 비율 중에서 고릅니다.
3. 미리 보고 **사진에 저장**(추가 전용 권한)하거나 시스템 공유 시트로 공유하세요.
4. 선택: 설정에서 **읽기 실시간 현황**을 켜세요(iPhone, 포그라운드에서 시작해야 함).

### 6. 학습 교실(美德学堂)

1. 홈 / 딥링크 `ivirtue://study` / 단축어에서 **학습**을 엽니다.
2. **페이드**, **빈칸 채우기**, **낭송 확인**, **퀴즈** 모드를 시도해 보세요.
3. **寻规**(짝 맞추기 게임)를 해 보세요.
4. **4단계 숙달도**(미학습 → 익숙함 → 알고 있음 → 숙달)와 연속 기록을 확인하세요.

### 7. 위젯, Siri, 홈 화면 바로가기

1. 홈 화면을 길게 누르기 → **위젯 편집** → **오늘의 대련 / 명구 / 학습 진행 상황 / 즐겨찾기**를 추가합니다.
2. 오늘의 대련 위젯에서 **종이 스타일**(부드러운 / 진한 빨강 / 단색)과 오늘의 대련을 바꾸는 **데스크톱 새로 고침**을 사용해 보세요(오늘의 알림 문구도 함께 맞춰집니다).
3. **Siri**에게 오늘의 대련, 낭송, 무작위, 즐겨찾기, 검색을 요청해 보세요.
4. **설정 → 바로가기**에서 최대 **4개의 홈 화면 빠른 동작**을 설정하세요.

### 8. 개인정보 보호와 동기화

1. 설치 후 모든 것이 **완전한 오프라인**으로 동작합니다.
2. 선택적 **iCloud 동기화**(설정 → 데이터)는 즐겨찾기, 대련 목록, 읽기 기록, 숙달도, 연속 기록을 iHTC Studio 서버가 아닌 **개인 iCloud**를 통해 미러링합니다.
3. 개발자 후원(선택적 StoreKit 구매)은 유료 콘텐츠를 잠금 해제하지 않으며 계정도 만들지 않습니다.

## 기능

### 낭송 스튜디오

- 하이라이트가 있는 노래방 스타일 **TTS**
- **속도**, **음높이**, **음성** 조절 가능
- 선택적 **백그라운드 오디오** + 잠금 화면 **지금 재생 중**
- 즐겨찾기 / 카테고리에서 이어지는 **연속 읽기** 대기열

### 세로쓰기 몰입형 읽기

- 고전적인 **세로·가로** 레이아웃
- **병음**, 번체 변환, 배경 / 감상 노트
- 줄 순서는 항상 **横批(있는 경우) → 상련 → 하련**
- 다양한 화면 비율을 지원하는 **12가지 공유 카드 스타일**

### 학습 시스템

- 페이드 · 빈칸 채우기 · 낭송 확인 · 퀴즈
- **寻规** 게임 모드
- **4단계 숙달도** + 연속 기록

### 상황별 오늘의 대련

- 절기 · 명절 · 계절(같은 날 캐시 / 데스크톱 새로 고침 지원)
- 로컬 알림(약 60일 예약 범위)
- 위젯 + 제어 센터 컨트롤(iOS 18 이상)

### 콘텐츠 한눈에 보기

- **대련 90개** · **작가 약 102명** · **명구 약 3,348구** · 내장 데이터 약 3.9 MB
- 다섯 가지 탐색 섹션, 목록 / 그리드 / 카드 미리보기
- **100% 오프라인** — 네트워크 없음, 계정 없음, 광고 없음

### 위젯, Siri 및 시스템 연동

- 오늘의 대련 / 명구 / 진행 상황 / 즐겨찾기 위젯(+ 잠금 화면)
- 읽기 **실시간 현황**(선택)
- Spotlight 색인, **`ivirtue://` 딥링크** — [바로가기 링크](url-scheme) 참고
- 설정 내 가이드: 사용법 · 위젯 · 단축어 · 기능 가이드 다시 보기

### 개인정보 보호

- 설치 후 **외부로 나가는 네트워크 요청 없음**(후원을 위한 선택적 Apple StoreKit과 사용자가 선택한 시스템 공유 대상 제외)
- **계정 없음 · 광고 없음 · 분석 SDK 없음**
- 로컬 App Group 데이터 + 선택적 개인 iCloud KVS
