iVirtue prend en charge les liens de raccourci ** `ivirtue://` ** (schéma URL). Les raccourcis de démarrage à froid et d'écran d'accueil sont livrés via un tampon unifié de sorte que les liens ne sont pas ouverts deux fois après l'embarquement.

## Format de lien


```
ivirtue://{host}?{params}
```

## Exemples


```
ivirtue://daily
ivirtue://practice
ivirtue://passage?id=1
ivirtue://recite?id=1
ivirtue://study
ivirtue://hunt
ivirtue://search?q=xiao
```


Utilisez-les dans l'application Raccourcis, Actions rapides Home Screen, Widgets, Control Center ou Safari. Voir aussi dans l'application **Paramètres → Guide des raccourcis**.
