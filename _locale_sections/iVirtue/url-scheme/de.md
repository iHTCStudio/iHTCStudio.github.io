iVirtue unterstützt ** `ivirtue://` ** Shortcut Links (URL-Schema). Kaltstart- und Home Screen-Verknüpfungen werden über einen einheitlichen Puffer geliefert, so dass Links nach dem Onboarding nicht zweimal geöffnet werden.

## Linkformat


```
ivirtue://{host}?{params}
```


## Stanzas & Entdeckung

| URL | Öffnet |
|-----|-------|
| `ivirtue://home` | Startseite |
| `ivirtue://daily` | Die heutige tägliche Regel |
| `ivirtue://practice` | Praxis / Check-in-Eintritt |
| `ivirtue://streak` | Streifen |
| `ivirtue://random` | Zufällige Strophe |
| `ivirtue://passage?id={id}` | Details Stanza |
| `ivirtue://author?id={id}` | Autorendetail |
| `ivirtue://recite` / `ivirtue://recite?id={id}` | Rezitationsablauf |
| `ivirtue://favorites` | Favoriten |
| `ivirtue://famous` | Berühmte Zeilen |
| `ivirtue://search` / `ivirtue://search?q={query}` | Suche |
| `ivirtue://study` | Virtue Klassenzimmer |
| `ivirtue://hunt` | Jagd (寻规) |
| `ivirtue://mastered` | Beherrscht |
| `ivirtue://categories` | Durchsuchen |
| `ivirtue://collection?name=` | Kapitel/Sammlung |
| `ivirtue://theme?id=` | Tugendthema |
| `ivirtue://last-read` | Zuletzt gelesen |
| `ivirtue://reading-history` | Leseverlauf |
| `ivirtue://notes` | Notizen |

## Beispiele


```
ivirtue://daily
ivirtue://practice
ivirtue://passage?id=1
ivirtue://recite?id=1
ivirtue://study
ivirtue://hunt
ivirtue://search?q=xiao
```


Verwenden Sie diese in der Shortcuts-App, den Schnellaktionen für den Startbildschirm, den Widgets, dem Control Center oder Safari. Siehe auch In-App **Settings → Shortcuts Guide**.
