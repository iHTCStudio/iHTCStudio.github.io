iVirtueは** `ivirtue://` **ショートカットリンク(URLスキーム)をサポートしています。 コールドスタートとホーム画面のショートカットは、統一されたバッファを介して配信されますので、リンクはオンボーディング後2回開いていません。

## リンク形式


```
ivirtue://{host}?{params}
```


## スタンザと発見

| URL | 開く画面 |
|-----|-------|
| `ivirtue://home` | ホーム |
| `ivirtue://daily` | 今日の毎日のルール |
| `ivirtue://practice` | 練習・チェックインエントリー |
| `ivirtue://streak` | ストール |
| `ivirtue://random` | ランダムスタンザ |
| `ivirtue://passage?id={id}` | スタンザの詳細 |
| `ivirtue://author?id={id}` | 作者の詳細 |
| `ivirtue://recite` / `ivirtue://recite?id={id}` | 誦読フロー |
| `ivirtue://favorites` | お気に入り |
| `ivirtue://famous` | 名句一覧 |
| `ivirtue://search` / `ivirtue://search?q={query}` | 検索 |
| `ivirtue://study` | Virtue教室 |
| `ivirtue://hunt` | ハント (寻规) |
| `ivirtue://mastered` | マスタード |
| `ivirtue://categories` | ブラウズ |
| `ivirtue://collection?name=` | チャプター/コレクション |
| `ivirtue://theme?id=` | Virtueテーマ |
| `ivirtue://last-read` | 最後に読んだ項目 |
| `ivirtue://reading-history` | 閲覧履歴 |
| `ivirtue://notes` | ノート |

## 例


```
ivirtue://daily
ivirtue://practice
ivirtue://passage?id=1
ivirtue://recite?id=1
ivirtue://study
ivirtue://hunt
ivirtue://search?q=xiao
```


これらをショートカットアプリ、ホーム画面のクイックアクション、ウィジェット、コントロールセンター、またはSafariで使用してください。 アプリ内設定 → ショートカットガイド** も参照してください。
