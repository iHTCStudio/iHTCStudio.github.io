iVirtue는 ** `ivirtue://` ** 단축키 링크 (URL 계획)를 지원합니다. 콜드 시작 및 홈 화면 단축은 통합 버퍼를 통해 전달되므로 링크가 내장 된 후 두 번 열리지 않습니다.

## 링크 형식


```
ivirtue://{host}?{params}
```


## Stanzas & 발견

| URL | 열리는 화면 |
|-----|-------|
| `ivirtue://home` | 홈 |
| `ivirtue://daily` | 오늘의 규칙 |
| `ivirtue://practice` | 연습 / 체크인 |
| `ivirtue://streak` | 사이트맵 |
| `ivirtue://random` | 무작위 stanza |
| `ivirtue://passage?id={id}` | Stanza 세부사항 |
| `ivirtue://author?id={id}` | 작가 상세 |
| `ivirtue://recite` / `ivirtue://recite?id={id}` | 낭독 흐름 |
| `ivirtue://favorites` | 즐겨찾기 |
| `ivirtue://famous` | 명구 목록 |
| `ivirtue://search` / `ivirtue://search?q={query}` | 검색 |
| `ivirtue://study` | Virtue 교실 |
| `ivirtue://hunt` | Hunt ()) |
| `ivirtue://mastered` | 인기있는 |
| `ivirtue://categories` | 둘러보기 |
| `ivirtue://collection?name=` | 장 / 수집 |
| `ivirtue://theme?id=` | Virtue 테마 |
| `ivirtue://last-read` | 마지막으로 읽은 항목 |
| `ivirtue://reading-history` | 읽기 기록 |
| `ivirtue://notes` | 메모 |

| URL | 열리는 화면 |
|-----|-------|
| `ivirtue://settings` | 설정 |
| `ivirtue://daily-settings` | 일일 규칙 설정 |
| `ivirtue://home-shortcuts` | 홈 화면 빠른 작업 |
| `ivirtue://usage-guide` | 사용 가이드 |
| `ivirtue://widget-guide` | 위젯 가이드 |
| `ivirtue://shortcuts-guide` | 단축어 가이드 |
| `ivirtue://feature-guide` | 온보딩 다시 보기 |
| `ivirtue://tip` | 팁 개발자 |
| `ivirtue://feedback` | 피드백 이메일 |
| `ivirtue://in-app-review` | 앱 내 / App Store 리뷰 |
| `ivirtue://privacy` | In-app 프라이버시 |

## 예시


```
ivirtue://daily
ivirtue://practice
ivirtue://passage?id=1
ivirtue://recite?id=1
ivirtue://study
ivirtue://hunt
ivirtue://search?q=xiao
```


Shortcuts 앱에서 이러한 사용, 홈 화면 빠른 행동, 위젯, 제어 센터, 또는 사파리. in-app**Settings → 단축키 가이드** 참조.
