ivirtus รองรับ ** BAR `ivirtue://` BAR * ลิงก์ลัด (RUL scheme) การเริ่มหน้าจอหน้าจอเย็นและหน้าจอบ้าน จะถูกส่งไปผ่านระบบบัฟเฟอร์แบบรวม ดังนั้นลิงก์จึงไม่ถูกเปิดสองครั้งหลังจากขึ้นเครื่อง

## รูปแบบลิงก์


```
ivirtue://{host}?{params}
```


## การค้นพบ Stanzas

| URL | เปิด |
|-----|-------|
| `ivirtue://home` | หน้าแรก |
| `ivirtue://daily` | กฎ ใน ปัจจุบัน |
| `ivirtue://practice` | ฝึก / ตรวจสอบข้อมูล |
| `ivirtue://streak` | สไตรก |
| `ivirtue://random` | หมุน & 90 |
| `ivirtue://passage?id={id}` | รายละเอียด Stanza |
| `ivirtue://author?id={id}` | รายละเอียดผู้แต่ง |
| `ivirtue://recite` / `ivirtue://recite?id={id}` | โฟลว์การท่อง |
| `ivirtue://favorites` | รายการโปรด |
| `ivirtue://famous` | บรรทัดขึ้นชื่อ |
| `ivirtue://search` / `ivirtue://search?q={query}` | ค้นหา |
| `ivirtue://study` | ห้องเรียนคุณธรรม |
| `ivirtue://hunt` | ล่า (寻规) |
| `ivirtue://mastered` | สําเร็จการศึกษาแล้ว |
| `ivirtue://categories` | เรียกดู |
| `ivirtue://collection?name=` | บท / ชุดสะสม |
| `ivirtue://theme?id=` | ชุดตกแต่งคุณธรรม |
| `ivirtue://last-read` | รายการที่อ่านล่าสุด |
| `ivirtue://reading-history` | ประวัติการอ่าน |
| `ivirtue://notes` | บันทึก |

## การตั้งค่าและคู่มือ

| URL | เปิด |
|-----|-------|
| `ivirtue://settings` | การตั้งค่า |
| `ivirtue://daily-settings` | ตั้งค่ากฎประจําวัน |
| `ivirtue://home-shortcuts` | การกระทํากับหน้าจอส่วนตัวอย่างรวดเร็ว |
| `ivirtue://usage-guide` | คู่มือการใช้งาน |
| `ivirtue://widget-guide` | คู่มือวิดเจ็ต |
| `ivirtue://shortcuts-guide` | คู่มือทางลัด |
| `ivirtue://feature-guide` | เล่นทัวร์แนะนำอีกครั้ง |
| `ivirtue://tip` | ผู้พัฒนาข้อความ |
| `ivirtue://feedback` | อีเมลข้อเสนอแนะ |
| `ivirtue://in-app-review` | รีวิวในแอป / App Store |
| `ivirtue://privacy` | ความเป็นส่วนตัว |

## ตัวอย่าง


```
ivirtue://daily
ivirtue://practice
ivirtue://passage?id=1
ivirtue://recite?id=1
ivirtue://study
ivirtue://hunt
ivirtue://search?q=xiao
```


ใช้เหล่านี้ในโปรแกรมปุ่มพิมพ์ลัด, การกระทําของหน้าจอส่วนตัวอย่างรวดเร็ว, วิดเจ็ต, ศูนย์ควบคุม, หรือซาฟารี ดูใน-apps ด้วย
