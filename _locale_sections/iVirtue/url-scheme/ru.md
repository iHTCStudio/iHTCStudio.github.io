iVirtue поддерживает ярлыки ** `ivirtue://` ** (схема URL). Холодный старт и ярлыки домашнего экрана доставляются через единый буфер, поэтому ссылки не открываются дважды после входа.

## Формат ссылки


```
ivirtue://{host}?{params}
```


## Станца и открытие

| URL | Открывает |
|-----|-------|
| `ivirtue://home` | Главная |
| `ivirtue://daily` | Сегодняшнее ежедневное правило |
| `ivirtue://practice` | Практика / регистрация входа |
| `ivirtue://streak` | полоса |
| `ivirtue://random` | Случайная строфа |
| `ivirtue://passage?id={id}` | Детали Станца |
| `ivirtue://author?id={id}` | Страница автора |
| `ivirtue://recite` / `ivirtue://recite?id={id}` | Режим чтения вслух |
| `ivirtue://favorites` | Избранное |
| `ivirtue://famous` | Знаменитые строки |
| `ivirtue://search` / `ivirtue://search?q={query}` | Поиск |
| `ivirtue://study` | Класс добродетели |
| `ivirtue://hunt` | Охота ()) |
| `ivirtue://mastered` | мастеринг |
| `ivirtue://categories` | Обзор |
| `ivirtue://collection?name=` | Глава / Коллекция |
| `ivirtue://theme?id=` | Тема добродетели |
| `ivirtue://last-read` | Последнее прочитанное |
| `ivirtue://reading-history` | История чтения |
| `ivirtue://notes` | Заметки |

## Настройки и руководства

| URL | Открывает |
|-----|-------|
| `ivirtue://settings` | Настройки |
| `ivirtue://daily-settings` | Ежедневные настройки Правил |
| `ivirtue://home-shortcuts` | Домой Экран Быстрые действия |
| `ivirtue://usage-guide` | Руководство по использованию |
| `ivirtue://widget-guide` | Руководство по виджетам |
| `ivirtue://shortcuts-guide` | Руководство по «Командам» |
| `ivirtue://feature-guide` | Повторное знакомство |
| `ivirtue://tip` | Разработчик Tip |
| `ivirtue://feedback` | Письмо с отзывом |
| `ivirtue://in-app-review` | Отзыв в приложении / App Store |
| `ivirtue://privacy` | Приватность в приложении |

## Примеры


```
ivirtue://daily
ivirtue://practice
ivirtue://passage?id=1
ivirtue://recite?id=1
ivirtue://study
ivirtue://hunt
ivirtue://search?q=xiao
```


Используйте их в приложении Shortcuts, быстрых действиях Home Screen, виджетах, Центре управления или Safari. См. также in-app **Settings → Shortcuts Guide**.
