iVirtue ** `ivirtue://` ** kısayol bağlantıları (URL planı). Soğuk başlangıç ve Ev Ekran kısayolları birleşik bir tampon aracılığıyla teslim edilir, bu yüzden bağlantılar gemiden sonra iki kez açılmaz.

## Bağlantı biçimi


```
ivirtue://{host}?{params}
```


## Stanzas & keşif

| URL | Açar |
|-----|-------|
| `ivirtue://home` | Ana sayfa |
| `ivirtue://daily` | Bugünün Günlük Kuralları |
| `ivirtue://practice` | Uygulama / check-in giriş |
| `ivirtue://streak` | Streak |
| `ivirtue://random` | Random stanza |
| `ivirtue://passage?id={id}` | Stanza detayı |
| `ivirtue://author?id={id}` | Yazar ayrıntısı |
| `ivirtue://recite` / `ivirtue://recite?id={id}` | Okuma akışı |
| `ivirtue://favorites` | Favoriler |
| `ivirtue://famous` | Ünlü dizeler |
| `ivirtue://search` / `ivirtue://search?q={query}` | Ara |
| `ivirtue://study` | Virtue sınıfı |
| `ivirtue://hunt` | Hunt ( Hunt) |
| `ivirtue://mastered` | Mastered |
| `ivirtue://categories` | Gözat |
| `ivirtue://collection?name=` | Bölüm / koleksiyon |
| `ivirtue://theme?id=` | Virtue tema |
| `ivirtue://last-read` | Son okunan |
| `ivirtue://reading-history` | Okuma geçmişi |
| `ivirtue://notes` | Notlar |

| URL | Açar |
|-----|-------|
| `ivirtue://settings` | Ayarlar |
| `ivirtue://daily-settings` | Günlük Kural ayarları |
| `ivirtue://home-shortcuts` | Home Ekran hızlı eylemleri |
| `ivirtue://usage-guide` | Kullanım kılavuzu |
| `ivirtue://widget-guide` | Widget kılavuzu |
| `ivirtue://shortcuts-guide` | Kısayol kılavuzu |
| `ivirtue://feature-guide` | Tanıtımı yeniden oynat |
| `ivirtue://tip` | İpucu Geliştirici |
| `ivirtue://feedback` | Geri bildirim e-postası |
| `ivirtue://in-app-review` | Uygulama içi / App Store değerlendirme |
| `ivirtue://privacy` | In-app gizlilik |

## Örnekler


```
ivirtue://daily
ivirtue://practice
ivirtue://passage?id=1
ivirtue://recite?id=1
ivirtue://study
ivirtue://hunt
ivirtue://search?q=xiao
```


Bunları kısa kesimlerde kullanın, Home Ekran hızlı eylemleri, widgets, Control Center veya Safari. Ayrıca bakınız **Settings → Kısayollar Kılavuzu**.
