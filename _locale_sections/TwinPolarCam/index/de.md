TwinPolarCam (太极双摄) ist eine **datenschutzorientierte Dual-Kamera-Aufnahme-App** für **iPhone und iPad**. Sie nimmt **Front- und Rückkamera gleichzeitig** auf, **setzt Hauptbild + Picture-in-Picture (PiP)** zusammen und speichert in Fotos — **100 % auf dem Gerät, kein Konto, kein Cloud-Upload**.

**Auf einen Blick:** Dual-Kamera-Aufnahme · verschiebbares PiP · Pause/Fortsetzen · serielle **Export-Warteschlange** · Listen-/Raster-Pending-Manager · **Live-Aktivität (iOS 16.2+)** · wiederherstellbare Unterbrechungen · Notfall-Speicherung im Hintergrund · In-App-Anleitungen · Trinkglas · Englisch / 简体中文 / 繁體中文 · `twinpolarcam://`-Deep-Links.

## Erste Schritte

1. Öffnen Sie TwinPolarCam auf einem **Multi-Cam-fähigen** Gerät (typisch iPhone XS/XR oder neuer; kompatible iPad-Pro-Modelle).
2. Erteilen Sie Kamera / Mikrofon / Fotos-Berechtigungen, wenn Sie dazu aufgefordert werden (schrittweise Autorisierung).
3. Stellen Sie Hauptkamera / PiP / Audio ein und tippen Sie auf **Aufnahme**.
4. Stoppen Sie, um den Export einzureihen; verwalten Sie ausstehende Jobs in der **Pending**-Liste (Liste oder Raster).
5. Optional: **Live-Aktivität** aktivieren, In-App-**Anleitungen** öffnen oder Home-Bildschirm-Kurzaktionen / `twinpolarcam://` nutzen.
