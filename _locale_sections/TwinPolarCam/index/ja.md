TwinPolarCam（太极双摄）は、**iPhone と iPad** 向けの**プライバシー優先のデュアルカメラ録画アプリ**です。**前面と背面カメラを同時に**撮影し、**メイン画面 + ピクチャ・イン・ピクチャ（PiP）**を合成して写真に保存します — **端末内 100 %、アカウント不要、クラウドアップロードなし**。

**一覧：** デュアルカメラ撮影 · ドラッグ可能な PiP · 一時停止/再開 · 直列**エクスポートキュー** · リスト/グリッドの Pending 管理 · **Live Activity（iOS 16.2+）** · 復旧可能な中断 · バックグラウンド緊急保存 · アプリ内ガイド · チップ · English / 简体中文 / 繁體中文 · `twinpolarcam://` ディープリンク。

## はじめに

1. **マルチカメラ対応**端末で TwinPolarCam を開きます（一般的に iPhone XS/XR 以降、対応 iPad Pro など）。
2. 求められたらカメラ / マイク / 写真の権限を付与します（段階的な許可）。
3. メインカメラ / PiP / オーディオを調整し、**録画**をタップします。
4. 停止するとエクスポートキューに入ります。**Pending** リスト（リストまたはグリッド）で待機ジョブを管理します。
5. 任意：**Live Activity** を有効化、アプリ内**ガイド**を開く、ホーム画面ショートカット / `twinpolarcam://` を使用。

> **完全なステップガイド：** 要件、操作、PiP、信頼性、エクスポート、設定、トラブルシューティングの全セクションは [**FAQ / ユーザーガイド**](faq) にあります。
