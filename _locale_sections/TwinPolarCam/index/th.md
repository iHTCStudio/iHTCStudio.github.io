TwinPolarCam (太极双摄) คือแอป**บันทึกกล้องคู่ที่ให้ความสำคัญกับความเป็นส่วนตัว**สำหรับ **iPhone และ iPad** จับภาพ**กล้องหน้าและหลังพร้อมกัน** จากนั้น**ผสานมุมมองหลัก + Picture-in-Picture (PiP)** แล้วบันทึกลงรูปภาพ — **100% บนอุปกรณ์ ไม่ต้องมีบัญชี ไม่อัปโหลดคลาวด์**

**สรุป:** ถ่ายกล้องคู่ · PiP ลากได้ · หยุดชั่วคราว/ทำต่อ · **คิวส่งออก**แบบเรียง · จัดการ Pending แบบรายการ/ตาราง · **Live Activity (iOS 16.2+)** · กู้คืนเมื่อขัดจังหวะ · บันทึกฉุกเฉินในพื้นหลัง · คู่มือในแอป · ทิป · English / 简体中文 / 繁體中文 · ดีปลิงก์ `twinpolarcam://`

## เริ่มต้นใช้งาน

1. เปิด TwinPolarCam บนอุปกรณ์ที่**รองรับ multi-cam** (โดยทั่วไป iPhone XS/XR ขึ้นไป และ iPad Pro ที่รองรับ)
2. อนุญาตกล้อง / ไมโครโฟน / รูปภาพเมื่อระบบถาม (อนุญาตทีละขั้น)
3. ปรับกล้องหลัก / PiP / เสียง แล้วแตะ **บันทึก**
4. หยุดเพื่อเข้าคิวส่งออก จัดการงานค้างในรายการ **Pending** (รายการหรือตาราง)
5. ทางเลือก: เปิด **Live Activity** เปิด**คู่มือ**ในแอป หรือใช้ทางลัดหน้าโฮม / `twinpolarcam://`
