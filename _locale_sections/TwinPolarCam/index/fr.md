TwinPolarCam (太极双摄) est une **application d’enregistrement double caméra axée sur la confidentialité** pour **iPhone et iPad**. Elle capture **les caméras avant et arrière simultanément**, puis **compose la vue principale + Picture-in-Picture (PiP)** et enregistre dans Photos — **100 % sur l’appareil, sans compte, sans envoi cloud**.

**En bref :** capture double caméra · PiP déplaçable · pause/reprise · **file d’export** séquentielle · gestion Pending en liste/grille · **Live Activity (iOS 16.2+)** · interruptions récupérables · sauvegarde d’urgence en arrière-plan · guides intégrés · pourboire · anglais / 简体中文 / 繁體中文 · liens profonds `twinpolarcam://`.

## Premiers pas

1. Ouvrez TwinPolarCam sur un appareil **compatible multi-cam** (souvent iPhone XS/XR ou ultérieur ; iPad Pro compatibles).
2. Accordez les autorisations caméra / micro / Photos lorsque demandé (autorisation progressive).
3. Réglez caméra principale / PiP / audio, puis touchez **Enregistrer**.
4. Arrêtez pour mettre en file d’export ; gérez les tâches en attente dans **Pending** (liste ou grille).
5. Facultatif : activer la **Live Activity**, ouvrir les **guides** intégrés, ou utiliser les raccourcis de l’écran d’accueil / `twinpolarcam://`.
