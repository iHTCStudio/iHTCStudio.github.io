iHTC Studio(「당사」)는 iPhone용 TwinPolarCam(「太极双摄」/「太極雙攝」)을 제공합니다. 이 페이지는 앱 사용 시 데이터 수집·이용·공개 정책을 설명합니다.

## 요약

**TwinPolarCam은 개인 데이터를 수집·저장·전송하지 않습니다.** 모든 동영상 녹화와 처리는 기기에서만 이루어집니다. 계정 불필요, 인터넷 불필요.

## 데이터 수집

데이터를 수집하지 않습니다.

- **개인정보 없음**(이름, 이메일, 전화, 계정).
- **사용 데이터·분석 없음**.
- **광고·분석·크래시용 서드파티 SDK 없음**.
- **쿠키·추적 없음**.
- **업로드 없음**. 공유하기 전까지 동영상은 기기에만 있습니다.

## 기기에 저장되는 데이터

| 데이터 | 저장 | 사용자 제어 |
|------|---------|-----------|
| 녹화 세그먼트 | 앱 샌드박스(임시) | 내보내기 후 자동 정리 또는 앱 삭제 |
| 내보낸 동영상 | 사진 보관함 | 사진 앱에서 삭제 |
| 앱 설정 | 로컬(UserDefaults) | 앱 삭제 |
| 크래시 복구 세그먼트 | 샌드박스 | 다음 실행 시 내보내기 제안 또는 앱 삭제 |
| 내보내기 대기열 | 샌드박스 | Pending Exports에서 관리 |

## 권한

| 권한 | 목적 |
|------------|---------|
| 카메라 | 전·후면 동시 녹화 |
| 마이크 | 동영상과 함께 오디오 |
| 사진(쓰기) | 내보낸 동영상 저장 |

최초 사용 시에만 녹화·저장 목적으로 요청하며, 데이터는 기기 밖으로 나가지 않습니다.
