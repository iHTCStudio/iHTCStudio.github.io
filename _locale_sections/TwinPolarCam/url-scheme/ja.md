TwinPolarCamは、** `twinpolarcam://` **のショートカットリンクをサポートしています。 **Safariブックマーク**、**ショートカット**アプリ、または**ホーム画面のクイックアクション**および**Spotlight**でガイドやキー画面に直接ジャンプできます。

## リンク形式


```
twinpolarcam://{host}
```


ルーティングは**ホスト名だけ**(ケースインセンティブ)です。

---

## ガイド

| URL | 開く画面 |
|-----|-------|
| `twinpolarcam://usage-guide` | **利用方法**ガイドシート |
| `twinpolarcam://recording-guide` | **録画と信頼性**ガイドシート |
| `twinpolarcam://export-guide` | **輸出入**ガイドシート |
| `twinpolarcam://feature-guide` | **特集ツアー**(6ページオンボーディングリプレイ) |

* App Settings → Help** と同じ宛先。

---

## アプリ画面

| URL | 開く画面 |
|-----|-------|
| `twinpolarcam://settings` | アプリ設定パネル |
| `twinpolarcam://pending` | ペンディング・エクスポート・マネージャー |
| `twinpolarcam://feedback` | フィードバックを送信する(メールコンポーザー) |
| `twinpolarcam://recording` | 主なアプリ(ライブアクティビティ/ダイナミックアイランドリターン) |

---

## ホーム スクリーンのクイックアクション

**TwinPolarCamアイコンを長押し** — 4つの固定ショートカット(上記と同じホスト):

| Quick action | サイトマップ |
|--------------|-----|
| Usage Guide | `twinpolarcam://usage-guide` |
| Recording Tips | `twinpolarcam://recording-guide` |
| Export Guide | `twinpolarcam://export-guide` |
| Feature Tour | `twinpolarcam://feature-guide` |

クイックアクションは、**cold launch**とアプリが既に実行されている場合に動作します。 まだオンボーディングが完了していない場合、リンクは**queued**で、ウェルカムガイドを終了した後に配信されます。

## ノート

- **Unsupported devices** can still open guide links from the unsupported screen — 払い戻しの前に条件を読むために有用。
- 未知のホストは、安全に無視されます**(クラッシュなし)。
- ガイドは、メインUIを準備する必要があります。初期化が完了するまで、コールドスタートURLがバッファされます。
