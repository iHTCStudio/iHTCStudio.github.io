## รูปแบบลิงก์


```
twinpolarcam://{host}
```


ไม่มีพาธหรือส่วนประกอบการสืบค้น — การออกเสียงเป็นชื่อเครื่องเท่านั้น* (ทั้งกรณีไม่อ่อนไหว).

## จุด

TwinPollarCam indexs guides pages in ~Spotlight~. ค้นหา:

- แฝดโพลาร์แคม
- คําแนะนําการใช้งาน / การบันทึกความจุ/ ส่งออก & การท่องเที่ยวแบบธรรมชาติ

การเคาะผลเปิดแผ่นคู่มือที่เข้าคู่กัน

## บันทึก

- **Unsupported devices** can still open guide links from the unsupported screen — ใช้สําหรับการอ่านความต้องการ ก่อนที่จะทําการคืนค่า
- โฮสต์ไม่ทราบชื่อถูกปรับให้ปลอดภัย
- ไกด์ต้องการตัวหลักของ UI ให้พร้อม ที่อยู่ URL เริ่มต้นแบบเย็นจะถูกบัฟเฟอร์จนเสร็จสิ้น
