iNutrition は **`inutrition://`** ショートカットリンクに対応しています。

## リンク形式


```
inutrition://{host}/{id}
inutrition://{host}
```


## コンテンツディープリンク

| URL | 開く画面 |
|-----|-------|
| `inutrition://food/{id}` | 食品の詳細 |
| `inutrition://nutrient/{id}` | 栄養素百科の項目 |
| `inutrition://article/{id}` | ナレッジ記事 |

## ナビゲーション

| URL | 開く画面 |
|-----|-------|
| `inutrition://home` | ホーム |
| `inutrition://search` | 検索 |
| `inutrition://favorites` | お気に入り |
| `inutrition://settings` | 設定 |
| `inutrition://labelreader` | AI ラベルリーダー（iOS 26+） |

## ツール

| URL | 開く画面 |
|-----|-------|
| `inutrition://tool/bmi` | BMI 計算機 |
| `inutrition://tool/bmr` | BMR 計算機 |
| `inutrition://tool/tdee` | TDEE 計算機 |
| `inutrition://tool` | ツール一覧 |
