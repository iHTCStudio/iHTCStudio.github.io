iNutrition, **`inutrition://`** kısayol bağlantılarını destekler.

## Bağlantı biçimi


```
inutrition://{host}/{id}
inutrition://{host}
```


## Derin bağlantılar

| URL | Açar |
|-----|-------|
| `inutrition://food/{id}` | Yiyecek ayrıntısı |
| `inutrition://nutrient/{id}` | Besin ansiklopedisi kaydı |
| `inutrition://article/{id}` | Bilgi makalesi |

## Navigation

| URL | Açar |
|-----|-------|
| `inutrition://home` | Ana sayfa |
| `inutrition://search` | Ara |
| `inutrition://favorites` | Favoriler |
| `inutrition://settings` | Ayarlar |
| `inutrition://labelreader` | AI Label Reader (iOS 26+) |

## Araçlar

| URL | Açar |
|-----|-------|
| `inutrition://tool/bmi` | BMI hesaplayıcı |
| `inutrition://tool/bmr` | BMR hesaplayıcı |
| `inutrition://tool/tdee` | TDEE hesaplayıcı |
| `inutrition://tool` | Tüm araçlar listesi |
