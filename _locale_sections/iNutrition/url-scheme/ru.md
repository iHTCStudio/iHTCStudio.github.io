iNutrition поддерживает **`inutrition://`** — ссылки-ярлыки.

## Формат ссылки


```
inutrition://{host}/{id}
inutrition://{host}
```


## Глубокие ссылки

| URL | Открывает |
|-----|-------|
| `inutrition://food/{id}` | Страница продукта |
| `inutrition://nutrient/{id}` | Статья энциклопедии нутриентов |
| `inutrition://article/{id}` | Обучающая статья |

## Навигация

| URL | Открывает |
|-----|-------|
| `inutrition://home` | Главная |
| `inutrition://search` | Поиск |
| `inutrition://favorites` | Избранное |
| `inutrition://settings` | Настройки |
| `inutrition://labelreader` | AI Label Reader (iOS 26+) |

## Инструменты

| URL | Открывает |
|-----|-------|
| `inutrition://tool/bmi` | Калькулятор ИМТ |
| `inutrition://tool/bmr` | Калькулятор BMR |
| `inutrition://tool/tdee` | Калькулятор TDEE |
| `inutrition://tool` | Список всех инструментов |
