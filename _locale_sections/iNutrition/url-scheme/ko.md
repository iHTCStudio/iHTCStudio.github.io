iNutrition는 **`inutrition://`** 바로가기 링크를 지원합니다.

## 링크 형식


```
inutrition://{host}/{id}
inutrition://{host}
```


## 내용 깊은 링크

| URL | 열리는 화면 |
|-----|-------|
| `inutrition://food/{id}` | 음식 상세 |
| `inutrition://nutrient/{id}` | 영양소 백과 항목 |
| `inutrition://article/{id}` | 지식 아티클 |

## - 연혁

| URL | 열리는 화면 |
|-----|-------|
| `inutrition://home` | 홈 |
| `inutrition://search` | 검색 |
| `inutrition://favorites` | 즐겨찾기 |
| `inutrition://settings` | 설정 |
| `inutrition://labelreader` | AI 라벨 리더(iOS 26+) |

## 회사 소개

| URL | 열리는 화면 |
|-----|-------|
| `inutrition://tool/bmi` | BMI 계산기 |
| `inutrition://tool/bmr` | BMR 계산기 |
| `inutrition://tool/tdee` | TDEE 계산기 |
| `inutrition://tool` | 모든 도구 목록 |
