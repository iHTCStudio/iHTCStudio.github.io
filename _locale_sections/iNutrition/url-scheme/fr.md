iNutrition prend en charge les liens **`inutrition://`**.

## Format de lien


```
inutrition://{host}/{id}
inutrition://{host}
```


## Liens profonds

| URL | Ouvre |
|-----|-------|
| `inutrition://food/{id}` | Détail de l’aliment |
| `inutrition://nutrient/{id}` | Entrée encyclopédique nutriment |
| `inutrition://article/{id}` | Article de connaissances |

## Navigation

| URL | Ouvre |
|-----|-------|
| `inutrition://home` | Accueil |
| `inutrition://search` | Recherche |
| `inutrition://favorites` | Favoris |
| `inutrition://settings` | Réglages |
| `inutrition://labelreader` | AI Label Reader (iOS 26+) |

## Outils

| URL | Ouvre |
|-----|-------|
| `inutrition://tool/bmi` | Calculateur IMC |
| `inutrition://tool/bmr` | Calculateur BMR |
| `inutrition://tool/tdee` | Calculateur TDEE |
| `inutrition://tool` | Liste de tous les outils |
