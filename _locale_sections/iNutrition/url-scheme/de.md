iNutrition unterstützt **`inutrition://`**-Verknüpfungslinks.

## Linkformat


```
inutrition://{host}/{id}
inutrition://{host}
```


## Content Deep Links

| URL | Öffnet |
|-----|-------|
| `inutrition://food/{id}` | Lebensmitteldetail |
| `inutrition://nutrient/{id}` | Nährstoff-Lexikoneintrag |
| `inutrition://article/{id}` | Wissensartikel |

## Navigation

| URL | Öffnet |
|-----|-------|
| `inutrition://home` | Startseite |
| `inutrition://search` | Suche |
| `inutrition://favorites` | Favoriten |
| `inutrition://settings` | Einstellungen |
| `inutrition://labelreader` | AI Label Reader (iOS 26+) |

## Werkzeuge

| URL | Öffnet |
|-----|-------|
| `inutrition://tool/bmi` | BMI-Rechner |
| `inutrition://tool/bmr` | BMR-Rechner |
| `inutrition://tool/tdee` | TDEE-Rechner |
| `inutrition://tool` | Liste aller Tools |
