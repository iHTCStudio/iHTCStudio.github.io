iNutrition รองรับลิงก์ทางลัด **`inutrition://`**

## รูปแบบลิงก์


```
inutrition://{host}/{id}
inutrition://{host}
```


## เนื้อหาที่อยู่เชื่อมโยงแบบลึก

| URL | เปิด |
|-----|-------|
| `inutrition://food/{id}` | รายละเอียดอาหาร |
| `inutrition://nutrient/{id}` | รายการสารานุกรมสารอาหาร |
| `inutrition://article/{id}` | บทความความรู้ |

## การนําทาง

| URL | เปิด |
|-----|-------|
| `inutrition://home` | หน้าแรก |
| `inutrition://search` | ค้นหา |
| `inutrition://favorites` | รายการโปรด |
| `inutrition://settings` | การตั้งค่า |
| `inutrition://labelreader` | AI Label Reader (iOS 26+) |

## เครื่องมือ

| URL | เปิด |
|-----|-------|
| `inutrition://tool/bmi` | เครื่องคำนวณ BMI |
| `inutrition://tool/bmr` | เครื่องคำนวณ BMR |
| `inutrition://tool/tdee` | เครื่องคำนวณ TDEE |
| `inutrition://tool` | รายการเครื่องมือทั้งหมด |
