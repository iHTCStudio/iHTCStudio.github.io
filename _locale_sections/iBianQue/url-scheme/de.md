爱扁鹊 / iBianQue unterstützt ** `ibianque://` ** Shortcut Links (URL-Schema). Kaltstart- und Home Screen-Verknüpfungen werden über einen einheitlichen Puffer geliefert, so dass Links nach dem Onboarding nicht zweimal geöffnet werden.

## Linkformat


```
ibianque://{host}?{params}
```


## Einzigartiger Schreibtisch

| URL | Öffnet |
|-----|-------|
| `ibianque://daily` | Tägliche Kunst |
| `ibianque://atlas` / `ibianque://meridian` | Meridianatlas |
| `ibianque://point?code=` | Sprung zu einem Acupoint-Code |
| `ibianque://quiz` | Spielerisches Verfassungsquiz |
| `ibianque://tongue` | Farbskizze auf dem Gerät |
| `ibianque://nanjing` | Nan Jing Regal |
| `ibianque://study` | Que-Studie |
| `ibianque://hunt` | Punktjagd |
| `ibianque://fables` | Lore |
| `ibianque://concepts` | Konzepte |
