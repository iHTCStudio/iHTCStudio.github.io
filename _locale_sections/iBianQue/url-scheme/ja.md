爱扁鹊 / iBianQue は、** `ibianque://` ** ショートカットリンク(URLスキーム)をサポートしています。 コールドスタートとホーム画面のショートカットは、統一されたバッファを介して配信されますので、リンクはオンボーディング後2回開いていません。

## リンク形式


```
ibianque://{host}?{params}
```


## ユニークなデスク

| URL | 開く画面 |
|-----|-------|
| `ibianque://daily` | デイリーアート |
| `ibianque://atlas` / `ibianque://meridian` | メリディアン・アトラス |
| `ibianque://point?code=` | アクポイントコードへのジャンプ |
| `ibianque://quiz` | 遊び心のある憲法クイズ |
| `ibianque://tongue` | オンデバイス舌カラースケッチ |
| `ibianque://nanjing` | 南京棚 |
| `ibianque://study` | キュー・スタディ |
| `ibianque://hunt` | ポイントハント |
| `ibianque://fables` | ログイン |
| `ibianque://concepts` | コンセプト |

## 例


```

ibianque://atlas
ibianque://passage?id=1
ibianque://study
```
