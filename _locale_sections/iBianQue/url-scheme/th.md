爱扁鹊 / iBian Quee รองรับ... `ibianque://` * ลิงก์ลัด (URL scheme) การเริ่มหน้าจอหน้าจอเย็นและหน้าจอบ้าน จะถูกส่งไปผ่านระบบบัฟเฟอร์แบบรวม ดังนั้นลิงก์จึงไม่ถูกเปิดสองครั้งหลังจากขึ้นเครื่อง

## รูปแบบลิงก์


```
ibianque://{host}?{params}
```


## โต๊ะยูนิโค้ด

| URL | เปิด |
|-----|-------|
| `ibianque://daily` | ศิลปะประจําวัน |
| `ibianque://atlas` / `ibianque://meridian` | เม ริ เดีย น แอ ตลาส |
| `ibianque://point?code=` | กระโดดไปที่รหัส |
| `ibianque://quiz` | ข้อสอบรัฐธรรมนูญการเล่น |
| `ibianque://tongue` | ภาพร่างลิ้นแบบใช้ร่วม: |
| `ibianque://nanjing` | ชั้นวางของนันจิง |
| `ibianque://study` | การ ศึกษา พระ คัมภีร์ |
| `ibianque://hunt` | จุดล่า |
| `ibianque://fables` | บันทึกการทํางาน |
| `ibianque://concepts` | จับภาพ |
