short / iBianQue 지원 ** `ibianque://` ** 단축 링크 (URL 계획). 콜드 시작 및 홈 화면 단축은 통합 버퍼를 통해 전달되므로 링크가 내장 된 후 두 번 열리지 않습니다.

## 링크 형식


```
ibianque://{host}?{params}
```


## 회사 소개

| URL | 열리는 화면 |
|-----|-------|
| `ibianque://daily` | 매일 예술 |
| `ibianque://atlas` / `ibianque://meridian` | 메리디안 atlas |
| `ibianque://point?code=` | acupoint 코드로 점프 |
| `ibianque://quiz` | Playful 헌법 퀴즈 |
| `ibianque://tongue` | On-device 혀 색상 스케치 |
| `ibianque://nanjing` | Nan Jing 선반 |
| `ibianque://study` | 공부하기 |
| `ibianque://hunt` | 포인트 헌트 |
| `ibianque://fables` | 뚱 베어 |
| `ibianque://concepts` | 회사 소개 |
