). / iBianQue, ** `ibianque://` ** kısayol bağlantıları (URL planı). Soğuk başlangıç ve Ev Ekran kısayolları birleşik bir tampon aracılığıyla teslim edilir, bu yüzden bağlantılar gemiden sonra iki kez açılmaz.

## Bağlantı biçimi


```
ibianque://{host}?{params}
```


## Benzersiz masası

| URL | Açar |
|-----|-------|
| `ibianque://daily` | Günlük Sanat |
| `ibianque://atlas` / `ibianque://meridian` | Meridian atlas |
| `ibianque://point?code=` | Bir acupoint koduna atlamak |
| `ibianque://quiz` | Playful anayasa testleri |
| `ibianque://tongue` | In-device dil rengi çizer |
| `ibianque://nanjing` | Nan Jing raf |
| `ibianque://study` | Que Çalışması |
| `ibianque://hunt` | Point Hunt |
| `ibianque://fables` | Lore |
| `ibianque://concepts` | Kavramlar |
