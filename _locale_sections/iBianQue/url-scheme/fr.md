Le logiciel iBianQue prend en charge les liens de raccourci ** `ibianque://` ** (système URL). Les raccourcis de démarrage à froid et d'écran d'accueil sont livrés via un tampon unifié de sorte que les liens ne sont pas ouverts deux fois après l'embarquement.

## Format de lien


```
ibianque://{host}?{params}
```


## Bureau unique

| URL | Ouvre |
|-----|-------|
| `ibianque://daily` | Art quotidien |
| `ibianque://atlas` / `ibianque://meridian` | Atlas méridien |
| `ibianque://point?code=` | Aller à un code acupoint |
| `ibianque://quiz` | Quiz de constitution ludique |
| `ibianque://tongue` | Esquisse couleur langue sur l'appareil |
| `ibianque://nanjing` | Étagère Nan Jing |
| `ibianque://study` | Étude de la question |
| `ibianque://hunt` | Chasse à la pointe |
| `ibianque://fables` | Leurre |
| `ibianque://concepts` | Concepts |

