). / iBianQue поддерживает ярлыки ** `ibianque://` ** (схема URL). Холодный старт и ярлыки домашнего экрана доставляются через единый буфер, поэтому ссылки не открываются дважды после входа.

## Формат ссылки


```
ibianque://{host}?{params}
```


## Уникальный стол

| URL | Открывает |
|-----|-------|
| `ibianque://daily` | Ежедневное искусство |
| `ibianque://atlas` / `ibianque://meridian` | Атлас меридианов |
| `ibianque://point?code=` | Перейти к коду acupoint |
| `ibianque://quiz` | Викторина игривая конституция |
| `ibianque://tongue` | Цветной эскиз языка на устройстве |
| `ibianque://nanjing` | Полка Нэн Цзин |
| `ibianque://study` | Que Study |
| `ibianque://hunt` | Пойнт Хант |
| `ibianque://fables` | Лора |
| `ibianque://concepts` | Концепции |
