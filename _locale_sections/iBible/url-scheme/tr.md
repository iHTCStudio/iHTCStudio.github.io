iBible, ** `ibible://` ** Kısa kesimler, widgets, Siri ve Home Ekran eylemleri için kısa bağlantılar.

## Bağlantı biçimi


```
ibible://{host}?{params}
```


## Daily & reading

| URL | Açar |
|-----|-------|
| `ibible://today` or `ibible://daily` | Bugünün Kur'ânı |
| `ibible://random` | Rasûlullah |
| `ibible://verse?b=43&c=3&v=16` | Kur'ân-ı Kerim |
| `ibible://chapter?b=43&c=3` | Bölüm okuyucu |
| `ibible://read` | Okumaya Başlayın (bugün değilse) |
| `ibible://read?b=19&c=23&v=1` | Kur'an'ı oku |
| `ibible://last-read` | Son bölüm devam et |
| `ibible://reading-history` | Okuma geçmişi |

## Göz ve çalışma

| URL | Açar |
|-----|-------|
| `ibible://book?id=43` | Book (1–66) |
| `ibible://topics` | Tüm konular |
| `ibible://topic?id=love` | Topic detay |
| `ibible://famous` | Ünlü ayetler |
| `ibible://plans` | Okuma planları |
| `ibible://plan?id=beginner7` | Özel plan |
| `ibible://favorites` | Favoriler |
| `ibible://search?q=love` | Ara |

## Ayarlar ve kılavuzlar

| URL | Açar |
|-----|-------|
| `ibible://home` | Ana sayfa |
| `ibible://settings` | Ayarlar |
| `ibible://usage-guide` | Kullanım kılavuzu |
| `ibible://widget-guide` | Widget kılavuzu |
| `ibible://shortcuts-guide` | Kısayol kılavuzu |
| `ibible://feature-guide` | Özel tur |
| `ibible://feedback` | Geri bildirim |

Kitap numaraları ortak Protestan düzeni takip eder (1 = Genesis ... 66 = Vahiy).
