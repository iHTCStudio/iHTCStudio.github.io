iBible prend en charge ** `ibible://` ** les liens de raccourci pour les actions Raccourcis, widgets, Siri et Home Screen.

## Format de lien


```
ibible://{host}?{params}
```


## Lecture quotidienne

| URL | Ouvre |
|-----|-------|
| `ibible://today` or `ibible://daily` | Aujourd'hui Verset |
| `ibible://random` | Verset aléatoire |
| `ibible://verse?b=43&c=3&v=16` | Verset spécifique (livre / chapitre / verset) |
| `ibible://chapter?b=43&c=3` | Lecteur de chapitres |
| `ibible://read` | Commencez à lire (aujourd'hui si aucun verset) |
| `ibible://read?b=19&c=23&v=1` | Lisez à haute voix un verset |
| `ibible://last-read` | Continuer le dernier chapitre |
| `ibible://reading-history` | Historique de lecture |

## Parcourir et étudier

| URL | Ouvre |
|-----|-------|
| `ibible://book?id=43` | Livre (1-66) |
| `ibible://topics` | Tous les sujets |
| `ibible://topic?id=love` | Détails du sujet |
| `ibible://famous` | Versets célèbres |
| `ibible://plans` | Plans de lecture |
| `ibible://plan?id=beginner7` | Plan spécifique |
| `ibible://favorites` | Favoris |
| `ibible://search?q=love` | Recherche |

## Réglages et guides

| URL | Ouvre |
|-----|-------|
| `ibible://home` | Accueil |
| `ibible://settings` | Réglages |
| `ibible://usage-guide` | Guide d'utilisation |
| `ibible://widget-guide` | Guide des widgets |
| `ibible://shortcuts-guide` | Guide Raccourcis |
| `ibible://feature-guide` | Visite principale |
| `ibible://feedback` | Commentaires |

Les numéros de livre suivent l'ordre protestant commun (1 = Genèse ... 66 = Révélation).
