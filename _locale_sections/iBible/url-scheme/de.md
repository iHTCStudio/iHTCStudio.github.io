iBible unterstützt ** `ibible://` ** Shortcut-Links für Shortcuts, Widgets, Siri und Home Screen Aktionen.

## Linkformat


```
ibible://{host}?{params}
```


## Täglich & Lesen

| URL | Öffnet |
|-----|-------|
| `ibible://today` or `ibible://daily` | Der heutige Vers |
| `ibible://random` | Zufallsvers |
| `ibible://verse?b=43&c=3&v=16` | Spezifischer Vers (Buch / Kapitel / Vers) |
| `ibible://chapter?b=43&c=3` | Kapitelleser |
| `ibible://read` | Starten Sie read-aloud (heute, wenn kein Vers) |
| `ibible://read?b=19&c=23&v=1` | Lies laut einen Vers |
| `ibible://last-read` | Weiter Nächstes Kapitel |
| `ibible://reading-history` | Leseverlauf |

## Browse & Studie

| URL | Öffnet |
|-----|-------|
| `ibible://book?id=43` | Buch (1–66) |
| `ibible://topics` | Alle Themen |
| `ibible://topic?id=love` | Einzelheiten zum Thema |
| `ibible://famous` | Berühmte Verse |
| `ibible://plans` | Lesepläne |
| `ibible://plan?id=beginner7` | Spezifischer Plan |
| `ibible://favorites` | Favoriten |
| `ibible://search?q=love` | Suche |

## Einstellungen & Anleitungen

| URL | Öffnet |
|-----|-------|
| `ibible://home` | Startseite |
| `ibible://settings` | Einstellungen |
| `ibible://usage-guide` | Nutzungsanleitung |
| `ibible://widget-guide` | Widget-Anleitung |
| `ibible://shortcuts-guide` | Kurzbefehle-Anleitung |
| `ibible://feature-guide` | Feature Tour |
| `ibible://feedback` | Feedback |

Buchnummern folgen der gemeinsamen protestantischen Ordnung (1 = Genesis ... 66 = Offenbarung).
