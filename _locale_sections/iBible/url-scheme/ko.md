iBible support ** `ibible://` ** Shortcuts, 위젯, Siri 및 홈 화면 작업을위한 단축 링크.

## 링크 형식


```
ibible://{host}?{params}
```


## 매일 & 독서

| URL | 열리는 화면 |
|-----|-------|
| `ibible://today` or `ibible://daily` | 오늘의 Verse |
| `ibible://random` | 무작위 구절 |
| `ibible://verse?b=43&c=3&v=16` | 특정 구절 (책 / 장 / 구절) |
| `ibible://chapter?b=43&c=3` | 장 리더 |
| `ibible://read` | 읽기-aloud 시작 (구절이 없다면) |
| `ibible://read?b=19&c=23&v=1` | 구절을 읽으십시오 |
| `ibible://last-read` | 마지막 장 |
| `ibible://reading-history` | 읽기 기록 |

## 검색 및 연구

| URL | 열리는 화면 |
|-----|-------|
| `ibible://book?id=43` | 도서 (1-66) |
| `ibible://topics` | 모든 주제 |
| `ibible://topic?id=love` | Topic 세부사항 |
| `ibible://famous` | 인기있는 |
| `ibible://plans` | 독서 계획 |
| `ibible://plan?id=beginner7` | 특정 계획 |
| `ibible://favorites` | 즐겨찾기 |
| `ibible://search?q=love` | 검색 |

## 설정 및 가이드

| URL | 열리는 화면 |
|-----|-------|
| `ibible://home` | 홈 |
| `ibible://settings` | 설정 |
| `ibible://usage-guide` | 사용 가이드 |
| `ibible://widget-guide` | 위젯 가이드 |
| `ibible://shortcuts-guide` | 단축어 가이드 |
| `ibible://feature-guide` | 관광 명소 |
| `ibible://feedback` | 이름 * |

책 번호는 일반적인 Protestant 주문 (1 = Genesis ... 66 = Revelation)을 따릅니다.
