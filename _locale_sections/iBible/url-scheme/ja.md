iBibleは、ショートカット、ウィジェット、Siri、ホーム画面のアクションのショートカットリンクをサポートしています。

## リンク形式


```
ibible://{host}?{params}
```


## 毎日の読書

| URL | 開く画面 |
|-----|-------|
| `ibible://today` or `ibible://daily` | 今日のヴェルス |
| `ibible://random` | ランダムバース |
| `ibible://verse?b=43&c=3&v=16` | 特定の詩(本/章/詩) |
| `ibible://chapter?b=43&c=3` | チャプターリーダー |
| `ibible://read` | 読み出しを開始(バースがない場合) |
| `ibible://read?b=19&c=23&v=1` | 読み aloud averse |
| `ibible://last-read` | 最後の章を続けてください |
| `ibible://reading-history` | 閲覧履歴 |

## ブラウズ&スタディ

| URL | 開く画面 |
|-----|-------|
| `ibible://book?id=43` | 書籍 (1–66) |
| `ibible://topics` | すべてのトピック |
| `ibible://topic?id=love` | トピックの詳細 |
| `ibible://famous` | 有名な詩 |
| `ibible://plans` | 読書計画 |
| `ibible://plan?id=beginner7` | 具体的な計画 |
| `ibible://favorites` | お気に入り |
| `ibible://search?q=love` | 検索 |

## 設定とガイド

| URL | 開く画面 |
|-----|-------|
| `ibible://home` | ホーム |
| `ibible://settings` | 設定 |
| `ibible://usage-guide` | 使い方ガイド |
| `ibible://widget-guide` | ウィジェットガイド |
| `ibible://shortcuts-guide` | ショートカットガイド |
| `ibible://feature-guide` | 特徴ツアー |
| `ibible://feedback` | フィードバック |

ブック番号は、一般的なプロテスタント注文(1 = Genesis ... 66 = Revelation)に従います。
