iBible поддерживает ярлыки ** `ibible://` ** для ярлыков, виджетов, Siri и действий на домашнем экране.

## Формат ссылки


```
ibible://{host}?{params}
```


## Ежедневно и чтение

| URL | Открывает |
|-----|-------|
| `ibible://today` or `ibible://daily` | Сегодняшний стих |
| `ibible://random` | Случайный стих |
| `ibible://verse?b=43&c=3&v=16` | Специфический стих (книга / глава / стих) |
| `ibible://chapter?b=43&c=3` | Глава Читатель |
| `ibible://read` | Начните читать (сегодня, если нет стиха) |
| `ibible://read?b=19&c=23&v=1` | Читать вслух стих |
| `ibible://last-read` | Продолжаем последнюю главу |
| `ibible://reading-history` | История чтения |

## Просмотр и изучение

| URL | Открывает |
|-----|-------|
| `ibible://book?id=43` | Книга (1-66) |
| `ibible://topics` | Все темы |
| `ibible://topic?id=love` | Тематическая деталь |
| `ibible://famous` | Знаменитые стихи |
| `ibible://plans` | Чтение планов |
| `ibible://plan?id=beginner7` | Конкретный план |
| `ibible://favorites` | Избранное |
| `ibible://search?q=love` | Поиск |

## Настройки и руководства

| URL | Открывает |
|-----|-------|
| `ibible://home` | Главная |
| `ibible://settings` | Настройки |
| `ibible://usage-guide` | Руководство по использованию |
| `ibible://widget-guide` | Руководство по виджетам |
| `ibible://shortcuts-guide` | Руководство по «Командам» |
| `ibible://feature-guide` | Особенности тура |
| `ibible://feedback` | обратная связь |

Числа книг следуют общему протестантскому порядку (1 = Бытие... 66 = Откровение).
