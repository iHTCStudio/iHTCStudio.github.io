### แอปออฟไลน์โดยสมบูรณ์หรือไม่

ใช่สำหรับการใช้งานหลัก พระคัมภีร์ฉบับเต็ม — **หนังสือ 66 เล่ม** และ **~31,021 ข้อ** — รวมอยู่ในชุด หลังจากติดตั้ง การเรียกดู การอ่านแบบขนาน แผน TTS วิดเจ็ต และการแจ้งเตือนรายวันในท้องถิ่นจะทำงานได้ **โดยไม่มีเครือข่าย** ข้อยกเว้นเพิ่มเติม: **การให้ทิป StoreKit** (Apple) และการแชร์ไปยังแอปอื่นที่คุณเลือก

### สิ่งนี้แตกต่างจากโปรแกรมอ่านพระคัมภีร์ทั่วไปอย่างไร?

iBible เป็น **สถานีงานอุทิศสองภาษา**: **ข้อพระคัมภีร์ประจำวัน** ที่มีความสอดคล้องกันทั้งในแอป / วิดเจ็ต / การแจ้งเตือน **การอ่านคู่ขนานภาษาจีน-อังกฤษ** คัดสรร **หัวข้อ / ข้อพระคัมภีร์ที่มีชื่อเสียง / แผนงาน** การ์ดแชร์ TTS พื้นหลัง วิดเจ็ต กิจกรรมสดที่เป็นตัวเลือก และ Siri — **ไม่มีบัญชี ไม่มีโฆษณา ไม่มีฟีดโซเชียล**

### ข้อพระคัมภีร์ของวันนี้คืออะไร?

ข้อพระคัมภีร์รายวันที่เลือกโดยมีบริบท **วันธรรมดา + ฤดูกาลพิธีกรรม** (รวมถึงหน้าต่างอีสเตอร์แบบไดนามิก) ข้อเดียวกันนี้ปรากฏในแอป วิดเจ็ต การแจ้งเตือนท้องถิ่นที่เป็นตัวเลือก และลิงก์ในรายละเอียด วิดเจ็ตสามารถ **รีเฟรช** ไปยังข้ออื่นสำหรับวันนี้ได้

### ฉันสามารถอ่านภาษาจีนและภาษาอังกฤษด้วยกันได้หรือไม่?

ใช่. เลือกเวอร์ชัน **หลัก** และ **ขนาน** สลับโหมดสองภาษา และสลับว่าด้านใดเป็นเวอร์ชันหลัก ภาษา UI (EN / 简 / 繁) ไม่ขึ้นอยู่กับภาษาในพระคัมภีร์

### มีแผนการอ่านอะไรบ้าง?

หกแผน: **ก้าวแรก (7)**, **ข่าวประเสริฐของยอห์น (21)**, **สุภาษิต (31)**, **สดุดี (31)**, **พันธสัญญาใหม่ 90 วัน** และ **พระคัมภีร์ในหนึ่งปี (365)**

### ฉันจะเพิ่มวิดเจ็ตได้อย่างไร?

กดหน้าจอหลักค้างไว้ → แก้ไข → เพิ่มวิดเจ็ต → ค้นหา **iBible** ครอบครัวประกอบด้วยข้อพระคัมภีร์ประจำวัน ข้อที่มีชื่อเสียง รายการโปรด ความคืบหน้าของแผน และการอ่านต่อ (พร้อมขนาดหน้าจอล็อคหากมี)

### เหตุใด Live Activity จึงไม่ปรากฏขึ้น

เปิดใช้งานได้ใน **การตั้งค่า → การอ่านและคำพูด** จะต้องเริ่มต้นในขณะที่แอปอยู่ใน **เบื้องหน้า** บน iPhone ที่รองรับ การออกจากเซสชันการอ่านจะสิ้นสุดลง ลักษณะการทำงานจะแตกต่างออกไปบน Mac

### iCloud Sync ครอบคลุมอะไรบ้าง

การซิงค์เพิ่มเติมสำหรับ **รายการโปรด** และ **รายการข้อ** ผ่านการจัดเก็บคีย์-ค่า iCloud ส่วนตัวของคุณ ข้อความในพระคัมภีร์มีอยู่ในอุปกรณ์แล้วและไม่ได้ดาวน์โหลดจากเซิร์ฟเวอร์ของเรา

### คุณรวบรวมข้อมูลของฉันหรือไม่?

**ไม่** ดู [นโยบายความเป็นส่วนตัว](../privacy): ไม่มีการเก็บรวบรวมข้อมูล โดย iHTC Studio; ไม่มีโฆษณา/การวิเคราะห์ SDK; ไม่มีบัญชี

### URL นโยบายความเป็นส่วนตัวสำหรับ App Store Connect อยู่ที่ไหน

เปิดหน้า [นโยบายความเป็นส่วนตัว](../privacy) ของไซต์นี้ และคัดลอก URL จากแถบที่อยู่ของเบราว์เซอร์ของคุณ

iPhone / iPad **iOS 17.0+**, Mac **macOS 14.0+**.
