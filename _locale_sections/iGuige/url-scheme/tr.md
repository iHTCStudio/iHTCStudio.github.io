). / iGuige, ** `iguige://` ** kısayol bağlantıları (URL planı). Soğuk başlangıç ve Ev Ekran kısayolları birleşik bir tampon aracılığıyla teslim edilir, bu yüzden bağlantılar gemiden sonra iki kez açılmaz.

## Bağlantı biçimi


```
iguige://{host}?{params}
```


## Benzersiz masası

| URL | Açar |
|-----|-------|
| `iguige://daily` | Günlük Strateji |
| `iguige://rhetoric` | Her Kind |
| `iguige://arts` / `iguige://art?id=` | Sanat kartları |
| `iguige://cases` / `iguige://case?id=` | Savaş Devletler Davası |
| `iguige://scenarios` | Modern çalışma sahneleri |
| `iguige://persons` / `iguige://timeline` | Şekiller ve kronoloji |
| `iguige://study` | Guigu Academy |
| `iguige://hunt` | Hunt the Art |
| `iguige://counselor` | On-device danışmanı (iOS 26 +) |
