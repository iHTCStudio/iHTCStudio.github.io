鬼谷子 / iGuigeは** `iguige://` **ショートカットリンク(URLスキーム)をサポートしています。 コールドスタートとホーム画面のショートカットは、統一されたバッファを介して配信されますので、リンクはオンボーディング後2回開いていません。

## リンク形式


```
iguige://{host}?{params}
```


## ユニークなデスク

| URL | 開く画面 |
|-----|-------|
| `iguige://daily` | 毎日の戦略 |
| `iguige://rhetoric` | 各種類にピーク |
| `iguige://arts` / `iguige://art?id=` | アートカード |
| `iguige://cases` / `iguige://case?id=` | 戦国事例 |
| `iguige://scenarios` | 近代的な学習シーン |
| `iguige://persons` / `iguige://timeline` | 図とクロノロジー |
| `iguige://study` | ギグアカデミー |
| `iguige://hunt` | ハント・ザ・アート |
| `iguige://counselor` | オンデバイスアドバイザー(iOS 26+) |
