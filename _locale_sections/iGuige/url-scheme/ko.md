short谷子 / iGuige 지원 ** `iguige://` ** 단축 링크 (URL 계획). 콜드 시작 및 홈 화면 단축은 통합 버퍼를 통해 전달되므로 링크가 내장 된 후 두 번 열리지 않습니다.

## 링크 형식


```
iguige://{host}?{params}
```


## 회사 소개

| URL | 열리는 화면 |
|-----|-------|
| `iguige://daily` | 매일 전략 |
| `iguige://rhetoric` | 각 종류에 대해 |
| `iguige://arts` / `iguige://art?id=` | 아트 카드 |
| `iguige://cases` / `iguige://case?id=` | 미국 사례 |
| `iguige://scenarios` | 현대 연구 장면 |
| `iguige://persons` / `iguige://timeline` | 그림 & 연어 |
| `iguige://study` | 구이구 아카데미 |
| `iguige://hunt` | 예술을 사냥 |
| `iguige://counselor` | 고문 (iOS 26+) |
