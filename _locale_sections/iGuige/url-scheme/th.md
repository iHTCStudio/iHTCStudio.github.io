爱鬼谷/ iguage รองรับ~ BAR `iguige://` BAR * ลิงก์ลัด (URL scheme). การเริ่มหน้าจอหน้าจอเย็นและหน้าจอบ้าน จะถูกส่งไปผ่านระบบบัฟเฟอร์แบบรวม ดังนั้นลิงก์จึงไม่ถูกเปิดสองครั้งหลังจากขึ้นเครื่อง

## รูปแบบลิงก์


```
iguige://{host}?{params}
```


## โต๊ะยูนิโค้ด

| URL | เปิด |
|-----|-------|
| `iguige://daily` | กลยุทธ์ประจําวัน |
| `iguige://rhetoric` | พูด กับ แต่ ละ คน |
| `iguige://arts` / `iguige://art?id=` | นามบัตรศิลปะ |
| `iguige://cases` / `iguige://case?id=` | กรณีของสงคราม |
| `iguige://scenarios` | ฉาก การ ศึกษา สมัย ใหม่ |
| `iguige://persons` / `iguige://timeline` | ตัวเลขและการคํานวณ |
| `iguige://study` | โรงเรียนไกกู |
| `iguige://hunt` | ล่าศิลปะ |
| `iguige://counselor` | ที่ปรึกษาผู้ฝึกสอน (inOS 26+) |
