). / iGuige поддерживает ярлыки ** `iguige://` ** (схема URL). Холодный старт и ярлыки домашнего экрана доставляются через единый буфер, поэтому ссылки не открываются дважды после входа.

## Формат ссылки


```
iguige://{host}?{params}
```


## Уникальный стол

| URL | Открывает |
|-----|-------|
| `iguige://daily` | Ежедневная стратегия |
| `iguige://rhetoric` | Говорите с каждым видом |
| `iguige://arts` / `iguige://art?id=` | Искусство |
| `iguige://cases` / `iguige://case?id=` | Дела воюющих государств |
| `iguige://scenarios` | Современные учебные сцены |
| `iguige://persons` / `iguige://timeline` | Рисунки и хронология |
| `iguige://study` | Академия Гуйгу |
| `iguige://hunt` | Охота на искусство |
| `iguige://counselor` | Советник по устройству (iOS 26+) |
