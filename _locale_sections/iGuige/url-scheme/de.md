爱鬼谷子 / iGuige unterstützt ** `iguige://` ** Shortcut Links (URL-Schema). Kaltstart- und Home Screen-Verknüpfungen werden über einen einheitlichen Puffer geliefert, so dass Links nach dem Onboarding nicht zweimal geöffnet werden.

## Linkformat


```
iguige://{host}?{params}
```


## Einzigartiger Schreibtisch

| URL | Öffnet |
|-----|-------|
| `iguige://daily` | Die tägliche Strategie |
| `iguige://rhetoric` | Sprich mit jedem Kind |
| `iguige://arts` / `iguige://art?id=` | Kunstkarten |
| `iguige://cases` / `iguige://case?id=` | Fälle von Kriegsstaaten |
| `iguige://scenarios` | Moderne Studienszenen |
| `iguige://persons` / `iguige://timeline` | Zahlen und Chronologie |
| `iguige://study` | Guigu Akademie |
| `iguige://hunt` | Jagd auf die Kunst |
| `iguige://counselor` | On-Device Advisor (iOS 26+) |
