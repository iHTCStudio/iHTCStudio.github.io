Le logiciel iGuige prend en charge les liens de raccourci ** `iguige://` ** (système URL). Les raccourcis de démarrage à froid et d'écran d'accueil sont livrés via un tampon unifié de sorte que les liens ne sont pas ouverts deux fois après l'embarquement.

## Format de lien


```
iguige://{host}?{params}
```


## Bureau unique

| URL | Ouvre |
|-----|-------|
| `iguige://daily` | Stratégie quotidienne |
| `iguige://rhetoric` | Parlez à chaque genre |
| `iguige://arts` / `iguige://art?id=` | Cartes d'art |
| `iguige://cases` / `iguige://case?id=` | États en guerre |
| `iguige://scenarios` | Scènes d'études modernes |
| `iguige://persons` / `iguige://timeline` | Figures & chronologie |
| `iguige://study` | Académie Guigu |
| `iguige://hunt` | Chasser l'art |
| `iguige://counselor` | Conseiller sur place (iOS 26+) |

```

```
