**一度に 1 つの韻ペア。**

 iRhyme (愛声律启蒙 / 愛聲律啟蒙) は **オフラインのサウンド韻スタジオ** であり、別の連句ダンプではありません。 **アカウントは必要ありません。** すべての **312** パッセージがデバイスに配信されます: *Shenglü Qimeng*、*Li Weng Dui Yun*、**30 韻**、*Qian Jia Shi*、*You Xue Qiong Lin*。 **並列処理の視覚化** は、単に印刷するのではなく、对仗を表示します。 **同じ韻の比較** は、1 つの韻クラスに 2 つの入門書を並べます。 **今日の韻**から始めましょう。 段落を強調表示して **暗唱**します。 **ライムアカデミー**で練習してください。 **韻カード**をエクスポートします。 **ウィジェット**、オプションの**ライブアクティビティの読み取り**、**Siriとショートカット**、およびオプションの**iCloud**を追加します。 オリジナルはパブリックドメインです。 ノートと用語集は勉強の補助です。 **広告はありません。 追跡はありません。 Data Not Collected.**

 **概要:** 312 のパッセージ、30 の韻の章、127 人の著者、120 の有名なセリフ、93 の用語集、並列表示、同じ韻の比較、暗唱、韻アカデミー、韻ハント、今日の韻、韻カード、ウィジェット、コントロール センター、`irhyme://`、EN / 简 / 繁。 

## はじめに (ステップバイステップ)

 ### 1. 最初の起動

1. [App Store](https://apps.apple.com/app/id1439667243) からインストールし、**iRhyme** を開きます。 
2. ウェルカムガイドを完了します: 今日の韻→朗読→並列→韻アカデミー→同じ韻の比較→ジェスチャー→プライバシー。 
3. **[設定] → [ヘルプ] → [機能ガイド]** (`irhyme://feature-guide`) でいつでも再生できます。 
4. 使用法、ウィジェット、およびショートカットのガイドは、**設定 → ヘルプ** にあります。 

### 2. ホームで今日の詩を読む

 1. [**ホーム**] タブを開きます。 
2. **今日の韻**の主人公が今日の一節を示します。 タップして詳細を開きます。 
3. オプション: 設定でローカル **今日の韻通知** を有効にします。 
4. ホームから朗読、ライムアカデミー、ライムハント、お気に入り、検索にジャンプします。 

### 3. 参照と検索

 1. *Shenglü Qimeng*、*Li Weng Dui Yun* (30 の韻)、*Qian Jia Shi*、*You Xue Qiong Lin*、韻のクラス、用語集、および **120 の有名なセリフ**を参照します。 
2. タイトル、原文、名セリフを検索します。 iOS では、オプションの **手書き検索** によりデバイス上の文字が認識されます。 
3. パッセージにスターを付けて **お気に入り**に追加し、個人用**リスト** (韵单) に集めます。 

### 4. 精読、並列、韻カード

1. **バイリンガル/中国語のみ/英語のみ**を切り替えます。 母国語、英語、ピンインを個別に切り替えます。 
2. **並列処理の視覚化** と **同韻比較** (`irhyme://compare?rhyme=dong`) を開きます。 用語集: `irhyme://glossary`。 
3. 没入型​​の読書、縦方向のレイアウト、中央揃え、フォント スケール、分割されたページを試してください。 
4. **韻カード**を開き、スタイル/比率を選択し、写真 (追加専用) またはシステム共有に保存します。 

### 5. 朗読＆韻アカデミー

 1. ハイライトされた TTS、調整可能な音声とペース、オプションの現地語/英語のキャプション、連続再生、およびバックグラウンド オーディオの朗読ワークベンチを開きます。 
2. **ライム アカデミー** (`irhyme://study`): フェード、穴埋め、セルフチェック、クイズ、ペアリング (`irhyme://pair`)、マスタリー追跡機能付き。 
3. Home の **Rhyme Hunt** は、別の対句を見つけるゲームです。 

### 6. ウィジェット、Siri、システム機能

 1. **今日の韻 / 名セリフ / お気に入り / 勉強の進み具合** ウィジェットを追加します。 
2. コントロール センター、Siri、Spotlight、`irhyme://` ディープ リンクを使用します。 
3. オプションの読書ライブ アクティビティは、サポートされている iPhone デバイスで引き続き利用できます。 

### 7. プライバシーと同期

1. ライブラリ、読書、朗読 (システム TTS)、韻アカデミー、ウィジェット、およびローカル通知は、インストール後 **完全にオフライン**で機能します。 
2. オプションの **_iCloud 同期** は、**プライベート iCloud*** を通じてお気に入り、リスト、履歴、進行状況、連続記録、メモをミラーリングします。 
3. 開発者 (オプションの StoreKit) は、ペイウォールのロックを解除したり、アカウントを作成したりすることはありません。 

## ダウンロードする理由

 - **読むだけでなく対句をご覧ください** — 並列性の視覚化と同韻比較が机に変わります。 
- **1 つのアプリに 4 つの入門書** — *Shenglü*、*Li Weng*、*Qian Jia Shi*、および *You Xue Qiong Lin*、オフライン。 
- **ネイティブ学習デスク** — 暗唱、ペアリング、用語集、ウィジェット、Siri、ディープリンクを 1 つのアプリで実行します。 
- **設計によるプライバシー** — アカウント、広告、分析 SDK はありません。

 - **312** の文章 · **30** の押韻章 · **127** の著者 · **120** の有名なセリフ · **93** の用語集
