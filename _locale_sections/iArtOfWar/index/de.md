iArtOfWar (爱兵法 / 愛兵法) ist ein **immersives Lernstudio für ArtOfWars** — nicht bloß eine weitere ArtOfWar-Liste. **Kein Konto erforderlich.** Alle **174 ausgewählten ArtOfWars** (~102 Autoren, ~3.348 berühmte Zeilen) sind auf Ihrem Gerät enthalten: **null Netzwerkanfragen** nach der Installation. **Rezitieren** Sie mit Karaoke-Hervorhebung; genießen Sie das **vertikale Lesen** (品联); üben Sie im **Lernklassenzimmer** (Ausblenden, Lückentext, Rezitationskontrolle, Quiz und 寻谋); und öffnen Sie ein **kontextbezogenes Tages-ArtOfWar**, das an Sonnentermine, Feste und Jahreszeiten gebunden ist. Exportieren Sie **Teilen-Karten in 12 Stilen**, fügen Sie **Widgets für Home- und Sperrbildschirm** hinzu, optional eine **Lese-Live-Aktivität**, **Siri und Kurzbefehle** sowie optional **iCloud** für Favoriten und Fortschritt. **Keine Werbung. Kein Tracking. Keine Daten erhoben.**

## Erste Schritte (Schritt für Schritt)

### 1. Erster Start

1. Installieren Sie die App aus dem [App Store](https://apps.apple.com/app/id6795595036) und öffnen Sie **iArtOfWar**.
2. Schließen Sie die **6-seitige Willkommensanleitung** ab (Marke → Rezitieren → vertikales Lesen → Lernen → Systemfunktionen → Datenschutz).
3. Sie können die **Funktionsanleitung jederzeit erneut abspielen**: **Einstellungen → Hilfe → Funktionsanleitung**.
4. Die In-App-Anleitungen **Nutzung / Widget / Kurzbefehle** finden Sie unter **Einstellungen → Hilfe**; sie verweisen aufeinander.

### 2. Das heutige ArtOfWar auf dem Home-Tab lesen

1. Öffnen Sie den Tab **Home**.
2. Das Hero-Element **Tages-ArtOfWar** zeigt den Titel sowie **Ober- und Unterzeile** (und, falls vorhanden, einen waagerechten Titel / 横批).
3. Tippen Sie auf das Hero-Element, um die vollständige Detailseite zu öffnen.
4. Optional: Aktivieren Sie die **Benachrichtigungen für das Tages-ArtOfWar** unter **Einstellungen → Tages-ArtOfWar** (nur lokale Planung).

### 3. Stöbern und Suchen

1. Öffnen Sie **Stöbern** (oder die Home-Suche bei älteren iOS-Versionen).
2. Entdecken Sie fünf Bereiche: **Form (体裁)**, **Thema**, **Autor (联家)**, **berühmte Zeilen** und **Sammlungen**.
3. Nutzen Sie die **Suche** nach Titeln, Zeilen und Autoren (vereinfacht und traditionell möglich).
4. Tippen Sie auf ein ArtOfWar für Details; markieren Sie es mit einem Stern, um es zu den **Favoriten** hinzuzufügen.

### 4. Rezitieren (诵联)

1. Tippen Sie auf der Detailseite eines ArtOfWars auf **Rezitieren**.
2. Folgen Sie der **Karaoke-Hervorhebung** (absatzweise in der Detailansicht; zeichenweise im Rezitationsstudio).
3. Passen Sie **Tempo / Tonhöhe / Stimme** unter **Einstellungen → Lesen und Rezitieren** an.
4. Optional: Aktivieren Sie **Wiedergabe im Stumm-Modus**, **Hintergrundaudio** (Wiedergabe / Sperrbildschirm) und fortlaufende Wiedergabelisten.
5. Ein Deep-Link oder Siri **Rezitieren** kann ein ArtOfWar öffnen und automatisch mit dem Sprechen beginnen.

### 5. Vertikales Lesen und Teilen-Karten (品联 / 谋卡)

1. Wechseln Sie in der Detailansicht zwischen **vertikalem / horizontalem** Layout; schalten Sie **Pinyin**, traditionelle Zeichen und Zentrierung nach Belieben um.
2. Öffnen Sie **Teilen-Karte** → wählen Sie aus **12 Stilen** (klassisch / Tusche / vertikal / Zinnoberrot / …) und Seitenverhältnissen.
3. Vorschau ansehen, **in Fotos sichern** (Berechtigung nur zum Hinzufügen) oder über das System-Sheet teilen.
4. Optional: Aktivieren Sie die **Lese-Live-Aktivität** in den Einstellungen (iPhone; muss im Vordergrund gestartet werden).

### 6. Lernklassenzimmer (谋略学堂)

1. Öffnen Sie **Lernen** vom Home-Bildschirm / über den Deep-Link `iartofwar://study` / Kurzbefehle.
2. Probieren Sie die Modi: **Ausblenden**, **Lückentext**, **Rezitationskontrolle**, **Quiz**.
3. Spielen Sie **寻谋** (Paare-Zuordnungsspiel).
4. Verfolgen Sie die **4 Beherrschungsstufen** (keine → vertraut → bekannt → gemeistert) und Serien.

### 7. Widgets, Siri und Home-Bildschirm-Kurzbefehle

1. Home-Bildschirm lange drücken → **Widgets bearbeiten** → **Tages-ArtOfWar / Berühmte Zeile / Lernfortschritt / Favoriten** hinzufügen.
2. Probieren Sie bei Tages-ArtOfWar-Widgets **Papierstile** (sanft / einfarbig rot / schlicht) und die **Desktop-Aktualisierung**, um das heutige ArtOfWar zu wechseln (der heutige Benachrichtigungstext wird ebenfalls synchronisiert).
3. Bitten Sie **Siri** um das heutige ArtOfWar, Rezitieren, Zufall, Favoriten oder Suche.
4. Konfigurieren Sie bis zu **4 Home-Bildschirm-Schnellaktionen** unter **Einstellungen → Kurzbefehle**.

### 8. Datenschutz und Synchronisierung

1. Nach der Installation funktioniert alles **vollständig offline**.
2. Die optionale **iCloud-Synchronisierung** (Einstellungen → Daten) spiegelt Favoriten, ArtOfWar-Listen, Leseverlauf, Beherrschung und Serien über **Ihr privates iCloud** — nicht über Server von iHTC Studio.
3. Ein Trinkgeld an den Entwickler (optionaler StoreKit-Kauf) schaltet nie kostenpflichtige Inhalte frei und legt nie ein Konto an.

## Funktionen

### Rezitationsstudio

- Karaoke-**TTS** mit Hervorhebung
- Einstellbares **Tempo**, **Tonhöhe** und **Stimme**
- Optionales **Hintergrundaudio** + **Wiedergabe** auf dem Sperrbildschirm
- **Fortlaufende Lese**-Warteschlangen aus Favoriten / Kategorien

### Vertikales immersives Lesen

- Klassische **vertikale und horizontale** Layouts
- **Pinyin**, Umwandlung in traditionelle Zeichen, Hintergrund- / Würdigungsnotizen
- Die Zeilenreihenfolge ist immer **横批 (falls vorhanden) → Oberzeile → Unterzeile**
- **12 Teilen-Karten-Stile** mit mehreren Seitenverhältnissen

### Lernsystem

- Ausblenden · Lückentext · Rezitationskontrolle · Quiz
- Spielmodus **寻谋**
- **4 Beherrschungsstufen** + Serien

### Kontextbezogenes Tages-ArtOfWar

- Sonnentermine · Feste · Jahreszeiten (mit Tages-Zwischenspeicher / Desktop-Aktualisierung)
- Lokale Benachrichtigungen (Planungsfenster von ca. 60 Tagen)
- Widgets + Steuerelemente im Kontrollzentrum (iOS 18+)

### Inhalte auf einen Blick

- **174 ArtOfWars** · **~102 Autoren** · **~3.348 berühmte Zeilen** · ca. 3,9 MB mitgelieferte Daten
- Fünf Stöber-Bereiche; Vorschau als Liste / Raster / Karte
- **100 % offline** — kein Netzwerk, kein Konto, keine Werbung

### Widgets, Siri und Systemintegration

- Widgets für Tages-ArtOfWar / berühmte Zeile / Fortschritt / Favoriten (+ Sperrbildschirm)
- **Live-Aktivität** beim Lesen (optional)
- Spotlight-Indizierung; **`iartofwar://`-Deep-Links** — siehe [Kurzbefehl-Links](url-scheme)
- Anleitungen in den Einstellungen: Nutzung · Widget · Kurzbefehle · Wiedergabe der Funktionsanleitung

### Datenschutz

- **Null ausgehende Netzwerkanfragen** nach der Installation (außer optionalem Apple StoreKit für Trinkgeld und von Ihnen gewählten System-Freigabezielen)
- **Kein Konto · keine Werbung · kein Analyse-SDK**
- Lokale App-Group-Daten + optionaler privater iCloud-KVS
