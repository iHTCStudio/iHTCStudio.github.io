iArtOfWar（爱兵法 / 愛兵法）は、単なる対聯リストではない、**没入型の対聯学習スタジオ**です。**アカウント不要。** 厳選した **174 件の対聯**（作者約 102 名、名句約 3,348 句）がすべて端末に同梱されており、インストール後の**ネットワークリクエストはゼロ**です。カラオケ風ハイライトで**朗誦**し、**縦書き閲読**（品联）を楽しみ、**学習教室**（フェード、穴埋め、朗誦チェック、クイズ、寻谋）で練習し、二十四節気・祝祭日・季節に合わせた**文脈型の今日の一謀**を開けます。**12 スタイルの共有カード**の書き出し、**ホーム画面 / ロック画面のウィジェット**、任意の**閲読ライブアクティビティ**、**Siri とショートカット**、お気に入りと進捗用の任意の **iCloud** にも対応。**広告なし。トラッキングなし。データは収集されません。**

## はじめに（ステップごとの手順）

### 1. 初回起動

1. [App Store](https://apps.apple.com/app/id6795595036) からインストールし、**iArtOfWar** を開きます。
2. **6 ページのウェルカムガイド**（ブランド → 朗誦 → 縦書き閲読 → 学習 → システム機能 → プライバシー）を完了します。
3. 機能ガイドはいつでも**再表示**できます：**設定 → ヘルプ → 機能ガイド**。
4. アプリ内の**使い方 / ウィジェット / ショートカット**のガイドは**設定 → ヘルプ**にあり、相互にリンクしています。

### 2. ホームで今日の一謀を読む

1. **ホーム**タブを開きます。
2. **今日の一謀**のヒーロー表示に、題名と**上聯・下聯**（および、ある場合は横書きの題＝横批）が表示されます。
3. ヒーローをタップすると、詳細ページが開きます。
4. 任意：**設定 → 今日の一謀**で**今日の一謀の通知**をオンにします（ローカルでのスケジュールのみ）。

### 3. 閲覧と検索

1. **閲覧**を開きます（古い iOS ビルドではホームの検索）。
2. 5 つのセクションを見てみましょう：**体裁（形式）**、**テーマ**、**作者（联家）**、**名句**、**コレクション**。
3. **検索**で題名、句、作者を探せます（簡体字・繁体字のどちらでも可）。
4. 対聯をタップして詳細を表示し、スターを付けて**お気に入り**に追加します。

### 4. 朗誦（诵联）

1. 対聯の詳細ページで**朗誦**をタップします。
2. **カラオケ風**のハイライトに合わせます（詳細画面では段落単位、朗誦スタジオでは文字単位）。
3. **速度 / ピッチ / 音声**は**設定 → 閲読と朗誦**で調整できます。
4. 任意：**サイレントモードでの再生**、**バックグラウンドオーディオ**（再生中画面 / ロック画面）、連続再生リストを有効にできます。
5. ディープリンクや Siri の**朗誦**で、対聯を開いて自動的に読み上げを始めることもできます。

### 5. 縦書き閲読と共有カード（品联 / 谋卡）

1. 詳細画面で**縦書き / 横書き**レイアウトを切り替え、**ピンイン**、繁体字、センタリングを好みに合わせて設定します。
2. **共有カード**を開き、**12 スタイル**（クラシック / 水墨 / 縦書き / 朱色 / …）と縦横比から選びます。
3. プレビューして、**写真に保存**（追加のみの権限）するか、システムの共有シートで共有します。
4. 任意：設定で**閲読ライブアクティビティ**を有効にします（iPhone。フォアグラウンドで開始する必要があります）。

### 6. 学習教室（谋略学堂）

1. ホーム / ディープリンク `iartofwar://study` / ショートカットから**学習**を開きます。
2. **フェード**、**穴埋め**、**朗誦チェック**、**クイズ**のモードを試します。
3. **寻谋**（ペアを合わせるゲーム）で遊びます。
4. **4 段階の習熟度**（未習得 → なじみ → 知っている → 習得）と連続記録を確認します。

### 7. ウィジェット、Siri、ホーム画面のショートカット

1. ホーム画面を長押し → **ウィジェットを編集** → **今日の一謀 / 名句 / 学習の進捗 / お気に入り**を追加します。
2. 今日の一謀ウィジェットでは、**紙スタイル**（やわらか / 無地の赤 / 白地）と、今日の一謀を変える**デスクトップ更新**を試せます（今日の通知テキストも同期されます）。
3. **Siri** に、今日の一謀、朗誦、ランダム、お気に入り、検索を頼めます。
4. **設定 → ショートカット**で、最大 **4 件のホーム画面クイックアクション**を設定できます。

### 8. プライバシーと同期

1. インストール後は、すべてが**完全オフライン**で動作します。
2. 任意の **iCloud 同期**（設定 → データ）は、お気に入り、対聯リスト、閲読履歴、習熟度、連続記録を、iHTC Studio のサーバーではなく**お客様のプライベートな iCloud** 経由でミラーリングします。
3. 開発者への投げ銭（任意の StoreKit 購入）で有料コンテンツが解放されることはなく、アカウントが作られることもありません。

## 機能

### 朗誦スタジオ

- ハイライト付きのカラオケ風 **TTS**
- **速度**、**ピッチ**、**音声**を調整可能
- 任意の**バックグラウンドオーディオ**＋ロック画面の**再生中**表示
- お気に入り / カテゴリからの**連続読み上げ**キュー

### 縦書きの没入型閲読

- 古典的な**縦書き・横書き**レイアウト
- **ピンイン**、繁体字変換、背景・鑑賞ノート
- 行の順序は常に**横批（あれば）→ 上聯 → 下聯**
- 複数の縦横比に対応した **12 種類の共有カードスタイル**

### 学習システム

- フェード · 穴埋め · 朗誦チェック · クイズ
- **寻谋**ゲームモード
- **4 段階の習熟度**＋連続記録

### 文脈型の今日の一謀

- 二十四節気 · 祝祭日 · 季節（同日キャッシュ / デスクトップ更新に対応）
- ローカル通知（約 60 日間のスケジュール範囲）
- ウィジェット＋コントロールセンター用コントロール（iOS 18 以降）

### コンテンツの概要

- **174 件の対聯** · **作者約 102 名** · **名句約 3,348 句** · 同梱データ約 3.9 MB
- 5 つの閲覧セクション。リスト / グリッド / カードのプレビュー
- **100% オフライン** — ネットワーク不要、アカウント不要、広告なし

### ウィジェット、Siri、システム連携

- 今日の一謀 / 名句 / 進捗 / お気に入りのウィジェット（＋ロック画面）
- 閲読**ライブアクティビティ**（任意）
- Spotlight インデックス。**`iartofwar://` ディープリンク** — [ショートカットリンク](url-scheme)を参照
- 設定内のガイド：使い方 · ウィジェット · ショートカット · 機能ガイドの再表示

### プライバシー

- インストール後の**外部へのネットワークリクエストはゼロ**（投げ銭用の任意の Apple StoreKit と、お客様が選ぶシステムの共有先を除く）
- **アカウントなし · 広告なし · 分析 SDK なし**
- ローカルの App Group データ＋任意のプライベート iCloud KVS
