iSutra(爱佛经 / 愛佛經)는 일반 텍스트 덤프가 아닌 **몰입형 경전 읽기 및 수행 스튜디오**입니다. **계정이 필요하지 않습니다.** **144개 항목** 오프라인 색인에는 자주 낭송되는 고전(심장경, 금강경 32구간, 아미타경, 약불서원, 보살문, 지장 13장, 진언, 플랫폼경 발췌, 42장, 팔각성 등)이 포함되어 있으며 **이중 언어 읽기**, **토어** 및 **101** 유명한 대사. **암송** 단락 강조 표시; **스터디홀**에서 연습하세요. **목어 노래 카운터**를 탭하세요. **경전 복사** PencilKit 추적(iOS); 헌신적으로 **아침/저녁 연습**을 계속하세요. 상황별 **매일경**을 엽니다. **Dharma 카드** 내보내기, **위젯**, 선택 사항 **읽기/찬송 라이브 활동**, **Siri 및 단축키** 및 선택 사항 **iCloud**를 추가합니다. 텍스트는 **학습 및 교육용**용입니다. **광고가 없습니다. 추적이 없습니다. Data Not Collected.**

## 시작하기(단계별) 

### 1. 첫 실행 

1. [App Store](https://apps.apple.com/app/id6796014949)에서 설치하고 **iSutra**를 엽니다. 
2. **웰컴 가이드**(브랜드 → 이중언어 읽기 → 암송 → 학습/성가 → 연습 → 개인정보 보호)를 완료합니다. 
3. 언제든 다시보기: **설정 → 도움말 → 기능안내** (`isutra://feature-guide`). 
4. 인앱 **사용법/위젯/바로가기** 가이드는 **설정 → 도움말**에 있습니다. 

### 2. 홈에서 오늘의 경전 읽기 

1. **홈** 탭을 엽니다. 
2. **일경** 영웅이 오늘의 말씀을 보여줍니다. 세부정보를 열려면 탭하세요. 
3. 선택 사항: 설정에서 **매일 경전 알림**을 켭니다(로컬 예약에만 해당). 
4. 계속 읽기, 유명한 대사, 연속선, 단축키(암송/공부/사냥/찬송/복사/연습)를 탭 한 번이면 됩니다. 

### 3. 탐색 및 검색

1. **찾아보기**를 엽니다(기본적으로 켜져 있으며 설정에서 숨길 수 있음). 
2. **컬렉션**(반야 / 연꽃 / 화엄사 / 정토 / 지장보살 / 밀교 / 선 / 사십이 / 여덟 각성), 테마, 유명한 대사, 번역자 및 모든 항목을 탐색하십시오. 대형 책 껍질은 볼륨 카탈로그를 엽니다. 
3. 제목, 행 및 현지어(간체/번체 친화적)에 대해서는 **검색**을 사용하십시오. _iOS에서는 선택적 **필기 경전 검색**이 장치의 문자를 인식합니다. 
4. **즐겨찾기**에 별표 표시를 하세요. 개인 **경 목록**(经单)을 작성합니다. 즐겨찾기 탭은 **기본적으로 켜져 있습니다**. 

### 4. 이중 언어 읽기 및 달마 카드 

1. 세부사항에서 **이중언어 / 중국어만 / 영어만** 선택하세요. 모국어, 영어, 병음을 독립적으로 전환합니다. 
2. 긴 장을 읽으려면 **몰입형 읽기**, 세로 레이아웃, 글꼴 크기, **분할된 페이지**를 사용해 보세요. 
3. **공유 카드(법卡)** 열기 → 스타일/비율 선택 → 사진(추가 전용) 또는 시스템 공유에 저장합니다. 
4. 선택 사항: iPhone에서 **실시간 활동 읽기**를 활성화합니다(포그라운드에서 시작). 

### 5. 암송(诵经)

1. 세부정보에서 **암송**을 탭하거나 암송 워크벤치를 엽니다. 
2. 들으면서 **단락 강조**를 따르세요. 
3. **설정 → 읽기 및 암송**에서 **재생 콘텐츠 매트릭스**(원본/모국어/영어)를 설정합니다. *보는 내용*과는 별개입니다. 
4. 선택 사항: 무음 모드 재생, 배경 오디오 + 지금 재생 중, 챕터 부분 연속 재생, 화면 켜짐 유지. 

### 6. 자습실, 챈트, 복사 및 연습 

1. **공부**(`isutra://study`): 암송/빈칸 채우기/자가 점검/퀴즈, 플러스 **사냥(寻经)**. 
2. **챈트**(`isutra://count`): 목표(27 / 54 / 108 / 1080 또는 사용자 정의)가 있는 목어 카운터, 5가지 톤, 선택적 챈트 라이브 활동. 
3. **경전 복사**(`isutra://copy`, iOS): PencilKit 추적 — 잉크/펜 스타일, 실행 취소, 줄당 초안, PNG/PDF 내보내기(획은 장치에 유지됨). 
4. **연습** (`isutra://practice`): 아침/저녁 체크리스트 및 헌정문; 체크리스트 구성을 위한 선택 사항 iCloud. 

### 7. 위젯, Siri 및 홈 화면 바로가기

1. 홈화면 길게 누르기 → **위젯 편집** → **일경/명언/공부진행/즐겨찾기/오늘의 찬송**을 추가합니다. 
2. **시리**에게 오늘의 경전, 암송, 무작위, 즐겨찾기, 공부, 사냥, 독창, 복사, 검색을 요청하세요. 
3. **설정 → 바로가기**에서 홈 화면 빠른 동작을 구성합니다. 
4. 제어 센터 제어(iOS 18+)에는 오늘/무작위/검색/공부/사냥/찬트/연습/복사 등이 포함됩니다. 

### 8. 개인정보 보호 및 동기화 

1. 도서관, 독서, 암송(시스템 TTS), 공부, 성가, 연습, 위젯, 지역 알림 등이 설치 후 **완전히 오프라인**으로 작동합니다. Copy-sutra는 iOS 전용이며 스트로크를 로컬에 저장합니다. 
2. 옵션 **iCloud 동기화**는 **비공개 iCloud**를 통해 즐겨찾기, 목록, 기록, 숙달, 메모, 성가 기본 설정 및 연습 구성을 미러링합니다. 
3. 개발자(StoreKit 옵션)는 페이월 콘텐츠를 잠금 해제하거나 계정을 생성하지 않는다는 점을 알려주세요.
