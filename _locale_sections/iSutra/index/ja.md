**電話は 1 台。 無数のお経**

 iSutra (爱佛经 / 愛佛經) は **没入型の読経および練習スタジオ** であり、別のプレーン テキスト ダンプではありません。 **アカウントは必要ありません。** **144 項目**のオフライン インデックスには、頻繁に誦誦される古典 (般若心経、32 部の金剛経、阿弥陀経、薬師如来の誓い、普遍の門、13 章の地蔵、マントラ、壇経の抜粋、42 章、八つの目覚めなど) が含まれており、**バイリンガルの読書**、**現地語**、 **101** の有名なセリフ。 **暗唱**し、段落を強調表示します。 **学習ホール**で練習します。 **木魚の詠唱カウンター**をタップします。 **PencilKit トレースで**写経** (iOS); **朝夕の練習**を熱心に続けてください。 コンテキストに応じた **Daily Sutra** を開きます。 **ダルマ カード**をエクスポートし、**ウィジェット**、オプションの**朗読/詠唱ライブ アクティビティ**、**Siri とショートカット**、およびオプションの**iCloud**を追加します。 テキストは **学習および教育用** を目的としています。 **広告はありません。 追跡はありません。 Data Not Collected.**

**概要:** 144 インデックス ライブラリ · ダイヤモンドとディザンの大ボリューム · バイリンガルの読書 · 暗唱 · 詠唱 · 写経 · 実践 · 毎日の経典 · 101 行 · ダルマ カード · ウィジェット · コントロール センター · `isutra://` · EN / 简 / 繁。 

## はじめに (ステップバイステップ)

 ### 1. 最初の起動

 1. [App Store](https://apps.apple.com/app/id6796014949) からインストールし、**iSutra** を開きます。 
2. **ウェルカム ガイド** (ブランド → バイリンガル リーディング → 暗唱 → 学習/チャント → 練習 → プライバシー) を完了します。 
3. いつでも再生できます: **[設定] → [ヘルプ] → [機能ガイド]** (`isutra://feature-guide`)。 
4. アプリ内の**使用法 / ウィジェット / ショートカット** ガイドは、**設定 → ヘルプ** に表示されます。 

### 2. ホームで今日のお経を読んでください

 1. [**ホーム**] タブを開きます。 
2. **日刊経**の主人公が今日の一節を示しています。 タップして詳細を開きます。 
3. オプション: [設定] で **毎日の経典通知** をオンにします (ローカル スケジュールのみ)。 
4. ワンタップで続きを読む、名セリフ、スジ、ショートカット（暗唱/勉強/狩り/詠唱/コピー/練習）が可能です。 

### 3. 参照と検索

1. **参照** を開きます (デフォルトでオン。設定で非表示にできます)。 
2. **コレクション** (般若 / 蓮華 / アヴァタムサカ / 浄土 / 地蔵菩薩 / 密教 / 禅 / 四十二 / 八覚)、テーマ、有名なセリフ、翻訳者、およびすべてのエントリを探索します。 大きな本のシェルは、ボリュームのあるカタログを開きます。 
3. **検索**を使用して、タイトル、行、および言語 (簡体字/繁体字対応) を検索します。 iOS では、オプションの **手書き写経検索** により、デバイス上の文字が認識されます。 
4. **お気に入り**にスターを付けます。 個人的な **経典リスト** (经单) を作成します。 [お気に入り] タブは **デフォルトでオンになっています**。 

### 4. バイリンガルリーディングとダルマカード

 1. 詳細で、**バイリンガル/中国語のみ/英語のみ**を選択します。 母国語、英語、ピンインを個別に切り替えます。 
2. 長い章については、**没入型読書**、縦型レイアウト、フォント スケール、**分割ページ**を試してください。 
3. **共有カード (法卡)** を開き、スタイル / 比率を選択し、写真 (追加専用) またはシステム共有に保存します。 
4. オプション: iPhone で **ライブ アクティビティの読み取り** を有効にします (フォアグラウンドで開始)。 

### 5. 朗読（诵经）

1. 詳細で、[**朗読**] をタップするか、朗読ワークベンチを開きます。 
2. 聞きながら**段落の強調表示**に従ってください。 
3. **[設定] → [朗読と朗読]** で、*表示内容*とは独立して、**再生コンテンツ マトリックス** (オリジナル / 現地語 / 英語) を設定します。 
4. オプション: サイレント モード再生、バックグラウンド オーディオ + 再生中、チャプター部分にわたる連続再生、画面をオンのままにします。 

### 6. スタディホール、チャント、コピー、練習

 1. **勉強** (`isutra://study`): 暗唱 / 穴埋め / セルフチェック / クイズ、および **ハント (寻经)**。 
2. **チャント** (`isutra://count`): 目標付き木魚カウンター (27 / 54 / 108 / 1080 またはカスタム)、5 つのトーン、オプションのチャント ライブ アクティビティ。 
3. **写経** (`isutra://copy`、iOS): PencilKit トレース — インク/ペン スタイル、元に戻す、行ごとのドラフト、PNG/PDF エクスポート (ストロークはデバイス上に残ります)。 
4. **練習** (`isutra://practice`): 朝/夕方のチェックリストと献身的なテキスト。 チェックリスト構成のオプション iCloud。 

### 7. ウィジェット、Siri、ホーム画面のショートカット

1. ホーム画面を長押し→**ウィジェットの編集**→**毎日のお経/名セリフ/勉強の進み具合/お気に入り/今日のお経**を追加します。 
2. **Siri** に今日のお経、朗読、ランダム、お気に入り、勉強、狩り、詠唱、写経、または検索を尋ねます。 
3. **[設定] → [ショートカット]** でホーム画面のクイック アクションを構成します。 
4. コントロール センター コントロール (iOS 18+) には、Today / Random / Search / Study / Hunt / Chant / Practice / Copy などが含まれます。 

### 8. プライバシーと同期

 1. 図書館、読書、暗唱 (システム TTS)、学習、聖歌、練習、ウィジェット、およびローカル通知は、インストール後 **完全にオフライン**で機能します。 Copy-sutra は iOS のみであり、ストロークをローカルに保存します。 
2. オプションの **_iCloud Sync** は、お気に入り、リスト、履歴、マスタリー、メモ、チャント設定、および練習設定を **あなたのプライベート iCloud** を通じてミラーリングします。 
3. 開発者 (オプションの StoreKit) は、ペイウォールで保護されたコンテンツのロックを解除したり、アカウントを作成したりすることはありません。 

## ダウンロードする理由

- **本物の練習スタジオ** — 1 つのネイティブ アプリで、毎日の典礼を読んだり、暗唱したり、唱えたり、コピーしたり、記録したりできます。 
- **本格的なオフライン ライブラリ** — ハート / ダイヤモンド / ディザン / マントラなど、分割ごとに大量のボリュームがロードされます。 
- **役立つシステム機能** - ウィジェット、ライブ アクティビティ、コントロール センター、Siri、ディープ リンク、オプションの iCloud。 
- **設計によるプライバシー** — アカウント、広告、分析 SDK はありません。 パブリックドメインのテキストの教育的使用。

 ### 経工房
 - **144** のインデックス エントリ · 現地語 · バイリンガルの配置 · **101** の有名なセリフ
 - コレクション、テーマ、翻訳者、没入型読書、ダーマ カード

 - 再生コンテンツマトリックスを備えたカラオケスタイルの TTS
 - スタディホールの4つのモード+ハント・マスタリーバッジ
 - ゴール、トーン、チャントライブアクティビティ付きの木魚のチャント
 - PencilKit 写経 (iOS) PNG / PDF エクスポート付き

 ### 毎日のお経とシステムの特徴
 - 文脈日常経・ローカル通知
 - ウィジェット · コントロールセンター · Siri · ディープリンク — [ショートカットリンク](url-scheme)を参照してください。 
- オプションのスポットライト · オプションの iCloud 同期

 - **アカウントなし、広告なし、分析 SDK なし**

 - オプションのプライベート iCloud KVS
