iLvShi (爱吕氏春秋 / 爱吕氏春秋) เป็น**สตูดิโอ Lüshi Chunqiu แบบออฟไลน์**—ไม่ใช่การทิ้งข้อความธรรมดาอื่น** ไม่จําเป็นต้องมีบัญชี** คลัง *Lüshi Chunqiu* จะมาพร้อมกับอุปกรณ์ของคุณด้วย **ต้นฉบับ / โน้ต Gao You / ภาษาท้องถิ่น / ภาษาอังกฤษ (สี่เลเยอร์)** เริ่มต้นด้วย **Daily Passage** **Recite** ด้วยการไฮไลท์ย่อหน้า ฝึกฝนใน **Spring-Autumn Study** เล่น **Autumn Hunt** ส่งออก **การ์ดฤดูใบไม้ร่วง** เพิ่ม **วิดเจ็ต**, ตัวเลือก **การอ่านกิจกรรมสด**, **Siri & Shortcuts** และตัวเลือก **iCloud** ต้นฉบับเป็นข้อความการศึกษาในโดเมนสาธารณะ; โน้ตเป็นเครื่องมือการศึกษา** ไม่มีโฆษณา ไม่มีการติดตาม Data Not Collected**

**ดูแบบคร่าวๆ : ** 160 บท · ประมาณ 1061 ส่วน · 100 บรรทัดที่มีชื่อเสียง ·  Almanac (กฎประจําเดือน) · ต้นฉบับ / บันทึกของเกาโย่ว / ภาษาท้องถิ่น / ภาษาอังกฤษ (สี่ชั้น) · ท่อง · Spring-Autumn Study · Autumn Hunt · Daily Passage · การ์ดฤดูใบไม้ร่วง · วิดเจ็ต · Control Center · `ilvshi://` · EN / สั้น / หนา

## การเริ่มต้น (ทีละขั้นตอน)

### 1. การเปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store] (https://apps.apple.com/app/id6808957717) และเปิด **iLvShi**
2. เสร็จสิ้นคู่มือต้อนรับ (การอ่านประจําวัน → การอ่านปิด → การท่อง → การศึกษา → คุณสมบัติของระบบ → ความเป็นส่วนตัว)
3. เล่นซ้ําได้ทุกเมื่อ: **การตั้งค่า → วิธีใช้ → คู่มือคุณสมบัติ** (`ilvshi://feature-guide`)
4. คู่มือการใช้งาน / วิดเจ็ต / คําสั่งลัดอยู่ภายใต้ **การตั้งค่า → วิธีใช้**

### 2. อ่านส่วนของวันนี้บน Home

1. เปิดแท็บ **Home**
2. ตัวเอก **Daily Passage** แสดงเส้นทางของวันนี้ แตะเพื่อเปิดรายละเอียด
3. ไม่บังคับ: เปิดใช้งานการแจ้งเตือน **Daily Passage** ในพื้นที่ในการตั้งค่า
4. กระโดดจาก Home ไปยัง Recitation, Spring-Autumn Study, Autumn Hunt, Favorites และ Search

### 3. เรียกดูและค้นหา

1. เรียกดู *Lüshi Chunqiu* ทั้งหมด บรรทัดที่มีชื่อเสียง และชั้นวางพิเศษ
2. ค้นหาชื่อเรื่องและบรรทัด (ง่ายขึ้น / สะดวกแบบดั้งเดิม) บน iOS การค้นหาลายมือเขียน** ทางเลือก** จะจดจําอักขระบนอุปกรณ์
3. ติดดาวย่อหน้าลงใน **รายการโปรด** และรวบรวมลงใน **รายการฤดูใบไม้ร่วงส่วนบุคคล**

### 4. ปิดการอ่านและการแชร์การ์ด

1. สลับ **สองภาษา / เฉพาะภาษาจีน / เฉพาะภาษาอังกฤษ**; สลับเลเยอร์อย่างอิสระหากมี
2. ลองอ่านแบบสมจริง เค้าโครงแนวตั้ง ขนาดแบบอักษร และหน้าแบบแบ่งส่วนสําหรับส่วนที่ยาวขึ้น
3. เปิด **การ์ดฤดูใบไม้ร่วง** → เลือกสไตล์ / อัตราส่วน → บันทึกไปยังรูปภาพ (เพิ่มเท่านั้น) หรือการแชร์ระบบ

### 5. การท่องและศึกษาฤดูใบไม้ผลิ-ฤดูใบไม้ร่วง

1. เปิดเวิร์กเบนช์การท่องเพื่อค้นหา TTS ที่ไฮไลท์ไว้ เสียงและจังหวะที่ปรับได้ คําบรรยายภาษาท้องถิ่น/ภาษาอังกฤษแบบไม่บังคับ การเล่นต่อเนื่อง และเสียงพื้นหลัง
2. **การศึกษาฤดูใบไม้ผลิ-ฤดูใบไม้ร่วง** (`ilvshi://study`): จางจาง, เติมว่าง, ทดสอบตนเอง และท้าทาย พร้อมการติดตามความเชี่ยวชาญ
3. **Autumn Hunt** on Home เป็นเกมค้นหาส่วนแยกต่างหาก

### 6. วิดเจ็ต, Siri และคุณสมบัติของระบบ

1. เพิ่มวิดเจ็ต Daily / Famous Line / Favorites / Study Progress (และ Almanac หากมี)
2. ใช้ศูนย์ควบคุม, Siri, Spotlight และ `ilvshi://` ลิงก์ลึก
3. กิจกรรมการอ่านสดแบบไม่บังคับยังคงมีให้ใช้งานบนอุปกรณ์ที่รองรับ iPhone

### 7. ความเป็นส่วนตัวและการซิงค์

1. คลัง, การอ่าน, การท่อง (ระบบ TTS), การศึกษา, วิดเจ็ต และการแจ้งเตือนในเครื่องจะทํางานแบบออฟไลน์อย่างสมบูรณ์หลังจากติดตั้ง
2. ตัวเลือก**iCloud Sync** สะท้อนรายการโปรด รายการ ประวัติ ความคืบหน้า เส้น และโน้ตผ่าน**iCloud**ส่วนตัวของคุณ
3. เคล็ดลับสําหรับนักพัฒนา (ไม่บังคับ StoreKit) ไม่ควรปลดล็อค Paywall และไม่ควรสร้างบัญชี
