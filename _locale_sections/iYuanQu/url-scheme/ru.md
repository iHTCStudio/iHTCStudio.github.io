iYuanQu поддерживает **`iyuanqu://`** — ссылки-ярлыки.

## Формат ссылки


```
iyuanqu://{host}?{params}
```


## Работы и открытия

| URL | Открывает |
|-----|-------|
| `iyuanqu://work?id=1` | Qu Detail (например, id 1) |
| `iyuanqu://daily` | Ежедневный qu |
| `iyuanqu://last-read` | Последнее чтение qu |
| `iyuanqu://search?q=秋` | Поиск работ, содержащих |

## Навигация

| URL | Открывает |
|-----|-------|
| `iyuanqu://home` | Главная |
| `iyuanqu://categories` | Категории |
| `iyuanqu://categories?section=gongdiao` | Категория:Прыжок в раздел |
| `iyuanqu://favorites` | Избранное |
| `iyuanqu://settings` | Настройки |
| `iyuanqu://reading-history` | История чтения |

## Руководства и отзывы

| URL | Открывает |
|-----|-------|
| `iyuanqu://usage-guide` | Руководство по использованию |
| `iyuanqu://widget-guide` | Руководство по виджетам |
| `iyuanqu://shortcuts-guide` | Руководство по «Командам» |
| `iyuanqu://feature-guide` | Обзор функций |
| `iyuanqu://feedback` | Письмо с отзывом |
| `iyuanqu://in-app-review` | Обзор в приложении |
