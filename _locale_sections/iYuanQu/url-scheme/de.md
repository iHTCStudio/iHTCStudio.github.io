iYuanQu unterstützt **`iyuanqu://`**-Verknüpfungslinks.

## Linkformat


```
iyuanqu://{host}?{params}
```


## Werke und Entdeckungen

| URL | Öffnet |
|-----|-------|
| `iyuanqu://work?id=1` | Detail Qu (z. B. ID 1) |
| `iyuanqu://daily` | Täglicher Qu |
| `iyuanqu://last-read` | Zuletzt gelesen qu |
| `iyuanqu://search?q=秋` | Suche nach Werken, die 秋 enthalten |

## Navigation

| URL | Öffnet |
|-----|-------|
| `iyuanqu://home` | Startseite |
| `iyuanqu://categories` | Kategorien |
| `iyuanqu://categories?section=gongdiao` | Kategorien, springen zu einem Abschnitt |
| `iyuanqu://favorites` | Favoriten |
| `iyuanqu://settings` | Einstellungen |
| `iyuanqu://reading-history` | Leseverlauf |
