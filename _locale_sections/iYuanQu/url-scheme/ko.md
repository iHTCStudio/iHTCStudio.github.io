iYuanQu는 **`iyuanqu://`** 바로가기 링크를 지원합니다.

## 링크 형식


```
iyuanqu://{host}?{params}
```


## 작품 및 발견

| URL | 열리는 화면 |
|-----|-------|
| `iyuanqu://work?id=1` | 예시 (예 : id 1) |
| `iyuanqu://daily` | 매일 쿼 |
| `iyuanqu://last-read` | 최근 읽음 |
| `iyuanqu://search?q=秋` | 작품 검색 秋 |

## - 연혁

| URL | 열리는 화면 |
|-----|-------|
| `iyuanqu://home` | 홈 |
| `iyuanqu://categories` | 1명2명3명4명5명5명6명7명9명～ |
| `iyuanqu://categories?section=gongdiao` | 카테고리, 섹션으로 이동 |
| `iyuanqu://favorites` | 즐겨찾기 |
| `iyuanqu://settings` | 설정 |
| `iyuanqu://reading-history` | 읽기 기록 |
