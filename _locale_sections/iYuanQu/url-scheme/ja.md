iYuanQu は **`iyuanqu://`** ショートカットリンクに対応しています。

## リンク形式


```
iyuanqu://{host}?{params}
```


## 作品と発見

| URL | 開く画面 |
|-----|-------|
| `iyuanqu://work?id=1` | 数量(例:id 1) |
| `iyuanqu://daily` | デイリーク |
| `iyuanqu://last-read` | 最後の読み込み qu |
| `iyuanqu://search?q=秋` | 秋を含む作品の検索 |

## ナビゲーション

| URL | 開く画面 |
|-----|-------|
| `iyuanqu://home` | ホーム |
| `iyuanqu://categories` | カテゴリー |
| `iyuanqu://categories?section=gongdiao` | カテゴリー, セクションにジャンプ |
| `iyuanqu://favorites` | お気に入り |
| `iyuanqu://settings` | 設定 |
| `iyuanqu://reading-history` | 閲覧履歴 |
