iYuanQu prend en charge les liens **`iyuanqu://`**.

## Format de lien


```
iyuanqu://{host}?{params}
```


## Travaux et découverte

| URL | Ouvre |
|-----|-------|
| `iyuanqu://work?id=1` | Qu détail (par exemple id 1) |
| `iyuanqu://daily` | Qu quotidiennement |
| `iyuanqu://last-read` | Dernière lecture qu |
| `iyuanqu://search?q=秋` | Recherche d'oeuvres contenant : |

## Navigation

| URL | Ouvre |
|-----|-------|
| `iyuanqu://home` | Accueil |
| `iyuanqu://categories` | Catégories |
| `iyuanqu://categories?section=gongdiao` | Catégories, sauter à une section |
| `iyuanqu://favorites` | Favoris |
| `iyuanqu://settings` | Réglages |
| `iyuanqu://reading-history` | Historique de lecture |
