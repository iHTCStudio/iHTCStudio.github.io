iYuanQu รองรับลิงก์ทางลัด **`iyuanqu://`**

## รูปแบบลิงก์


```
iyuanqu://{host}?{params}
```


## การค้นพบงาน

| URL | เปิด |
|-----|-------|
| `iyuanqu://work?id=1` | รายละเอียด Q (e.g. id 1) |
| `iyuanqu://daily` | ทุก ๆ วัน |
| `iyuanqu://last-read` | ข้อความอ่านล่าสุด |
| `iyuanqu://search?q=秋` | ค้นหางานที่มี 秋 |

## การนําทาง

| URL | เปิด |
|-----|-------|
| `iyuanqu://home` | หน้าแรก |
| `iyuanqu://categories` | หมวดหมู่ |
| `iyuanqu://categories?section=gongdiao` | หมวดหมู่ กระโดดไปยังส่วน |
| `iyuanqu://favorites` | รายการโปรด |
| `iyuanqu://settings` | การตั้งค่า |
| `iyuanqu://reading-history` | ประวัติการอ่าน |
