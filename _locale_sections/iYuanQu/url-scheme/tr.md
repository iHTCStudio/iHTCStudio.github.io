iYuanQu, **`iyuanqu://`** kısayol bağlantılarını destekler.

## Bağlantı biçimi


```
iyuanqu://{host}?{params}
```


## Works & keşif

| URL | Açar |
|-----|-------|
| `iyuanqu://work?id=1` | Qu detay (e.g. id 1) |
| `iyuanqu://daily` | Günlük |
| `iyuanqu://last-read` | Son oku |
| `iyuanqu://search?q=秋` | 秋 |

## Navigation

| URL | Açar |
|-----|-------|
| `iyuanqu://home` | Ana sayfa |
| `iyuanqu://categories` | Kategoriler Kategoriler |
| `iyuanqu://categories?section=gongdiao` | Kategoriler, bir bölüme atlamak |
| `iyuanqu://favorites` | Favoriler |
| `iyuanqu://settings` | Ayarlar |
| `iyuanqu://reading-history` | Okuma geçmişi |
