### 앱이 완전히 오프라인 상태인가요? 

예. **8,969 qu 작품**이 모두 번들로 제공됩니다. 설치 후 앱은 **아웃바운드 네트워크 요청이 전혀 발생하지 않습니다**. 계정도, 광고도, 분석도 없습니다. 선택 사항인 iCloud는 활성화된 경우에만 Apple 서비스를 사용합니다. 

### 당/가요 앱과 어떻게 다른가요? 

iYuanQu는 **원구(元曲)에 수직**입니다. 즉, sanqu 및 zaju 아리아는 혼합 시 목록이 아닙니다. **gongdiao/qupai** 지식, **162개의 zaju 플레이 컬렉션**, **선별된 번역 및 주석**, 일일 qu, 공유 카드, 위젯 및 라이브 활동이 추가됩니다. 

### 얼마나 많은 콘텐츠가 포함되어 있나요? 

| 아이템 | 카운트 | 
|------|---------| 
| Qu 작품(전체) | 8,969 | 
| 코퍼스(원문) | ~8,934 | 
| 선별된 배지(클래식 35개 + 프로모션 10개) | 45 | 
| 번역된 레이어 | ~1,862 | 
| 저자 | 227 | 
| 공디아오 모드 | 12 | 
| 쿠파이 패턴 | 23 | 
| Zaju 플레이 컬렉션 | 162개(전체 개요 포함) | 

### 세 가지 콘텐츠 등급이란 무엇인가요? 

- **말뭉치** — 원본 텍스트만(대부분의 작품) 
- **번역됨** — 번역 및/또는 주석 추가(목록에 배지) 
- **선별** — 번역 + 주석 + 감사(인감 배지, 45개) 

### 모든 작품에 번역이 있나요?

번호 **45개 작품**에는 전체 번역 + 주석 + 감상이 포함된 선별된 배지(클래식 35개 + 프로모션 10개)가 표시됩니다. 약 **1,862** 작품이 번역된 레이어에 있습니다. 나머지는 원문을 보여줍니다. 이는 의도적인 것입니다. 이 앱은 모든 아리아의 전체 학술 버전이 아니라 독서 및 발견 스튜디오입니다. 

### 자주극을 연속해서 읽으려면 어떻게 해야 하나요? 

**카테고리 → 플레이(명剧)**로 이동하세요. 드라마를 선택하세요(예: *Dou E Yuan*). 모든 아리아는 순차적으로 읽을 수 있도록 원막 순서대로 나열되어 있습니다. 162편의 희곡은 모두 상단에 시놉시스를 보여준다. 

### Daily Qu는 어떻게 작동하나요? 

매일 선별된 작품이 선택됩니다. **홈**에서 열고, 오늘의 풀에서 다른 선택을 위해 새로고침하고, 앱을 한 번 연 후 **Daily Qu** / **인용** 위젯에서 볼 수 있습니다. 

### 글꼴 크기는 어떻게 변경하나요? 

**설정 → 읽기** 슬라이더 또는 **세부정보 → 더보기 → 글꼴 크기**. 범위 **50%~300%**; 활성화된 경우 iCloud를 통해 동기화됩니다. 

### 세로 읽기와 병음은 어떻게 작동하나요? 

**설정 → 읽기**에서 전체적으로 켜세요. 모든 작업 세부정보에서 전역 기본값을 변경하지 않고도 해당 세션에 대한 병음 또는 세로 레이아웃을 **재정의**할 수 있습니다. 

### 소리내어 읽기(TTS)는 어떻게 작동하나요?

세부정보 도구 모음에서 **스피커** 아이콘을 탭하세요. 기기 내 음성 합성을 사용합니다. 동일한 버튼으로 일시 중지하고 다시 시작하세요. 

### 몰입형 독서란 무엇인가요? 

**세부 정보 → 더보기 → 몰입형 독서**는 크롬이 없는 전체 화면 페이지를 엽니다. 큰 화면에서 낭독하거나 발표하는 데 적합합니다. 

### 즐겨찾기와 재생목록은 어떻게 다릅니까? 

**즐겨찾기** = 별표 표시된 작품(탭 한 번 ♥). **재생 목록** = 귀하가 생성한 사용자 지정 이름 목록; 작품은 여러 재생목록에 포함될 수 있습니다. 세부정보에서 **재생목록에 추가**를 사용하거나 즐겨찾기 페이지에서 일괄 선택하세요. 

### 즐겨찾기를 일괄 편집하려면 어떻게 해야 하나요? 

**즐겨찾기 → 편집** → 여러 작품 선택 → 즐겨찾기 삭제 또는 재생목록에 추가합니다. 빠르게 제거하려면 행을 왼쪽으로 스와이프하세요. 

### 독서기록은 어디에 있나요? 

**설정 → 데이터 → 읽기 기록** — 상대 시간을 포함한 최대 100개 항목. **마지막으로 읽은** 빠른 작업 또는 `iyuanqu://last-read`에서 계속하세요. 

### 어떤 공유 카드 스타일이 있나요? 

12가지 스타일: 클래식, 잉크, 미니멀, 수직, 진사, 다크, 청자, 황토색, 백설공주, 두루마리, 달백색, 대나무 그림자. 전문이나 발췌문을 선택하세요. PNG를 내보냅니다. 

### 어떤 위젯을 사용할 수 있나요?

| 위젯 | 목적 | 
|---------|---------| 
| 데일리 큐 | 오늘의 하이라이트 작품 | 
| 견적 | 유명한 노선 | 
| 공디아오 지식 | 매일 공디아오 팁 → 오픈 카테고리 | 

크기: 홈 화면의 소형/중형/대형; 잠금 화면 직사각형 또는 인라인. 중/대형 일일 Qu 및 견적에는 **셔플**이 있습니다. iOS 18+ **제어 센터**는 일일, 무작위, 검색을 제어합니다. 

### 위젯에 잘못된 텍스트 또는 빈 텍스트가 표시됩니까? 

1. 설치 후 앱을 한 번 실행해 보세요. 
2. 언어 변경 후 앱을 잠시 열어 위젯 캐시를 새로고침하세요. 
3. 시스템 설정에서 iYuanQu에 위젯이 허용되는지 확인하세요. 

### 품曲 라이브 액티비티란? 

세부 정보 페이지에서 **앱을 종료**할 때 읽고 있는 내용을 선택적으로 동적 섬/잠금 화면에 표시합니다. **기본적으로 꺼져 있음** — **설정 → 읽기**에서 활성화하세요. 앱으로 돌아가면 종료됩니다. 

### 어떤 Siri 단축키가 있나요? 

매일 qu, 즐겨찾기, 검색, 무작위 선별 작품을 엽니다. 설정에서 **홈 화면 빠른 작업**(최대 4개)을 구성하세요. 

### iCloud 동기화에는 어떤 내용이 포함되나요? 

즐겨찾기, 재생 목록, 읽기 기록, 글꼴 크기 — 테마, 악센트 또는 빠른 동작 선택 **아님**. 

### 중국어 번체 디스플레이?

UI에는 전용 **繁體中文** 문자열이 있습니다. 코퍼스 텍스트는 중국어 간체로 저장되며 중국어 번체 모드의 경우 **표시 시 변환**됩니다. 데이터베이스 사본 두 개가 필요하지 않습니다. 

### 탭을 숨길 수 있나요? 

예. **설정 → 탭 표시줄** — 카테고리 및/또는 즐겨찾기 탭을 전환합니다. 



### 지원팀에 어떻게 문의하나요? 

[AppleOSer@gmail.com](mailto:AppleOSer@gmail.com) — 일반적으로 48시간 이내에 답변을 드립니다.

설정 → 읽기에서 **연속 읽기**를 활성화하세요. 작업이 TTS를 마치면 하단 표시줄이 나타납니다. 몇 초 동안 유휴 상태가 되면 현재 대기열의 다음 부분이 시작됩니다. 제목과 본문은 동일한 길게 누르기 메뉴(복사/번역/말하기/카드 공유)를 공유합니다. 매일 qu는 **지역 알림** 알림을 보낼 수 있습니다.

## 2부 — 작품 찾기(6가지 탐색 방법) 

**카테고리** 탭을 엽니다. 6개 섹션을 통해 다양한 각도에서 라이브러리를 탐색할 수 있습니다. 

### 1. 테마(主题) 

사랑, 자연, 이별, 철학 등 주제별로 분류된 엄선된 컬렉션입니다. 테마를 탭하면 해당 작품을 볼 수 있습니다. 

### 2. 작가(명가) 

**227명의 저자**, 전기 포함. 프로필과 전체 작품 목록을 보려면 작성자를 탭하세요. 옵션 메뉴(**목록**, **그리드** 또는 **카드**)를 사용하여 레이아웃을 전환합니다. iPhone 및 iPad에서 그리드 열을 별도로 조정합니다. 

### 3. 플레이 / Zaju(명剧)

**162개의 자주극** — **연속 읽기**를 위해 그룹화된 동일한 드라마의 아리아(예: *The Injustice to Dou E*, 38개 세그먼트). **전체 162개 극**에는 상단에 시놉시스(제목, 작가, 줄거리 요약)가 포함되어 있습니다. 이는 개별 아리아를 찾기보다는 전체 연극을 순서대로 읽고 싶을 때 이상적입니다. 

### 4. 공도(宫调) 

**12개의 공디아오 모드** — 원 운문의 조 체계(예: 仙吕, 南吕, 越调). 각 항목은 기분과 특징을 설명합니다. 해당 모드의 모든 작품을 보려면 탭하세요. 

### 5. 쿠파이(曲牌) 

**23 qupai** — 고정된 곡 패턴(예: 天净沙, 山坡羊). 패턴을 배우고 해당 곡으로 작성된 작품을 찾아보세요. 

### 6. 전체 카탈로그(전체) 

전체 **8,969개 작품** 지수. 하나의 스크롤 가능한 목록에 모든 항목을 포함하려는 경우에 사용하세요. 

### 레이아웃 및 필터 옵션 

카테고리 또는 작성자 페이지에서 **⋯** 메뉴를 탭하세요. 

- **레이아웃** — 목록/그리드/카드 
- **섹션 공개 상태** — 6개 섹션 중 하나를 표시하거나 숨깁니다. 
- **정렬 순서** — 섹션이 표시되는 방식을 재정렬합니다. 
- **그리드 열** — iPhone의 경우 2~4개, iPad의 경우 2~4개(별도 기억) 

### 홈 단축키 

**홈**에서는 테마 및 작성자 카드에 미리보기가 표시됩니다. **모두 보기**를 탭하면 카테고리로 이동하여 해당 섹션으로 바로 이동할 수 있습니다. 

### 찾다

**검색**을 열고 **제목**, **줄**, **저자**와 일치하는 키워드를 입력하세요. iOS에서는 선택적 **필기 아리아 검색**이 기기의 문자를 인식합니다. 결과로 작업 세부정보 페이지가 열립니다. Siri 또는 `iyuanqu://search?q=…`([바로가기 링크](../url-scheme) 참조)를 통해 도착할 수도 있습니다.

## 3부 - 콘텐츠 수준 이해하기 

모든 저작물에 편집 내용의 깊이가 동일한 것은 아닙니다. 목록 행과 세부정보 헤더에서 **배지**를 찾으세요. 

| 레벨 | 배지 | 당신이 보는 것 | 
|-------|-------|---| 
| **코퍼스** | (없음) | 원본 텍스트만 — 8,932개 코퍼스 작품의 대부분 | 
| **번역됨** | 번역 뱃지 | 원본 + 번역 및/또는 주석 | 
| **선별** | 엄선된 씰 | 번역 + 주석 + 감상 (큐레이트 뱃지 45개) | 

상세페이지에 **번역/주석/감상** 섹션은 해당 레벨의 콘텐츠가 존재할 때만 나타납니다. 읽는 동안 각 섹션을 켜거나 끕니다. 

> 선별되고 번역된 콘텐츠는 **학습용으로 편집 준비**되어 있습니다. 말뭉치 텍스트는 자동 정리 기능을 통해 과거 컬렉션에서 가져옵니다. 주석은 학술적 인용이 아닌 참고용입니다.

## 파트 4 — 작품 읽기 (상세 페이지)

작품을 탭하여 **작품 상세**를 엽니다. 이것이 핵심 읽기 경험입니다.

### 툴바 (오른쪽 상단)

| 버튼 | 동작 |
|--------|--------|
| **♥** | 즐겨찾기에 추가하거나 제거 (별표 표시 시 강조 색상 사용) |
| **스피커** | **TTS 읽어주기** 시작; 다시 탭하면 일시정지 / 재개 |
| **⋯ 더 보기** | 액션 메뉴 열기 (아래 참조) |

### 더보기 메뉴 (⋯)

| 항목 | 기능 |
|------|----------------|
| **글꼴 크기** | 스케일링 패널 열기 (50%–300%, 기본 22 pt) |
| **몰입형 읽기** | 전체 화면, 방해 요소 없는 보기 |
| **재생목록에 추가** | 기존 재생목록 선택 또는 즉석에서 생성 |
| **전체 텍스트 복사** | 작품 전체를 클립보드로 복사 |
| **텍스트 공유** | 일반 텍스트로 시스템 공유 시트 열기 |
| **공유 카드 생성** | 12가지 스타일의 이미지 카드 편집기 열기 |

### 읽기 옵션

- **병음** — 설정의 전역 기본값입니다. 세부적으로 작품별로 재정의 
- **수직 레이아웃** — 전통적인 위에서 아래로 읽기; 작업당 재정의 
- **원본 텍스트 중앙에** — 기본적으로 켜져 있습니다. 기본 텍스트 블록을 정렬합니다. 
- **시스템 번역**(iOS 17.4+) — 선택한 텍스트에 대한 Apple의 번역 패널 
- **섹션 전환** — 가능한 경우 번역, 주석, 감사 표시/숨기기 

### 몰입형 독서 

더 보기 메뉴에서 **몰입형 독서**를 선택하면 깔끔한 전체 화면 페이지를 볼 수 있습니다. iPad에서 낭독하거나 발표하는 데 적합합니다. 

### 목록 행을 길게 누르기 

어떤 작업 목록에서든 행을 **길게 눌러** 빠른 작업을 수행할 수 있습니다. **즐겨찾기**, **소리내어 읽기**, **재생목록에 추가**, **공유** 또는 **기록에서 제거**(기록 보기에서).

## 5부 - 매일 Qu(每日一曲) 

### 집에서 

**Daily Qu** 카드에는 오늘의 하이라이트 부분이 표시됩니다. 전체 작품을 읽으려면 탭하세요. 

### 새로고침 

**새로고침**(가능한 경우)을 당기거나 탭하여 오늘 선별된 풀에서 다른 작품을 가져오세요. 내일까지 기다리지 않고 다른 추천을 원하는 경우 유용합니다. 

### 위젯 동기화

앱이 실행될 때(그리고 언어를 변경할 때) 오늘의 qu를 **앱 그룹** 저장소에 기록하므로 **Daily Qu** 및 **Quote** 위젯이 동기화 상태로 유지됩니다. 네트워크가 필요하지 않습니다.

## 파트 6 — 즐겨찾기, 재생 목록 및 기록 

### 즐겨찾기 

원하는 작업에서 **♥**를 누르거나 → **즐겨찾기**를 길게 누르세요. **즐겨찾기** 탭을 열어 별표 표시된 모든 작품을 확인하세요. 

### 일괄 편집 

즐겨찾기 페이지에서 **수정**을 탭하세요. 

- **다중 선택**은 체크 표시와 함께 작동합니다. 
- **모두 선택 / 모두 선택 취소** 
- 즐겨찾기에서 **일괄 삭제**(확인 후) 
- **재생목록에 일괄 추가** 

빠른 **제거** 작업을 수행하려면 행을 왼쪽으로 스와이프하세요. 

### 재생목록(曲单) 

작품을 사용자 정의 목록으로 정리하세요: 

1. **즐겨찾기** 탭 → **재생목록**을 탭하거나 세부정보에서 **재생목록에 추가**를 사용하세요. 
2. 새 재생목록을 **만들거나** 기존 재생목록을 확인하세요. 
3. 재생목록 관리자에서 재생목록 **이름 바꾸기** 또는 **삭제** 
4. 동일한 **재생 목록에 추가** 시트는 단일 작품 또는 일괄 선택에 적용됩니다. 

### 읽은 이력 

**설정 → 데이터 → 읽은 기록**에는 최근 본 작품을 **상대 시간**(예: "2시간 전")으로 최대 **100**개까지 표시합니다.

- 행을 탭하여 **읽기 계속**
- 왼쪽으로 스와이프하여 항목 삭제
- 확인 후 **모두 지우기**
- **홈 화면 빠른 실행** "마지막 읽은 글"과 딥 링크 `iyuanqu://last-read`는 기록이 있을 때 여기로 이동

## 8부 — 위젯 (단계별)

### 홈 화면에 위젯 추가

1. 홈 화면 길게 누르기 → **홈 화면 편집** → **+** 탭
2. **iYuanQu** / **爱元曲** 검색
3. 위젯 유형 및 크기 선택 → **위젯 추가**

### 위젯 유형

| 위젯 | 크기 | 행동 | 
|---------|-------|----------| 
| **데일리 큐** | 소형 / 중형 / 대형 + 잠금화면 직사각형 | 오늘의 qu를 표시합니다. 크게는 전체 분할된 텍스트를 표시합니다. 중형/대형의 **셔플** 버튼으로 오늘 선별된 다른 작품 선택 | 
| **인용문** | 소형 / 중형 / 대형 + 잠금화면 인라인/직사각형 | 유명한 대사; 중형/대형 셔플 | 
| **공디아오 지식** | 소형 / 중형 + 잠금화면 직사각형 | 하루에 하나의 공디아오 항목을 순환합니다. 탭하면 열립니다 카테고리 → Gongdiao | 

### 잠금 화면 위젯 

위젯을 추가할 때 **잠금 화면** 사용자 정의 페이지로 전환하고 iYuanQu 직사각형 또는 인라인 액세서리를 선택하세요. 

### 위젯 테마 

**설정 → 위젯 → 앱 테마 따르기** — 위젯은 밝은/어두운/악센트 선택과 일치할 수 있습니다. 

### 제어 센터(iOS 18+) 

설정 → 제어 센터에서 **오늘의 Qu**, **Random Curated** 및 **검색**에 대한 제어를 추가하세요. 

### 위젯 문제 해결 

- 설치 후 앱을 한 번 실행하면 매일 qu 캐시가 기록됩니다. 
- 언어 변경 후 텍스트가 잘못 보이는 경우 앱을 잠시 엽니다. 위젯 캐시가 자동으로 새로 고쳐집니다. 
- 새로운 일일 질문을 위해 위젯이 자정에 새로 고쳐집니다.

## 9부 — Siri, 단축키 및 홈 화면 작업 

### Siri 문구 

예(정확한 표현은 시스템 언어에 따라 다를 수 있음): 

- "iYuanQu의 오늘의 qu" 
- "iYuanQu에서 즐겨찾기 열기" 
- "iYuanQu에서 무작위로 선별된 qu" 
- "iYuanQu에서 검색" 

### 홈 화면 빠른 작업 

앱 아이콘을 길게 누르세요. 기본적으로 **Daily Qu**, **마지막 읽기**, **즐겨찾기** 등이 표시될 수 있습니다. 

사용자 지정(최대 **4** 항목): **설정 → 바로가기 → 홈 화면 빠른 작업** — 일일, 마지막 읽기, 읽기 기록, 즐겨찾기, 검색, 카테고리 등에서 선택하세요. **읽은 기록**은 가능한 경우 '최근 항목 12개'와 같은 동적 자막을 표시합니다. 

### 딥링크 

[바로가기 링크](../url-scheme)의 전체 목록입니다. 예: 

- _`iyuanqu://daily` — 오늘의 큐 
- _`iyuanqu://work?id=123` — ID로 열린 작품 
- _`iyuanqu://categories?section=gongdiao` — 카테고리, Gongdiao 섹션 
- _`iyuanqu://last-read` — 중단한 부분부터 계속 

바로가기, 메모 또는 Safari에서 사용하세요. 

### 스포트라이트 

앱은 시스템 검색을 위해 처음 **1,200**의 색인을 생성합니다. Spotlight 결과를 탭하여 해당 작업을 직접 엽니다.

## 파트 10 — 라이브 활동(품曲) 

앱을 종료하면 **Dynamic Island** 및 **잠금 화면**에서 읽고 있는 내용을 표시합니다. 

### 할 수 있게 하다

**설정 → 읽기 → 품曲 라이브 활동** — **기본적으로 꺼져 있음**; 수동으로 켜십시오. 

### 나타날 때 

**라이브 활동이 활성화되어** 있고 **작업 세부정보가 열려 있는 동안 앱을 종료**하는 경우에만(앱이 백그라운드로 이동함) 작품을 연 순간부터 시작되지 **않습니다**. 

### 끝나면 

앱(포그라운드)으로 돌아가면 라이브 활동이 **자동으로 종료됩니다**.

## 파트 11 - 설정(전체 연습) 

**설정**을 엽니다. 위에서 아래로 8개 섹션: 

### 외관 

- **테마** — 밝음/어두움/시스템 
- **악센트 색상** — 10가지 잉크에서 영감을 받은 팔레트(수墨, 青瓷, 松绿, 黛蓝, 群青, 青莲, 胭脂, 朱砂, 琥珀, 赭金); 색상 견본을 탭합니다. 선택한 링 + 체크 표시 
- **언어** — 영어 / 简体中文 / 繁體中文(UI가 즉시 전환되고 말뭉치 텍스트는 단순화된 상태로 유지되며 전통 디스플레이로 변환됨) 

### 읽기 

- **글꼴 크기 슬라이더** — 50%~300% 연속 비율(자세한 내용은 추가 메뉴에서도 확인 가능) 
- **세로 읽기** — 전역 토글 
- **병음** — 기본적으로 켜져 있음 
- **원본 텍스트 중앙에** — 기본적으로 켜져 있습니다. 
- **품曲 라이브 활동** — 기본적으로 꺼져 있습니다(10부 참조). 

### 데이터

- **읽은 기록** — 기록 목록 열기 
- **iCloud 동기화** — 선택 사항; 즐겨찾기, 재생 목록, 기록, 글꼴 크기를 동기화합니다. 
- **즐겨찾기 내보내기** — 컬렉션을 파일로 공유 

### 탭바 

- **카테고리** 탭 표시 여부 전환(기본값은 켜져 있음) 
- **즐겨찾기** 탭 표시 여부 전환(기본값은 켜짐) 

### 위젯 

- 위젯별 지침이 포함된 **위젯 가이드** 링크 
- **앱 테마 따르기** 토글 

### 단축키 

- **홈 화면 빠른 작업** — 최대 4개 선택 
- **단축키 가이드** — 앱의 원탭 복사 버튼이 포함된 딥 링크 참조 

### 도움말 

- **사용 가이드** — 재생 기능 둘러보기 
- **기능 가이드** — 더 자세한 기능 카드 
- **의견 보내기** — 이메일 열기 

### 소개 

- 버전, 개발자 팁(인앱 구매 옵션), App Store 링크, 온보딩 다시보기
