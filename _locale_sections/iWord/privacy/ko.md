iHTC Studio가 iWord(爱词语 / 愛詞語)를 만들었습니다.

## 요약

**iWord는 계정이 필요 없으며 iHTC Studio 서버에 개인 데이터를 수집하지 않습니다.** 모든 콘텐츠는 로컬 SQLite 데이터베이스에 저장됩니다. 즐겨찾기와 설정에 한해 선택적으로 **iCloud 동기화**를 사용할 수 있으며, **SRS 및 학습 데이터는 기기에만 저장**됩니다. **광고 없음. 추적 없음.**

## 기기에 저장되는 데이터

| 데이터 | 용도 |
|------|---------|
| 항목 데이터베이스 | 성어, 헐후어, 수수께끼 등 107,000개 이상 |
| 즐겨찾기 | 별표를 표시한 항목 |
| 열람 기록 | 최근 본 항목 |
| SRS 진행 상황 | 복습 일정, 평가, 연속 학습 기록 |
| 퀴즈 및 게임 기록 | 점수, 오답 노트 |
| 설정 | 테마, 언어, TTS 설정 |
| 잰말놀이 녹음 | 임시 로컬 오디오 파일 |

## iCloud 동기화

개인 iCloud를 통해 즐겨찾기와 설정을 동기화하는 선택 기능입니다. **학습 진행 상황은 동기화되지 않습니다.** 기본값은 꺼짐입니다.
