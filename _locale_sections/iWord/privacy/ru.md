iWord (爱词语 / 愛詞語) создан студией iHTC Studio.

## Кратко

**iWord не требует учётной записи и не собирает персональные данные на серверах iHTC Studio.** Всё содержимое хранится в локальной базе данных SQLite. Необязательная **синхронизация через iCloud** охватывает только избранное и настройки — **данные SRS и обучения остаются на устройстве**. **Без рекламы. Без отслеживания.**

## Данные, хранящиеся на вашем устройстве

| Данные | Назначение |
|------|---------|
| База записей | Более 107 000 чэнъюй, сехоуюй, загадок и др. |
| Избранное | Записи, отмеченные звёздочкой |
| История просмотров | Недавно открытые записи |
| Прогресс SRS | Расписание повторений, оценки, серии занятий |
| Результаты викторин и игр | Баллы, журнал ошибок |
| Настройки | Тема, язык, параметры озвучивания (TTS) |
| Записи скороговорок | Временные локальные аудиофайлы |

## Синхронизация через iCloud

Необязательная синхронизация избранного и настроек через ваш личный iCloud. **Прогресс обучения не синхронизируется** — по умолчанию функция выключена.

## Разрешения

| Разрешение | Когда | Зачем |
|------------|------|-----|
| Микрофон | Запись скороговорок (iOS) | Сравнение вашего произношения — только временные локальные файлы |
| iCloud | Необязательная синхронизация | Синхронизация избранного и настроек |
