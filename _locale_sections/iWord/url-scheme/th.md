iWord รองรับลิงก์ทางลัด **`iword://`**

## รูปแบบลิงก์


```
iword://{host}?{params}
```


## การเรียนรู้

| URL | เปิด |
|-----|-------|
| `iword://daily` | คำประจำวัน |
| `iword://random` | รายการแบบสุ่ม |
| `iword://review` | เซสชันทบ SRS |
| `iword://learn` | ศูนย์การเรียนรู้ |

## เรียกดูและค้นหา

| URL | เปิด |
|-----|-------|
| `iword://browse` | เรียกดูทุกโมดูล |
| `iword://browse?type=idiom` | เรียกดูสำนวน |
| `iword://browse?type=xiehouyu` | เรียกดูซียู |
| `iword://entry?type=idiom&id=1` | รายการที่ระบุ |
| `iword://search` | ค้นหา |
| `iword://favorites` | รายการโปรด |

## การนำทางและคู่มือ

| URL | เปิด |
|-----|-------|
| `iword://home` | หน้าแรก |
| `iword://settings` | การตั้งค่า |
| `iword://widget-guide` | คู่มือวิดเจ็ต |
| `iword://shortcuts-guide` | คู่มือทางลัด |
| `iword://usage-guide` | คู่มือการใช้งาน |
| `iword://feature-guide` | คู่มือฟีเจอร์ |
| `iword://feedback` | อีเมลข้อเสนอแนะ |
| `iword://in-app-review` | ให้คะแนน App Store ในแอป |

### ชนิดของรายการสําหรับ `iword://` และ `iword://daily` BAR `iword://` BAR `iword://daily` .
