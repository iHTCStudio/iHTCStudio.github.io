iWord는 **`iword://`** 바로가기 링크를 지원합니다.

## 링크 형식


```
iword://{host}?{params}
```


## 학습

| URL | 열리는 화면 |
|-----|-------|
| `iword://daily` | 오늘의 단어 |
| `iword://random` | 무작위 항목 |
| `iword://review` | SRS 복습 세션 |
| `iword://learn` | 학습 센터 |

## 탐색 및 검색

| URL | 열리는 화면 |
|-----|-------|
| `iword://browse` | 모든 모듈 탐색 |
| `iword://browse?type=idiom` | 관용구 탐색 |
| `iword://browse?type=xiehouyu` | 탐색 xiehouyu |
| `iword://entry?type=idiom&id=1` | 특정 항목 |
| `iword://search` | 검색 |
| `iword://favorites` | 즐겨찾기 |
