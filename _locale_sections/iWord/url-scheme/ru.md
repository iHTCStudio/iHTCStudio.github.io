iWord поддерживает **`iword://`** — ссылки-ярлыки.

## Формат ссылки


```
iword://{host}?{params}
```


## Обучение

| URL | Открывает |
|-----|-------|
| `iword://daily` | Слово дня |
| `iword://random` | Случайная запись |
| `iword://review` | Сессия повторения SRS |
| `iword://learn` | Центр обучения |

## Обзор и поиск

| URL | Открывает |
|-----|-------|
| `iword://browse` | Обзор всех модулей |
| `iword://browse?type=idiom` | Обзор идиом |
| `iword://browse?type=xiehouyu` | Просмотреть xiehouyu |
| `iword://entry?type=idiom&id=1` | Конкретная запись |
| `iword://search` | Поиск |
| `iword://favorites` | Избранное |

## Навигация и руководства

| URL | Открывает |
|-----|-------|
| `iword://home` | Главная |
| `iword://settings` | Настройки |
| `iword://widget-guide` | Руководство по виджетам |
| `iword://shortcuts-guide` | Руководство по «Командам» |
| `iword://usage-guide` | Руководство по использованию |
| `iword://feature-guide` | Обзор функций |
| `iword://feedback` | Письмо с отзывом |
| `iword://in-app-review` | Оценка в App Store из приложения |
