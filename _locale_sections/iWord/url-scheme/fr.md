iWord prend en charge les liens **`iword://`**.

## Format de lien


```
iword://{host}?{params}
```


## Apprentissage

| URL | Ouvre |
|-----|-------|
| `iword://daily` | Mot du jour |
| `iword://random` | Entrée aléatoire |
| `iword://review` | Session de révision SRS |
| `iword://learn` | Centre d’apprentissage |

## Parcourir et rechercher

| URL | Ouvre |
|-----|-------|
| `iword://browse` | Parcourir tous les modules |
| `iword://browse?type=idiom` | Parcourir les idiomes |
| `iword://browse?type=xiehouyu` | Parcourir xiehouyu |
| `iword://entry?type=idiom&id=1` | Entrée spécifique |
| `iword://search` | Recherche |
| `iword://favorites` | Favoris |

## Navigation et guides

| URL | Ouvre |
|-----|-------|
| `iword://home` | Accueil |
| `iword://settings` | Réglages |
| `iword://widget-guide` | Guide des widgets |
| `iword://shortcuts-guide` | Guide Raccourcis |
| `iword://usage-guide` | Guide d'utilisation |
| `iword://feature-guide` | Guide des fonctionnalités |
