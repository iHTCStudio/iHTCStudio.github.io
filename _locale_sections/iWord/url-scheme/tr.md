iWord, **`iword://`** kısayol bağlantılarını destekler.

## Bağlantı biçimi


```
iword://{host}?{params}
```


## Öğrenme

| URL | Açar |
|-----|-------|
| `iword://daily` | Günün kelimesi |
| `iword://random` | Rastgele kayıt |
| `iword://review` | SRS tekrar oturumu |
| `iword://learn` | Öğrenme merkezi |

## Gözat ve ara

| URL | Açar |
|-----|-------|
| `iword://browse` | Tüm modüllere göz at |
| `iword://browse?type=idiom` | Deyimlere göz at |
| `iword://browse?type=xiehouyu` | xiehouyu |
| `iword://entry?type=idiom&id=1` | Belirli kayıt |
| `iword://search` | Ara |
| `iword://favorites` | Favoriler |

## Gezinme ve kılavuzlar

| URL | Açar |
|-----|-------|
| `iword://home` | Ana sayfa |
| `iword://settings` | Ayarlar |
| `iword://widget-guide` | Widget kılavuzu |
| `iword://shortcuts-guide` | Kısayol kılavuzu |
| `iword://usage-guide` | Kullanım kılavuzu |
| `iword://feature-guide` | Özellik kılavuzu |
| `iword://feedback` | Geri bildirim e-postası |
| `iword://in-app-review` | Uygulama içi App Store puanı |
