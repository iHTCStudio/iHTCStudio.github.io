iWord unterstützt **`iword://`**-Verknüpfungslinks.

## Linkformat


```
iword://{host}?{params}
```


## Lernen

| URL | Öffnet |
|-----|-------|
| `iword://daily` | Wort des Tages |
| `iword://random` | Zufälliger Eintrag |
| `iword://review` | SRS-Wiederholung |
| `iword://learn` | Lernzentrum |

## Durchsuchen & Suche

| URL | Öffnet |
|-----|-------|
| `iword://browse` | Alle Module durchsuchen |
| `iword://browse?type=idiom` | Idiome durchsuchen |
| `iword://browse?type=xiehouyu` | Browse xiehouyu |
| `iword://entry?type=idiom&id=1` | Bestimmter Eintrag |
| `iword://search` | Suche |
| `iword://favorites` | Favoriten |

## Navigation & Anleitungen

| URL | Öffnet |
|-----|-------|
| `iword://home` | Startseite |
| `iword://settings` | Einstellungen |
| `iword://widget-guide` | Widget-Anleitung |
| `iword://shortcuts-guide` | Kurzbefehle-Anleitung |
| `iword://usage-guide` | Nutzungsanleitung |
| `iword://feature-guide` | Funktionsübersicht |
| `iword://feedback` | Feedback-E-Mail |
| `iword://in-app-review` | App-Store-Bewertung in der App |
