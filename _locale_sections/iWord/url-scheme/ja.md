iWord は **`iword://`** ショートカットリンクに対応しています。

## リンク形式


```
iword://{host}?{params}
```


## 学習

| URL | 開く画面 |
|-----|-------|
| `iword://daily` | 今日の単語 |
| `iword://random` | ランダムな項目 |
| `iword://review` | SRS 復習セッション |
| `iword://learn` | 学習センター |

## 閲覧と検索

| URL | 開く画面 |
|-----|-------|
| `iword://browse` | すべてのモジュールを閲覧 |
| `iword://browse?type=idiom` | 熟語を閲覧 |
| `iword://browse?type=xiehouyu` | xiehouyuをブラウズする |
| `iword://entry?type=idiom&id=1` | 特定の項目 |
| `iword://search` | 検索 |
| `iword://favorites` | お気に入り |

## ナビゲーションとガイド

| URL | 開く画面 |
|-----|-------|
| `iword://home` | ホーム |
| `iword://settings` | 設定 |
| `iword://widget-guide` | ウィジェットガイド |
| `iword://shortcuts-guide` | ショートカットガイド |
| `iword://usage-guide` | 使い方ガイド |
| `iword://feature-guide` | 機能ガイド |
| `iword://feedback` | フィードバックメール |
| `iword://in-app-review` | アプリ内 App Store 評価 |
