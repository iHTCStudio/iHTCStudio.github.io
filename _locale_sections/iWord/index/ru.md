iWord (爱词语) — **полностью офлайновая библиотека китайского языка и культуры**: откройте для себя богатство китайской речи через **чэнъюй, сехоуюй, скороговорки, пословицы, парные надписи (дуйлянь) и загадки**. **Учётная запись не нужна.** **Более 107 000 записей** и полнотекстовый поиск SQLite **FTS5**: находите всё по китайскому тексту, пиньиню или аббревиатуре. Учитесь с помощью **интервальных повторений SRS**, **викторин по чэнъюй**, **成语接龙** и **飞花令**; слушайте каждую запись в озвучке **TTS**; поддерживайте мотивацию с помощью **слова дня**, серий занятий и целей. **4 виджета**, **2 элемента Пункта управления**, **Siri**, **Spotlight** и **глубокие ссылки `iword://`**. Необязательная синхронизация избранного через **iCloud**. **Без рекламы. Без отслеживания.**

## Первые шаги

1. Пройдите **приветственное руководство из 6 страниц** при первом запуске (его можно открыть снова в **Настройки → Руководства**).
2. Изучите **шесть модулей** на главном экране — чэнъюй, сехоуюй, скороговорки, пословицы, парные надписи, загадки.
3. Используйте **Поиск** (отдельная вкладка в iOS 18+) — FTS5 мгновенно находит записи по китайскому тексту, пиньиню или аббревиатуре.
4. Нажмите на любую запись, чтобы увидеть подробности: значение, пиньинь, источник, цитаты, примеры, синонимы и антонимы (чэнъюй); интерфейс «переверни, чтобы увидеть ответ» (сехоуюй и загадки).
5. Откройте **Обучение** с **карточками SRS** — оцените себя от 0 до 5, и движок запланирует следующее повторение.
6. Играйте в **成语接龙** (цепочка), **飞花令**, угадывайте сехоуюй или загадки.
7. Попробуйте **запись скороговорок** (iOS) — запишите себя и сравните с TTS.
8. Добавьте **виджеты** и элементы **Пункта управления**; попросите **Siri** показать слово дня или начать повторение.

### Мощный поиск

- **Полнотекстовый поиск FTS5** по всем 107 000+ записей
- Поиск по **китайскому тексту**, **пиньиню** или **аббревиатурам**
- **CoreSpotlight** индексирует всё при первом запуске — находите записи прямо с экрана «Домой»
- **Отдельная вкладка поиска** в iOS 18+

### Учитесь и играйте

- **Повторение SRS** (в стиле SM-2) с самооценкой 0–5 и планированием карточек
- **Викторина по чэнъюй** — вопросы с 4 вариантами и журнал ошибок
- **成语接龙** — цепочка чэнъюй по совпадающим иероглифам
- **飞花令** — поиск стихов и записей по иероглифу
- Игры «угадай **сехоуюй**» и «угадай **загадку**»
- **Ежедневные цели** и напоминания; отслеживание серий на главном экране

### Озвучивание и обмен

- **TTS** для всех типов записей с настраиваемыми параметрами голоса
- **Делитесь** записями в виде текста или изображений
- **Избранное** и история просмотров — закрепляйте избранное, используйте быстрые действия по долгому нажатию и открывайте историю из настроек
- Режимы просмотра **список / сетка / карточки** с настраиваемым числом столбцов, сортировкой по пиньиню и буквенным указателем (чэнъюй и сехоуюй)
- **Стили викторин** — значение → слово, слово → значение или смешанный

### Виджеты, Пункт управления и интеграция с системой

- **4 виджета** — слово дня, избранное, прогресс обучения, случайная запись (+ экран блокировки)
- **2 элемента Пункта управления** (iOS 18+) — слово дня, начать повторение
- **4 фразы для Siri** — Слово дня / Случайное / Повторение / Избранное
- **Быстрые действия на экране «Домой»** — до 4 настраиваемых
- **Глубокие ссылки `iword://`** — см. [Ссылки быстрых команд](url-scheme)

### Конфиденциальность

- **Без учётной записи · без регистрации · без рекламы · без отслеживания**
- **100 % локальная SQLite** для всего содержимого — просмотр, поиск и обучение офлайн
- Необязательный iCloud для избранного и настроек (по умолчанию выключен); данные SRS остаются на устройстве
- Микрофон используется **только** для записи скороговорок (временные локальные файлы)
