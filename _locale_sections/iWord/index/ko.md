iWord(爱词语)는 **완전 오프라인 중국어·중국 문화 라이브러리**입니다. **성어, 헐후어, 잰말놀이, 속담, 대련, 수수께끼**를 통해 중국어 표현의 풍부함을 탐구해 보세요. **계정이 필요 없습니다.** SQLite **FTS5** 전문 검색으로 **107,000개 이상의 항목**을 중국어, 병음, 약어로 찾을 수 있습니다. **SRS 간격 반복 복습**, **성어 퀴즈**, **成语接龙**, **飞花令**으로 배우고, 모든 항목을 **TTS**로 들으며, **오늘의 단어**, 연속 학습 기록, 목표로 꾸준히 학습하세요. **위젯 4종**, **제어 센터 컨트롤 2종**, **Siri**, **Spotlight**, **`iword://` 딥링크**를 지원합니다. 즐겨찾기를 위한 선택적 **iCloud** 동기화. **광고 없음. 추적 없음.**

## 시작하기

1. 처음 실행할 때 **6페이지 시작 가이드**를 완료하세요(**설정 → 가이드**에서 다시 열 수 있습니다).
2. 홈 화면에서 **여섯 가지 콘텐츠 모듈**(성어, 헐후어, 잰말놀이, 속담, 대련, 수수께끼)을 둘러보세요.
3. **검색**(iOS 18 이상에서는 전용 탭)을 사용하세요. FTS5가 중국어, 병음, 약어로 즉시 항목을 찾아 줍니다.
4. 항목을 탭하면 상세 정보가 나타납니다. 뜻, 병음, 출처, 인용, 예문, 유의어·반의어(성어)와 뒤집어서 정답을 보는 UI(헐후어·수수께끼)를 제공합니다.
5. **학습**을 열어 **SRS 복습 카드**를 사용하세요. 0~5점으로 스스로 평가하면 엔진이 다음 복습 일정을 정합니다.
6. **成语接龙**(끝말잇기), **飞花令**, 헐후어 맞히기, 수수께끼 맞히기를 즐겨 보세요.
7. **잰말놀이 녹음**(iOS)을 시도해 내 목소리를 TTS와 비교해 보세요.
8. **위젯**과 **제어 센터** 컨트롤을 추가하고, **Siri**에게 오늘의 단어나 복습 시작을 요청해 보세요.

## 기능

### 여섯 가지 콘텐츠 모듈

| 모듈 | 수량 | 주요 특징 |
|--------|------:|------------|
| 成语 성어 | 49,639 | 뜻, 병음, 출처, 인용, 예문, 유의어·반의어, 용법, 고사 |
| 歇后语 헐후어 | 14,026 | 뒤집어서 보는 수수께끼 + 정답 UI |
| 绕口令 잰말놀이 | 51 | iOS에서 녹음하고 비교 |
| 谚语 속담 | 964 | 맥락과 함께 보는 민간의 지혜 |
| 对联 대련 | 490 | 상련·하련과 해설 |
| 谜语 수수께끼 | 42,446 | 뒤집어서 정답 확인 |

### 강력한 검색

- 107,000개 이상의 모든 항목을 대상으로 하는 **FTS5 전문 검색**
- **중국어**, **병음**, **약어**로 검색
- **CoreSpotlight**가 처음 실행할 때 모든 항목을 색인 — 홈 화면에서 항목 검색
- iOS 18 이상에서는 **전용 검색 탭**

### 배우고 즐기기

- 0~5점 자기 평가와 복습 기한 일정을 갖춘 **SRS 복습**(SM-2 방식)
- **성어 퀴즈** — 4지선다 문제와 오답 노트
- **成语接龙** — 글자를 이어 성어 잇기
- **飞花令** — 글자로 시나 항목 검색
- **헐후어**와 **수수께끼** 맞히기 게임
- **일일 목표**와 알림, 홈 화면의 연속 학습 기록

### 소리 내어 읽기와 공유

- 모든 항목 유형에서 **TTS** 지원, 음성 설정 조정 가능
- 항목을 텍스트나 이미지로 **공유**
- **즐겨찾기**와 열람 기록 — 즐겨찾기 고정, 길게 눌러 빠른 동작, 설정에서 기록 열기
- **목록 / 그리드 / 카드** 탐색 레이아웃(열 수 조정, 병음순 정렬, 글자 색인 지원: 성어·헐후어)
- **퀴즈 방식** — 뜻 → 단어, 단어 → 뜻, 또는 혼합

### 위젯, 제어 센터 및 시스템 연동

- **위젯 4종** — 오늘의 단어, 즐겨찾기, 학습 진행 상황, 랜덤(잠금 화면 포함)
- **제어 센터 컨트롤 2종**(iOS 18 이상) — 오늘의 단어, 복습 시작
- **Siri 문구 4종** — 오늘의 단어 / 랜덤 / 복습 / 즐겨찾기
- **홈 화면 빠른 동작** — 최대 4개까지 사용자 지정 가능
- **`iword://` 딥링크** — [바로가기 링크](url-scheme) 참고

### 개인정보 보호

- **계정 없음 · 가입 없음 · 광고 없음 · 추적 없음**
- 모든 콘텐츠를 **100% 로컬 SQLite**로 제공 — 오프라인으로 탐색, 검색, 학습
- 즐겨찾기와 설정에 한해 선택적 iCloud 동기화(기본값 꺼짐), SRS 데이터는 기기에만 저장
- 마이크는 **잰말놀이 녹음에만** 사용(로컬 임시 파일)
