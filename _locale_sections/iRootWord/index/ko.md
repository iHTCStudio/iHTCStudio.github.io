iRootWord(爱词根)는 **하나의 어근을 배우면 수많은 단어가 열리도록** 도와줍니다. **계정이 필요 없습니다.** 무작정 암기가 아니라 **형태론**을 중심으로 **240개 이상의 접사 사전**, **오프라인 단어 분해기**, **라이트너 간격 반복 복습**을 갖추고 있습니다. 접두사, 어근, 접미사를 의미, 어원, 시험 카테고리별로 둘러보고, 모든 영어 단어를 접사 단위로 분해하고, 플래시카드와 퀴즈로 복습하며, **Swift Charts**로 연속 학습 기록을 확인하세요. **위젯 4종**, **제어 센터**, **Siri**, **단축어**, **Spotlight**로 학습을 가까이에서 이어 갈 수 있습니다. 선택적 **iCloud 동기화**(기본값 꺼짐). **완전 오프라인. 광고 없음. 추적 없음.**

> **참고:** 어원 데이터는 학습 목적으로 공개된 참고 자료를 바탕으로 정리한 것입니다.

## 시작하기

1. 처음 실행할 때 **5페이지 시작 가이드**를 완료하세요(**설정 → 가이드**에서 다시 열 수 있습니다).
2. **카테고리**를 둘러보세요 — 의미 주제, 어원 언어, 접사 유형, 시험 세트(CET-4/6, GRE, IELTS/TOEFL).
3. 접사를 탭하면 중국어 뜻, 어원, 변형, 암기 팁, 예시 단어, 형태 분석 등 상세 정보를 볼 수 있습니다.
4. **분해기**를 열어 보세요 — 영어 단어를 입력하면 오프라인으로 접사를 떼어 내고 어근을 대조해 구간별 설명을 보여 줍니다.
5. 접사에 별표를 눌러 **즐겨찾기**에 추가하고, 중요한 것은 고정해 빠르게 열어 보세요.
6. 즐겨찾기와 별도로 **사용자 단어 목록**을 만들 수 있고, 어근 정보를 보내고 싶을 때는 **공유 카드**를 내보내세요.
7. 복습할 카드가 있으면 **복습**을 시작하세요 — **다시 / 어려움 / 좋음 / 쉬움**으로 평가하면 라이트너 엔진이 다음 학습 일정을 정합니다. 잘못 누르면 약 **3초 안에 취소**할 수 있습니다.
8. **통계**에서 연속 학습 기록, 숙달도 분포, 주간 학습 곡선을 확인하세요.
9. **위젯**(홈·잠금 화면)이나 제어 센터의 **복습 시작** 컨트롤(iOS 18 이상)을 추가하거나, **Siri**에게 오늘의 어근을 물어보세요.

> 카테고리 목록은 **목록/그리드** 레이아웃 전환을 지원하고, **오늘의 어근**은 새로 고칠 수 있으며, 검색 사용성도 개선되었습니다.

## 기능

### 접사 사전

- **접사 240개 이상** — 접두사 44 · 어근 171 · 접미사 30
- 형태 분석이 포함된 **예시 단어 770개 이상**
- **46개 카테고리** — 의미 주제 34 · 어원 언어 4 · 유형 4 · 시험 세트 4
- 상세 페이지: 뜻, 어원, 변형, 암기 팁, 인용, 예시 단어
- 모든 항목에서 **미국식·영국식 TTS** 발음 지원
- 3개 언어 UI(English · 简体中文 · 繁體中文), 사전 콘텐츠는 간체이며 간체→번체 실시간 변환 지원

### 오프라인 단어 분해기

- 영어 단어를 입력 — 기기에서 **접두사·접미사 제거 + 어근 대조**
- 구간별 설명, 일치한 접사를 탭하면 사전 상세로 이동
- 네트워크 불필요 — 알고리즘이 내장 접사 표를 기준으로 동작

### 사용자 목록 및 공유

- **사용자 단어 목록** — 즐겨찾기와 독립적
- **공유 카드** — 메시지나 SNS에 보내기 좋은 깔끔한 카드 내보내기

### 과학적 복습(SRS)

- **라이트너 간격 반복** — 상자 간격: 0, 1, 2, 4, 8, 16, 32일
- 카드를 평가한 뒤 약 **3초간 취소 가능**
- **플래시카드**와 **객관식 퀴즈**
- **다시 / 어려움 / 좋음 / 쉬움**으로 평가, 최상위 상자에 도달하면 숙달
- 홈 화면, 위젯, 복습 진입점에 복습 기한 카드 수 표시

### 학습 통계

- **연속 학습 기록**과 일일 목표 추적
- **숙달도 분포**와 **주간 학습 곡선**(Swift Charts)
- 복습 기록과 진행 상황을 한눈에 확인

### 즐겨찾기와 검색

- 즐겨찾기 별표, 고정, 드래그 정렬, 밀어서 삭제
- 접사와 예시 단어를 아우르는 통합 검색
- iPhone에서 iOS 18 이상은 **전용 검색 탭**

### 위젯 및 시스템 연동

- **위젯 4종** — 오늘의 어근, 시간별 어근, 복습 진행 상황, 즐겨찾기 미리보기(홈·잠금 화면)
- **제어 센터**(iOS 18 이상) — **복습 시작** 컨트롤
- **Siri 및 단축어** — 오늘의 어근, 단어 분해, 복습 시작
- **Spotlight** — 모든 접사를 색인, 탭하면 상세 화면 열기
- **홈 화면 빠른 동작** — 최대 4개까지 사용자 지정 가능
- **`irootword://` 딥링크** — [바로가기 링크](url-scheme) 참고
- 위젯과 단축어를 알려 주는 **TipKit** 팁(iOS 17 이상)

### 개인정보 보호

- **계정 없음 · 가입 없음 · 광고 없음 · 추적 없음**
- 사전이 앱에 포함 — 오프라인으로 탐색, 검색, 분해, 복습
- 즐겨찾기와 SRS 진행 상황에 한해 선택적 iCloud 동기화(**기본값 꺼짐**)
