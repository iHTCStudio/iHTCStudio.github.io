IRootWord รองรับ} BAR `irootword://` BAR ~ ลิงก์ลัดสําหรับปุ่มพิมพ์ลัด, คั่นหน้า Safari, วิดเจ็ต, และการกระทําอย่างรวดเร็วของหน้าจอบ้าน

## รูปแบบลิงก์


```
irootword://{host}?{params}
```


## เนื้อหาที่อยู่เชื่อมโยงแบบลึก

| URL | เปิด |
|-----|-------|
| `irootword://affix?id=42` | รายละเอียดเพิ่มเติมโดยหมายเลข |
| `irootword://decompose?word=inspection` | เปิดโปงคําว่า "การวินิจฉัย" |
| `irootword://daily` | รากของวันนี้ |
| `irootword://review` | เริ่มการทบทวนค่า SRS |

## การนําทาง

| URL | เปิด |
|-----|-------|
| `irootword://home` | หน้าแรก |
| `irootword://categories` | การเรียกดูหมวดหมู่ |
| `irootword://favorites` | รายการโปรด |
| `irootword://search` | ค้นหา |
| `irootword://stats` | สถิติการเรียนรู้ |
| `irootword://settings` | การตั้งค่า |

## ปุ่มพิมพ์ลัดแบบ Siri

ส่วนเชื่อมโยงของ App:

- **Root of the Day** — เปิดงานวันนี้
- **Decompose Word** — ย่อยสลายคําที่ใช้พูดหรือพิมพ์
- **Start Review** — เริ่มวาระงานของ SSR เมื่อมีกําหนดไพ่
