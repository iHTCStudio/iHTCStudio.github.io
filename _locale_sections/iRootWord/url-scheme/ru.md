iRootWord поддерживает ярлыки ** `irootword://` ** для коротких ярлыков, закладок Safari, виджетов и быстрых действий на домашнем экране.

## Формат ссылки


```
irootword://{host}?{params}
```


## Глубокие ссылки

| URL | Открывает |
|-----|-------|
| `irootword://affix?id=42` | Детали проставления ID |
| `irootword://decompose?word=inspection` | Разложить слово «инспекция» |
| `irootword://daily` | Сегодняшний корень |
| `irootword://review` | Начать сессию обзора SRS |

## Навигация

| URL | Открывает |

| `irootword://stats` | Статистика обучения |

## Руководство и действия

| URL | Открывает |
|-----|-------|
| `irootword://feature-guide` | Обзор функций |
| `irootword://widget-guide` | Руководство по виджетам |

| `irootword://usage-guide` | Руководство по использованию |
| `irootword://feedback` | Письмо с отзывом |

## Siri и Shortcuts

Встроенные приложения Intents:

- **Root of the Day** — Открытие сегодняшнего аффикса
- **Decompose Word** — Разлагает произнесенное или напечатанное слово
- **Start Review** — Начинается сеанс SRS, когда карты должны быть
