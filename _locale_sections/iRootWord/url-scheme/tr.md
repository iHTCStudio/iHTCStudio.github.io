iRootWord ** `irootword://` ** Kısa kesimler için kısayol bağlantıları, Safari kitap işaretleri, widgets ve Home Ekran hızlı eylemleri destekler.

## Bağlantı biçimi


```
irootword://{host}?{params}
```


## Derin bağlantılar

| URL | Açar |
|-----|-------|
| `irootword://affix?id=42` | ID ile ek detay |
| `irootword://decompose?word=inspection` | Decompose the word "inspection" |
| `irootword://daily` | Bugünün kökü |
| `irootword://review` | Start SRS inceleme seansı |

## Navigation

| URL | Açar |
|-----|-------|
| `irootword://home` | Ana sayfa |
| `irootword://categories` | Kategoriler |
| `irootword://favorites` | Favoriler |
| `irootword://search` | Ara |
| `irootword://stats` | Öğrenme istatistikleri |
| `irootword://settings` | Ayarlar |

## Rehberler ve eylemler

| URL | Açar |
|-----|-------|
| `irootword://feature-guide` | Özellik kılavuzu |

| `irootword://shortcuts-guide` | Kısayol kılavuzu |
| `irootword://usage-guide` | Kullanım kılavuzu |

## Siri & Shortcuts

Yerleşik App niyetleri:

- **Root of the Day** — Bugünün canaltı açılıyor
- **Decompose Word** — Decomposes a speak or typed word
- **Start Review** — Kartlar nedeniyle SRS seansı başlar
