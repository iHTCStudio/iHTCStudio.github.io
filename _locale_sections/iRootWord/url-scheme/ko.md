iRootWord는 ** `irootword://` ** Shortcuts, Safari bookmarks, 위젯 및 홈 화면 빠른 행동을위한 단축 링크.

## 링크 형식


```
irootword://{host}?{params}
```


## 내용 깊은 링크

| URL | 열리는 화면 |
|-----|-------|
| `irootword://affix?id=42` | ID로 문의 |
| `irootword://decompose?word=inspection` | 단어 "inspection"를 해독 |
| `irootword://daily` | 오늘의 뿌리 |
| `irootword://review` | SRS 검토 세션 시작 |

## - 연혁

| URL | 열리는 화면 |
|-----|-------|

## Siri 및 단축키

내장 앱 의도:

- **Root of the Day** — 오늘 공개 affix
- **Decompose Word** — decomposes a 말 또는 유형 단어
- **Start Review** — 카드가 발생했을 때 SRS 세션을 시작합니다.
