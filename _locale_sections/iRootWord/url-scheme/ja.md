iRootWordは、ショートカット、Safariブックマーク、ウィジェット、ホーム画面のクイックアクションのショートカットリンクをサポートしています。

## リンク形式


```
irootword://{host}?{params}
```


## コンテンツディープリンク

| URL | 開く画面 |
|-----|-------|
| `irootword://affix?id=42` | IDによるAFfixの詳細 |
| `irootword://decompose?word=inspection` | 「インスペクション」という言葉を分解 |
| `irootword://daily` | 今日のルート |
| `irootword://review` | SRSレビューセッションを開始する |

## ナビゲーション

## シリとショートカット

組み込みアプリの意図:

- **Root of the Day** — 今日のアフィックスを開く
- **Decompose Word** — 単語や単語を分解する
- **Start Review** — カードが期限を過ぎるとSRSセッションが始まります
