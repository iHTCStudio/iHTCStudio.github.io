iRootWord prend en charge ** `irootword://` ** liens raccourcis pour raccourcis, signets Safari, widgets et actions rapides de l'écran d'accueil.

## Format de lien


```
irootword://{host}?{params}
```


## Liens profonds

| URL | Ouvre |
|-----|-------|
| `irootword://affix?id=42` | Fixez le détail par ID |
| `irootword://decompose?word=inspection` | Décomposer le mot "inspection" |
| `irootword://daily` | La racine d'aujourd'hui |
| `irootword://review` | Début de la session d'examen du SRS |

## Navigation

| URL | Ouvre |
|-----|-------|
| `irootword://home` | Accueil |
| `irootword://categories` | Catégories |
| `irootword://favorites` | Favoris |
| `irootword://search` | Recherche |
| `irootword://stats` | Statistiques d'apprentissage |
| `irootword://settings` | Réglages |

| URL | Ouvre |
|-----|-------|

| `irootword://widget-guide` | Guide des widgets |
| `irootword://shortcuts-guide` | Guide Raccourcis |

## Siri & raccourcis

Contenu de l'application intégrée :

- **Root of the Day** — ouvre l'apfix aujourd'hui
- **Decompose Word** — décompose un mot parlé ou tapé
- **Start Review** — commence une session SRS quand les cartes sont dues
