iHTC Studio создала iRootWord (爱词根 / 愛詞根). На этой странице описано, как мы обращаемся с данными.

## Кратко

**iRootWord не требует учётной записи и не собирает персональные данные на серверах iHTC Studio.** Словарь аффиксов встроен в приложение. Ваше избранное, прогресс SRS и настройки **хранятся на вашем устройстве**; необязательная **синхронизация через iCloud** позволяет поддерживать их в актуальном состоянии на всех ваших устройствах через **ваш личный iCloud** — по умолчанию **выключена**. **Без рекламы. Без отслеживания.**

## Сбор данных

- **Без учётной записи** — не нужны ни регистрация, ни электронная почта, ни номер телефона.
- **Без аналитики и рекламы** — никаких сторонних SDK для аналитики, рекламы или отслеживания.
- **Без облачного словаря** — поисковые запросы и разбор слов никогда не покидают устройство.

## Данные, хранящиеся на вашем устройстве

| Данные | Назначение |
|------|---------|
| Словарь аффиксов (SQLite) | Встроенный словарь только для чтения |
| Избранное | Аффиксы, которые вы отметили звёздочкой или закрепили |
| Прогресс SRS | Уровни ящиков Лейтнера, сроки повторения, журнал занятий |
| Серия занятий и ежедневная цель | Статистика обучения |
| Настройки | Тема, язык, TTS, параметры виджетов |
| Снимок для виджетов | Лёгкие данные для виджетов главного экрана |
| Состояние первого запуска и подсказок | Видели ли вы руководства |
| Переключатель синхронизации iCloud | Локальная настройка для включения синхронизации |

## Синхронизация через iCloud

Необязательная синхронизация iCloud поддерживает избранное и прогресс SRS (журнал занятий, серии) одинаковыми на iPhone, iPad, Mac и visionOS, где выполнен вход с одним Apple ID. Данные синхронизируются через **ваше личное хранилище «ключ — значение» iCloud**, а не через серверы iHTC Studio. **По умолчанию отключена.**

## Разрешения

iRootWord не запрашивает никаких специальных разрешений, кроме необязательного iCloud. Доступа к камере, микрофону и геопозиции нет.
