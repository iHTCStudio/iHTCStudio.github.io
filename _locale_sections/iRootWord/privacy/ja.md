iHTC Studio が iRootWord（爱词根 / 愛詞根）を開発しました。このページでは、データの取り扱いについて説明します。

## 概要

**iRootWord はアカウント不要で、iHTC Studio のサーバーに個人データを収集することはありません。** 接辞辞書はアプリに同梱されています。お気に入り、SRS の進捗、設定は**端末内に保存**されます。任意の **iCloud 同期**を使うと、**お客様のプライベートな iCloud** を通じて複数の端末間で同期できます（初期設定は**オフ**）。**広告なし。トラッキングなし。**

## データ収集について

- **アカウントなし** — 登録、メールアドレス、電話番号は不要です。
- **分析や広告なし** — サードパーティの分析、広告、トラッキング SDK は使用しません。
- **クラウド辞書なし** — 検索や語の分解結果は端末の外に出ません。

## 端末に保存されるデータ

| データ | 用途 |
|------|---------|
| 接辞辞書（SQLite） | 同梱の読み取り専用辞書 |
| お気に入り | スターを付けた、またはピン留めした接辞 |
| SRS の進捗 | ライトナーボックスのレベル、期日、学習ログ |
| 学習の連続記録と毎日の目標 | 学習統計 |
| 設定 | テーマ、言語、TTS、ウィジェットの設定 |
| ウィジェットのスナップショット | ホーム画面ウィジェット用の軽量データ |
| オンボーディングとヒントの状態 | ガイドを表示済みかどうか |
| iCloud 同期のスイッチ | 同期を有効にするためのローカル設定 |

## iCloud 同期

任意の iCloud 同期により、同じ Apple ID でサインインしている iPhone、iPad、Mac、visionOS の間で、お気に入りと SRS の進捗（学習ログ、連続記録）を揃えられます。データは iHTC Studio のサーバーではなく、**お客様のプライベートな iCloud キーバリューストア**を通じて同期されます。**初期設定では無効**です。

## 権限

iRootWord は、任意の iCloud 以外に特別な権限を要求しません。カメラ、マイク、位置情報へのアクセスはありません。
