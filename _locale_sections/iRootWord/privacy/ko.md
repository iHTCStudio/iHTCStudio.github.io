iHTC Studio가 iRootWord(爱词根 / 愛詞根)를 만들었습니다. 이 페이지에서는 데이터 처리 방식을 설명합니다.

## 요약

**iRootWord는 계정이 필요 없으며 iHTC Studio 서버에 개인 데이터를 수집하지 않습니다.** 접사 사전은 앱에 포함되어 있습니다. 즐겨찾기, SRS 진행 상황, 설정은 **기기에 저장**됩니다. 선택 사항인 **iCloud 동기화**를 켜면 **개인 iCloud**를 통해 여러 기기에서 동기화할 수 있으며, 기본값은 **꺼짐**입니다. **광고 없음. 추적 없음.**

## 데이터 수집

- **계정 없음** — 가입, 이메일, 전화번호가 필요하지 않습니다.
- **분석·광고 없음** — 서드파티 분석, 광고, 추적 SDK를 사용하지 않습니다.
- **클라우드 사전 없음** — 검색과 단어 분해 결과는 기기 밖으로 나가지 않습니다.

## 기기에 저장되는 데이터

| 데이터 | 용도 |
|------|---------|
| 접사 사전(SQLite) | 앱에 포함된 읽기 전용 사전 |
| 즐겨찾기 | 별표를 표시하거나 고정한 접사 |
| SRS 진행 상황 | 라이트너 상자 단계, 복습 기한, 학습 기록 |
| 연속 학습 기록과 일일 목표 | 학습 통계 |
| 설정 | 테마, 언어, TTS, 위젯 설정 |
| 위젯 스냅숏 | 홈 화면 위젯용 경량 데이터 |
| 온보딩 및 팁 상태 | 가이드를 본 적이 있는지 여부 |
| iCloud 동기화 스위치 | 동기화를 켜기 위한 로컬 설정 |

## iCloud 동기화

선택 사항인 iCloud 동기화는 같은 Apple ID로 로그인한 iPhone, iPad, Mac, visionOS 간에 즐겨찾기와 SRS 진행 상황(학습 기록, 연속 학습 기록)을 맞춰 줍니다. 데이터는 iHTC Studio 서버가 아니라 **개인 iCloud 키-값 저장소**를 통해 동기화됩니다. **기본값은 비활성화**입니다.

## 권한

iRootWord는 선택 사항인 iCloud 외에 별도의 권한을 요청하지 않습니다. 카메라, 마이크, 위치 정보에 접근하지 않습니다.
