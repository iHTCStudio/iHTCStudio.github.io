iHTC Studio เป็นผู้พัฒนา iRootWord (爱词根 / 愛詞根) หน้านี้อธิบายแนวทางการจัดการข้อมูลของเรา

## สรุป

**iRootWord ไม่ต้องสมัครบัญชี และไม่เก็บข้อมูลส่วนบุคคลบนเซิร์ฟเวอร์ของ iHTC Studio** พจนานุกรมคำเติม (affix) รวมอยู่ในแอปแล้ว รายการโปรด ความคืบหน้า SRS และการตั้งค่าของคุณ **จัดเก็บบนอุปกรณ์ของคุณ** ส่วน **การซิงค์ iCloud** แบบเลือกใช้ช่วยให้ข้อมูลเหล่านี้ตรงกันในทุกอุปกรณ์ผ่าน **iCloud ส่วนตัวของคุณ** — ปิดไว้เป็นค่าเริ่มต้น **ไม่มีโฆษณา ไม่มีการติดตาม**

## การเก็บรวบรวมข้อมูล

- **ไม่มีบัญชี** — ไม่ต้องสมัคร ไม่ต้องใช้อีเมลหรือหมายเลขโทรศัพท์
- **ไม่มีการวิเคราะห์หรือโฆษณา** — ไม่มี SDK วิเคราะห์ โฆษณา หรือติดตามจากบุคคลที่สาม
- **ไม่มีพจนานุกรมบนคลาวด์** — การค้นหาและการแยกส่วนของคำไม่ออกจากอุปกรณ์ของคุณ

## ข้อมูลที่จัดเก็บบนอุปกรณ์ของคุณ

| ข้อมูล | วัตถุประสงค์ |
|------|---------|
| พจนานุกรมคำเติม (SQLite) | พจนานุกรมแบบอ่านอย่างเดียวที่รวมมากับแอป |
| รายการโปรด | คำเติมที่คุณติดดาวหรือปักหมุด |
| ความคืบหน้า SRS | ระดับกล่องไลต์เนอร์ วันครบกำหนด บันทึกการเรียน |
| สถิติต่อเนื่องและเป้าหมายรายวัน | สถิติการเรียนรู้ |
| การตั้งค่า | ธีม ภาษา TTS การตั้งค่าวิดเจ็ต |
| สแนปช็อตของวิดเจ็ต | ข้อมูลขนาดเล็กสำหรับวิดเจ็ตบนหน้าจอหลัก |
| สถานะการแนะนำและเคล็ดลับ | ว่าคุณเคยดูคู่มือแล้วหรือไม่ |
| สวิตช์ซิงค์ iCloud | การตั้งค่าบนเครื่องสำหรับเปิดการซิงค์ |

## การซิงค์ iCloud

การซิงค์ iCloud แบบเลือกใช้ช่วยให้รายการโปรดและความคืบหน้า SRS (บันทึกการเรียน สถิติต่อเนื่อง) ตรงกันบน iPhone, iPad, Mac และ visionOS ที่ลงชื่อเข้าใช้ด้วย Apple ID เดียวกัน ข้อมูลจะซิงค์ผ่าน **ที่เก็บข้อมูลคีย์-ค่าใน iCloud ส่วนตัวของคุณ** ไม่ใช่เซิร์ฟเวอร์ของ iHTC Studio **ปิดไว้เป็นค่าเริ่มต้น**

## สิทธิ์การเข้าถึง

iRootWord ไม่ขอสิทธิ์พิเศษใด ๆ นอกจาก iCloud แบบเลือกใช้ ไม่มีการเข้าถึงกล้อง ไมโครโฟน หรือตำแหน่งที่ตั้ง
