## การเริ่มต้น (ทีละขั้นตอน)

### 1. การเปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store] (https://apps.apple.com/app/id6808958120) และเปิด **iGuanZhi**
2. เสร็จสิ้นคู่มือต้อนรับ (การอ่านประจําวัน → การอ่านปิด → การท่อง → การศึกษา → คุณสมบัติของระบบ → ความเป็นส่วนตัว)
3. เล่นซ้ําได้ทุกเมื่อ: **การตั้งค่า → วิธีใช้ → คู่มือคุณสมบัติ** (`iguanzhi://feature-guide`)
4. คู่มือการใช้งาน / วิดเจ็ต / คําสั่งลัดอยู่ภายใต้ **การตั้งค่า → วิธีใช้**

### 2. อ่านส่วนของวันนี้บน Home

1. เปิดแท็บ **Home**
2. วีรบุรุษของ **เรียงความของวันนี้** จะแสดงบทของวันนี้ แตะเพื่อเปิดรายละเอียด
3. ไม่บังคับ: เปิดใช้งานการแจ้งเตือนแบบฝึกหัดในท้องถิ่นของ **วันนี้** ในการตั้งค่า
4. กระโดดจาก Home ไปยัง Recitation, Classics Study, Essay Hunt, Favorites และ Search

### 3. เรียกดูและค้นหา

1. เรียกดู *กูเวน กวนจือ* ทั้งหมด บรรทัดที่มีชื่อเสียง และชั้นวางพิเศษ
2. ค้นหาชื่อเรื่องและบรรทัด (ง่ายขึ้น / สะดวกแบบดั้งเดิม) บน iOS การค้นหาลายมือเขียน** ทางเลือก** จะจดจําอักขระบนอุปกรณ์
3. ติดดาวย่อหน้าลงใน **รายการโปรด** และรวบรวมลงใน **รายการเรียงความส่วนบุคคล**

### 4. ปิดการอ่านและการแชร์การ์ด

1. สลับ **สองภาษา / เฉพาะภาษาจีน / เฉพาะภาษาอังกฤษ**; สลับเลเยอร์อย่างอิสระหากมี
2. ลองอ่านแบบดื่มด่ํา เค้าโครงแนวตั้ง ขนาดแบบอักษร และหน้าแบบแบ่งส่วนสําหรับส่วนที่ยาวขึ้น
3. เปิด**การ์ดเก่า** → เลือกสไตล์ / อัตราส่วน → บันทึกไปยังรูปภาพ (เพิ่มเท่านั้น) หรือการแชร์ระบบ

### 5. การท่องและศึกษาคลาสสิก

1. เปิดเวิร์กเบนช์การท่องเพื่อดู TTS ที่ไฮไลท์ เสียงและจังหวะที่ปรับได้ คําบรรยายภาษาท้องถิ่น/ภาษาอังกฤษแบบไม่บังคับ การเล่นต่อเนื่อง และเสียงพื้นหลัง
2. **การศึกษาคลาสสิก** (`iguanzhi://study`): การจาง, การเติมว่าง, การตรวจสอบตัวเอง และแบบทดสอบ พร้อมการติดตามความเชี่ยวชาญ
3. **Essay Hunt** on Home เป็นเกมค้นหาข้อความแยกต่างหาก

### 6. วิดเจ็ต, Siri และคุณสมบัติของระบบ

1. เพิ่มวิดเจ็ต Daily / Famous Line / Favorites / Study Progress (และ Almanac หากมี)
2. ใช้ศูนย์ควบคุม, Siri, Spotlight และ `iguanzhi://` ลิงก์ลึก
3. กิจกรรมการอ่านสดแบบไม่บังคับยังคงมีให้ใช้งานบนอุปกรณ์ที่รองรับ iPhone

### 7. ความเป็นส่วนตัวและการซิงค์

1. คลัง, การอ่าน, การท่อง (ระบบ TTS), การศึกษา, วิดเจ็ต และการแจ้งเตือนในเครื่องจะทํางานแบบออฟไลน์อย่างสมบูรณ์หลังจากติดตั้ง
2. ตัวเลือก**iCloud Sync** สะท้อนรายการโปรด รายการ ประวัติ ความคืบหน้า เส้น และโน้ตผ่าน**iCloud**ส่วนตัวของคุณ
3. เคล็ดลับสําหรับนักพัฒนา (ไม่บังคับ StoreKit) ไม่ควรปลดล็อค Paywall และไม่ควรสร้างบัญชี
