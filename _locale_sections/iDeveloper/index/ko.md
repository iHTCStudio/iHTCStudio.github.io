**더 빠르게 출시하세요. 주머니 속에서 바로 찾아보세요.**

iDeveloper(爱开发者 / 愛開發者)는 iPhone, iPad, Mac용 **개발자 포켓 스튜디오**입니다. 아무렇게나 모아 둔 도구 모음이 아닙니다. **계정이 필요 없습니다.** 13개 카테고리의 **오프라인 도구 176개**(JSON / XML / YAML / SQL, Base64 / JWT, 해시 / AES, 타임스탬프 / Cron, 정규식, 색상, HTTP / Curl, 코드 변환기, **약 255개 항목의 기기 모델 백과**와 화면 크기를 포함한 Apple 도우미 등)와 **이중 언어 치트시트 14개 주제**(약 420개 항목)를 사용할 수 있습니다. **즐겨찾기, 기록, 스니펫**을 보관하고, **공유**로 스마트 추천과 함께 텍스트를 보내고, **위젯**, **집중 실시간 현황**, **Siri 및 단축어**, 제어 센터를 추가하세요. **광고 없음. 추적 없음. 네트워크 도구는 사용자가 요청을 시작할 때만 실행됩니다.**

## 시작하기 (단계별)

### 1. 처음 실행

1. [App Store](https://apps.apple.com/app/id1240856775)에서 설치하고 **iDeveloper**를 엽니다.
2. **환영 가이드**(도구 → 참고 자료 → 워크플로 → 시스템 기능 → 개인정보 보호)를 끝까지 진행합니다.
3. 언제든 다시 볼 수 있습니다: **설정 → 도움말 → 기능 가이드**.
4. 앱 내 **사용법 / 위젯 / 단축어** 가이드는 **설정 → 도움말**에 있습니다.

### 2. 도구를 열고 결과 얻기

1. **홈** 또는 **둘러보기**에서 도구를 고릅니다(예: JSON, Base64, 타임스탬프, 정규식).
2. 입력을 붙여넣거나 직접 입력합니다. 또는 **도구로 보내기**나 스마트 추천(추천 → 최근 → 전체)이 있는 **공유** 확장을 사용합니다.
3. 도구를 실행하고 출력을 복사한 뒤, 필요하면 **스니펫**으로 저장하거나 **기록**에서 복원합니다(두 패널 도구는 양쪽 모두 복원됩니다).
4. 다음 단계에 도움이 될 때는 관련 도구가 가벼운 링크로 표시됩니다.

### 3. 오프라인 치트시트 사용하기

1. **참고 자료** 센터를 열거나 주제로 바로 이동합니다(HTTP / 헤더 / MIME / Git / Docker / Cron / SQL / 정규식 / SSH / npm / Kubernetes / Linux / JWT / TLS).
2. 전체 검색을 하거나 딥링크 `ideveloper://reference?id=…`로 특정 항목을 엽니다.
3. 즐겨찾기를 고정하고 홈 화면에 일일 참고 자료 위젯을 추가합니다.

### 4. 실제로 오래 쓰는 워크플로 만들기

1. 매주 쓰는 도구와 참고 자료 항목에 별표를 표시합니다.
2. 다시 입력하지 말고 **최근**과 **기록**을 다시 열어 보세요.
3. 바로 붙여넣을 수 있는 조각을 재사용 가능한 **스니펫**으로 저장합니다.
4. 다른 앱에서 iDeveloper로 공유하면 선택 화면에서 가장 알맞은 도구가 먼저 표시됩니다.

### 5. 위젯, 집중 실시간 현황, Siri

1. 홈 화면을 길게 누르기 → **위젯 편집** → 일일 참고 자료 / 빠른 도구 / 타임스탬프 / 즐겨찾기를 추가합니다(지원되는 경우 홈 및 잠금 화면 크기).
2. **집중** 타이머를 시작하면 잠금 화면 / Dynamic Island에 **실시간 현황**이 표시됩니다.
3. **Siri**에게 요청하거나 단축어로 검색, 즐겨찾기, 집중, 자주 쓰는 도구를 실행할 수 있습니다.
4. 홈 화면 빠른 동작과 제어 센터 컨트롤을 설정합니다(iOS 18+).

### 6. 화면 모양과 개인정보 보호

1. 테마, 강조 색상(9가지), 언어(EN / 简 / 繁), 글자 크기를 고릅니다.
2. 탭 표시 여부를 전환하고, 필요하면 위젯이 앱 테마를 따르게 하며, 대체 앱 아이콘을 선택합니다.
3. 핵심 도구와 치트시트는 **오프라인**에서 작동합니다. 네트워크가 필요한 도구는 명확한 안내를 표시하며, **사용자**가 탭할 때만 요청합니다.
4. 선택 사항인 팁(StoreKit)은 유료 콘텐츠를 잠금 해제하지 않으며 계정도 만들지 않습니다.

## 다운로드해야 하는 이유

- **탭 스무 개 대신 하나의 스튜디오** — 포매터, 암호화, 시간, 정규식, HTTP 도우미, Apple 지향 도구를 차분한 네이티브 UI로 제공합니다.
- **들고 다니는 치트시트** — 검색, 즐겨찾기, 위젯을 갖춘 이중 언어 오프라인 참고 자료.
- **워크플로 기억** — 즐겨찾기, 기록 복원, 스니펫, 알맞은 도구를 제안하는 공유 라우팅.
- **중요한 곳은 네이티브로** — 위젯, 실시간 현황, 공유 확장, 제어 센터, Siri, Spotlight, 딥링크.
- **기본이 개인정보 보호** — 계정 없음, 광고 없음, 분석 SDK 없음. 언제 온라인으로 연결할지는 사용자가 정합니다.

## 기능

### 도구 상자
- 도구 **176**개 · 카테고리 **13**개(기기 모델 포함)
- JSON / XML / YAML / SQL · 인코딩 · 암호화 · 시간 / Cron · 정규식 · 색상 · 숫자 / Diff · HTTP / Curl · 코드 변환기 · Apple 도우미 · UUID / QR · 집중 타이머 등
- 관련 도구로 이동 및 예시 입력

### 오프라인 참고 자료
- 주제 **14**개 · 이중 언어 항목 약 **420**개
- 지연 로딩 샤드 + 검색 가능한 색인
- 일일 참고 자료 위젯

### 워크플로 기억
- 즐겨찾기 · 최근 도구 · 작업 기록 · 스니펫
- 추천 / 최근 / 전체를 갖춘 공유 확장
- 전체 검색 및 Spotlight

### 네이티브 기능 한눈에 보기
- 홈 / 잠금 화면 위젯 · 집중 실시간 현황 · 제어 센터 · App Intents / Siri · 홈 화면 빠른 동작 · `ideveloper://` 딥링크

### 개인정보 보호
- **계정 없음 · 광고 없음 · 서드파티 분석 SDK 없음**
- 오프라인 우선, 네트워크 도구는 동작마다 직접 선택
- 일부 설정 / 워크플로 데이터를 위한 선택적 비공개 iCloud KVS
