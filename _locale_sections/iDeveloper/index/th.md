**ส่งงานเร็วขึ้น ค้นข้อมูลได้โดยไม่ต้องเปิดคอมพิวเตอร์**

iDeveloper (爱开发者 / 愛開發者) คือ **สตูดิโอพกพาสำหรับนักพัฒนา** บน iPhone, iPad และ Mac — ไม่ใช่กองเครื่องมือที่รวมกันมั่ว ๆ **ไม่ต้องมีบัญชี** ใช้ **เครื่องมือออฟไลน์ 176 ชิ้น** ใน 13 หมวด (JSON / XML / YAML / SQL, Base64 / JWT, แฮช / AES, ไทม์สแตมป์ / Cron, regex, สี, HTTP / Curl, ตัวแปลงโค้ด, ตัวช่วยสำหรับ Apple รวมถึง **สารานุกรมรุ่นอุปกรณ์ประมาณ 255 รายการ** และขนาดหน้าจอ และอื่น ๆ) พร้อม **ชีตสรุป 14 หัวข้อสองภาษา** (ประมาณ 420 รายการ) เก็บ **รายการโปรด ประวัติ และสนิปเป็ต** ส่งข้อความผ่าน **แชร์** พร้อมคำแนะนำอัจฉริยะ เพิ่ม **วิดเจ็ต**, **Live Activity โหมดโฟกัส**, **Siri และคำสั่งลัด** และศูนย์ควบคุม **ไม่มีโฆษณา ไม่มีการติดตาม เครื่องมือที่ใช้เครือข่ายจะทำงานเฉพาะเมื่อคุณเริ่มคำขอเอง**

## เริ่มต้นใช้งาน (ทีละขั้นตอน)

### 1. เปิดใช้ครั้งแรก

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id1240856775) แล้วเปิด **iDeveloper**
2. ทำตาม**คู่มือต้อนรับ**ให้จบ (เครื่องมือ → ข้อมูลอ้างอิง → เวิร์กโฟลว์ → ฟีเจอร์ระบบ → ความเป็นส่วนตัว)
3. เปิดดูซ้ำได้ทุกเมื่อ: **การตั้งค่า → ความช่วยเหลือ → คู่มือฟีเจอร์**
4. คู่มือ **การใช้งาน / วิดเจ็ต / คำสั่งลัด** ในแอปอยู่ที่ **การตั้งค่า → ความช่วยเหลือ**

### 2. เปิดเครื่องมือและรับผลลัพธ์

1. จาก **หน้าหลัก** หรือ **เรียกดู** เลือกเครื่องมือ (เช่น JSON, Base64, ไทม์สแตมป์, regex)
2. วางหรือพิมพ์ข้อมูลนำเข้า — หรือใช้ **ส่งไปยังเครื่องมือ** / ส่วนขยาย **แชร์** พร้อมคำแนะนำอัจฉริยะ (แนะนำ → ล่าสุด → ทั้งหมด)
3. เรียกใช้เครื่องมือ คัดลอกผลลัพธ์ และจะบันทึกเป็น **สนิปเป็ต** หรือกู้คืนจาก **ประวัติ** ก็ได้ (เครื่องมือแบบสองแผงกู้คืนได้ทั้งสองฝั่ง)
4. เครื่องมือที่เกี่ยวข้องจะแสดงเป็นลิงก์เบา ๆ เมื่อเหมาะกับขั้นตอนถัดไป

### 3. ใช้ชีตสรุปแบบออฟไลน์

1. เปิดศูนย์ **ข้อมูลอ้างอิง** หรือข้ามไปยังหัวข้อ (HTTP / เฮดเดอร์ / MIME / Git / Docker / Cron / SQL / Regex / SSH / npm / Kubernetes / Linux / JWT / TLS)
2. ค้นหาทั้งแอป หรือเปิดรายการที่ต้องการด้วยดีปลิงก์ `ideveloper://reference?id=…`
3. ปักหมุดรายการโปรด และเพิ่มวิดเจ็ตข้อมูลอ้างอิงประจำวันบนหน้าจอโฮม

### 4. สร้างเวิร์กโฟลว์ที่คุณจะใช้จริง

1. กดดาวเครื่องมือและรายการอ้างอิงที่ใช้ทุกสัปดาห์
2. กลับไปที่ **ล่าสุด** และ **ประวัติ** แทนการพิมพ์ใหม่
3. บันทึก **สนิปเป็ต** ที่ใช้ซ้ำได้ เป็นชิ้นส่วนพร้อมวาง
4. จากแอปอื่น แชร์เข้า iDeveloper — ตัวเลือกจะจัดเครื่องมือที่เหมาะที่สุดไว้ก่อน

### 5. วิดเจ็ต, Live Activity โหมดโฟกัส และ Siri

1. กดหน้าจอโฮมค้าง → **แก้ไขวิดเจ็ต** → เพิ่มข้อมูลอ้างอิงประจำวัน / เครื่องมือด่วน / ไทม์สแตมป์ / รายการโปรด (ขนาดสำหรับหน้าจอโฮมและหน้าจอล็อกเท่าที่มี)
2. เริ่มตัวจับเวลา **โฟกัส** เพื่อแสดง **Live Activity** บนหน้าจอล็อก / Dynamic Island
3. สั่ง **Siri** หรือใช้คำสั่งลัดสำหรับการค้นหา รายการโปรด โฟกัส และเครื่องมือที่ใช้บ่อย
4. ตั้งค่าคำสั่งด่วนบนหน้าจอโฮมและตัวควบคุมในศูนย์ควบคุม (iOS 18+)

### 6. หน้าตาแอปและความเป็นส่วนตัว

1. เลือกธีม สีเน้น (9 ตัวเลือก) ภาษา (EN / 简 / 繁) และขนาดตัวอักษร
2. เปิด/ปิดการแสดงแท็บ เลือกให้วิดเจ็ตใช้ธีมเดียวกับแอป และเลือกไอคอนแอปทางเลือก
3. เครื่องมือหลักและชีตสรุปทำงาน**ออฟไลน์**ได้ เครื่องมือที่ต้องใช้เครือข่ายจะแสดงข้อความแจ้งชัดเจนและส่งคำขอเฉพาะเมื่อ**คุณ**แตะ
4. ทิปแบบไม่บังคับ (StoreKit) ไม่ปลดล็อกเนื้อหาแบบเสียเงิน และไม่สร้างบัญชี

## เหตุผลที่ควรดาวน์โหลด

- **หนึ่งสตูดิโอแทนยี่สิบแท็บ** — ตัวจัดรูปแบบ การเข้ารหัส เวลา regex ตัวช่วย HTTP และเครื่องมือสำหรับ Apple ในอินเทอร์เฟซเนทีฟที่ใช้งานสบาย
- **ชีตสรุปที่พกไปได้ทุกที่** — ข้อมูลอ้างอิงออฟไลน์สองภาษา พร้อมการค้นหา รายการโปรด และวิดเจ็ต
- **ความจำของเวิร์กโฟลว์** — รายการโปรด การกู้คืนประวัติ สนิปเป็ต และการส่งต่อจากแชร์ที่แนะนำเครื่องมือที่ใช่
- **เนทีฟในจุดที่สำคัญ** — วิดเจ็ต, Live Activity, ส่วนขยายแชร์, ศูนย์ควบคุม, Siri, Spotlight, ดีปลิงก์
- **ความเป็นส่วนตัวเป็นค่าเริ่มต้น** — ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK วิเคราะห์ข้อมูล คุณเป็นผู้ตัดสินใจว่าจะออนไลน์เมื่อใด

## ฟีเจอร์

### กล่องเครื่องมือ
- **176** เครื่องมือ · **13** หมวด (รวมรุ่นอุปกรณ์)
- JSON / XML / YAML / SQL · การเข้ารหัส · คริปโต · เวลา / Cron · regex · สี · ตัวเลข / Diff · HTTP / Curl · ตัวแปลงโค้ด · ตัวช่วยสำหรับ Apple · UUID / QR · ตัวจับเวลาโฟกัส และอื่น ๆ
- ลิงก์ไปยังเครื่องมือที่เกี่ยวข้องและตัวอย่างข้อมูลนำเข้า

### ข้อมูลอ้างอิงออฟไลน์
- **14** หัวข้อ · ประมาณ **420** รายการสองภาษา
- โหลดข้อมูลเป็นส่วนเมื่อต้องการ + ดัชนีที่ค้นหาได้
- วิดเจ็ตข้อมูลอ้างอิงประจำวัน

### ความจำของเวิร์กโฟลว์
- รายการโปรด · เครื่องมือล่าสุด · ประวัติการใช้งาน · สนิปเป็ต
- ส่วนขยายแชร์พร้อมแนะนำ / ล่าสุด / ทั้งหมด
- การค้นหาทั้งแอปและ Spotlight

### ภาพรวมความสามารถเนทีฟ
- วิดเจ็ตหน้าโฮม / หน้าจอล็อก · Live Activity โหมดโฟกัส · ศูนย์ควบคุม · App Intents / Siri · คำสั่งด่วนบนหน้าจอโฮม · ดีปลิงก์ `ideveloper://`

### ความเป็นส่วนตัว
- **ไม่มีบัญชี · ไม่มีโฆษณา · ไม่มี SDK วิเคราะห์ข้อมูลของบุคคลที่สาม**
- ออฟไลน์เป็นหลัก เครื่องมือเครือข่ายทำงานเมื่อคุณสั่งเป็นรายการ
- iCloud KVS ส่วนตัวแบบไม่บังคับสำหรับการตั้งค่า / ข้อมูลเวิร์กโฟลว์บางส่วน
