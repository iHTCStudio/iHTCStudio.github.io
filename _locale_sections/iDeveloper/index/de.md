**Schneller liefern. Nachschlagen, ohne die Hosentasche zu verlassen.**

iDeveloper (爱开发者 / 愛開發者) ist ein **Entwickler-Taschenstudio** für iPhone, iPad und Mac – keine zufällige Werkzeugsammlung. **Kein Konto erforderlich.** Nutze **176 Offline-Tools** in 13 Kategorien (JSON / XML / YAML / SQL, Base64 / JWT, Hash / AES, Zeitstempel / Cron, Regex, Farben, HTTP / Curl, Code-Konverter, Apple-Helfer inklusive **Geräte­modell-Enzyklopädie mit ca. 255 Einträgen** und Bildschirmgrößen u. v. m.) sowie **14 zweisprachige Spickzettel-Themen** (ca. 420 Einträge). Behalte **Favoriten, Verlauf und Snippets**; leite Text über **Teilen** mit intelligenten Vorschlägen weiter; ergänze **Widgets**, **Fokus-Live-Aktivität**, **Siri & Kurzbefehle** und das Kontrollzentrum. **Keine Werbung. Kein Tracking. Netzwerk-Tools laufen nur, wenn du eine Anfrage startest.**

## Erste Schritte (Schritt für Schritt)

### 1. Erster Start

1. Installiere die App aus dem [App Store](https://apps.apple.com/app/id1240856775) und öffne **iDeveloper**.
2. Schließe die **Willkommens­anleitung** ab (Tools → Referenzen → Workflow → Systemfunktionen → Datenschutz).
3. Jederzeit erneut abspielbar: **Einstellungen → Hilfe → Funktionsanleitung**.
4. Die In-App-Anleitungen zu **Nutzung / Widgets / Kurzbefehlen** findest du unter **Einstellungen → Hilfe**.

### 2. Ein Tool öffnen und ein Ergebnis erhalten

1. Wähle auf **Start** oder unter **Durchsuchen** ein Tool (z. B. JSON, Base64, Zeitstempel, Regex).
2. Füge Eingaben ein oder tippe sie – oder nutze **An Tool senden** bzw. die **Teilen**-Erweiterung mit intelligenten Empfehlungen (Vorgeschlagen → Zuletzt → Alle).
3. Führe das Tool aus, kopiere die Ausgabe und speichere optional ein **Snippet** oder stelle sie aus dem **Verlauf** wieder her (Tools mit zwei Bereichen stellen beide Seiten wieder her).
4. Verwandte Tools erscheinen als dezente Links, wenn sie für den nächsten Schritt sinnvoll sind.

### 3. Die Offline-Spickzettel nutzen

1. Öffne das **Referenz**-Center oder springe zu einem Thema (HTTP / Header / MIME / Git / Docker / Cron / SQL / Regex / SSH / npm / Kubernetes / Linux / JWT / TLS).
2. Suche global oder öffne einen bestimmten Eintrag per Deep Link `ideveloper://reference?id=…`.
3. Hefte Favoriten an und nutze die täglichen Referenz-Widgets auf dem Home-Bildschirm.

### 4. Einen Workflow aufbauen, den du wirklich behältst

1. Markiere Tools und Referenzeinträge mit einem Stern, die du wöchentlich brauchst.
2. Rufe **Zuletzt** und **Verlauf** auf, statt neu zu tippen.
3. Speichere wiederverwendbare **Snippets** für einfügefertige Textbausteine.
4. Teile aus einer anderen App in iDeveloper – die Auswahl listet die passendsten Tools zuerst.

### 5. Widgets, Fokus-Live-Aktivität & Siri

1. Halte den Home-Bildschirm gedrückt → **Widgets bearbeiten** → füge Tägliche Referenz / Schnellwerkzeuge / Zeitstempel / Favoriten hinzu (Größen für Home- und Sperrbildschirm, soweit verfügbar).
2. Starte einen **Fokus**-Timer, um die **Live-Aktivität** auf dem Sperrbildschirm / in der Dynamic Island anzuzeigen.
3. Frage **Siri** oder nutze Kurzbefehle für Suche, Favoriten, Fokus und häufige Tools.
4. Richte Home-Bildschirm-Kurzaktionen und Kontrollzentrum-Steuerelemente ein (iOS 18+).

### 6. Darstellung & Datenschutz

1. Wähle Design, Akzentfarbe (9 Optionen), Sprache (EN / 简 / 繁) und Textgröße.
2. Schalte die Sichtbarkeit von Tabs um; lasse Widgets optional dem App-Design folgen; wähle alternative App-Symbole.
3. Kern-Tools und Spickzettel funktionieren **offline**. Tools, die das Netzwerk brauchen, zeigen einen klaren Hinweis und senden nur eine Anfrage, wenn **du** tippst.
4. Das optionale Trinkgeld (StoreKit) schaltet nie kostenpflichtige Inhalte frei und legt nie ein Konto an.

## Darum lohnt sich der Download

- **Ein Studio statt zwanzig Tabs** – Formatierer, Krypto, Zeit, Regex, HTTP-Helfer und Apple-orientierte Tools in einer ruhigen, nativen Oberfläche.
- **Spickzettel für unterwegs** – zweisprachige Offline-Referenzen mit Suche, Favoriten und Widgets.
- **Workflow-Gedächtnis** – Favoriten, Verlaufs­wiederherstellung, Snippets und Teilen-Routing, das das passende Tool vorschlägt.
- **Nativ, wo es zählt** – Widgets, Live-Aktivität, Teilen-Erweiterung, Kontrollzentrum, Siri, Spotlight, Deep Links.
- **Datenschutz als Standard** – kein Konto, keine Werbung, kein Analyse-SDK; du entscheidest, wann etwas online geht.
