**もっと速くリリース。ポケットの中で調べものが完結。**

iDeveloper（爱开发者 / 愛開發者）は、iPhone・iPad・Mac 向けの**開発者のためのポケットスタジオ**です。寄せ集めのツール集ではありません。**アカウント不要。** 13 カテゴリ・**176 種類のオフラインツール**（JSON / XML / YAML / SQL、Base64 / JWT、ハッシュ / AES、タイムスタンプ / Cron、正規表現、カラー、HTTP / Curl、コード変換、**約 255 項目のデバイスモデル事典**や画面サイズを含む Apple 向けヘルパーなど）と、**14 テーマのバイリンガル早見表**（約 420 項目）が使えます。**お気に入り・履歴・スニペット**を保存でき、**共有**からスマートな候補付きでテキストを送れます。さらに**ウィジェット**、**集中モードのライブアクティビティ**、**Siri とショートカット**、コントロールセンターにも対応。**広告なし。トラッキングなし。ネットワークツールはあなたがリクエストを開始したときだけ動作します。**

## はじめかた（ステップごとに）

### 1. 初回起動

1. [App Store](https://apps.apple.com/app/id1240856775) からインストールし、**iDeveloper** を開きます。
2. **ウェルカムガイド**（ツール → リファレンス → ワークフロー → システム機能 → プライバシー）を完了します。
3. いつでも再表示できます：**設定 → ヘルプ → 機能ガイド**。
4. アプリ内の**使い方 / ウィジェット / ショートカット**ガイドは **設定 → ヘルプ** にあります。

### 2. ツールを開いて結果を得る

1. **ホーム**または**ブラウズ**からツールを選びます（例：JSON、Base64、タイムスタンプ、正規表現）。
2. 入力を貼り付けるか入力します。または **ツールに送信** や、スマートなおすすめ（おすすめ → 最近 → すべて）付きの**共有**機能拡張を使います。
3. ツールを実行して出力をコピーし、必要に応じて**スニペット**として保存したり、**履歴**から復元したりできます（2 ペインのツールは両側を復元できます）。
4. 次のステップに役立つ場合は、関連ツールが控えめなリンクとして表示されます。

### 3. オフライン早見表を使う

1. **リファレンス**センターを開くか、テーマに直接移動します（HTTP / ヘッダー / MIME / Git / Docker / Cron / SQL / 正規表現 / SSH / npm / Kubernetes / Linux / JWT / TLS）。
2. 全体検索するか、ディープリンク `ideveloper://reference?id=…` で特定の項目を開きます。
3. お気に入りをピン留めし、ホーム画面に毎日のリファレンスウィジェットを置けます。

### 4. 本当に続けられるワークフローをつくる

1. 毎週使うツールやリファレンス項目にスターを付けます。
2. 打ち直さずに、**最近**や**履歴**から呼び出します。
3. すぐ貼り付けられる断片を、再利用できる**スニペット**として保存します。
4. 他のアプリから iDeveloper に共有すると、ピッカーが最も合うツールを上位に表示します。

### 5. ウィジェット、集中モードのライブアクティビティ、Siri

1. ホーム画面を長押し → **ウィジェットを編集** → 今日のリファレンス / クイックツール / タイムスタンプ / お気に入りを追加します（ホーム・ロック画面のサイズは対応するもののみ）。
2. **集中**タイマーを開始すると、ロック画面 / Dynamic Island に**ライブアクティビティ**が表示されます。
3. **Siri** に頼むか、ショートカットで検索・お気に入り・集中・よく使うツールを呼び出せます。
4. ホーム画面のクイックアクションとコントロールセンターのコントロールを設定します（iOS 18+）。

### 6. 外観とプライバシー

1. テーマ、アクセントカラー（9 種類）、言語（EN / 简 / 繁）、文字サイズを選びます。
2. タブの表示を切り替え、必要に応じてウィジェットをアプリのテーマに合わせ、別のアプリアイコンを選べます。
3. 主要なツールと早見表は**オフライン**で動作します。ネットワークが必要なツールは明確な確認を表示し、**あなた**がタップしたときだけリクエストします。
4. 任意のチップ（StoreKit）で有料コンテンツが解放されることはなく、アカウントが作られることもありません。

## ダウンロードしたくなる理由

- **20 個のタブの代わりに 1 つのスタジオ** — フォーマッタ、暗号、時刻、正規表現、HTTP ヘルパー、Apple 向けツールを、落ち着いたネイティブ UI で。
- **持ち歩ける早見表** — 検索・お気に入り・ウィジェット付きのバイリンガル・オフラインリファレンス。
- **ワークフローの記憶** — お気に入り、履歴の復元、スニペット、最適なツールを提案する共有ルーティング。
- **要所はネイティブ** — ウィジェット、ライブアクティビティ、共有機能拡張、コントロールセンター、Siri、Spotlight、ディープリンク。
- **プライバシーが初期設定** — アカウント不要、広告なし、解析 SDK なし。オンラインにするタイミングはあなたが決めます。

## 機能

### ツールボックス
- **176** ツール · **13** カテゴリ（デバイスモデルを含む）
- JSON / XML / YAML / SQL · エンコード · 暗号 · 時刻 / Cron · 正規表現 · カラー · 数値 / Diff · HTTP / Curl · コード変換 · Apple 向けヘルパー · UUID / QR · 集中タイマーなど
- 関連ツールへのジャンプとサンプル入力

### オフラインリファレンス
- **14** テーマ · 約 **420** のバイリンガル項目
- 遅延読み込みのシャード＋検索可能なインデックス
- 毎日のリファレンスウィジェット

### ワークフローの記憶
- お気に入り · 最近使ったツール · 操作履歴 · スニペット
- おすすめ / 最近 / すべて を備えた共有機能拡張
- 全体検索と Spotlight

### ネイティブ機能一覧
- ホーム / ロック画面ウィジェット · 集中モードのライブアクティビティ · コントロールセンター · App Intents / Siri · ホーム画面クイックアクション · `ideveloper://` ディープリンク

### プライバシー
- **アカウントなし · 広告なし · サードパーティ解析 SDK なし**
- オフライン優先。ネットワークツールは操作ごとに明示的に実行
- 一部の設定 / ワークフローデータ用の任意のプライベート iCloud KVS
