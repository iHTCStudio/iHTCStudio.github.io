**Выпускайте быстрее. Находите нужное, не выходя из кармана.**

iDeveloper (爱开发者 / 愛開發者) — это **карманная студия разработчика** для iPhone, iPad и Mac, а не очередная случайная куча инструментов. **Учётная запись не нужна.** Пользуйтесь **176 офлайн-инструментами** в 13 категориях (JSON / XML / YAML / SQL, Base64 / JWT, хеши / AES, метки времени / Cron, регулярные выражения, цвета, HTTP / Curl, конвертеры кода, помощники для Apple, включая **энциклопедию моделей устройств на ~255 записей** и размеры экранов, и многое другое), а также **14 двуязычных тем со шпаргалками** (~420 записей). Сохраняйте **избранное, историю и сниппеты**; отправляйте текст через **«Поделиться»** с умными подсказками; добавляйте **виджеты**, **Live Activity для «Фокуса»**, **Siri и «Быстрые команды»** и Пункт управления. **Без рекламы. Без отслеживания. Сетевые инструменты работают только тогда, когда вы сами запускаете запрос.**

## Начало работы (шаг за шагом)

### 1. Первый запуск

1. Установите приложение из [App Store](https://apps.apple.com/app/id1240856775) и откройте **iDeveloper**.
2. Пройдите **приветственный гид** (инструменты → справочники → рабочий процесс → системные функции → конфиденциальность).
3. Повторить можно в любой момент: **Настройки → Справка → Обзор функций**.
4. Встроенные руководства по **использованию / виджетам / «Быстрым командам»** находятся в **Настройки → Справка**.

### 2. Откройте инструмент и получите результат

1. На экране **«Главная»** или в **«Обзоре»** выберите инструмент (например, JSON, Base64, метка времени, регулярные выражения).
2. Вставьте или введите данные — либо используйте **«Отправить в инструмент»** / расширение **«Поделиться»** с умными рекомендациями (Рекомендуемые → Недавние → Все).
3. Запустите инструмент, скопируйте результат и при желании сохраните **сниппет** или восстановите данные из **истории** (в двухпанельных инструментах восстанавливаются обе стороны).
4. Связанные инструменты появляются как ненавязчивые ссылки, когда они уместны для следующего шага.

### 3. Используйте офлайн-шпаргалки

1. Откройте центр **«Справочники»** или перейдите к теме (HTTP / заголовки / MIME / Git / Docker / Cron / SQL / регулярные выражения / SSH / npm / Kubernetes / Linux / JWT / TLS).
2. Ищите по всему содержимому или открывайте конкретную запись по глубокой ссылке `ideveloper://reference?id=…`.
3. Закрепляйте избранное и добавляйте виджеты ежедневного справочника на экран «Домой».

### 4. Постройте рабочий процесс, который вы действительно сохраните

1. Отмечайте звёздочкой инструменты и записи справочников, которыми пользуетесь каждую неделю.
2. Возвращайтесь в **«Недавние»** и **«Историю»**, вместо того чтобы вводить всё заново.
3. Сохраняйте повторно используемые **сниппеты** — готовые к вставке фрагменты.
4. Из другого приложения нажмите «Поделиться» → iDeveloper: список сначала покажет наиболее подходящие инструменты.

### 5. Виджеты, Live Activity «Фокуса» и Siri

1. Нажмите и удерживайте экран «Домой» → **Изменить виджеты** → добавьте «Справочник дня» / «Быстрые инструменты» / «Метка времени» / «Избранное» (размеры для экрана «Домой» и экрана блокировки — где доступны).
2. Запустите таймер **«Фокуса»**, чтобы показать **Live Activity** на экране блокировки / в Dynamic Island.
3. Попросите **Siri** или используйте «Быстрые команды» для поиска, избранного, фокуса и частых инструментов.
4. Настройте быстрые действия на экране «Домой» и элементы Пункта управления (iOS 18+).

### 6. Оформление и конфиденциальность

1. Выберите тему, акцентный цвет (9 вариантов), язык (EN / 简 / 繁) и размер текста.
2. Включайте и отключайте вкладки; при желании пусть виджеты следуют теме приложения; выберите альтернативную иконку приложения.
3. Основные инструменты и шпаргалки работают **офлайн**. Инструменты, которым нужна сеть, показывают понятный запрос и отправляют данные только тогда, когда **вы** нажимаете кнопку.
4. Необязательные чаевые (StoreKit) никогда не открывают платный контент и не создают учётную запись.

## Почему стоит скачать

- **Одна студия вместо двадцати вкладок** — форматтеры, криптография, время, регулярные выражения, помощники HTTP и инструменты для Apple в спокойном нативном интерфейсе.
- **Шпаргалки всегда с вами** — двуязычные офлайн-справочники с поиском, избранным и виджетами.
- **Память рабочего процесса** — избранное, восстановление из истории, сниппеты и маршрутизация «Поделиться», предлагающая нужный инструмент.
- **Нативно там, где это важно** — виджеты, Live Activity, расширение «Поделиться», Пункт управления, Siri, Spotlight, глубокие ссылки.
- **Конфиденциальность по умолчанию** — без учётной записи, без рекламы, без SDK аналитики; вы сами решаете, когда что-то уходит в сеть.

- JSON / XML / YAML / SQL · кодирование · криптография · время / Cron · регулярные выражения · цвет · числа / Diff · HTTP / Curl · конвертеры кода · помощники для Apple · UUID / QR · таймер «Фокуса» и другое
- Переходы к связанным инструментам и примеры ввода

- **14** тем · ~**420** двуязычных записей
- Отложенная подгрузка фрагментов + поисковый индекс
- Виджеты ежедневного справочника

### Память рабочего процесса
- Избранное · недавние инструменты · история операций · сниппеты

### Матрица нативных возможностей
- Виджеты «Домой» / экрана блокировки · Live Activity «Фокуса» · Пункт управления · App Intents / Siri · быстрые действия на экране «Домой» · глубокие ссылки `ideveloper://`
