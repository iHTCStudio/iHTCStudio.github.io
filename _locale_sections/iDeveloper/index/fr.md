**Livrez plus vite. Retrouvez l’info sans quitter votre poche.**

iDeveloper (爱开发者 / 愛開發者) est un **studio de poche pour développeurs** sur iPhone, iPad et Mac — pas un énième tas d’outils. **Aucun compte requis.** Utilisez **176 outils hors ligne** répartis en 13 catégories (JSON / XML / YAML / SQL, Base64 / JWT, hash / AES, horodatages / Cron, regex, couleurs, HTTP / Curl, convertisseurs de code, utilitaires Apple dont une **encyclopédie des modèles d’appareils (~255 entrées)** et les tailles d’écran, etc.) ainsi que **14 thèmes d’aide-mémoire bilingues** (~420 entrées). Gardez **favoris, historique et snippets** ; envoyez du texte via **Partager** avec des suggestions intelligentes ; ajoutez des **widgets**, une **Live Activity Concentration**, **Siri et Raccourcis** et le Centre de contrôle. **Pas de publicité. Pas de suivi. Les outils réseau ne s’exécutent que lorsque vous lancez une requête.**

## Premiers pas (étape par étape)

### 1. Premier lancement

1. Installez l’app depuis l’[App Store](https://apps.apple.com/app/id1240856775) et ouvrez **iDeveloper**.
2. Suivez le **guide de bienvenue** (outils → références → workflow → fonctions système → confidentialité).
3. Rejouez-le à tout moment : **Réglages → Aide → Guide des fonctionnalités**.
4. Les guides intégrés **Utilisation / Widgets / Raccourcis** se trouvent sous **Réglages → Aide**.

### 2. Ouvrir un outil et obtenir un résultat

1. Depuis **Accueil** ou **Parcourir**, choisissez un outil (p. ex. JSON, Base64, horodatage, regex).
2. Collez ou saisissez votre entrée — ou utilisez **Envoyer vers l’outil** / l’extension **Partager** avec recommandations intelligentes (Suggérés → Récents → Tous).
3. Exécutez l’outil, copiez le résultat et, si vous le souhaitez, enregistrez un **snippet** ou restaurez depuis l’**historique** (les outils à double panneau restaurent les deux côtés).
4. Des outils associés apparaissent sous forme de liens discrets lorsqu’ils sont utiles pour l’étape suivante.

### 3. Utiliser les aide-mémoire hors ligne

1. Ouvrez le centre **Références** ou accédez directement à un thème (HTTP / En-têtes / MIME / Git / Docker / Cron / SQL / Regex / SSH / npm / Kubernetes / Linux / JWT / TLS).
2. Recherchez globalement ou ouvrez une entrée précise via le lien profond `ideveloper://reference?id=…`.
3. Épinglez vos favoris et affichez les widgets de référence quotidienne sur l’écran d’accueil.

### 4. Construire un workflow que vous garderez vraiment

1. Mettez en favori les outils et entrées de référence que vous utilisez chaque semaine.
2. Revenez à **Récents** et **Historique** plutôt que de tout retaper.
3. Enregistrez des **snippets** réutilisables, prêts à coller.
4. Depuis une autre app, partagez vers iDeveloper — le sélecteur classe d’abord les outils les plus pertinents.

### 5. Widgets, Live Activity Concentration et Siri

1. Appui long sur l’écran d’accueil → **Modifier les widgets** → ajoutez Référence du jour / Outils rapides / Horodatage / Favoris (tailles Écran d’accueil et Écran verrouillé selon disponibilité).
2. Lancez un minuteur de **Concentration** pour afficher la **Live Activity** sur l’écran verrouillé / la Dynamic Island.
3. Demandez à **Siri** ou utilisez Raccourcis pour la recherche, les favoris, la concentration et les outils courants.
4. Configurez les actions rapides de l’écran d’accueil et les contrôles du Centre de contrôle (iOS 18+).

### 6. Apparence et confidentialité

1. Choisissez le thème, la couleur d’accent (9 options), la langue (EN / 简 / 繁) et la taille du texte.
2. Affichez ou masquez les onglets ; faites éventuellement suivre aux widgets le thème de l’app ; choisissez une autre icône d’app.
3. Les outils essentiels et les aide-mémoire fonctionnent **hors ligne**. Les outils qui ont besoin du réseau affichent une invite claire et n’envoient une requête que lorsque **vous** appuyez.
4. Le pourboire facultatif (StoreKit) ne débloque jamais de contenu payant et ne crée jamais de compte.

## Pourquoi la télécharger

- **Un studio au lieu de vingt onglets** — formateurs, chiffrement, temps, regex, aides HTTP et outils orientés Apple dans une interface native et sereine.
- **Des aide-mémoire qui vous suivent** — références bilingues hors ligne avec recherche, favoris et widgets.
- **Mémoire de workflow** — favoris, restauration de l’historique, snippets et routage du partage qui suggère le bon outil.
- **Natif là où ça compte** — widgets, Live Activity, extension Partager, Centre de contrôle, Siri, Spotlight, liens profonds.
- **Confidentialité par défaut** — pas de compte, pas de publicité, pas de SDK d’analyse ; vous décidez quand quelque chose passe en ligne.

## Fonctionnalités

### Boîte à outils
- **176** outils · **13** catégories (dont modèles d’appareils)
- JSON / XML / YAML / SQL · encodage · chiffrement · temps / Cron · regex · couleur · nombres / Diff · HTTP / Curl · convertisseurs de code · utilitaires Apple · UUID / QR · minuteur Concentration, et plus
- Sauts vers les outils associés et exemples d’entrées

### Références hors ligne
- **14** thèmes · ~**420** entrées bilingues
- Fragments chargés à la demande + index consultable
- Widgets de référence quotidienne

### Mémoire de workflow
- Favoris · outils récents · historique des opérations · snippets
- Extension Partager avec Suggérés / Récents / Tous
- Recherche globale et Spotlight

### Matrice des capacités natives
- Widgets Accueil / Verrouillage · Live Activity Concentration · Centre de contrôle · App Intents / Siri · actions rapides de l’écran d’accueil · liens profonds `ideveloper://`

### Confidentialité
- **Aucun compte · aucune publicité · aucun SDK d’analyse tiers**
- Hors ligne d’abord ; les outils réseau sont activés action par action
- iCloud KVS privé facultatif pour certaines préférences / données de workflow
