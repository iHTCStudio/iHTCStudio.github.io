**최종 업데이트:** 2026년 7월 29일

iHTC Studio(이하 "당사")는 **iDeveloper**(별칭 "爱开发者" / "愛開發者", 번들 ID `com.iHTCboy.iDeveloper`)를 만들었습니다. 이 개인정보 처리방침은 앱을 사용할 때 어떤 데이터가 처리되는지(그리고 처리되지 않는지)를 설명합니다. **Apple App Review**와 사용자는 이 페이지를 공개 개인정보 URL로 활용할 수 있습니다.

## 요약 (Apple 개인정보 보호 영양 성분 라벨 대응)

| 항목 | 당사의 운영 방식 |
|------|------------------|
| 계정 | **필요 없음** |
| iHTC Studio의 데이터 수집 | **데이터 수집 안 함** — 도구 입력이나 개인 데이터를 받는 백엔드를 **운영하지 않습니다** |
| 네트워크 | 도구와 치트시트는 기본적으로 **오프라인**으로 작동합니다. 네트워크 사용 도구는 **사용자**가 시작할 때만 요청을 보냅니다 |
| 분석 / 광고 / 추적 | **없음** — 서드파티 분석, 광고, 추적 SDK를 사용하지 않습니다 |
| 선택적 Apple 서비스 | **iCloud**(사용자의 비공개 KVS), **StoreKit** 팁, 사용자가 선택하는 시스템 공유 대상, Apple이 제공하는 위젯 / 실시간 현황 / Siri |

## 데이터 수집

광고나 분석 목적으로 개인정보를 수집, 판매 또는 공유하지 **않습니다**. 입력, 출력, 즐겨찾기, 기록, 스니펫은 기기에(선택적으로 **사용자의** iCloud에) 남습니다. **당사는 이 앱을 위한 서버를 운영하지 않기** 때문에 iHTC Studio 서버로 업로드되지 않습니다.

## 앱 작동 방식

- **내장 도구 및 참고 자료** — 엔진과 치트시트 JSON은 앱 / 위젯 / 공유 확장 번들 안에 포함되어 있습니다.
- **기기 내 처리** — 포맷, 인코딩, 암호화 도우미, 정규식 및 대부분의 유틸리티는 로컬에서 실행됩니다.
- **선택 시에만 네트워크 사용** — 도구가 인터넷을 필요로 하면 UI에 안내가 표시됩니다. 요청은 사용자의 동작으로만 시작되며 해당 도구의 대상 호스트로 전송됩니다. iHTC Studio 프록시를 거치지 않습니다.
- **공유 확장** — 공유된 텍스트/데이터는 기기의 앱 그룹 `group.com.iHTCboy.iDeveloper`를 통해 전달됩니다.
- **위젯 및 실시간 현황** — 이미 열어 본 콘텐츠나 시작한 타이머의 스냅샷을 앱 그룹 / ActivityKit을 통해 표시합니다.
- **선택적 팁** — Apple이 처리하는 소모성 **StoreKit** 구매입니다.

## 기기에 저장되는 데이터

| 데이터 | 목적 |
|--------|------|
| 도구 카탈로그 및 참고 자료 라이브러리 | 오프라인 도구와 치트시트 |
| 즐겨찾기 / 최근 도구 | 빠른 접근 |
| 작업 기록 | 이전 입력/출력 복원 |
| 스니펫 | 사용자가 저장한 재사용 가능한 조각 |
| 공유 받은 편지함 버퍼 | 공유 / 도구로 보내기에서 오는 임시 전달 |
| 화면 모양 및 환경설정 | 테마, 강조 색상, 언어, 탭, 위젯 |
| 집중 / 실시간 현황 상태 | 타이머 표시 |
| 온보딩 및 평가 안내 | 환영 / 리뷰 경험 |

## iCloud 동기화(선택)

활성화하면 일부 환경설정 / 워크플로 상태가 **사용자의 Apple ID**에 연결된 Apple의 **`NSUbiquitousKeyValueStore`**를 통해 동기화될 수 있습니다. 동기화 트래픽은 iHTC Studio가 아닌 **Apple iCloud**로 전송됩니다.

## 권한

iDeveloper는 기능이 필요로 할 때만 권한을 요청합니다(예: 도구가 내보낸 이미지를 저장할 때의 사진 보관함, 네트워크 도구를 실행할 때의 네트워크). 분석을 위해 추적, 연락처, 정확한 위치를 요청하지 **않습니다**.
