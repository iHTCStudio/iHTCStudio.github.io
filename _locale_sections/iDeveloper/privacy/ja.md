**最終更新日：** 2026年7月29日

iHTC Studio（以下「当社」）は **iDeveloper**（別名「爱开发者」/「愛開發者」、Bundle ID `com.iHTCboy.iDeveloper`）を開発しました。本プライバシーポリシーは、本アプリをご利用いただく際にどのようなデータが取り扱われるか（および取り扱われないか）を説明するものです。**Apple App Review** およびユーザーは、本ページを公開プライバシー URL としてご利用いただけます。

## 概要（Apple のプライバシー栄養ラベルとの対応）

| 項目 | 当社の運用 |
|------|------------|
| アカウント | **不要** |
| iHTC Studio によるデータ収集 | **データは収集されません** — ツールの入力内容や個人データを受信するバックエンドは**運用していません** |
| ネットワーク | ツールと早見表は既定で**オフライン**動作します。ネットワーク対応ツールは、**あなた**が開始したときだけリクエストを送信します |
| 解析 / 広告 / トラッキング | **なし** — サードパーティの解析・広告・トラッキング SDK は使用しません |
| 任意の Apple サービス | **iCloud**（あなたのプライベート KVS）、**StoreKit** のチップ、あなたが選ぶシステムの共有先、Apple が提供するウィジェット / ライブアクティビティ / Siri |

## データ収集

広告や解析のために個人情報を収集・販売・共有することは**ありません**。入力内容、出力、お気に入り、履歴、スニペットはお使いの端末内（任意で**あなたの** iCloud 内）にのみ保存されます。**当社は本アプリ用にそのようなサーバーを運用していない**ため、iHTC Studio のサーバーにアップロードされることはありません。

## アプリの仕組み

- **同梱のツールとリファレンス** — エンジンと早見表の JSON は、アプリ / ウィジェット / 共有機能拡張のバンドルに含まれています。
- **端末内処理** — フォーマット、エンコード、暗号ヘルパー、正規表現、ほとんどのユーティリティはローカルで実行されます。
- **オプトインのネットワーク** — ツールがインターネットを必要とする場合、UI に確認が表示されます。リクエストはあなたの操作でのみ開始され、そのツール固有の宛先ホストに送信されます。iHTC Studio のプロキシは経由しません。
- **共有機能拡張** — 共有されたテキスト / データは、端末上の App Group `group.com.iHTCboy.iDeveloper` を介して受け渡されます。
- **ウィジェットとライブアクティビティ** — すでに開いたコンテンツや開始したタイマーのスナップショットを、App Group / ActivityKit 経由で表示します。
- **任意のチップ** — Apple が処理する消耗型 **StoreKit** 購入です。

## 端末内に保存されるデータ

| データ | 目的 |
|--------|------|
| ツールカタログとリファレンスライブラリ | オフラインのツールと早見表 |
| お気に入り / 最近使ったツール | すばやいアクセス |
| 操作履歴 | 以前の入力 / 出力の復元 |
| スニペット | あなたが保存した再利用可能な断片 |
| 共有受信バッファ | 共有 / ツールに送信 からの一時的な受け渡し |
| 外観と設定 | テーマ、アクセント、言語、タブ、ウィジェット |
| 集中 / ライブアクティビティの状態 | タイマー表示 |
| オンボーディングと評価の案内 | ウェルカム / レビューの体験 |

## iCloud 同期（任意）

有効にすると、一部の設定 / ワークフローの状態が、**あなたの Apple ID** に紐づく Apple の **`NSUbiquitousKeyValueStore`** を通じて同期されることがあります。同期の通信先は **Apple iCloud** であり、iHTC Studio ではありません。

## 権限

iDeveloper は、機能が必要とする場合にのみ権限を求めます（例：ツールが書き出した画像を保存する際の写真ライブラリ、ネットワークツールを実行する際のネットワーク）。解析目的でトラッキング、連絡先、正確な位置情報を求めることは**ありません**。
