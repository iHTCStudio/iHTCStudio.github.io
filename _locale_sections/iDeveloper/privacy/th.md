**อัปเดตล่าสุด:** 29 กรกฎาคม 2026

iHTC Studio ("เรา") พัฒนา **iDeveloper** (หรือชื่อ "爱开发者" / "愛開發者" Bundle ID `com.iHTCboy.iDeveloper`) นโยบายความเป็นส่วนตัวนี้อธิบายว่าข้อมูลใดถูกประมวลผล (และข้อมูลใดไม่ถูกประมวลผล) เมื่อคุณใช้แอป **Apple App Review** และผู้ใช้สามารถอ้างอิงหน้านี้เป็น URL ความเป็นส่วนตัวสาธารณะได้

## สรุป (สอดคล้องกับป้ายโภชนาการความเป็นส่วนตัวของ Apple)

| หัวข้อ | แนวปฏิบัติของเรา |
|--------|------------------|
| บัญชี | **ไม่จำเป็น** |
| การเก็บข้อมูลโดย iHTC Studio | **ไม่มีการเก็บข้อมูล** — เรา**ไม่ได้**ดำเนินการแบ็กเอนด์ที่รับข้อมูลนำเข้าจากเครื่องมือหรือข้อมูลส่วนบุคคลของคุณ |
| เครือข่าย | เครื่องมือและชีตสรุปทำงาน**ออฟไลน์**ตามค่าเริ่มต้น เครื่องมือที่ใช้เครือข่ายได้จะส่งคำขอเฉพาะเมื่อ**คุณ**เริ่มเอง |
| การวิเคราะห์ / โฆษณา / การติดตาม | **ไม่มี** — ไม่มี SDK วิเคราะห์ โฆษณา หรือติดตามของบุคคลที่สาม |
| บริการของ Apple แบบไม่บังคับ | **iCloud** (KVS ส่วนตัวของคุณ), ทิปผ่าน **StoreKit**, ปลายทางแชร์ของระบบที่คุณเลือก, วิดเจ็ต / Live Activity / Siri ที่ Apple เป็นผู้ให้บริการ |

## การเก็บข้อมูล

เรา**ไม่**เก็บ ขาย หรือแบ่งปันข้อมูลส่วนบุคคลเพื่อการโฆษณาหรือการวิเคราะห์ ข้อมูลนำเข้า ผลลัพธ์ รายการโปรด ประวัติ และสนิปเป็ตของคุณอยู่บนอุปกรณ์ของคุณ (และอยู่ใน iCloud ของ**คุณ**หากเลือกเปิดใช้) ข้อมูลเหล่านี้จะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ของ iHTC Studio เพราะ**เราไม่ได้ดำเนินการเซิร์ฟเวอร์ดังกล่าวสำหรับแอปนี้**

## แอปทำงานอย่างไร

- **เครื่องมือและข้อมูลอ้างอิงที่มาพร้อมแอป** — เอนจินและ JSON ของชีตสรุปอยู่ในบันเดิลของแอป วิดเจ็ต และส่วนขยายแชร์
- **ประมวลผลบนอุปกรณ์** — การจัดรูปแบบ การเข้ารหัส ตัวช่วยคริปโต regex และยูทิลิตีส่วนใหญ่ทำงานในเครื่อง
- **เครือข่ายเมื่อคุณเลือกเท่านั้น** — หากเครื่องมือต้องใช้อินเทอร์เน็ต UI จะแสดงข้อความแจ้ง คำขอจะเริ่มจากการกระทำของคุณเท่านั้น และส่งไปยังโฮสต์ปลายทางของเครื่องมือนั้น — ไม่ผ่านพร็อกซีของ iHTC Studio
- **ส่วนขยายแชร์** — ข้อความ/ข้อมูลที่แชร์จะส่งต่อบนอุปกรณ์ของคุณผ่าน App Group `group.com.iHTCboy.iDeveloper`
- **วิดเจ็ตและ Live Activity** — แสดงภาพสแนปช็อตของเนื้อหาที่คุณเปิดไปแล้วหรือตัวจับเวลาที่คุณเริ่ม ผ่าน App Group / ActivityKit
- **ทิปแบบไม่บังคับ** — การซื้อแบบใช้หมดไปผ่าน **StoreKit** ดำเนินการโดย Apple

## ข้อมูลที่จัดเก็บบนอุปกรณ์ของคุณ

| ข้อมูล | วัตถุประสงค์ |
|--------|--------------|
| แคตตาล็อกเครื่องมือและคลังข้อมูลอ้างอิง | เครื่องมือและชีตสรุปออฟไลน์ |
| รายการโปรด / เครื่องมือล่าสุด | เข้าถึงได้รวดเร็ว |
| ประวัติการใช้งาน | กู้คืนข้อมูลนำเข้า/ผลลัพธ์ก่อนหน้า |
| สนิปเป็ต | ชิ้นส่วนที่ใช้ซ้ำได้ซึ่งคุณบันทึกไว้ |
| บัฟเฟอร์กล่องรับจากแชร์ | การส่งต่อชั่วคราวจากแชร์ / ส่งไปยังเครื่องมือ |
| รูปลักษณ์และการตั้งค่า | ธีม สีเน้น ภาษา แท็บ วิดเจ็ต |
| สถานะโฟกัส / Live Activity | การแสดงตัวจับเวลา |
| การแนะนำการใช้งานและการขอให้ให้คะแนน | ประสบการณ์ต้อนรับ / รีวิว |

## การซิงก์ iCloud (ไม่บังคับ)

หากเปิดใช้ การตั้งค่า / สถานะเวิร์กโฟลว์บางส่วนอาจซิงก์ผ่าน **`NSUbiquitousKeyValueStore`** ของ Apple ซึ่งผูกกับ **Apple ID ของคุณ** ทราฟฟิกการซิงก์ไปยัง **Apple iCloud** ไม่ใช่ iHTC Studio

## สิทธิ์การเข้าถึง

iDeveloper ขอสิทธิ์เฉพาะเมื่อฟีเจอร์ต้องใช้ (เช่น คลังรูปภาพ หากเครื่องมือบันทึกรูปที่คุณส่งออก หรือเครือข่ายเมื่อคุณเรียกใช้เครื่องมือเครือข่าย) เรา**ไม่**ขอสิทธิ์การติดตาม รายชื่อติดต่อ หรือตำแหน่งที่แม่นยำเพื่อการวิเคราะห์
