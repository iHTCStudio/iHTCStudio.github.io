iLinux は、**iPhone、iPad、Mac** 上の **Linux**、**Windows CMD/Batch**、**PowerShell** 用のプライバシー優先の完全オフライン **シェル コマンド リファレンスおよび学習アプリ**です。コンテンツ言語ごとに **1650+** コマンドを参照し、Markdown ドキュメントを読み、クロスプラットフォームの同等のコマンドを比較し、各シェル ライブラリに範囲を絞った毎日のクイズに答え、お気に入り、学習ステータス、誤った回答を追跡します。コア ライブラリは **アカウントなし**で動作します。オプションの **iCloud 同期** を使用すると、Apple デバイス全体で進行状況を調整できます。

> **重要:** iLinux は、ローカルのリファレンスおよび学習のパートナーです。これは、デバイス上のシェル コマンドを検索して学習するのに役立ちます。 **実際の端末、リモート サーバー、またはその他のマシンに接続したり、それらのマシン上でコマンドを実行したりすることはありません。**

## はじめに

1. iLinux を開きます。ツールバー (ターミナル アイコン) の **シェル プラットフォーム** メニューを使用して、**Linux**、**CMD/Batch**、または **PowerShell** を選択します。
2. **コマンド**からコマンドを参照するか、**カテゴリ**に切り替えてトピックベースの探索を行ってください。 **Mac** では、下部のタブではなく **サイドバー** からセクションを選択します。
3. 任意のコマンドを開いて、その概要、完全な Markdown ドキュメント、**クロスプラットフォームの同等物** (利用可能な場合) を読みます。
4. **デイリー クイズ** に移動して、**現在のシェル プラットフォーム** 用の今日のクイズ セットで練習してください。
5. **⌘F** を押して (または iOS では拡大鏡をタップして)、コマンド名または説明で検索します。
6. コマンドにスターを付けて **お気に入り**に追加します。詳細ページまたはリストアクションから **学習ステータス** (未学習/学習/習得) を設定します。
7. **設定**を開いて、テーマ、言語 (iOS/iPad)、リスト/グリッド レイアウト、お気に入りの範囲、**iCloud 同期**、ウィジェット シェル ライブラリ (iOS/iPad)、およびホーム画面のショートカット (iOS/iPad) をカスタマイズします。

## コマンドライブラリ

各コンテンツ言語 (英語、簡体字中国語、繁体字中国語) には、次の 3 つのオフライン ライブラリが同梱されています。

| シェルプラットフォーム | コマンド | カテゴリー |
|----------------|----------|------------|
| **Linux** | 1050 | 14 |
| **CMD / バッチ** | 300 | 10 |
| **PowerShell** | 300 | 10 |
| **合計** | **1650+** | プラットフォームごと |

**コマンド**、**カテゴリ**、または**デイリークイズ**のツールバーからライブラリを切り替えます。選択内容が維持され、検索、カテゴリ、クイズの質問、および (iOS/iPad の) ウィジェット コンテンツが実行されます。

|---|----------|

| 2 | ファイル転送 |

## 特長

### クロスプラットフォームの同等物

**100 を超える同等のグループ** が Linux、CMD​​、PowerShell コマンドにリンクします (例: `ls` ↔ `dir` ↔ `Get-ChildItem`)。コマンド詳細ページの **同等** バーを使用すると、1 回のタップまたはクリックで別のプラットフォームにジャンプできます。

### コマンド

- **A–Z インデックス** — オプションの **お気に入り** および **最近** セクション (設定で切り替え)。
- **リストとグリッド ビュー** - **iPhone では 1 ～ 6 列**、iPad および Mac では **1 ～ 8 列** (各デバイスは個別に記憶します)。
- **クイック フィルター** — すべて、お気に入り、最近、未学習。
- **全文検索** — 現在のシェル ライブラリ内。入力すると結果が更新されます。
- **コマンドの詳細** - 概要と構文の強調表示付きのマークダウン。
- **学習ステータス** — 未学習 / 学習済み / 習得済み。
- **共有** — **Markdown ファイル** または **スタイル付き PNG 共有カード** をエクスポートします。

### 毎日のクイズ

- 毎日のクイズ セットは **アクティブなシェル プラットフォームを対象としています**。
- **一致概要** および **一致オプションの意味** 質問タイプ。
- **ランダム リフレッシュ** および **パーフェクト ストリーク** (プラットフォームごと)。
- 間違った答えは **間違った答えブック** に保存されます。

### 学習の進捗状況と iCloud 同期

- **範囲**の**お気に入り** (すべてのプラットフォームと現在のプラットフォームのみ)。
- **最近**、**学習状況**、**誤答記録**。
- **iCloud 同期** (オプション、[設定] → [学習統計]): 同じ Apple ID にサインインすると、**お気に入り**、**クイズの進行状況**、**テーマ**、**表示設定** (言語、シェル プラットフォーム、お気に入りの範囲、リスト/グリッド) が **iPhone、iPad、Mac** 間で同期されます。競合は自動的にマージされます (お気に入りの結合など)。他のデバイスに影響を与えずにデバイスごとに無効にします。 iCloudが必要です。コマンド ライブラリは完全にオフラインのままです。

### macOS デスクトップ エクスペリエンス

ネイティブ **macOS 13.0+** アプリ (Mac Catalyst ではない):

- **サイドバー シェル** — `NavigationSplitView` レイアウトのコマンド、カテゴリ、毎日のクイズおよび設定。
- **ウィンドウ サイズ** - 最小 **900×560**、デフォルト **1100×720**。サイズ変更可能なデスクトップウィンドウ。
- **拡張キーボード ショートカット** — **⌘,** 設定; **⌘[** / **Esc** 戻る; **⌘← / ⌘→** 前/次のカテゴリ;クイズ キー **1 ～ 4**、**⌘R** 再シャッフル、**次の質問に戻る**。
- **システム設定スタイルのトグル** とデスクトップに最適化されたシート。
- **共有** macOS 共有ピッカー経由。 **フィードバック** `mailto:` またはメール クライアント経由で。

**Mac の制限 (仕様による):** ホーム画面の **ウィジェット**、**ホーム画面のクイック アクション**、**代替アプリ アイコン**は **iOS/iPad のみ**です。 「設定」に通知が表示されます — iPhone または iPad でウィジェットを設定します。

### iPhoneとiPad

- **タブ バー** ナビゲーション (コマンド / カテゴリ / クイズ / 設定)。
- **5 つのホーム画面とロック画面ウィジェット**、構成可能なシェル ライブラリとデイリー コマンド シャッフル (iOS 17 以降)。
- **ホーム画面のクイック アクション** — 7 つのオプションから最大 4 つ。
- **6 つのアプリ アイコン** - デフォルトと 5 つの代替アイコン。
- 主要なアクションに関する**触覚フィードバック**。

### URLスキーム

`ilinux://` deep links work on **iOS, iPad and Mac** (command detail with optional `platform=`, quiz, favourites, wrong book). Home Screen quick-action-only URLs (`search`, `categories`, `feedback`, `review`) remain **iOS/iPad only**. See [URL Scheme Reference](url-scheme).

### テーマと言語

- **15 色のプリセット** + **カスタム アクセント**;ライト/ダーク/システム。
- **UI とコンテンツの言語:** 英語、简体中文、繁體中文、またはシステム - **iOS/iPad** の **[設定] → [言語]** のピッカー。設定が有効になっている場合、**iCloud 経由で Mac に同期**します。

## システム要件

| プラットフォーム | 最小値 | 注意事項 |
|----------|---------|-------|
| iPhone / iPad | iOS16.0以降 | ウィジェットには iOS 17.0 以降が必要です |
| マック | macOS 13.0以降 | ネイティブサイドバーアプリ。ウィジェットなし |
| 検索オートフォーカス（⌘F） | iOS 17.0以降 / macOS 14.0以降 | 以前の OS では検索が開きます。マニュアルフォーカスが必要な場合があります |

## キーボードショートカット

**すべてのプラットフォーム (iPad キーボードおよび Mac メニュー):**

| ショートカット | アクション |
|----------|--------|
| ⌘F | 検索を開く |
| ⌘1 | コマンド |
| ⌘2 | カテゴリー |
| ⌘3 | 毎日のクイズ |
| ⌘4 | 設定 |

**Mac のみ:**

| ショートカット | アクション |
|----------|--------|
| ⌘, | 設定 |
| ⌘[ / Esc | 戻る |
| ⌘← / ⌘→ | 前/次のカテゴリ |
| 1–4 | クイズの答えを選択 |
| ⌘R | 入れ替えクイズ |
| 戻る | 次のクイズの問題（解答後） |
