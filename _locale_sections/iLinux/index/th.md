iLinux is a privacy-first, fully offline **shell command reference and learning app** for **Linux**, **Windows CMD/Batch**, and **PowerShell** — on **iPhone, iPad and Mac**. Browse **1650+** commands per content language, read Markdown documentation, compare cross-platform equivalents, take daily quizzes scoped to each shell library, and track favourites, learning status and wrong answers. Core libraries work **without any account**; optional **iCloud sync** keeps progress aligned across your Apple devices.

> **ข้อสำคัญ:** iLinux เป็นข้อมูลอ้างอิงและการเรียนรู้ในท้องถิ่น ช่วยให้คุณค้นหาและศึกษาคำสั่งเชลล์บนอุปกรณ์ของคุณ **ไม่ได้เชื่อมต่อหรือดำเนินการคำสั่งบนเทอร์มินัลจริง เซิร์ฟเวอร์ระยะไกล หรือเครื่องอื่นใด**

## เริ่มต้นใช้งาน

1. เปิด iLinux ใช้เมนู **แพลตฟอร์ม Shell** ในแถบเครื่องมือ (ไอคอนเทอร์มินัล) เพื่อเลือก **Linux**, **CMD/Batch** หรือ **PowerShell**
2. เรียกดูคำสั่งจาก **คำสั่ง** หรือสลับไปที่ **หมวดหมู่** เพื่อการสำรวจตามหัวข้อ บน **Mac** ให้เลือกส่วนจาก **แถบด้านข้าง** แทนแท็บด้านล่าง
3. เปิดคำสั่งใดๆ เพื่ออ่านข้อมูลสรุป เอกสารประกอบ Markdown ฉบับเต็ม และ **เทียบเท่าข้ามแพลตฟอร์ม** (หากมี)
4. ไปที่ **แบบทดสอบรายวัน** เพื่อฝึกฝนชุดแบบทดสอบของวันนี้สำหรับ **แพลตฟอร์มเชลล์ปัจจุบัน**
5. กด **⌘F** (หรือแตะแว่นขยายบน iOS) เพื่อค้นหาตามชื่อคำสั่งหรือคำอธิบาย
6. ติดดาวคำสั่งเพื่อเพิ่มลงใน **รายการโปรด**; ตั้งค่า **สถานะการเรียนรู้** (ไม่ได้เรียนรู้ / เรียนรู้ / เชี่ยวชาญ) จากหน้ารายละเอียดหรือรายการการดำเนินการ
7. เปิด **การตั้งค่า** เพื่อปรับแต่งธีม ภาษา (iOS/iPad) รายการ/เค้าโครงตาราง ขอบเขตรายการโปรด **การซิงค์ iCloud** ไลบรารีเชลล์วิดเจ็ต (iOS/iPad) และทางลัดหน้าจอหลัก (iOS/iPad)

| แพลตฟอร์มเชลล์ | คำสั่ง | หมวดหมู่ |

## คุณสมบัติ

### การเทียบเท่าข้ามแพลตฟอร์ม

**กลุ่มที่เทียบเท่ามากกว่า 100 กลุ่ม** ลิงก์คำสั่ง Linux, CMD และ PowerShell — เช่น `ls` ↔ `dir` ↔ `Get-ChildItem` แถบ **เทียบเท่า** ในหน้ารายละเอียดคำสั่งช่วยให้คุณข้ามไปยังแพลตฟอร์มอื่นได้ด้วยการแตะหรือคลิกเพียงครั้งเดียว

### คำสั่ง

- **ดัชนี A–Z** — ตัวเลือก **รายการโปรด** และ **ล่าสุด** (สลับในการตั้งค่า)
- **มุมมองรายการและตาราง** — **1–6 คอลัมน์บน iPhone**, **1–8 บน iPad และ Mac** (อุปกรณ์แต่ละเครื่องจะจดจำแยกกัน)
- **ฟิลเตอร์ด่วน** — ทั้งหมด รายการโปรด ล่าสุด ยังไม่ได้เรียนรู้
- **การค้นหาข้อความแบบเต็ม** — ภายในไลบรารีเชลล์ปัจจุบัน ผลลัพธ์จะอัปเดตเมื่อคุณพิมพ์
- **รายละเอียดคำสั่ง** — สรุป + Markdown พร้อมการเน้นไวยากรณ์
- **สถานะการเรียนรู้** — ไม่ได้เรียน / เรียนรู้ / เชี่ยวชาญ
- **แชร์** — ส่งออก **ไฟล์ Markdown** หรือ **การ์ดแชร์ PNG ที่มีสไตล์**

### แบบทดสอบรายวัน

- ชุดคำถามรายวัน **กำหนดขอบเขตไว้ที่แพลตฟอร์มเชลล์ที่ใช้งานอยู่**
- **สรุปการจับคู่** และ **ความหมายตัวเลือกการจับคู่** ประเภทคำถาม
- **การรีเฟรชแบบสุ่ม** และ **การต่อเนื่องที่สมบูรณ์แบบ** (ต่อแพลตฟอร์ม)
- คำตอบที่ผิดบันทึกไว้ใน **หนังสือคำตอบที่ไม่ถูกต้อง**

### ความคืบหน้าการเรียนรู้และการซิงค์ iCloud

- **รายการโปรด** พร้อม **ขอบเขต** (ทุกแพลตฟอร์มเทียบกับแพลตฟอร์มปัจจุบันเท่านั้น)
- **ล่าสุด** **สถานะการเรียนรู้** และ **บันทึกคำตอบที่ผิด**
- **iCloud Sync** (ตัวเลือก ตัวเลือก การตั้งค่า → สถิติการเรียนรู้): เมื่อลงชื่อเข้าใช้ Apple ID เดียวกัน ซิงค์ **รายการโปรด** **ความคืบหน้าของแบบทดสอบ** **ธีม** และ **การตั้งค่าการแสดงผล** (ภาษา แพลตฟอร์มเชลล์ ขอบเขตรายการโปรด รายการ/ตาราง) ผ่าน **iPhone, iPad และ Mac** ความขัดแย้งจะผสานโดยอัตโนมัติ (เช่น การรวมรายการโปรด) ปิดการใช้งานต่ออุปกรณ์โดยไม่ส่งผลกระทบต่อผู้อื่น ต้องใช้ iCloud; ไลบรารีคำสั่งยังคงออฟไลน์โดยสมบูรณ์

### ประสบการณ์เดสก์ท็อป macOS

แอปเนทิฟ **macOS 13.0+** (ไม่ใช่ Mac Catalyst):

- **เปลือกแถบด้านข้าง** — คำสั่ง หมวดหมู่ แบบทดสอบรายวัน และการตั้งค่าในรูปแบบ `NavigationSplitView`
- **ขนาดหน้าต่าง** — ขั้นต่ำ **900×560** ค่าเริ่มต้น **1100×720**; หน้าต่างเดสก์ท็อปที่ปรับขนาดได้
- **แป้นพิมพ์ลัดแบบขยาย** — **⌘,** การตั้งค่า; **⌘[** / **Esc** ย้อนกลับ; **⌘← / ⌘→** หมวดหมู่ก่อนหน้า/ถัดไป; ปุ่มทดสอบ **1–4**, **⌘R** สับเปลี่ยน, **ย้อนกลับ** คำถามถัดไป
- **การสลับรูปแบบการตั้งค่าระบบ** และชีตที่ปรับให้เหมาะกับเดสก์ท็อป
- **แชร์** ผ่านเครื่องมือเลือกการแชร์ macOS **คำติชม** ผ่านทาง `mailto:` หรือโปรแกรมรับส่งเมลของคุณ

**ข้อจำกัดของ Mac (ตามการออกแบบ):** หน้าจอหลัก **วิดเจ็ต**, **การดำเนินการด่วนบนหน้าจอหลัก** และ **ไอคอนแอปสำรอง** เป็น **iOS/iPad เท่านั้น** การตั้งค่าจะแสดงการแจ้งเตือน — กำหนดค่าวิดเจ็ตบน iPhone หรือ iPad

### ไอโฟนและไอแพด

- **แถบแท็บ** การนำทาง (คำสั่ง / หมวดหมู่ / แบบทดสอบ / การตั้งค่า)
- **5 วิดเจ็ตหน้าจอหลักและหน้าจอล็อค** พร้อมไลบรารีเชลล์ที่กำหนดค่าได้และการสับเปลี่ยนคำสั่งรายวัน (iOS 17+)
- **การดำเนินการด่วนบนหน้าจอหลัก** — สูงสุด 4 รายการจาก 7 ตัวเลือก
- **ไอคอนแอป 6 ไอคอน** — ค่าเริ่มต้นบวกอีก 5 รายการ
- **การตอบสนองแบบสัมผัส** ในการดำเนินการหลัก

### โครงการ URL

`ilinux://` deep links work on **iOS, iPad and Mac** (command detail with optional `platform=`, quiz, favourites, wrong book). Home Screen quick-action-only URLs (`search`, `categories`, `feedback`, `review`) remain **iOS/iPad only**. See [URL Scheme Reference](url-scheme).

### ธีมและภาษา

- **ค่าสีที่ตั้งไว้ล่วงหน้า 15 สี** + **สำเนียงที่กำหนดเอง**; แสง / มืด / ระบบ
- **UI และภาษาของเนื้อหา:** อังกฤษ, 简体中文, 繁體中文 หรือระบบ — ตัวเลือกใน **การตั้งค่า → ภาษา** บน **iOS/iPad**; การตั้งค่า **ซิงค์กับ Mac ผ่าน iCloud** เมื่อเปิดใช้งาน

## ความต้องการของระบบ

| แพลตฟอร์ม | ขั้นต่ำ | หมายเหตุ |
|----------|---------|-------|
| ไอโฟน/ไอแพด | ไอโอเอส 16.0+ | วิดเจ็ตต้องใช้ iOS 17.0+ |
| แม็ค | macOS 13.0+ | แอปแถบด้านข้างแบบเนทีฟ ไม่มีวิดเจ็ต |
| ค้นหาโฟกัสอัตโนมัติ (⌘F) | iOS 17.0+ / macOS 14.0+ | OS รุ่นก่อนหน้าจะเปิดการค้นหา อาจจำเป็นต้องใช้โฟกัสแบบแมนนวล |

## แป้นพิมพ์ลัด

**ทุกแพลตฟอร์ม (แป้นพิมพ์ iPad และเมนู Mac):**

| ทางลัด | การดำเนินการ |
|----------|--------|
| ⌘F | เปิดการค้นหา |
| ⌘1 | คำสั่ง |
| ⌘2 | หมวดหมู่ |
| ⌘3 | แบบทดสอบรายวัน |
| ⌘4 | การตั้งค่า |

**เฉพาะ Mac เท่านั้น:**

| ทางลัด | การดำเนินการ |
|----------|--------|
| ⌘, | การตั้งค่า |
| ⌘[ / Esc | กลับ |
| ⌘← / ⌘→ | หมวดหมู่ก่อนหน้า/ถัดไป |
| 1–4 | เลือกคำตอบแบบทดสอบ |
| ⌘R | สับเปลี่ยนแบบทดสอบ |
| กลับ | คำถามถัดไป (หลังจากตอบแล้ว) |
