iVideo（爱视频）は、iPhone、iPad、Mac 向けの **プライバシー第一のプロ動画ツールボックス** — 画面録画、フレーム精度プレイヤー、**31 の編集ツール**、**マルチトラック編集プロジェクト**、すべて **100% 端末内**処理。**クラウドなし・アカウントなし・アップロードなし・広告なし・トラッキングなし。** 本ページは **完全ステップバイステップガイド** です。

**概要：** ライブラリ + **編集プロジェクト**（常時、ステッカー＆画像トラック）· 任意の録画（タブ既定オフ）＆ Live Photo（既定オン）· 7 カテゴリ 31 ツール · マルチトラックタイムライン · 再生 **0.05–8×** · 端末内字幕（60+ 言語）· 顔ぼかし · カラーグレーディング + LUT · バッチ処理 · 6 画質段 + 4 名前付きエクスポートプリセット · JKL プロ再生 · 代替アイコン · Siri · 任意 iCloud 同期

---

## Part 1 — 初回起動と UI

### オンボーディングとサンプル動画

初回起動で短い **ガイド付きオンボーディング**（プロワークスペース、フレーム精度、カラー、プライバシー、端末内字幕）。**サンプル動画が自動追加** — すぐ任意ツールを試せます。**設定 → ヘルプ** でツアー再視聴。

### メインタブ

| タブ | 役割 |
|------|------|
| **ライブラリ** | 全動画 — 検索、filt、sort、一括編集 |
| **編集プロジェクト** | 常時プロジェクト一覧 — 作成/改名/複製/マルチトラックを開く；**ステッカー**＆**画像オーバーレイ** |
| **録画** *(任意、タブ既定オフ)* | 画面録画；タブバッジに経過時間。**設定 → タブバーに表示** |
| **Live Photo** *(任意、既定オン)* | Live Photo 相互変換；未使用なら設定で非表示 |
| **設定** | テーマ、言語、アイコン、エクスポート、録画、ストレージ、ヘルプ、タブ表示 |

録画/Live Photo をタブから隠しても、設定、Siri/Shortcuts、空ライブラリ CTA から開けます。

## Part 2 — 動画の取り込み

### 画面録画

**iOS：** **録画** タブ → 録画ボタン → システム **Broadcast Picker** → **iVideo** → **Start Broadcast**。Record タブにライブ時間バッジ。設定で自動スナップショット間隔。

> iOS 画面録画は **実機** 必須 — Simulator は不可。

**macOS：** **ScreenCaptureKit**、マルチディスプレイ、任意システム音声。初回 **システム設定 → プライバシーとセキュリティ → 画面収録**。

### インポート

- **写真** — 再エンコードなし、進捗表示
- **ファイル** — 複数選択 (iOS)
- **リモート URL** — 直リンク DL（既定非表示；**設定 → 詳細** で有効化可）

## Part 3 — 動画ライブラリ

- **検索** — ファイル名、カスタム名、タグ
- **filt** — すべて / お気に入り / 録画 / インポート / エクスポート / メモあり
- **sort** — 日付 / 名前 / サイズ / 種類 / お気に入り、昇降順切替
- **表示** — グリッド / リスト、列数調整
- **一括** — 共有、写真へ保存、お気に入り、結合、コラージュ、バッチ処理、削除
- **カバー** — ワークスペースで **現在フレームをカバーに** — ライブラリに反映

## Part 4 — ワークスペースと再生

任意の動画を開くと **ワークスペース**：暗色プレビュー、コンパクト再生バー、ツールカテゴリ、ツールグリッド。

### 再生

- 再生/一時停止、コマ送り、⏪10s / ⏩10s
- **スクラバー** + フローティング **サムネプレビュー**
- **速度カプセル** — 長押し (0.5s) でカスタム速度シート
- プレビュー **横スワイプ** でシーク、**ダブルタップ** 没入全画面、**ピンチ** 1×–12×
- **AirPlay & PiP** (iOS)

### 可変速度

8 プリセット (0.05×…8×)、カスタムスライダー、**最近 2** チップ、iPhone **ピンチ**、速度/ミュート **iCloud 同期**

### JKL シャトル

| キー | 動作 |
|------|------|
| **L** | 順再生 2×→4×→8× |
| **J** | 逆再生 |
| **K** | 一時停止＆リセット |
| **K+J/L** | 0.5× スロー |
| **Space** | 再生/一時停止 |
| **← →** | 1 フレーム · **Shift+← →** 10 秒 |

**JKL HUD**、任意 **Live Activity** (iOS 16.1+)。逆再生中スクラバー **赤**。

### お気に入りツールバー

ツール **長押し → お気に入り**（最大 5、iCloud 同期）

## Part 6 — 端末内字幕

1. **音声 → 字幕**
2. **Speech / Sound events / 複合**
3. **認識言語**（60+；オフライン pack はシステム設定）
4. **`requiresOnDeviceRecognition`** で端末内生成
5. 行編集、タップでシーク
6. **スタイル**、命名プリセット
7. 任意 **Apple Translation** 二言語
8. **SRT/ASS** または **焼き付け**

> iOS 26 / macOS 26 では `SpeechAnalyzer` で長時間安定。
