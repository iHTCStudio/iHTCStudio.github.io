iVideo (爱视频) est une **boîte à outils vidéo pro privacy-first** pour iPhone, iPad et Mac — enregistrement d'écran, lecteur frame-accurate, **31 outils**, **Edit Projects** multi-pistes, **100 % on-device**. **Pas de cloud, compte, upload, pub ni tracking.** Guide complet.

**En bref :** Library + **Edit Projects** (sticker & image track) · optional Record & Live Photo · 31 tools · **0.05–8×** · on-device subtitles · face blur · color grading · batch · JKL · Siri · optional iCloud

## Parts 1–4
Onboarding + sample video. Tabs: Library, Edit Projects, Record, Live Photo, Settings. Import: screen record (iOS Broadcast **iVideo**, real device; macOS ScreenCaptureKit), Photos, Files, URL. Library search/filter/sort/batch. Workspace playback, variable speed, **JKL**, favorites bar.

## Parts 5–13
31 tools in 7 categories. On-device subtitles (`requiresOnDeviceRecognition`). Face Blur (Vision). Grading/LUTs. Speed Ramp, Beat Sync. Social/Merge/Collage. Live Photo Studio. Batch recipes. Edit Projects NLE (PiP, BGM, Publish Wizard).

## Parts 14–18
Export Original–540p MP4/MOV, global queue. Siri/Shortcuts. Settings. iCloud prefs only. Privacy: [Privacy Policy](privacy)
