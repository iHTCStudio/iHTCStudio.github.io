iHanFei (愛韓非子 / 愛韓非子) เป็น**สตูดิโอ Han Feizi แบบออฟไลน์**—ไม่ใช่การทิ้งข้อความธรรมดาอื่น ๆ **ไม่ต้องใช้บัญชี** คลัง *Han Feizi* ติดตั้งบนอุปกรณ์ของคุณด้วย **ภาษาต้นฉบับ / ภาษาท้องถิ่น / ภาษาอังกฤษ** เริ่มต้นด้วย **Daily Stratagem** **Recite** พร้อมการไฮไลท์ย่อหน้า** ฝึกใน **Legalism Study** เล่น **Law Hunt** ส่งออก **การ์ดกฎหมาย** เพิ่ม **widgets**, ตัวเลือก **Reading Live Activity**, **Siri & Shortcuts** และตัวเลือก **iCloud** ต้นฉบับเป็นข้อความการศึกษาในโดเมนสาธารณะ; โน้ตเป็นสิ่งช่วยเหลือในการศึกษา **ไม่มีโฆษณา ไม่มีการติดตาม Data Not Collected **

## การเริ่มต้น (ทีละขั้นตอน)

### 1. การเปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store] (https://apps.apple.com/app/id6808957997) และเปิด **iHanFei**
2. เสร็จสิ้นคู่มือต้อนรับ (การอ่านประจําวัน → การอ่านปิด → การท่อง → การศึกษา → คุณสมบัติของระบบ → ความเป็นส่วนตัว)
3. เล่นซ้ําได้ทุกเมื่อ: **การตั้งค่า → วิธีใช้ → คู่มือคุณสมบัติ** (`ihanfei://feature-guide`)
4. คู่มือการใช้งาน / วิดเจ็ต / คําสั่งลัดอยู่ภายใต้ **การตั้งค่า → วิธีใช้**

### 2. อ่านส่วนของวันนี้บน Home

1. เปิดแท็บ **Home**
2. ฮีโร่ **Daily Stratagem** แสดงส่วนของวันนี้ แตะเพื่อเปิดรายละเอียด ใช้ **refresh** เพื่อแลกเคล็ดลับอื่นสําหรับวันนี้ (การหลอกลวงที่ชาญฉลาดกว่า) หน้าหลักยังมี **บทสุ่ม**
3. ไม่บังคับ: เปิดใช้งานการแจ้งเตือน **Daily Stratagem** ภายในในการตั้งค่า
4. กระโดดจาก Home ไปยัง Recitation, Legalism Study, Law Hunt, Favorites และ Search

### 3. เรียกดูและค้นหา

1. เรียกดู *ฮั่นเฟยจื่อ* ทั้งหมด บรรทัดที่มีชื่อเสียง และชั้นวางพิเศษ
2. ค้นหาชื่อเรื่องและบรรทัด (ง่ายขึ้น / สะดวกแบบดั้งเดิม) บน iOS การค้นหาลายมือเขียน** ทางเลือก** จะจดจําอักขระบนอุปกรณ์
3. ติดดาวย่อหน้าลงใน **รายการโปรด** และรวบรวมลงในรายการ **หนังสือย่อส่วนบุคคล**

### 4. ปิดการอ่านและการแชร์การ์ด

1. สลับ **สองภาษา / เฉพาะภาษาจีน / เฉพาะภาษาอังกฤษ**; สลับเลเยอร์อย่างอิสระหากมี
2. ลองใช้การอ่านแบบสมจริง เค้าโครงแนวตั้ง ขนาดแบบอักษร และหน้าแบบแบ่งส่วนสําหรับส่วนที่ยาวขึ้น
3. เปิด **การ์ดกฎหมาย** → เลือกสไตล์ / อัตราส่วน → บันทึกไปยังรูปภาพ (เพิ่มเท่านั้น) หรือการแชร์ระบบ

### 5. การศึกษาการท่องและกฎหมาย

1. เปิดเวิร์กเบนช์การท่องเพื่อค้นหา TTS ที่ไฮไลท์ไว้ เสียงและจังหวะที่ปรับได้ คําบรรยายภาษาท้องถิ่น/ภาษาอังกฤษแบบไม่บังคับ การเล่นต่อเนื่อง และเสียงพื้นหลัง
2. **การศึกษาด้านกฎหมาย** (`ihanfei://study`): การจาง, การเติมว่าง, การตรวจสอบตัวเอง และแบบทดสอบ พร้อมการติดตามความเชี่ยวชาญ
3. **Law Hunt** on Home เป็นเกมค้นหาข้อความแยกต่างหาก

### 6. วิดเจ็ต, Siri และคุณสมบัติของระบบ

1. เพิ่มวิดเจ็ต Daily / Famous Line / Favorites / Study Progress (และ Almanac หากมี)
2. ใช้ศูนย์ควบคุม, Siri, Spotlight และ `ihanfei://` ลิงก์ลึก
3. กิจกรรมการอ่านสดแบบไม่บังคับยังคงมีให้ใช้งานบนอุปกรณ์ที่รองรับ iPhone

### 7. ความเป็นส่วนตัวและการซิงค์

1. คลัง, การอ่าน, การท่อง (ระบบ TTS), การศึกษา, วิดเจ็ต และการแจ้งเตือนในเครื่องจะทํางานแบบออฟไลน์อย่างสมบูรณ์หลังจากติดตั้ง
2. ตัวเลือก**iCloud Sync** สะท้อนรายการโปรด รายการ ประวัติ ความคืบหน้า เส้น และโน้ตผ่าน**iCloud**ส่วนตัวของคุณ
3. เคล็ดลับสําหรับนักพัฒนา (ไม่บังคับ StoreKit) ไม่ควรปลดล็อค Paywall และไม่ควรสร้างบัญชี
