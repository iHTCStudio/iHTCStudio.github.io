**หนึ่งนามสกุลต่อวัน วัฒนธรรมในทุกตัวอักษร **

iBaiJia (นามสกุลอ้ายป๋อเจีย / นามสกุลอ้ายป๋อเจีย) เป็น **สตูดิโอการเรียนรู้วัฒนธรรมนามสกุลที่สมจริง**—ไม่ใช่รายการธรรมดาอื่น ๆ **ไม่ต้องใช้บัญชี ****นามสกุล 967** (504 ชื่อดั้งเดิม + 463 ชื่อขยาย รวมถึงชื่อที่มีส่วนผสม) จัดส่งบนอุปกรณ์ของคุณพร้อมด้วย **origins**, **hall names**, **migration notes**, **notable figures**, **distribution charts** และ **English glosses** (ไม่บังคับ) **Browse** ตามพินอิน, ขีดเขียน, วูชิ่ง, เดี่ยว/รวม, แหล่งที่มา, อันดับประชากร หรือข้อความสี่อักขระแบบคลาสสิก; **recite** ต้นฉบับพร้อมการไฮไลท์บรรทัด; ฝึกใน **Study Hall**; ลอง **naming inspiration** (ภาษาท้องถิ่นทั้งหมด) เริ่มต้นด้วย **Daily Surname** และ **My Surname** ส่งออก **share cards**, เพิ่ม **widgets**, **Reading Live Activity** (ไม่บังคับ), **Siri & Shortcuts** และ **iCloud** (ไม่บังคับ) **ไม่มีโฆษณา ไม่มีการติดตาม Data Not Collected **

**ดูแบบรวดเร็ว: ** 967 นามสกุล · 8 แกนการเรียกดู · รายละเอียดสองภาษา · อ่านออกเสียง · ห้องเรียน · นามสกุลประจําวัน · การติดตามเส้นขีด · สถิติ · การตั้งชื่อ · 4 วิดเจ็ต · ศูนย์ควบคุม · `ibaijia://` · EN / สั้น / หนา

## การเริ่มต้น (ทีละขั้นตอน)

### 1. การเปิดตัวครั้งแรก

1. ติดตั้งจาก [App Store] (https://apps.apple.com/app/id6796013615) และเปิด **iBaiJia**
2. เสร็จสิ้นคู่มือต้อนรับ 6 หน้า** (แบรนด์ → เลือกหา → รายละเอียด → อ่านออกเสียง → ศึกษา → ความเป็นส่วนตัว)
3. เล่นซ้ําได้ทุกเมื่อ: **การตั้งค่า → วิธีใช้ → คู่มือฟีเจอร์** (`ibaijia://feature-guide`)
4. คู่มือการใช้งาน / วิดเจ็ต / คําสั่งลัดภายในแอปจะอยู่ภายใต้ **การตั้งค่า → วิธีใช้**

### 2. นามสกุลประจําวันในบ้าน

1. เปิดแท็บ **Home**
2. วีรบุรุษ **ชื่อสกุลประจําวัน** จะแสดงชื่อสกุลของวันนี้ แตะเพื่อเปิดรายละเอียด
3. ตั้งค่า **นามสกุลของฉัน** สําหรับคําสั่งลัดและวิดเจ็ตที่กําหนดเอง
4. ไม่บังคับ: เปิดการแจ้งเตือน**นามสกุลประจําวัน** ในการตั้งค่า (เฉพาะกําหนดเวลาในพื้นที่เท่านั้น)
5. ติดตามความคืบหน้าของคุณใน **รายละเอียดการเช็คอิน**; ดําเนินการต่อจากที่คุณทําค้างไว้

### 3. เรียกดูและค้นหา

1. เปิด**Browse** (แท็บหมวดหมู่)
2. สํารวจ **แปดมิติ**: พินอิน, ขีด, วอกซ์, เดี่ยว/ผสม, ดั้งเดิมเทียบกับขยาย, แหล่งที่มาของนามสกุล, อันดับประชากร และข้อความ *ร้อยนามสกุล* แบบเต็ม
3. การ์ดเปิดกลุ่ม; การแสดงตัวอย่างเปิดนามสกุล แอปจะจดจํามิติและเค้าโครงล่าสุดของคุณ
4. ใช้ **Search** สําหรับนามสกุล พินอิน อักษรย่อ หรือตัวอักษรหลัก - ออฟไลน์อย่างสมบูรณ์ บน iOS การค้นหา**นามสกุลแบบเขียนด้วยลายมือ** ทางเลือกจะจดจําอักขระบนอุปกรณ์
5. ติดดาวนามสกุลลงใน **รายการโปรด**; สร้าง **รายการนามสกุล** และ **โน้ต**. แท็บรายการโปรดเปิดอยู่ตามค่าเริ่มต้น** (สามารถซ่อนได้ในการตั้งค่า)

### 4. รายละเอียด การอ่านและการแชร์การ์ด

1. เกี่ยวกับรายละเอียด: ที่มา, ชื่อห้อง, การย้ายถิ่นฐาน, ตัวเลขสําคัญ, การกระจาย, ความหมายภาษาอังกฤษ
2. สลับระหว่างการอ่านแบบดื่มด่ํา กดข้อความเนื้อหาเป็นเวลานานเพื่อคัดลอก อ่านออกเสียง หรือใช้การแปลระบบ (iOS 17.4+)
3. เปิด **การติดตามเส้นขีด** สําหรับตัวอักษรนามสกุล; ส่งออก **รูปแบบการแบ่งปันการ์ด** ไปยังแอพรูปภาพ (เพิ่มเท่านั้น) หรือการแชร์ระบบ
4. ทําเครื่องหมาย **นามสกุลของฉัน** เพิ่มโน้ต หรือรายการโปรดจากการทํางานรายละเอียด

### 5. การท่อง (อ่านออกเสียงสี่คํา)

1. เปิด **Recite** จาก Home, Browse หรือ `ibaijia://recite`
2. เค้าโครงสี่คอลัมน์พร้อมไฮไลท์บรรทัดปัจจุบันและเครื่องหมายสีน้ําตาลแดง แตะที่บรรทัดหนึ่งเพื่อเริ่มต้นที่นั่น
3. ช่องเล่นด้านล่างรองรับการเล่นวนแบบบรรทัดเดียว เสียงพื้นหลังเสริม + กิจกรรมสด
4. กําหนดค่าเสียงและอัตราใน **การตั้งค่า → การอ่าน**

### 6. ห้องเรียนและการตั้งชื่อ

1. เปิด **Study** จาก Home / `ibaijia://study` / Shortcuts
2. โหมด: **คําถามการจดจํา**, **การจับคู่พินอิน**, **แฟลชการ์ด**, **สตริงสี่ตัวอักษร**, **คําถามต้นฉบับ** (สามารถรวมนามสกุลที่ขยายได้)
3. คะแนนสูงจะยังคงอยู่บนอุปกรณ์ เปิด **การให้แรงบันดาลใจในการตั้งชื่อ** สําหรับแนวคิดการตั้งชื่อในท้องถิ่นอย่างเต็มรูปแบบ - ไม่มีอะไรถูกอัปโหลด

### 7. สถิติและวิดเจ็ต

1. แท็บ **สถิติ**: Swift Charts สําหรับประชากร, ขีด, Wuxing, อักษรย่อ และการกระจายในจังหวัด
2. กดหน้าจอหลักค้างไว้ → **แก้ไขวิดเจ็ต** → เพิ่ม **นามสกุลประจําวัน / นามสกุลของฉัน / Trivia / ความคืบหน้าการเรียน**
3. ตัวควบคุมศูนย์ควบคุม (iOS18+): daily, random, recite, search, my last name, study, favorites, statistics
4. ถาม **Siri** สําหรับนามสกุลของวันนี้ สุ่ม พูดซ้ํา รายการโปรด ศึกษา หรือค้นหา

### 8. ความเป็นส่วนตัวและการซิงค์

1. ไลบรารีนามสกุล ข้อมูลการขีดเขียน การอ่าน การท่อง (TTS ของระบบ) การศึกษา วิดเจ็ต และการแจ้งเตือนเฉพาะที่ทํางาน **ออฟไลน์อย่างสมบูรณ์** หลังจากติดตั้ง
2. ตัวเลือก**iCloud Sync** สะท้อนรายการโปรด รายการ โน้ต ความคืบหน้า และเส้นผ่าน**iCloud**ส่วนตัวของคุณ
3. ตัวเลือก **การส่งออก/นําเข้าข้อความ** ในการตั้งค่าสําหรับการสํารองข้อมูล - ยังคงอยู่บนอุปกรณ์ของคุณเท่านั้น
4. เคล็ดลับสําหรับนักพัฒนา (ไม่บังคับ StoreKit) ไม่ควรปลดล็อคเนื้อหาที่มีการป้องกันด้วยไฟร์วอลล์แบบชําระเงินและไม่ควรสร้างบัญชี

## เหตุใดคุณจึงต้องการดาวน์โหลด

- **สร้างขึ้นสําหรับวัฒนธรรมนามสกุล** - ต้นกําเนิด ห้องเรียน การย้ายถิ่นฐาน การกระจาย - ไม่ใช่แค่รายการชื่อ
- **แปดวิธีในการเรียกดู** — พินอิน ขีดเขียน วัคซิ่ง แหล่งที่มา การจัดอันดับ ข้อความคลาสสิก และอื่นๆ
- **การฝึกซ้อม ไม่ใช่แค่หน้า** - แบบทดสอบห้องเรียน สตูดิโอท่องหนังสือ เส้นขีด
- **เนทีฟในที่ที่ช่วยได้** – วิดเจ็ต, กิจกรรมสด, ศูนย์ควบคุม, Siri, ลิงก์ลึก, ตัวเลือก iCloud
- **ความเป็นส่วนตัวตามการออกแบบ** - ไม่มีบัญชี ไม่มีโฆษณา ไม่มี SDK การวิเคราะห์ ทุกอย่างยังคงอยู่บนอุปกรณ์ของคุณ
