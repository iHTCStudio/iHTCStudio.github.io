## Начало работы (шаг за шагом)

### 1. Первый запуск

1. Установите из [App Store] (https://apps.apple.com/app/id6796013615) и откройте **iBaiJia**.
2. Заполните 6-страничное руководство по приветствию** (brand → browse → detail → recite → study → privacy).
3. Воспроизведение в любое время: **Настройки → Справка → Руководство по функциям** (`ibaijia://feature-guide`).
4. Руководства в приложении **Использование / Виджет / Быстрые команды** находятся в разделе **Настройки → Справка**.

### 2. Повседневная фамилия на Home

1. Откройте вкладку «Дом».
2. Герой **Ежедневная фамилия** показывает фамилию текущего дня; нажмите, чтобы открыть сведения.
3. Задайте **Мою фамилию** для персонализированной быстрой команды и виджета.
4. Необязательно: включите **Уведомления о ежедневной фамилии** в Настройках (только локальное расписание).
5. Отслеживайте свою серию в разделе **Сведения о регистрации**; продолжайте с того места, где остановились.

### 3. Обзор и поиск

1. Откройте вкладку «Обзор» (Категории).
2. Ознакомьтесь с **восьми измерениями**: пиньинь, штрихи, воксинг, одиночная/сложная, традиционная и расширенная, источник фамилии, рейтинг населения и полный текст *Сто семейных фамилий*.
3. Карты открывают группы; предварительный просмотр открывает фамилию. Приложение запоминает ваше последнее измерение и макет.
4. Используйте **Search** для поиска фамилии, пиньинь, инициала или примечательной фигуры — полностью офлайн. На iOS необязательный **рукописный поиск фамилий** распознает символы на устройстве.
5. Отметьте фамилии в **Избранное**; создайте **Списки фамилий** и **Заметки**. Вкладка «Избранное» по умолчанию включена** (можно скрыть ее в Настройках).

### 4. Подробности, чтение и обмен картами

1. О деталях: происхождение, названия залов, миграция, примечательные фигуры, распределение, английский gloss.
2. Переключайте иммерсивное чтение; длительное нажатие на основной текст для копирования, чтения вслух или использования системного перевода (iOS 17.4+).
3. Откройте ***Tracing Stroke** для символов фамилии; экспортируйте ***Share Card** стили в Фото (только для добавления) или системный общий доступ.
4. Отметьте **Мою фамилию**, добавьте заметки или добавьте в избранное из действий детализации.

### 5. Чтение (четверосложное чтение)

1. Откройте **Recite** из Home, Browse или `ibaijia://recite`.
2. Четырехколонный макет с выделением текущей строки и цинниковыми метками; нажмите строку, чтобы начать с нее.
3. Нижний остров воспроизведения поддерживает однострочный цикл; дополнительный фоновый звук + Live Activity.
4. Настройте голос и частоту в **Настройки → Чтение**.

### 6. Зал для занятий и именование

1. Откройте **Study** из Дома / `ibaijia://study` / Shortcuts.
2. Режимы: **Запрос распознавания**, **Соответствие пиньинь**, **Флэшкарты**, **Четырехзначная цепочка**, **Запрос источника** (может включать расширенные фамилии).
3. Высокие оценки остаются на устройстве. Откройте **Название вдохновения** для получения полностью локальных идей по именам — ничего не загружается.

### 7. Статистика и виджеты

1. Вкладка **Статистика**: Быстрые диаграммы для численности населения, штрихов, сокращений, инициалов и провинциального распределения.
2. Долгое нажатие экрана «Домой» → → «Изменить виджеты» → «Добавить» → «Ежедневная фамилия» / «Моя фамилия» / «Тривиа» / «Учебный прогресс»**.
3. Элементы управления Пункта управления (iOS18+): daily, random, recite, search, my last name, study, favorites, statistics.
4. Попросите Siri *** фамилию текущего дня, случайное, повторение, избранные, изучение или поиск.

### 8. Конфиденциальность и синхронизация

1. Библиотека фамилий, данные штриховки, чтение, декламация (система TTS), изучение, виджеты и локальные уведомления работают **полностью в автономном режиме** после установки.
2. Необязательный ***iCloud Sync** отображает избранные, списки, заметки, прогресс и штрихи через ***вашу личную ***iCloud**.
3. Необязательный **экспорт/импорт текста** в Настройках для резервного копирования — по-прежнему только на ваших устройствах.
4. Совет разработчику (необязательно StoreKit) никогда не разблокировать платное содержимое и никогда не создавать учетную запись.
