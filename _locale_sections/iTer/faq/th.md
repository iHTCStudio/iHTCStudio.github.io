### ค้นหาคำถามสัมภาษณ์อย่างไร?

เปิด iTer ใช้แท็บ **ภาษา** สำหรับ 17 หมวดภาษาโปรแกรม หรือแท็บ **หมวดหมู่** สำหรับเส้นทางอาชีพ ธนาคารข้อสอบบริษัท และลิงก์เรียนรู้ขั้นสูง แตะคำถามเพื่อเปิดรายละเอียด ใช้ **การค้นหาทั้งแอป** (⌘F บน iPad/Mac) พร้อมตัวกรองขอบเขต

### iTer ใช้งานออฟไลน์ได้ไหม?

ได้ **คำถาม 10,000+** และทรัพยากรการเรียนรู้รวมอยู่ในแอป ไม่ต้องมีบัญชี ล็อกอิน หรืออินเทอร์เน็ต รายการโปรด ความคืบหน้าควิซ สมุดคำตอบผิด และการตั้งค่าเก็บบนอุปกรณ์

### ทำไมวิดเจ็ตไม่แสดงคำถาม?

**หลังติดตั้งหรืออัปเดต iTer ให้เปิดแอปหลักอย่างน้อยหนึ่งครั้ง** เพื่อซิงค์แคตตาล็อกไปยัง App Group วิดเจ็ตอ่านจากมิrror ออฟไลน์นั้น หากยังว่าง เปิดแอปรอโหลดไลบรารีเสร็จ แล้วลบวิดเจ็ตแล้วเพิ่มใหม่

### เลือกขอบเขตคำถามใน “คำถามประจำวัน” ได้ไหม?

บน **iOS 17+** กดค้างวิดเจ็ตคำถามประจำวัน → **แก้ไขวิดเจ็ต** เลือกขอบเขต (ทั้งหมด / ภาษา / อาชีพ / บริษัท) แตะ “สุ่ม” ในวิดเจ็ตเพื่อเปลี่ยนคำถามวันนี้ ขอบเขตควิซรายวันในแอปซิงค์กับวิดเจ็ตเมื่อเปลี่ยนในแท็บควิซ

### ทางลัดคีย์บอร์ดในรายละเอียดคำถามทำงานอย่างไร?

เมื่อเปิดคำถามจากรายการที่มี **สองรายการขึ้นไป** แถบล่างแสดง ก่อนหน้า · สุ่ม · คำตอบ · ถัดไป บน **iPad ที่มีคีย์บอร์ดภายนอก** หรือ **Mac**:

| ปุ่ม | การทำงาน |
|-----|--------|
| ← | ก่อนหน้า |
| R | สุ่ม |
| Space | แสดงคำตอบ |
| → | ถัดไป |

บน Mac **Esc** กลับ (หรือปิดตัวอย่างแชร์ก่อน) ทางลัดปิดใช้ที่ขอบรายการหรือหลังแสดงคำตอบแล้ว

### UI แอปรองรับภาษาใดบ้าง?

**อังกฤษ** **简体中文** **繁體中文** และ **ตามระบบ** เปลี่ยนใน การตั้งค่า → ภาษาแสดงผล วิดเจ็ตหน้าจอหลักใช้การตั้งค่าเดียวกัน

### Quick Actions บนหน้าจอหลักคืออะไร?

กดค้างไอคอน iTer บน iPhone/iPad ใช้ทางลัดจาก **การตั้งค่า → ทางลัดหน้าจอหลัก** (สูงสุด **4** จาก **7**):

| ประเภท | การทำงาน |
|------|--------|
| `iTer://search` | เปิดการค้นหา |
| `iTer://quiz` | เปิดควิซรายวัน |
| `iTer://favorites` | เปิดรายการโปรด |
| `iTer://wrong` | เปิดสมุดคำตอบผิด |
| `iTer://categories` | เปิดแท็บหมวดหมู่ |
| `iTer://feedback` | ส่งความคิดเห็น (เมล) |
| `iTer://review` | ให้คะแนนแอป (StoreKit) |

วิดเจ็ตและทางลัดใช้ **`iTer://question?id=`** **`quiz`** **`favorites`** **`wrong`** ได้ — ดู [URL Scheme](../url-scheme)
