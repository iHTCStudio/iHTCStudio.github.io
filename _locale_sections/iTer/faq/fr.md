### Comment parcourir les questions d’entretien ?

Ouvrez iTer et utilisez l'onglet **Langues** pour 17 catégories de langages de programmation, ou l'onglet **Catégories** pour les parcours de carrière, les banques d'entreprise et les liens d'apprentissage avancés. Appuyez sur une question pour ouvrir sa page de détails. Utilisez la **recherche globale** (⌘F sur iPad/Mac) pour rechercher des questions dans l'ensemble de la bibliothèque avec des filtres de portée facultatifs.

### iTer fonctionne-t-il hors ligne ?

Oui. Les **10 000+** questions et ressources d'apprentissage sont regroupées avec l'application. Aucun compte, connexion ou connexion Internet n'est requis. Les favoris, la progression du quiz, les mauvais enregistrements de livres et les préférences sont stockés localement sur votre appareil.

### Pourquoi mes widgets n'affichent-ils pas les questions ?

Après avoir installé ou mis à jour iTer, **ouvrez l'application principale une fois** afin qu'elle synchronise le catalogue de questions avec le stockage du groupe d'applications. Les widgets sont lus à partir de ce miroir hors ligne. Si les widgets semblent toujours vides, lancez l'application et attendez que le chargement de la bibliothèque soit terminé, puis supprimez et rajoutez le widget.

### Puis-je choisir les questions qui apparaissent dans le widget Questions quotidiennes ?

Sur **iOS 17+**, appuyez longuement sur le widget Question quotidienne → **Modifier le widget** pour choisir une portée (Tous/Langue/Profession/Entreprise). Vous pouvez également appuyer sur la lecture aléatoire sur le widget pour modifier le choix du jour. La portée du quiz quotidien intégré à l'application se synchronise avec les widgets lorsque vous la modifiez dans l'onglet Quiz.

### Comment fonctionnent les raccourcis clavier dans le détail des questions ?

Lorsque vous ouvrez une question à partir d'une liste contenant **2 questions ou plus**, la barre inférieure affiche Précédent · Aléatoire · Réponse · Suivant. Sur **iPad avec clavier externe** ou **Mac** :

| Clé | Action |
|-----|--------|
| ← | Précédent |
| R | Aléatoire |
| Espace | Afficher la réponse |
| → | Suivant |

Sur Mac, **Esc** revient en arrière (ou ferme d'abord l'aperçu du partage). Les raccourcis sont désactivés aux limites de la liste ou une fois que la réponse est déjà affichée.

### Quelles langues l'interface utilisateur de l'application prend-elle en charge ?

L'interface est disponible en **anglais**, **chinois simplifié**, **chinois traditionnel** et **Follow System**. Modifiez-le dans Paramètres → Langue d'affichage. Les widgets de l'écran d'accueil suivent la même préférence de langue.

### Quelles sont les actions rapides de l’écran d’accueil ?

Sur iPhone et iPad, appuyez longuement sur l'icône iTer pour utiliser les raccourcis configurés dans **Paramètres → Raccourcis de l'écran d'accueil** (jusqu'à **4** sur **7**) :

| Tapez | Action |
|------|--------|
| `iTer://search` | Ouvrir la recherche globale |
| `iTer://quiz` | Quiz quotidien ouvert |
| `iTer://favorites` | Ouvrir les Favoris |
| `iTer://wrong` | Ouvrir le livre de mauvaises réponses |
| `iTer://categories` | Ouvrir l'onglet Catégories |
| `iTer://feedback` | Envoyer des commentaires (courriel) |
| `iTer://review` | Évaluez l'application (StoreKit) |

Les widgets et les raccourcis peuvent également utiliser **`iTer://question?id=`**, **`quiz`**, **`favorites`** et **`wrong`** — voir la [référence du schéma d'URL](../url-scheme).
