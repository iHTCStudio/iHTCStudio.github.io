iTer is an **IT learning and job interview preparation app** for developers on **iPhone, iPad, and Mac**. Browse **10,000+** offline interview questions across **17 programming languages**, **12 career tracks**, and **16 company question banks — with daily quiz, favorites, wrong-book review, home & lock screen widgets, and native SwiftUI on iPhone, iPad, and Mac.**

## 시작하기

1. iTer를 열고 카테고리 탭에서 **언어**, **경력 카테고리** 또는 **회사**별로 질문을 찾아보세요.
2. 질문을 탭하면 전체 프롬프트를 읽을 수 있습니다. **답변**을 탭하거나 키보드에서 **스페이스**를 눌러 설명을 확인하세요.
3. 여러 질문이 있는 목록에서 하단 막대나 키보드를 사용하여 **이전 / 무작위 / 다음**으로 이동하세요.
4. **일일 퀴즈**를 시도해 보세요. 하루에 5개의 객관식 문제가 나옵니다. 상단 메뉴에서 문제은행 범위를 변경하세요.
5. 행을 스와이프하여 **즐겨찾기** 또는 **마스터로 표시**하세요. 학습 상태를 보려면 길게 누르세요.
6. 홈이나 잠금 화면에 **위젯**을 추가하세요. 위젯이 오프라인 카탈로그를 동기화할 수 있도록 설치 후 앱을 한 번 엽니다.
7. **설정**에서 표시 언어를 전환하세요(영어, 중국어 간체, 중국어 번체 또는 팔로우 시스템).

## 특징

### 질문 라이브러리

- **10,000개 이상의 질문** — 17개 언어 파일, 12개 직업 트랙, 16개 회사(2025 캠퍼스 인터뷰 세트를 포함한 120개 이상의 JSON 볼륨).
- **완전 오프라인** — 모든 콘텐츠가 번들로 제공됩니다. 계정이나 네트워크가 필요하지 않습니다.
- **글로벌 검색** — 전체/언어/직업/회사별로 필터링합니다. 디바운싱된 입력, 빠른 색인 조회.
- **마크다운 답변** — 답변의 제목, 목록, 코드 블록 및 표. 필요할 때 일반 텍스트로 전환하세요.
- **세부 탐색 표시줄** — 이전 · 무작위 · **답변** · 다중 질문 목록에서 열 때 다음; 공개 시 답변이 스크롤되어 표시됩니다.

### 학습 도구

- **일일 퀴즈** — 날짜 시드가 포함된 하루 5개의 MCQ; 선택적 은행 범위(검색 범위 및 위젯과 일치)
- **즐겨찾기 및 최근** — 질문을 저장합니다. 한 번의 탭으로 모든 최근 기록을 지웁니다.
- **잘못된 문제집** — 검토 목록과 함께 자동 수집된 퀴즈 실수입니다.
- **숙달 마크** — 학습하지 않음 / 검토 필요 / 마스터함; 업데이트하려면 스와이프하거나 길게 누르세요.
- **고급 학습** — Objc.io 및 NSHipster 이중 언어 섹션, 설명 자막이 있는 Awesome/Gitbook/연습 프로젝트 링크.

### 개인화

- **15가지 내장 테마** + 밝음/어두움/시스템 모양.
- **UI 언어** — 영어, 중국어 간체, 중국어 번체, 팔로우 시스템(위젯은 앱 언어를 따릅니다).
- **홈 화면 빠른 작업**(iOS) — **설정 → 홈 화면 바로가기**(검색, 퀴즈, 즐겨찾기, 잘못된 책, 카테고리, 피드백, 평가)의 **7** 옵션에서 최대 **4** 바로가기를 구성합니다. 위젯 및 **`iTer://`** 딥 링크는 질문, 퀴즈, 즐겨찾기 및 잘못된 책을 엽니다. [URL 체계](url-scheme)를 참조하세요.
- **인앱 Safari** 외부 링크용.

### iOS 및 아이패드

- **4가지 위젯 유형** — 일일 질문, 퀴즈 보기, 즐겨찾기 보기, 틀린 책 보기. 홈 화면(지원되는 경우 소형/중형) 및 **잠금 화면**(iOS의 경우 인라인/원형/직사각형).
- 일일 질문 위젯(iOS 17+): 추가/편집 시 문제 은행 범위를 선택합니다. 오늘의 선택을 변경하려면 셔플을 탭하세요.
- 잘못된 책 위젯: 특정 잘못된 기록에 대한 딥 링크(`iTer://wrong?record=`).
- **iPad + 키보드**: ⌘F 검색, ⌘1~⌘4 탭; 세부 단축키 ← / R / Space / → (아래 참조).

### macOS

- 탭 탐색, **Esc** 뒤로/해제, 전용 **검색 시트**(⌘F) 및 시스템 공유 패널이 포함된 기본 Mac 앱입니다.
- 기본 **그리드** 목록 레이아웃. iOS의 독립적인 레이아웃 기본 설정.
- 세부 검색 단축키를 포함한 전체 키보드 지원.

## 위젯

iTer는 홈 화면과 잠금 화면에 **4가지 종류의 위젯**을 제공합니다.

> **팁:** 설치 또는 업데이트 후 기본 앱을 한 번 열어 질문 카탈로그를 위젯용 앱 그룹 저장소에 동기화하세요.

### 추가하는 방법

1. 홈 화면(또는 잠금 화면)을 길게 눌러 편집 모드로 들어갑니다.
2. **+**를 탭하고 **iTer**를 검색하세요.
3. 위젯과 크기를 선택한 다음 **위젯 추가**를 탭하세요.
4. **일일 질문**(iOS 17+)의 경우 위젯을 길게 누르고 → **위젯 편집**을 눌러 문제 은행 범위(전체/언어/직업/회사)를 선택하세요.

### 사용 가능한 위젯

| 위젯 | 설명 | 크기 |
|--------|-------------|-------|
| 일일 질문 | 하루에 하나의 면접 질문; 선택적 범위 및 셔플 | 소형, 중형; 잠금 화면 |
| 퀴즈 한눈에 | 오늘의 퀴즈 점수, 완료, 연속 기록 | 작은; 잠금 화면 |
| 즐겨찾기 한눈에 보기 | 즐겨찾는 개수 + 미리보기 제목 | 작은; 잠금 화면 |
| 잘못된 책 살펴보기 | 잘못된 개수 + 요약 탭하여 기록 열기(iOS 17+) | 작은; 잠금 화면 |

## 키보드 단축키

### iPad(외부 키보드)

| 바로가기 | 액션 |
|----------|--------|
| ⌘F | 검색 열기 |
| ⌘1 | 언어 탭 |
| ⌘2 | 카테고리 탭 |
| ⌘3 | 일일 퀴즈 탭 |
| ⌘4 | 설정 탭 |
| ← | 이전 질문*(세부사항, 다중 질문 목록)* |
| R | 무작위 질문 *(세부사항)* |
| 공간 | 답변 표시 *(세부정보, 공개 후 비활성화됨)* |
| → | 다음 질문 *(자세히)* |

### macOS

| 바로가기 | 액션 |
|----------|--------|
| ⌘F | 검색 시트 열기 |
| ⌘1 – ⌘4 | 탭 전환(언어/카테고리/퀴즈/설정) |
| Esc | 뒤로 이동 또는 닫기 *(검색 텍스트를 먼저 지우고 팝업 전에 공유 미리보기를 닫음)* |
| ← | 이전 질문*(세부사항, 다중 질문 목록)* |
| R | 무작위 질문 *(세부사항)* |
| 공간 | 답변 표시 *(세부정보, 공개 후 비활성화됨)* |
| → | 다음 질문 *(자세히)* |

세부정보 바로가기는 하단 탐색 표시줄이 표시되는 경우에만 적용됩니다(현재 풀에 질문 2개 이상).
