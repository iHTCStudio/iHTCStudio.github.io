iTer — это **приложение для обучения ИТ и подготовки к собеседованию** для разработчиков на **iPhone, iPad и Mac**. Просматривайте **10 000+** вопросов для офлайн-собеседований на **17 языках программирования**, **12 карьерных направлениях** и **16 банках вопросов компании — с ежедневными викторинами, избранным, обзором неправильных книг, виджетами на главном экране и на экране блокировки, а также встроенным SwiftUI на iPhone, iPad и Mac.**

## Начало работы

1. Откройте iTer и просмотрите вопросы по **языку**, **карьерной категории** или **компании** на вкладке «Категории».
2. Коснитесь любого вопроса, чтобы прочитать полную подсказку; нажмите **Ответить** (или нажмите **Пробел** на клавиатуре), чтобы открыть объяснение.
3. В списке с несколькими вопросами используйте нижнюю панель или клавиатуру для перемещения **Предыдущий/Случайный/Следующий**.
4. Попробуйте **Ежедневную викторину** — 5 вопросов с несколькими вариантами ответов в день; измените объем банка вопросов в меню вверху.
5. Проведите по строке до пункта **Избранное** или **Отметить как освоенное**; долгое нажатие для статуса обучения.
6. Добавляйте **виджеты** на главный экран или экран блокировки; откройте приложение один раз после установки, чтобы виджеты могли синхронизировать автономный каталог.
7. Переключите язык отображения в **Настройках** (английский, упрощенный китайский, традиционный китайский или Системный).

## Особенности

### Библиотека вопросов

- **Более 10 000 вопросов** — 17 языковых файлов, 12 профессиональных направлений, 16 компаний (более 120 томов JSON, включая 2025 наборов интервью в кампусе).
- **Полностью офлайн** — весь контент в комплекте; учетная запись или сеть не требуются.
- **Глобальный поиск** — Фильтр по всем/языку/профессии/компании; устранение дребезга ввода, быстрый индексированный поиск.
- **Ответы на разметку** — заголовки, списки, блоки кода и таблицы в ответах; переключитесь на обычный текст, когда это необходимо.
- **Панель подробного просмотра** — Предыдущий · Случайный · **Ответ** · Следующий при открытии из списка с несколькими вопросами; ответ прокручивается в поле зрения при раскрытии.

### Инструменты обучения

- **Ежедневная викторина** — 5 MCQ в день с указанием даты; необязательная область банка (соответствует области поиска и виджету).
- **Избранное и последние** — Сохраняйте вопросы; очистить всю недавнюю историю одним нажатием.
- **Неправильный сборник вопросов** — ошибки в тесте автоматически собираются вместе со списком отзывов.
- **Оценки мастерства** — Не изучено/Требует проверки/Освоено; проведите пальцем по экрану или нажмите и удерживайте, чтобы обновить.
- **Продвинутое обучение** — двуязычные разделы Objc.io и NSHipster, ссылки Awesome/Gitbook/практического проекта с субтитрами примечаний.

### Персонализация

- **15 встроенных тем** + светлый/темный/системный внешний вид.
- **Языки пользовательского интерфейса** — английский, упрощенный китайский, традиционный китайский, следование системе (виджеты соответствуют языку приложения).
- **Быстрые действия на главном экране** (iOS) — настройте до **4** ярлыков из **7** параметров в разделе **Настройки → Ярлыки на главном экране** (Поиск, Тест, Избранное, Неправильная книга, Категории, Обратная связь, Оценка). Виджеты и глубокие ссылки **`iTer://`** открывают вопросы, викторины, избранное и не ту книгу — см. [Схема URL-адресов](url-scheme).
- **Safari в приложении** для внешних ссылок.

### iOS и iPad

- **4 типа виджетов** — «Ежедневный вопрос», «Викторина», «Избранное», «Неправильная книга». Главный экран (маленький/средний, если поддерживается) и **Экран блокировки** (строчный/круговой/прямоугольный на iOS).
- Виджет ежедневных вопросов (iOS 17+): выбирайте объем банка вопросов при добавлении/редактировании; нажмите «Перемешать», чтобы изменить сегодняшний выбор.
- Виджет «Неправильная книга»: глубокая ссылка на конкретную неправильную запись (`iTer://wrong?record=`).
- **iPad + клавиатура**: поиск ⌘F, вкладки ⌘1–⌘4; подробные ярлыки ←/R/Пробел/→ (см. ниже).

### macOS

- Родное приложение для Mac с навигацией по вкладкам, клавишей **Esc** назад/закрыть, специальным **листом поиска** (⌘F) и панелью общего доступа к системе.
- Макет списка **сетка** по умолчанию; независимые предпочтения макета от iOS.
- Полная поддержка клавиатуры, включая сочетания клавиш для подробного просмотра.

## Виджеты

iTer предлагает **4 вида виджетов** для главного экрана и экрана блокировки.

> **Совет.** Откройте основное приложение один раз после установки или обновления, чтобы оно синхронизировало каталог вопросов с хранилищем группы приложений для виджетов.

### Как добавить

1. Нажмите и удерживайте главный экран (или экран блокировки), чтобы войти в режим редактирования.
2. Tap **+** and search for **iTer**.
3. Choose a widget and size, then tap **Add Widget**.
4. Для **Ежедневного вопроса** (iOS 17+) нажмите и удерживайте виджет → **Редактировать виджет**, чтобы выбрать область банка вопросов (Все / Язык / Профессия / Компания).

### Доступные виджеты

| Виджет | Описание | Размеры |
|--------|-------------|-------|
| Ежедневный вопрос | Один вопрос на собеседовании в день; дополнительная область действия и перетасовка | Маленький, Средний; Экран блокировки |
| Викторина Взгляд | Результат сегодняшней викторины, завершение, серия | Маленький; Экран блокировки |
| Избранное Взгляд | Любимый счетчик + предварительный просмотр заголовков | Маленький; Экран блокировки |
| Неправильный взгляд на книгу | Неправильный подсчет + резюме; нажмите, чтобы открыть запись (iOS 17+) | Маленький; Экран блокировки |

## Сочетания клавиш

### iPad (внешняя клавиатура)

| Ярлык | Действие |
|----------|--------|
| ⌘F | Открыть поиск |
| ⌘1 | Вкладка «Языки» |
| ⌘2 | Вкладка «Категории» |
| ⌘3 | Вкладка «Ежедневная викторина» |
| ⌘4 | Вкладка «Настройки» |
| ← | Предыдущий вопрос *(подробно, список вопросов)* |
| R | Случайный вопрос *(подробно)* |
| Космос | Показать ответ *(подробно; после раскрытия отключено)* |
| → | Следующий вопрос *(подробно)* |

### macOS

| Ярлык | Действие |
|----------|--------|
| ⌘F | Открыть лист поиска |
| ⌘1 – ⌘4 | Переключение вкладок (Языки/Категории/Тест/Настройки) |
| Esc | Вернуться назад или закрыть *(сначала очищается текст поиска; закрывает предварительный просмотр перед открытием)* |
| ← | Предыдущий вопрос *(подробно, список вопросов)* |
| R | Случайный вопрос *(подробно)* |
| Космос | Показать ответ *(подробно; после раскрытия отключено)* |
| → | Следующий вопрос *(подробно)* |

Ярлыки для подробностей применяются только тогда, когда видна нижняя панель просмотра (более 2 вопросов в текущем пуле).
