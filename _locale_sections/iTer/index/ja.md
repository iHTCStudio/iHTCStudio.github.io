iTer は、**iPhone、iPad、Mac** 上の開発者向けの **IT 学習および就職面接準備アプリ**です。 **17 のプログラミング言語**、**12 のキャリア トラック**、**16 の企業の質問バンクにわたる**10,000+**のオフライン面接の質問を閲覧できます。毎日のクイズ、お気に入り、間違った本のレビュー、ホームおよびロック画面のウィジェット、iPhone、iPad、Mac のネイティブ SwiftUI を備えています。**

## はじめに

1. iTer を開き、[カテゴリ] タブで **言語**、**キャリア カテゴリ**、または **会社** ごとに質問を参照します。
2. 質問をタップすると、プロンプト全体を読むことができます。 **答え**をタップして(またはキーボードの**スペース**を押して)、説明を表示します。
3. 複数の質問が含まれるリストから、下部のバーまたはキーボードを使用して **前 / ランダム / 次** に移動します。
4. **デイリー クイズ** に挑戦してください — 1 日あたり 5 つの多肢選択式の質問。上部のメニューから質問バンクの範囲を変更します。
5. 行をスワイプして **お気に入り** または **マスター済みとしてマーク**します。長押しすると学習ステータスが表示されます。
6. **ウィジェット**をホーム画面またはロック画面に追加します。インストール後にアプリを 1 回開くと、ウィジェットがオフライン カタログを同期できるようになります。
7. **設定**で表示言語を切り替えます (英語、簡体字中国語、繁体字中国語、またはシステムに従う)。

## 特長

### 質問ライブラリ

- **10,000 件以上の質問** — 17 の言語ファイル、12 の職業トラック、16 の企業 (2025 年のキャンパス インタビュー セットを含む 120 以上の JSON ボリューム)。
- **完全にオフライン** — すべてのコンテンツがバンドルされています。アカウントやネットワークは必要ありません。
- **グローバル検索** — すべて/言語/職業/会社でフィルタリングします。デバウンス入力、高速インデックス検索。
- **マークダウン回答** — 回答内の見出し、リスト、コード ブロック、および表。必要に応じてプレーンテキストに切り替えます。
- **詳細参照バー** — 前へ · ランダム · **回答** · 複数の質問リストから開いた場合は次へ。回答が表示されるとスクロールして表示されます。

### 学習ツール

- **毎日のクイズ** — 日付シード付きの 1 日あたり 5 つの MCQ。オプションのバンク スコープ (検索スコープとウィジェットに一致)。
- **お気に入りと最近** — 質問を保存します。ワンタップで最近の履歴をすべてクリアします。
- **間違った問題集** — 自動収集されたクイズの間違いとレビュー リスト。
- **マスタリー マーク** — 未学習 / 復習が必要 / 習得済み。スワイプまたは長押しして更新します。
- **高度な学習** — Objc.io および NSHipster のバイリンガル セクション、Awesome / Gitbook / 演習プロジェクトのリンク (コメントの字幕付き)。

### パーソナライゼーション

- **15 の組み込みテーマ** + ライト/ダーク/システムの外観。
- **UI 言語** — 英語、簡体字中国語、繁体字中国語、システムに従ってください (ウィジェットはアプリの言語に従います)。
- **ホーム画面のクイック アクション** (iOS) - **[設定] → [ホーム画面のショートカット]** の **7** オプションから最大 **4** のショートカットを構成します (検索、クイズ、お気に入り、間違った本、カテゴリ、フィードバック、評価)。ウィジェットと **`iTer://`** ディープ リンクは、質問、クイズ、お気に入り、間違った本を開きます。[URL スキーム](url-scheme) を参照してください。
- **アプリ内 Safari** の外部リンク。

### iOSとiPad

- **4 つのウィジェット タイプ** — 毎日の質問、クイズ グランス、お気に入りのグランス、間違った本のグランス。ホーム画面 (サポートされている場合は小/中) および **ロック画面** (iOS ではインライン/円形/長方形)。
- 毎日の質問ウィジェット (iOS 17 以降): 追加/編集時に質問バンクの範囲を選択します。今日のピックを変更するには、「シャッフル」をタップします。
- 間違った本ウィジェット: 特定の間違ったレコードへのディープリンク (`iTer://wrong?record=`)。
- **iPad + キーボード**: ⌘F 検索、⌘1 ～ ⌘4 タブ。詳細ショートカット ← / R / スペース / → (下記を参照)。

### macOS

- タブ ナビゲーション、**Esc** 戻る/閉じる、専用の**検索シート** (⌘F)、およびシステム共有パネルを備えたネイティブ Mac アプリ。
- デフォルトの **グリッド** リスト レイアウト。 iOS から独立したレイアウト設定。
- 詳細参照ショートカットを含む完全なキーボードのサポート。

## ウィジェット

iTer では、ホーム画面とロック画面用に **4 種類のウィジェット**を提供しています。

> **ヒント:** インストールまたは更新後にメイン アプリを 1 回開くと、質問カタログがウィジェット用のアプリ グループ ストレージに同期されます。

### 追加方法

1. ホーム画面 (またはロック画面) を長押しして、編集モードに入ります。
2. **+** をタップし、**iTer** を検索します。
3. ウィジェットとサイズを選択し、**ウィジェットを追加** をタップします。
4. **毎日の質問** (iOS 17 以降) の場合は、ウィジェットを長押し → **ウィジェットの編集** して、質問バンクの範囲 (すべて / 言語 / 職業 / 会社) を選択します。

### 利用可能なウィジェット

| ウィジェット | 説明 | サイズ |
|--------|-------------|-------|
| 毎日の質問 | 面接での質問は 1 日に 1 つ。オプションのスコープとシャッフル | 小、中。ロック画面 |
| クイズグランス | 今日のクイズのスコア、達成数、連勝数 | 小さい;ロック画面 |
| お気に入りの一覧 | お気に入り数 + プレビュー タイトル | 小さい;ロック画面 |
| 間違った本の見方 | カウントと要約が間違っています。タップしてレコードを開きます (iOS 17 以降) | 小さい;ロック画面 |

## キーボードショートカット

### iPad（外付けキーボード）

| ショートカット | アクション |
|----------|--------|
| ⌘F | 検索を開く |
| ⌘1 | 「言語」タブ |
| ⌘2 | 「カテゴリ」タブ |
| ⌘3 | 毎日のクイズタブ |
| ⌘4 | 「設定」タブ |
| ← | 前の質問 *(詳細、複数の質問リスト)* |
| R | ランダムな質問 *(詳細)* |
| 宇宙 | 回答を表示 *(詳細; 公開後は無効になります)* |
| → | 次の質問 *(詳細)* |

### macOS

| ショートカット | アクション |
|----------|--------|
| ⌘F | 検索シートを開く |
| ⌘1 – ⌘4 | タブの切り替え (言語 / カテゴリ / クイズ / 設定) |
| Esc | 戻るか閉じる *(最初に検索テキストをクリアし、ポップする前に共有プレビューを閉じます)* |
| ← | 前の質問 *(詳細、複数の質問リスト)* |
| R | ランダムな質問 *(詳細)* |
| 宇宙 | 回答を表示 *(詳細; 公開後は無効になります)* |
| → | 次の質問 *(詳細)* |

詳細ショートカットは、下部の参照バーが表示されている場合 (現在のプールに 2 つ以上の質問がある場合) にのみ適用されます。
