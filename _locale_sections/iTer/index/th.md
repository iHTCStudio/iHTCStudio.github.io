iTer คือ **แอปเตรียมการเรียนรู้ด้านไอทีและการสัมภาษณ์งาน** สำหรับนักพัฒนาบน **iPhone, iPad และ Mac** ค้นหาคำถามสัมภาษณ์แบบออฟไลน์ **10,000+** คำถามใน **ภาษาโปรแกรม 17 ภาษา** **เส้นทางอาชีพ 12 เส้นทาง** และ **คลังคำถามของบริษัท 16 รายการ พร้อมแบบทดสอบรายวัน รายการโปรด บทวิจารณ์หนังสือผิด วิดเจ็ตหน้าจอหลักและล็อค และ SwiftUI แบบเนทีฟบน iPhone, iPad และ Mac**

## เริ่มต้นใช้งาน

1. เปิด iTer และเรียกดูคำถามตาม **ภาษา** **หมวดหมู่อาชีพ** หรือ **บริษัท** บนแท็บหมวดหมู่
2. แตะคำถามใดก็ได้เพื่ออ่านข้อความแจ้งทั้งหมด แตะ **ตอบ** (หรือกด **Space** บนแป้นพิมพ์) เพื่อแสดงคำอธิบาย
3. จากรายการที่มีคำถามหลายข้อ ให้ใช้แถบด้านล่างหรือแป้นพิมพ์เพื่อย้าย **ก่อนหน้า / สุ่ม / ถัดไป**
4. ลองทำ **แบบทดสอบรายวัน** — คำถามแบบปรนัย 5 ข้อต่อวัน เปลี่ยนขอบเขตธนาคารคำถามจากเมนูด้านบน
5. ปัดแถวเพื่อ **รายการโปรด** หรือ **ทำเครื่องหมายว่าเชี่ยวชาญ**; กดแบบยาวเพื่อดูสถานะการเรียนรู้
6. เพิ่ม **วิดเจ็ต** ให้กับหน้าจอหลักหรือหน้าจอล็อค เปิดแอปอีกครั้งหลังจากติดตั้งเพื่อให้วิดเจ็ตสามารถซิงค์แคตตาล็อกออฟไลน์ได้
7. สลับภาษาที่แสดงใน **การตั้งค่า** (อังกฤษ จีนตัวย่อ จีนตัวเต็ม หรือระบบติดตาม)

## คุณสมบัติ

### ห้องสมุดคำถาม

- **คำถามกว่า 10,000 ข้อ** — ไฟล์ภาษา 17 ไฟล์ เส้นทางอาชีพ 12 เส้นทาง บริษัท 16 แห่ง (ปริมาณ JSON มากกว่า 120 รายการ รวมถึงชุดสัมภาษณ์มหาวิทยาลัยปี 2025)
- **ออฟไลน์โดยสมบูรณ์** — รวมเนื้อหาทั้งหมดแล้ว ไม่จำเป็นต้องมีบัญชีหรือเครือข่าย
- **การค้นหาทั่วโลก** — กรองตามทั้งหมด / ภาษา / อาชีพ / บริษัท อินพุต debounced, การค้นหาที่จัดทำดัชนีอย่างรวดเร็ว
- **Markdown Answers** — หัวข้อ รายการ บล็อกโค้ด และตารางในคำตอบ เปลี่ยนเป็นข้อความธรรมดาเมื่อจำเป็น
- **แถบเรียกดูรายละเอียด** — ก่อนหน้า · สุ่ม · **ตอบ** · ถัดไป เมื่อเปิดจากรายการคำถามหลายคำถาม คำตอบเลื่อนดูเมื่อเปิดเผย

### เครื่องมือการเรียนรู้

- **แบบทดสอบรายวัน** — 5 MCQ ต่อวันพร้อมเมล็ดอินทผลัม ขอบเขตธนาคารที่เป็นตัวเลือก (ตรงกับขอบเขตการค้นหาและวิดเจ็ต)
- **รายการโปรดและล่าสุด** — บันทึกคำถาม; ล้างประวัติล่าสุดทั้งหมดด้วยการแตะเพียงครั้งเดียว
- **สมุดคำถามผิด** — รวบรวมข้อผิดพลาดแบบทดสอบอัตโนมัติพร้อมรายการทบทวน
- **เครื่องหมายความเชี่ยวชาญ** — ไม่ได้เรียนรู้ / ต้องการการทบทวน / เชี่ยวชาญ; ปัดหรือกดค้างเพื่ออัปเดต
- **การเรียนรู้ขั้นสูง** — ส่วนสองภาษา Objc.io และ NSHipster ลิงก์โครงการ Awesome / Gitbook / แบบฝึกหัดพร้อมคำบรรยายหมายเหตุ

### การปรับเปลี่ยนในแบบของคุณ

- **15 ธีมในตัว** + สว่าง / มืด / ลักษณะระบบ
- **ภาษา UI** — อังกฤษ จีนตัวย่อ จีนตัวเต็ม ติดตามระบบ (วิดเจ็ตตามภาษาของแอป)
- **การดำเนินการด่วนบนหน้าจอหลัก** (iOS) — กำหนดค่าทางลัดได้สูงสุด **4** จากตัวเลือก **7** ใน **การตั้งค่า → ทางลัดบนหน้าจอหลัก** (ค้นหา แบบทดสอบ รายการโปรด หนังสือผิด หมวดหมู่ คำติชม อัตรา) วิดเจ็ตและ **`iTer://`** ลิงก์ในรายละเอียดเปิดคำถาม แบบทดสอบ รายการโปรด และหนังสือเล่มที่ไม่ถูกต้อง — ดู [URL Scheme](url-scheme)
- **Safari ในแอป** สำหรับลิงก์ภายนอก

### iOS และไอแพด

- **4 ประเภทวิดเจ็ต** — คำถามรายวัน, แบบทดสอบ, สรุปรายการโปรด, สรุปหนังสือผิด หน้าจอหลัก (เล็ก / กลางที่รองรับ) และ **ล็อคหน้าจอ** (อินไลน์ / วงกลม / สี่เหลี่ยมบน iOS)
- วิดเจ็ตคำถามรายวัน (iOS 17+): เลือกขอบเขตคลังคำถามเมื่อเพิ่ม/แก้ไข แตะสับเปลี่ยนเพื่อเปลี่ยนการเลือกของวันนี้
- วิดเจ็ตหนังสือผิด: ลิงก์ในรายละเอียดไปยังบันทึกที่ไม่ถูกต้อง (`iTer://wrong?record=`)
- **iPad + แป้นพิมพ์**: ⌘F ค้นหา ⌘1–⌘4 แท็บ; ทางลัดรายละเอียด ← / R / Space / → (ดูด้านล่าง)

### ระบบปฏิบัติการ macOS

- แอปเนทีฟสำหรับ Mac พร้อมการนำทางด้วยแท็บ, **Esc** ย้อนกลับ / ยกเลิก, **แผ่นค้นหา** (⌘F) โดยเฉพาะ และแผงแชร์ระบบ
- เค้าโครงรายการ **ตาราง** เริ่มต้น การตั้งค่าเค้าโครงที่เป็นอิสระจาก iOS
- รองรับคีย์บอร์ดเต็มรูปแบบรวมถึงทางลัดในการเรียกดูรายละเอียด

## วิดเจ็ต

iTer นำเสนอ **วิดเจ็ต 4 ชนิด** สำหรับหน้าจอหลักและหน้าจอล็อค

> **เคล็ดลับ:** เปิดแอปหลักหนึ่งครั้งหลังจากติดตั้งหรืออัปเดต เพื่อซิงค์แคตตาล็อกคำถามกับพื้นที่เก็บข้อมูลกลุ่มแอปสำหรับวิดเจ็ต

### วิธีการเพิ่ม

1. กดหน้าจอหลักค้างไว้ (หรือหน้าจอล็อค) เพื่อเข้าสู่โหมดแก้ไข
2. แตะ **+** และค้นหา **iTer**
3. เลือกวิดเจ็ตและขนาด จากนั้นแตะ **เพิ่มวิดเจ็ต**
4. สำหรับ **คำถามรายวัน** (iOS 17+) ให้กดวิดเจ็ตค้างไว้ → **แก้ไขวิดเจ็ต** เพื่อเลือกขอบเขตคลังคำถาม (ทั้งหมด / ภาษา / วิชาชีพ / บริษัท)

### วิดเจ็ตที่ใช้ได้

| วิดเจ็ต | คำอธิบาย | ขนาด |
|--------|-------------|-------|
| คำถามรายวัน | คำถามสัมภาษณ์หนึ่งคำถามต่อวัน ขอบเขตและสับเปลี่ยนเสริม | เล็ก, กลาง; ล็อคหน้าจอ |
| แบบทดสอบโดยสรุป | คะแนนควิซวันนี้ จบ ต่อเนื่อง | เล็ก; ล็อคหน้าจอ |
| ภาพรวมรายการโปรด | จำนวนรายการโปรด + ชื่อตัวอย่าง | เล็ก; ล็อคหน้าจอ |
| ภาพรวมหนังสือผิด | นับผิด + สรุป; แตะเพื่อเปิดบันทึก (iOS 17+) | เล็ก; ล็อคหน้าจอ |

## แป้นพิมพ์ลัด

### iPad (แป้นพิมพ์ภายนอก)

| ทางลัด | การดำเนินการ |
|----------|--------|
| ⌘F | เปิดการค้นหา |
| ⌘1 | แท็บภาษา |
| ⌘2 | แท็บหมวดหมู่ |
| ⌘3 | แท็บแบบทดสอบรายวัน |
| ⌘4 | แท็บการตั้งค่า |
| ← | คำถามก่อนหน้า *(รายละเอียด, รายการคำถามหลายข้อ)* |
| R | สุ่มคำถาม *(รายละเอียด)* |
| อวกาศ | แสดงคำตอบ *(รายละเอียด ปิดการใช้งานหลังเปิดเผย)* |
| → | คำถามถัดไป *(รายละเอียด)* |

### ระบบปฏิบัติการ macOS

| ทางลัด | การดำเนินการ |
|----------|--------|
| ⌘F | เปิดแผ่นค้นหา |
| ⌘1 – ⌘4 | สลับแท็บ (ภาษา / หมวดหมู่ / แบบทดสอบ / การตั้งค่า) |
| Esc | ย้อนกลับหรือยกเลิก *(ล้างข้อความค้นหาก่อน ปิดตัวอย่างการแชร์ก่อนป๊อป)* |
| ← | คำถามก่อนหน้า *(รายละเอียด, รายการคำถามหลายข้อ)* |
| R | สุ่มคำถาม *(รายละเอียด)* |
| อวกาศ | แสดงคำตอบ *(รายละเอียด ปิดการใช้งานหลังเปิดเผย)* |
| → | คำถามถัดไป *(รายละเอียด)* |

ทางลัดรายละเอียดจะใช้เฉพาะเมื่อมองเห็นแถบเรียกดูด้านล่าง (2+ คำถามในกลุ่มปัจจุบัน)
