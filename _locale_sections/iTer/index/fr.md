iTer is an **IT learning and job interview preparation app** for developers on **iPhone, iPad, and Mac**. Parcourez **plus de 10 000** questions d'entretien hors ligne dans **17 langages de programmation**, **12 pistes de carrière** et **16 banques de questions d'entreprise — avec des quiz quotidiens, des favoris, une critique de mauvais livre, des widgets d'écran d'accueil et de verrouillage et SwiftUI natif sur iPhone, iPad et Mac.**

## Commencer

1. Open iTer and browse questions by **language**, **career category**, or **company** on the Categories tab.
2. Appuyez sur n'importe quelle question pour lire l'invite complète ; appuyez sur **Répondre** (ou appuyez sur **Espace** sur le clavier) pour révéler l'explication.
3. From a list with multiple questions, use the bottom bar or keyboard to move **Previous / Random / Next**.
4. Try the **Daily Quiz** — 5 multiple-choice questions per day; change the question bank scope from the menu at the top.
5. Swipe a row to **favorite** or **mark mastered**; appuyez longuement pour obtenir le statut d'apprentissage.
6. Ajoutez des **widgets** à l'écran d'accueil ou de verrouillage ; ouvrez l'application une fois après l'installation afin que les widgets puissent synchroniser le catalogue hors ligne.
7. Switch display language in **Settings** (English, Simplified Chinese, Traditional Chinese, or Follow System).

## Caractéristiques

### Bibliothèque de questions

- **10,000+ Questions** — 17 language files, 12 profession tracks, 16 companies (120+ JSON volumes, including 2025 campus interview sets).
- **Entièrement hors ligne** – Tout le contenu est regroupé ; aucun compte ou réseau requis.
- **Global Search** — Filter by all / language / profession / company; entrée anti-rebond, recherche indexée rapide.
- **Réponses Markdown** — Titres, listes, blocs de code et tableaux dans les réponses ; passer au texte brut si nécessaire.
- **Detail Browse Bar** — Previous · Random · **Answer** · Next when opened from a multi-question list; la réponse défile lors de la révélation.

### Outils d'apprentissage

- **Daily Quiz** — 5 MCQs per day with date seed; Portée bancaire facultative (correspond à la portée de recherche et au widget).
- **Favoris et récents** — Enregistrez les questions ; effacer tout l'historique récent en un seul clic.
- **Mauvais livre de questions** - Erreurs de quiz collectées automatiquement avec liste de révision.
- **Marques de maîtrise** — Non appris / Nécessite une révision / Maîtrisé ; faites glisser ou appuyez longuement pour mettre à jour.
- **Apprentissage avancé** — Sections bilingues Objc.io et NSHipster, liens de projet Awesome / Gitbook / pratique avec sous-titres de remarques.

### Personnalisation

- **15 Built-in Themes** + light / dark / system appearance.
- **UI Languages** — English, Simplified Chinese, Traditional Chinese, Follow System (widgets follow app language).
- **Actions rapides sur l'écran d'accueil** (iOS) : configurez jusqu'à **4** raccourcis parmi les **7** options dans **Paramètres → Raccourcis de l'écran d'accueil** (Recherche, Quiz, Favoris, Mauvais livre, Catégories, Commentaires, Notation). Les widgets et les liens profonds **`iTer://`** ouvrent des questions, des quiz, des favoris et un mauvais livre — voir [Schéma d'URL](url-scheme).
- **Safari intégré à l'application** pour les liens externes.

### iOS et iPad

- **4 types de widgets** — Question quotidienne, coup d'œil au quiz, coup d'œil aux favoris, coup d'œil au mauvais livre. Écran d'accueil (petit/moyen si pris en charge) et **écran de verrouillage** (en ligne/circulaire/rectangulaire sur iOS).
- Widget de questions quotidiennes (iOS 17+) : choisissez la portée de la banque de questions lors de l'ajout/de la modification ; appuyez sur Lecture aléatoire pour modifier le choix du jour.
- Widget Wrong Book : lien profond vers un mauvais enregistrement spécifique (`iTer://wrong?record=`).
- **iPad + clavier** : ⌘F recherche, ⌘1–⌘4 onglets ; raccourcis détaillés ← / R / Espace / → (voir ci-dessous).

### macOS

- Application Mac native avec navigation par onglets, **Esc** retour/rejet, **feuille de recherche** dédiée (⌘F) et panneau de partage système.
- Disposition de la liste **grille** par défaut ; préférence de mise en page indépendante d'iOS.
- Prise en charge complète du clavier, y compris les raccourcis de navigation détaillée.

## Widgets

iTer propose **4 types de widgets** pour l'écran d'accueil et l'écran de verrouillage.

> **Conseil :** Ouvrez l'application principale une fois après l'installation ou la mise à jour afin qu'elle synchronise le catalogue de questions avec le stockage du groupe d'applications pour les widgets.

### Comment ajouter

1. Appuyez longuement sur l'écran d'accueil (ou l'écran de verrouillage) pour passer en mode édition.
2. Appuyez sur **+** et recherchez **iTer**.
3. Choisissez un widget et une taille, puis appuyez sur **Ajouter un widget**.
4. Pour les **Questions quotidiennes** (iOS 17+), appuyez longuement sur le widget → **Modifier le widget** pour choisir la portée de la banque de questions (Tous/Langue/Profession/Entreprise).

### Widgets disponibles

| Widget | Descriptif | Tailles |
|--------|-------------|-------|
| Question quotidienne | Une question d'entretien par jour ; portée et lecture aléatoire en option | Petit, moyen ; Écran de verrouillage |
| Aperçu du quiz | Score du quiz du jour, achèvement, séquence | Petit ; Écran de verrouillage |
| Aperçu des favoris | Nombre de favoris + titres en avant-première | Petit ; Écran de verrouillage |
| Mauvais regard sur un livre | Mauvais décompte + résumés ; appuyez pour ouvrir l'enregistrement (iOS 17+) | Petit ; Écran de verrouillage |

## Raccourcis clavier

### iPad (clavier externe)

| Raccourci | Action |
|----------|--------|
| ⌘F | Ouvrir la recherche |
| ⌘1 | Onglet Langues |
| ⌘2 | Onglet Catégories |
| ⌘3 | Onglet Quiz quotidien |
| ⌘4 | Onglet Paramètres |
| ← | Question précédente *(détail, liste multi-questions)* |
| R | Question aléatoire *(détail)* |
| Espace | Afficher la réponse *(détail ; désactivé après révélation)* |
| → | Question suivante *(détail)* |

### macOS

| Raccourci | Action |
|----------|--------|
| ⌘F | Ouvrir la feuille de recherche |
| ⌘1 – ⌘4 | Changer d'onglet (Langues / Catégories / Quiz / Paramètres) |
| Échap | Revenir en arrière ou ignorer *(efface d'abord le texte de recherche ; ferme l'aperçu du partage avant l'apparition)* |
| ← | Question précédente *(détail, liste multi-questions)* |
| R | Question aléatoire *(détail)* |
| Espace | Afficher la réponse *(détail ; désactivé après révélation)* |
| → | Question suivante *(détail)* |

Les raccourcis détaillés s'appliquent uniquement lorsque la barre de navigation inférieure est visible (plus de 2 questions dans le pool actuel).
