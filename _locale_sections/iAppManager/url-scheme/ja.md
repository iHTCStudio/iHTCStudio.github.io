iAppManager は、ショートカット、ウィジェット、アプリのインテント、ホーム画面のアクションのリンクとして、**         ** をサポートしています。

## リンク形式


```
iappmanager://{host}[/…]
```


## アプリとモジュール

| URL | 開く画面 |
|-----|-------|
| `iappmanager://apps` | 私のアプリ |
| `iappmanager://apps/{appleId}` | 特定のアプリ(概要) |
| `iappmanager://apps/{appleId}/{tab}` | アプリ詳細モジュール | `iappmanager://` は数値アプリストアコネクト/App StoreアプリIDです。 `iappmanager://apps` | Tab | モジュール |
|-----|--------|
| `overview` | プロフィール |
| `versions` | バージョン |
| `builds` | ビルド |
| `backgroundAssets` | 背景資産 |
| `encryption` | 暗号化 |
| `submissions` | レビュー投稿者 |
| `reviewDetail` | レビュー詳細 |
| `metadata` | メタデータ |
| `media` | スクリーンショットとプレビュー |
| `productPages` | カスタム製品ページ |
| `appEvents` | アプリ内イベント |
| `appClips` | アプリクリップ |
| `experiments` | ストア実験 |
| `nominations` | ノミネーションを特徴とする |
| `availability` | 交通アクセス |
| `pricing` | 料金について |
| `ageRating` | 年齢評価 |
| `accessibility` | アクセス |
| `appTags` | アプリタグ |
| `iap` | アプリ内購入 |
| `gameCenter` | ゲームセンター |
| `testflight` | テストフライト |
| `reviews` | 顧客レビュー |
| `privacy` | プライバシー(栄養メモ) |
| `promoCodes` | プロモーションコード |
| `webhooks` | ウェブホック |
