การรองรับการทํา iDigi # `idict://` BAR -~ ลิงก์ลัดสําหรับปุ่มพิมพ์ลัด, ที่คั่นหน้าภาษาซาฟารี, วิดเจ็ต, และการกระทําอย่างรวดเร็วของหน้าจอบ้าน

## รูปแบบลิงก์


```
idict://{host}?{params}
```


## ค้นหา

| URL | เปิด |
|-----|-------|
| `idict://char?c=爱` | รายละเอียดตัวอักษรสําหรับ 爱 |
| `idict://word?id=123` | รายการคําโดยหมายเลข |
| `idict://idiom?id=456` | หมายเลขรายการ IDC |
| `idict://search` | ค้นหาหน้าจอ |

## สุ่มทุกวัน

| URL | เปิด |
|-----|-------|
| `idict://daily` | การ์ดของตัวละครรายวัน |
| `idict://random` | สุ่มอักขระ |
