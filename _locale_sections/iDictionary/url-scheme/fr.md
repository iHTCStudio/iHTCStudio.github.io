iDictionary prend en charge ** `idict://` ** liens raccourcis pour raccourcis, signets Safari, widgets et actions rapides de l'écran d'accueil.

## Format de lien


```
idict://{host}?{params}
```


## Recherche

| URL | Ouvre |
|-----|-------|
| `idict://char?c=爱` | Caractère détaillé pour : |
| `idict://word?id=123` | Entrée Word par ID |
| `idict://idiom?id=456` | Entrée d'idiome par ID |
| `idict://search` | Écran de recherche |

## Quotidien & aléatoire

| URL | Ouvre |
|-----|-------|
| `idict://daily` | Carte de caractère quotidienne |
| `idict://random` | caractère aléatoire |

## Modes d'entrée

| URL | Ouvre |
|-----|-------|
| `idict://handwriting` | Recherche d'écriture |
| `idict://ocr` | Scan OCR caméra |
