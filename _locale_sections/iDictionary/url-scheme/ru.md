iDictionary поддерживает ярлыки ** `idict://` ** для коротких ярлыков, закладок Safari, виджетов и быстрых действий на домашнем экране.

## Формат ссылки


```
idict://{host}?{params}
```


## Поиск

| URL | Открывает |
|-----|-------|
| `idict://char?c=爱` | Характеристики для |
| `idict://word?id=123` | Ввод слова ID |
| `idict://idiom?id=456` | Идиомный вход по ID |
| `idict://search` | Поисковый экран |

## Daily & Random

| URL | Открывает |
|-----|-------|
| `idict://daily` | Ежедневная карта персонажей |
| `idict://random` | Случайный персонаж |

## Режимы ввода

| URL | Открывает |
|-----|-------|
| `idict://handwriting` | Поиск почерка |
| `idict://ocr` | Сканирование камеры OCR |

## Навигация

| URL | Открывает |

| `idict://favorites` | Избранное |
