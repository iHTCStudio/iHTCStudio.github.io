iDictionaryは、ショートカット、Safariブックマーク、ウィジェット、ホーム画面のクイックアクションのショートカットリンクをサポートしています。

## リンク形式


```
idict://{host}?{params}
```


## インタビュー

| URL | 開く画面 |
|-----|-------|
| `idict://char?c=爱` | キャラクター詳細 |
| `idict://word?id=123` | IDによるWordの入力 |
| `idict://idiom?id=456` | IDによるIdiomエントリー |
| `idict://search` | 検索画面 |

## デイリー&ランダム

| URL | 開く画面 |
|-----|-------|
| `idict://daily` | 毎日のキャラクターカード |
| `idict://random` | ランダムキャラクター |

| URL | 開く画面 |
