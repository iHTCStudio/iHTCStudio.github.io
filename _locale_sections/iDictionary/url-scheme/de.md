iDictionary unterstützt ** `idict://` ** Shortcut-Links für Shortcuts, Safari-Lesezeichen, Widgets und schnelle Aktionen auf dem Startbildschirm.

## Linkformat


```
idict://{host}?{params}
```


## Lookup

| URL | Öffnet |
|-----|-------|
| `idict://char?c=爱` | Zeichendetail für 爱 |
| `idict://word?id=123` | Word Entry nach ID |
| `idict://idiom?id=456` | Idiom-Eintrag nach ID |
| `idict://search` | Suchbildschirm |

## Täglich & Random

| URL | Öffnet |
|-----|-------|
| `idict://daily` | Tägliche Zeichenkarte |
| `idict://random` | Zufallscharakter |
