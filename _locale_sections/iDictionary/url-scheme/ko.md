iDictionary는 ** `idict://` ** Shortcuts, Safari bookmarks, 위젯 및 홈 화면 빠른 행동을위한 단축 링크.

## 링크 형식


```
idict://{host}?{params}
```


## 사이트 맵

| URL | 열리는 화면 |
|-----|-------|
| `idict://char?c=爱` | 캐릭터 디테일 |
| `idict://word?id=123` | ID로 로그인 |
| `idict://idiom?id=456` | ID로 입력 |
| `idict://search` | 검색 화면 |

## 매일 & 무작위

| URL | 열리는 화면 |
|-----|-------|
| `idict://daily` | 매일 문자 카드 |
| `idict://random` | 무작위 문자 |

## 입력 모드

| URL | 열리는 화면 |
