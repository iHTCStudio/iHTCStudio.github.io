iDictionary ** `idict://` ** Kısa kesimler için kısayol bağlantıları, Safari kitap işaretleri, widgets ve Home Ekran hızlı eylemleri.

## Bağlantı biçimi


```
idict://{host}?{params}
```


## Lookup

| URL | Açar |
|-----|-------|
| `idict://char?c=爱` | 爱 |
| `idict://word?id=123` | Word entry Tarafından ID |
| `idict://idiom?id=456` | Idiom Girişi ID |
| `idict://search` | Arama ekranı |

## Daily & Random

| URL | Açar |
|-----|-------|
| `idict://daily` | Günlük karakter kartı kartı kart |
| `idict://random` | Rastgele karakter |
