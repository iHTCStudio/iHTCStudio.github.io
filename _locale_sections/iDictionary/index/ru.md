iDictionary (爱字词典) — **полностью офлайновый словарь для изучения китайских иероглифов**, ваша карманная библиотека китайской письменности. **Учётная запись не нужна.** После однократной настройки базы данных при первом запуске всё работает на вашем устройстве: **более 20 000 иероглифов**, **более 320 000 слов**, **более 49 000 чэнъюй** и **более 9 500 SVG-анимаций порядка черт**. Ищите по пиньиню, ключу, числу черт, рукописному вводу или через камеру (OCR); слушайте **путунхуа в озвучке TTS**; листайте карточки **иероглифа дня** и **чэнъюй дня**; а **виджеты**, **Live Activity**, **Пункт управления**, **Siri**, **Быстрые команды** и **Spotlight** помогут не бросать учёбу. Необязательная **синхронизация iCloud** для избранного — по умолчанию выключена. **Без рекламы. Без отслеживания.**

## Первые шаги

1. При первом запуске немного подождите, пока распаковывается офлайн-база (около 155 МБ) — после этого вы навсегда полностью офлайн.
2. Пройдите **приветственное руководство** (его можно открыть снова в **Настройки → Руководства**).
3. Используйте **Поиск** по иероглифам, словам, чэнъюй или пиньиню — либо просматривайте по **ключам**, **числу черт**, **частотности** и **многозначным иероглифам (полифонам)**.
4. Нажмите на иероглиф, чтобы увидеть подробности: пиньинь, ключ, черты, структуру, варианты, значения, цитаты и **анимацию порядка черт**.
5. Попробуйте **рукописный** поиск или **OCR-сканирование камерой**, когда встретите незнакомый иероглиф.
6. Откройте карточки **иероглифа дня** или **чэнъюй дня** на главном экране.
7. Отмечайте записи звёздочкой, чтобы добавить их в **Избранное**; **Историю** можно просмотреть в любой момент.
8. Добавьте **виджеты** (экран «Домой» и экран блокировки), включите **Live Activity** для иероглифа дня или попросите **Siri** найти иероглиф.

## Возможности

### Крупный офлайн-словарь

- **20 000+ иероглифов** · **320 000+ слов** · **49 000+ чэнъюй** — единый поиск FTS5
- Статья об иероглифе: пиньинь, ключ, число черт, структура, варианты, значения, примеры с цитатами
- **9 500+ SVG-анимаций порядка черт** — смотрите каждую черту шаг за шагом
- Указатели для просмотра: ключи, черты, частотность, полифоны, пиньинь чэнъюй
- Трёхъязычный интерфейс (English · 简体中文 · 繁體中文); содержимое на упрощённом китайском с преобразованием «упрощённый → традиционный» на лету

### Мультимодальный поиск

- **Рукописный ввод** — нарисуйте иероглиф для поиска
- **OCR-сканирование камерой** — наведите камеру на печатный текст для распознавания иероглифов
- **Озвучивание путунхуа (TTS)** с автоматическим чтением и регулируемой скоростью
- Карточки **иероглифа дня** и **чэнъюй дня** для обучения небольшими порциями
- **Случайный иероглиф** — встряхните кубик или используйте Пункт управления (iOS 18+)

### Обучение и персонализация

- **Учебные инструменты на главном экране** — структурированные точки входа для практики помимо ежедневных карточек
- **Просмотр по категориям** — изучайте иероглифы по тематическим подборкам
- **Избранное** с пакетным управлением и **история просмотров**
- **Карточки для обмена** — экспортируйте карточку иероглифа, чтобы поделиться
- **Акцентные темы** — смена акцентного цвета приложения
- Необязательная **синхронизация iCloud KV** для избранного и настроек (по умолчанию выключена)
- Настраиваемые TTS, тема и параметры отображения

### Виджеты, Live Activity и интеграция с системой

- **Виджеты** — иероглиф дня, чэнъюй дня, обзор обучения + аксессуары экрана блокировки
- **Live Activity** (iOS 16.2+) — иероглиф дня в Dynamic Island и на экране блокировки
- **Пункт управления** (iOS 18+) — элемент для случайного иероглифа
- **Siri и Быстрые команды** — поиск, иероглиф дня, случайный иероглиф, открыть поиск
- **Spotlight** (iOS 17+) — индекс иероглифов с глубокими ссылками на подробности
- **Быстрые действия на экране «Домой»** — до 4 настраиваемых ярлыков
- **Глубокие ссылки `idict://`** — см. [Ссылки быстрых команд](url-scheme)

### Конфиденциальность

- **Без учётной записи · без регистрации · без рекламы · без отслеживания**
- Все данные словаря остаются на вашем устройстве после настройки при первом запуске
- Необязательная синхронизация iCloud — только для вашего собственного избранного
