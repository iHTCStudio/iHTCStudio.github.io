### iDictionary는 완전히 오프라인으로 사용할 수 있나요?

네. 처음 실행할 때 한 번 데이터베이스 설정(약 155 MB 압축 해제)을 마치면 **모든 사전 콘텐츠를 인터넷 없이 사용할 수 있습니다**. 선택 사항인 iCloud 동기화를 켰을 때만 네트워크를 사용합니다.

### 계정이 필요한가요?

아니요. iDictionary는 **가입, 로그인, 계정이 필요 없습니다**.

### 한자, 단어, 성어는 각각 몇 개가 수록되어 있나요?

**한자 20,000자 이상**, **단어 320,000개 이상**, **성어 49,000개 이상**과 **필순 애니메이션 9,500개 이상**을 수록하고 있습니다.

### 손글씨 검색은 어떻게 작동하나요?

손글씨 패드에 글자를 쓰면 iDictionary가 내장 한자 데이터베이스와 획을 대조해 결과를 즉시 보여 줍니다. 모든 처리는 기기 내에서 이루어집니다.

### OCR / 카메라 검색은 어떻게 작동하나요?

인쇄된 중국어 글자에 카메라를 향하세요. 기기 내 비전 기능이 글자를 인식해 해당 사전 항목을 엽니다. 이미지는 업로드되지 않습니다.

### 필순 애니메이션이란 무엇인가요?

**9,500개 이상의 SVG 애니메이션**이 각 획을 올바른 순서로 보여 줍니다. 글자 쓰는 법을 배우기에 이상적입니다.

### 어떤 위젯이 있나요?

오늘의 한자, 오늘의 성어, 학습 개요와 잠금 화면 액세서리가 있습니다. iOS 16.2 이상에서는 **실시간 현황(Live Activity)**이 다이내믹 아일랜드와 잠금 화면에 오늘의 한자를 표시합니다. iOS 18 이상에서는 무작위 한자를 보여 주는 **제어 센터** 컨트롤도 추가됩니다.

### Siri나 단축어를 사용할 수 있나요?

네. 한자 검색, 오늘의 한자 열기, 무작위 한자 보기, 검색 열기를 Siri와 단축어 앱으로 실행할 수 있습니다. [바로가기 링크](../url-scheme)를 참고하세요.

### iCloud 동기화는 무엇을 포함하나요?

**즐겨찾기**와 **설정**을 동기화하는 선택 기능입니다. **기본값은 꺼짐**이며, iHTC Studio 서버가 아닌 개인 iCloud 키-값 저장소를 사용합니다.

### 앱은 어떤 언어를 지원하나요?

UI는 **English, 简体中文, 繁體中文**를 지원합니다. 사전 콘텐츠는 간체 중국어이며 간체→번체 실시간 변환을 지원합니다.

### 어떤 기기를 지원하나요?

iPhone, iPad, Mac, visionOS를 지원합니다. 최소 OS 버전은 [지원 페이지](.)를 참고하세요.
