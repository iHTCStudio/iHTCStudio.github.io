iHTC Studio создала iDictionary (爱字词典 / 愛字詞典). На этой странице описано, как мы обращаемся с данными.

## Кратко

**iDictionary не требует учётной записи и не собирает персональные данные на серверах iHTC Studio.** Всё содержимое словаря после первоначальной настройки при первом запуске хранится на вашем устройстве. Необязательная **синхронизация через iCloud** позволяет синхронизировать избранное и настройки между вашими устройствами через **ваш личный iCloud** — по умолчанию **выключена**. **Без рекламы. Без отслеживания.**

## Сбор данных

- **Без учётной записи** — не нужны ни регистрация, ни электронная почта, ни номер телефона.
- **Без аналитики и рекламы** — никаких сторонних SDK для аналитики, рекламы или отслеживания.
- **Без облачного словаря** — поисковые запросы не покидают устройство (за исключением необязательного iCloud для вашего собственного избранного).

## Данные, хранящиеся на вашем устройстве

| Данные | Назначение |
|------|---------|
| Распакованная база словаря | Офлайн-доступ к иероглифам, словам, чэнъюй, SVG порядка черт |
| Избранное | Иероглифы, слова и чэнъюй, отмеченные звёздочкой |
| История просмотров | Недавние запросы |
| Настройки | Тема, язык, параметры озвучивания (TTS) |
| Состояние первого запуска | Видели ли вы руководства |
| Переключатель синхронизации iCloud | Локальная настройка для включения синхронизации |

## Синхронизация через iCloud

Необязательная синхронизация iCloud поддерживает избранное и настройки одинаковыми на устройствах, где выполнен вход с одним Apple ID. Данные синхронизируются через **ваше личное хранилище «ключ — значение» iCloud**, а не через серверы iHTC Studio. **По умолчанию отключена.**

## Разрешения

| Разрешение | Когда | Зачем |
|------------|------|-----|
| Камера | Поиск по OCR | Распознавание иероглифов на фото — обработка на устройстве |
| Микрофон | Не используется | — |
| iCloud | Необязательная синхронизация | Синхронизация избранного между устройствами |

## Конфиденциальность детей

iDictionary сознательно не собирает персональную информацию детей.
