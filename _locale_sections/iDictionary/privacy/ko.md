iHTC Studio가 iDictionary(爱字词典 / 愛字詞典)를 만들었습니다. 이 페이지에서는 데이터 처리 방식을 설명합니다.

## 요약

**iDictionary는 계정이 필요 없으며 iHTC Studio 서버에 개인 데이터를 수집하지 않습니다.** 모든 사전 콘텐츠는 처음 실행 시 설정을 마친 후 기기에 저장됩니다. 선택 사항인 **iCloud 동기화**를 켜면 **개인 iCloud**를 통해 여러 기기에서 즐겨찾기와 설정을 맞출 수 있으며, 기본값은 **꺼짐**입니다. **광고 없음. 추적 없음.**

## 데이터 수집

- **계정 없음** — 가입, 이메일, 전화번호가 필요하지 않습니다.
- **분석·광고 없음** — 서드파티 분석, 광고, 추적 SDK를 사용하지 않습니다.
- **클라우드 사전 없음** — 검색은 기기 밖으로 나가지 않습니다(본인의 즐겨찾기를 위한 선택적 iCloud 제외).

## 기기에 저장되는 데이터

| 데이터 | 용도 |
|------|---------|
| 압축 해제된 사전 데이터베이스 | 오프라인 한자, 단어, 성어, 필순 SVG |
| 즐겨찾기 | 별표를 표시한 한자, 단어, 성어 |
| 열람 기록 | 최근 검색 |
| 설정 | 테마, 언어, TTS 설정 |
| 온보딩 상태 | 가이드를 본 적이 있는지 여부 |
| iCloud 동기화 스위치 | 동기화를 켜기 위한 로컬 설정 |

## iCloud 동기화

선택 사항인 iCloud 동기화는 같은 Apple ID로 로그인한 기기 간에 즐겨찾기와 설정을 맞춰 줍니다. 데이터는 iHTC Studio 서버가 아니라 **개인 iCloud 키-값 저장소**를 통해 동기화됩니다. **기본값은 비활성화**입니다.

## 권한

| 권한 | 시점 | 이유 |
|------------|------|-----|
| 카메라 | OCR 검색 | 사진 속 글자 인식 — 기기 내에서 처리 |
| 마이크 | 사용하지 않음 | — |
| iCloud | 선택적 동기화 | 기기 간 즐겨찾기 동기화 |

## 아동 개인정보 보호

iDictionary는 아동의 개인정보를 의도적으로 수집하지 않습니다.
