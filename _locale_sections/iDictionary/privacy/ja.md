iHTC Studio が iDictionary（爱字词典 / 愛字詞典）を開発しました。このページでは、データの取り扱いについて説明します。

## 概要

**iDictionary はアカウント不要で、iHTC Studio のサーバーに個人データを収集することはありません。** すべての辞書コンテンツは、初回起動時のセットアップ後、端末内に保存されます。任意の **iCloud 同期**を使うと、**お客様のプライベートな iCloud** を通じて、お気に入りと設定を複数の端末間で揃えられます（初期設定は**オフ**）。**広告なし。トラッキングなし。**

## データ収集について

- **アカウントなし** — 登録、メールアドレス、電話番号は不要です。
- **分析や広告なし** — サードパーティの分析、広告、トラッキング SDK は使用しません。
- **クラウド辞書なし** — 検索は端末の外に出ません（ご自身のお気に入りに対する任意の iCloud を除く）。

## 端末に保存されるデータ

| データ | 用途 |
|------|---------|
| 展開済み辞書データベース | オフラインの漢字、語、成語、筆順 SVG |
| お気に入り | スターを付けた漢字、語、成語 |
| 閲覧履歴 | 最近の検索 |
| 設定 | テーマ、言語、読み上げ（TTS）の設定 |
| オンボーディング状態 | ガイドを表示済みかどうか |
| iCloud 同期のスイッチ | 同期を有効にするためのローカル設定 |

## iCloud 同期

任意の iCloud 同期により、同じ Apple ID でサインインしている端末間で、お気に入りと設定を揃えられます。データは iHTC Studio のサーバーではなく、**お客様のプライベートな iCloud キーバリューストア**を通じて同期されます。**初期設定では無効**です。

## 権限

| 権限 | タイミング | 目的 |
|------------|------|-----|
| カメラ | OCR 検索 | 写真内の文字を認識 — 処理は端末内で完結 |
| マイク | 使用しません | — |
| iCloud | 任意の同期 | お気に入りを端末間で同期 |

## お子様のプライバシー

iDictionary は、お子様から個人情報を意図的に収集することはありません。

## 変更について

本ポリシーは更新されることがあります。変更後も引き続きご利用いただいた場合、変更に同意したものとみなされます。
