iTangPoems는 **`itangpoems://`** 바로가기 링크를 지원합니다.

## 링크 형식


```
itangpoems://{host}?{params}
```


## Poems 및 저자

| URL | 열리는 화면 |
|-----|-------|
| `itangpoems://poem?id=1` | 시 상세(예: id 1) |
| `itangpoems://author?id=1` | 시인 상세 |
| `itangpoems://recite?id=1` | 시 암송 모드 |

## 탐색

| URL | 열리는 화면 |
|-----|-------|
| `itangpoems://daily` | 오늘의 시 |
| `itangpoems://random` | 무작위 시 |
| `itangpoems://favorites` | 즐겨찾기 |
| `itangpoems://search?q=月` | 「月」가 포함된 시 검색 |
