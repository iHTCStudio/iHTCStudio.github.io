iTangPoems поддерживает **`itangpoems://`** — ссылки-ярлыки.

## Формат ссылки


```
itangpoems://{host}?{params}
```


## Стихи и авторы

| URL | Открывает |
|-----|-------|
| `itangpoems://poem?id=1` | Страница стихотворения (напр. id 1) |
| `itangpoems://author?id=1` | Страница поэта |
| `itangpoems://recite?id=1` | Режим декламации стиха |

## Обзор

| URL | Открывает |
|-----|-------|
| `itangpoems://daily` | Стих дня |
| `itangpoems://random` | Случайное стихотворение |
| `itangpoems://favorites` | Избранное |
| `itangpoems://search?q=月` | Поиск стихов с 月 |
