iTangPoems, **`itangpoems://`** kısayol bağlantılarını destekler.

## Bağlantı biçimi


```
itangpoems://{host}?{params}
```


## Poems & Yazarlar

| URL | Açar |
|-----|-------|
| `itangpoems://poem?id=1` | Şiir ayrıntısı (ör. id 1) |
| `itangpoems://author?id=1` | Şair ayrıntısı |
| `itangpoems://recite?id=1` | Şiir için ezber modu |

## Keşfet

| URL | Açar |
|-----|-------|
| `itangpoems://daily` | Günün şiiri |
| `itangpoems://random` | Rastgele şiir |
| `itangpoems://favorites` | Favoriler |
| `itangpoems://search?q=月` | 月 içeren şiirleri ara |
