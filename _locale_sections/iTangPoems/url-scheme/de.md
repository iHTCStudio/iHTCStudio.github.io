iTangPoems unterstützt **`itangpoems://`**-Verknüpfungslinks.

## Linkformat


```
itangpoems://{host}?{params}
```


## Gedichte & Autoren

| URL | Öffnet |
|-----|-------|
| `itangpoems://poem?id=1` | Gedichtdetail (z. B. id 1) |
| `itangpoems://author?id=1` | Dichterdetail |
| `itangpoems://recite?id=1` | Rezitationsmodus für ein Gedicht |

## Entdecken

| URL | Öffnet |
|-----|-------|
| `itangpoems://daily` | Gedicht des Tages |
| `itangpoems://random` | Zufälliges Gedicht |
| `itangpoems://favorites` | Favoriten |
| `itangpoems://search?q=月` | Gedichte mit 月 suchen |
