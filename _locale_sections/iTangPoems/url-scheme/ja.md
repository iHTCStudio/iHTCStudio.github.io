iTangPoems は **`itangpoems://`** ショートカットリンクに対応しています。

## リンク形式


```
itangpoems://{host}?{params}
```


## 詩と著者

| URL | 開く画面 |
|-----|-------|
| `itangpoems://poem?id=1` | 詩の詳細（例: id 1） |
| `itangpoems://author?id=1` | 詩人の詳細 |
| `itangpoems://recite?id=1` | 詩の暗誦モード |

## 発見

| URL | 開く画面 |
|-----|-------|
| `itangpoems://daily` | 今日の詩 |
| `itangpoems://random` | ランダムな詩 |
| `itangpoems://favorites` | お気に入り |
| `itangpoems://search?q=月` | 「月」を含む詩を検索 |
