iTangPoems รองรับลิงก์ทางลัด **`itangpoems://`**

## รูปแบบลิงก์


```
itangpoems://{host}?{params}
```


## ผู้เขียนบทกวี

| URL | เปิด |
|-----|-------|
| `itangpoems://poem?id=1` | รายละเอียดบทกวี (เช่น id 1) |
| `itangpoems://author?id=1` | รายละเอียดกวี |
| `itangpoems://recite?id=1` | โหมดท่องบทกวี |

## ค้นพบ

| URL | เปิด |
|-----|-------|
| `itangpoems://daily` | บทกวีประจำวัน |
| `itangpoems://random` | บทกวีแบบสุ่ม |
| `itangpoems://favorites` | รายการโปรด |
| `itangpoems://search?q=月` | ค้นหาบทกวีที่มี 月 |
