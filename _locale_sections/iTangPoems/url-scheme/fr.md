iTangPoems prend en charge les liens **`itangpoems://`**.

## Format de lien


```
itangpoems://{host}?{params}
```


## Poèmes & auteurs

| URL | Ouvre |
|-----|-------|
| `itangpoems://poem?id=1` | Détail du poème (p. ex. id 1) |
| `itangpoems://author?id=1` | Détail du poète |
| `itangpoems://recite?id=1` | Mode récitation pour un poème |

## Découverte

| URL | Ouvre |
|-----|-------|
| `itangpoems://daily` | Poème du jour |
| `itangpoems://random` | Poème aléatoire |
| `itangpoems://favorites` | Favoris |
| `itangpoems://search?q=月` | Rechercher des poèmes contenant 月 |
