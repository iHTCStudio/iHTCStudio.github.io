iHTC Studio가 iTangPoems(爱唐诗 / 愛唐詩)를 개발했습니다.

## 요약

**수집하는 데이터 없음(Data Not Collected).** iTangPoems는 설치 후 **외부 네트워크 요청을 전혀 보내지 않습니다**. **계정 없음. 광고 없음. 분석 SDK 없음.** 모든 시 데이터는 기기에 로컬로 저장됩니다. 즐겨찾기와 학습 진행 상황을 위한 선택형 **iCloud 동기화**는 **사용자의 개인 iCloud**만 사용합니다.

## 기기에 저장되는 데이터

| 데이터 | 용도 |
|------|---------|
| 시 데이터베이스 | 앱에 내장된 368편의 시 |
| 즐겨찾기 | 별표를 표시한 시 |
| 학습 진행 상황 | 숙련도, 연속 학습 일수, 퀴즈 결과 |
| 환경설정 | 테마, TTS 설정, 읽기 레이아웃 |
| 알림 설정 | 매일 시 알림(로컬 전용) |

## iCloud 동기화

사용자의 개인 iCloud 키-값 저장소를 통해 즐겨찾기와 학습 진행 상황을 선택적으로 동기화합니다.

## 권한

| 권한 | 시점 | 이유 |
|------------|------|-----|
| 알림 | 매일 시 알림 | 로컬 예약만 사용 — 서버 없음 |
| iCloud | 선택형 동기화 | 즐겨찾기와 진행 상황 동기화 |
