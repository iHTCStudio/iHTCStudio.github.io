iTangPoems (爱唐诗 / 愛唐詩) разработана студией iHTC Studio.

## Кратко

**Данные не собираются (Data Not Collected).** После установки iTangPoems **не отправляет никаких исходящих сетевых запросов**. **Без учётной записи. Без рекламы. Без аналитических SDK.** Все данные о стихотворениях хранятся локально. Необязательная **синхронизация через iCloud** для избранного и прогресса обучения использует только **ваш личный iCloud**.

## Данные, хранящиеся на вашем устройстве

| Данные | Назначение |
|------|---------|
| База стихотворений | 368 стихотворений, встроенных в приложение |
| Избранное | Стихотворения, отмеченные звёздочкой |
| Прогресс обучения | Уровни освоения, серии занятий, результаты викторин |
| Настройки | Тема, параметры озвучивания (TTS), макет чтения |
| Настройки уведомлений | Ежедневные напоминания о стихотворении (только локально) |

## Синхронизация через iCloud

Необязательная синхронизация избранного и прогресса обучения через ваше личное хранилище «ключ — значение» iCloud.

## Разрешения

| Разрешение | Когда | Зачем |
|------------|------|-----|
| Уведомления | Ежедневное напоминание о стихотворении | Только локальное планирование — без сервера |
| iCloud | Необязательная синхронизация | Синхронизация избранного и прогресса |
