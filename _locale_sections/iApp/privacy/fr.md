iHTC Studio (« nous », « notre » ou « notre ») a créé une iApp (également connue sous le nom de « 爱应用 » / « 愛應用 »). Cette page décrit nos politiques concernant la collecte, l'utilisation et la divulgation de données lorsque vous utilisez notre application. 

## Résumé 

**iApp ne nécessite pas de compte et ne collecte pas de données personnelles sur les serveurs iHTC Studio.** L'application lit les **données publiques de l'App Store** sur Internet. Vos favoris, filtres, historique de classement, historique de recherche et paramètres d'abonnement sont **enregistrés sur votre appareil** ; **iCloud Sync** en option peut synchroniser les favoris, les abonnements, les préréglages de filtres et les préférences de région de recherche via **iCloud**. Sur iOS 17+, les favoris sont également partagés avec les widgets de l'écran d'accueil de votre appareil. 

## Collecte de données 

Nous n'exploitons pas de backend qui collecte vos informations personnelles. Plus précisément : 

- **Aucun compte** — Aucune inscription, e-mail ou numéro de téléphone n'est requis. 
- **Aucune analyse ni publicité** — Aucun outil d'analyse, de publicité ou de suivi tiers n'est intégré. 
- **Aucun accès au contenu** — Nous ne pouvons pas voir quelles applications vous parcourez, recherchez ou préférez. 

## Comment fonctionne l'application 

iApp récupère les informations **publiques** sur l'application depuis l'App Store via Internet :

Les classements, les résultats de recherche et les pages de détails nécessitent un accès réseau.
-Les données sont fournies par Apple; iApp ne modifie pas les listes des magasins.
-L'ouverture de l'App Store officiel ou de la page produit in-app utilise les services système d'Apple.

## Synchronisation iCloud 

La synchronisation iCloud utilise des **bascules distinctes** dans **Paramètres → Données** : 

- **Favoris** — vos applications enregistrées (par ID d'application et région), groupes, notes et épingles ; fusionné par horodatage afin que les suppressions soient respectées 
- **Favoris des développeurs** — développeurs enregistrés (par artiste + région) ; **bascule séparée, désactivée par défaut** ; fusion basée sur l'horodatage 
- **Abonnements** — votre liste de surveillance (facultatif) 
- **Préréglages de filtre** — préréglages de suivi de classement (facultatif) 
- **Région de recherche et régions rapides** — valeurs par défaut de recherche et puces de région rapide (facultatif) 

Les données sont synchronisées sur les appareils iPhone, iPad et Mac connectés au même identifiant Apple via **iCloud**. Les données restent dans **votre compte iCloud privé**, pas sur les serveurs iHTC Studio. 

Sur **iOS 17+**, les favoris nécessaires aux widgets sont également conservés sur votre appareil pour que le widget puisse les lire. Ces données ne quittent pas votre appareil, sauf via **iCloud** lorsque la synchronisation est activée.

## Confidentialité des enfants

iApp ne collecte pas sciemment de données personnelles auprès de quiconque, y compris les enfants de moins de 13 ans. Comme iHTC Studio ne gère pas de système de collecte de données, aucune disposition spéciale n'est requise au-delà des politiques de la plateforme Apple.

## Avis de non-responsabilité

iApp **n'est pas affilié à Apple Inc.** et ne fournit pas de services de téléchargement ou d'installation d'applications. Toutes les données de la boutique proviennent de sources publiques de l'App Store ; veuillez vous référer à l'App Store officiel pour les achats et les téléchargements.
