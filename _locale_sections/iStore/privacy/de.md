iHTC Studio („wir“, „uns“ oder „unser“) hat iStore (auch bekannt als „爱商店“ / „愛商店“) entwickelt. Diese Seite beschreibt unsere Richtlinien zur Erhebung, Nutzung und Offenlegung von Daten bei der Nutzung unserer App.

## Zusammenfassung

**iStore benötigt kein Konto und erhebt keine personenbezogenen Daten auf Servern von iHTC Studio.** Das Wechseln der Region nutzt Apples **offiziellen App-Store-Weiterleitungslink** — iStore sieht oder speichert niemals Ihre Apple-ID, Ihr Passwort oder Ihre Zahlungsinformationen. Ihre Favoriten, angehefteten Regionen, Schnellregionen, der Wechselverlauf und Ihre Einstellungen werden **auf Ihrem Gerät gespeichert**; die optionale **iCloud-Synchronisierung** kann sie über **iCloud** auf Ihren Geräten abgeglichen halten.

## Datenerhebung

Wir betreiben kein Backend, das Ihre personenbezogenen Informationen erhebt. Im Einzelnen:

- **Kein Konto** — Keine Registrierung, keine E-Mail-Adresse und keine Telefonnummer erforderlich.
- **Keine Analyse oder Werbung** — Es sind keine Analyse-, Werbe- oder Tracking-Tools von Drittanbietern eingebunden.
- **Keine Zugangsdaten** — iStore verarbeitet niemals Ihre Apple-ID oder Ihr Passwort; der Wechsel findet auf Apples eigenen Bildschirmen statt.

## Wie die App funktioniert

- **Das Wechseln der Region** öffnet Apples offiziellen App-Store-Weiterleitungslink; der App Store übernimmt die Bestätigung.
- **Verfügbarkeitsprüfungen** nutzen Apples **öffentliche iTunes-Lookup-API**, um zu sehen, wo eine App verfügbar ist. Nur der von Ihnen eingegebene App-Link bzw. die App-ID wird an Apples öffentlichen Endpunkt gesendet; es wird keine persönliche Kennung angehängt.
- Regionsflaggen, Namen und Kartenkoordinaten sind **in die App integriert** und erfordern keine Netzwerkanfrage.

## Auf Ihrem Gerät gespeicherte Daten

| Daten | Speicherort | Zweck |
|------|------------------|---------|
| Favoriten | Auf Ihrem Gerät; optional **iCloud** | Regionen, die Sie mit einem Stern markieren |
| Angeheftete Regionen | Auf Ihrem Gerät; optional **iCloud** | Regionen, die ganz oben bleiben (Teilmenge der Favoriten) |
| Schnellregionen | Auf Ihrem Gerät; optional **iCloud** | Regionen für die Store-Gruppe „Beliebt“, Widgets und Schnellaktionen |
| Wechselverlauf | Auf Ihrem Gerät; optional **iCloud** | Letzte Wechsel (bis zu 30) |
| Zuletzt gewechselte Region | Auf Ihrem Gerät; optional **iCloud** | Für das Steuerelement und Widget „Zuletzt wechseln“ |
| Zwischengespeicherte Storefront-Region | Auf Ihrem Gerät | Ihre tatsächliche App-Store-Region, um „aktuell“ hervorzuheben |
| Darstellung und Sprache | Auf Ihrem Gerät; optional **iCloud** | Hell / Dunkel / System; Sprache; Anzeigemodus der Regionsnamen |
| Store-Layout und Rasterspalten | Auf Ihrem Gerät; optional **iCloud** | Einstellungen für Liste / Raster / Karten |
| Anzeige / Gruppierung / Sortierung der Favoriten | Auf Ihrem Gerät; optional **iCloud** | Einstellungen des Favoriten-Tabs |
| Bestätigung vor dem Wechsel | Auf Ihrem Gerät; optional **iCloud** | Ob vor dem Wechsel bestätigt wird |
| Widget-Einstellungen | Auf Ihrem Gerät; optional **iCloud** | Design folgen, eigene Widget-Regionen |
| Onboarding- und Tipps-Status | Auf Ihrem Gerät | Ob Sie die Willkommensanleitung / Tipps schon gesehen haben |
| Home-Bildschirm-Kurzbefehle | Auf Ihrem Gerät | Regionsplätze für Schnellaktionen |
| Eingeklappte Bereiche | Auf Ihrem Gerät | Welche Store-Bereiche eingeklappt sind |
| iCloud-Synchronisierungsschalter | Auf Ihrem Gerät | Lokale Einstellung zum Aktivieren der Synchronisierung |

## iCloud-Synchronisierung

Die optionale iCloud-Synchronisierung hält Ihre Favoriten, angehefteten Regionen, Schnellregionen, den Wechselverlauf, die zuletzt gewechselte Region sowie Einstellungen zu Darstellung / Layout / Favoriten auf iPhone und iPad abgeglichen, die mit derselben Apple-ID angemeldet sind. Die Daten werden über **Ihr privates iCloud-Konto** (Schlüssel-Wert-Speicher) synchronisiert — nicht über Server von iHTC Studio. Die Synchronisierung lässt sich in den Einstellungen ausschalten.

## Berechtigungen

iStore fordert Berechtigungen nur bei Bedarf an:

| Berechtigung | Zweck |
|------------|---------|
| Netzwerk | Verfügbarkeitsprüfungen (Apples öffentliche Lookup-API) und das Öffnen von Apples App-Store-Weiterleitungslinks |

iStore fordert keinen Zugriff auf Ihre Kontakte, Fotos, Ihren Standort, Ihr Mikrofon oder Ihre Kamera an.

## Datenschutz für Kinder

iStore erhebt wissentlich von niemandem personenbezogene Daten, auch nicht von Kindern unter 13 Jahren. Da iHTC Studio kein Backend zur Datenerhebung betreibt, sind über die Plattformrichtlinien von Apple hinaus keine besonderen Vorkehrungen erforderlich.

## Haftungsausschluss
