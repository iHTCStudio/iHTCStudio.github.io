iHTC Studio（以下「当社」）は、iStore（「爱商店」/「愛商店」とも呼ばれます）を開発しました。このページでは、本アプリのご利用時におけるデータの収集、利用、開示に関する方針を説明します。

## 概要

**iStore はアカウント不要で、iHTC Studio のサーバーに個人データを収集することはありません。** 地域の切り替えには Apple の**公式 App Store リダイレクトリンク**を使用します。iStore がお客様の Apple ID、パスワード、お支払い情報を見たり保存したりすることはありません。お気に入り、ピン留めした地域、クイック地域、切り替え履歴、設定は**端末内に保存**されます。任意の **iCloud 同期**を使うと、**iCloud** を通じて複数の端末間で揃えられます。

## データ収集について

当社は、お客様の個人情報を収集するバックエンドを運用していません。具体的には次のとおりです。

- **アカウントなし** — 登録、メールアドレス、電話番号は不要です。
- **分析や広告なし** — サードパーティの分析、広告、トラッキングツールは組み込まれていません。
- **認証情報なし** — iStore がお客様の Apple ID やパスワードを扱うことはありません。切り替えは Apple 自身の画面で行われます。

## アプリの仕組み

- **地域の切り替え**では Apple の公式 App Store リダイレクトリンクを開き、確認は App Store が行います。
- **アプリの提供状況**の確認には、Apple の**公開 iTunes Lookup API** を使い、アプリがどの地域で提供されているかを調べます。Apple の公開エンドポイントに送信されるのは、入力されたアプリのリンク / ID のみで、個人を特定する識別子は付加されません。
- 地域の国旗、名称、地図の座標は**アプリに組み込まれて**おり、ネットワークリクエストは不要です。

## 端末に保存されるデータ

| データ | 保存場所 | 用途 |
|------|------------------|---------|
| お気に入り | 端末内。任意で **iCloud** | スターを付けた地域 |
| ピン留めした地域 | 端末内。任意で **iCloud** | 常に上部に表示する地域（お気に入りの一部） |
| クイック地域 | 端末内。任意で **iCloud** | ストアの「人気」グループ、ウィジェット、クイックアクション用の地域 |
| 切り替え履歴 | 端末内。任意で **iCloud** | 最近の切り替え（最大 30 件） |
| 最後に切り替えた地域 | 端末内。任意で **iCloud** | 「前回の地域に切り替え」コントロールとウィジェット用 |
| キャッシュされたストアフロントの地域 | 端末内 | 実際の App Store の地域。「現在」を強調表示するため |
| 外観と言語 | 端末内。任意で **iCloud** | ライト / ダーク / システム、言語、地域名の表示モード |
| ストアのレイアウトとグリッド列数 | 端末内。任意で **iCloud** | リスト / グリッド / カードの設定 |
| お気に入りの表示 / グループ / 並べ替え | 端末内。任意で **iCloud** | お気に入りタブの設定 |
| 切り替え前の確認 | 端末内。任意で **iCloud** | 切り替える前に確認するかどうか |
| ウィジェットの設定 | 端末内。任意で **iCloud** | テーマへの追従、ウィジェット用のカスタム地域 |
| オンボーディングとヒントの状態 | 端末内 | ウェルカムガイド / ヒントを表示済みかどうか |
| ホーム画面のショートカット | 端末内 | クイックアクション用の地域スロット |
| 折りたたんだセクション | 端末内 | 折りたたまれているストアのセクション |
| iCloud 同期のスイッチ | 端末内 | 同期を有効にするためのローカル設定 |

## iCloud 同期

任意の iCloud 同期により、同じ Apple ID でサインインしている iPhone と iPad の間で、お気に入り、ピン留めした地域、クイック地域、切り替え履歴、最後に切り替えた地域、外観 / レイアウト / お気に入りの設定を揃えられます。データは iHTC Studio のサーバーではなく、**お客様のプライベートな iCloud アカウント**（キーバリューストア）を通じて同期されます。同期は設定でオフにできます。

## 権限

iStore は、必要なときにのみ権限を要求します。

| 権限 | 目的 |
|------------|---------|
| ネットワーク | アプリの提供状況の確認（Apple の公開 Lookup API）と、Apple の App Store リダイレクトリンクを開くため |

iStore は、連絡先、写真、位置情報、マイク、カメラへのアクセスを要求しません。

## お子様のプライバシー

iStore は、13 歳未満のお子様を含め、誰からも個人データを意図的に収集することはありません。iHTC Studio はデータ収集用のバックエンドを運用していないため、Apple のプラットフォームポリシー以外に特別な措置は必要ありません。

## 免責事項

iStore は **Apple Inc. とは提携していません。** 地域の切り替えには Apple の公式 App Store リダイレクトリンクを使用します。提供状況とストアのルールは最終的に Apple が定めるものです。購入とダウンロードについては、公式の App Store をご確認ください。
