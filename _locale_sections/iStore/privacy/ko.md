iHTC Studio("당사")는 iStore("爱商店" / "愛商店"으로도 알려져 있음)를 만들었습니다. 이 페이지는 앱 사용 시 데이터 수집, 이용 및 공개에 관한 당사의 방침을 설명합니다.

## 요약

**iStore는 계정이 필요 없으며 iHTC Studio 서버에 개인 데이터를 수집하지 않습니다.** 지역 전환은 Apple의 **공식 App Store 리디렉션 링크**를 사용하며, iStore는 Apple ID, 비밀번호, 결제 정보를 보거나 저장하지 않습니다. 즐겨찾기, 고정한 지역, 빠른 지역, 전환 기록, 설정은 **기기에 저장**됩니다. 선택적 **iCloud 동기화**를 켜면 **iCloud**를 통해 여러 기기에서 맞출 수 있습니다.

## 데이터 수집

당사는 개인정보를 수집하는 백엔드를 운영하지 않습니다. 구체적으로 다음과 같습니다.

- **계정 없음** — 가입, 이메일, 전화번호가 필요하지 않습니다.
- **분석·광고 없음** — 서드파티 분석, 광고, 추적 도구가 통합되어 있지 않습니다.
- **인증 정보 없음** — iStore는 Apple ID나 비밀번호를 다루지 않으며, 전환은 Apple의 자체 화면에서 이루어집니다.

## 앱 작동 방식

- **지역 전환**은 Apple의 공식 App Store 리디렉션 링크를 열며, 확인은 App Store가 처리합니다.
- **앱 제공 여부** 확인은 Apple의 **공개 iTunes Lookup API**를 사용해 앱이 어느 지역에서 제공되는지 조회합니다. 입력한 앱 링크/ID만 Apple의 공개 엔드포인트로 전송되며, 개인 식별자는 포함되지 않습니다.
- 지역 국기, 이름, 지도 좌표는 **앱에 내장**되어 있어 네트워크 요청이 필요하지 않습니다.

## 기기에 저장되는 데이터

| 데이터 | 저장 위치 | 용도 |
|------|------------------|---------|
| 즐겨찾기 | 기기 내, 선택적으로 **iCloud** | 별표를 표시한 지역 |
| 고정한 지역 | 기기 내, 선택적으로 **iCloud** | 항상 맨 위에 두는 지역(즐겨찾기의 일부) |
| 빠른 지역 | 기기 내, 선택적으로 **iCloud** | 스토어의 "인기" 그룹, 위젯, 빠른 동작에 쓰이는 지역 |
| 전환 기록 | 기기 내, 선택적으로 **iCloud** | 최근 전환 기록(최대 30개) |
| 마지막으로 전환한 지역 | 기기 내, 선택적으로 **iCloud** | "마지막 지역으로 전환" 컨트롤과 위젯에 사용 |
| 캐시된 스토어프론트 지역 | 기기 내 | 실제 App Store 지역("현재" 강조 표시용) |
| 화면 모드 및 언어 | 기기 내, 선택적으로 **iCloud** | 라이트 / 다크 / 시스템, 언어, 지역 이름 표시 방식 |
| 스토어 레이아웃 및 그리드 열 수 | 기기 내, 선택적으로 **iCloud** | 목록 / 그리드 / 카드 설정 |
| 즐겨찾기 표시 / 그룹 / 정렬 | 기기 내, 선택적으로 **iCloud** | 즐겨찾기 탭 설정 |
| 전환 전 확인 | 기기 내, 선택적으로 **iCloud** | 전환 전에 확인할지 여부 |
| 위젯 설정 | 기기 내, 선택적으로 **iCloud** | 테마 따라가기, 위젯용 사용자 지정 지역 |
| 온보딩 및 팁 상태 | 기기 내 | 시작 가이드 / 팁을 본 적이 있는지 여부 |
| 홈 화면 바로가기 | 기기 내 | 빠른 동작용 지역 슬롯 |
| 접힌 섹션 | 기기 내 | 접혀 있는 스토어 섹션 |
| iCloud 동기화 스위치 | 기기 내 | 동기화를 켜기 위한 로컬 설정 |

## iCloud 동기화

선택적 iCloud 동기화는 같은 Apple ID로 로그인한 iPhone과 iPad 간에 즐겨찾기, 고정한 지역, 빠른 지역, 전환 기록, 마지막으로 전환한 지역, 화면 / 레이아웃 / 즐겨찾기 설정을 맞춰 줍니다. 데이터는 iHTC Studio 서버가 아니라 **개인 iCloud 계정**(키-값 저장소)을 통해 동기화됩니다. 동기화는 설정에서 끌 수 있습니다.

## 권한

iStore는 필요할 때에만 권한을 요청합니다.

| 권한 | 용도 |
|------------|---------|
| 네트워크 | 앱 제공 여부 확인(Apple 공개 Lookup API) 및 Apple App Store 리디렉션 링크 열기 |

iStore는 연락처, 사진, 위치, 마이크, 카메라에 대한 접근을 요청하지 않습니다.

## 아동 개인정보 보호

iStore는 13세 미만 아동을 포함해 누구에게서도 개인 데이터를 의도적으로 수집하지 않습니다. iHTC Studio는 데이터 수집 백엔드를 운영하지 않으므로 Apple의 플랫폼 정책 외에 별도의 조치는 필요하지 않습니다.

## 면책 조항

iStore는 **Apple Inc.와 제휴 관계가 아닙니다.** 지역 전환에는 Apple의 공식 App Store 리디렉션 링크를 사용합니다. 제공 여부와 스토어 규정은 최종적으로 Apple이 정하며, 구매와 다운로드는 공식 App Store를 참고하세요.
