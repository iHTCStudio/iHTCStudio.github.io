iHTC Studio ("เรา") เป็นผู้พัฒนา iStore (หรือที่รู้จักในชื่อ "爱商店" / "愛商店") หน้านี้อธิบายนโยบายของเราเกี่ยวกับการเก็บรวบรวม การใช้ และการเปิดเผยข้อมูลเมื่อคุณใช้แอปของเรา

## สรุป

**iStore ไม่ต้องสมัครบัญชี และไม่เก็บข้อมูลส่วนบุคคลบนเซิร์ฟเวอร์ของ iHTC Studio** การสลับภูมิภาคใช้ **ลิงก์เปลี่ยนเส้นทาง App Store อย่างเป็นทางการ** ของ Apple — iStore ไม่เคยเห็นหรือจัดเก็บ Apple ID รหัสผ่าน หรือข้อมูลการชำระเงินของคุณ รายการโปรด ภูมิภาคที่ปักหมุด ภูมิภาคด่วน ประวัติการสลับ และการตั้งค่าของคุณ **บันทึกไว้บนอุปกรณ์ของคุณ** ส่วน **การซิงค์ iCloud** แบบเลือกใช้ช่วยให้ข้อมูลเหล่านี้ตรงกันในทุกอุปกรณ์ผ่าน **iCloud**

## การเก็บรวบรวมข้อมูล

เราไม่ได้ดำเนินการแบ็กเอนด์ที่เก็บข้อมูลส่วนบุคคลของคุณ โดยเฉพาะอย่างยิ่ง:

- **ไม่มีบัญชี** — ไม่ต้องสมัคร ไม่ต้องใช้อีเมลหรือหมายเลขโทรศัพท์
- **ไม่มีการวิเคราะห์หรือโฆษณา** — ไม่มีเครื่องมือวิเคราะห์ โฆษณา หรือติดตามจากบุคคลที่สามรวมอยู่
- **ไม่มีข้อมูลรับรอง** — iStore ไม่เคยจัดการ Apple ID หรือรหัสผ่านของคุณ การสลับเกิดขึ้นบนหน้าจอของ Apple เอง

## แอปทำงานอย่างไร

- **การสลับภูมิภาค** จะเปิดลิงก์เปลี่ยนเส้นทาง App Store อย่างเป็นทางการของ Apple โดย App Store เป็นผู้จัดการการยืนยัน
- **การตรวจสอบความพร้อมให้บริการของแอป** ใช้ **iTunes Lookup API สาธารณะ** ของ Apple เพื่อดูว่าแอปมีให้บริการในภูมิภาคใดบ้าง จะส่งเฉพาะลิงก์/ID ของแอปที่คุณป้อนไปยังปลายทางสาธารณะของ Apple โดยไม่แนบตัวระบุส่วนบุคคลใด ๆ
- ธงภูมิภาค ชื่อ และพิกัดบนแผนที่ **ฝังอยู่ในแอป** และไม่ต้องส่งคำขอผ่านเครือข่าย

| ภูมิภาคที่ปักหมุด | บนอุปกรณ์ของคุณ และ **iCloud** แบบเลือกใช้ | ภูมิภาคที่อยู่บนสุดเสมอ (เป็นส่วนย่อยของรายการโปรด) |
| ภูมิภาคด่วน | บนอุปกรณ์ของคุณ และ **iCloud** แบบเลือกใช้ | ภูมิภาคสำหรับกลุ่ม "ยอดนิยม" ของร้านค้า วิดเจ็ต และการทำงานด่วน |
| ประวัติการสลับ | บนอุปกรณ์ของคุณ และ **iCloud** แบบเลือกใช้ | การสลับล่าสุด (สูงสุด 30 รายการ) |
| ภูมิภาคที่สลับล่าสุด | บนอุปกรณ์ของคุณ และ **iCloud** แบบเลือกใช้ | ใช้กับตัวควบคุมและวิดเจ็ต "สลับกลับภูมิภาคล่าสุด" |
| ภูมิภาคร้านค้าที่แคชไว้ | บนอุปกรณ์ของคุณ | ภูมิภาค App Store จริงของคุณ เพื่อไฮไลต์ "ปัจจุบัน" |
| รูปลักษณ์และภาษา | บนอุปกรณ์ของคุณ และ **iCloud** แบบเลือกใช้ | สว่าง / มืด / ตามระบบ ภาษา โหมดการแสดงชื่อภูมิภาค |
| เค้าโครงร้านค้าและจำนวนคอลัมน์ตาราง | บนอุปกรณ์ของคุณ และ **iCloud** แบบเลือกใช้ | การตั้งค่ารายการ / ตาราง / การ์ด |
| การแสดง / การจัดกลุ่ม / การเรียงรายการโปรด | บนอุปกรณ์ของคุณ และ **iCloud** แบบเลือกใช้ | การตั้งค่าแท็บรายการโปรด |
| ยืนยันก่อนสลับ | บนอุปกรณ์ของคุณ และ **iCloud** แบบเลือกใช้ | ว่าจะยืนยันก่อนสลับหรือไม่ |
| การตั้งค่าวิดเจ็ต | บนอุปกรณ์ของคุณ และ **iCloud** แบบเลือกใช้ | ตามธีม ภูมิภาคที่กำหนดเองสำหรับวิดเจ็ต |
| สถานะการแนะนำและเคล็ดลับ | บนอุปกรณ์ของคุณ | ว่าคุณเคยดูคู่มือต้อนรับ / เคล็ดลับแล้วหรือไม่ |
| ทางลัดบนหน้าจอหลัก | บนอุปกรณ์ของคุณ | ช่องภูมิภาคสำหรับการทำงานด่วน |
| ส่วนที่ย่อไว้ | บนอุปกรณ์ของคุณ | ส่วนของร้านค้าที่ถูกย่อไว้ |
| สวิตช์ซิงค์ iCloud | บนอุปกรณ์ของคุณ | การตั้งค่าบนเครื่องสำหรับเปิดการซิงค์ |

## การซิงค์ iCloud

การซิงค์ iCloud แบบเลือกใช้ช่วยให้รายการโปรด ภูมิภาคที่ปักหมุด ภูมิภาคด่วน ประวัติการสลับ ภูมิภาคที่สลับล่าสุด และการตั้งค่ารูปลักษณ์ / เค้าโครง / รายการโปรดของคุณตรงกันบน iPhone และ iPad ที่ลงชื่อเข้าใช้ด้วย Apple ID เดียวกัน ข้อมูลจะซิงค์ผ่าน **บัญชี iCloud ส่วนตัวของคุณ** (ที่เก็บข้อมูลคีย์-ค่า) ไม่ใช่เซิร์ฟเวอร์ของ iHTC Studio คุณปิดการซิงค์ได้ในการตั้งค่า

## สิทธิ์การเข้าถึง

iStore ขอสิทธิ์เฉพาะเมื่อจำเป็น:

| สิทธิ์ | วัตถุประสงค์ |
|------------|---------|
| เครือข่าย | การตรวจสอบความพร้อมให้บริการของแอป (Lookup API สาธารณะของ Apple) และการเปิดลิงก์เปลี่ยนเส้นทาง App Store ของ Apple |

iStore ไม่ขอสิทธิ์เข้าถึงรายชื่อติดต่อ รูปภาพ ตำแหน่งที่ตั้ง ไมโครโฟน หรือกล้องของคุณ

## ความเป็นส่วนตัวของเด็ก

iStore ไม่ได้ตั้งใจเก็บข้อมูลส่วนบุคคลจากใครก็ตาม รวมถึงเด็กอายุต่ำกว่า 13 ปี เนื่องจาก iHTC Studio ไม่ได้ดำเนินการแบ็กเอนด์เก็บข้อมูล จึงไม่จำเป็นต้องมีข้อกำหนดพิเศษใด ๆ นอกเหนือจากนโยบายแพลตฟอร์มของ Apple

## ข้อจำกัดความรับผิดชอบ

iStore **ไม่มีความเกี่ยวข้องกับ Apple Inc.** การสลับภูมิภาคใช้ลิงก์เปลี่ยนเส้นทาง App Store อย่างเป็นทางการของ Apple ความพร้อมให้บริการและกฎของร้านค้าเป็นไปตามที่ Apple กำหนดเป็นสำคัญ โปรดดู App Store อย่างเป็นทางการสำหรับการซื้อและการดาวน์โหลด
