iHTC Studio (「私たち」、「私たち」、または「私たちの」) は、iCoder (「iLeetCoder」 / 「愛情算法」 / 「愛算法」とも呼ばれます) を構築しました。このページでは、お客様が当社のアプリを使用する際のデータの収集、使用、開示に関する当社のポリシーについて説明します。

## 概要

**iCoder は個人データを収集、保存、または iHTC Studio のサーバーに送信しません。** すべてのアルゴリズムの問​​題とクイズのコンテンツはデバイスにバンドルされています。コア機能はアカウントを必要とせずにオフラインで動作します。学習データはデバイス上に残ります。オプションの **iCloud Sync** は、Apple ID で Apple の iCloud Key-Value ストレージを使用します。

## データ収集

当社はお客様からデータを収集しません。具体的には:

- **個人情報**は iHTC Studio に送信されません (サーバー上の名前、電子メール、電話番号、アカウントは送信されません)。
- **使用状況分析**やサードパーティからのクラッシュレポート SDK はありません。
- **広告なし** または追跡テクノロジーはありません。

## デバイスに保存されているデータ

次のデータは iCoder によって作成され、ローカルに保存されます (UserDefaults および App Group 共有ストレージ)。

| データ | ストレージ | ユーザーコントロール |
|------|---------|--------------|
| アプリの設定 (テーマ、言語、レイアウト) | ローカル | 設定の変更。アプリ削除でリセット |
| お気に入りと学習状況 | ローカル | アプリで管理;問題ごとのステータスのリセット |
| 最近の閲覧 | ローカル | 「参照」タブまたは「設定」でクリア |
| 毎日のクイズのスコアと誤答ブック | ローカル | 設定で間違った本を消去する |
| ウィジェットの設定 | アプリグループ (ウィジェット拡張機能と共有) | 設定変更（iOS） |

データが iHTC Studio にアップロードされたり、第三者と共有されたりすることはありません。

## オプションの iCloud 同期

If you enable **iCloud Sync** in Settings, favorites, learning status, the wrong-answer book, and daily quiz progress sync across your iPhone, iPad, and Mac devices signed in to the same Apple ID via **iCloud Key-Value storage** (keys such as `iCloud.com.iHTCboy.iLeetCoder.cloudSnapshot.v1`). Data stays in **your private iCloud account** through Apple's infrastructure — not iHTC Studio servers. You can turn sync off anytime; local data remains on each device, and you may optionally remove the copy stored in iCloud.

## 権限

iCoder は、コア機能のためにカメラ、マイク、位置情報、連絡先、または写真ライブラリへのアクセスを必要としません。オンライン コンテンツの表示を選択した場合、ソリューション ページまたは外部リンクを開くとネットワークが使用されます。

## 子供のプライバシー

iCoder は、13 歳未満の子供を含むいかなる人物からも個人データを意図的に収集しません。iHTC Studio はデータ収集バックエンドを運用しないため、Apple のプラットフォーム ポリシーを超える特別な規定は必要ありません。

当社は、このプライバシー ポリシーを随時更新することがあります。変更があった場合は、更新日とともにこのページに掲載されます。このページを定期的に確認することをお勧めします。
