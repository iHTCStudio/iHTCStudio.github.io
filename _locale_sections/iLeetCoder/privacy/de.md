iHTC Studio („wir“, „uns“ oder „unser“) hat iCoder (auch bekannt als „iLeetCoder“ / „爱算法“ / „愛算法“) entwickelt. Auf dieser Seite werden unsere Richtlinien zur Datenerhebung, -nutzung und -offenlegung bei der Nutzung unserer App beschrieben.

## Zusammenfassung

**iCoder erhebt, speichert oder übermittelt keine personenbezogenen Daten an die Server von iHTC Studio.** Alle Algorithmusprobleme und Quizinhalte werden auf Ihrem Gerät gebündelt. Kernfunktionen funktionieren offline, ohne dass ein Konto erforderlich ist. Lerndaten bleiben auf Ihrem Gerät; optional **iCloud Sync** nutzt den iCloud-Schlüsselwertspeicher von Apple unter Ihrer Apple-ID.

## Datenerfassung

Wir erheben keine Daten von Ihnen. Konkret:

- **Keine persönlichen Daten** werden an iHTC Studio gesendet (kein Name, E-Mail, Telefonnummer oder Konto auf unseren Servern).
- **Keine Nutzungsanalysen** oder Absturzberichts-SDKs von Drittanbietern.
- **Keine Werbung** oder Tracking-Technologien.

## Auf Ihrem Gerät gespeicherte Daten

Die folgenden Daten werden von iCoder erstellt und lokal gespeichert (gemeinsamer Speicher von UserDefaults und App Group):

| Daten | Lagerung | Benutzerkontrolle |
|------|---------|--------------|
| App-Einstellungen (Thema, Sprache, Layout) | Lokal | Änderung der Einstellungen; Zurücksetzen durch Löschen der App |
| Favoriten und Lernstatus | Lokal | In der App verwalten; Reset-Status pro Problem |
| Letztes Surfen | Lokal | Löschen Sie die Option auf der Registerkarte „Durchsuchen“ oder in den Einstellungen |
| Tägliche Quizergebnisse und ein Buch mit falschen Antworten | Lokal | Löschen Sie das falsche Buch in den Einstellungen |
| Widget-Einstellungen | App-Gruppe (gemeinsam mit Widget Extension) | Änderung der Einstellungen (iOS) |

Es werden keine Daten auf iHTC Studio hochgeladen oder an Dritte weitergegeben.

## Optionale iCloud-Synchronisierung

If you enable **iCloud Sync** in Settings, favorites, learning status, the wrong-answer book, and daily quiz progress sync across your iPhone, iPad, and Mac devices signed in to the same Apple ID via **iCloud Key-Value storage** (keys such as `iCloud.com.iHTCboy.iLeetCoder.cloudSnapshot.v1`). Data stays in **your private iCloud account** through Apple's infrastructure — not iHTC Studio servers. You can turn sync off anytime; local data remains on each device, and you may optionally remove the copy stored in iCloud.

## Berechtigungen

Für die Kernfunktionen benötigt iCoder keinen Zugriff auf Kamera, Mikrofon, Standort, Kontakte oder Fotobibliothek. Beim Öffnen von Lösungsseiten oder externen Links wird das Netzwerk genutzt, wenn Sie sich für die Anzeige von Online-Inhalten entscheiden.

## Privatsphäre von Kindern

iCoder sammelt wissentlich keine personenbezogenen Daten von irgendjemandem, auch nicht von Kindern unter 13 Jahren. Da iHTC Studio kein Datenerfassungs-Backend betreibt, sind über die Plattformrichtlinien von Apple hinaus keine besonderen Bestimmungen erforderlich.
