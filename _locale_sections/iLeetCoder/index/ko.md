iCoder(이전 iLeetCoder)는 코딩 인터뷰 준비를 위해 설계된 **999 LeetCode 문제**가 포함된 알고리즘 학습 앱입니다. 번호, 태그 또는 회사별로 찾아보세요. 학습 진행 상황을 추적합니다. 매일 퀴즈를 풀어보세요. iPhone, iPad, Mac에서 완전히 오프라인으로 홈 화면과 잠금 화면 위젯을 사용할 수 있습니다.

*참고: 저작권 제한으로 인해 이 앱은 현재 중국 본토에서는 사용할 수 없으며 중국 본토 이외의 지역에서만 제공됩니다.*

## 시작하기

1. iCoder를 열고 **문제** 탭을 탐색하거나 태그 및 회사 기반 교육을 위해 **카테고리**로 전환하세요.
2. 문제를 탭하여 설명을 읽고, 글꼴 크기를 조정하고, **즐겨찾기**를 표시하고, **학습 상태**(학습됨/마스터됨)를 설정하세요.
3. 하루에 10개의 질문을 풀려면 **일일 퀴즈** 탭을 사용하세요. **설정**에서 오답집의 실수를 검토하세요.
4. **설정 → 학습 기록**을 열어 학습했거나 마스터했다고 표시한 모든 문제를 필터로 찾아보세요.
5. 선택적으로 설정에서 **iCloud 동기화**를 활성화하여 즐겨찾기, 학습 상태, 오답 책을 Apple 기기 전체에 걸쳐 동기화할 수 있습니다.
6. 일일 문제, 연속 퀴즈, 즐겨찾기 등을 보려면 홈 화면이나 잠금 화면에 **위젯**을 추가하세요.
7. 키보드가 있는 Mac 또는 iPad에서는 **⌘F**를 사용하여 검색하고 **⌘1–4**를 사용하여 탭을 전환하세요. Mac에서는 **Esc**를 눌러 다른 패널로 이동하기 전에 패널 사이를 뒤로 이동합니다.
8. **`iLeetCoder://`** 딥 링크 또는 홈 화면 빠른 작업을 사용하세요. [URL 체계 참조](url-scheme)를 확인하세요.

## 하이라이트

- **macOS 네이티브** — iOS 16+ 및 macOS 13+용과 동일한 SwiftUI 코드베이스: 메뉴 표시줄 바로가기, 탭 아래 캡슐 검색 표시줄, 드래그 가능/크기 조정 가능한 부동 솔루션 패널, 기본 공유 시트 및 계층적 **Esc** 뒤로 탐색.
- **중국어 번체 콘텐츠** — UI가 중국어 번체로 설정되면 문제 제목, 설명 및 태그가 즉시 변환됩니다. 검색은 단순화된 키워드와 전통적 키워드 모두와 일치합니다.
- **더 스마트한 위젯** — 일일 문제 위젯은 iOS 17 이상에서 난이도/태그 필터를 지원합니다. 회사 스포트라이트 셔플; 개선된 난이도 한눈에 보기 레이아웃; 잠금 화면 액세서리 위젯.
- **SwiftUI 경험** — 새롭게 디자인된 정보 및 위젯 가이드, 공유 가능한 긴 이미지, 글꼴 크기 슬라이더, 지울 수 있는 최근 탐색 및 카테고리 탐색 수정.

## 특징

- **999 알고리즘 문제** — 배열, 문자열, 트리, 그래프, 동적 프로그래밍 등을 다루는 엄선된 LeetCode 문제입니다. 난이도, VIP 및 즐겨찾기 필터가 포함된 목록 또는 그리드 레이아웃입니다.
- **카테고리 및 회사** — 알고리즘 태그 또는 IT 회사 인터뷰 세트를 통해 학습합니다. 목록/그리드 레이아웃은 문제 탭과 일치합니다.
- **강력한 검색** — 번호, 제목, 키워드로 문제를 찾아보세요. 중국어 번체 쿼리는 간체 콘텐츠와 자동으로 일치합니다.
- **학습 진행** — 문제를 학습 또는 마스터로 표시합니다. 문제 탭과 설정 통계에서 학습률과 숙달률을 추적하세요. **학습 기록**에는 학습/마스터 필터에 표시된 모든 문제가 나열되어 있습니다.
- **iCloud 동기화** — 설정의 옵션 토글은 동일한 iCloud 계정에 로그인한 모든 기기에서 즐겨찾기, 학습 상태 및 오답 책을 동기화합니다.
- **일일 퀴즈** — 연속 추적 기능이 포함된 하루 10개의 질문과 문제 세부정보에 연결된 오답 책.
- **스크린샷 및 긴 이미지 공유** — 문제를 메시지, 이메일 또는 스터디 그룹용 이미지로 캡처합니다.
- **솔루션 브라우저** — 앱 내에서 공식 솔루션 페이지를 엽니다(iOS의 Safari 보기, 확대/축소 및 시스템 브라우저 옵션이 있는 Mac의 부동 WebView).
- **15가지 테마 사전 설정** — 맞춤 강조 색상; 밝음, 어두움 또는 시스템 모양; 앱 테마(iOS)를 따르는 선택적 위젯 배경입니다.
- **URL 체계 및 빠른 작업** — `iLeetCoder://` 문제, 퀴즈, 즐겨찾기, 태그 및 회사에 대한 딥 링크; 구성 가능한 홈 화면 단축키(iOS).
- **키보드 단축키** — ⌘F 검색, ⌘1–4 탭 전환; Mac Esc는 글꼴 표시줄 → 공유 → 솔루션 패널 → 뒤로 탐색을 닫습니다.
- **다국어 UI** — 시스템 언어와 무관한 영어, 중국어 간체, 중국어 번체.
- **오프라인** — 모든 문제와 퀴즈 콘텐츠가 로컬로 번들로 제공됩니다. 위젯은 오프라인에서도 작동합니다.
- **광고 없음** — 앱에 광고 팝업이 표시되지 않습니다.

## 위젯

iCoder는 **7개의 홈 화면 위젯**과 **잠금 화면 액세서리**를 제공하여 학습 진행 상황을 한눈에 추적할 수 있습니다. 전체 그림 가이드는 앱의 **설정 → 위젯 → 사용 방법**을 참조하세요.

### 추가하는 방법

1. 홈 화면(또는 잠금 화면)을 길게 눌러 편집 모드로 들어갑니다.
2. **+**를 탭하고 'iCoder'를 검색하세요.
3. 위젯과 크기를 선택한 후 **위젯 추가**를 탭하세요.
4. iOS 17 이상에서는 **Daily Problem** 위젯을 편집하여 난이도와 태그별로 필터링하세요.

### 사용 가능한 위젯

| 위젯 | 설명 | 크기 |
|--------|-------------|------|
| 일일 문제 | 매일 추천되는 문제입니다. iOS 17+: 난이도/태그별로 필터링합니다. **⇄**을 탭하여 셔플하세요. | 소형, 중형 |
| 회사 스포트라이트 | 주요 회사와 샘플 인터뷰 질문 **↻**를 탭하여 셔플하세요(iOS 17 이상). | 소형, 중형 |
| 난이도 살펴보기 | 색상 막대(작음) 또는 행 세부 정보(중간)를 사용하여 간편/중간/하드 배포입니다. | 소형, 중형 |
| 퀴즈 한눈에 | 오늘의 퀴즈 점수, 완료 상태, 연속 기록입니다. | 작은 |
| 즐겨찾기 한눈에 보기 | 즐겨찾기 최대 3개와 총 개수. | 소형, 중형 |
| 잘못된 책 살펴보기 | 최근 오답 및 횟수입니다. | 소형, 중형 |
| 학습 진행 | 학습 및 숙달 횟수는 백분율로 표시됩니다. | 소형, 중형 |
| 잠금 화면 | 컴팩트한 일일 문제, 퀴즈, 즐겨찾기 또는 잘못된 책 요약. | 잠금 화면 |

문제 세부 정보, 퀴즈, 즐겨찾기, 잘못된 책 또는 회사 카테고리에 대한 위젯 딥 링크입니다. 앱과 일치하는 그라데이션에 대해 설정(iOS)에서 **위젯 배경이 테마를 따릅니다**를 활성화합니다.
