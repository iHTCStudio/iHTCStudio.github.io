iCoder (ก่อนหน้านี้คือ iLeetCoder) เป็นแอปการเรียนรู้อัลกอริทึมที่มีปัญหา **999 LeetCode** ออกแบบมาเพื่อการเตรียมการสัมภาษณ์ด้วยการเข้ารหัส เรียกดูตามหมายเลข แท็ก หรือบริษัท ติดตามความก้าวหน้าในการเรียนรู้ ทำแบบทดสอบรายวัน และใช้วิดเจ็ตบนหน้าจอหลักและหน้าจอล็อค — ออฟไลน์โดยสมบูรณ์บน iPhone, iPad และ Mac

*หมายเหตุ: เนื่องจากข้อจำกัดด้านลิขสิทธิ์ ปัจจุบันแอปนี้ยังไม่พร้อมให้บริการในจีนแผ่นดินใหญ่ และมีให้บริการในภูมิภาคนอกจีนแผ่นดินใหญ่เท่านั้น*

## เริ่มต้นใช้งาน

1. เปิด iCoder และเรียกดูแท็บ **ปัญหา** หรือสลับไปที่ **หมวดหมู่** สำหรับการฝึกอบรมตามแท็กและบริษัท
2. แตะปัญหาใดก็ได้เพื่ออ่านคำอธิบาย ปรับขนาดตัวอักษร ทำเครื่องหมาย **รายการโปรด** และตั้งค่า **สถานะการเรียนรู้** (เรียนรู้แล้ว / เชี่ยวชาญแล้ว)
3. ใช้แท็บ **แบบทดสอบรายวัน** สำหรับคำถาม 10 ข้อต่อวัน ตรวจสอบข้อผิดพลาดในหนังสือที่ตอบผิดใต้ **การตั้งค่า**
4. เปิด **การตั้งค่า → บันทึกการเรียนรู้** เพื่อเรียกดูทุกปัญหาที่คุณทำเครื่องหมายว่าเรียนรู้หรือเชี่ยวชาญแล้ว พร้อมตัวกรอง
5. เลือกเปิดใช้งาน **iCloud Sync** ในการตั้งค่าเพื่อเก็บรายการโปรด สถานะการเรียนรู้ และหนังสือที่ตอบผิดให้ซิงค์กับอุปกรณ์ Apple ของคุณ
6. เพิ่ม **วิดเจ็ต** ลงในหน้าจอหลักหรือหน้าจอล็อกสำหรับปัญหาประจำวัน แนวข้อสอบ รายการโปรด และอื่นๆ อีกมากมาย
7. บน Mac หรือ iPad ที่มีแป้นพิมพ์ ให้ใช้ **⌘F** เพื่อค้นหา และใช้ **⌘1–4** เพื่อสลับแท็บ บน Mac **Esc** จะย้อนกลับไปตามแผงต่างๆ ก่อนออกเดินทาง
8. ใช้ **`iLeetCoder://`** ลิงก์ในรายละเอียดหรือการดำเนินการด่วนบนหน้าจอหลัก — ดู [การอ้างอิงโครงร่าง URL](url-scheme)

## ไฮไลท์

- **macOS Native** — โค้ดเบส SwiftUI เดียวกันสำหรับ iOS 16+ และ macOS 13+: ทางลัดแถบเมนู แถบค้นหาแคปซูลใต้แท็บ แผงโซลูชันแบบลอยที่ลากได้/ปรับขนาดได้ แผ่นแบ่งปันดั้งเดิม และการนำทางด้านหลัง **Esc** แบบลำดับชั้น
- **เนื้อหาภาษาจีนตัวเต็ม** — เมื่อ UI ถูกตั้งค่าเป็นภาษาจีนตัวเต็ม ชื่อปัญหา คำอธิบาย และแท็กจะถูกแปลงทันที การค้นหาตรงกับคำหลักทั้งแบบง่ายและแบบดั้งเดิม
- **วิดเจ็ตที่ชาญฉลาดยิ่งขึ้น** — วิดเจ็ตปัญหารายวันรองรับตัวกรองความยาก/แท็กบน iOS 17+; สุ่มสปอตไลท์ของบริษัท; ปรับปรุงเค้าโครงความยากโดยสรุป; วิดเจ็ตอุปกรณ์เสริมล็อคหน้าจอ
- **ประสบการณ์ SwiftUI** — เกี่ยวกับและคำแนะนำวิดเจ็ตที่ออกแบบใหม่ รูปภาพขนาดยาวที่แชร์ได้ แถบเลื่อนขนาดตัวอักษร การเรียกดูล่าสุดที่ชัดเจน และการแก้ไขการนำทางหมวดหมู่

## คุณสมบัติ

- **ปัญหาอัลกอริธึม 999 ข้อ** — ปัญหา LeetCode ที่คัดสรรแล้วครอบคลุมอาร์เรย์ สตริง ต้นไม้ กราฟ การเขียนโปรแกรมไดนามิก และอื่นๆ รายการหรือเค้าโครงตารางที่มีความยากระดับ VIP และตัวกรองรายการโปรด
- **หมวดหมู่และบริษัท** — ฝึกอบรมโดยใช้แท็กอัลกอริธึมหรือชุดสัมภาษณ์บริษัทไอที เค้าโครงรายการ/กริดตรงกับแท็บปัญหา
- **การค้นหาที่ทรงพลัง** — ค้นหาปัญหาตามหมายเลข ชื่อ หรือคำสำคัญ ข้อความค้นหาภาษาจีนตัวเต็มจะจับคู่เนื้อหาตัวย่อโดยอัตโนมัติ
- **ความก้าวหน้าในการเรียนรู้** — ทำเครื่องหมายปัญหาว่าเรียนรู้แล้วหรือเชี่ยวชาญแล้ว ติดตามอัตราการเรียนรู้และความเชี่ยวชาญจากแท็บปัญหาและสถิติการตั้งค่า **บันทึกการเรียนรู้** แสดงรายการปัญหาที่ทำเครื่องหมายไว้ทุกประการด้วยตัวกรองการเรียนรู้/การเรียนรู้ที่เชี่ยวชาญ
- **iCloud Sync** — ตัวเลือกสลับในการตั้งค่าจะซิงค์รายการโปรด สถานะการเรียนรู้ และหนังสือที่ตอบผิดบนอุปกรณ์ต่างๆ ที่ลงชื่อเข้าใช้บัญชี iCloud เดียวกัน
- **แบบทดสอบรายวัน** — 10 คำถามต่อวันพร้อมการติดตามต่อเนื่องและหนังสือคำตอบผิดที่เชื่อมโยงกับรายละเอียดของปัญหา
- **ภาพหน้าจอและการแชร์ภาพขนาดยาว** — จับภาพปัญหาเป็นรูปภาพสำหรับข้อความ อีเมล หรือกลุ่มการศึกษา
- **เบราว์เซอร์โซลูชัน** — เปิดหน้าโซลูชันอย่างเป็นทางการในแอป (มุมมอง Safari บน iOS; WebView แบบลอยบน Mac พร้อมตัวเลือกการซูมและเบราว์เซอร์ระบบ)
- **ตั้งค่าธีมล่วงหน้า 15 แบบ** — สีเฉพาะจุดที่กำหนดเอง ลักษณะสว่าง มืด หรือระบบ พื้นหลังวิดเจ็ตเสริมที่เป็นไปตามธีมแอพ (iOS)
- **โครงร่าง URL และการดำเนินการด่วน** — `iLeetCoder://` ลิงก์ในรายละเอียดสำหรับปัญหา แบบทดสอบ รายการโปรด แท็ก และบริษัท ทางลัดหน้าจอหลักที่กำหนดค่าได้ (iOS)
- **แป้นพิมพ์ลัด** — ⌘F ค้นหา ⌘1–4 สลับแท็บ; Mac Esc ปิดแถบแบบอักษร → แบ่งปัน → แผงโซลูชัน → การนำทางย้อนกลับ
- **UI หลายภาษา** — อังกฤษ จีนตัวย่อ และจีนตัวเต็ม โดยไม่ขึ้นอยู่กับภาษาของระบบ
- **ออฟไลน์** — เนื้อหาปัญหาและแบบทดสอบทั้งหมดรวมอยู่ในเครื่องแล้ว วิดเจ็ตทำงานแบบออฟไลน์ได้เช่นกัน
- **ไม่มีโฆษณา** — แอปไม่เคยแสดงป๊อปอัปโฆษณา

## วิดเจ็ต

iCoder มี **วิดเจ็ตบนหน้าจอหลัก 7 รายการ** และ **อุปกรณ์เสริมหน้าจอล็อค** เพื่อติดตามความคืบหน้าในการเรียนของคุณได้อย่างรวดเร็ว ดู **การตั้งค่า → วิดเจ็ต → วิธีใช้งาน** ในแอปเพื่อดูคำแนะนำที่มีภาพประกอบทั้งหมด

### วิธีการเพิ่ม

1. กดหน้าจอหลักของคุณค้างไว้ (หรือหน้าจอล็อค) เพื่อเข้าสู่โหมดแก้ไข
2. แตะ **+** และค้นหา "iCoder"
3. เลือกวิดเจ็ต เลือกขนาด แล้วแตะ **เพิ่มวิดเจ็ต**
4. บน iOS 17+ ให้แก้ไขวิดเจ็ต **ปัญหารายวัน** เพื่อกรองตามความยากและแท็ก

### วิดเจ็ตที่ใช้ได้

| วิดเจ็ต | คำอธิบาย | ขนาด |
|--------|-------------|------|
| ปัญหารายวัน | ปัญหาเด่นในแต่ละวัน iOS 17+: กรองตามความยาก/แท็ก แตะ **⇄** เพื่อสุ่ม | เล็ก, กลาง |
| จุดเด่นของบริษัท | บริษัทเด่นพร้อมตัวอย่างคำถามสัมภาษณ์ แตะ **↻** เพื่อสุ่ม (iOS 17+) | เล็ก, กลาง |
| ภาพรวมความยากลำบาก | การกระจายแบบง่าย / ปานกลาง / ยากพร้อมแถบสี (เล็ก) หรือรายละเอียดแถว (กลาง) | เล็ก, กลาง |
| แบบทดสอบโดยสรุป | คะแนนแบบทดสอบวันนี้ สถานะการสำเร็จหลักสูตร และสถิติต่อเนื่อง | เล็ก |
| ภาพรวมรายการโปรด | มากถึงสามรายการโปรดบวกจำนวนทั้งหมด | เล็ก, กลาง |
| ภาพรวมหนังสือผิด | คำตอบที่ผิดและการนับล่าสุด | เล็ก, กลาง |
| ความก้าวหน้าการเรียนรู้ | เรียนรู้และเชี่ยวชาญนับด้วยเปอร์เซ็นต์ | เล็ก, กลาง |
| ล็อคหน้าจอ | ปัญหาประจำวันแบบกระชับ แบบทดสอบ รายการโปรด หรือสรุปเล่มผิด | ล็อคหน้าจอ |

วิดเจ็ตเชื่อมโยงในรายละเอียดปัญหา แบบทดสอบ รายการโปรด หนังสือผิด หรือหมวดหมู่ของบริษัท เปิดใช้งาน **พื้นหลังวิดเจ็ตตามธีม** ในการตั้งค่า (iOS) เพื่อการไล่ระดับสีที่ตรงกับแอป
