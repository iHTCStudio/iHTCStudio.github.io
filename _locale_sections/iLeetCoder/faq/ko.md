### 특정 문제를 검색하려면 어떻게 해야 합니까?

**문제** 탭의 검색 창(또는 Mac의 경우 탭 아래 캡슐 검색 창)을 사용하세요. 문제번호, 제목, 키워드로 검색하실 수 있습니다. UI가 중국어 번체로 설정된 경우 쿼리는 번들 문제 라이브러리의 간체 콘텐츠도 일치합니다.

### 문제를 학습 또는 숙달한 것으로 표시하려면 어떻게 해야 합니까?

문제의 세부정보 페이지를 열고 툴바의 **학습 상태** 메뉴를 사용하세요. **학습함** 또는 **통달함**을 선택하세요. 목록 보기에서 행을 스와이프하여 문제를 **미학습**으로 재설정합니다. 학습 통계(학습/마스터 횟수 및 속도)는 **설정** 및 **학습 진행 상황** 위젯에 표시됩니다. **설정 → 학습 기록**에는 학습/마스터 필터로 표시된 모든 문제가 나열됩니다.

### iCloud 동기화는 어떻게 작동하나요?

**설정 → iCloud 동기화**로 이동하여 토글을 켭니다. 즐겨찾기, 학습 상태, 오답 도서는 동일한 iCloud 계정에 로그인한 iPhone, iPad, Mac 기기에서 동기화됩니다. 동기화를 끄면 데이터가 기기에 유지됩니다. 선택적으로 iCloud에 저장된 복사본을 제거할 수 있습니다.

### 일일 퀴즈는 어떻게 진행되나요?

**일일 퀴즈** 탭을 엽니다. 매일 **10개의 질문**을 받습니다. 최고 점수와 완료 상태는 로컬에 저장됩니다. 오답은 **설정**에서 열 수 있는 오답 책에 추가됩니다. 퀴즈 연속은 퀴즈 탭과 **퀴즈 한눈에 보기** 위젯에 나타납니다.

### 문제의 해결책을 어떻게 봅니까?

문제를 탭하여 세부 정보 페이지를 연 다음 도구 모음에서 솔루션 링크를 엽니다. **iOS**에서는 솔루션이 앱 내 Safari 보기에서 열립니다. **Mac**에서는 오른쪽 하단에 있는 **플로팅 패널**에서 열립니다. 드래그하여 이동하고, 제목 표시줄 버튼을 사용하여 확대/축소하거나 시스템 브라우저에서 엽니다.

### 문제 스크린샷이나 긴 이미지를 공유하려면 어떻게 해야 하나요?

문제를 열고 툴바에서 **공유** 작업을 사용하세요. 문제를 이미지(스크롤 가능한 긴 이미지 포함)로 캡처하여 메시지, 이메일 또는 공유 채널을 통해 보낼 수 있습니다.

### iCoder를 오프라인으로 사용할 수 있나요?

예. 모든 **999** 문제, 일일 퀴즈, 즐겨찾기, 학습 진행 상황 및 위젯은 **완전히 오프라인**으로 작동합니다. 핵심 기능에는 인터넷 연결이 필요하지 않습니다. 솔루션 페이지나 외부 링크를 열려면 당연히 네트워크 연결이 필요합니다.

### 어떤 키보드 단축키를 사용할 수 있나요?

| 바로가기 | 액션 |
|----------|--------|
| ⌘F | **문제** 탭을 열고 검색에 집중하세요. |
| ⌘1 | **문제** 탭 |
| ⌘2 | **카테고리** 탭 |
| ⌘3 | **일일 퀴즈** 탭 |
| ⌘4 | **설정** 탭 |
| Esc(맥) | 글꼴 크기 막대 닫기 → 시트 공유 → 솔루션 패널 → 뒤로 탐색(현재 탭만) |

Mac에서는 **⌘F**를 누르면 탭 아래의 캡슐 검색 표시줄이 확장됩니다. **Esc**를 눌러 접으세요.

### iCoder는 어떤 플랫폼을 지원합니까?

iCoder는 기본적으로 단일 SwiftUI 코드베이스를 통해 **iPhone**, **iPad** 및 **Mac**에서 실행됩니다. 위젯은 **iOS에서만 사용할 수 있습니다**(Mac에서는 사용할 수 없음). 최소 버전: iOS 16.0+, macOS 13.0+. 일부 위젯 기능(일일 문제 필터, 셔플 버튼)에는 **iOS 17+**이 필요합니다.

### 앱 언어를 어떻게 전환하나요?

**설정**으로 이동하여 언어를 변경하세요. 장치의 시스템 언어에 관계없이 영어, 중국어 간체 또는 중국어 번체를 선택할 수 있습니다. 중국어 번체는 간체 번들 데이터에서 문제 콘텐츠를 즉시 변환합니다.

### 위젯을 어떻게 추가하고 구성하나요?

홈 화면을 길게 누르기 → **+** → "iCoder"를 검색하세요. 단계별 지침, 잠금 화면 팁 및 확장 가능한 위젯 카탈로그를 보려면 앱 내에서 **설정 → 위젯 → 사용 방법**을 엽니다.

**iOS 17+**에서는 **Daily Problem** 위젯 → **Edit Widget**을 길게 눌러 난이도와 태그별로 필터링하세요. 다른 매칭 문제를 섞으려면 위젯에서 **⇄**를 탭하세요.

### iCoder는 어디서 다운로드할 수 있나요?

iCoder는 iPhone, iPad, Mac용 [App Store](https://apps.apple.com/app/id1458259471)에서 다운로드할 수 있습니다.
