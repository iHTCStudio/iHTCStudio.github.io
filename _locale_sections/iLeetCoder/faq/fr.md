### Comment rechercher un problème spécifique ?

Utilisez la barre de recherche sur l'onglet **Problèmes** (ou la barre de recherche de capsule sous l'onglet sur Mac). Vous pouvez effectuer une recherche par numéro de problème, titre ou mot-clé. Lorsque l’interface utilisateur est définie sur Chinois traditionnel, les requêtes correspondent également au contenu simplifié de la bibliothèque de problèmes groupée.

### Comment marquer un problème comme appris ou maîtrisé ?

Ouvrez la page de détails d'un problème et utilisez le menu **Statut d'apprentissage** dans la barre d'outils. Choisissez **Appris** ou **Maîtrisé**. Dans la vue Liste, faites glisser une ligne pour réinitialiser un problème sur **Non appris**. Les statistiques d'apprentissage (nombres et taux appris/maîtrisés) apparaissent dans **Paramètres** et sur le widget **Progression de l'apprentissage**. **Paramètres → Learning Records** répertorie tous les problèmes marqués avec les filtres appris/maîtrisés.

### Comment fonctionne la synchronisation iCloud ?

Accédez à **Paramètres → iCloud Sync** et activez le bouton. Les favoris, l'état d'apprentissage et le carnet de mauvaises réponses sont synchronisés sur les appareils iPhone, iPad et Mac connectés au même compte iCloud. La désactivation de la synchronisation conserve les données sur l'appareil ; vous pouvez éventuellement supprimer la copie stockée dans iCloud.

### Comment fonctionne le quiz quotidien ?

Ouvrez l'onglet **Quiz quotidien**. Chaque jour, vous recevez **10 questions**. Votre meilleur score et votre statut d'achèvement sont enregistrés localement. Les mauvaises réponses sont ajoutées au carnet de mauvaises réponses, que vous pouvez ouvrir depuis **Paramètres**. Les séries de quiz apparaissent dans l'onglet Quiz et sur le widget **Quiz Glance**.

### Comment puis-je visualiser la solution d'un problème ?

Appuyez sur n'importe quel problème pour ouvrir sa page de détails, puis ouvrez le lien de la solution dans la barre d'outils. Sur **iOS**, la solution s'ouvre dans une vue Safari intégrée à l'application. Sur **Mac**, il s'ouvre dans un **panneau flottant** en bas à droite : faites glisser pour le déplacer, utilisez les boutons de la barre de titre pour effectuer un zoom avant/arrière ou ouvrez-le dans le navigateur de votre système.

### Comment partager une capture d'écran problématique ou une image longue ?

Ouvrez n'importe quel problème et utilisez l'action **Partager** dans la barre d'outils. Vous pouvez capturer le problème sous forme d'image (y compris une longue image défilante) et l'envoyer via Messages, e-mail ou tout autre canal de partage.

### Puis-je utiliser iCoder hors ligne ?

Oui. Tous les **999** problèmes, le quiz quotidien, les favoris, les progrès d'apprentissage et les widgets fonctionnent **complètement hors ligne**. Aucune connexion Internet n'est requise pour les fonctionnalités de base. L’ouverture de pages de solution ou de liens externes nécessite naturellement une connexion réseau.

### Quels raccourcis clavier sont disponibles ?

| Raccourci | Action |
|----------|--------|
| ⌘F | Ouvrez l'onglet **Problèmes** et concentrez-vous sur la recherche. |
| ⌘1 | Onglet **Problèmes** |
| ⌘2 | Onglet **Catégories** |
| ⌘3 | Onglet **Quiz quotidien** |
| ⌘4 | Onglet **Paramètres** |
| Échap (Mac) | Fermer la barre de taille de police → partager la feuille → panneau de solution → revenir en arrière (onglet actuel uniquement) |

Sur Mac, **⌘F** développe la barre de recherche de capsules sous l'onglet ; appuyez sur **Esc** pour le réduire.

### Quelles plateformes iCoder prend-il en charge ?

iCoder fonctionne nativement sur **iPhone**, **iPad** et **Mac** à partir d'une seule base de code SwiftUI. Les widgets sont disponibles sur **iOS uniquement** (pas sur Mac). Versions minimales : iOS 16.0+, macOS 13.0+. Certaines fonctionnalités du widget (filtres Problèmes quotidiens, boutons de lecture aléatoire) nécessitent **iOS 17+**.

### Comment changer la langue de l'application ?

Accédez à **Paramètres** et changez la langue. Vous pouvez choisir l'anglais, le chinois simplifié ou le chinois traditionnel quelle que soit la langue du système de votre appareil. Le chinois traditionnel convertit le contenu problématique à la volée à partir des données groupées simplifiées.

### Comment ajouter et configurer des widgets ?

Appuyez longuement sur l'écran d'accueil → **+** → recherchez « iCoder ». Pour obtenir des instructions étape par étape, des conseils sur l'écran de verrouillage et un catalogue de widgets extensible, ouvrez **Paramètres → Widgets → Comment utiliser** dans l'application.

Sur **iOS 17+**, appuyez longuement sur le widget **Problème quotidien** → **Modifier le widget** pour filtrer par difficulté et par balises. Appuyez sur **⇄** sur le widget pour passer à un autre problème correspondant.
