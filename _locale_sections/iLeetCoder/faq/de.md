### Wie suche ich nach einem bestimmten Problem?

Use the search bar on the **Problems** tab (or the capsule search bar below the tab on Mac). Sie können nach Problemnummer, Titel oder Schlüsselwort suchen. When the UI is set to Traditional Chinese, queries also match Simplified content in the bundled problem library.

### Wie markiere ich ein Problem als gelernt oder gemeistert?

Open a problem's detail page and use the **Learning Status** menu in the toolbar. Wählen Sie **Gelernt** oder **Beherrscht**. In list view, swipe a row to reset a problem to **Unlearned**. Learning stats (learned / mastered counts and rates) appear in **Settings** and on the **Learning Progress** widget. **Einstellungen → Lernaufzeichnungen** listet jedes markierte Problem mit erlernten/beherrschten Filtern auf.

### Wie funktioniert die iCloud-Synchronisierung?

Go to **Settings → iCloud Sync** and turn the toggle on. Favorites, learning status, and the wrong-answer book sync across iPhone, iPad, and Mac devices signed in to the same iCloud account. Wenn Sie die Synchronisierung deaktivieren, bleiben die Daten auf dem Gerät. you can optionally remove the copy stored in iCloud.

### Wie funktioniert das tägliche Quiz?

Open the **Daily Quiz** tab. Each day you get **10 questions**. Your best score and completion status are saved locally. Wrong answers are added to the wrong-answer book, which you can open from **Settings**. Quiz streaks appear in the Quiz tab and on the **Quiz Glance** widget.

### Wie kann ich die Lösung eines Problems einsehen?

Tippen Sie auf ein Problem, um dessen Detailseite zu öffnen, und öffnen Sie dann den Lösungslink in der Symbolleiste. On **iOS**, the solution opens in an in-app Safari view. Auf **Mac** öffnet es sich in einem **schwebenden Bereich** unten rechts – ziehen Sie es zum Verschieben, verwenden Sie die Schaltflächen in der Titelleiste zum Vergrößern/Verkleinern oder öffnen Sie es in Ihrem Systembrowser.

### How do I share a problem screenshot or long image?

Open any problem and use the **Share** action in the toolbar. Sie können das Problem als Bild (einschließlich eines scrollbaren langen Bildes) erfassen und es per Nachricht, E-Mail oder über einen beliebigen Freigabekanal senden.

### Kann ich iCoder offline verwenden?

Ja. All **999** problems, the daily quiz, favorites, learning progress, and widgets work **completely offline**. Für die Kernfunktionen ist keine Internetverbindung erforderlich. Das Öffnen von Lösungsseiten oder externen Links erfordert natürlich eine Netzwerkverbindung.

### Welche Tastaturkürzel sind verfügbar?

| Abkürzung | Aktion |
|----------|--------|
| ⌘F | Öffnen Sie die Registerkarte **Probleme** und konzentrieren Sie sich auf die Suche |
| ⌘1 | Registerkarte **Probleme** |
| ⌘2 | Registerkarte **Kategorien** |
| ⌘3 | Registerkarte **Tägliches Quiz** |
| ⌘4 | Registerkarte **Einstellungen** |
| Esc (Mac) | Schriftgrößenleiste schließen → Blatt teilen → Lösungsbereich → zurück navigieren (nur aktuelle Registerkarte) |

Auf dem Mac erweitert **⌘F** die Kapselsuchleiste unter der Registerkarte; Drücken Sie **Esc**, um es zu reduzieren.

### Welche Plattformen unterstützt iCoder?

iCoder läuft nativ auf **iPhone**, **iPad** und **Mac** über eine einzige SwiftUI-Codebasis. Widgets sind nur auf **iOS** verfügbar (nicht auf Mac). Mindestversionen: iOS 16.0+, macOS 13.0+. Für einige Widget-Funktionen (Tägliche Problemfilter, Zufallsschaltflächen) ist **iOS 17+** erforderlich.

### Wie ändere ich die App-Sprache?

Gehen Sie zu **Einstellungen** und ändern Sie die Sprache. Sie können unabhängig von der Systemsprache Ihres Geräts Englisch, vereinfachtes Chinesisch oder traditionelles Chinesisch wählen. Traditionelles Chinesisch konvertiert problematische Inhalte im Handumdrehen aus den vereinfachten gebündelten Daten.

### Wie füge und konfiguriere ich Widgets?

Drücken Sie lange auf den Startbildschirm → ***+** → suchen Sie nach „iCoder“. Für Schritt-für-Schritt-Anleitungen, Tipps zum Sperrbildschirm und einen erweiterbaren Widget-Katalog öffnen Sie **Einstellungen → Widgets → Verwendung** in der App.

Drücken Sie unter **iOS 17+** lange auf das Widget **Tägliches Problem** → **Widget bearbeiten**, um nach Schwierigkeitsgrad und Tags zu filtern. Tippen Sie im Widget auf **⇄**, um zu einem anderen Zuordnungsproblem zu wechseln.
