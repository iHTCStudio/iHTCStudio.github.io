### ฉันจะค้นหาปัญหาเฉพาะได้อย่างไร

ใช้แถบค้นหาบนแท็บ **ปัญหา** (หรือแถบค้นหาแคปซูลด้านล่างแท็บบน Mac) คุณสามารถค้นหาด้วยหมายเลขปัญหา ชื่อเรื่อง หรือคำสำคัญ เมื่อตั้งค่า UI เป็นภาษาจีนตัวเต็ม แบบสอบถามยังตรงกับเนื้อหาแบบย่อในไลบรารีปัญหาแบบรวม

### ฉันจะทำเครื่องหมายปัญหาว่าเรียนรู้หรือเชี่ยวชาญแล้วได้อย่างไร

เปิดหน้ารายละเอียดของปัญหาและใช้เมนู **สถานะการเรียนรู้** ในแถบเครื่องมือ เลือก **เรียนรู้แล้ว** หรือ **เชี่ยวชาญ** ในมุมมองรายการ ให้ปัดแถวเพื่อรีเซ็ตปัญหาเป็น **ไม่ได้เรียนรู้** สถิติการเรียนรู้ (จำนวนและอัตราการเรียนรู้ / เชี่ยวชาญ) ปรากฏใน **การตั้งค่า** และบนวิดเจ็ต **ความก้าวหน้าการเรียนรู้** **การตั้งค่า → บันทึกการเรียนรู้** แสดงรายการปัญหาที่ทำเครื่องหมายไว้ทั้งหมดพร้อมตัวกรองการเรียนรู้/การเรียนรู้ที่เชี่ยวชาญ

### การซิงค์ iCloud ทำงานอย่างไร

ไปที่ **การตั้งค่า → iCloud Sync** และเปิดสวิตช์ รายการโปรด สถานะการเรียนรู้ และหนังสือที่ตอบผิดจะซิงค์กับอุปกรณ์ iPhone, iPad และ Mac ที่ลงชื่อเข้าใช้บัญชี iCloud เดียวกัน การปิดการซิงค์จะเก็บข้อมูลไว้ในอุปกรณ์ คุณสามารถเลือกลบสำเนาที่จัดเก็บไว้ใน iCloud ได้

### แบบทดสอบรายวันทำงานอย่างไร?

เปิดแท็บ **แบบทดสอบรายวัน** ในแต่ละวันคุณจะได้รับ **10 คำถาม** คะแนนที่ดีที่สุดและสถานะการสำเร็จของคุณจะถูกบันทึกไว้ในเครื่อง คำตอบที่ผิดจะเพิ่มลงในหนังสือที่ตอบผิด ซึ่งคุณเปิดได้จาก **การตั้งค่า** เส้นแบบทดสอบจะปรากฏในแท็บแบบทดสอบและบนวิดเจ็ต **Quiz Glance**

### ฉันจะดูวิธีแก้ไขปัญหาได้อย่างไร

แตะที่ปัญหาใดๆ เพื่อเปิดหน้ารายละเอียด จากนั้นเปิดลิงก์วิธีแก้ปัญหาจากแถบเครื่องมือ บน **iOS** โซลูชันจะเปิดขึ้นในมุมมอง Safari ในแอป บน **Mac** จะเปิดขึ้นใน **แผงลอย** ที่มุมขวาล่าง — ลากเพื่อย้าย ใช้ปุ่มแถบชื่อเรื่องเพื่อซูมเข้า/ออก หรือเปิดในเบราว์เซอร์ระบบของคุณ

### ฉันจะแชร์ภาพหน้าจอที่มีปัญหาหรือรูปภาพขนาดยาวได้อย่างไร

เปิดปัญหาใดๆ และใช้การดำเนินการ **แชร์** ในแถบเครื่องมือ คุณสามารถจับภาพปัญหาเป็นรูปภาพ (รวมถึงรูปภาพขนาดยาวแบบเลื่อนได้) และส่งผ่านข้อความ อีเมล หรือช่องทางการแชร์ใดๆ

### ฉันสามารถใช้ iCoder ออฟไลน์ได้หรือไม่

ใช่. ปัญหา **999** ทั้งหมด แบบทดสอบรายวัน รายการโปรด ความคืบหน้าในการเรียนรู้ และวิดเจ็ตทำงานได้ **ออฟไลน์โดยสมบูรณ์** ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ตสำหรับคุณสมบัติหลัก การเปิดหน้าโซลูชันหรือลิงก์ภายนอกจำเป็นต้องมีการเชื่อมต่อเครือข่าย

### มีแป้นพิมพ์ลัดอะไรบ้าง?

| ทางลัด | การดำเนินการ |
|----------|--------|
| ⌘F | เปิดแท็บ **ปัญหา** และโฟกัสการค้นหา |
| ⌘1 | **ปัญหา** แท็บ |
| ⌘2 | **หมวดหมู่** แท็บ |
| ⌘3 | แท็บ **แบบทดสอบรายวัน** |
| ⌘4 | **การตั้งค่า** แท็บ |
| Esc (แมค) | ปิดแถบขนาดแบบอักษร → แผ่นแบ่งปัน → แผงโซลูชัน → นำทางกลับ (แท็บปัจจุบันเท่านั้น) |

บน Mac **⌘F** จะขยายแถบค้นหาแคปซูลใต้แท็บ กด **Esc** เพื่อยุบ

### iCoder รองรับแพลตฟอร์มใดบ้าง?

iCoder ทำงานบน **iPhone**, **iPad** และ **Mac** จากโค้ดเบส SwiftUI เดียว วิดเจ็ตใช้งานได้บน **iOS เท่านั้น** (ไม่มีบน Mac) เวอร์ชันขั้นต่ำ: iOS 16.0+, macOS 13.0+ คุณสมบัติวิดเจ็ตบางอย่าง (ตัวกรองปัญหารายวัน ปุ่มสุ่ม) ต้องใช้ **iOS 17+**

### ฉันจะเปลี่ยนภาษาของแอปได้อย่างไร?

ไปที่ **การตั้งค่า** และเปลี่ยนภาษา คุณสามารถเลือกภาษาอังกฤษ จีนตัวย่อ หรือจีนตัวเต็มได้ โดยไม่คำนึงถึงภาษาระบบของอุปกรณ์ของคุณ ภาษาจีนตัวเต็มจะแปลงเนื้อหาปัญหาได้ทันทีจากข้อมูลที่รวมแบบง่าย

### ฉันจะเพิ่มและกำหนดค่าวิดเจ็ตได้อย่างไร?

กดหน้าจอหลักค้างไว้ → **+** → ค้นหา "iCoder" สำหรับคำแนะนำทีละขั้นตอน เคล็ดลับหน้าจอล็อค และแค็ตตาล็อกวิดเจ็ตที่ขยายได้ ให้เปิด **การตั้งค่า → วิดเจ็ต → วิธีใช้งาน** ภายในแอป

บน **iOS 17+** กดวิดเจ็ต **ปัญหารายวัน** ค้างไว้ → **แก้ไขวิดเจ็ต** เพื่อกรองตามความยากและแท็ก แตะ **⇄** บนวิดเจ็ตเพื่อสลับไปยังปัญหาการจับคู่อื่น
