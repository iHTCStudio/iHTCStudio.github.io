Le logiciel iZiSi prend en charge les liens de raccourci ** `izisi://` ** (système URL). Les raccourcis de démarrage à froid et d'écran d'accueil sont livrés via un tampon unifié de sorte que les liens ne sont pas ouverts deux fois après l'embarquement.

## Format de lien


```
izisi://{host}?{params}
```


## Bureau unique

| URL | Ouvre |
|-----|-------|
| `izisi://daily` | Aujourd'hui la pensée |
| `izisi://shendu` / `izisi://vigilance` | Studio de veille |
| `izisi://five-steps` / `izisi://wubu` | Cinq étapes |
| `izisi://wuxing` | Galerie Cinq Conduits |
| `izisi://lineage` | Carte des lignes |
| `izisi://home-quick` | Grille rapide à la maison |
| `izisi://study` | Étude Zisi |
| `izisi://hunt` | Trouver la moyenne |
