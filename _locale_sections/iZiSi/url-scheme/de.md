爱子思 / iZiSi unterstützt ** `izisi://` ** Shortcut Links (URL-Schema). Kaltstart- und Home Screen-Verknüpfungen werden über einen einheitlichen Puffer geliefert, so dass Links nach dem Onboarding nicht zweimal geöffnet werden.

## Linkformat


```
izisi://{host}?{params}
```


## Einzigartiger Schreibtisch

| URL | Öffnet |
|-----|-------|
| `izisi://daily` | Der heutige Gedanke |
| `izisi://shendu` / `izisi://vigilance` | Wachsamkeitsstudio |
| `izisi://five-steps` / `izisi://wubu` | Fünf Schritte |
| `izisi://wuxing` | Fünf Dirigentengalerie |
| `izisi://lineage` | Linienkarte |
| `izisi://home-quick` | Home Schnellnetz |
| `izisi://study` | Zisi-Studie |
| `izisi://hunt` | Finde den Mittelwert |
