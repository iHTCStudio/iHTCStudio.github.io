iZiSiは、** `izisi://` **のショートカットリンク(URLスキーム)をサポートしています。 コールドスタートとホーム画面のショートカットは、統一されたバッファを介して配信されますので、リンクはオンボーディング後2回開いていません。

## リンク形式


```
izisi://{host}?{params}
```


## ユニークなデスク

| URL | 開く画面 |
|-----|-------|
| `izisi://daily` | 今日の想い |
| `izisi://shendu` / `izisi://vigilance` | ウォッチフルネススタジオ |
| `izisi://five-steps` / `izisi://wubu` | 5つのステップ |
| `izisi://wuxing` | 5つの指揮ギャラリー |
| `izisi://lineage` | サイトマップ |
| `izisi://home-quick` | ホーム クイックグリッド |
| `izisi://study` | Zisiスタディ |
| `izisi://hunt` | 意味を見つける |

| URL | 開く画面 |
|-----|-------|
| `izisi://home` | ホーム |
| `izisi://passage?id=` / `izisi://chapter?id=` | 章句の詳細 |
| `izisi://recite` / `izisi://recite?id=` | リサイト |
| `izisi://random` | ランダムな章句 |
| `izisi://favorites` | お気に入り |
| `izisi://search?q=` | 検索 |
| `izisi://famous` | 名句一覧 |
| `izisi://categories` | ブラウズ |
| `izisi://last-read` | 最後に読んだ項目 |
| `izisi://reading-history` | 閲覧履歴 |
| `izisi://notes` | ノート |
| `izisi://handwriting` | 手書き検索(iOS) |
| `izisi://settings` | 設定 |
| `izisi://usage-guide` | 使い方ガイド |
| `izisi://widget-guide` | ウィジェットガイド |
| `izisi://shortcuts-guide` | ショートカットガイド |
| `izisi://feature-guide` | オンボーディングの再生 |
| `izisi://feedback` | フィードバックメール |

## 例


```
izisi://daily
izisi://shendu
izisi://wuxing
izisi://five-steps
```
