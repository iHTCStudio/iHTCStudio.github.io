). / iZiSi поддерживает ярлыки ** `izisi://` ** (схема URL). Холодный старт и ярлыки домашнего экрана доставляются через единый буфер, поэтому ссылки не открываются дважды после входа.

## Формат ссылки


```
izisi://{host}?{params}
```


## Уникальный стол

| URL | Открывает |
|-----|-------|
| `izisi://daily` | Сегодняшняя мысль |
| `izisi://shendu` / `izisi://vigilance` | Студия Watchfully |
| `izisi://five-steps` / `izisi://wubu` | Пять шагов |
| `izisi://wuxing` | Галерея Five Conducts |
| `izisi://lineage` | Линейная карта |
| `izisi://home-quick` | Быстрая сетка |
| `izisi://study` | Исследование Zisi |
| `izisi://hunt` | Найдите смысл |
