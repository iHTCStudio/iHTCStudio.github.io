iZiSi 지원 ** `izisi://` ** 단축 링크 (URL 계획). 콜드 시작 및 홈 화면 단축은 통합 버퍼를 통해 전달되므로 링크가 내장 된 후 두 번 열리지 않습니다.

## 링크 형식


```
izisi://{host}?{params}
```


## 회사 소개

| URL | 열리는 화면 |
|-----|-------|
| `izisi://daily` | 오늘의 생각 |
| `izisi://shendu` / `izisi://vigilance` | 시계 |
| `izisi://five-steps` / `izisi://wubu` | 5 단계 |
| `izisi://wuxing` | 5개의 작품 갤러리 |
| `izisi://lineage` | Lineage 지도 |
| `izisi://home-quick` | 홈 빠른 그리드 |
| `izisi://study` | Zisi 연구 |
| `izisi://hunt` | 자주 묻는 질문 |
