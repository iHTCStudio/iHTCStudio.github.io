iHTC Studio("당사")는 iEnglish("爱英语" / "初学者必备词汇"로도 알려져 있음)를 만들었습니다. 이 페이지는 앱 사용 시 데이터 수집, 이용 및 공개에 관한 당사의 방침을 설명합니다.

## 요약

**iEnglish는 어떤 개인 데이터도 수집, 저장하거나 iHTC Studio 서버로 전송하지 않습니다.** 모든 어휘 데이터, 퀴즈, 재생은 기기에서 이루어집니다. 계정이 필요 없으며, 핵심 기능에는 인터넷 연결이 필요하지 않습니다.

## 데이터 수집

당사는 어떤 데이터도 수집하지 않습니다. 구체적으로 다음과 같습니다.

- **개인정보를 수집하지 않습니다**(이름, 이메일, 전화번호, 계정 없음).
- **사용 데이터나 분석 데이터를 수집하지 않습니다.**
- 광고, 분석, 충돌 보고용 **서드파티 SDK가 통합되어 있지 않습니다.**
- **쿠키나 추적 기술을 사용하지 않습니다.**

## 기기에 로컬로 저장되는 데이터

iEnglish가 만드는 모든 데이터는 기기에 남습니다.

| 데이터 | 저장 위치 | 사용자 제어 |
|------|---------|--------------|
| 어휘 데이터베이스(3000단어) | 로컬(SQLite) | 읽기 전용, 앱에 포함 |
| 즐겨찾기 및 학습 상태 | 로컬(App Group) | 단어별로 삭제 가능 |
| 퀴즈 진행 상황 및 연속 기록 | 로컬(App Group) | 설정에서 초기화하거나 앱 삭제 |
| 오답 노트 | 로컬(App Group) | 설정에서 지우기 |
| 최근 열람 | 로컬(App Group) | 단어 탭이나 설정에서 지우기 |
| 재생 목록 | 로컬(UserDefaults) | 재생 목록을 개별 삭제 |
| 앱 환경설정 | 로컬(UserDefaults) | 앱을 삭제해 초기화 |

위젯은 메인 앱과 위젯 확장 간에 데이터를 공유하기 위해 **App Group** 컨테이너(`group.cc.ihtc.iEnglish`)를 사용합니다. 이 컨테이너는 기기에 남으며 어떤 제3자도 접근할 수 없습니다.

## 선택적 iCloud 동기화

설정에서 **iCloud 동기화**를 켜면 즐겨찾기, 학습 상태, 오답 노트가 같은 Apple ID로 로그인한 iPhone, iPad, Mac 간에 **iCloud 키-값 저장소**(`iCloud.com.iHTCboy.iEnglish` 아래의 키)를 통해 동기화됩니다. 데이터는 Apple의 인프라를 통해 iHTC Studio 서버가 아니라 **개인 iCloud 계정** 안에 머뭅니다. 동기화는 언제든 끌 수 있으며, 로컬 데이터는 각 기기에 남고, iCloud에 저장된 사본은 선택적으로 삭제할 수 있습니다.

## 앱 내 후원

iEnglish는 **StoreKit 2**를 통한 선택적 후원을 제공합니다. 모든 결제 처리는 전적으로 Apple이 담당합니다. 당사는 금융 정보, 신용카드 정보, Apple ID 데이터를 받거나 저장하거나 접근하지 않습니다. 후원 거래에는 Apple 자체의 개인정보 처리방침과 약관이 적용됩니다.

## 권한

iEnglish는 특별한 기기 권한을 요청하지 않습니다. 카메라, 마이크, 연락처, 위치, 사진 보관함, 로컬 네트워크에 접근하지 않습니다.

## 아동 개인정보 보호

iEnglish는 13세 미만 아동을 포함해 누구에게서도 개인 데이터를 의도적으로 수집하지 않습니다. 데이터를 전혀 수집하지 않으므로 별도의 조치는 필요하지 않습니다. 앱에는 광고, 소셜 기능, 사용자 생성 콘텐츠가 없습니다.
