iEnglish는 초보자를 위한 영어 어휘 학습 앱으로, A–Z로 분류된 **3000개의 기초 핵심 단어**와 **책별 진행률**을 지원하는 선택형 **고등 / CET-4 / CET-6** 단어장을 제공합니다. 원어민 발음, 일일 퀴즈, 맞춤 재생 목록, 읽기 도우미, 위젯을 갖추었으며 iPhone, iPad, Mac에서 완전히 오프라인으로 작동합니다.

## 시작하기

1. iEnglish를 열고 알파벳순으로 단어를 둘러보거나 그리드 보기로 전환하세요.
2. 단어를 눌러 상세 정보(Apple 사전 뜻, 발음, Youdao 조회)를 확인하세요.
3. **퀴즈** 탭에서 매일 5문제 퀴즈를 풀고 연속 기록을 쌓아 보세요.
4. **재생 목록**을 만들어 반복 횟수, 간격, 속도를 조절하며 단어를 순서대로 재생하세요.
5. **설정**의 **읽기 도우미**를 사용해 보세요. 영어 텍스트를 붙여넣으면 일시정지/재개와 함께 소리 내어 읽어 줍니다.
6. 상세 페이지에서 단어를 **학습함** 또는 **마스터함**으로 표시하세요. 표시한 단어는 **설정 → 학습 기록**에서 모아 볼 수 있고, 전체 진행 상황은 **설정 → 학습 통계**에서 확인합니다.
7. 설정에서 **iCloud 동기화**를 켜면 즐겨찾기, 학습 상태, 오답 노트를 Apple 기기 간에 동기화할 수 있습니다(선택 사항).
8. 홈 화면에 **위젯**을 추가하세요(iPhone과 iPad만 해당). 오늘의 단어, 퀴즈 진행 상황, 즐겨찾기를 볼 수 있습니다. **`ienglish://`** URL로 같은 화면을 열 수도 있습니다. [URL 스킴 참조](url-scheme)를 확인하세요.

## 기능

- **3000개 핵심 단어** — A–Z 그룹, 목록/그리드 보기 전환, 선택형 A–Z 사이드바 색인(설정에서 전환)을 갖춘 초급 어휘.
- **선택형 시험 단어장** — **설정 → 단어장**에서 **고등 / CET-4 / CET-6** 팩을 켤 수 있습니다. 툴바에서 단어장을 전환하며, 즐겨찾기, 퀴즈, 재생 목록, 학습 상태는 **단어장별로 분리**됩니다(단어장을 꺼도 진행 상황은 유지). 위젯은 기본적으로 핵심 단어장을 반영하며, 선택적으로 현재 단어장을 따를 수 있습니다.
- **단어 상세** — Apple 사전(iOS는 네이티브, macOS는 다중 사전 카드), Youdao 조회, 학습 상태 메뉴, 긴 이미지 공유.
- **반복 재생** — 스피커를 길게 누르거나(iOS) 오른쪽 클릭 후 **반복 재생**(macOS)을 선택하면 전역 음성 설정을 바꾸지 않고 발음을 무제한 반복합니다.
- **인라인 재생 버튼** — 단어 목록 행 끝에 표시할 수 있는 선택형 재생 컨트롤(설정, 기본값 꺼짐).
- **앱 내 리뷰 안내** — 시스템 평가 대화상자 전에 표시할 수 있는 선택형 전체 화면 리뷰 안내.
- **학습 진행 상황** — 상세 페이지에서 단어를 학습함 또는 마스터함으로 표시하세요. 설정의 **학습률**은 학습함과 마스터함을 모두 집계합니다. **학습 기록**은 표시한 모든 단어를 학습함·마스터함 필터와 함께 보여 줍니다.
- **iCloud 동기화** — 설정의 선택형 토글로, 같은 iCloud 계정으로 로그인한 기기 간에 즐겨찾기, 학습 상태, 오답 노트를 동기화합니다.
- **최근 기록 지우기** — 단어 탭이나 설정에서 최근 열람 기록을 삭제합니다.
- **뜻 언어** — 앱 UI 언어와 별개로 단어 번역에 쓸 중국어 간체, 중국어 번체, 영어를 선택하세요.
- **원어민 발음** — 반복 횟수, 간격, 볼륨, 속도를 조절할 수 있는 영어 및 중국어 TTS.
- **읽기 도우미** — 영어 텍스트를 붙여넣어 일시정지/재개를 지원하는 TTS로 듣기(설정).
- **일일 퀴즈** — 하루 5문제, 연속 기록 카운터, 단어 상세로 연결되는 오답 노트, 문제 추적.
- **맞춤 재생 목록** — 단어 플랜 자동 생성, 이름 변경, 학습함/마스터함 단어 제외, **여기서부터 재생**, 화면을 켠 채 순차 재생.
- **위젯(iOS 전용)** — Daily Word(iOS 17+에서 단어 풀: 전체 / 알파벳 / 카테고리, 셔플 ⇄), Category Spotlight, Quiz Progress, Favorites, Wrong Book을 홈 화면과 잠금 화면에서 제공. 위젯 배경은 앱 테마 그라데이션을 따를 수 있습니다(설정에서 전환).
- **15가지 테마 프리셋** — 사용자 지정 색상 선택으로 나만의 스타일을 만들 수 있습니다.
- **macOS 네이티브** — 키보드 단축키(⌘F 검색, ⌘1–5 탭, Esc 뒤로), 인라인 검색, 다중 사전 카드, Mac 스타일 대화상자, 기본 그리드 레이아웃. **macOS에서는 위젯을 사용할 수 없습니다.**
- **홈 화면 빠른 동작** — 사용자 지정 가능, 최대 4개, 정렬 가능(iOS).
- **딥링크 지원** — `ienglish://word?id=`, `ienglish://categories`, `ienglish://quiz` 등. [URL 스킴 참조](url-scheme)를 확인하세요.
- **후원** — StoreKit 2를 통한 선택형 앱 내 후원(모든 결제는 Apple이 처리).
- **다크 모드** — 라이트/다크 외관을 완전히 지원합니다.
- **다국어** — 영어, 중국어 간체, 중국어 번체. 단어 탭 아이콘은 앱 언어에 맞춰 바뀝니다.

## 위젯

iEnglish는 한눈에 학습을 이어 갈 수 있도록 **5개의 홈 화면 위젯**과 **4개의 잠금 화면 위젯**을 제공합니다.

### 추가 방법

1. 홈 화면을 길게 눌러 편집 모드로 들어갑니다.
2. **+** 버튼을 누르고 "iEnglish"를 검색합니다.
3. 위젯을 고르고, 스와이프해 크기를 선택한 뒤 **위젯 추가**를 누릅니다.
4. 잠금 화면 위젯은 잠금 화면을 길게 누르고 **사용자화**를 누른 뒤 iEnglish 액세서리를 추가합니다.

### 사용 가능한 위젯

| 위젯 | 설명 | 크기 |
|--------|-------------|------|
| Daily Word | 매일 번역과 함께 새로운 영어 단어를 보여 줍니다. iOS 17+: 단어 풀(전체 / 알파벳 / 카테고리)을 고를 수 있고, **⇄**를 눌러 셔플합니다. | 소형, 중형 |
| Category Spotlight | 카테고리의 추천 단어. | 중형 |
| Quiz Glance | 오늘의 퀴즈 진행 상황과 연속 기록. | 소형 |
| Favorites Glance | 즐겨찾는 단어를 빠르게 확인. | 소형 |
| Wrong Book Glance | 최근에 틀린 단어. | 소형 |
| Lock Daily | 잠금 화면에 오늘의 단어 표시. | 잠금 화면 |
| Lock Quiz | 퀴즈 연속 기록을 한눈에. | 잠금 화면 |
| Lock Favorites | 즐겨찾는 단어 수. | 잠금 화면 |
| Lock Wrong Book | 오답 개수 알림. | 잠금 화면 |

## 시스템 요구 사항

| 플랫폼 | 최소 버전 |
|----------|-----------------|
| iPhone / iPad | iOS 16.0 이상 |
| Mac | macOS 13.0 이상(위젯 없음) |

위젯은 iOS 또는 iPadOS가 필요합니다. Mac 앱에는 위젯 확장이 포함되어 있지 않습니다.
