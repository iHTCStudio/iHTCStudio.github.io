iEnglish は初心者向けの英単語学習アプリです。A–Z に分類された **3000 語の基本語彙**に加え、**書籍ごとの進捗**を管理できる任意の **高校 / CET-4 / CET-6** 単語帳を備えています。ネイティブ発音、デイリークイズ、カスタムプレイリスト、読み上げアシスタント、ウィジェットを搭載し、iPhone、iPad、Mac で完全オフラインで動作します。

## はじめに

1. iEnglish を開き、文字順に単語を閲覧するか、グリッド表示に切り替えます。
2. 単語をタップして詳細（Apple 辞書の定義、発音、有道での検索）を表示します。
3. **クイズ**タブで毎日 5 問のクイズに挑戦し、連続記録を伸ばします。
4. **プレイリスト**を作成し、ループ回数、間隔、速度を調整しながら単語を順番に再生します。
5. **設定**の**読み上げアシスタント**を試します。英語のテキストを貼り付けて、一時停止/再開付きで読み上げます。
6. 詳細ページで単語を**学習済み**または**習得済み**にマークします。マークした単語は **設定 → 学習記録**で確認でき、全体の進捗は **設定 → 学習統計**で確認できます。
7. 設定で **iCloud 同期**を有効にすると、お気に入り、学習状況、間違い帳を Apple デバイス間で同期できます（任意）。
8. ホーム画面に**ウィジェット**を追加します（iPhone と iPad のみ）。デイリーワード、クイズの進捗、お気に入りなどを表示できます。**`ienglish://`** URL で同じ画面を開くこともできます。[URL スキームリファレンス](url-scheme)をご覧ください。

## 機能

- **3000 語の基本語彙** — A–Z 分類、リスト/グリッド表示の切り替え、任意の A–Z サイドバーインデックス（設定で切り替え）に対応した初級語彙。
- **任意の試験対策単語帳** — **設定 → 単語帳**で **高校 / CET-4 / CET-6** パックを有効にできます。ツールバーから単語帳を切り替えられ、お気に入り、クイズ、プレイリスト、学習状況は**単語帳ごとに独立**して管理されます（単語帳を無効にしても進捗は保持されます）。ウィジェットは既定で基本単語帳を表示し、任意で現在の単語帳に追従できます。
- **単語詳細** — Apple 辞書（iOS ではネイティブ、macOS では複数辞書カード）、有道での検索、学習状況メニュー、長い画像での共有。
- **リピート再生** — スピーカーを長押し（iOS）または右クリックで**リピート再生**（macOS）すると、グローバルな音声設定を変えずに発音を無制限にループできます。
- **インライン再生ボタン** — 単語リストの行末に表示できる任意の再生コントロール（設定。既定ではオフ）。
- **アプリ内レビューの案内** — システムの評価ダイアログの前に表示できる、任意のフルスクリーンのレビュー案内。
- **学習の進捗** — 詳細ページで単語を学習済みまたは習得済みにマークできます。設定の**学習率**は学習済みと習得済みの両方を数えます。**学習記録**にはマークしたすべての単語が、学習済み・習得済みのフィルター付きで一覧表示されます。
- **iCloud 同期** — 設定の任意のトグルで、同じ iCloud アカウントでサインインしたデバイス間で、お気に入り、学習状況、間違い帳を同期します。
- **最近の履歴を消去** — 「単語」タブまたは設定から、最近の閲覧履歴を削除できます。
- **意味の言語** — アプリの UI 言語とは別に、単語の訳として簡体字中国語、繁体字中国語、英語を選べます。
- **ネイティブ発音** — ループ回数、間隔、音量、速度を調整できる英語と中国語の TTS。
- **読み上げアシスタント** — 英語のテキストを貼り付けて、一時停止/再開付きで TTS 再生（設定）。
- **デイリークイズ** — 1 日 5 問、連続記録カウンター、単語詳細へのリンク付き間違い帳、出題の追跡。
- **カスタムプレイリスト** — 単語プランの自動生成、名前変更、学習済み/習得済み単語の除外、**ここから再生**、画面オンのまま順次再生。
- **ウィジェット（iOS のみ）** — Daily Word（iOS 17 以降で単語プール：すべて / 文字 / カテゴリ、シャッフル ⇄）、Category Spotlight、Quiz Progress、Favorites、Wrong Book を、ホーム画面とロック画面に。ウィジェットの背景はアプリのテーマグラデーションに追従できます（設定で切り替え）。
- **15 種類のテーマプリセット** — さらにカスタムカラー選択で、自分好みの外観に。
- **macOS ネイティブ** — キーボードショートカット（⌘F で検索、⌘1–5 でタブ、Esc で戻る）、インライン検索、複数辞書カード、Mac スタイルのダイアログ、既定のグリッドレイアウト。**macOS ではウィジェットは利用できません。**
- **ホーム画面のクイックアクション** — カスタマイズ可能、最大 4 項目、並べ替え可能（iOS）。
- **ディープリンク対応** — `ienglish://word?id=`、`ienglish://categories`、`ienglish://quiz` など。[URL スキームリファレンス](url-scheme)をご覧ください。
- **投げ銭** — StoreKit 2 による任意のアプリ内投げ銭（決済はすべて Apple が処理）。
- **ダークモード** — ライト/ダークの外観に完全対応。
- **多言語対応** — 英語、簡体字中国語、繁体字中国語。「単語」タブのアイコンはアプリの言語に合わせて切り替わります。

## ウィジェット

iEnglish は、**5 種類のホーム画面ウィジェット**と **4 種類のロック画面ウィジェット**で、学習をひと目で確認できるようにします。

### 追加方法

1. ホーム画面を長押しして編集モードに入ります。
2. **+** ボタンをタップして「iEnglish」を検索します。
3. ウィジェットを選び、スワイプしてサイズを選択し、**ウィジェットを追加**をタップします。
4. ロック画面ウィジェットは、ロック画面を長押しして**カスタマイズ**をタップし、iEnglish のアクセサリを追加します。

### 利用できるウィジェット

| ウィジェット | 説明 | サイズ |
|--------|-------------|------|
| Daily Word | 毎日新しい英単語と訳を表示。iOS 17 以降：単語プール（すべて / 文字 / カテゴリ）を選択でき、**⇄** をタップでシャッフル。 | スモール、ミディアム |
| Category Spotlight | カテゴリから厳選した単語を表示。 | ミディアム |
| Quiz Glance | 今日のクイズの進捗と連続記録。 | スモール |
| Favorites Glance | お気に入りの単語をひと目で確認。 | スモール |
| Wrong Book Glance | 最近間違えた単語。 | スモール |
| Lock Daily | ロック画面に今日の単語を表示。 | ロック画面 |
| Lock Quiz | クイズの連続記録をひと目で確認。 | ロック画面 |
| Lock Favorites | お気に入りの単語数。 | ロック画面 |
| Lock Wrong Book | 間違えた単語数のリマインダー。 | ロック画面 |

## システム要件

| プラットフォーム | 最低バージョン |
|----------|-----------------|
| iPhone / iPad | iOS 16.0 以降 |
| Mac | macOS 13.0 以降（ウィジェットなし） |

ウィジェットには iOS または iPadOS が必要です。Mac アプリにはウィジェット機能拡張は含まれていません。
