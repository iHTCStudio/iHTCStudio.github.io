iEnglish เป็นแอปเรียนคำศัพท์ภาษาอังกฤษสำหรับผู้เริ่มต้น มี **คำศัพท์พื้นฐานหลัก 3000 คำ** จัดกลุ่ม A–Z พร้อมหนังสือคำศัพท์แบบเลือกได้ **Senior / CET-4 / CET-6** ที่มี **ความคืบหน้าแยกตามเล่ม** มีเสียงออกเสียงเจ้าของภาษา แบบทดสอบประจำวัน เพลย์ลิสต์แบบกำหนดเอง ผู้ช่วยอ่าน และวิดเจ็ต — ใช้งานแบบออฟไลน์เต็มรูปแบบบน iPhone, iPad และ Mac

## เริ่มต้นใช้งาน

1. เปิด iEnglish แล้วเรียกดูคำศัพท์ตามตัวอักษร หรือสลับไปมุมมองตาราง
2. แตะคำใดก็ได้เพื่อดูรายละเอียด — คำนิยามจาก Apple Dictionary การออกเสียง และการค้นหา Youdao
3. ใช้แท็บ **แบบทดสอบ** เพื่อทำแบบทดสอบ 5 ข้อทุกวันและติดตามสถิติต่อเนื่องของคุณ
4. สร้าง **เพลย์ลิสต์** เพื่อเล่นคำตามลำดับ พร้อมปรับจำนวนรอบ ช่วงเวลา และความเร็วได้
5. ลอง **ผู้ช่วยอ่าน** ใน **การตั้งค่า** — วางข้อความภาษาอังกฤษใดก็ได้เพื่อฟังเสียงอ่าน พร้อมหยุดชั่วคราว/เล่นต่อ
6. ทำเครื่องหมายคำเป็น **เรียนแล้ว** หรือ **เชี่ยวชาญ** ที่หน้ารายละเอียด ดูคำที่ทำเครื่องหมายทั้งหมดได้ใน **การตั้งค่า → บันทึกการเรียนรู้** และติดตามความคืบหน้าโดยรวมได้ใน **การตั้งค่า → สถิติการเรียนรู้**
7. เลือกเปิด **การซิงค์ iCloud** ในการตั้งค่า เพื่อให้รายการโปรด สถานะการเรียนรู้ และสมุดบันทึกข้อที่ตอบผิดซิงค์ข้ามอุปกรณ์ Apple ของคุณ
8. เพิ่ม **วิดเจ็ต** ลงหน้าจอโฮม (เฉพาะ iPhone และ iPad) สำหรับคำประจำวัน ความคืบหน้าแบบทดสอบ หรือรายการโปรด เปิดปลายทางเดียวกันผ่าน URL **`ienglish://`** — ดู [เอกสารอ้างอิง URL Scheme](url-scheme)

## ฟีเจอร์

- **คำศัพท์หลัก 3000 คำ** — คำศัพท์ระดับเริ่มต้น จัดกลุ่ม A–Z สลับมุมมองรายการ/ตาราง และมีดัชนีแถบข้าง A–Z แบบเลือกได้ (เปิด/ปิดในการตั้งค่า)
- **หนังสือคำศัพท์สอบแบบเลือกได้** — เปิดชุด **Senior / CET-4 / CET-6** ได้ใน **การตั้งค่า → หนังสือคำศัพท์** สลับเล่มจากแถบเครื่องมือ รายการโปรด แบบทดสอบ เพลย์ลิสต์ และสถานะการเรียนรู้ **แยกกันตามเล่ม** (ปิดเล่มแล้วความคืบหน้ายังคงอยู่) โดยค่าเริ่มต้นวิดเจ็ตจะแสดงเล่มหลัก และเลือกให้ตามเล่มปัจจุบันได้
- **รายละเอียดคำ** — Apple Dictionary (เนทีฟบน iOS การ์ดหลายพจนานุกรมบน macOS) การค้นหา Youdao เมนูสถานะการเรียนรู้ และการแชร์เป็นภาพยาว
- **เล่นซ้ำ** — กดค้างที่ลำโพง (iOS) หรือคลิกขวาแล้วเลือก **เล่นซ้ำ** (macOS) เพื่อวนเสียงออกเสียงไม่จำกัดโดยไม่เปลี่ยนการตั้งค่าเสียงส่วนกลาง
- **ปุ่มเล่นในแถว** — ปุ่มเล่นท้ายแถวในรายการคำศัพท์แบบเลือกได้ (การตั้งค่า; ปิดเป็นค่าเริ่มต้น)
- **หน้าขอรีวิวในแอป** — หน้าจอแนะนำการรีวิวแบบเต็มหน้าจอที่เลือกได้ ก่อนกล่องโต้ตอบให้คะแนนของระบบ
- **ความคืบหน้าการเรียนรู้** — ทำเครื่องหมายคำเป็นเรียนแล้วหรือเชี่ยวชาญที่หน้ารายละเอียด **อัตราการเรียนรู้** ในการตั้งค่านับทั้งคำที่เรียนแล้วและเชี่ยวชาญ **บันทึกการเรียนรู้** แสดงทุกคำที่คุณทำเครื่องหมาย พร้อมตัวกรองสำหรับเรียนแล้วและเชี่ยวชาญ
- **การซิงค์ iCloud** — สวิตช์แบบเลือกได้ในการตั้งค่า ซิงค์รายการโปรด สถานะการเรียนรู้ และสมุดบันทึกข้อที่ตอบผิดข้ามอุปกรณ์ที่ลงชื่อเข้าใช้บัญชี iCloud เดียวกัน
- **ล้างรายการล่าสุด** — ลบประวัติการเปิดดูล่าสุดจากแท็บคำศัพท์หรือการตั้งค่า
- **ภาษาของความหมาย** — เลือกจีนตัวย่อ จีนตัวเต็ม หรืออังกฤษสำหรับคำแปล โดยไม่ขึ้นกับภาษา UI ของแอป
- **เสียงออกเสียงเจ้าของภาษา** — TTS ภาษาอังกฤษและจีน พร้อมปรับจำนวนรอบ ช่วงเวลา ระดับเสียง และความเร็วได้
- **ผู้ช่วยอ่าน** — วางข้อความภาษาอังกฤษเพื่อฟังด้วย TTS รองรับหยุดชั่วคราว/เล่นต่อ (การตั้งค่า)
- **แบบทดสอบประจำวัน** — วันละ 5 ข้อ ตัวนับสถิติต่อเนื่อง สมุดบันทึกข้อที่ตอบผิดพร้อมลิงก์ไปยังรายละเอียดคำ และการติดตามคำถาม
- **เพลย์ลิสต์แบบกำหนดเอง** — สร้างแผนคำศัพท์อัตโนมัติ เปลี่ยนชื่อ ยกเว้นคำที่เรียนแล้ว/เชี่ยวชาญ **เล่นจากตรงนี้** เล่นตามลำดับโดยเปิดหน้าจอค้างไว้
- **วิดเจ็ต (เฉพาะ iOS)** — Daily Word (กลุ่มคำ: ทั้งหมด / ตัวอักษร / หมวดหมู่ บน iOS 17+; สลับ ⇄ บน iOS 17+), Category Spotlight, Quiz Progress, Favorites และ Wrong Book สำหรับหน้าจอโฮมและหน้าจอล็อก พื้นหลังวิดเจ็ตตามไล่เฉดสีธีมของแอปได้ (เปิด/ปิดในการตั้งค่า)
- **ธีมที่ตั้งไว้ล่วงหน้า 15 แบบ** — พร้อมเลือกสีเองเพื่อลุคส่วนตัว
- **เนทีฟบน macOS** — แป้นพิมพ์ลัด (⌘F ค้นหา, ⌘1–5 แท็บ, Esc ย้อนกลับ) ค้นหาแบบอินไลน์ การ์ดหลายพจนานุกรม กล่องโต้ตอบสไตล์ Mac เลย์เอาต์ตารางเป็นค่าเริ่มต้น **วิดเจ็ตไม่พร้อมใช้งานบน macOS**
- **การดำเนินการด่วนบนหน้าจอโฮม** — ปรับแต่งได้ สูงสุด 4 รายการ จัดเรียงได้ (iOS)
- **รองรับ Deep Link** — `ienglish://word?id=`, `ienglish://categories`, `ienglish://quiz` และอื่น ๆ ดู [เอกสารอ้างอิง URL Scheme](url-scheme)
- **ทิป** — การให้ทิปในแอปแบบเลือกได้ผ่าน StoreKit 2 (Apple จัดการการชำระเงินทั้งหมด)
- **โหมดมืด** — รองรับรูปลักษณ์สว่างและมืดเต็มรูปแบบ
- **หลายภาษา** — อังกฤษ จีนตัวย่อ และจีนตัวเต็ม ไอคอนแท็บคำศัพท์ปรับตามภาษาของแอป

## วิดเจ็ต

iEnglish มี **วิดเจ็ตหน้าจอโฮม 5 แบบ** และ **วิดเจ็ตหน้าจอล็อก 4 แบบ** ให้คุณเรียนรู้ได้ในพริบตา

### วิธีเพิ่ม

1. กดค้างที่หน้าจอโฮมเพื่อเข้าสู่โหมดแก้ไข
2. แตะปุ่ม **+** แล้วค้นหา "iEnglish"
3. เลือกวิดเจ็ต ปัดเพื่อเลือกขนาด แล้วแตะ **เพิ่มวิดเจ็ต**
4. สำหรับวิดเจ็ตหน้าจอล็อก ให้กดค้างที่หน้าจอล็อก แตะ **ปรับแต่ง** แล้วเพิ่มวิดเจ็ตเสริมของ iEnglish

### วิดเจ็ตที่มี

| วิดเจ็ต | คำอธิบาย | ขนาด |
|--------|-------------|------|
| Daily Word | คำภาษาอังกฤษใหม่ทุกวันพร้อมคำแปล iOS 17+: เลือกกลุ่มคำ (ทั้งหมด / ตัวอักษร / หมวดหมู่); แตะ **⇄** เพื่อสลับ | เล็ก, กลาง |
| Category Spotlight | คำเด่นจากหมวดหมู่ | กลาง |
| Quiz Glance | ความคืบหน้าแบบทดสอบวันนี้และสถิติต่อเนื่อง | เล็ก |
| Favorites Glance | ดูคำโปรดของคุณอย่างรวดเร็ว | เล็ก |
| Wrong Book Glance | คำที่คุณตอบผิดเมื่อเร็ว ๆ นี้ | เล็ก |
| Lock Daily | คำของวันนี้บนหน้าจอล็อก | หน้าจอล็อก |
| Lock Quiz | สถิติต่อเนื่องของแบบทดสอบในพริบตา | หน้าจอล็อก |
| Lock Favorites | จำนวนคำโปรด | หน้าจอล็อก |
| Lock Wrong Book | การแจ้งเตือนจำนวนข้อที่ตอบผิด | หน้าจอล็อก |

| แพลตฟอร์ม | เวอร์ชันขั้นต่ำ |
|----------|-----------------|
| iPhone / iPad | iOS 16.0+ |
| Mac | macOS 13.0+ (ไม่มีวิดเจ็ต) |

วิดเจ็ตต้องใช้ iOS หรือ iPadOS แอป Mac ไม่มีส่วนขยายวิดเจ็ต
