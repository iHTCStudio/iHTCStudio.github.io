### 単語を検索するには？

単語リストの上部にある検索バーを使うか、Mac では **⌘F** を押してインライン検索を有効にします。入力に合わせてリストが絞り込まれ、一致する結果まで自動でスクロールします。英語、簡体字中国語、繁体字中国語で検索できます。

### デイリークイズの仕組みは？

**クイズ**タブから始めます。毎日、3000 語のライブラリから 5 問の選択問題が出題されます。正解すると連続記録が伸びます。間違えた問題は自動的に**間違い帳**に保存されるので、後で復習して練習できます。

### プレイリストの仕組みは？

**プレイリスト**タブで **＋** をタップして新しいプランを作成します。名前と単語数を入力すると、iEnglish が（他のプランで使用済みの単語を除いて）ライブラリからランダムに単語を選びます。**学習済み**または**習得済み**にマークした単語を除外することもできます。プランの名前変更や削除はリストから行え、プランを開くと単語を順番に再生できます。コンテキストメニューの**ここから再生**で途中から開始できます。再生中は画面がオンのままになります（iOS）。ループ回数、間隔、速度は **設定 → 音声** で調整できます。

### 単語の発音を繰り返すには？

単語の詳細ページで、iPhone または iPad では丸いスピーカーボタンを**長押し**（約 0.35 秒）すると、停止をタップするまで発音を無限にループします。この操作でグローバルなループ設定は変わりません。Mac では、スピーカーを**右クリック**して**リピート再生**を選ぶと同じ動作になります。

### 学習状況の仕組みは？

単語の詳細を開き、ツールバーのメニューから**学習済み**、**習得済み**、**未学習**にマークします。**設定 → 学習統計**の**学習率**は、3000 語のライブラリ全体で学習済みと習得済みの両方を数えます。**設定 → 学習記録**を開くと、マークしたすべての単語を、学習済み・習得済みのフィルターで閲覧できます。

### iCloud 同期の仕組みは？

**設定 → iCloud 同期**に移動してトグルをオンにします。お気に入り、学習状況、間違い帳が、同じ iCloud アカウントでサインインしている iPhone、iPad、Mac の間で同期されます。同期をオフにしてもデータは端末に残り、iCloud に保存されたコピーは任意で削除できます。

### 最近の閲覧を消去するには？

**単語**タブで最近の履歴の消去操作を使うか、**設定**で最近の閲覧リストを削除します。お気に入り、プレイリスト、学習状況には影響しません。

### A–Z サイドバーインデックスを切り替えるには？

**設定**で A–Z インデックスをオンまたはオフにします。有効にすると、リスト表示に文字のサイドバーが表示され、セクション間をすばやく移動できます。

### 意味の言語を変更するには？

**設定 → 意味の言語**で、単語の訳として簡体字中国語、繁体字中国語、英語のいずれかを選びます。これは **設定 → 言語**のアプリ UI 言語とは独立しています。

### 読み上げアシスタントの使い方は？

**設定 → 読み上げアシスタント**（英語 TTS リーダー）を開きます。英語のテキストを貼り付けるか入力し、再生をタップして音声読み上げを開始します。いつでも一時停止と再開ができます。読み上げ速度と音量は **設定 → 音声** で調整できます。

### iEnglish はインターネット接続が必要ですか？

いいえ。3000 語すべての単語、定義、発音は、端末上のローカル SQLite データベースに保存されています。クイズ、プレイリスト、ウィジェット、読み上げアシスタントはすべて完全にオフラインで動作します。任意でネットワークを使う機能は、単語詳細での有道辞書の検索だけです。

### ウィジェットの使い方は？

ホーム画面またはロック画面を長押しして編集モードに入り、**＋**ボタンをタップして「iEnglish」を検索します。利用できるウィジェットは **Daily Word**、**Category Spotlight**、**Quiz Progress**、**Favorites**、**Wrong Book** です。**Favorites** と **Wrong Book** は**スモールサイズのみ**です。iOS 17 以降では、Daily Word ウィジェットを編集して単語プール（すべての単語、特定の文字、またはカテゴリ）を選べます。対応する Daily Word ウィジェットの **⇄ シャッフル**ボタンをタップすると、アプリを開かずに別の単語に切り替えられます。ウィジェットは iPhone と iPad で自動的に更新されます。**設定**では、**ウィジェットの背景をテーマに合わせる**を切り替えて、ホーム画面のウィジェットにアプリのテーマグラデーションを使用できます。

### iEnglish は macOS で動作しますか？

はい。iEnglish はネイティブの macOS アプリです（macOS 13.0 以降が必要）。検索の **⌘F**、タブ切り替えの **⌘1–5**、戻る・シートを閉じる **Esc**、Mac スタイルのインライン検索、macOS Dictionary フレームワークによる複数辞書カード、単語詳細のスピーカーボタンを右クリックする**リピート再生**などのキーボードショートカットに対応しています。**macOS ではウィジェットは利用できません**。iPhone または iPad でのみ追加してください。

### テーマを変更するには？

**設定 → テーマ**に移動します。15 種類のプリセットカラーテーマから選ぶか、カラーホイールのアイコンをタップして、システムのカラーピッカーで好きな色を選べます。テーマはアプリ全体に即座に反映されます。

### アプリの言語を変更するには？

アプリ内の **設定 → 言語**に移動します。端末のシステム言語とは別に、英語、簡体字中国語、繁体字中国語から選べます。

### ディープリンクとは何で、どう使いますか？

iEnglish は `ienglish://` URL スキームに対応しています。パスは `word`、`quiz`、`favorites`、`wrong`、`playlist`、`categories` です。ショートカット、ブックマーク、ウィジェットで利用できます。[URL スキームリファレンス](../url-scheme)をご覧ください。

### 投げ銭の仕組みは？

iEnglish は、設定から **StoreKit 2** による任意の投げ銭を用意しています。決済処理はすべて Apple が行います。当社は金融情報を受け取ったり保存したりすることはありません。
