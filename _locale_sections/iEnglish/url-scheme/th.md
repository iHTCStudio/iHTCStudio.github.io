## โพรโทคอล


```
ienglish://<host>[?query]
```

|------|--------|

| **Word detail** | โฮสต์ 'คํา' — สืบค้น **. สืบค้น = < suffid> '' (require, ไม่ว่างเปล่า) |

| **Favourites** | โฮสต์ |
