**iVeil（爱修图）** は、秘密までは共有せずに写真を渡せます。写真が iPhone または iPad を離れる前に、iVeil は顔、ナンバープレート、電話番号、身分証とカード番号、QR コード、位置情報を見つけ、隠し、まだ何が見えるかを示します。**すべて端末上で動きます。アカウント不要、アップロードなし、広告なし、追跡なし。**（初期バージョンの名称は iPhoto です。）

**ひと目で：** 安心共有（共有メニューからも）· プライバシー診断 · 自分は残し通行人は隠す · コードの中身 · 書類モード · スクリーンショット検査 · おおよその位置 · 絵文字と Genmoji のベール · ビデオベール · ライブベールカメラ（iOS 18 のロック画面）· 「写真」編集機能拡張 · ショートカットとコントロールセンター · 見えない印 · レイヤー、Apple Pencil、フィルムレシピ · 最近削除した項目。

> iVeil は独立した App であり、**Apple Inc. とは関係がありません。**

## ここから：安心共有

1. **どの App からでも：** 「写真」またはほかの App で **共有 → iVeil** をタップします。読み込まずに、一度に最大 10 枚を確認できます。
2. **iVeil の中では：** ライブラリで写真を長押し → **安心共有**。見本「Street Corner」では、ナンバープレートと電話番号が隠される様子を示します。
3. 見つかったものを確認します。**機密をすべて隠す**をタップするか、項目ごとにオン／オフします。ほかの箇所は手で塗りつぶせます。
4. **人物：** *通行人だけ*、*全員*、*隠さない* から選ぶか、一人をタップします。残した人のハサミをタップすると、透明な画像として切り出せます。
5. **位置情報：** *削除*、*街区程度（約 5 km）*、*正確*。カメラやシリアル番号などのファイル情報も並ぶので、写真と一緒に何が出て行くか分かります。
6. 身分証や契約書を送るときは **書類モード** を開きます。「××専用」の透かしを敷き詰め、番号は下 4 桁だけ残し、書類の縁まで切り抜きます。
7. **安心コピーを共有** または **写真に保存** をタップします。原本は変わりません。

**ビデオベール：** ライブラリ → **+** → **ビデオベール**。ビデオ（最長 10 分）を選び、残したい人の顔をタップします。**ライブベール：** 撮影でライブベールをオンにすると、撮っているあいだ顔を隠します。

自動検出は頼れる最初の一手であり、保証ではありません。送る前に一度見てください。

## パート 1 — 初回起動とタブ

1. [App Store](https://apps.apple.com/app/id6787360978) からダウンロードし、**iVeil** を開きます。
2. 短い**ウェルカムガイド**を終えます（あとで **設定 → 機能ガイド** から再生できます）。
3. 求められたら、**カメラ**（撮影用）と**写真**（読み込み／任意の保存）を許可します。
4. ガイドの最後、またはあとで設定から、**起動タブ**を **撮影** か **ライブラリ** に選びます。

サインインはありません。すぐに使えます。

| タブ | できること |
|-----|----------------|
| **ライブラリ** | 読み込み、閲覧、検索、複数選択、エディタを開く |
| **撮影** | 美肌とフィルター付きのライブカメラ — 使わないときは設定でこのタブを隠せます |
| **設定** | 外観、アイコン、撮影、書き出し、ガイド |
| **検索** | iOS 18 以降 — プロジェクト、フィルター、エディタのツールを検索 |

## パート 2 — ライブラリ

- **写真**から読み込むか、撮影で撮ります。
- **グリッド／リスト**を切り替えます。列数は設定で調整します。
- **すべて · 編集済み · 撮影 · 読み込み · お気に入り**で絞り込み、新しい順、古い順、名前順に並べます。
- **選択**して、まとめて共有、写真へ保存、お気に入り、削除ができます。
- 項目をタップすると非破壊エディタが開きます。読み込んだプロジェクトの**原本ファイルは残ります**。

---

## パート 3 — ライブビューティーで撮影

1. **撮影**を開きます（隠している場合は設定でオンにします）。
2. **ビューティー**を切り替えます。**量**に加え、スムーズ、ホワイト、小顔、目、歯、チーク、リップを細かく調整します。
3. 任意：フラッシュ、カウントダウン、グリッド、フロントミラー、ライブ**フィルター**（お気に入り登録、強度スライダー）。
4. ビューティーまたはフィルターがオンのとき、プレビューは顔の重ね合わせではなく、**処理済みのフレーム全体**を表示します。
5. シャッターをタップします。ルックは保存された原本に**一度だけ焼き込まれ**、エディタが二重に適用することはありません。
6. 設定：ビューティーレシピを覚える、JPEG/HEVC、焼き込んでいないネガを残す、撮影後の動作。

---

## パート 4 — 非破壊エディタ

プロジェクトを開きます。下端のツール：

| ツール | できること |
|------|-----------------|
| **調整** | 露出、コントラスト、ホワイトバランスなど — 加えて**ワンタップ補正**（端末上） |
| **フィルター** | 自作の **3D LUT** ルック **55** 種、10 の系統。強度とお気に入り |
| **ルック** | **ルックレシピ**（フィルター + トーン + ビューティー + フレーム）を保存して再適用。ライブラリから一括適用 |
| **コラージュ** | **2〜9** 枚を複数選択 → コラージュスタジオ（レイアウト、間隔、背景） |
| **ビューティー** | プリセット。複数の顔が見つかったときは顔ごとに調整 |
| **切り抜き** | 比率、回転、反転、**傾き補正（−45°…45°）** |
| **エフェクト** | ワンタップのスタイル（ソフト / フィルム / ボールド）と背景ぼかし |
| **フレーム** | 5 グループで約 30 種。太さと 10 色のマット |
| **ステッカー** | 表情、形、マーク、季節、旅行、食べ物など約 **800+** |
| **テキスト** | 最終画像に描き込まれるキャプション |
| **プライバシー** | EXIF、GPS、端末のメタデータを取り除く |

- プレビューを**タップ**すると **原本 | 後** を並べて比較します。**長押し**で原本を一瞬表示します。
- ビューティーは**端末上の Vision** を使います。ランドマークが端末の外に出ることはありません。
- **すべての顔**または一つの顔を選び、パラメータを別々に調整できます。
- 任意：**ワンタップ補正に軽いビューティーを含める**（スムーズ + クールな明るさのみ — 設定）。

---

## パート 5 — 書き出しとプライバシー

1. 書き出しをタップし、**オリジナル / 高 / 中 / 低** を選びます。
2. 必要なら **写真に保存** します。
3. 確認したいときは **書き出し前に確認** をオンにします。
4. 旅行写真やポートレートを共有する前に **メタデータを除去** をオンにします。

写真は App のサンドボックス（および任意の写真アルバム）に残ります。解析のために iPhoto が**アップロードすることはありません**。

## パート 6 — ウィジェット、アイコン、ショートカット

### ウィジェット

**ホーム画面（4）：** クイック撮影 · 最近のプロジェクト · ライブラリ統計 · 毎日のヒント。

**ロック画面（2）：** クイック撮影 · 最近のプロジェクト。

iOS のウィジェットギャラリーから追加します。**設定 → ウィジェットガイド**を参照してください。

### App アイコン

**設定 → 外観 → App アイコン** — 標準に加え、**フレーム、フィルム、レンズ、ブルーム、サンセット**。

### Siri とショートカット

撮影を開く、ライブラリを開く、写真を読み込む。一覧：[ショートカットリンク](url-scheme)。

### ディープリンク

`iphoto://capture`、`iphoto://library`、`iphoto://import`、`iphoto://search` など。詳しくは [ショートカットリンク](url-scheme)。

## パート 7 — 知っておきたい設定

- **外観** — ライト / ダーク / システム。App アイコン。ウィジェットはテーマに合わせられます
- **言語** — English · 简体中文 · 繁體中文
- **撮影** — 撮影タブの表示／非表示、起動タブ、グリッド、フロントミラー、ビューティーを覚える、エンコード、ネガを残す
- **書き出し** — 既定の画質、写真へ保存、確認ダイアログ、ビューティー付きワンタップ補正
- **iCloud 同期** — 環境設定のみ（写真ファイルは同期しません）
- **ガイド** — 使い方、ウィジェット、ショートカット、機能ガイド
- **開発者にチップ** — 任意の消耗型チップ（機能は無料のまま）
