**iVeil(爱修图)** 은 비밀까지 공유하지 않고 사진을 건넬 수 있게 합니다. 사진이 iPhone 또는 iPad를 떠나기 전에 iVeil이 얼굴, 번호판, 전화번호, 신분증과 카드 번호, QR 코드, 위치를 찾아 가리고, 아직 무엇이 보이는지 알려 줍니다. **모두 기기에서 실행됩니다. 계정 없음, 업로드 없음, 광고 없음, 추적 없음.** (초기 버전 이름은 iPhoto입니다.)

**한눈에:** 안심 공유(공유 메뉴에서도) · 개인정보 점검 · 나만 남기고 행인은 가리기 · 코드 속 내용 · 서류 모드 · 스크린샷 검사 · 대략적인 위치 · 이모지와 Genmoji 베일 · 비디오 베일 · 라이브 베일 카메라(iOS 18 잠금 화면) · 「사진」 편집 확장 · 단축어와 제어 센터 · 보이지 않는 표시 · 레이어, Apple Pencil, 필름 레시피 · 최근 삭제된 항목.

> iVeil은 독립 앱이며 **Apple Inc.와 제휴하지 않습니다.**

## 여기서 시작: 안심 공유

1. **아무 앱에서:** 「사진」 또는 다른 앱에서 **공유 → iVeil**을 탭합니다. 가져오지 않고 한 번에 최대 10장을 확인할 수 있습니다.
2. **iVeil 안에서:** 보관함에서 사진을 길게 눌러 **안심 공유**. 샘플 「Street Corner」는 번호판과 전화번호가 가려지는 모습을 보여 줍니다.
3. 찾은 항목을 살펴봅니다. **민감한 항목 모두 가리기**를 탭하거나 항목마다 켜고 끕니다. 나머지는 손으로 칠할 수 있습니다.
4. **사람:** *행인만*, *모두*, *가리지 않음* 중에서 고르거나 한 사람을 탭합니다. 남긴 사람 위의 가위를 누르면 투명한 이미지로 오려 냅니다.
5. **위치:** *제거*, *대략적인 위치(약 5 km)*, *정확*. 카메라와 일련번호 같은 파일 정보도 나열되어, 사진과 함께 무엇이 나가는지 알 수 있습니다.
6. 신분증이나 계약서를 보내나요? **서류 모드**를 열면 「×× 전용」 워터마크를 바둑판처럼 깔고, 번호는 끝 4자리만 남기며, 서류 가장자리까지 자를 수 있습니다.
7. **안심 사본 공유** 또는 **사진에 저장**을 탭합니다. 원본은 바뀌지 않습니다.

**비디오 베일:** 보관함 → **+** → **비디오 베일**. 비디오(최대 10분)를 고른 뒤, 남길 사람의 얼굴을 탭합니다. **라이브 베일:** 촬영에서 라이브 베일을 켜면 찍는 동안 얼굴을 가립니다.

자동 인식은 든든한 첫 단계일 뿐 보장이 아닙니다. 보내기 전에 한 번 더 봐 주세요.

## 1부 — 첫 실행과 탭

1. [App Store](https://apps.apple.com/app/id6787360978)에서 받아 **iVeil**을 엽니다.
2. 짧은 **환영 안내**를 마칩니다(나중에 **설정 → 기능 안내**에서 다시 볼 수 있습니다).
3. 요청이 나오면 **카메라**(촬영)와 **사진**(가져오기 / 선택적 저장)을 허용합니다.
4. 안내 마지막이나 나중에 설정에서 **시작 탭**을 **촬영** 또는 **보관함**으로 고릅니다.

로그인은 없습니다. 바로 쓸 수 있습니다.

| 탭 | 하는 일 |
|-----|----------------|
| **보관함** | 가져오기, 둘러보기, 검색, 다중 선택, 편집기 열기 |
| **촬영** | 뷰티와 필터가 있는 라이브 카메라 — 쓰지 않으면 설정에서 이 탭을 숨깁니다 |
| **설정** | 모양, 아이콘, 촬영, 내보내기, 안내 |
| **검색** | iOS 18 이상 — 프로젝트, 필터, 편집 도구 검색 |

## 2부 — 보관함

- **사진**에서 가져오거나 촬영에서 찍습니다.
- **격자 / 목록**을 바꿉니다. 열 수는 설정에서 조절합니다.
- **전체 · 편집됨 · 촬영 · 가져옴 · 즐겨찾기**로 거르고, 최신, 오래된 순 또는 이름으로 정렬합니다.
- **선택**하면 일괄 공유, 사진에 저장, 즐겨찾기, 삭제가 됩니다.
- 항목을 탭하면 비파괴 편집기가 열립니다. 가져온 프로젝트의 **원본 파일은 남습니다**.

---

## 3부 — 라이브 뷰티로 촬영

1. **촬영**을 엽니다(숨겨 두었다면 설정에서 켭니다).
2. **뷰티**를 전환합니다. **강도**와 함께 매끈, 미백, 얼굴 축소, 눈, 치아, 블러셔, 립스틱을 조절합니다.
3. 선택: 플래시, 카운트다운, 격자, 전면 거울, 라이브 **필터**(즐겨찾기, 강도 슬라이더).
4. 뷰티나 필터가 켜져 있으면 미리보기는 얼굴 위 겹침이 아니라 **처리된 프레임 전체**를 보여 줍니다.
5. 셔터를 탭합니다. 룩은 저장된 원본에 **한 번 구워지므로** 편집기가 두 번 적용하지 않습니다.
6. 설정: 뷰티 레시피 기억, JPEG/HEVC, 굽지 않은 네거티브 보관, 촬영 후 동작.

---

## 4부 — 비파괴 편집기

프로젝트를 엽니다. 아래쪽 도구:

| 도구 | 할 수 있는 일 |
|------|-----------------|
| **조정** | 노출, 대비, 화이트 밸런스 등 — 그리고 **원탭 향상**(기기에서) |
| **필터** | 직접 만든 **3D LUT** 룩 **55**종, 10개 계열. 강도와 즐겨찾기 |
| **룩** | **룩 레시피**(필터 + 톤 + 뷰티 + 프레임)를 저장하고 다시 적용. 보관함에서 일괄 적용 |
| **콜라주** | **2–9**장을 다중 선택 → 콜라주 스튜디오(레이아웃, 간격, 배경) |
| **뷰티** | 프리셋. 얼굴이 여러 개면 얼굴마다 조절 |
| **자르기** | 비율, 회전, 뒤집기, **수평 맞추기(−45°…45°)** |
| **효과** | 원탭 스타일(소프트 / 필름 / 볼드)과 배경 흐림 |
| **프레임** | 다섯 그룹, 약 30종. 두께와 10색 매트 |
| **스티커** | 표정, 모양, 표시, 계절, 여행, 음식 등 약 **800+** |
| **텍스트** | 최종 이미지에 그려지는 캡션 |
| **개인정보** | EXIF, GPS, 기기 메타데이터 제거 |

- 미리보기를 **탭**하면 **원본 | 후**를 나란히 비교합니다. **길게 누르면** 원본이 잠깐 보입니다.
- 뷰티는 **기기의 Vision**을 씁니다. 랜드마크는 기기를 떠나지 않습니다.
- **모든 얼굴** 또는 한 얼굴을 골라 값을 따로 조절합니다.
- 선택: **원탭 향상에 가벼운 뷰티 포함**(매끈 + 차가운 밝기만 — 설정).

## 5부 — 내보내기와 개인정보

1. 내보내기를 탭하고 **원본 / 높음 / 중간 / 낮음**을 고릅니다.
2. 원하면 **사진에 저장**합니다.
3. 확인이 필요하면 **내보내기 전 확인**을 켭니다.
4. 여행 사진이나 인물 사진을 공유하기 전에 **메타데이터 제거**를 켭니다.

사진은 앱 샌드박스(그리고 선택한 사진 앨범)에 남습니다. 분석을 위해 iPhoto가 **업로드하지 않습니다**.

## 6부 — 위젯, 아이콘, 단축어

### 위젯

**홈 화면(4):** 빠른 촬영 · 최근 프로젝트 · 보관함 통계 · 오늘의 팁.

**잠금 화면(2):** 빠른 촬영 · 최근 프로젝트.

iOS 위젯 갤러리에서 추가합니다. **설정 → 위젯 안내**를 보세요.

### 앱 아이콘

**설정 → 모양 → 앱 아이콘** — 기본과 **프레임, 필름, 렌즈, 블룸, 선셋**.

### Siri와 단축어

촬영 열기, 보관함 열기, 사진 가져오기. 전체 목록: [단축어 링크](url-scheme).

### 딥 링크

`iphoto://capture`, `iphoto://library`, `iphoto://import`, `iphoto://search` 등. 자세한 내용: [단축어 링크](url-scheme).

## 7부 — 알아 두면 좋은 설정

- **모양** — 라이트 / 다크 / 시스템. 앱 아이콘. 위젯은 테마를 따를 수 있습니다
- **언어** — English · 简体中文 · 繁體中文
- **촬영** — 촬영 탭 표시/숨기기, 시작 탭, 격자, 전면 거울, 뷰티 기억, 인코딩, 네거티브 보관
- **내보내기** — 기본 화질, 사진에 저장, 확인 대화상자, 뷰티가 포함된 원탭 향상
- **iCloud 동기화** — 환경설정만(사진 파일은 동기화하지 않음)
- **안내** — 사용법, 위젯, 단축어, 기능 안내
- **개발자에게 후원** — 선택적 소모성 후원(기능은 무료로 유지)
