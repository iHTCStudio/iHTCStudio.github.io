**iPhoto(爱修图)**는 개인 정보 보호를 최우선으로 생각하는 iPhone 및 iPad용 **로컬 사진 스튜디오**입니다. 풀프레임 라이브 뷰티로 캡처하고, **3D LUT** 룩, **콜라주 2~9**, **Look 레시피** 및 ~**800+** 스티커로 편집하고, 공유하기 전에 메타데이터를 제거합니다. **계정 없음, 사진 업로드 없음, 광고 없음, 추적 없음**

**한눈에 보기:** 라이브러리 · 선택적 캡처 · 설정 · 검색(iOS 18+) · 55개의 3D LUT 필터 · 콜라주 2~9 · 레시피 보기 · ~800개 이상의 스티커 · 원터치 강화 · 자르기 교정 · 나란히 비교 · 프레임 · 개인정보 내보내기 · 홈 및 잠금 위젯 · 6개의 앱 아이콘 · Siri, 단축키 및 `iphoto://` · 선택적 iCloud 기본 설정 동기화.

> iPhoto는 독립적인 앱이며 **Apple Inc.와 제휴되어 있지 않습니다**

## 1부 — 첫 실행 및 탭

1. [App Store](https://apps.apple.com/app/id6787360978)에서 다운로드하고 **iPhoto**를 엽니다.
2. 짧은 **환영 가이드**를 작성하세요(나중에 **설정 → 기능 가이드**에서 다시 재생).
3. 메시지가 표시되면 **카메라**(캡처용) 및 **사진**(가져오기/선택적 저장용)을 허용합니다.
4. 가이드 끝부분에서 **실행 탭**을 선택하거나 나중에 설정에서 **캡처** 또는 **라이브러리**를 선택하세요.

로그인하지 않아도 즉시 준비가 완료됩니다.

| 탭 | 기능 |
|-----|----------------|
| **도서관** | 가져오기, 찾아보기, 검색, 다중 선택, 편집기 열기 |
| **캡처** | 뷰티 및 필터가 포함된 라이브 카메라 - 사용하지 않는 경우 설정에서 이 탭을 숨깁니다. |
| **설정** | 모양, 아이콘, 캡처, 내보내기, 가이드 |
| **검색** | iOS 18+ — 프로젝트, 필터 및 편집 도구 검색 |

## 2부 - 라이브러리

- **사진**에서 가져오거나 Capture에서 촬영하세요.
- **그리드/목록** 전환; 설정에서 열을 조정하세요.
- **모두 · 편집됨 · 캡처됨 · 가져옴 · 즐겨찾기**로 필터링; 최신순, 가장 오래된순 또는 이름순으로 정렬합니다.
- 일괄 공유, 사진에 저장, 즐겨찾기 또는 삭제를 위해 **선택**하세요.
- 비파괴 편집기를 열려면 항목을 탭하세요. **원본 파일은 가져온 프로젝트에 대해 유지**됩니다.

---

## 3부 - 라이브 뷰티로 촬영하기

1. **캡처**를 엽니다(또는 숨겨진 경우 설정에서 활성화).
2. **뷰티**를 전환합니다. **양**과 매끈함, 미백, 슬림한 얼굴, 눈, 치아, 블러셔, 립스틱을 미세 조정하세요.
3. 선택 사항: 플래시, 카운트다운, 그리드, 전면 거울, 라이브 **필터**(즐겨찾기, 강도 슬라이더).
4. 뷰티 또는 필터가 켜져 있으면 미리보기에 얼굴 오버레이뿐만 아니라 **전체 처리된 프레임**이 표시됩니다.
5. 셔터를 탭하세요. 해당 룩은 저장된 원본에 **한 번** 적용되므로 편집자는 이를 두 번 적용하지 않습니다.
6. 설정: 뷰티 레시피, JPEG/HEVC, 굽지 않은 네거티브 유지, 촬영 후 발생하는 상황을 기억합니다.

## 4부 - 비파괴 편집기

프로젝트를 엽니다. 하단에 있는 도구:

| 도구 | 당신이 할 수 있는 일 |
|------|-----------------|
| **조정** | 노출, 대비, 화이트 밸런스 등 - **원터치 강화**(기기 내) |
| **필터** | **55** 자체 제작 **3D LUT**는 강렬함과 즐겨찾기가 포함된 10가지 제품군을 살펴봅니다. |
| **외모** | **Look 레시피**(필터 + 톤 + 뷰티 + 프레임)를 저장하고 다시 적용하세요. 라이브러리에서 일괄 적용 |
| **콜라주** | **2~9**장 사진 다중 선택 → 콜라주 스튜디오(레이아웃, 간격, 배경) |
| **뷰티** | 여러 얼굴이 발견된 경우 사전 설정 + 얼굴별 컨트롤 |
| **자르기** | 비율, 회전, 뒤집기 및 **직선화(−45°…45°)** |
| **효과** | 원탭 스타일(부드러움/필름/굵게) 및 배경 흐림 |
| **프레임** | 5개 그룹으로 구성된 ~30프레임; 두께와 10가지 컬러의 매트 |
| **스티커** | 표정, 모양, 마크, 계절, 여행, 음식 등 다양한 스티커 ~**800개 이상** |
| **텍스트** | 최종 이미지로 렌더링되는 캡션 |
| **개인정보 보호** | EXIF, GPS 및 장치 메타데이터 제거 |

- 나란히 있는 미리보기를 **탭**하세요 **원본 | 후** 비교; **길게** 원본을 플래시하세요.
- Beauty는 **온디바이스 비전**을 사용합니다. 랜드마크는 휴대전화에서 절대 떠나지 않습니다.
- **모든 얼굴** 또는 단일 얼굴을 선택하여 매개변수를 독립적으로 다이얼합니다.
- 선택 사항: **한 번의 탭으로 강화하면 가벼운 아름다움이 포함됩니다**(부드러움 + 쿨 브라이트만 해당 - 설정).

## 5부 - 수출 및 개인정보 보호

1. 내보내기를 누르고 **원본 / 높음 / 중간 / 낮음**을 선택하세요.
2. 선택적으로 **사진에 저장**.
3. 안전 확인을 원할 경우 **내보내기 전 확인**을 활성화하세요.
4. 여행 사진이나 인물 사진을 공유하기 전에 **스트립 메타데이터**를 켜세요.

사진은 앱 샌드박스(및 선택적 사진 앨범)에 유지됩니다. 분석을 위해 iPhoto가 **절대 업로드하지 않습니다**.

## 6부 — 위젯, 아이콘 및 바로가기

### 위젯

**홈 화면(4):** 빠른 캡처 · 최근 프로젝트 · 라이브러리 통계 · 일일 팁.

**잠금 화면(2):** 빠른 캡처 · 최근 프로젝트.

iOS 위젯 갤러리에서 추가하세요. **설정 → 위젯 가이드**를 참조하세요.

### 앱 아이콘

**설정 → 모양 → 앱 아이콘** — 기본값 + **프레임, 필름, 렌즈, 블룸, 일몰**.

### Siri 및 단축키

캡처를 열고 라이브러리를 열거나 사진을 가져옵니다. 전체 목록: [바로가기 링크](url-scheme).

### 딥링크

`iphoto://capture`, `iphoto://library`, `iphoto://import`, `iphoto://search` 등. [바로가기 링크](url-scheme)를 참조하세요.

## 7부 - 알아두면 좋은 설정

- **외관** — 밝음/어두움/시스템; 앱 아이콘; 위젯은 테마를 따를 수 있습니다
- **언어** — 영어 · 简体中文 · 繁體中文
- **캡처** — 캡처 탭 표시/숨기기, 탭 시작, 그리드, 전면 미러, 아름다움 기억, 인코딩, 네거티브 유지
- **내보내기** — 기본 품질, 사진에 저장, 대화 상자 확인, 원터치로 아름다움 향상
- **iCloud 동기화** — 환경설정만 해당(사진 파일은 해당 안 됨)
- **가이드** — 사용법, 위젯, 단축키, 기능 가이드
- **팁 개발자** — 선택적 소모품 팁(기능은 무료로 유지됨)
