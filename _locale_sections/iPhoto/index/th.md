**iPhoto (爱修上)** คือ **สตูดิโอถ่ายภาพในพื้นที่** ที่เน้นความเป็นส่วนตัวสำหรับ iPhone และ iPad ถ่ายภาพด้วยความงามแบบสดฟูลเฟรม ตัดต่อด้วยลุค **3D LUT**, **คอลลาจ 2–9**, **สูตรอาหาร** และสติกเกอร์ ~**800+** ลบข้อมูลเมตาก่อนแชร์ — **ไม่มีบัญชี ไม่มีการอัพโหลดรูปภาพ ไม่มีโฆษณา ไม่มีการติดตาม**

**ข้อมูลโดยสรุป:** ไลบรารี · การจับภาพที่เป็นตัวเลือก · การตั้งค่า · ค้นหา (iOS 18+) · ฟิลเตอร์ 3D LUT 55 ตัว · ภาพต่อกัน 2–9 · ดูสูตรอาหาร · สติกเกอร์มากกว่า 800+ อัน · ปรับปรุงด้วยการแตะเพียงครั้งเดียว · ครอบตัดให้ตรง · เปรียบเทียบแบบเคียงข้างกัน · เฟรม · ส่งออกความเป็นส่วนตัว · วิดเจ็ตหน้าแรกและล็อค · ไอคอนแอป 6 รายการ · Siri, ทางลัด & `iphoto://` · การซิงค์การตั้งค่าเสริม iCloud

> iPhoto เป็นแอปอิสระและ **ไม่มีส่วนเกี่ยวข้องกับ Apple Inc.**

## ส่วนที่ 1 — การเปิดตัวครั้งแรกและแท็บ

1. ดาวน์โหลดจาก [App Store](https://apps.apple.com/app/id6787360978) และเปิด **iPhoto**
2. กรอก **คำแนะนำต้อนรับ** สั้นๆ ให้ครบถ้วน (เล่นซ้ำในภายหลังใน **การตั้งค่า → คำแนะนำคุณสมบัติ**)
3. เมื่อได้รับแจ้ง ให้อนุญาต **กล้อง** (สำหรับการจับภาพ) และ **รูปภาพ** (สำหรับการนำเข้า / บันทึกเพิ่มเติม)
4. เลือก **แท็บเปิดตัว** ที่ท้ายคำแนะนำ หรือหลังจากนั้นในการตั้งค่า: **จับภาพ** หรือ **คลัง**

ไม่มีการลงชื่อเข้าใช้ คุณพร้อมทันที

| แท็บ | มันทำอะไร |
|-----|----------------|
| **ห้องสมุด** | นำเข้า เรียกดู ค้นหา เลือกหลายรายการ เปิดตัวแก้ไข |
| **จับ** | กล้องถ่ายทอดสดพร้อมความงามและฟิลเตอร์ — ซ่อนแท็บนี้ในการตั้งค่าหากไม่ได้ใช้ |
| **การตั้งค่า** | ลักษณะที่ปรากฏ ไอคอน การจับภาพ การส่งออก คำแนะนำ |
| **ค้นหา** | iOS 18+ — ค้นหาโปรเจ็กต์ ตัวกรอง และเครื่องมือแก้ไข |

## ส่วนที่ 2 – ห้องสมุด

- นำเข้าจาก **รูปภาพ** หรือถ่ายภาพใน Capture
- สลับ **ตาราง / รายการ**; ปรับคอลัมน์ในการตั้งค่า
- กรองตาม **ทั้งหมด · แก้ไขแล้ว · บันทึกแล้ว · นำเข้า · รายการโปรด**; จัดเรียงตามใหม่ที่สุด เก่าที่สุด หรือชื่อ
- **เลือก** สำหรับการแชร์เป็นชุด บันทึกลงในรูปภาพ รายการโปรด หรือลบ
- แตะรายการใดก็ได้เพื่อเปิดตัวแก้ไขแบบไม่ทำลาย **ไฟล์ต้นฉบับยังคงอยู่** สำหรับโครงการที่นำเข้า

## ตอนที่ 3 — ถ่ายภาพด้วย Live Beauty

1. เปิด **จับภาพ** (หรือเปิดใช้งานในการตั้งค่าหากซ่อนไว้)
2. สลับ **ความงาม** ปรับแต่ง **จำนวน** บวกกับความเรียบเนียน ขาวขึ้น หน้าเรียว ดวงตา ฟัน บลัชออน ลิปสติก
3. ตัวเลือกเสริม: แฟลช, นับถอยหลัง, ตาราง, กระจกหน้า, **ฟิลเตอร์** แบบสด (รายการโปรด; แถบเลื่อนความเข้ม)
4. เมื่อเปิดบิวตี้หรือฟิลเตอร์ การแสดงตัวอย่างจะแสดง **เฟรมที่ประมวลผลแบบเต็ม** — ไม่ใช่แค่การซ้อนทับใบหน้า
5. แตะชัตเตอร์ รูปลักษณ์จะถูก **อบหนึ่งครั้ง** ลงในต้นฉบับที่บันทึกไว้ ดังนั้นโปรแกรมแก้ไขจะไม่ใช้ซ้ำอีกครั้ง
6. การตั้งค่า: จำสูตรความงาม, JPEG/HEVC, เก็บค่าเนกาทีฟที่ยังไม่ได้อบ และสิ่งที่เกิดขึ้นหลังจากช็อต

## ส่วนที่ 4 — ตัวแก้ไขแบบไม่ทำลาย

เปิดโครงการอะไรก็ได้ เครื่องมือด้านล่าง:

| เครื่องมือ | สิ่งที่คุณสามารถทำได้ |
|------|-----------------|
| **ปรับ** | ค่าแสง คอนทราสต์ สมดุลสีขาว และอื่นๆ อีกมากมาย — พร้อม **การปรับปรุงด้วยการแตะเพียงครั้งเดียว** (บนอุปกรณ์) |
| **ตัวกรอง** | **55** แต่งเอง **3D LUT** มี 10 ตระกูล พร้อมด้วยความเข้มข้นและรายการโปรด |
| **รูปลักษณ์** | บันทึกและสมัครใหม่ **ดูสูตร** (ฟิลเตอร์ + โทนสี + ความงาม + กรอบ); ใช้เป็นกลุ่มจากห้องสมุด |
| **คอลลาจ** | รูปภาพ **2–9** แบบเลือกได้หลายรายการ → สตูดิโอภาพต่อกัน (เลย์เอาต์ ช่องว่าง พื้นหลัง) |
| **ความงาม** | ค่าที่ตั้งล่วงหน้า + การควบคุมต่อใบหน้าเมื่อพบหลายใบหน้า |
| **ครอบตัด** | อัตราส่วน หมุน พลิก และ **ยืดให้ตรง (−45°…45°)** |
| **ผลกระทบ** | สไตล์ด้วยการแตะเพียงครั้งเดียว (นุ่มนวล / ฟิล์ม / ตัวหนา) และเบลอพื้นหลัง |
| **เฟรม** | ~30 เฟรมในห้ากลุ่ม; ความหนาและเนื้อแมตต์ 10 สี |
| **สติ๊กเกอร์** | ~**800+** สติกเกอร์ที่มีทั้งสีหน้า รูปร่าง เครื่องหมาย ฤดูกาล การเดินทาง อาหาร และอื่นๆ |
| **ข้อความ** | คำบรรยายที่แสดงผลเป็นภาพสุดท้าย |
| **ความเป็นส่วนตัว** | ตัด EXIF, GPS และข้อมูลเมตาของอุปกรณ์ |

- **แตะ** ตัวอย่างเพื่อดูแบบเคียงข้างกัน **ต้นฉบับ | หลังจาก** เปรียบเทียบ; **กดค้างไว้** เพื่อแฟลชต้นฉบับ
- ความงามใช้ **การมองเห็นบนอุปกรณ์** — จุดสังเกตไม่เคยละสายตาจากโทรศัพท์ของคุณ
- เลือก **ใบหน้าทั้งหมด** หรือใบหน้าเดียวเพื่อหมุนพารามิเตอร์โดยแยกจากกัน
- ตัวเลือกเสริม: **การปรับปรุงด้วยการแตะเพียงครั้งเดียวจะรวมถึงความสวยงามของแสง** (การตั้งค่าที่นุ่มนวล + สว่างแบบเย็นเท่านั้น — การตั้งค่า)

## ส่วนที่ 5 — การส่งออกและความเป็นส่วนตัว

1. แตะส่งออกและเลือก **ดั้งเดิม / สูง / ปานกลาง / ต่ำ**
2. ทางเลือก **บันทึกลงในรูปภาพ**
3. เปิดใช้งาน **ยืนยันก่อนส่งออก** หากคุณต้องการการตรวจสอบความปลอดภัย
4. เปิด **Strip Metadata** ก่อนแชร์รูปภาพการเดินทางหรือภาพบุคคล

รูปภาพจะยังคงอยู่ในแซนด์บ็อกซ์ของแอพ (และอัลบั้มรูปภาพเสริม) — **ไม่เคยอัพโหลด** โดย iPhoto เพื่อการวิเคราะห์

## ส่วนที่ 6 — วิดเจ็ต ไอคอน และทางลัด

### วิดเจ็ต

**หน้าจอหลัก (4):** จับภาพด่วน · โปรเจ็กต์ล่าสุด · สถิติห้องสมุด · เคล็ดลับรายวัน

**ล็อคหน้าจอ (2):** จับภาพด่วน · โปรเจ็กต์ล่าสุด

เพิ่มจากแกลเลอรีวิดเจ็ต iOS โปรดดู **การตั้งค่า → คู่มือวิดเจ็ต**

### ไอคอนแอพ

**การตั้งค่า → ลักษณะ → ไอคอนแอป** — ค่าเริ่มต้นบวกด้วย **กรอบ ฟิล์ม เลนส์ บาน พระอาทิตย์ตก**

### สิริและทางลัด

เปิด Capture เปิด Library หรือนำเข้ารูปภาพ รายการทั้งหมด: [ลิงก์ทางลัด](url-scheme)

### ลิงก์ลึก

`iphoto://capture`, `iphoto://library`, `iphoto://import`, `iphoto://search` และอื่นๆ ดู [ลิงก์ทางลัด](url-scheme)

## ตอนที่ 7 — การตั้งค่าที่ควรรู้

- **ลักษณะที่ปรากฏ** — สว่าง / มืด / ระบบ; ไอคอนแอพ; วิดเจ็ตสามารถติดตามธีมได้
- **ภาษา** — อังกฤษ · 简体中文 · 繁體中文
- **จับภาพ** — แสดง/ซ่อนแท็บจับภาพ แท็บเรียกใช้ ตาราง กระจกหน้า จดจำความงาม เข้ารหัส เก็บค่าลบ
- **ส่งออก** — คุณภาพเริ่มต้น บันทึกลงในรูปภาพ ยืนยันกล่องโต้ตอบ ปรับปรุงด้วยความสวยงามด้วยการแตะเพียงครั้งเดียว
- **iCloud Sync** — การตั้งค่าเท่านั้น (ไม่ใช่ไฟล์รูปภาพ)
- **คำแนะนำ** — การใช้งาน วิดเจ็ต ทางลัด คู่มือคุณสมบัติ
- **นักพัฒนาทิป** — ทิปเสริมแบบสิ้นเปลือง (ฟีเจอร์ใช้งานได้ฟรี)
