iSongCi (爱宋词 / 愛宋詞) разработана студией iHTC Studio.

## Кратко

**Данные не собираются (Data Not Collected).** После установки iSongCi **не отправляет никаких исходящих сетевых запросов**. **Без учётной записи. Без рекламы. Без аналитических SDK.** Все данные о цы (песенная лирика эпохи Сун) хранятся локально. Необязательная **синхронизация через iCloud** для избранного, заметок, оформления, серии ежедневного чтения и видимости вкладок использует только **ваш личный iCloud**.

## Данные, хранящиеся на вашем устройстве

| Данные | Назначение |
|------|---------|
| База цы | 21 592 текста песенной лирики эпохи Сун, встроенных в приложение |
| Избранное | Произведения, отмеченные звёздочкой |
| Личные заметки | Заметки к отдельным произведениям (видны только вам) |
| Серия чтения | Ежедневная отметка о чтении и общее количество |
| Настройки | Тема, акцентный цвет, макет чтения, масштаб шрифта, видимость вкладок |
| Настройки уведомлений | Ежедневное напоминание о цы (только локальное планирование) |

## Синхронизация через iCloud

Необязательная синхронизация через хранилище «ключ — значение» iCloud: избранное, заметки, оформление (светлое/тёмное/системное), масштаб основного шрифта, видимость вкладок «Категории» и «Избранное», серия чтения. **Тексты цы никогда не загружаются** — они всегда остаются внутри пакета приложения.

## Разрешения

| Разрешение | Когда | Зачем |
|------------|------|-----|
| Уведомления | Ежедневное напоминание о цы | Только локальное планирование — без сервера |
| iCloud | Необязательная синхронизация | Синхронизация избранного, заметок и настроек |
| Медиатека (только добавление) | Сохранение карточек для публикации | Только запись — сохранение изображений карточек цы в «Фото» |

## Встроенные покупки

Необязательная поддержка разработчиков («чаевые») через Apple StoreKit (`com.iHTCboy.iSongCi.6`). Платёж полностью обрабатывается Apple; мы не получаем платёжные данные напрямую.
