iHTC Studio가 iSongCi(爱宋词 / 愛宋詞)를 개발했습니다.

## 요약

**수집하는 데이터 없음(Data Not Collected).** iSongCi는 설치 후 **외부 네트워크 요청을 전혀 보내지 않습니다**. **계정 없음. 광고 없음. 분석 SDK 없음.** 모든 사(詞) 데이터는 기기에 로컬로 저장됩니다. 즐겨찾기, 메모, 화면 모드, 연속 읽기 기록, 탭 표시 설정을 위한 선택형 **iCloud 동기화**는 **사용자의 개인 iCloud**만 사용합니다.

## 기기에 저장되는 데이터

| 데이터 | 용도 |
|------|---------|
| 사 데이터베이스 | 앱에 내장된 21,592편의 송사(宋詞) |
| 즐겨찾기 | 별표를 표시한 작품 |
| 비공개 메모 | 작품별 메모(본인만 볼 수 있음) |
| 연속 읽기 기록 | 매일 읽기 체크인 및 누적 횟수 |
| 환경설정 | 테마, 강조 색상, 읽기 레이아웃, 글꼴 배율, 탭 표시 설정 |
| 알림 설정 | 매일 사 알림(로컬 예약만 사용) |

## iCloud 동기화

iCloud 키-값 저장소를 통해 즐겨찾기, 메모, 화면 모드(라이트/다크/시스템), 본문 글꼴 배율, 카테고리/즐겨찾기 탭 표시 설정, 연속 읽기 기록을 선택적으로 동기화합니다. **사 본문은 절대 업로드되지 않으며** 항상 앱 번들 안에만 있습니다.

## 권한

| 권한 | 시점 | 이유 |
|------------|------|-----|
| 알림 | 매일 사 알림 | 로컬 예약만 사용 — 서버 없음 |
| iCloud | 선택형 동기화 | 즐겨찾기, 메모, 환경설정 동기화 |
| 사진 보관함(추가 전용) | 공유 카드 저장 시 | 쓰기 전용 — 사 카드 이미지를 사진에 저장 |

## 앱 내 구입

Apple StoreKit을 통한 선택형 팁 기능(`com.iHTCboy.iSongCi.6`)이 있습니다. 결제는 전적으로 Apple이 처리하며, 당사는 결제 정보를 직접 받지 않습니다.
