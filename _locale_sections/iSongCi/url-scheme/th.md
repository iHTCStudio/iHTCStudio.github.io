iSongCi รองรับลิงก์ทางลัด **`isongci://`**

## รูปแบบลิงก์


```
isongci://{host}?{params}
```


## การค้นพบงาน

| URL | เปิด |
|-----|-------|
| `isongci://poem?id=42` | รายละเอียดต่าง ๆ (เลขประจําตัว = ดัชนีในหมวดหมู่) |
| `isongci://author?id=12` | โพรไฟล์ผู้เขียน |
| `isongci://daily` | วันนี้ซี |
| `isongci://random` | เซเรนดิพิ ติส — ซี ที่ รักษา อย่าง สุ่ม |
| `isongci://continue-reading` | อ่านต่อไป |
| `isongci://search?q=明月` | สืบค้นเมื่อ ○ |

## การนําทาง

| URL | เปิด |
|-----|-------|
| `isongci://home` | แท็บหน้าแรก |
| `isongci://category` | แท็บสําหรับเรียกดู |
| `isongci://favorites` | แท็บโปรด |
| `isongci://settings` | แท็บการตั้งค่า |

| URL | เปิด |

| `isongci://usage-guide` | คู่มือการใช้งาน |
| `isongci://widget-guide` | คู่มือวิดเจ็ต |
| `isongci://shortcuts-guide` | แป้นพิมพ์ลัด & Siri |

## ปุ่มพิมพ์ลัดแบบ Siri

3 App Intents เรือที่มีแอพ:

| Intent | วลีตัวอย่าง |
|--------|----------------|
| Open Today's Ci | "วันนี้ Ci in ISongCi" |
| Random Ci | Serendiity in ISongCi". |
| Search Ci | "ค้นหาใน ISongCi" (ด้วยคําสําคัญ) |

ใช้ใน~plooks ~ อัตโนมัติ — e.g. open c. BAR เช้าทุก ๆ เช้า หลังจากสัญญาณเตือนของคุณ
