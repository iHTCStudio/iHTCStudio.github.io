iSongCi는 **`isongci://`** 바로가기 링크를 지원합니다.

## 링크 형식


```
isongci://{host}?{params}
```


## 작품 및 발견

| URL | 열리는 화면 |
|-----|-------|
| `isongci://poem?id=42` | Ci detail (poem ID = 카탈로그 인덱스) |
| `isongci://author?id=12` | 저자 프로필 |
| `isongci://daily` | 오늘의 Ci |
| `isongci://random` | Serendipity — 무작위 curated 과학 |
| `isongci://continue-reading` | 계속 읽기 |
| `isongci://search?q=明月` | 明月에 대한 검색 |

## - 연혁

| URL | 열리는 화면 |
|-----|-------|
| `isongci://home` | 홈 탭 |
| `isongci://category` | 비밀번호 |
| `isongci://favorites` | 즐겨찾기 탭 |
| `isongci://settings` | 설정 탭 |

## 가이드 & 피드백

| URL | 열리는 화면 |
|-----|-------|
| `isongci://usage-guide` | 사용 가이드 |
| `isongci://widget-guide` | 위젯 가이드 |
| `isongci://shortcuts-guide` | Shortcuts & Siri 가이드 |
| `isongci://home-shortcuts` | 홈 화면 빠른 작업 |
| `isongci://feature-guide` | Replay 환영 가이드 |
| `isongci://feedback` | 피드백 이메일 |
| `isongci://in-app-review` | In-app 리뷰 |

## Siri 및 단축키

앱을 가진 3개의 App Intents 배:

| Intent | 예제 구문 |
|--------|----------------|
| Open Today's Ci | "오늘의 ci에서 iSongCi" |
| Random Ci | "iSongCi의 보증" |
| Search Ci | "Search in iSongCi" (키워드 포함) |

**Shortcuts** 오토메이션 - 예. 오픈 `isongci://` 알람 후 매일 아침.
