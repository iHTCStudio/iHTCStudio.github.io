iSongCi поддерживает **`isongci://`** — ссылки-ярлыки.

## Формат ссылки


```
isongci://{host}?{params}
```


## Работы и открытия

| URL | Открывает |
|-----|-------|
| `isongci://poem?id=42` | Ci Detail (поэма ID = индекс в каталоге) |
| `isongci://author?id=12` | Авторский профиль |
| `isongci://daily` | Сегодняшний Ci |
| `isongci://random` | Serendipity — случайный куратор ci |
| `isongci://continue-reading` | Continue reading |
| `isongci://search?q=明月` | Поиск по |

## Навигация

| URL | Открывает |
|-----|-------|
| `isongci://home` | Вкладка «Главная» |
| `isongci://category` | Просмотреть вкладку |
| `isongci://favorites` | Любимая вкладка |
| `isongci://settings` | Настройка вкладки |

## Руководства и отзывы

| URL | Открывает |
|-----|-------|
| `isongci://usage-guide` | Руководство по использованию |
| `isongci://widget-guide` | Руководство по виджетам |
| `isongci://shortcuts-guide` | Короткие пути и Siri Guide |
| `isongci://home-shortcuts` | Домой Экран Быстрые действия |
| `isongci://feature-guide` | Обсуждение Welcome Guide |
| `isongci://feedback` | Письмо с отзывом |
| `isongci://in-app-review` | Обзор в приложении |

## Siri и Shortcuts

Три App Intents отправляются с приложением:

| Intent | Пример фразы |
|--------|----------------|
| Open Today's Ci | «Сегодняшние ци в iSongCi» |
| Random Ci | Серендипит в iSongCi |
| Search Ci | «Поиск в iSongCi» (с ключевым словом) |

Используйте **Shortcuts** автоматизацию — например, открывайте `isongci://` каждое утро после сигнализации.
