iSongCi prend en charge les liens **`isongci://`**.

## Format de lien


```
isongci://{host}?{params}
```


## Travaux et découverte

| URL | Ouvre |
|-----|-------|
| `isongci://poem?id=42` | Ci détail (poem ID = index dans le catalogue) |
| `isongci://author?id=12` | Profil de l'auteur |
| `isongci://daily` | Aujourd'hui Ci |
| `isongci://random` | Serendipité — randomisée |
| `isongci://continue-reading` | Continuer la lecture |
| `isongci://search?q=明月` | Rechercher |

## Navigation

| URL | Ouvre |
|-----|-------|
| `isongci://home` | Onglet Accueil |
| `isongci://category` | Parcourir l'onglet |
| `isongci://favorites` | Onglet Favoris |
| `isongci://settings` | Onglet Paramètres |

## Guides et commentaires

| URL | Ouvre |
|-----|-------|
| `isongci://usage-guide` | Guide d'utilisation |
| `isongci://widget-guide` | Guide des widgets |
| `isongci://shortcuts-guide` | Raccourcis & Guide Siri |
| `isongci://home-shortcuts` | Actions rapides de l'écran d'accueil |
| `isongci://feature-guide` | Rejouer le guide de bienvenue |
| `isongci://feedback` | E-mail de commentaires |
| `isongci://in-app-review` | Examen en application |

## Siri & raccourcis

Trois App Intents sont livrés avec l'application:

| Intent | Exemple de phrase |
|--------|----------------|
| Open Today's Ci | "Les ci d'aujourd'hui en iSongCi" |
| Random Ci | "Serendipity in iSongCi" |
| Search Ci | "Recherche dans iSongCi" (avec mot clé) |

Utilisez les automatismes ** Raccourcis**, p.ex. ouvert chaque matin après votre alarme.
