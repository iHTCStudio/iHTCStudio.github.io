iSongCi は **`isongci://`** ショートカットリンクに対応しています。

## リンク形式


```
isongci://{host}?{params}
```


## 作品と発見

| URL | 開く画面 |
|-----|-------|
| `isongci://poem?id=42` | Ci の細部(poem ID = カタログの索引) |
| `isongci://author?id=12` | 著者プロフィール |
| `isongci://daily` | 今日のCi |
| `isongci://random` | セレンディピティ — ランダムキュレーション CI |
| `isongci://continue-reading` | 続きを読む |
| `isongci://search?q=明月` | 明月検索 |

## ナビゲーション

## シリとショートカット

3つのアプリはアプリで出荷します。

| Intent | 例句 |
|--------|----------------|
| Open Today's Ci | "Today's ci で iSongCi" |
| Random Ci | "iSongCiのSerendipity" |
| Search Ci | iSongCiで検索(キーワード付き) |

*Shortcuts** の自動化でご使用ください。例えば、アラーム後に毎日 `isongci://` を開きます。
