iSongCi, **`isongci://`** kısayol bağlantılarını destekler.

## Bağlantı biçimi


```
isongci://{host}?{params}
```


## Works & keşif

| URL | Açar |
|-----|-------|
| `isongci://poem?id=42` | Ci detay (poem ID = index in katalog) |
| `isongci://author?id=12` | Author Profil |
| `isongci://daily` | Bugünün Civarı |
| `isongci://random` | Serendipity - random curated ci |
| `isongci://continue-reading` | Okumaya devam et |
| `isongci://search?q=明月` | Arama için |

## Navigation

| URL | Açar |
|-----|-------|
| `isongci://home` | Ana sayfa sekmesi |
| `isongci://category` | Hafif sekme |
| `isongci://favorites` | Favoriler sekmesi |
| `isongci://settings` | Ayarlar sekmesi |

## Rehberler ve geri bildirimler

| URL | Açar |
|-----|-------|
| `isongci://usage-guide` | Kullanım kılavuzu |
| `isongci://widget-guide` | Widget kılavuzu |
| `isongci://shortcuts-guide` | Kısayollar & Siri rehberi |
| `isongci://home-shortcuts` | Home Ekran hızlı eylemleri |
| `isongci://feature-guide` | Replay welcome guide |
| `isongci://feedback` | Geri bildirim e-postası |
| `isongci://in-app-review` | In-app review |

## Siri & Shortcuts

Uygulama ile üç App niyet gemisi:

| Intent | Örnek cümle |
|--------|----------------|
| Open Today's Ci | "Bugün iSongCi'de" |
| Random Ci | "Serendipity in iSongCi" |
| Search Ci | "ISongCi'ye ara" ( anahtar kelime ile) |

**Shortcuts ** otomasyonlar - e.g. open `isongci://` her sabah alarmınızdan sonra.
