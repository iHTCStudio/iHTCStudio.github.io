iSongCi unterstützt **`isongci://`**-Verknüpfungslinks.

## Linkformat


```
isongci://{host}?{params}
```


## Werke und Entdeckungen

| URL | Öffnet |
|-----|-------|
| `isongci://poem?id=42` | Ci-Detail (Poem ID = Index im Katalog) |
| `isongci://author?id=12` | Autorenprofil |
| `isongci://daily` | Das heutige Ci |
| `isongci://random` | Serendipity — random curated ci |
| `isongci://continue-reading` | Weiterlesen |
| `isongci://search?q=明月` | Suche nach 明月 |

## Navigation

| URL | Öffnet |
|-----|-------|
| `isongci://home` | Register „Start“ |
| `isongci://category` | Tab Browsing |
| `isongci://favorites` | Favoriten-Tab |
| `isongci://settings` | Tab Einstellungen |

## Guides & Feedback

| URL | Öffnet |
|-----|-------|
| `isongci://usage-guide` | Nutzungsanleitung |
| `isongci://widget-guide` | Widget-Anleitung |
| `isongci://shortcuts-guide` | Shortcuts & Siri Guide |
| `isongci://home-shortcuts` | Home Bildschirm Schnelle Aktionen |
| `isongci://feature-guide` | Replay Welcome Guide |
| `isongci://feedback` | Feedback-E-Mail |
| `isongci://in-app-review` | In-App-Überprüfung |

## Siri & Shortcuts

Drei App Intents werden mit der App ausgeliefert:

| Intent | Beispielsatz |
|--------|----------------|
| Open Today's Ci | "Heute ci in iSongCi" |
| Random Ci | "Serendipity in iSongCi" |
| Search Ci | "Search in iSongCi" (mit Keyword) |

Verwenden Sie in **Shortcuts**-Automatisierungen - z. B. öffnen Sie `isongci://` jeden Morgen nach Ihrem Alarm.
