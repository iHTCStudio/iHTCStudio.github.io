iCouplet (爱对联 / 愛對聯) is an **immersive couplet learning studio** — not just another couplet list. **No account required.** All **3,369 curated couplets** (~102 authors, ~3,348 famous lines) are bundled on your device: **zero network requests** after install. **Recite** with karaoke-style highlighting; enjoy **vertical reading** (品联); practice in the **Study classroom** (fade, fill-blank, recitation check, quiz, and 对对子); and open a **contextual Daily Couplet** tied to solar terms, festivals, and seasons. Export **12-style share cards**, add **home / lock screen widgets**, optional **Reading Live Activity**, **Siri & Shortcuts**, and optional **iCloud** for favorites and progress. **No ads. No tracking. Data Not Collected.**

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id6793778879) and open **iCouplet**.
2. Complete the **6-page welcome guide** (brand → recite → vertical reading → study → system features → privacy).
3. You can **replay the feature guide** anytime: **Settings → Help → Feature Guide**.
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help** and cross-link each other.

### 2. Read today’s couplet on Home

1. Open the **Home** tab.
2. The **Daily Couplet** hero shows the title plus **upper and lower lines** (and a horizontal scroll title / 横批 when present).
3. Tap the hero to open the full detail page.
4. Optional: turn on **Daily Couplet notifications** in **Settings → Daily Couplet** (local scheduling only).

### 3. Browse & search

1. Open **Browse** (or Home search on older iOS builds).
2. Explore five sections: **form (体裁)**, **theme**, **author (联家)**, **famous lines**, and **collections**.
3. Use **Search** for titles, lines, and authors (Simplified / Traditional friendly).
4. Tap any couplet for detail; star it to **Favorites**.

### 4. Recite (诵联)

1. On a couplet detail page, tap **Recite**.
2. Follow **karaoke-style** highlighting (paragraph-level in detail; word-level in the Recitation studio).
3. Adjust **rate / pitch / voice** in **Settings → Reading & Recitation**.
4. Optional: enable **play in silent mode**, **background audio** (Now Playing / lock screen), and continuous playlists.
5. Deep link / Siri **recite** can open a couplet and start speaking automatically.

### 5. Vertical reading & share cards (品联 / 联卡)

1. On detail, switch **vertical / horizontal** layout; toggle **pinyin**, traditional characters, and centering as you like.
2. Open **Share Card** → pick among **12 styles** (classic / ink / vertical / cinnabar / …) and aspect ratios.
3. Preview, **save to Photos** (add-only permission), or share via the system sheet.
4. Optional: enable **Reading Live Activity** in Settings (iPhone; must start in foreground).

### 6. Study classroom (对课学堂)

1. Open **Study** from Home / deep link `icouplet://study` / Shortcuts.
2. Try modes: **Fade**, **Fill-blank**, **Recitation check**, **Quiz**.
3. Play **对对子** (pair matching game).
4. Track **4-level mastery** (none → familiar → known → mastered) and streaks.

### 7. Widgets, Siri & Home Screen shortcuts

1. Long-press Home Screen → **Edit Widgets** → add **Daily Couplet / Famous Line / Study Progress / Favorites**.
2. On Daily Couplet widgets, try **paper styles** (soft / solid red / plain) and **desktop refresh** to change today’s couplet (also syncs today’s notification text).
3. Ask **Siri** for today’s couplet, recite, random, favorites, or search.
4. Configure up to **4 Home Screen quick actions** in **Settings → Shortcuts**.

### 8. Privacy & sync

1. Everything works **fully offline** after install.
2. Optional **iCloud Sync** (Settings → Data) mirrors favorites, couplet lists, reading history, mastery, and streaks through **your private iCloud** — not iHTC Studio servers.
3. Tip the developer (optional StoreKit purchase) never unlocks paywalled content and never creates an account.

## Features

### Recitation Studio

- Karaoke-style **TTS** with highlighting
- Adjustable **speed**, **pitch**, and **voice**
- Optional **background audio** + lock-screen **Now Playing**
- **Continuous reading** queues from favorites / categories

### Vertical Immersive Reading

- Classical **vertical & horizontal** layouts
- **Pinyin**, traditional conversion, background / appreciation notes
- Line order always **横批 (if any) → upper → lower**
- **12 share-card styles** with multiple aspect ratios

### Study System

- Fade · fill-blank · recitation check · quiz
- **对对子** game mode
- **4-level mastery** + streaks

### Contextual Daily Couplet

- Solar terms · festivals · seasons (with same-day cache / desktop refresh)
- Local notifications (~60-day schedule window)
- Widgets + Control Center controls (iOS 18+)

### Content at a Glance

- **3,369 couplets** · **~102 authors** · **~3,348 famous lines** · ~3.9 MB bundled data
- Five browse sections; list / grid / card previews
- **100% offline** — no network, no account, no ads

### Widgets, Siri & System Integration

- Daily / famous / progress / favorites widgets (+ lock screen)
- Reading **Live Activity** (optional)
- Spotlight indexing; **`icouplet://` deep links** — see [Shortcut Links](url-scheme)
- Settings guides: Usage · Widget · Shortcuts · Feature Guide replay

### Privacy

- **Zero outbound network requests** after install (except optional Apple StoreKit for tipping, and system share targets you choose)
- **No account · no ads · no analytics SDK**
- Local App Group data + optional private iCloud KVS

## 保姆级上手教程

### 1. 第一次打开

1. 从 [App Store](https://apps.apple.com/app/id6793778879) 安装并打开**爱对联**。
2. 跟随 **6 页欢迎引导**（品牌欢迎 → 诵联 → 竖排品鉴 → 对课学堂 → 系统能力 → 隐私离线）。
3. 之后可随时：**设置 → 帮助 → 功能引导** 重播（不会改写「已完成引导」状态）。
4. **设置 → 帮助** 内还有互相跳转的**使用说明 / 小组件指南 / 快捷指南**，建议按需打开对照操作。

### 2. 在首页看「每日一联」

1. 打开**首页** Tab。
2. Hero 卡片会显示题名 + **上联与下联**（有横批时按「横批 → 上联 → 下联」展示）。
3. 点按 Hero 进入详情，可读赏析、开诵联、做对课、分享联卡。
4. 想每天提醒：到 **设置 → 每日一联** 打开通知并设定时间（**仅本机调度**，无服务器）。

### 3. 分类浏览与搜索

1. 打开**分类** Tab（若关闭了分类 Tab，可从首页入口或深链进入）。
2. 五分区：**体裁 / 主题 / 联家 / 名句 / 合集**。
3. 用**搜索**查题名、联句、联家（简繁均可）。
4. 点进任意一联收藏为星标，之后在**收藏** Tab 管理联单。

### 4. 诵联（怎么听、怎么连读）

1. 在联详情点**诵联**。
2. 详情页为段落高亮；**诵联工作台**可字级高亮，更适合跟读。
3. 到 **设置 → 阅读与诵联** 调节语速、音调、音色。
4. 建议按需打开：
   - **静音模式仍外放**（默认开）
   - **后台诵联**（锁屏 Now Playing；远程「下一首」仅播放列表有效）
   - **连续播放**
5. 也可用 Siri / 深链 `icouplet://recite` 或 `icouplet://recite?id=` 直接开读。

### 5. 竖排品鉴与联卡分享

1. 详情页切换竖排/横排，按喜好开拼音、繁体、居中。
2. 打开**联卡** → 选 **12** 种风格与比例（方形 / Story 等）。
3. 预览后可**存入相册**（仅「添加照片」权限）或系统分享。
4. iPhone 可在设置中打开**品联实时活动**（须在前台启动；离开详情会结束）。

### 6. 对课学堂（怎么练到掌握）

1. 从首页或 `icouplet://study` 进入对课。
2. 四种模式：**渐隐 / 填空 / 对课检测 / 测验**；另有**对对子**。
3. 行序与展示一致：有横批时横批为第 0 行。
4. 掌握度四级：未学习 → 已了解 → 已学会 → 已掌握；配合打卡连续天数。

### 7. 小组件、Siri、主屏快捷（一步步加到桌面）

1. 长按主屏幕空白处 → **编辑** → **添加小组件** → 搜索「爱对联」。
2. 可选：**每日一联 / 名句 / 学习进度 / 收藏**（含锁屏尺寸）。
3. 每日一联小组件可改**联纸样式**（淡彩 / 朱纸 / 素面），并用桌面「刷新」换联（会同步今日通知正文与落地 ID）。
4. 对 Siri 说今日一联、随机、诵联、收藏或搜索。
5. **设置 → 快捷**：最多勾选 **4** 个主屏长按快捷（默认含每日 / 随机 / 诵联 / 收藏）。

### 8. 数据、同步与隐私（放心用）

1. 对联库装在 App 内，**日常使用不需要网络**。
2. **设置 → 数据 → iCloud 同步**（可选）：同步收藏、联单、浏览记录、掌握度与打卡——走**你的私有 iCloud**，不经过我们的服务器。
3. 「打赏开发者」为可选内购，**不解锁功能、不创建账号**。
4. 完整说明见 [隐私政策](privacy)。

iCouplet（爱对联 / 愛對聯）は、単なる対聯リストではない、**没入型の対聯学習スタジオ**です。**アカウント不要。** 厳選した **3,369 件の対聯**（作者約 102 名、名句約 3,348 句）がすべて端末に同梱されており、インストール後の**ネットワークリクエストはゼロ**です。カラオケ風ハイライトで**朗誦**し、**縦書き閲読**（品联）を楽しみ、**学習教室**（フェード、穴埋め、朗誦チェック、クイズ、对对子）で練習し、二十四節気・祝祭日・季節に合わせた**文脈型の今日の対聯**を開けます。**12 スタイルの共有カード**の書き出し、**ホーム画面 / ロック画面のウィジェット**、任意の**閲読ライブアクティビティ**、**Siri とショートカット**、お気に入りと進捗用の任意の **iCloud** にも対応。**広告なし。トラッキングなし。データは収集されません。**

## はじめに（ステップごとの手順）

### 1. 初回起動

1. [App Store](https://apps.apple.com/app/id6793778879) からインストールし、**iCouplet** を開きます。
2. **6 ページのウェルカムガイド**（ブランド → 朗誦 → 縦書き閲読 → 学習 → システム機能 → プライバシー）を完了します。
3. 機能ガイドはいつでも**再表示**できます：**設定 → ヘルプ → 機能ガイド**。
4. アプリ内の**使い方 / ウィジェット / ショートカット**のガイドは**設定 → ヘルプ**にあり、相互にリンクしています。

### 2. ホームで今日の対聯を読む

1. **ホーム**タブを開きます。
2. **今日の対聯**のヒーロー表示に、題名と**上聯・下聯**（および、ある場合は横書きの題＝横批）が表示されます。
3. ヒーローをタップすると、詳細ページが開きます。
4. 任意：**設定 → 今日の対聯**で**今日の対聯の通知**をオンにします（ローカルでのスケジュールのみ）。

### 3. 閲覧と検索

1. **閲覧**を開きます（古い iOS ビルドではホームの検索）。
2. 5 つのセクションを見てみましょう：**体裁（形式）**、**テーマ**、**作者（联家）**、**名句**、**コレクション**。
3. **検索**で題名、句、作者を探せます（簡体字・繁体字のどちらでも可）。
4. 対聯をタップして詳細を表示し、スターを付けて**お気に入り**に追加します。

### 4. 朗誦（诵联）

1. 対聯の詳細ページで**朗誦**をタップします。
2. **カラオケ風**のハイライトに合わせます（詳細画面では段落単位、朗誦スタジオでは文字単位）。
3. **速度 / ピッチ / 音声**は**設定 → 閲読と朗誦**で調整できます。
4. 任意：**サイレントモードでの再生**、**バックグラウンドオーディオ**（再生中画面 / ロック画面）、連続再生リストを有効にできます。
5. ディープリンクや Siri の**朗誦**で、対聯を開いて自動的に読み上げを始めることもできます。

### 5. 縦書き閲読と共有カード（品联 / 联卡）

1. 詳細画面で**縦書き / 横書き**レイアウトを切り替え、**ピンイン**、繁体字、センタリングを好みに合わせて設定します。
2. **共有カード**を開き、**12 スタイル**（クラシック / 水墨 / 縦書き / 朱色 / …）と縦横比から選びます。
3. プレビューして、**写真に保存**（追加のみの権限）するか、システムの共有シートで共有します。
4. 任意：設定で**閲読ライブアクティビティ**を有効にします（iPhone。フォアグラウンドで開始する必要があります）。

### 6. 学習教室（对课学堂）

1. ホーム / ディープリンク `icouplet://study` / ショートカットから**学習**を開きます。
2. **フェード**、**穴埋め**、**朗誦チェック**、**クイズ**のモードを試します。
3. **对对子**（ペアを合わせるゲーム）で遊びます。
4. **4 段階の習熟度**（未習得 → なじみ → 知っている → 習得）と連続記録を確認します。

### 7. ウィジェット、Siri、ホーム画面のショートカット

1. ホーム画面を長押し → **ウィジェットを編集** → **今日の対聯 / 名句 / 学習の進捗 / お気に入り**を追加します。
2. 今日の対聯ウィジェットでは、**紙スタイル**（やわらか / 無地の赤 / 白地）と、今日の対聯を変える**デスクトップ更新**を試せます（今日の通知テキストも同期されます）。
3. **Siri** に、今日の対聯、朗誦、ランダム、お気に入り、検索を頼めます。
4. **設定 → ショートカット**で、最大 **4 件のホーム画面クイックアクション**を設定できます。

### 8. プライバシーと同期

1. インストール後は、すべてが**完全オフライン**で動作します。
2. 任意の **iCloud 同期**（設定 → データ）は、お気に入り、対聯リスト、閲読履歴、習熟度、連続記録を、iHTC Studio のサーバーではなく**お客様のプライベートな iCloud** 経由でミラーリングします。
3. 開発者への投げ銭（任意の StoreKit 購入）で有料コンテンツが解放されることはなく、アカウントが作られることもありません。

iCouplet(爱对联 / 愛對聯)은 단순한 대련 목록이 아닌 **몰입형 대련 학습 스튜디오**입니다. **계정이 필요 없습니다.** 엄선한 **대련 3,369개**(작가 약 102명, 명구 약 3,348구)가 모두 기기에 내장되어 있어 설치 후 **네트워크 요청이 전혀 없습니다**. 노래방 스타일 하이라이트로 **낭송**하고, **세로쓰기 읽기**(品联)를 즐기고, **학습 교실**(페이드, 빈칸 채우기, 낭송 확인, 퀴즈, 对对子)에서 연습하며, 절기·명절·계절에 맞춘 **상황별 오늘의 대련**을 열어 보세요. **12가지 스타일의 공유 카드** 내보내기, **홈 / 잠금 화면 위젯**, 선택적 **읽기 실시간 현황(Live Activity)**, **Siri 및 단축어**, 즐겨찾기와 진행 상황을 위한 선택적 **iCloud**도 지원합니다. **광고 없음. 추적 없음. 수집되는 데이터 없음.**

## 시작하기(단계별)

### 1. 처음 실행

1. [App Store](https://apps.apple.com/app/id6793778879)에서 설치하고 **iCouplet**을 엽니다.
2. **6페이지 시작 가이드**(브랜드 → 낭송 → 세로쓰기 읽기 → 학습 → 시스템 기능 → 개인정보 보호)를 완료하세요.
3. 기능 가이드는 언제든 **다시 볼 수 있습니다**: **설정 → 도움말 → 기능 가이드**.
4. 앱 내 **사용법 / 위젯 / 단축어** 가이드는 **설정 → 도움말**에 있으며 서로 연결되어 있습니다.

### 2. 홈에서 오늘의 대련 읽기

1. **홈** 탭을 엽니다.
2. **오늘의 대련** 히어로에 제목과 **상련·하련**(그리고 있으면 가로 제목인 横批)이 표시됩니다.
3. 히어로를 탭하면 전체 상세 페이지가 열립니다.
4. 선택: **설정 → 오늘의 대련**에서 **오늘의 대련 알림**을 켜세요(로컬 예약만 사용).

### 3. 탐색 및 검색

1. **탐색**을 엽니다(이전 iOS 빌드에서는 홈 검색).
2. 다섯 가지 섹션을 둘러보세요: **형식(体裁)**, **주제**, **작가(联家)**, **명구**, **모음집**.
3. **검색**으로 제목, 구절, 작가를 찾을 수 있습니다(간체 / 번체 모두 지원).
4. 대련을 탭해 상세 정보를 보고, 별표를 눌러 **즐겨찾기**에 추가하세요.

### 4. 낭송(诵联)

1. 대련 상세 페이지에서 **낭송**을 탭합니다.
2. **노래방 스타일** 하이라이트를 따라가세요(상세 화면은 문단 단위, 낭송 스튜디오는 글자 단위).
3. **속도 / 음높이 / 음성**은 **설정 → 읽기 및 낭송**에서 조절합니다.
4. 선택: **무음 모드 재생**, **백그라운드 오디오**(지금 재생 중 / 잠금 화면), 연속 재생 목록을 켤 수 있습니다.
5. 딥링크나 Siri의 **낭송**으로 대련을 열고 자동으로 읽기를 시작할 수도 있습니다.

### 5. 세로쓰기 읽기와 공유 카드(品联 / 联卡)

1. 상세 화면에서 **세로 / 가로** 레이아웃을 전환하고, **병음**, 번체 글자, 가운데 정렬을 원하는 대로 설정하세요.
2. **공유 카드**를 열어 **12가지 스타일**(클래식 / 수묵 / 세로쓰기 / 주홍 / …)과 화면 비율 중에서 고릅니다.
3. 미리 보고 **사진에 저장**(추가 전용 권한)하거나 시스템 공유 시트로 공유하세요.
4. 선택: 설정에서 **읽기 실시간 현황**을 켜세요(iPhone, 포그라운드에서 시작해야 함).

### 6. 학습 교실(对课学堂)

1. 홈 / 딥링크 `icouplet://study` / 단축어에서 **학습**을 엽니다.
2. **페이드**, **빈칸 채우기**, **낭송 확인**, **퀴즈** 모드를 시도해 보세요.
3. **对对子**(짝 맞추기 게임)를 해 보세요.
4. **4단계 숙달도**(미학습 → 익숙함 → 알고 있음 → 숙달)와 연속 기록을 확인하세요.

### 7. 위젯, Siri, 홈 화면 바로가기

1. 홈 화면을 길게 누르기 → **위젯 편집** → **오늘의 대련 / 명구 / 학습 진행 상황 / 즐겨찾기**를 추가합니다.
2. 오늘의 대련 위젯에서 **종이 스타일**(부드러운 / 진한 빨강 / 단색)과 오늘의 대련을 바꾸는 **데스크톱 새로 고침**을 사용해 보세요(오늘의 알림 문구도 함께 맞춰집니다).
3. **Siri**에게 오늘의 대련, 낭송, 무작위, 즐겨찾기, 검색을 요청해 보세요.
4. **설정 → 바로가기**에서 최대 **4개의 홈 화면 빠른 동작**을 설정하세요.

### 8. 개인정보 보호와 동기화

1. 설치 후 모든 것이 **완전한 오프라인**으로 동작합니다.
2. 선택적 **iCloud 동기화**(설정 → 데이터)는 즐겨찾기, 대련 목록, 읽기 기록, 숙달도, 연속 기록을 iHTC Studio 서버가 아닌 **개인 iCloud**를 통해 미러링합니다.
3. 개발자 후원(선택적 StoreKit 구매)은 유료 콘텐츠를 잠금 해제하지 않으며 계정도 만들지 않습니다.

iCouplet (爱对联 / 愛對聯) — **студия для изучения парных надписей с эффектом погружения**, а не просто очередной список. **Учётная запись не нужна.** Все **3 369 отобранных парных надписей** (~102 автора, ~3 348 известных строк) встроены в ваше устройство: **ноль сетевых запросов** после установки. **Декламируйте** с подсветкой в стиле караоке; наслаждайтесь **вертикальным чтением** (品联); тренируйтесь в **учебном классе** (угасание, заполнение пропусков, проверка декламации, викторина и 对对子); и открывайте **надпись дня по контексту**, привязанную к сезонам солнечного календаря, праздникам и временам года. Экспортируйте **карточки для обмена в 12 стилях**, добавляйте **виджеты на экран «Домой» и экран блокировки**, необязательную **Live Activity для чтения**, **Siri и «Быстрые команды»** и необязательный **iCloud** для избранного и прогресса. **Без рекламы. Без отслеживания. Данные не собираются.**

## Первые шаги (по порядку)

### 1. Первый запуск

1. Установите из [App Store](https://apps.apple.com/app/id6793778879) и откройте **iCouplet**.
2. Пройдите **приветственное руководство из 6 страниц** (бренд → декламация → вертикальное чтение → обучение → системные функции → конфиденциальность).
3. **Повторно открыть руководство по функциям** можно в любой момент: **Настройки → Справка → Руководство по функциям**.
4. Встроенные руководства **«Использование» / «Виджеты» / «Быстрые команды»** находятся в **Настройки → Справка** и ссылаются друг на друга.

### 2. Читаем надпись дня на главном экране

1. Откройте вкладку **Главная**.
2. Блок **«Надпись дня»** показывает название, а также **верхнюю и нижнюю строки** (и горизонтальный заголовок / 横批, если он есть).
3. Нажмите на блок, чтобы открыть полную страницу.
4. По желанию: включите **уведомления «Надпись дня»** в **Настройки → Надпись дня** (только локальное планирование).

### 3. Просмотр и поиск

1. Откройте **Обзор** (или поиск на главном экране в старых версиях iOS).
2. Изучите пять разделов: **форма (体裁)**, **тема**, **автор (联家)**, **известные строки** и **коллекции**.
3. Используйте **Поиск** по названиям, строкам и авторам (с поддержкой упрощённых и традиционных иероглифов).
4. Нажмите на надпись для подробностей; отметьте её звёздочкой, чтобы добавить в **Избранное**.

### 4. Декламация (诵联)

1. На странице подробностей надписи нажмите **Декламировать**.
2. Следуйте за подсветкой **в стиле караоке** (по абзацам в подробном просмотре; по иероглифам в студии декламации).
3. Настройте **скорость / высоту тона / голос** в **Настройки → Чтение и декламация**.
4. По желанию: включите **воспроизведение в беззвучном режиме**, **фоновое аудио** (экран «Сейчас играет» / экран блокировки) и непрерывные плейлисты.
5. Глубокая ссылка или команда Siri **«декламировать»** могут открыть надпись и автоматически начать озвучивание.

### 5. Вертикальное чтение и карточки для обмена (品联 / 联卡)

1. На странице подробностей переключайте **вертикальную / горизонтальную** раскладку; включайте **пиньинь**, традиционные иероглифы и центрирование по желанию.
2. Откройте **Карточку для обмена** и выберите один из **12 стилей** (классика / тушь / вертикальный / киноварь / …) и соотношение сторон.
3. Просмотрите, **сохраните в «Фото»** (разрешение только на добавление) или поделитесь через системное меню.
4. По желанию: включите **Live Activity для чтения** в настройках (iPhone; запускать нужно на переднем плане).

### 6. Учебный класс (对课学堂)

1. Откройте **Обучение** с главного экрана / по глубокой ссылке `icouplet://study` / из «Быстрых команд».
2. Попробуйте режимы: **Угасание**, **Заполнение пропусков**, **Проверка декламации**, **Викторина**.
3. Сыграйте в **对对子** (игра на подбор пар).
4. Следите за **4 уровнями освоения** (нет → знакомо → известно → освоено) и сериями.

### 7. Виджеты, Siri и ярлыки на экране «Домой»

1. Долгое нажатие на экран «Домой» → **Изменить виджеты** → добавьте **«Надпись дня» / «Известная строка» / «Прогресс обучения» / «Избранное»**.
2. У виджетов «Надпись дня» попробуйте **стили бумаги** (мягкий / сплошной красный / простой) и **обновление на рабочем столе**, чтобы сменить сегодняшнюю надпись (текст сегодняшнего уведомления тоже синхронизируется).
3. Попросите **Siri** показать надпись дня, декламировать, случайную, избранное или выполнить поиск.
4. Настройте до **4 быстрых действий на экране «Домой»** в **Настройки → Быстрые команды**.

### 8. Конфиденциальность и синхронизация

1. После установки всё работает **полностью офлайн**.
2. Необязательная **синхронизация iCloud** (Настройки → Данные) отражает избранное, списки надписей, историю чтения, уровень освоения и серии через **ваш личный iCloud**, а не через серверы iHTC Studio.
3. Благодарность разработчику (необязательная покупка StoreKit) никогда не открывает платный контент и не создаёт учётную запись.

## Возможности

### Студия декламации

- **TTS** с подсветкой в стиле караоке
- Настраиваемые **скорость**, **высота тона** и **голос**
- Необязательное **фоновое аудио** + **«Сейчас играет»** на экране блокировки
- Очереди **непрерывного чтения** из избранного / категорий

### Вертикальное чтение с погружением

- Классические **вертикальная и горизонтальная** раскладки
- **Пиньинь**, преобразование в традиционные иероглифы, примечания о фоне / разбор
- Порядок строк всегда **横批 (если есть) → верхняя → нижняя**
- **12 стилей карточек для обмена** с несколькими соотношениями сторон

### Система обучения

- Угасание · заполнение пропусков · проверка декламации · викторина
- Игровой режим **对对子**
- **4 уровня освоения** + серии

### Надпись дня по контексту

- Сезоны солнечного календаря · праздники · времена года (с кэшем на день / обновлением на рабочем столе)
- Локальные уведомления (окно планирования ~60 дней)
- Виджеты + элементы Пункта управления (iOS 18+)

### Содержимое в цифрах

- **3 369 парных надписей** · **~102 автора** · **~3 348 известных строк** · ~3,9 МБ встроенных данных
- Пять разделов просмотра; предпросмотр в виде списка / сетки / карточек
- **100 % офлайн** — без сети, без учётной записи, без рекламы

### Виджеты, Siri и интеграция с системой

- Виджеты «Надпись дня» / «Известная строка» / «Прогресс» / «Избранное» (+ экран блокировки)
- **Live Activity** для чтения (необязательно)
- Индексация Spotlight; **глубокие ссылки `icouplet://`** — см. [Ссылки быстрых команд](url-scheme)
- Руководства в настройках: Использование · Виджеты · Быстрые команды · повтор руководства по функциям

### Конфиденциальность

- **Ноль исходящих сетевых запросов** после установки (кроме необязательного Apple StoreKit для благодарности и системных получателей в меню «Поделиться», которых вы выбираете)
- **Без учётной записи · без рекламы · без SDK аналитики**
- Локальные данные App Group + необязательный личный iCloud KVS

iCouplet (爱对联 / 愛對聯) คือ **สตูดิโอเรียนรู้คำคู่แบบดื่มด่ำ** ไม่ใช่แค่รายการคำคู่ทั่วไป **ไม่ต้องใช้บัญชี** **คำคู่ที่คัดสรรทั้ง 3,369 บท** (ผู้ประพันธ์ ~102 ท่าน ประโยคเด่น ~3,348 ประโยค) รวมอยู่ในอุปกรณ์ของคุณ: **ไม่มีคำขอผ่านเครือข่ายเลย** หลังติดตั้ง **ท่อง** พร้อมไฮไลต์สไตล์คาราโอเกะ เพลิดเพลินกับ **การอ่านแนวตั้ง** (品联) ฝึกใน **ห้องเรียนฝึกฝน** (ค่อย ๆ จางหาย เติมช่องว่าง ตรวจสอบการท่อง แบบทดสอบ และ 对对子) และเปิด **คำคู่ประจำวันตามบริบท** ที่ผูกกับฤดูกาลทางสุริยคติ เทศกาล และฤดูกาล ส่งออก **การ์ดแชร์ 12 สไตล์** เพิ่ม **วิดเจ็ตบนหน้าจอหลัก / หน้าจอล็อก** **Live Activity ขณะอ่าน** แบบเลือกใช้ **Siri และคำสั่งลัด** และ **iCloud** แบบเลือกใช้สำหรับรายการโปรดและความคืบหน้า **ไม่มีโฆษณา ไม่มีการติดตาม ไม่เก็บข้อมูล**

## เริ่มต้นใช้งาน (ทีละขั้นตอน)

### 1. เปิดแอปครั้งแรก

1. ติดตั้งจาก [App Store](https://apps.apple.com/app/id6793778879) แล้วเปิด **iCouplet**
2. ทำ **คู่มือต้อนรับ 6 หน้า** ให้จบ (แบรนด์ → การท่อง → การอ่านแนวตั้ง → การเรียน → ฟีเจอร์ของระบบ → ความเป็นส่วนตัว)
3. **เปิดดูคู่มือฟีเจอร์ซ้ำ** ได้ทุกเมื่อ: **การตั้งค่า → ความช่วยเหลือ → คู่มือฟีเจอร์**
4. คู่มือ **การใช้งาน / วิดเจ็ต / คำสั่งลัด** ในแอปอยู่ที่ **การตั้งค่า → ความช่วยเหลือ** และลิงก์ถึงกัน

### 2. อ่านคำคู่ประจำวันบนหน้าหลัก

1. เปิดแท็บ **หน้าหลัก**
2. ส่วนเด่น **คำคู่ประจำวัน** แสดงชื่อพร้อม **วรรคบนและวรรคล่าง** (และหัวเรื่องแนวนอน / 横批 หากมี)
3. แตะส่วนเด่นเพื่อเปิดหน้ารายละเอียดฉบับเต็ม
4. ไม่บังคับ: เปิด **การแจ้งเตือนคำคู่ประจำวัน** ที่ **การตั้งค่า → คำคู่ประจำวัน** (ตั้งเวลาในเครื่องเท่านั้น)

### 3. เรียกดูและค้นหา

1. เปิด **เรียกดู** (หรือการค้นหาบนหน้าหลักใน iOS รุ่นเก่า)
2. สำรวจห้าส่วน: **รูปแบบ (体裁)** **หัวข้อ** **ผู้ประพันธ์ (联家)** **ประโยคเด่น** และ **คอลเลกชัน**
3. ใช้ **ค้นหา** สำหรับชื่อเรื่อง ประโยค และผู้ประพันธ์ (รองรับทั้งอักษรจีนตัวย่อและตัวเต็ม)
4. แตะคำคู่ใดก็ได้เพื่อดูรายละเอียด ติดดาวเพื่อเพิ่มใน **รายการโปรด**

### 4. การท่อง (诵联)

1. ในหน้ารายละเอียดของคำคู่ แตะ **ท่อง**
2. ตามไฮไลต์ **สไตล์คาราโอเกะ** (ระดับย่อหน้าในหน้ารายละเอียด ระดับตัวอักษรในสตูดิโอการท่อง)
3. ปรับ **ความเร็ว / ระดับเสียง / เสียงพูด** ได้ที่ **การตั้งค่า → การอ่านและการท่อง**
4. ไม่บังคับ: เปิด **เล่นในโหมดเงียบ** **เสียงเบื้องหลัง** (กำลังเล่น / หน้าจอล็อก) และเพลย์ลิสต์ต่อเนื่อง
5. ลิงก์ลึกหรือ Siri **ท่อง** สามารถเปิดคำคู่และเริ่มอ่านออกเสียงโดยอัตโนมัติ

### 5. การอ่านแนวตั้งและการ์ดแชร์ (品联 / 联卡)

1. ในหน้ารายละเอียด สลับเค้าโครง **แนวตั้ง / แนวนอน** เปิดหรือปิด **พินอิน** อักษรตัวเต็ม และการจัดกึ่งกลางตามต้องการ
2. เปิด **การ์ดแชร์** → เลือกจาก **12 สไตล์** (คลาสสิก / หมึกจีน / แนวตั้ง / แดงชาด / …) และอัตราส่วนภาพ
3. ดูตัวอย่าง **บันทึกลงรูปภาพ** (สิทธิ์เพิ่มอย่างเดียว) หรือแชร์ผ่านชีตของระบบ
4. ไม่บังคับ: เปิด **Live Activity ขณะอ่าน** ในการตั้งค่า (iPhone ต้องเริ่มขณะแอปอยู่เบื้องหน้า)

### 6. ห้องเรียนฝึกฝน (对课学堂)

1. เปิด **เรียน** จากหน้าหลัก / ลิงก์ลึก `icouplet://study` / คำสั่งลัด
2. ลองโหมด: **ค่อย ๆ จางหาย** **เติมช่องว่าง** **ตรวจสอบการท่อง** **แบบทดสอบ**
3. เล่น **对对子** (เกมจับคู่)
4. ติดตาม **ระดับความชำนาญ 4 ระดับ** (ยังไม่เรียน → คุ้นเคย → รู้แล้ว → ชำนาญ) และสถิติต่อเนื่อง

### 7. วิดเจ็ต Siri และทางลัดบนหน้าจอหลัก

1. กดค้างที่หน้าจอหลัก → **แก้ไขวิดเจ็ต** → เพิ่ม **คำคู่ประจำวัน / ประโยคเด่น / ความคืบหน้าการเรียน / รายการโปรด**
2. บนวิดเจ็ตคำคู่ประจำวัน ลอง **สไตล์กระดาษ** (นุ่มนวล / แดงทึบ / เรียบ) และ **การรีเฟรชบนหน้าจอหลัก** เพื่อเปลี่ยนคำคู่ของวันนี้ (ข้อความแจ้งเตือนของวันนี้จะซิงค์ตามด้วย)
3. ขอให้ **Siri** บอกคำคู่ประจำวัน ท่อง สุ่ม รายการโปรด หรือค้นหา
4. กำหนด **การทำงานด่วนบนหน้าจอหลัก** ได้สูงสุด 4 รายการที่ **การตั้งค่า → ทางลัด**

### 8. ความเป็นส่วนตัวและการซิงค์

1. ทุกอย่างทำงาน **แบบออฟไลน์เต็มรูปแบบ** หลังติดตั้ง
2. **การซิงค์ iCloud** แบบเลือกใช้ (การตั้งค่า → ข้อมูล) จะทำสำเนารายการโปรด รายการคำคู่ ประวัติการอ่าน ระดับความชำนาญ และสถิติต่อเนื่อง ผ่าน **iCloud ส่วนตัวของคุณ** ไม่ใช่เซิร์ฟเวอร์ของ iHTC Studio
3. การให้ทิปนักพัฒนา (การซื้อ StoreKit แบบเลือกได้) ไม่ปลดล็อกเนื้อหาแบบเสียเงินและไม่สร้างบัญชี

## ฟีเจอร์

### สตูดิโอการท่อง

- **TTS** สไตล์คาราโอเกะพร้อมไฮไลต์
- ปรับ **ความเร็ว** **ระดับเสียง** และ **เสียงพูด** ได้

### การอ่านแนวตั้งแบบดื่มด่ำ

1. **Göz At**'ı açın (veya eski iOS sürümlerinde Ana Sayfa aramasını).
2. Beş bölümü keşfedin: **biçim (体裁)**, **tema**, **yazar (联家)**, **ünlü dizeler** ve **koleksiyonlar**.
3. Başlıklar, dizeler ve yazarlar için **Arama**'yı kullanın (Basitleştirilmiş / Geleneksel dostu).
4. Ayrıntı için bir beyite dokunun; **Favoriler**'e eklemek için yıldızlayın.

### 4. Seslendirme (诵联)

1. Bir beyit ayrıntı sayfasında **Seslendir**'e dokunun.
2. **Karaoke tarzı** vurguyu izleyin (ayrıntıda paragraf düzeyinde; Seslendirme stüdyosunda karakter düzeyinde).
3. **Ayarlar → Okuma ve Seslendirme** bölümünde **hız / perde / sesi** ayarlayın.
4. İsteğe bağlı: **sessiz modda oynatmayı**, **arka plan sesini** (Şimdi Çalıyor / kilit ekranı) ve sürekli oynatma listelerini etkinleştirin.
5. Derin bağlantı / Siri **seslendir** komutu bir beyiti açıp otomatik olarak okumaya başlayabilir.

### 5. Dikey okuma ve paylaşım kartları (品联 / 联卡)

1. Ayrıntıda **dikey / yatay** düzen arasında geçiş yapın; **pinyin**, geleneksel karakterler ve ortalamayı dilediğiniz gibi açıp kapatın.
2. **Paylaşım Kartı**'nı açın → **12 stil** (klasik / mürekkep / dikey / cinnabar / …) ve en-boy oranları arasından seçin.
3. Önizleyin, **Fotoğraflar'a kaydedin** (yalnızca ekleme izni) veya sistem sayfasıyla paylaşın.
4. İsteğe bağlı: Ayarlar'da **Okuma Canlı Etkinliği**'ni etkinleştirin (iPhone; ön planda başlatılmalıdır).

### 6. Çalışma sınıfı (对课学堂)

1. Ana Sayfa'dan / `icouplet://study` derin bağlantısından / Kısayollar'dan **Çalışma**'yı açın.
2. Modları deneyin: **Soldurma**, **Boşluk doldurma**, **Seslendirme kontrolü**, **Test**.
3. **对对子** (eşleştirme oyunu) oynayın.
4. **4 seviyeli ustalığı** (yok → tanıdık → biliyor → usta) ve serileri takip edin.

### 7. Widget'lar, Siri ve Ana Ekran kısayolları

1. Ana Ekran'a uzun basın → **Widget'ları Düzenle** → **Günün Beyiti / Ünlü Dize / Çalışma İlerlemesi / Favoriler** ekleyin.
2. Günün Beyiti widget'larında **kağıt stillerini** (yumuşak / düz kırmızı / sade) ve bugünün beytini değiştirmek için **masaüstü yenilemeyi** deneyin (bugünün bildirim metni de senkronize olur).
3. **Siri**'den günün beyitini, seslendirmeyi, rastgele beyiti, favorileri veya aramayı isteyin.
4. **Ayarlar → Kısayollar** bölümünde en fazla **4 Ana Ekran hızlı eylemi** yapılandırın.

### 8. Gizlilik ve senkronizasyon

1. Kurulumdan sonra her şey **tamamen çevrimdışı** çalışır.
2. İsteğe bağlı **iCloud Senkronizasyonu** (Ayarlar → Veriler), favorileri, beyit listelerini, okuma geçmişini, ustalığı ve serileri iHTC Studio sunucuları üzerinden değil, **özel iCloud'unuz** aracılığıyla yansıtır.
3. Geliştiriciye bahşiş vermek (isteğe bağlı StoreKit satın alımı) hiçbir zaman ücretli içeriğin kilidini açmaz ve hesap oluşturmaz.

## Özellikler

### Seslendirme Stüdyosu

- Vurgulu karaoke tarzı **TTS**
- Ayarlanabilir **hız**, **perde** ve **ses**
- İsteğe bağlı **arka plan sesi** + kilit ekranında **Şimdi Çalıyor**
- Favorilerden / kategorilerden **sürekli okuma** kuyrukları

### Dikey Sürükleyici Okuma

- Klasik **dikey ve yatay** düzenler
- **Pinyin**, geleneksel karakter dönüşümü, arka plan / değerlendirme notları
- Satır sırası her zaman **横批 (varsa) → üst → alt**
- Birden fazla en-boy oranıyla **12 paylaşım kartı stili**

### Çalışma Sistemi

- Soldurma · boşluk doldurma · seslendirme kontrolü · test
- **对对子** oyun modu
- **4 seviyeli ustalık** + seriler

### Bağlamsal Günün Beyiti

- Güneş dönemleri · bayramlar · mevsimler (aynı gün önbelleği / masaüstü yenileme ile)
- Yerel bildirimler (yaklaşık 60 günlük zamanlama penceresi)
- Widget'lar + Denetim Merkezi kontrolleri (iOS 18+)

### Tek Bakışta İçerik

- **3.369 beyit** · **~102 yazar** · **~3.348 ünlü dize** · yaklaşık 3,9 MB yerleşik veri
- Beş gezinme bölümü; liste / ızgara / kart önizlemeleri
- **%100 çevrimdışı** — ağ yok, hesap yok, reklam yok

### Widget'lar, Siri ve Sistem Entegrasyonu

- Günün beyiti / ünlü dize / ilerleme / favoriler widget'ları (+ kilit ekranı)
- Okuma **Canlı Etkinliği** (isteğe bağlı)
- Spotlight dizinleme; **`icouplet://` derin bağlantıları** — bkz. [Kısayol Bağlantıları](url-scheme)
- Ayarlar'daki rehberler: Kullanım · Widget · Kısayollar · Özellik Rehberi'ni yeniden oynatma

### Gizlilik

- Kurulumdan sonra **sıfır dışa giden ağ isteği** (bahşiş için isteğe bağlı Apple StoreKit ve seçtiğiniz sistem paylaşım hedefleri hariç)
