<section lang="en" markdown="1">

iBible supports **`ibible://`** shortcut links for Shortcuts, widgets, Siri, and Home Screen actions.

## Link format

```
ibible://{host}?{params}
```

## Daily & reading

| URL | Opens |
|-----|-------|
| `ibible://today` or `ibible://daily` | Today’s Verse |
| `ibible://random` | Random verse |
| `ibible://verse?b=43&c=3&v=16` | Specific verse (book / chapter / verse) |
| `ibible://chapter?b=43&c=3` | Chapter reader |
| `ibible://read` | Start read-aloud (today if no verse) |
| `ibible://read?b=19&c=23&v=1` | Read aloud a verse |
| `ibible://last-read` | Continue last chapter |
| `ibible://reading-history` | Reading history |

## Browse & study

| URL | Opens |
|-----|-------|
| `ibible://book?id=43` | Book (1–66) |
| `ibible://topics` | All topics |
| `ibible://topic?id=love` | Topic detail |
| `ibible://famous` | Famous verses |
| `ibible://plans` | Reading plans |
| `ibible://plan?id=beginner7` | Specific plan |
| `ibible://favorites` | Favorites |
| `ibible://search?q=love` | Search |

## Settings & guides

| URL | Opens |
|-----|-------|
| `ibible://home` | Home |
| `ibible://settings` | Settings |
| `ibible://usage-guide` | Usage guide |
| `ibible://widget-guide` | Widget guide |
| `ibible://shortcuts-guide` | Shortcuts guide |
| `ibible://feature-guide` | Feature tour |
| `ibible://feedback` | Feedback |

Book numbers follow the common Protestant ordering (1 = Genesis … 66 = Revelation).

</section>
