**Ship faster. Look things up without leaving your pocket.**

iDeveloper (爱开发者 / 愛開發者) is a **developer pocket studio** for iPhone, iPad and Mac — not another random tool pile. **No account required.** Use **176 offline tools** across 13 categories (JSON / XML / YAML / SQL, Base64 / JWT, Hash / AES, timestamps / Cron, regex, colors, HTTP / Curl, code converters, Apple helpers including **device-model encyclopedia ~255 entries** & screen sizes, and more) plus **14 bilingual cheat-sheet topics** (~420 entries). Keep **favorites, history, and snippets**; route text via **Share** with smart suggestions; add **widgets**, **Focus Live Activity**, **Siri & Shortcuts**, and Control Center. **No ads. No tracking. Network tools only run when you start a request.**

## Getting Started (step by step)

### 1. First launch

1. Install from the [App Store](https://apps.apple.com/app/id1240856775) and open **iDeveloper**.
2. Complete the **welcome guide** (tools → references → workflow → system features → privacy).
3. Replay anytime: **Settings → Help → Feature Guide**.
4. In-app **Usage / Widget / Shortcuts** guides live under **Settings → Help**.

### 2. Open a tool and get a result

1. From **Home** or **Browse**, pick a tool (e.g. JSON, Base64, Timestamp, Regex).
2. Paste or type input — or use **Send to Tool** / the **Share** extension with smart recommendations (Suggested → Recent → All).
3. Run the tool, copy the output, and optionally save a **snippet** or restore from **history** (dual-pane tools can restore both sides).
4. Related tools appear as light links when they make sense for the next step.

### 3. Use the offline cheat sheets

1. Open the **Reference** center or jump to a topic (HTTP / Headers / MIME / Git / Docker / Cron / SQL / Regex / SSH / npm / Kubernetes / Linux / JWT / TLS).
2. Search globally or open a specific entry via deep link `ideveloper://reference?id=…`.
3. Pin favorites and open daily reference widgets on the Home Screen.

### 4. Build a workflow you’ll actually keep

1. Star tools and reference entries you use weekly.
2. Revisit **Recent** and **History** instead of re-typing.
3. Save reusable **snippets** for paste-ready fragments.
4. From another app, Share into iDeveloper — the picker ranks the best-matching tools first.

### 5. Widgets, Focus Live Activity & Siri

1. Long-press Home Screen → **Edit Widgets** → add Daily Reference / Quick Tools / Timestamp / Favorites (Home & Lock sizes where available).
2. Start a **Focus** timer to show **Live Activity** on Lock Screen / Dynamic Island.
3. Ask **Siri** or use Shortcuts for search, favorites, focus, and common tools.
4. Configure Home Screen quick actions and Control Center controls (iOS 18+).

### 6. Appearance & privacy

1. Choose theme, accent color (9 options), language (EN / 简 / 繁), and text size.
2. Toggle tab visibility; optionally let widgets follow the app theme; pick alternate app icons.
3. Core tools and cheat sheets work **offline**. Tools that need the network show a clear prompt and only request when **you** tap.
4. Optional tip (StoreKit) never unlocks paywalled content and never creates an account.

Gardez **favoris, historique et snippets** ; envoyez du texte via **Partager** avec des suggestions intelligentes ; ajoutez des **widgets**, une **Live Activity Concentration**, **Siri et Raccourcis** et le Centre de contrôle. **Pas de publicité. Pas de suivi. Les outils réseau ne s’exécutent que lorsque vous lancez une requête.**

## Premiers pas (étape par étape)

### 1. Premier lancement

1. Installez l’app depuis l’[App Store](https://apps.apple.com/app/id1240856775) et ouvrez **iDeveloper**.
2. Suivez le **guide de bienvenue** (outils → références → workflow → fonctions système → confidentialité).
3. Rejouez-le à tout moment : **Réglages → Aide → Guide des fonctionnalités**.
4. Les guides intégrés **Utilisation / Widgets / Raccourcis** se trouvent sous **Réglages → Aide**.

### 2. Ouvrir un outil et obtenir un résultat

1. Depuis **Accueil** ou **Parcourir**, choisissez un outil (p. ex. JSON, Base64, horodatage, regex).
2. Collez ou saisissez votre entrée — ou utilisez **Envoyer vers l’outil** / l’extension **Partager** avec recommandations intelligentes (Suggérés → Récents → Tous).
3. Exécutez l’outil, copiez le résultat et, si vous le souhaitez, enregistrez un **snippet** ou restaurez depuis l’**historique** (les outils à double panneau restaurent les deux côtés).
4. Des outils associés apparaissent sous forme de liens discrets lorsqu’ils sont utiles pour l’étape suivante.

### 3. Utiliser les aide-mémoire hors ligne

1. Ouvrez le centre **Références** ou accédez directement à un thème (HTTP / En-têtes / MIME / Git / Docker / Cron / SQL / Regex / SSH / npm / Kubernetes / Linux / JWT / TLS).
2. Recherchez globalement ou ouvrez une entrée précise via le lien profond `ideveloper://reference?id=…`.
3. Épinglez vos favoris et affichez les widgets de référence quotidienne sur l’écran d’accueil.

### 4. Construire un workflow que vous garderez vraiment

1. Mettez en favori les outils et entrées de référence que vous utilisez chaque semaine.
2. Revenez à **Récents** et **Historique** plutôt que de tout retaper.
3. Enregistrez des **snippets** réutilisables, prêts à coller.
4. Depuis une autre app, partagez vers iDeveloper — le sélecteur classe d’abord les outils les plus pertinents.

### 5. Widgets, Live Activity Concentration et Siri

1. Appui long sur l’écran d’accueil → **Modifier les widgets** → ajoutez Référence du jour / Outils rapides / Horodatage / Favoris (tailles Écran d’accueil et Écran verrouillé selon disponibilité).
2. Lancez un minuteur de **Concentration** pour afficher la **Live Activity** sur l’écran verrouillé / la Dynamic Island.
3. Demandez à **Siri** ou utilisez Raccourcis pour la recherche, les favoris, la concentration et les outils courants.
4. Configurez les actions rapides de l’écran d’accueil et les contrôles du Centre de contrôle (iOS 18+).

### 6. Apparence et confidentialité

1. Choisissez le thème, la couleur d’accent (9 options), la langue (EN / 简 / 繁) et la taille du texte.
2. Affichez ou masquez les onglets ; faites éventuellement suivre aux widgets le thème de l’app ; choisissez une autre icône d’app.
3. Les outils essentiels et les aide-mémoire fonctionnent **hors ligne**. Les outils qui ont besoin du réseau affichent une invite claire et n’envoient une requête que lorsque **vous** appuyez.
4. Le pourboire facultatif (StoreKit) ne débloque jamais de contenu payant et ne crée jamais de compte.

## Pourquoi la télécharger

- **Un studio au lieu de vingt onglets** — formateurs, chiffrement, temps, regex, aides HTTP et outils orientés Apple dans une interface native et sereine.
- **Des aide-mémoire qui vous suivent** — références bilingues hors ligne avec recherche, favoris et widgets.
- **Mémoire de workflow** — favoris, restauration de l’historique, snippets et routage du partage qui suggère le bon outil.
- **Natif là où ça compte** — widgets, Live Activity, extension Partager, Centre de contrôle, Siri, Spotlight, liens profonds.
- **Confidentialité par défaut** — pas de compte, pas de publicité, pas de SDK d’analyse ; vous décidez quand quelque chose passe en ligne.

## Başlarken (adım adım)

### 1. İlk açılış

1. [App Store](https://apps.apple.com/app/id1240856775)’dan yükleyin ve **iDeveloper**’ı açın.
2. **Karşılama rehberini** tamamlayın (araçlar → referanslar → iş akışı → sistem özellikleri → gizlilik).
3. İstediğiniz zaman yeniden izleyin: **Ayarlar → Yardım → Özellik Rehberi**.
4. Uygulama içi **Kullanım / Widget / Kısayollar** rehberleri **Ayarlar → Yardım** altındadır.

### 2. Bir araç açın ve sonuç alın

1. **Ana Sayfa**’dan veya **Göz At**’tan bir araç seçin (ör. JSON, Base64, Zaman Damgası, Regex).
2. Girdiyi yapıştırın veya yazın — ya da **Araca Gönder** / akıllı önerilere (Önerilen → Son Kullanılan → Tümü) sahip **Paylaş** uzantısını kullanın.
3. Aracı çalıştırın, çıktıyı kopyalayın; isterseniz bir **snippet** kaydedin veya **geçmişten** geri yükleyin (çift bölmeli araçlar iki tarafı da geri yükler).
4. Sonraki adım için anlamlı olduğunda ilgili araçlar hafif bağlantılar olarak görünür.

### 3. Çevrimdışı kopya kâğıtlarını kullanın

1. **Referans** merkezini açın veya bir konuya atlayın (HTTP / Başlıklar / MIME / Git / Docker / Cron / SQL / Regex / SSH / npm / Kubernetes / Linux / JWT / TLS).
2. Genel arama yapın veya `ideveloper://reference?id=…` derin bağlantısıyla belirli bir girişi açın.
3. Favorileri sabitleyin ve Ana Ekran’da günlük referans widget’larını açın.

### 4. Gerçekten sürdüreceğiniz bir iş akışı kurun

1. Haftalık kullandığınız araçları ve referans girişlerini yıldızlayın.
2. Yeniden yazmak yerine **Son Kullanılanlar** ve **Geçmiş**’e dönün.
3. Yapıştırmaya hazır parçalar için yeniden kullanılabilir **snippet**’ler kaydedin.
4. Başka bir uygulamadan iDeveloper’a paylaşın — seçici, en uygun araçları en üstte sıralar.

### 5. Widget’lar, Odak Canlı Etkinliği ve Siri

1. Ana Ekran’a uzun basın → **Widget’ları Düzenle** → Günlük Referans / Hızlı Araçlar / Zaman Damgası / Favoriler ekleyin (mevcut olduğunda Ana Ekran ve Kilit Ekranı boyutları).
2. Kilit Ekranı / Dynamic Island’da **Canlı Etkinlik** göstermek için bir **Odak** zamanlayıcısı başlatın.
3. Arama, favoriler, odak ve sık kullanılan araçlar için **Siri**’ye sorun veya Kısayollar’ı kullanın.
4. Ana Ekran hızlı eylemlerini ve Denetim Merkezi kontrollerini yapılandırın (iOS 18+).

### 6. Görünüm ve gizlilik

1. Tema, vurgu rengi (9 seçenek), dil (EN / 简 / 繁) ve metin boyutunu seçin.
2. Sekme görünürlüğünü değiştirin; isterseniz widget’ların uygulama temasını izlemesini sağlayın; alternatif uygulama simgeleri seçin.
3. Temel araçlar ve kopya kâğıtları **çevrimdışı** çalışır. Ağ gerektiren araçlar net bir uyarı gösterir ve yalnızca **siz** dokunduğunuzda istek gönderir.
4. İsteğe bağlı bahşiş (StoreKit) hiçbir zaman ücretli içeriğin kilidini açmaz ve hesap oluşturmaz.
